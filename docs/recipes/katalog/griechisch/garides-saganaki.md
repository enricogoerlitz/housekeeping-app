# Garides Saganaki

![Garides Saganaki](../../pictures/garides-saganaki.jpg)

Garnelen in würziger Tomatensauce mit Feta, kurz überbacken. Vegetarisch mit Halloumi.

## Zutaten

| Menge | Zutat            | Gruppe | Variante     | Hinweis                     | Einkauf |
| ----- | ---------------- | ------ | ------------ | --------------------------- | ------- |
| 250 g | Garnelen         |        | Mit Garnelen | geschält, aufgetaut         | Menge   |
| 150 g | Halloumi         |        | Vegetarisch  | in Würfeln                  | Menge   |
| 1     | Zwiebel          |        |              | fein gewürfelt              |         |
| 2     | Knoblauch        |        |              | Zehen                       |         |
| 400 g | Stückige Tomaten |        |              |                             |         |
| 50 ml | Weißwein         |        |              | trocken, ersatzweise Wasser |         |
| 2 EL  | Olivenöl         |        |              |                             |         |
| 1 TL  | Oregano          |        |              |                             |         |
| 100 g | Feta             |        |              | in Würfeln                  |         |
| 2 EL  | Petersilie       |        |              | gehackt                     |         |
| 1     | Baguette         |        |              | zum Dippen                  |         |
|       | Salz             |        |              |                             |         |
|       | Pfeffer          |        |              |                             |         |

## Zubereitung

1. Zwiebel in Olivenöl 5 Minuten glasig dünsten, Knoblauch 1 Minute mitbraten. ⏱ 5
2. Mit Weißwein ablöschen, Tomaten und Oregano zugeben und 10 Minuten einkochen. ⏱ 10
3. [Mit Garnelen] Garnelen in die Sauce geben und 3 Minuten garen, bis sie rosa sind. ⏱ 3
4. [Vegetarisch] Halloumi in einer separaten Pfanne goldbraun anbraten und in die Sauce geben.
5. Feta darüber verteilen, 3 Minuten bei geschlossenem Deckel schmelzen lassen. ⏱ 3
6. Mit Petersilie bestreuen und mit Brot servieren.

## Notizen

TK-Garnelen über Nacht im Kühlschrank auftauen.
