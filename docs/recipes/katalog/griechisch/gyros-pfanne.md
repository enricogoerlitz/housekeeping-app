# Gyros-Pfanne mit Reis

![Gyros-Pfanne mit Reis](../../pictures/gyros-pfanne.jpg)

Gyros aus der Pfanne mit Paprika und Zwiebeln auf Reis, mit Tzatziki. Vegetarisch mit Räuchertofu.

## Zutaten

| Menge  | Zutat             | Gruppe | Variante            | Hinweis            | Einkauf |
| ------ | ----------------- | ------ | ------------------- | ------------------ | ------- |
| 350 g  | Schweineschnitzel |        | Mit Schweinefleisch | in Streifen        | Menge   |
| 250 g  | Räuchertofu       |        | Vegetarisch         | in dünnen Streifen | Menge   |
| 2 TL   | Gyrosgewürz       |        |                     |                    |         |
| 1      | Zwiebel           |        |                     | in Streifen        |         |
| 1      | Paprika           |        |                     | rot, in Streifen   |         |
| 2 EL   | Olivenöl          |        |                     |                    |         |
| 150 g  | Basmatireis       |        |                     |                    | Menge   |
| 100 g  | Tzatziki          |        |                     |                    |         |
| 1      | Zitrone           |        |                     | in Spalten         |         |
|        | Salz              |        |                     |                    |         |
| 300 ml | Wasser            |        |                     | zum Reiskochen     | nie     |

## Zubereitung

1. Reis mit 300 ml Wasser und einer Prise Salz aufkochen und zugedeckt 12 Minuten auf kleinster Stufe garen. ⏱ 12
2. [Mit Schweinefleisch] Fleisch mit Gyrosgewürz vermengen und in einer heißen Pfanne in 1 EL Öl 6 Minuten scharf anbraten, herausnehmen. ⏱ 6
3. [Vegetarisch] Tofustreifen mit Gyrosgewürz mischen und in 1 EL Öl 5 Minuten knusprig braten, herausnehmen. ⏱ 5
4. Zwiebel und Paprika im restlichen Öl 5 Minuten braten. ⏱ 5
5. Fleisch bzw. Tofu zurückgeben, 1 Minute mitbraten und abschmecken.
6. Auf Reis anrichten, mit Tzatziki und Zitronenspalten servieren.

## Notizen

Gyrosgewürz im Supermarkt (Gewürzregal). Selbstmischung: Paprika, Oregano, Thymian, Knoblauchpulver, Kreuzkümmel.
