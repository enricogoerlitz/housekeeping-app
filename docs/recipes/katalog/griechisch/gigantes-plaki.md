# Gigantes plaki

![Gigantes plaki](../../pictures/gigantes-plaki.jpg)

Dicke weiße Riesenbohnen im Ofen in Tomatensauce mit Dill gebacken. Ein einfaches, sättigendes Ofengericht.

## Zutaten

| Menge  | Zutat            | Gruppe | Variante | Hinweis                                                   | Einkauf |
| ------ | ---------------- | ------ | -------- | --------------------------------------------------------- | ------- |
| 2 Dose | Weiße Bohnen     |        |          | Riesenbohnen, 400 g, abgetropft, ersatzweise Butterbohnen |         |
| 1      | Zwiebel          |        |          | gewürfelt                                                 |         |
| 3      | Knoblauch        |        |          | Zehen                                                     |         |
| 1      | Karotte          |        |          | gewürfelt                                                 |         |
| 400 g  | Stückige Tomaten |        |          |                                                           |         |
| 1 EL   | Tomatenmark      |        |          |                                                           |         |
| 4 EL   | Olivenöl         |        |          |                                                           |         |
| 2 EL   | Dill             |        |          | frisch, gehackt                                           |         |
| 1 EL   | Petersilie       |        |          | gehackt                                                   |         |
| 1 TL   | Zucker           |        |          |                                                           |         |
| 100 g  | Feta             |        | Mit Feta | in Scheiben                                               |         |
|        | Salz             |        |          |                                                           |         |
|        | Pfeffer          |        |          |                                                           |         |

## Zubereitung

1. Backofen auf 190 °C Ober-/Unterhitze vorheizen.
2. Zwiebel, Karotte in 2 EL Olivenöl 6 Minuten dünsten, Knoblauch und Tomatenmark 1 Minute mitbraten. ⏱ 6
3. Tomaten, Zucker, Salz, Pfeffer zugeben und 8 Minuten köcheln. ⏱ 8
4. Bohnen und die Hälfte der Kräuter unterheben, in eine Auflaufform füllen.
5. [Mit Feta] Feta in Scheiben auf die Bohnen legen.
6. Mit restlichem Olivenöl beträufeln und 30 Minuten backen, bis die Oberfläche leicht karamellisiert. ⏱ 30
7. Mit den übrigen Kräutern bestreuen.

## Notizen

Mit Brot servieren. Lauwarm am besten.
