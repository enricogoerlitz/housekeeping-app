# Briam

![Briam](../../pictures/briam.jpg)

Griechisches Ofengemüse aus Kartoffeln, Zucchini, Aubergine und Tomaten, langsam in Olivenöl geschmort.

## Zutaten

| Menge  | Zutat      | Gruppe | Variante | Hinweis                  | Einkauf |
| ------ | ---------- | ------ | -------- | ------------------------ | ------- |
| 3      | Kartoffel  |        |          | festkochend, in Scheiben |         |
| 1      | Zucchini   |        |          | in Scheiben              |         |
| 1      | Aubergine  |        |          | in Würfeln               |         |
| 1      | Zwiebel    |        |          | in Ringen                |         |
| 3      | Tomate     |        |          | gewürfelt                |         |
| 3      | Knoblauch  |        |          | Zehen                    |         |
| 5 EL   | Olivenöl   |        |          |                          |         |
| 1 EL   | Oregano    |        |          |                          |         |
| 2 EL   | Petersilie |        |          | gehackt                  |         |
| 100 ml | Wasser     |        |          |                          | nie     |
| 100 g  | Feta       |        | Mit Feta |                          |         |
|        | Salz       |        |          |                          |         |
|        | Pfeffer    |        |          |                          |         |

## Zubereitung

1. Backofen auf 200 °C Ober-/Unterhitze vorheizen.
2. Gemüse und Knoblauch in einer großen Form mit Olivenöl, Oregano, Salz und Pfeffer gründlich vermengen.
3. Wasser zugießen, die Form mit Alufolie abdecken.
4. 30 Minuten im Ofen garen. ⏱ 30
5. Folie entfernen, Gemüse wenden und weitere 30 Minuten garen, bis es gebräunt ist. ⏱ 30
6. [Mit Feta] Feta zerbröseln und in den letzten 5 Minuten darüber backen.
7. Mit Petersilie bestreuen.

## Notizen

Zu Brot und Joghurt, oder als Beilage zu Fisch.
