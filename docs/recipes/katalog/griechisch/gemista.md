# Gemista

![Gemista](../../pictures/gemista.jpg)

Gefüllte Tomaten und Paprika mit Kräuterreis, im Ofen mit Kartoffeln geschmort. Klassisch griechisch ist die vegetarische Version.

## Zutaten

| Menge  | Zutat        | Gruppe  | Variante        | Hinweis                   | Einkauf |
| ------ | ------------ | ------- | --------------- | ------------------------- | ------- |
| 4      | Tomate       |         |                 | große, Deckel abschneiden | Menge   |
| 2      | Paprika      |         |                 | rot, Deckel abschneiden   | Menge   |
| 100 g  | Rundkornreis | Füllung |                 | Menge                     |         |

## Zubereitung

1. Backofen auf 190 °C Ober-/Unterhitze vorheizen. Tomaten und Paprika aushöhlen, das Tomatenfruchtfleisch pürieren und aufheben.
2. Zwiebel in 2 EL Olivenöl 5 Minuten anschwitzen, Knoblauch zugeben. ⏱ 5
3. Reis, Kräuter, Tomatenpüree, Salz und Pfeffer unterrühren.
4. [Mit Hackfleisch] Hack vorher 5 Minuten mit der Zwiebel anbraten.
5. Gemüse zu zwei Dritteln mit der Füllung füllen (der Reis quillt), Deckel aufsetzen.
6. Kartoffelspalten zwischen das Gemüse in eine Form legen, mit Tomatenmark, Wasser, restlichem Olivenöl, Salz übergießen.
7. Im Ofen 60 Minuten garen, bis Reis und Kartoffeln weich sind. 10 Minuten ruhen lassen. ⏱ 60

## Notizen

Lauwarm schmeckt Gemista am besten, dazu Feta. Rundkornreis ersatzweise Milchreis.
