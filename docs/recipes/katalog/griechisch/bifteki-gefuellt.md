# Bifteki mit Feta gefüllt

![Bifteki mit Feta gefüllt](../../pictures/bifteki-gefuellt.jpg)

Saftige Hacksteaks mit Feta-Kern, direkt aus der Pfanne. Vegetarisch aus Kichererbsen und Zucchini.

## Zutaten

| Menge  | Zutat        | Gruppe | Variante       | Hinweis                   | Einkauf |
| ------ | ------------ | ------ | -------------- | ------------------------- | ------- |
| 350 g  | Rinderhack   |        | Mit Rinderhack |                           | Menge   |
| 1 Dose | Kichererbsen |        | Vegetarisch    | 400 g, abgetropft         |         |
| 1      | Zucchini     |        | Vegetarisch    | geraspelt und ausgedrückt |         |
| 4 EL   | Semmelbrösel |        |                |                           |         |
| 1      | Zwiebel      |        |                | fein gerieben             |         |
| 1      | Ei           |        |                |                           |         |
| 1 TL   | Oregano      |        |                |                           |         |
| 80 g   | Feta         |        |                | in 2 Stücken              |         |
| 2 EL   | Olivenöl     |        |                |                           |         |
| 1      | Zitrone      |        |                | in Spalten                |         |
|        | Salz         |        |                |                           |         |
|        | Pfeffer      |        |                |                           |         |

## Zubereitung

1. [Mit Rinderhack] Hack mit Zwiebel, Ei, Semmelbröseln, Oregano, Salz und Pfeffer kräftig verkneten.
2. [Vegetarisch] Kichererbsen grob zerdrücken, mit Zucchini, Zwiebel, Ei, Semmelbröseln, Oregano, Salz und Pfeffer vermengen und 15 Minuten ruhen lassen. ⏱ 15
3. Masse in 2 große flache Portionen teilen, je ein Stück Feta in die Mitte legen und rundum verschließen.
4. In einer Pfanne in Olivenöl bei mittlerer Hitze 6 Minuten je Seite braten. ⏱ 12
5. Mit Zitrone, Bratkartoffeln oder Reis und Salat servieren.

## Notizen

Die vegetarische Masse ist weicher: vorsichtig wenden. Feta nicht zu nah an den Rand legen.
