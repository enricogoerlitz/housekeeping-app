# Loukoumades

![Loukoumades](../../pictures/loukoumades.jpg)

Griechische Hefekrapfen, außen knusprig, innen luftig, mit Honig und Zimt.

## Zutaten

| Menge   | Zutat          | Gruppe | Variante | Hinweis               | Einkauf |
| ------- | -------------- | ------ | -------- | --------------------- | ------- |
| 200 g   | Mehl           |        |          |                       |         |
| 0.5     | Hefe           |        |          | Würfel (21 g) frisch  |         |
| 200 ml  | Wasser         |        |          | lauwarm               | nie     |
| 1 EL    | Zucker         |        |          |                       |         |
| 1 Prise | Salz           |        |          |                       |         |
| 500 ml  | Sonnenblumenöl |        |          | neutral, Sonnenblumen |         |
| 4 EL    | Honig          |        |          |                       |         |
| 1 TL    | Zimt           |        |          |                       |         |
| 30 g    | Walnüsse       |        |          | gehackt               |         |

## Zubereitung

1. Hefe im lauwarmen Wasser mit Zucker auflösen, mit Mehl und Salz zu einem zähflüssigen Teig rühren.
2. Abgedeckt 1 Stunde an einem warmen Ort gehen lassen, bis er sich verdoppelt hat. ⏱ 60
3. Öl in einem Topf auf 175 °C erhitzen.
4. Mit zwei feuchten Löffeln walnussgroße Bällchen abstechen und portionsweise 3–4 Minuten goldbraun frittieren. ⏱ 4
5. Auf Küchenpapier abtropfen, Honig leicht erwärmen und darüber geben, mit Zimt und Walnüssen bestreuen.

## Notizen

Sofort servieren; Öl-Temperatur mit Thermometer prüfen.
