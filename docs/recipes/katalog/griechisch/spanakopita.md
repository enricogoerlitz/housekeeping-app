# Spanakopita

![Spanakopita](../../pictures/spanakopita.jpg)

Knusprige Spinat-Feta-Pastete im Blätterteig. Mit Hack wird sie zur herzhaften Hauptmahlzeit.

## Zutaten

| Menge | Zutat            | Gruppe | Variante | Hinweis                       | Einkauf |
| ----- | ---------------- | ------ | -------- | ----------------------------- | ------- |
| 450 g | Blattspinat      |        |          | TK, aufgetaut und ausgedrückt |         |
| 200 g | Feta             |        |          | zerbröselt                    |         |
| 100 g | Ricotta          |        |          |                               |         |
| 1     | Zwiebel          |        |          | fein gewürfelt                |         |
| 2     | Frühlingszwiebel |        |          | in Ringen                     |         |
| 2 EL  | Dill             |        |          | frisch, gehackt               |         |
| 1     | Ei               |        |          |                               |         |
| 2 EL  | Olivenöl         |        |          |                               |         |
| 250 g | Rinderhack       |        | Mit Hack |                               | Menge   |
| 1     | Blätterteig      |        |          | Rolle, ersatzweise Filoteig   |         |
| 1     | Eier             |        |          | zum Bestreichen               |         |
|       | Salz             |        |          |                               |         |
|       | Pfeffer          |        |          |                               |         |

## Zubereitung

1. Backofen auf 200 °C Ober-/Unterhitze vorheizen.
2. Zwiebel und Frühlingszwiebeln in Olivenöl 5 Minuten anschwitzen.
3. [Mit Hack] Hack 8 Minuten mitbraten. ⏱ 8
4. Abkühlen lassen, mit Spinat, Feta, Ricotta, Ei, Dill, Pfeffer und etwas Salz mischen.
5. Blätterteig halbieren; eine Hälfte auf ein Blech legen, Füllung darauf verteilen, dabei einen 2 cm Rand lassen.
6. Zweite Hälfte darüber legen, Ränder festdrücken, einstechen, mit Eigelb bestreichen.
7. 30–35 Minuten goldbraun backen. ⏱ 30

## Notizen

Filoteig (Asia-/Griechischer Laden) ist authentischer: 6–8 Blätter mit Olivenöl bestreichen schichten.
