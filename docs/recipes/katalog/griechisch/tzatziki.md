# Tzatziki

![Tzatziki](../../pictures/tzatziki.jpg)

Griechischer Joghurtdip mit Gurke und viel Knoblauch, zu Fleisch, Gemüse und Brot.

## Zutaten

| Menge | Zutat                | Gruppe | Variante | Hinweis               | Einkauf |
| ----- | -------------------- | ------ | -------- | --------------------- | ------- |
| 300 g | Griechischer Joghurt |        |          | 10 % Fett             | Menge   |
| 0.5   | Salatgurke           |        |          | gerieben, ausgedrückt |         |
| 2     | Knoblauch            |        |          | Zehen, gepresst       |         |
| 2 EL  | Olivenöl             |        |          |                       |         |
| 1 EL  | Weißweinessig        |        |          |                       |         |
| 1 EL  | Dill                 |        |          | frisch, gehackt       |         |
|       | Salz                 |        |          |                       |         |

## Zubereitung

1. Gurke grob raspeln, mit Salz bestreuen, 10 Minuten stehen lassen und kräftig ausdrücken. ⏱ 10
2. Joghurt mit Knoblauch, Olivenöl und Essig glatt rühren.
3. Gurke und Dill unterheben, mit Salz abschmecken.
4. Vor dem Servieren mindestens 30 Minuten durchziehen lassen, mit Olivenöl beträufeln.

## Notizen

Für eine festere Konsistenz den Joghurt 2 Stunden in einem Tuch abtropfen lassen.
