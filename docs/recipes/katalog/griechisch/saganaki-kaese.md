# Saganaki mit Honig

![Saganaki mit Honig](../../pictures/saganaki-kaese.jpg)

Gebratener Käse mit knuspriger Kruste, mit Honig und Sesam.

## Zutaten

| Menge | Zutat    | Gruppe | Variante | Hinweis                                        | Einkauf |
| ----- | -------- | ------ | -------- | ---------------------------------------------- | ------- |
| 200 g | Halloumi |        |          | in dicken Scheiben, ersatzweise Kefalograviera | Menge   |
| 2 EL  | Mehl     |        |          |                                                |         |
| 2 EL  | Olivenöl |        |          |                                                |         |
| 1 EL  | Honig    |        |          |                                                |         |
| 1 EL  | Sesam    |        |          |                                                |         |
| 1     | Zitrone  |        |          | in Spalten                                     |         |

## Zubereitung

1. Käsescheiben in Wasser tauchen und im Mehl wenden.
2. Olivenöl in einer Pfanne erhitzen, Käse 2 Minuten je Seite goldbraun braten. ⏱ 4
3. Mit Honig beträufeln, Sesam streuen, mit Zitrone servieren.

## Notizen

Echter Saganaki aus Kefalograviera, Graviera oder Kasseri; Halloumi ist der gängige Ersatz.
