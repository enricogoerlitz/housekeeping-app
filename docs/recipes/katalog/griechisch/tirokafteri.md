# Tirokafteri

![Tirokafteri](../../pictures/tirokafteri.jpg)

Scharfer Fetadip mit Paprika und Chili, ein typischer Meze.

## Zutaten

| Menge  | Zutat                | Gruppe | Variante | Hinweis                       | Einkauf |
| ------ | -------------------- | ------ | -------- | ----------------------------- | ------- |
| 200 g  | Feta                 |        |          |                               |         |
| 100 g  | Griechischer Joghurt |        |          |                               |         |
| 1      | Paprika              |        |          | rot, aus dem Glas, abgetropft |         |
| 0.5 TL | Chiliflocken         |        |          |                               |         |
| 2 EL   | Olivenöl             |        |          |                               |         |
| 1 EL   | Zitronen             |        |          | Saft                          |         |

## Zubereitung

1. Alle Zutaten im Mixer oder mit dem Stabmixer cremig pürieren.
2. Mit Chili und Zitronensaft abschmecken, mindestens 20 Minuten kalt stellen. ⏱ 20

## Notizen

Hält sich im Kühlschrank 3 Tage.
