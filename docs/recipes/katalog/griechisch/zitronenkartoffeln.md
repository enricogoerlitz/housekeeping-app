# Zitronenkartoffeln

![Zitronenkartoffeln](../../pictures/zitronenkartoffeln.jpg)

Im Ofen gebackene Kartoffelspalten in Zitronen-Olivenöl-Sud, die perfekte Beilage zu Gegrilltem.

## Zutaten

| Menge  | Zutat     | Gruppe | Variante | Hinweis                   | Einkauf |
| ------ | --------- | ------ | -------- | ------------------------- | ------- |
| 600 g  | Kartoffel |        |          | festkochend, in Spalten   | Menge   |
| 2      | Zitrone   |        |          | Saft von 1, 1 in Scheiben |         |
| 4 EL   | Olivenöl  |        |          |                           |         |
| 3      | Knoblauch |        |          | Zehen                     |         |
| 1 EL   | Oregano   |        |          |                           |         |
| 200 ml | Wasser    |        |          |                           | nie     |
|        | Salz      |        |          |                           |         |
|        | Pfeffer   |        |          |                           |         |

## Zubereitung

1. Backofen auf 200 °C Ober-/Unterhitze vorheizen.
2. Kartoffeln in eine Form geben, mit Zitronensaft, Olivenöl, Wasser, Oregano, Salz, Pfeffer und Knoblauch vermengen.
3. Zitronenscheiben dazwischen legen.
4. 30 Minuten backen, wenden, weitere 30 Minuten backen, bis die Kartoffeln gebräunt sind und die Flüssigkeit eingekocht ist. ⏱ 60

## Notizen

Die Kartoffeln erst nach der halben Zeit wenden, damit sie die Brühe aufsaugen.
