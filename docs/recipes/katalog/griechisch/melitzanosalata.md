# Melitzanosalata

![Melitzanosalata](../../pictures/melitzanosalata.jpg)

Rauchiger Auberginendip mit Knoblauch, Zitrone und Olivenöl.

## Zutaten

| Menge | Zutat      | Gruppe | Variante | Hinweis         | Einkauf |
| ----- | ---------- | ------ | -------- | --------------- | ------- |
| 2     | Aubergine  |        |          |                 | Menge   |
| 2     | Knoblauch  |        |          | Zehen, gepresst |         |
| 3 EL  | Olivenöl   |        |          |                 |         |
| 1     | Zitrone    |        |          | Saft            |         |
| 2 EL  | Petersilie |        |          | gehackt         |         |
|       | Salz       |        |          |                 |         |
|       | Pfeffer    |        |          |                 |         |

## Zubereitung

1. Backofen auf 220 °C Grill/Oberhitze vorheizen. Auberginen mehrfach einstechen, auf ein Blech legen.
2. 35–40 Minuten rösten, einmal wenden, bis die Haut verkohlt und das Innere ganz weich ist. ⏱ 40
3. Etwas abkühlen lassen, Fruchtfleisch herauslöffeln und abtropfen lassen.
4. Mit Gabel zerdrücken, Knoblauch, Zitronensaft, Olivenöl, Salz und Pfeffer unterrühren.
5. Mit Petersilie bestreuen.

## Notizen

Direkt über der Gasflamme gegart wird er noch rauchiger.
