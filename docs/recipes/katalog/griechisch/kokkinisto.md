# Kokkinisto vom Rind

![Kokkinisto vom Rind](../../pictures/kokkinisto.jpg)

Langsam geschmortes Rind in Tomatensauce mit Lorbeer, Zimt und Kartoffeln. Vegetarisch mit Kichererbsen und Pilzen.

| Menge  | Zutat             | Gruppe | Variante    | Hinweis                 | Einkauf |
| ------ | ----------------- | ------ | ----------- | ----------------------- | ------- |
| 500 g  | Rindergulasch     |        | Mit Rind    |                         | Menge   |
| 300 g  | Champignons       |        | Vegetarisch | geviertelt              | Menge   |
| 1 Dose | Kichererbsen      |        | Vegetarisch | 400 g, abgetropft       |         |
| 1      | Zwiebel           |        |             | gewürfelt               |         |
| 3      | Knoblauch         |        |             | Zehen                   |         |

| 3      | Kartoffel         |        |             | festkochend, geviertelt |         |

## Zubereitung

1. [Mit Rind] Fleisch salzen und in Olivenöl portionsweise 8 Minuten kräftig anbraten, herausnehmen. ⏱ 8
2. [Vegetarisch] Pilze in Olivenöl 8 Minuten kräftig anbraten, herausnehmen. ⏱ 8
3. Zwiebel und Knoblauch im Bratfett 4 Minuten dünsten, mit Rotwein ablöschen und einkochen.
4. Tomaten, Wasser, Zimt und Lorbeer zugeben.
5. [Mit Rind] Fleisch zurückgeben und zugedeckt 90 Minuten bei kleiner Hitze schmoren. ⏱ 90
6. [Vegetarisch] Pilze und Kichererbsen zugeben, 20 Minuten köcheln. ⏱ 20
7. Kartoffeln zugeben und weitere 30 Minuten garen (vegetarisch 25 Minuten). ⏱ 30
8. Gewürze entfernen, abschmecken.

## Notizen

Schmeckt am nächsten Tag noch besser. Dazu Reis oder Brot.
