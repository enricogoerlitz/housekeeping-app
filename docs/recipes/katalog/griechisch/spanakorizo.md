# Spanakorizo

![Spanakorizo](../../pictures/spanakorizo.jpg)

Griechischer Spinatreis mit Dill und Zitrone, ein leichtes Alltagsgericht, mit Feta überstreut.

## Zutaten

| Menge  | Zutat            | Gruppe | Variante     | Hinweis             | Einkauf |
| ------ | ---------------- | ------ | ------------ | ------------------- | ------- |
| 300 g  | Blattspinat      |        |              | frisch oder TK      |         |
| 120 g  | Langkornreis     |        |              |                     | Menge   |
| 1      | Zwiebel          |        |              | gewürfelt           |         |
| 2      | Frühlingszwiebel |        |              | in Ringen           |         |
| 3 EL   | Olivenöl         |        |              |                     |         |
| 1 EL   | Tomatenmark      |        |              |                     |         |
| 1      | Zitrone          |        |              | Saft                |         |
| 2 EL   | Dill             |        |              | frisch, gehackt     |         |
| 100 g  | Feta             |        |              | zerbröselt          |         |
| 200 g  | Garnelen         |        | Mit Garnelen | geschält, aufgetaut | Menge   |
| 400 ml | Wasser           |        |              |                     | nie     |
|        | Salz             |        |              |                     |         |
|        | Pfeffer          |        |              |                     |         |

## Zubereitung

1. Zwiebel und Frühlingszwiebeln in Olivenöl 5 Minuten glasig dünsten. ⏱ 5
2. Tomatenmark und Reis zugeben und 1 Minute rühren.
3. Mit 400 ml Wasser aufgießen, salzen und zugedeckt 10 Minuten köcheln. ⏱ 10
4. Spinat unterheben und weitere 8 Minuten garen, bis der Reis weich ist. ⏱ 8
5. [Mit Garnelen] Garnelen in einer Pfanne mit etwas Öl 3 Minuten braten und über den Reis geben. ⏱ 3
6. Mit Zitronensaft, Dill und Pfeffer abschmecken, mit Feta servieren.

## Notizen

TK-Spinat vorher auftauen und gut ausdrücken.
