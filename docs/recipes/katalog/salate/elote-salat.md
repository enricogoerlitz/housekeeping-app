# Elote-Salat mit gegrilltem Mais

![Elote-Salat mit gegrilltem Mais](../../pictures/elote-salat.jpg)

Mexikanischer Straßenmais als Salat: gegrillter Mais mit Limetten-Mayo-Dressing, Cotija- oder Fetakäse, Koriander und knusprigen Tortillachips. Perfekt zum Grillen.

## Zutaten

| Menge      | Zutat         | Gruppe   | Variante | Hinweis                                | Einkauf |
| ---------- | ------------- | -------- | -------- | -------------------------------------- | ------- |
| 4          | Maiskolben    | Salat    |          | vorgegart oder 400 g Mais aus der Dose |         |
| 1 EL       | Rapsöl        | Salat    |          |                                        |         |
| 1          | Rote Zwiebel  | Salat    |          | fein gewürfelt                         |         |
| 1 Bund     | Koriander     | Salat    |          | gehackt                                |         |

| 1 TL       | Chiliflocken  | Dressing |          |                                        |         |

| 1          | Knoblauch     | Dressing |          | Zehe, gerieben                         |         |

| 1 Prise    | Salz          |          |          |                                        |         |

## Zubereitung

1. Maiskörner vom Kolben schneiden oder Dosenmais gut abtropfen und trocken tupfen.
2. Eine Pfanne sehr heiß werden lassen, Mais in Öl in zwei Portionen je 5 Minuten braten, bis er dunkle Röstflecken hat. ⏱ 10
3. Alle Dressing-Zutaten verrühren und mit Salz abschmecken.
4. Warmen Mais mit Zwiebel, Koriander und Dressing mischen.
5. Mit Feta und Tortillachips bestreuen und lauwarm servieren.

## Notizen

Auf dem Grill: Kolben direkt rösten, dann abschneiden. Cotija durch Feta ersetzt, da leichter erhältlich.
