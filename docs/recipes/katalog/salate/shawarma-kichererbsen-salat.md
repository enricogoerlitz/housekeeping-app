# Shawarma-Kichererbsen-Salat mit Joghurt-Tahin-Sauce

![Shawarma-Kichererbsen-Salat mit Joghurt-Tahin-Sauce](../../pictures/shawarma-kichererbsen-salat.jpg)

Knusprig geröstete Shawarma-Kichererbsen auf Gurken-Tomaten-Salat mit Joghurt-Tahin-Dressing. Sehr proteinreich und ideal vorzubereiten.

## Zutaten

| Menge   | Zutat              | Gruppe   | Variante     | Hinweis                                             | Einkauf |
| ------- | ------------------ | -------- | ------------ | --------------------------------------------------- | ------- |
| 2 Dosen | Kichererbsen       | Salat    |              | abgetropft, trocken getupft                         |         |
| 2 EL    | Olivenöl           | Salat    |              |                                                     |         |
| 2 TL    | Shawarma-Gewürz    | Salat    |              | oder Kreuzkümmel, Paprika, Koriander, Zimt gemischt |         |
| ½       | Salatgurke         | Salat    |              | in Würfeln                                          |         |
| 2       | Tomate             | Salat    |              | gewürfelt                                           |         |
| 1       | Romanasalat        | Salat    |              | in Streifen                                         |         |
| ½       | Rote Zwiebel       | Salat    |              | in dünnen Ringen                                    |         |
| 1 Bund  | Petersilie         | Salat    |              | gehackt                                             |         |

## Zubereitung

1. Ofen auf 220 °C Ober-/Unterhitze vorheizen. Kichererbsen mit Öl, Gewürz und Salz mischen und 25 Minuten rösten, bis sie knusprig sind. ⏱ 25
2. [Mit Hähnchen] Hähnchenstreifen mit Gewürz und Salz mischen und in einer heißen Pfanne 8 Minuten braten. ⏱ 8
3. Joghurt, Tahin, Zitronensaft, Knoblauch und Wasser zu einem cremigen Dressing verrühren, salzen.
4. Pinienkerne in einer trockenen Pfanne 2 Minuten rösten.
5. Gemüse und Petersilie auf Schalen verteilen, Kichererbsen und ggf. Hähnchen darauflegen.
6. Mit Dressing und Pinienkernen servieren.

## Notizen

Kichererbsen wirklich gut trocknen, sonst werden sie nicht knusprig. Pinienkerne ersetzbar durch Mandeln.
