# Warmer Ofenkürbis-Salat mit Feta und Granatapfel

![Warmer Ofenkürbis-Salat mit Feta und Granatapfel](../../pictures/ofenkuerbis-salat-feta.jpg)

Karamellisierter Hokkaido aus dem Ofen auf Rucola, mit Feta, Granatapfel, Kürbiskernen und Ahorn-Zitronen-Dressing. Perfekt für kühle Tage.

## Zutaten

| Menge   | Zutat              | Gruppe   | Variante     | Hinweis               | Einkauf |
| ------- | ------------------ | -------- | ------------ | --------------------- | ------- |
| 1       | Hokkaido-Kürbis    | Salat    |              | ca. 600 g, in Spalten |         |
| 1       | Rote Zwiebel       | Salat    |              | in Spalten            |         |
| 2 EL    | Olivenöl           | Salat    |              |                       |         |
| 1 TL    | Kreuzkümmel        | Salat    |              |                       |         |
| 80 g    | Rucola             | Salat    |              |                       |         |
| 150 g   | Feta               | Salat    |              | zerbröselt            | 1×      |
| ½       | Granatapfel        | Salat    |              | Kerne                 | Menge   |
| 3 EL    | Olivenöl           | Dressing |              |                       |         |
| 2 EL    | Zitronen           | Dressing |              | Saft                  |         |
| 1 EL    | Ahornsirup         | Dressing |              |                       |         |
| 1 TL    | Senf               | Dressing |              |                       |         |
| 1 Prise | Salz               | Dressing |              |                       |         |
| 3 EL    | Kürbiskerne        | Topping  |              |                       |         |
| 2       | Hähnchenbrustfilet | Protein  | Mit Hähnchen |                       |         |
| 1 Prise | Pfeffer            |          |              |                       |         |

## Zubereitung

1. Ofen auf 220 °C Ober-/Unterhitze vorheizen. Kürbis und Zwiebel mit Öl, Kreuzkümmel, Salz und Pfeffer mischen und 25-30 Minuten rösten, bis die Kanten karamellisieren. ⏱ 28
2. [Mit Hähnchen] Hähnchen salzen, pfeffern, in der Pfanne je Seite 5-6 Minuten braten, ruhen lassen, aufschneiden. ⏱ 12
3. Kürbiskerne die letzten 5 Minuten mit auf das Blech geben oder in einer trockenen Pfanne rösten.
4. Dressing aus Öl, Zitronensaft, Ahornsirup, Senf und Salz verrühren.
5. Rucola mit etwas Dressing mischen, warmen Kürbis, Feta und Granatapfel darauf anrichten.
6. Restliches Dressing darüber, mit Kürbiskernen bestreuen.

## Notizen

Hokkaido-Schale kann mitgegessen werden. Statt Feta passt Ziegenkäse.
