# Chinesischer Sesam-Kohlsalat

![Chinesischer Sesam-Kohlsalat](../../pictures/chinesischer-sesam-kohlsalat.jpg)

Knuspriger Weißkohl und Karotte in süß-saurem Sesam-Dressing mit gerösteten Nudelnestern und Cashews. Passt zu Gebratenem und Reis.

## Zutaten

| Menge      | Zutat            | Gruppe   | Variante | Hinweis                                | Einkauf |
| ---------- | ---------------- | -------- | -------- | -------------------------------------- | ------- |
| 400 g      | Weißkohl         | Salat    |          | sehr fein gehobelt                     |         |
| 2          | Karotte          | Salat    |          | in Streifen                            |         |
| 4          | Frühlingszwiebel | Salat    |          | in Ringen                              |         |
| 1 Bund     | Koriander        | Salat    |          | gehackt                                |         |
| 3 EL       | Sojasauce        | Dressing |          |                                        |         |
| 3 EL       | Reisessig        | Dressing |          |                                        |         |
| 1 EL       | Sesamöl          | Dressing |          |                                        |         |
| 1 EL       | Zucker           | Dressing |          |                                        |         |
| 1          | Knoblauch        | Dressing |          | Zehe, gerieben                         |         |
| 1 TL       | Ingwer           | Dressing |          | frisch gerieben                        |         |
| 2 EL       | Rapsöl           | Dressing |          |                                        |         |
| 50 g       | Cashewkerne      | Topping  |          | geröstet, gehackt                      |         |
| 2 EL       | Sesam            | Topping  |          | geröstet                               |         |
| 1 Handvoll | Mie-Nudeln       | Topping  |          | trockene Eiernudeln, knusprig gebraten |         |

## Zubereitung

1. Kohl mit 1 TL Salz kneten und 10 Minuten stehen lassen, dann ausdrücken. ⏱ 10
2. Dressing aus Sojasauce, Essig, Sesamöl, Zucker, Knoblauch, Ingwer und Rapsöl verrühren.
3. Cashews und Sesam in einer trockenen Pfanne 3 Minuten rösten. ⏱ 3
4. Kohl, Karotte, Frühlingszwiebel und Koriander mit dem Dressing mischen und 10 Minuten durchziehen lassen. ⏱ 10
5. Mit Nudeln, Cashews und Sesam bestreuen.

## Notizen

Knusperzutat: Instantnudeln (ohne Gewürz) in 1 cm Stücke brechen und in Öl 1 Minute frittieren; oder gekaufte Röstzwiebeln.
