# Rote-Bete-Salat mit Ziegenkäse und Haselnüssen

![Rote-Bete-Salat mit Ziegenkäse und Haselnüssen](../../pictures/rote-bete-ziegenkaese-salat.jpg)

Ofengeröstete Rote Bete mit Apfel, Rucola und cremigem Ziegenkäse in Meerrettich-Dressing, mit knusprigen Haselnüssen.

## Zutaten

| Menge   | Zutat        | Gruppe   | Variante         | Hinweis                   | Einkauf |
| ------- | ------------ | -------- | ---------------- | ------------------------- | ------- |
| 500 g   | Rote Bete    | Salat    |                  | roh, geschält, in Spalten |         |
| 2 EL    | Olivenöl     | Salat    |                  |                           |         |
| 1       | Apfel        | Salat    |                  | säuerlich, in Scheiben    |         |
| 80 g    | Rucola       | Salat    |                  |                           |         |
| 100 g   | Ziegenkäse   | Salat    |                  | Frischkäse, in Stücken    | 1×      |

| 1 EL    | Meerrettich  | Dressing |                  | aus dem Glas              |         |
| 1 EL    | Zitronen     | Dressing |                  | Saft                      |         |

## Zubereitung

1. Ofen auf 200 °C Ober-/Unterhitze vorheizen. Rote Bete mit Öl, Salz und Pfeffer mischen und 35-40 Minuten rösten, bis sie weich ist. ⏱ 38
2. Haselnüsse in einer trockenen Pfanne 3 Minuten rösten. ⏱ 3
3. Dressing aus Joghurt, Meerrettich, Zitronensaft, Öl, Honig und Salz verrühren.
4. Rucola und Apfel auf Tellern anrichten, warme Rote Bete darauf legen.
5. [Mit Räucherlachs] Lachs in Streifen darauflegen.
6. Ziegenkäse und Haselnüsse darüber geben, Dressing dazu reichen.

## Notizen

Vorgekochte Rote Bete aus der Packung spart Zeit (nur kurz anrösten). Ofengeröstet schmeckt sie süßer und weniger erdig.
