# Japanischer Soba-Salat mit Sesam-Miso-Dressing

![Japanischer Soba-Salat mit Sesam-Miso-Dressing](../../pictures/japanischer-soba-salat.jpg)

Kalte Buchweizennudeln mit Edamame, Gurke und Karotte in einem umami-reichen Sesam-Miso-Dressing, bestreut mit Nori und Röstsesam.

## Zutaten

| Menge   | Zutat            | Gruppe   | Variante  | Hinweis             | Einkauf |
| ------- | ---------------- | -------- | --------- | ------------------- | ------- |
| 180 g   | Soba-Nudeln      | Salat    |           |                     |         |
| 100 g   | Edamame          | Salat    |           | TK, aufgetaut       |         |
| ½       | Salatgurke       | Salat    |           | in Streifen         |         |
| 1       | Karotte          | Salat    |           | in Streifen         |         |
| 3       | Frühlingszwiebel | Salat    |           | in Ringen           |         |
| 1 EL    | Miso-Paste       | Dressing |           | hell                |         |
| 2 EL    | Tahin            | Dressing |           |                     |         |
| 2 EL    | Sojasauce        | Dressing |           |                     |         |
| 2 EL    | Reisessig        | Dressing |           |                     |         |
| 1 TL    | Sesamöl          | Dressing |           |                     |         |
| 1 TL    | Honig            | Dressing |           |                     |         |
| 1 TL    | Ingwer           | Dressing |           | frisch gerieben     |         |
| 2 EL    | Wasser           | Dressing |           |                     | nie     |
| 2 EL    | Sesam            | Topping  |           | hell, geröstet      |         |
| 1 Blatt | Nori             | Topping  |           | in feinen Streifen  |         |
| 2       | Lachsfilet       | Protein  | Mit Lachs | ca. 150 g, mit Haut |         |
| 1 EL    | Rapsöl           | Protein  | Mit Lachs |                     |         |

## Zubereitung

1. Soba nach Packungsangabe 4-5 Minuten kochen, in einem Sieb kalt abspülen, gut abtropfen. ⏱ 5
2. Alle Dressing-Zutaten glattrühren, mit Wasser auf gießfähige Konsistenz bringen.
3. [Mit Lachs] Lachs auf der Hautseite in Öl 4 Minuten knusprig braten, wenden, 2 Minuten weitergaren, zerpflücken. ⏱ 6
4. Nudeln, Edamame, Gurke, Karotte und Frühlingszwiebel mit dem Dressing mischen.
5. In Schalen anrichten, Lachs darauflegen, mit Sesam und Nori bestreuen.

## Notizen

Miso ersetzbar durch 1 EL mehr Sojasauce und 1 TL Erdnussbutter. Soba aus 100 % Buchweizen sind glutenfrei.
