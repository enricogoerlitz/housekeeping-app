# Halloumi-Granatapfel-Salat

![Halloumi-Granatapfel-Salat](../../pictures/halloumi-granatapfel-salat.jpg)

Warmer, gebratener Halloumi auf Rucola und Spinat mit Granatapfelkernen, Gurke und Pistazien, dazu ein Honig-Zitronen-Dressing mit Zaatar.

## Zutaten

| Menge   | Zutat              | Gruppe   | Variante     | Hinweis       | Einkauf |
| ------- | ------------------ | -------- | ------------ | ------------- | ------- |
| 100 g   | Rucola             | Salat    |              |               |         |
| 100 g   | Babyspinat         | Salat    |              |               |         |
| ½       | Salatgurke         | Salat    |              | in Halbmonden |         |
| ½       | Granatapfel        | Salat    |              | Kerne         | Menge   |
| 250 g   | Halloumi           | Protein  |              | in Scheiben   |         |
| 1 EL    | Olivenöl           | Protein  |              |               |         |
| 2       | Hähnchenbrustfilet | Protein  | Mit Hähnchen |               |         |
| 4 EL    | Olivenöl           | Dressing |              |               |         |
| 3 EL    | Zitronen           | Dressing |              | Saft          |         |
| 1 EL    | Honig              | Dressing |              |               |         |
| 1 TL    | Zaatar             | Dressing |              |               |         |
| 1 Prise | Salz               | Dressing |              |               |         |
| 40 g    | Pistazien          | Topping  |              | gehackt       |         |

## Zubereitung

1. Dressing aus Olivenöl, Zitronensaft, Honig, Zaatar und Salz verrühren.
2. [Mit Hähnchen] Hähnchen salzen und in Öl je Seite 5-6 Minuten braten, ruhen lassen, aufschneiden. ⏱ 12
3. Halloumi trocken tupfen und in einer beschichteten Pfanne mit Öl je Seite 2 Minuten goldbraun braten. ⏱ 4
4. Rucola, Spinat und Gurke mit der Hälfte des Dressings mischen und auf Teller geben.
5. Halloumi, Granatapfelkerne und Pistazien darauf verteilen, restliches Dressing darüberträufeln.

## Notizen

Zaatar ersetzbar durch getrockneten Oregano plus Sesam. Halloumi gleich nach dem Braten essen, er wird kalt gummiartig.
