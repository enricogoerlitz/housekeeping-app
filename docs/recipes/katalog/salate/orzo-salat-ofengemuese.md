# Orzo-Salat mit Ofengemüse und Pesto-Dressing

![Orzo-Salat mit Ofengemüse und Pesto-Dressing](../../pictures/orzo-salat-ofengemuese.jpg)

Reisförmige Orzo-Nudeln mit geröstetem Gemüse, getrockneten Tomaten und Mozzarella in Zitronen-Pesto-Dressing, gekrönt von knusprigen Pinienkernen.

## Zutaten

| Menge   | Zutat              | Gruppe   | Variante     | Hinweis         | Einkauf |
| ------- | ------------------ | -------- | ------------ | --------------- | ------- |
| 1       | Zucchini           | Salat    |              | in Würfeln      |         |
| 1       | Paprika            | Salat    |              | rot, in Würfeln |         |
| 200 g   | Kirschtomaten      | Salat    |              | halbiert        |         |
| 2 EL    | Olivenöl           | Salat    |              |                 |         |
| 150 g   | Orzo               | Salat    |              |                 |         |
| 125 g   | Mozzarella         | Salat    |              | Mini-Kugeln     | 1×      |
| 2 EL    | Basilikumpesto     | Dressing |              |                 |         |
| 3 EL    | Olivenöl           | Dressing |              |                 |         |
| 2 EL    | Zitronen           | Dressing |              | Saft            |         |
| 1 TL    | Honig              | Dressing |              |                 |         |
| 2 EL    | Pinienkerne        | Topping  |              | geröstet        |         |
| 2       | Hähnchenbrustfilet | Protein  | Mit Hähnchen |                 |         |
| 1 Prise | Salz               |          |              |                 |         |
| 1 Prise | Pfeffer            |          |              |                 |         |

## Zubereitung

1. Ofen auf 220 °C Ober-/Unterhitze vorheizen. Zucchini, Paprika und Tomaten mit Öl, Salz und Pfeffer auf einem Blech 20 Minuten rösten. ⏱ 20
2. [Mit Hähnchen] Hähnchen salzen, pfeffern und mit aufs Blech legen, 20 Minuten garen, dann aufschneiden.
3. Orzo in Salzwasser 8-9 Minuten kochen, abgießen, kurz abschrecken. ⏱ 9
4. Pesto, Öl, Zitronensaft und Honig zum Dressing verrühren.
5. Orzo mit Dressing mischen, Gemüse und Mozzarella unterheben.
6. Mit Pinienkernen bestreuen, lauwarm oder kalt servieren.

## Notizen

Funktioniert auch mit Couscous oder Risoni. Für vegan Mozzarella weglassen und Kichererbsen zugeben.
