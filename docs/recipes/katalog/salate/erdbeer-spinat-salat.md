# Erdbeer-Spinat-Salat mit Ziegenfrischkäse

![Erdbeer-Spinat-Salat mit Ziegenfrischkäse](../../pictures/erdbeer-spinat-salat.jpg)

Süße Erdbeeren auf jungem Spinat mit cremigem Ziegenfrischkäse, Mandelsplittern und Mohn-Balsamico-Dressing. Mit Hähnchen ein leichtes Hauptgericht.

## Zutaten

| Menge   | Zutat              | Gruppe   | Variante     | Hinweis                | Einkauf |
| ------- | ------------------ | -------- | ------------ | ---------------------- | ------- |
| 150 g   | Babyspinat         | Salat    |              |                        |         |
| 250 g   | Erdbeeren          | Salat    |              | in Scheiben            |         |
| ½       | Rote Zwiebel       | Salat    |              | in dünnen Ringen       |         |
| 100 g   | Ziegenkäse         | Salat    |              | Frischkäse, in Stücken | 1×      |
| 3 EL    | Olivenöl           | Dressing |              |                        |         |
| 2 EL    | Balsamicoessig     | Dressing |              |                        |         |
| 1 EL    | Honig              | Dressing |              |                        |         |
| 1 TL    | Mohn               | Dressing |              |                        |         |
| 1 TL    | Senf               | Dressing |              |                        |         |
| 1 Prise | Salz               | Dressing |              |                        |         |
| 40 g    | Mandeln            | Topping  |              | gehobelt, geröstet     |         |
| 2       | Hähnchenbrustfilet | Protein  | Mit Hähnchen |                        |         |
| 1 EL    | Olivenöl           | Protein  | Mit Hähnchen |                        |         |
| 1 Prise | Pfeffer            |          |              |                        |         |

## Zubereitung

1. Mandeln in einer trockenen Pfanne 2-3 Minuten rösten. ⏱ 3
2. [Mit Hähnchen] Hähnchen salzen, pfeffern und in Öl je Seite 5-6 Minuten braten, ruhen lassen, in Scheiben schneiden. ⏱ 12
3. Dressing aus Öl, Balsamico, Honig, Mohn, Senf und Salz verrühren.
4. Spinat mit Dressing mischen, auf Teller geben.
5. Erdbeeren, Zwiebel, Ziegenfrischkäse, Mandeln und ggf. Hähnchen darauf verteilen.

## Notizen

Statt Ziegenfrischkäse passt auch Feta oder Burrata.
