# Feldsalat mit Birne, Gorgonzola und Walnüssen

![Feldsalat mit Birne, Gorgonzola und Walnüssen](../../pictures/feldsalat-birne-gorgonzola.jpg)

Herbstlicher Feldsalat mit süßer Birne, würzigem Gorgonzola und karamellisierten Walnüssen in einem Honig-Balsamico-Dressing.

## Zutaten

| Menge   | Zutat      | Gruppe   | Variante | Hinweis          | Einkauf |
| ------- | ---------- | -------- | -------- | ---------------- | ------- |
| 150 g   | Feldsalat  | Salat    |          | gewaschen        |         |
| 1       | Birne      | Salat    |          | reif, in Spalten |         |
| 80 g    | Gorgonzola | Salat    |          | zerbröselt       |         |
| 3 EL    | Olivenöl   | Dressing |          |                  |         |
| 2 EL    | Balsamico  | Dressing |          | weiß             |         |
| 1 EL    | Honig      | Dressing |          |                  |         |
| 1 TL    | Senf       | Dressing |          |                  |         |
| 1 Prise | Salz       | Dressing |          |                  |         |
| 1 Prise | Pfeffer    | Dressing |          |                  |         |
| 50 g    | Walnüsse   | Topping  |          | grob gehackt     |         |
| 1 EL    | Honig      | Topping  |          |                  |         |
| 1 EL    | Butter     | Topping  |          |                  |         |

## Zubereitung

1. Walnüsse in Butter und Honig in einer Pfanne 3 Minuten karamellisieren, auf Backpapier abkühlen lassen. ⏱ 3
2. Dressing aus Öl, Balsamico, Honig, Senf, Salz und Pfeffer verrühren.
3. Feldsalat mit dem Dressing mischen und auf Tellern anrichten.
4. Birnenspalten, Gorgonzola und Walnüsse darauf verteilen.

## Notizen

Als Hauptgericht mit Baguette und gebratenem Hähnchen oder Entenbrust erweiterbar.
