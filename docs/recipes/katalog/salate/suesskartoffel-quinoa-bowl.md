# Ofen-Süßkartoffel-Quinoa-Bowl mit Tahin-Dressing

![Ofen-Süßkartoffel-Quinoa-Bowl mit Tahin-Dressing](../../pictures/suesskartoffel-quinoa-bowl.jpg)

Warme Süßkartoffeln und Kichererbsen aus dem Ofen auf Quinoa und Grünkohl, mit Zitronen-Tahin-Dressing und gerösteten Kürbiskernen.

## Zutaten

| Menge   | Zutat              | Gruppe   | Variante     | Hinweis                          | Einkauf |
| ------- | ------------------ | -------- | ------------ | -------------------------------- | ------- |
| 1       | Süßkartoffel       | Salat    |              | in 2 cm Würfeln                  |         |
| 1 Dose  | Kichererbsen       | Salat    |              | abgetropft                       |         |
| 1 EL    | Olivenöl           | Salat    |              |                                  |         |
| 1 TL    | Paprikapulver      | Salat    |              | geräuchert                       |         |
| 120 g   | Quinoa             | Salat    |              |                                  |         |
| 100 g   | Grünkohl           | Salat    |              | TK oder frisch, fein geschnitten |         |
| 1       | Avocado            | Salat    |              | in Scheiben                      |         |
| 2 EL    | Tahin              | Dressing |              |                                  |         |
| 2 EL    | Zitronen           | Dressing |              | Saft                             |         |
| 1 EL    | Ahornsirup         | Dressing |              |                                  |         |
| 1       | Knoblauch          | Dressing |              | Zehe, gerieben                   |         |
| 4 EL    | Wasser             | Dressing |              |                                  | nie     |
| 3 EL    | Kürbiskerne        | Topping  |              | geröstet                         |         |
| 2       | Hähnchenbrustfilet | Protein  | Mit Hähnchen |                                  |         |
| 1 Prise | Salz               |          |              |                                  |         |

## Zubereitung

1. Ofen auf 220 °C Ober-/Unterhitze vorheizen. Süßkartoffeln und Kichererbsen mit Öl, Paprika und Salz mischen, 25 Minuten rösten. ⏱ 25
2. Quinoa heiß abspülen, in der doppelten Menge Salzwasser 12 Minuten köcheln, 5 Minuten quellen lassen. ⏱ 17
3. [Mit Hähnchen] Hähnchen salzen und nach Belieben mit auf das Blech legen oder in der Pfanne 12 Minuten braten, aufschneiden. ⏱ 12
4. Grünkohl mit einer Prise Salz und etwas Dressing 2 Minuten kräftig durchkneten, bis er weich wird.
5. Dressing aus Tahin, Zitronensaft, Ahornsirup, Knoblauch und Wasser glattrühren.
6. Alles in Schalen anrichten, Dressing darübergeben, Kürbiskerne darüberstreuen.

## Notizen

Gut für Meal Prep: hält 3 Tage im Kühlschrank, Avocado und Dressing erst frisch zugeben.
