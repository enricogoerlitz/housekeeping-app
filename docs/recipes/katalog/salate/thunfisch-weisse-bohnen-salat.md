# Toskanischer Thunfisch-Bohnen-Salat

![Toskanischer Thunfisch-Bohnen-Salat](../../pictures/thunfisch-weisse-bohnen-salat.jpg)

Cremige weiße Bohnen mit Thunfisch, roten Zwiebeln, Tomaten und Rucola in Zitronen-Olivenöl-Dressing. Fertig in 15 Minuten aus dem Vorrat.

## Zutaten

| Menge   | Zutat         | Gruppe   | Variante      | Hinweis                     | Einkauf |
| ------- | ------------- | -------- | ------------- | --------------------------- | ------- |
| 2 Dosen | Weiße Bohnen  | Salat    |               | abgetropft, abgespült       |         |
| ½       | Rote Zwiebel  | Salat    |               | in dünnen Ringen            |         |
| 200 g   | Kirschtomaten | Salat    |               | halbiert                    |         |
| 60 g    | Rucola        | Salat    |               |                             |         |
| 1 Bund  | Petersilie    | Salat    |               | gehackt                     |         |
| 1 Dose  | Thunfisch     | Protein  | Mit Thunfisch | im eigenen Saft, abgetropft |         |
| 100 g   | Mozzarella    | Protein  | Vegetarisch   | in Stücken                  | 1×      |
| 4 EL    | Olivenöl      | Dressing |               |                             |         |
| 2 EL    | Zitronen      | Dressing |               | Saft                        |         |
| 1 TL    | Zitrone       | Dressing |               |                             |         |
| 1 TL    | Senf          | Dressing |               |                             |         |
| 1       | Knoblauch     | Dressing |               | Zehe, gerieben              |         |
| 1 Prise | Salz          | Dressing |               |                             |         |
| 1 Prise | Pfeffer       | Dressing |               |                             |         |
| 3 EL    | Semmelbrösel  | Topping  |               | in Olivenöl geröstet        |         |
| 1 EL    | Olivenöl      | Topping  |               |                             |         |

## Zubereitung

1. Semmelbrösel in Öl bei mittlerer Hitze 3 Minuten goldbraun rösten. ⏱ 3
2. Dressing aus Öl, Zitronensaft, Abrieb, Senf, Knoblauch, Salz und Pfeffer verrühren.
3. Bohnen, Zwiebel, Tomaten und Petersilie mit dem Dressing mischen und 5 Minuten ziehen lassen. ⏱ 5
4. Rucola unterheben und auf Teller verteilen.
5. Thunfisch in großen Stücken bzw. Mozzarella darauf anrichten und mit Bröseln bestreuen.

## Notizen

Zwiebel 5 Minuten in kaltem Wasser wässern für milderen Geschmack. Besonders gut mit Thunfisch in Olivenöl.
