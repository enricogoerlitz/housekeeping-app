# Wassermelonen-Feta-Salat mit Minze

![Wassermelonen-Feta-Salat mit Minze](../../pictures/wassermelonen-feta-salat.jpg)

Süße Wassermelone, salziger Feta, Gurke und Minze mit Limetten-Dressing und gerösteten Kernen. Erfrischende Beilage zum Grillen.

## Zutaten

| Menge   | Zutat        | Gruppe   | Variante | Hinweis              | Einkauf |
| ------- | ------------ | -------- | -------- | -------------------- | ------- |
| 600 g   | Wassermelone | Salat    |          | entkernt, in Würfeln |         |
| 150 g   | Feta         | Salat    |          | in Würfeln           | 1×      |
| ½       | Salatgurke   | Salat    |          | in Würfeln           |         |
| ½       | Rote Zwiebel | Salat    |          | in dünnen Ringen     |         |
| 1 Bund  | Minze        | Salat    |          | Blätter              |         |
| 3 EL    | Olivenöl     | Dressing |          |                      |         |
| 2 EL    | Limetten     | Dressing |          | Saft                 |         |
| 1 TL    | Honig        | Dressing |          |                      |         |
| 1 Prise | Salz         | Dressing |          |                      |         |
| 1 Prise | Pfeffer      | Dressing |          |                      |         |
| 3 EL    | Kürbiskerne  | Topping  |          | geröstet             |         |

## Zubereitung

1. Zwiebelringe 5 Minuten in kaltes Wasser legen, abtropfen (macht sie milder). ⏱ 5
2. Dressing aus Öl, Limettensaft, Honig, Salz und Pfeffer verrühren.
3. Melone, Gurke, Zwiebel und Minze vorsichtig mischen.
4. Feta darüber bröckeln, Dressing darüberträufeln.
5. Mit Kürbiskernen bestreuen und gut gekühlt servieren.

## Notizen

Nicht lange vorher anmachen, die Melone zieht Wasser.
