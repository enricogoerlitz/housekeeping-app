# Fish and Chips

![Fish and Chips](../../pictures/fish-and-chips.jpg)

Backteig-Fisch mit dicken Pommes und Erbsenpüree. Vegetarisch mit Halloumi.

## Zutaten

| Menge  | Zutat         | Gruppe      | Variante    | Hinweis                      | Einkauf |
| ------ | ------------- | ----------- | ----------- | ---------------------------- | ------- |
| 2      | Kabeljaufilet |             | Mit Fisch   | ca. 150 g                    | Menge   |
| 200 g  | Halloumi      |             | Vegetarisch | in dicke Scheiben            | Menge   |
| 600 g  | Kartoffel     |             |             | festkochend, in dicke Stifte | Menge   |
| 150 g  | Weizenmehl    | Teig        |             |                              |         |
| 1 TL   | Backpulver    | Teig        |             |                              |         |
| 200 ml | Bier          | Teig        |             | kalt                         |         |
| 1 l    | Rapsöl        |             |             | zum Frittieren               |         |
| 200 g  | Erbsen        | Erbsenpüree |             | TK                           |         |
| 1 EL   | Butter        | Erbsenpüree |             |                              |         |
| 1      | Zitrone       |             |             |                              |         |
| 1 TL   | Salz          |             |             |                              |         |

## Zubereitung

1. Kartoffeln abspülen, trocknen und bei 160 °C 8 Minuten vorfrittieren. ⏱ 8
2. Erbsen 4 Minuten kochen, mit Butter und Salz grob pürieren. ⏱ 4
3. Mehl, Backpulver und kaltes Bier zu glattem Teig verrühren.
4. Öl auf 180 °C erhitzen, Fisch bzw. Halloumi (bemehlt) durch den Teig ziehen und 4 bis 5 Minuten goldbraun frittieren. ⏱ 5
5. Pommes bei 190 °C 3 Minuten fertig frittieren und salzen. ⏱ 3
6. Mit Erbsenpüree und Zitrone servieren.

## Notizen

Dazu Malzessig. Ersatz: Weißweinessig.
