# Sticky Toffee Pudding

![Sticky Toffee Pudding](../../pictures/sticky-toffee-pudding.jpg)

Warmer Dattelkuchen mit Toffeesauce.

## Zutaten

| Menge  | Zutat          | Gruppe | Variante | Hinweis            | Einkauf |
| ------ | -------------- | ------ | -------- | ------------------ | ------- |
| 100 g  | Datteln        |        |          | entsteint, gehackt |         |
| 120 ml | Wasser         |        |          | kochend            | nie     |
| 60 g   | Butter         |        |          | weich              |         |
| 80 g   | Brauner Zucker |        |          |                    |         |
| 1      | Ei             |        |          |                    |         |
| 100 g  | Weizenmehl     |        |          |                    |         |
| 1 TL   | Backpulver     |        |          |                    |         |
| 100 g  | Brauner Zucker | Sauce  |          |                    |         |
| 100 ml | Sahne          | Sauce  |          |                    |         |
| 40 g   | Butter         | Sauce  |          |                    |         |

## Zubereitung

1. Datteln mit kochendem Wasser übergießen, 10 Minuten stehen lassen. ⏱ 10
2. Butter und Zucker schaumig rühren, Ei, Mehl, Backpulver und Datteln unterrühren.
3. In kleine Förmchen füllen und bei 180 °C 25 Minuten backen. ⏱ 25
4. Für die Sauce Zucker, Sahne und Butter 5 Minuten köcheln. ⏱ 5
5. Pudding mit Sauce übergießen.

## Notizen

Passt gut zu Vanilleeis.
