# Irish Stew

![Irish Stew](../../pictures/irish-stew.jpg)

Irischer Eintopf aus Lamm, Kartoffeln und Zwiebeln. Vegetarisch mit Pilzen und Gerste.

## Zutaten

| Menge  | Zutat        | Gruppe | Variante    | Hinweis    | Einkauf |
| ------ | ------------ | ------ | ----------- | ---------- | ------- |
| 600 g  | Lammschulter |        | Mit Lamm    | in Würfeln | Menge   |
| 250 g  | Champignon   |        | Vegetarisch |            | Menge   |
| 80 g   | Perlgraupen  |        | Vegetarisch |            | Menge   |
| 600 g  | Kartoffel    |        |             | in Stücken | Menge   |
| 2      | Zwiebel      |        |             | in Spalten |         |
| 2      | Karotte      |        |             | in Stücken |         |
| 600 ml | Brühe        |        |             |            |         |
| 2      | Thymian      |        |             | Zweige     |         |
| 1      | Petersilie   |        |             | Bund       |         |
| 1 TL   | Salz         |        |             |            |         |
| 1 TL   | Pfeffer      |        |             |            |         |

## Zubereitung

1. [Mit Lamm] Fleisch, Zwiebeln, Brühe und Thymian aufkochen und 60 Minuten schmoren. ⏱ 60
2. [Vegetarisch] Pilze, Zwiebeln, Graupen, Brühe und Thymian aufkochen und 25 Minuten köcheln. ⏱ 25
3. Karotten und Kartoffeln zugeben, 30 Minuten garen, bis alles weich ist. ⏱ 30
4. Mit Salz und Pfeffer abschmecken und mit Petersilie bestreuen.

## Notizen

Traditionell ohne Anbraten. Dazu Soda Bread.
