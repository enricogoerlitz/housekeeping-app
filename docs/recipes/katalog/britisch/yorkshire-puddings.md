# Yorkshire Puddings

![Yorkshire Puddings](../../pictures/yorkshire-puddings.jpg)

Hochaufgehende Eierteig-Küchlein, klassisch zum Sonntagsbraten.

## Zutaten

| Menge   | Zutat      | Gruppe | Variante | Hinweis | Einkauf |
| ------- | ---------- | ------ | -------- | ------- | ------- |
| 100 g   | Weizenmehl |        |          |         |         |
| 3       | Ei         |        |          |         |         |
| 120 ml  | Milch      |        |          |         |         |
| 4 EL    | Rapsöl     |        |          |         |         |
| 1 Prise | Salz       |        |          |         |         |

## Zubereitung

1. Mehl, Eier, Milch und Salz verrühren, 30 Minuten ruhen lassen. ⏱ 30
2. Ofen auf 230 °C Ober-/Unterhitze vorheizen. Je 1 TL Öl in 8 Muffinförmchen geben, 10 Minuten im Ofen erhitzen. ⏱ 10
3. Teig zügig einfüllen und 20 Minuten backen; Ofentür nicht öffnen. ⏱ 20

## Notizen

Fett muss rauchend heiß sein.
