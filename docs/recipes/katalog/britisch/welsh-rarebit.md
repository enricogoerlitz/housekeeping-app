# Welsh Rarebit

![Welsh Rarebit](../../pictures/welsh-rarebit.jpg)

Überbackener Käsetoast mit Bier-Senf-Sauce, ein schnelles britisches Abendessen.

## Zutaten

| Menge | Zutat          | Gruppe | Variante | Hinweis             | Einkauf |
| ----- | -------------- | ------ | -------- | ------------------- | ------- |
| 4     | Toastbrot      |        |          | Scheiben            |         |
| 200 g | Cheddar        |        |          | gerieben            | Menge   |
| 1 EL  | Butter         |        |          |                     |         |
| 1 EL  | Mehl           |        |          |                     |         |
| 80 ml | Bier           |        |          | dunkel              |         |
| 1 TL  | Senf           |        |          | englisch oder Dijon |         |
| 1 TL  | Worcestersauce |        |          |                     |         |

## Zubereitung

1. Butter schmelzen, Mehl 1 Minute anrösten, Bier einrühren, 2 Minuten köcheln. ⏱ 2
2. Käse, Senf und Worcestersauce unterrühren, bis der Käse zerlaufen ist.
3. Toast von beiden Seiten rösten, Käsesauce darauf verstreichen.
4. Unter dem Grill 3 Minuten überbacken. ⏱ 3

## Notizen

Mit Spiegelei: Buck Rarebit.
