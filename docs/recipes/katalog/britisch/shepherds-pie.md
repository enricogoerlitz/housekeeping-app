# Shepherd's Pie

![Shepherd's Pie](../../pictures/shepherds-pie.jpg)

Lammhack unter Kartoffelpüree-Kruste. Vegetarisch mit Linsen und Pilzen.

## Zutaten

| Menge  | Zutat          | Gruppe | Variante    | Hinweis       | Einkauf |
| ------ | -------------- | ------ | ----------- | ------------- | ------- |
| 400 g  | Lammhack       |        | Mit Lamm    |               | Menge   |
| 150 g  | Linsen         |        | Vegetarisch | Berglinsen    | Menge   |
| 200 g  | Champignon     |        | Vegetarisch | gewürfelt     | Menge   |
| 700 g  | Kartoffel      |        |             | mehligkochend | Menge   |
| 40 g   | Butter         |        |             |               |         |
| 80 ml  | Milch          |        |             |               |         |
| 1      | Zwiebel        |        |             | gewürfelt     |         |
| 2      | Karotte        |        |             | gewürfelt     |         |
| 100 g  | Erbsen         |        |             | TK            |         |
| 2 EL   | Tomatenmark    |        |             |               |         |
| 1 EL   | Worcestersauce |        |             |               |         |
| 300 ml | Brühe          |        |             |               |         |
| 1 TL   | Salz           |        |             |               |         |

## Zubereitung

1. Kartoffeln in Salzwasser 20 Minuten garen, mit Butter und Milch stampfen. ⏱ 20
2. Ofen auf 200 °C Ober-/Unterhitze vorheizen.
3. [Mit Lamm] Zwiebel, Karotten und Lammhack in Öl 10 Minuten anbraten. ⏱ 10
4. [Vegetarisch] Zwiebel, Karotten und Pilze 8 Minuten braten, Linsen zugeben. ⏱ 8
5. Tomatenmark, Worcestersauce und Brühe zugeben, 15 Minuten einkochen (Linsen 25 Minuten), Erbsen untermischen. ⏱ 20
6. In eine Form füllen, Püree darauf verstreichen, mit der Gabel Rillen ziehen.
7. 25 Minuten backen. ⏱ 25

## Notizen

Mit Rinderhack heißt das Gericht Cottage Pie. Worcestersauce enthält Sardellen; vegetarisch: vegane Variante nehmen.
