# Chicken and Leek Pie

![Chicken and Leek Pie](../../pictures/chicken-and-leek-pie.jpg)

Pie mit cremiger Füllung unter Blätterteig. Vegetarisch mit Pilzen und Kartoffeln.

## Zutaten

| Menge  | Zutat         | Gruppe | Variante     | Hinweis         | Einkauf |
| ------ | ------------- | ------ | ------------ | --------------- | ------- |
| 400 g  | Hähnchenbrust |        | Mit Hähnchen | in Würfeln      | Menge   |
| 250 g  | Champignon    |        | Vegetarisch  |                 | Menge   |
| 200 g  | Kartoffel     |        | Vegetarisch  | gewürfelt       | Menge   |
| 2      | Lauch         |        |              | in Ringen       |         |
| 30 g   | Butter        |        |              |                 |         |
| 30 g   | Mehl          |        |              |                 |         |
| 300 ml | Milch         |        |              |                 |         |
| 1      | Blätterteig   |        |              | Rolle           | 1×      |
| 1      | Eier          |        |              | zum Bestreichen |         |
| 1 TL   | Salz          |        |              |                 |         |

## Zubereitung

1. [Mit Hähnchen] Hähnchen in Butter 6 Minuten anbraten, herausnehmen. ⏱ 6
2. [Vegetarisch] Kartoffeln 8 Minuten vorkochen, Pilze in Butter 5 Minuten braten. ⏱ 8
3. Lauch in Butter 5 Minuten dünsten, Mehl einrühren, mit Milch aufgießen und 5 Minuten köcheln. ⏱ 10
4. Hähnchen bzw. Pilze und Kartoffeln unterrühren, in eine Form füllen, abkühlen lassen.
5. Blätterteig darüberlegen, Rand andrücken, mit Eigelb bestreichen, einschneiden.
6. Bei 200 °C 30 Minuten goldbraun backen. ⏱ 30

## Notizen

Füllung gut abkühlen lassen, sonst weicht der Teig durch.
