# Fideuà

![Fideuà](../../pictures/fideua.jpg)

Katalanische Nudelpfanne, Paella-Prinzip mit dünnen Fideo-Nudeln. Vegetarisch mit Paprika und Artischocken.

## Zutaten

| Menge   | Zutat              | Gruppe | Variante     | Hinweis                      | Einkauf |
| ------- | ------------------ | ------ | ------------ | ---------------------------- | ------- |
| 200 g   | Fideo-Nudeln       |        |              | oder Fadennudeln gebrochen   | Menge   |
| 200 g   | Garnelen           |        | Mit Garnelen | geschält                     | Menge   |
| 1       | Artischockenherzen |        | Vegetarisch  | Glas, abgetropft, geviertelt |         |
| 1       | Paprika            |        | Vegetarisch  | rot, in Streifen             |         |
| 1       | Zwiebel            |        |              | fein gewürfelt               |         |
| 2       | Knoblauch          |        |              | Zehen                        |         |
| 2 EL    | Tomatenmark        |        |              |                              |         |
| 1 TL    | Paprikapulver      |        |              |                              |         |
| 1 Prise | Safran             |        |              |                              |         |
| 600 ml  | Gemüsebrühe        |        |              | heiß                         |         |
| 3 EL    | Olivenöl           |        |              |                              |         |
| 1       | Zitrone            |        |              | Spalten, zum Servieren       |         |
| 1 TL    | Salz               |        |              |                              |         |

## Zubereitung

1. Nudeln in 1 EL Öl in einer weiten Pfanne goldbraun rösten und herausnehmen. ⏱ 4
2. Zwiebel, Knoblauch und (vegetarisch) Paprika in restlichem Öl 6 Minuten anbraten, Tomatenmark, Paprikapulver und Safran einrühren. ⏱ 6
3. Heiße Brühe angießen, aufkochen, Nudeln zugeben und 8 Minuten ohne Rühren köcheln. ⏱ 8
4. [Mit Garnelen] Garnelen auf die Nudeln legen und 3 Minuten ziehen lassen. ⏱ 3
5. [Vegetarisch] Artischocken darauflegen und 3 Minuten erwärmen. ⏱ 3
6. Mit Zitronenspalten und Aioli servieren.

## Notizen

Fideo-Nudeln gibt es im Spanienregal, ersatzweise Fadennudeln in 2 cm gebrochen.
