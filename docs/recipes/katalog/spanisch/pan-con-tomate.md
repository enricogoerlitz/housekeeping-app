# Pan con Tomate

![Pan con Tomate](../../pictures/pan-con-tomate.jpg)

Geröstetes Brot, mit Knoblauch und frischer Tomate eingerieben, mit Olivenöl.

## Zutaten

| Menge   | Zutat     | Gruppe | Variante | Hinweis             | Einkauf |
| ------- | --------- | ------ | -------- | ------------------- | ------- |
| 4       | Ciabatta  |        |          | Scheiben            |         |
| 2       | Tomate    |        |          | sehr reif, halbiert |         |
| 1       | Knoblauch |        |          | Zehe, halbiert      |         |
| 2 EL    | Olivenöl  |        |          |                     |         |
| 1 Prise | Salz      |        |          |                     |         |

## Zubereitung

1. Brot im Toaster oder in der Pfanne goldbraun rösten. ⏱ 3
2. Knoblauchseite über das heiße Brot reiben.
3. Tomatenhälften darauf zerreiben, das Fruchtfleisch bleibt auf dem Brot.
4. Mit Olivenöl beträufeln und salzen.

## Notizen

Nur mit sehr reifen Tomaten.
