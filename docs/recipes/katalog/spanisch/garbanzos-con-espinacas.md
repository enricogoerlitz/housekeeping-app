# Garbanzos con Espinacas

![Garbanzos con Espinacas](../../pictures/garbanzos-con-espinacas.jpg)

Sevillanisches Tapas-Gericht aus Kichererbsen und Spinat mit Kreuzkümmel und Paprika, schnell gekocht.

## Zutaten

| Menge  | Zutat                    | Gruppe | Variante    | Hinweis                  | Einkauf |
| ------ | ------------------------ | ------ | ----------- | ------------------------ | ------- |
| 400 g  | Kichererbsen             |        |             | Dose, abgetropft         | Menge   |
| 300 g  | Blattspinat              |        |             | frisch oder TK           | Menge   |
| 3      | Knoblauch                |        |             | Zehen, in Scheiben       |         |
| 1 TL   | Kreuzkümmel              |        |             | gemahlen                 |         |
| 1 TL   | Paprikapulver geräuchert |        |             |                          |         |
| 1 EL   | Sherryessig              |        |             |                          |         |
| 3 EL   | Olivenöl                 |        |             |                          |         |
| 1      | Baguette                 |        |             | Scheiben, in Öl gebraten |         |
| 80 g   | Chorizo                  |        | Mit Chorizo | gewürfelt                | Menge   |
| 100 ml | Wasser                   |        |             |                          | nie     |

## Zubereitung

1. [Mit Chorizo] Chorizo im Öl 3 Minuten anbraten.
2. Knoblauch im Öl 1 Minute goldgelb braten, Kreuzkümmel und Paprikapulver 20 Sekunden mitrösten. ⏱ 1
3. Kichererbsen und Wasser zugeben, 8 Minuten köcheln und teilweise zerdrücken. ⏱ 8
4. Spinat zugeben und 3 Minuten zusammenfallen lassen. ⏱ 3
5. Mit Essig und Salz abschmecken, mit Brot servieren.

## Notizen

Mit TK-Spinat vorher auftauen und ausdrücken.
