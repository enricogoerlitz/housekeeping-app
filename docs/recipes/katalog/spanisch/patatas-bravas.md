# Patatas Bravas

![Patatas Bravas](../../pictures/patatas-bravas.jpg)

Die Tapas-Klassiker: knusprige Kartoffelwürfel mit scharfer roter Sauce und Aioli.

## Zutaten

| Menge | Zutat                    | Gruppe | Variante | Hinweis                     | Einkauf |
| ----- | ------------------------ | ------ | -------- | --------------------------- | ------- |
| 600 g | Kartoffel                |        |          | festkochend, in 2 cm Würfel | Menge   |
| 3 EL  | Olivenöl                 |        |          |                             |         |
| 1     | Zwiebel                  | Sauce  |          | fein gewürfelt              |         |
| 1     | Knoblauch                | Sauce  |          | Zehe                        |         |
| 200 g | Passierte Tomaten        | Sauce  |          |                             |         |
| 1 TL  | Paprikapulver geräuchert | Sauce  |          |                             |         |
| 1 TL  | Chiliflocken             | Sauce  |          |                             |         |
| 1 TL  | Essig                    | Sauce  |          |                             |         |
| 3 EL  | Mayonnaise               | Aioli  |          |                             |         |
| 1     | Knoblauch                | Aioli  |          | Zehe, gepresst              |         |

## Zubereitung

1. Ofen auf 220 °C Umluft vorheizen. Kartoffeln mit Öl und Salz mischen und 30 Minuten backen, bis sie knusprig sind. ⏱ 30
2. Für die Sauce Zwiebel und Knoblauch in Öl anbraten, Paprika, Chili, Tomaten und Essig zugeben und 10 Minuten einkochen, pürieren. ⏱ 10
3. Mayonnaise mit gepresstem Knoblauch verrühren.
4. Kartoffeln mit Sauce und Aioli anrichten.

## Notizen

Chiliflocken je nach Schärfe anpassen. Salz nicht vergessen.
