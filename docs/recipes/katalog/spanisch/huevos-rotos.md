# Huevos Rotos

![Huevos Rotos](../../pictures/huevos-rotos.jpg)

Frittierte Kartoffeln mit Spiegeleiern, deren Dotter beim Servieren am Tisch zerdrückt wird.

## Zutaten

| Menge  | Zutat                    | Gruppe | Variante    | Hinweis            | Einkauf |
| ------ | ------------------------ | ------ | ----------- | ------------------ | ------- |
| 500 g  | Kartoffel                |        |             | in dünnen Scheiben | Menge   |
| 4      | Ei                       |        |             |                    |         |
| 60 g   | Rohschinken              |        | Mit Serrano | Serrano            | Menge   |
| 200 ml | Olivenöl                 |        |             | zum Braten         |         |
| 1 TL   | Paprikapulver geräuchert |        | Vegetarisch |                    |         |
| 1 TL   | Salz                     |        |             |                    |         |

## Zubereitung

1. Kartoffelscheiben trocknen. In einer Pfanne Öl auf mittlere Hitze erhitzen und die Kartoffeln 12 Minuten garen, bis sie goldgelb sind. ⏱ 12
2. Herausnehmen, abtropfen lassen und salzen.
3. Eier in einer zweiten Pfanne mit etwas Olivenöl braten, bis das Weiß knusprig ist.
4. Kartoffeln anrichten, Eier darauflegen,
5. [Mit Serrano] Serrano darübergeben,
6. [Vegetarisch] mit geräuchertem Paprika bestäuben.
7. Dotter am Tisch aufbrechen und unterheben.

## Notizen

Das Kartoffelöl lässt sich durch ein Sieb filtern und wiederverwenden.
