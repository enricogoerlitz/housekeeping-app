# Salmorejo Cordobés

![Salmorejo Cordobés](../../pictures/salmorejo.jpg)

Dicke kalte Tomatencreme aus Córdoba, mit gekochtem Ei und Serrano garniert.

## Zutaten

| Menge  | Zutat       | Gruppe | Variante            | Hinweis               | Einkauf |
| ------ | ----------- | ------ | ------------------- | --------------------- | ------- |
| 800 g  | Tomate      |        |                     | reif                  | Menge   |
| 150 g  | Weißbrot    |        |                     | altbacken, ohne Rinde |         |
| 1      | Knoblauch   |        |                     | Zehe                  |         |
| 100 ml | Olivenöl    |        |                     |                       |         |
| 1 EL   | Sherryessig |        |                     |                       |         |
| 2      | Ei          |        |                     | hart gekocht, gehackt |         |
| 40 g   | Rohschinken |        | Mit Ei und Schinken | Serrano, gewürfelt    | Menge   |
| 1 TL   | Salz        |        |                     |                       |         |

## Zubereitung

1. Eier 10 Minuten hart kochen, abschrecken. ⏱ 10
2. Tomaten, Brot, Knoblauch, Essig und Salz im Mixer sehr fein pürieren.
3. Das Olivenöl in dünnem Strahl einmixen, bis die Creme dick und cremig ist.
4. 2 Stunden kalt stellen und mit Ei,
5. [Mit Ei und Schinken] Schinken und Öl servieren. ⏱ 120

## Notizen

Vegetarisch: nur mit Ei, ohne Schinken. Vorlauf: 2 Stunden.
