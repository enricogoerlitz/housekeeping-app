# Croquetas de Jamón

![Croquetas de Jamón](../../pictures/croquetas-de-jamon.jpg)

Cremige Béchamel-Kroketten mit Serranoschinken, außen knusprig. Teig muss mindestens zwei Stunden kühlen.

## Zutaten

| Menge   | Zutat        | Gruppe | Variante | Hinweis               | Einkauf |
| ------- | ------------ | ------ | -------- | --------------------- | ------- |
| 40 g    | Butter       |        |          |                       |         |
| 50 g    | Mehl         |        |          |                       |         |
| 400 ml  | Milch        |        |          |                       |         |
| 80 g    | Rohschinken  |        |          | Serrano, fein gehackt | Menge   |
| 1 Prise | Muskat       |        |          |                       |         |
| 1       | Ei           | Panade |          |                       |         |
| 80 g    | Semmelbrösel | Panade |          |                       |         |
| 500 ml  | Rapsöl       |        |          | zum Frittieren        |         |

## Zubereitung

1. Butter schmelzen, Mehl zugeben und 2 Minuten rühren. Milch nach und nach einrühren, 8 Minuten zur dicken Creme köcheln. ⏱ 10
2. Schinken und Muskat unterrühren, in eine flache Form streichen und mindestens 2 Stunden kühlen. ⏱ 120
3. Mit nassen Händen Kroketten formen, in Ei und Bröseln wenden.
4. Öl auf 180 °C erhitzen, Kroketten in Portionen 2 bis 3 Minuten goldbraun frittieren. ⏱ 3
5. Auf Küchenpapier abtropfen.

## Notizen

Vorlauf: Teig über Nacht kühlen. Die Kroketten lassen sich einfrieren.
