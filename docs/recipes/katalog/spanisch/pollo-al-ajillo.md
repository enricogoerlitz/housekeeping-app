# Pollo al Ajillo

![Pollo al Ajillo](../../pictures/pollo-al-ajillo.jpg)

Knoblauchhähnchen aus Kastilien mit Weißwein. Vegetarisch mit Kartoffeln und Champignons.

## Zutaten

| Menge  | Zutat         | Gruppe | Variante     | Hinweis                      | Einkauf |
| ------ | ------------- | ------ | ------------ | ---------------------------- | ------- |
| 600 g  | Hähnchenkeule |        | Mit Hähnchen | ausgelöst oder mit Knochen   | Menge   |
| 400 g  | Champignon    |        | Vegetarisch  | halbiert                     | Menge   |
| 300 g  | Kartoffel     |        | Vegetarisch  | in Würfeln                   | Menge   |
| 10     | Knoblauch     |        |              | Zehen, ungeschält angedrückt |         |
| 100 ml | Weißwein      |        |              | trocken                      |         |
| 4 EL   | Olivenöl      |        |              |                              |         |
| 1      | Lorbeerblatt  |        |              |                              |         |
| 1      | Petersilie    |        |              | Bund, gehackt                |         |
| 1 TL   | Salz          |        |              |                              |         |

## Zubereitung

1. [Mit Hähnchen] Fleisch salzen und im Öl 5 Minuten pro Seite goldbraun braten. ⏱ 10
2. [Vegetarisch] Kartoffelwürfel im Öl 10 Minuten braten, Champignons zugeben und 5 Minuten weiterbraten. ⏱ 15
3. Knoblauch und Lorbeer zugeben und 3 Minuten mitbraten.
4. Mit Wein ablöschen, aufkochen, zugedeckt 20 Minuten (vegetarisch 12 Minuten) bei kleiner Hitze garen. ⏱ 20
5. Offen 3 Minuten einkochen, mit Petersilie bestreuen.

## Notizen

Knoblauch bleibt in der Schale, so wird er mild und süß. Mit Brot servieren.
