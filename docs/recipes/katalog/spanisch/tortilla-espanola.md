# Tortilla Española

![Tortilla Española](../../pictures/tortilla-espanola.jpg)

Das spanische Kartoffelomelett, außen goldbraun und innen saftig. Klassisch vegetarisch, optional mit Chorizo.

## Zutaten

| Menge  | Zutat     | Gruppe | Variante    | Hinweis                         | Einkauf |
| ------ | --------- | ------ | ----------- | ------------------------------- | ------- |
| 500 g  | Kartoffel |        |             | festkochend, in dünnen Scheiben | Menge   |
| 1      | Zwiebel   |        |             | in dünnen Streifen              |         |
| 5      | Ei        |        |             |                                 |         |
| 100 ml | Olivenöl  |        |             |                                 |         |
| 80 g   | Chorizo   |        | Mit Chorizo | gewürfelt                       | Menge   |
| 1 TL   | Salz      |        |             |                                 |         |

## Zubereitung

1. Kartoffeln und Zwiebel in einer Pfanne (24 cm) im Olivenöl bei mittlerer Hitze 15 Minuten sanft garen, ohne Farbe zu nehmen. ⏱ 15
2. [Mit Chorizo] Chorizo in einer zweiten Pfanne 3 Minuten ausbraten und zu den Kartoffeln geben.
3. Eier mit Salz verquirlen, Kartoffeln abtropfen lassen und unterheben, 5 Minuten ziehen lassen.
4. Etwas Öl in der Pfanne erhitzen, Masse einfüllen und 5 Minuten bei mittlerer Hitze stocken lassen. ⏱ 5
5. Mit einem Teller wenden und von der anderen Seite 3 bis 4 Minuten garen. ⏱ 4
6. 5 Minuten ruhen lassen, in Spalten schneiden, warm oder kalt servieren.

## Notizen

Mit Zwiebel (Variante con cebolla) oder ohne, beide sind klassisch. Innen darf sie leicht cremig bleiben.
