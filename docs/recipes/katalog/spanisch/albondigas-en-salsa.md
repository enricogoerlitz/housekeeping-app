# Albóndigas en Salsa

![Albóndigas en Salsa](../../pictures/albondigas-en-salsa.jpg)

Spanische Hackbällchen in würziger Tomatensauce. Vegetarisch mit Kichererbsen-Bällchen.

## Zutaten

| Menge  | Zutat                    | Gruppe | Variante        | Hinweis          | Einkauf |
| ------ | ------------------------ | ------ | --------------- | ---------------- | ------- |
| 400 g  | Gemischtes Hackfleisch   |        | Mit Hackfleisch |                  | Menge   |
| 400 g  | Kichererbsen             |        | Vegetarisch     | Dose, abgetropft | Menge   |
| 1      | Ei                       |        |                 |                  |         |
| 4 EL   | Semmelbrösel             |        |                 |                  |         |
| 3      | Knoblauch                |        |                 | Zehen, gehackt   |         |
| 1      | Petersilie               |        |                 | Bund, gehackt    |         |
| 1      | Zwiebel                  | Sauce  |                 | fein gewürfelt   |         |
| 400 g  | Passierte Tomaten        | Sauce  |                 |                  |         |
| 100 ml | Weißwein                 | Sauce  |                 |                  |         |
| 1 TL   | Paprikapulver geräuchert | Sauce  |                 |                  |         |
| 3 EL   | Olivenöl                 |        |                 |                  |         |
| 1 TL   | Salz                     |        |                 |                  |         |

## Zubereitung

1. [Mit Hackfleisch] Hack mit Ei, Semmelbröseln, Hälfte vom Knoblauch, Petersilie und Salz verkneten, zu 16 Bällchen formen.
2. [Vegetarisch] Kichererbsen grob zerdrücken, mit Ei, Semmelbröseln, Hälfte vom Knoblauch, Petersilie und Salz verkneten, 15 Minuten kühlen, 16 Bällchen formen. ⏱ 15
3. Bällchen in 2 EL Öl rundum 6 Minuten anbraten und herausnehmen. ⏱ 6
4. Zwiebel und restlichen Knoblauch im Bratfett 4 Minuten anbraten, Paprikapulver zugeben, mit Wein ablöschen. ⏱ 4
5. Passierte Tomaten zugeben, aufkochen, Bällchen einlegen und 15 Minuten köcheln. ⏱ 15

## Notizen

Dazu Brot oder Reis. Vegetarische Bällchen vorsichtig wenden.
