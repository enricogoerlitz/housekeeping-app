# Lentejas Estofadas

![Lentejas Estofadas](../../pictures/lentejas-estofadas.jpg)

Spanischer Linseneintopf mit Paprika und Kartoffeln, vegan oder mit Chorizo.

## Zutaten

| Menge  | Zutat                    | Gruppe | Variante    | Hinweis        | Einkauf |
| ------ | ------------------------ | ------ | ----------- | -------------- | ------- |
| 250 g  | Linsen                   |        |             | Berglinsen     | Menge   |
| 1      | Zwiebel                  |        |             | gewürfelt      |         |
| 2      | Knoblauch                |        |             | Zehen          |         |
| 2      | Karotte                  |        |             | gewürfelt      |         |
| 1      | Kartoffel                |        |             | gewürfelt      |         |
| 1      | Paprika                  |        |             | rot, gewürfelt |         |
| 1 EL   | Tomatenmark              |        |             |                |         |
| 2 TL   | Paprikapulver geräuchert |        |             |                |         |
| 800 ml | Gemüsebrühe              |        |             |                |         |
| 1      | Lorbeerblatt             |        |             |                |         |
| 100 g  | Chorizo                  |        | Mit Chorizo | in Scheiben    | Menge   |
| 2 EL   | Olivenöl                 |        |             |                |         |
| 1 EL   | Weißweinessig            |        |             |                |         |

## Zubereitung

1. [Mit Chorizo] Chorizo im Öl 3 Minuten braten, bis Öl rot wird.
2. Zwiebel, Paprika und Karotten 6 Minuten anbraten, Knoblauch, Tomatenmark und Paprikapulver 1 Minute mitrösten. ⏱ 7
3. Linsen, Kartoffel, Brühe und Lorbeer zugeben, aufkochen und 30 Minuten köcheln. ⏱ 30
4. Mit Essig und Salz abschmecken, 5 Minuten ruhen lassen.

## Notizen

Berglinsen müssen nicht eingeweicht werden. Braten Sie die Chorizo am Anfang, so gibt sie Würze an das ganze Gericht.
