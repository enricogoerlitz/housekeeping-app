# Gazpacho Andaluz

![Gazpacho Andaluz](../../pictures/gazpacho-andaluz.jpg)

Kalte Tomatensuppe aus rohem Gemüse, erfrischend im Sommer. Vorlauf: mindestens 2 Stunden kühlen.

## Zutaten

| Menge | Zutat       | Gruppe  | Variante | Hinweis                           | Einkauf |
| ----- | ----------- | ------- | -------- | --------------------------------- | ------- |
| 600 g | Tomate      |         |          | reif, grob gewürfelt              | Menge   |
| 1     | Gurke       |         |          | geschält                          |         |
| 1     | Paprika     |         |          | rot                               |         |
| 1     | Knoblauch   |         |          | Zehe                              |         |
| 2     | Weißbrot    |         |          | Scheiben, ohne Rinde, eingeweicht |         |
| 3 EL  | Olivenöl    |         |          |                                   |         |
| 1 EL  | Sherryessig |         |          |                                   |         |
| 1 TL  | Salz        |         |          |                                   |         |
| 1     | Gurke       | Topping |          | klein gewürfelt                   |         |

## Zubereitung

1. Tomaten, Gurke, Paprika, Knoblauch und das ausgedrückte Brot im Mixer sehr fein pürieren.
2. Olivenöl und Essig einmixen, mit Salz abschmecken, durch ein Sieb streichen.
3. Mindestens 2 Stunden kalt stellen. ⏱ 120
4. Mit gewürfelter Gurke, Olivenöl und Brotcroutons servieren.

## Notizen

Nur mit sehr reifen Tomaten, sonst wird die Suppe fad. Vorlauf: 2 Stunden.
