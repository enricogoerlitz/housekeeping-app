# Crema Catalana

![Crema Catalana](../../pictures/crema-catalana.jpg)

Katalanische Vanillecreme mit Zimt und Zitrone, mit Karamellkruste. Vorlauf: mindestens 4 Stunden.

## Zutaten

| Menge  | Zutat        | Gruppe | Variante | Hinweis             | Einkauf |
| ------ | ------------ | ------ | -------- | ------------------- | ------- |
| 300 ml | Milch        |        |          |                     |         |
| 3      | Eier         |        |          |                     |         |
| 50 g   | Zucker       |        |          |                     |         |
| 1 EL   | Speisestärke |        |          |                     |         |
| 1      | Zimtstange   |        |          |                     |         |
| 1      | Zitrone      |        |          | Schale, unbehandelt |         |
| 2 EL   | Zucker       |        |          | zum Karamellisieren |         |

## Zubereitung

1. Milch mit Zimt und Zitronenschale aufkochen, 10 Minuten ziehen lassen. ⏱ 10
2. Eigelbe, Zucker und Stärke glatt verrühren, heiße Milch (ohne Zutaten) einrühren.
3. Zurück in den Topf geben und unter Rühren aufkochen, bis die Creme dick wird. ⏱ 3
4. In Förmchen füllen und mindestens 4 Stunden kühlen. ⏱ 240
5. Mit Zucker bestreuen und mit dem Brenner oder unter dem Grill karamellisieren.

## Notizen

Vorlauf: 4 Stunden. Ohne Brenner mit einem heißen Löffel karamellisieren.
