# Pisto con Huevos

![Pisto con Huevos](../../pictures/pisto-con-huevos.jpg)

Spanisches Schmorgemüse mit Spiegelei. Mit Serranoschinken noch deftiger.

## Zutaten

| Menge | Zutat            | Gruppe | Variante    | Hinweis           | Einkauf |
| ----- | ---------------- | ------ | ----------- | ----------------- | ------- |
| 2     | Zucchini         |        |             | gewürfelt         |         |
| 1     | Paprika          |        |             | rot, gewürfelt    |         |
| 1     | Paprika          |        |             | grün, gewürfelt   |         |
| 1     | Zwiebel          |        |             | gewürfelt         |         |
| 2     | Knoblauch        |        |             | Zehen             |         |
| 400 g | Stückige Tomaten |        |             |                   |         |
| 3 EL  | Olivenöl         |        |             |                   |         |
| 2     | Ei               |        |             |                   |         |
| 4     | Rohschinken      |        | Mit Serrano | Serrano, Scheiben | Menge   |
| 1 TL  | Zucker           |        |             |                   |         |
| 1 TL  | Salz             |        |             |                   |         |

## Zubereitung

1. Zwiebel und Paprika in Öl 8 Minuten bei mittlerer Hitze anbraten. ⏱ 8
2. Zucchini und Knoblauch zugeben und 5 Minuten braten. ⏱ 5
3. Tomaten, Zucker und Salz einrühren, zugedeckt 20 Minuten schmoren, zuletzt offen einkochen. ⏱ 20
4. In der Mitte zwei Mulden formen, Eier hineinschlagen und zugedeckt 4 bis 5 Minuten stocken lassen. ⏱ 5
5. [Mit Serrano] Mit Serranoschinken belegen.

## Notizen

Der Pisto schmeckt am nächsten Tag noch besser und lässt sich gut vorkochen.
