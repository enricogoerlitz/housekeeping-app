# Pimientos Rellenos

![Pimientos Rellenos](../../pictures/pimientos-rellenos.jpg)

Gefüllte Paprika aus dem Baskenland in Tomatensauce, vegetarisch mit Reis und Kichererbsen.

## Zutaten

| Menge | Zutat             | Gruppe | Variante        | Hinweis                             | Einkauf |
| ----- | ----------------- | ------ | --------------- | ----------------------------------- | ------- |
| 4     | Paprika           |        |                 | rot, Deckel abgeschnitten, entkernt |         |
| 250 g | Rinderhack        |        | Mit Hackfleisch |                                     | Menge   |
| 200 g | Kichererbsen      |        | Vegetarisch     | Dose, abgetropft                    | Menge   |
| 100 g | Reis              |        |                 | vorgekocht                          |         |
| 1     | Zwiebel           |        |                 | fein gewürfelt                      |         |
| 2     | Knoblauch         |        |                 | Zehen                               |         |
| 400 g | Passierte Tomaten |        |                 |                                     |         |
| 1 TL  | Paprikapulver     |        |                 |                                     |         |
| 2 EL  | Olivenöl          |        |                 |                                     |         |
| 1 TL  | Salz              |        |                 |                                     |         |

## Zubereitung

1. Ofen auf 190 °C Ober-/Unterhitze vorheizen. Reis nach Packungsangabe garen. ⏱ 12
2. Zwiebel und Knoblauch im Öl 4 Minuten anbraten. ⏱ 4
3. [Mit Hackfleisch] Hack zugeben und 5 Minuten krümelig braten.
4. [Vegetarisch] Kichererbsen leicht zerdrücken und 3 Minuten mitbraten.
5. Mit Reis, Paprikapulver, Salz und der Hälfte der Tomatensauce mischen, in die Paprika füllen.
6. Restliche Tomatensauce in eine Form geben, Paprika hineinsetzen, Deckel aufsetzen und 40 Minuten backen. ⏱ 40

## Notizen

Vorgekochten Reis nehmen, so bleibt die Füllung locker.
