# Pimientos de Padrón

![Pimientos de Padrón](../../pictures/pimientos-de-padron.jpg)

Kleine grüne Paprika, in heißem Öl gebraten und mit Meersalz bestreut. Manche sind scharf.

## Zutaten

| Menge | Zutat               | Gruppe | Variante | Hinweis                       | Einkauf |
| ----- | ------------------- | ------ | -------- | ----------------------------- | ------- |
| 250 g | Pimientos de Padrón |        |          | oder milde Spitzpaprika-Minis | Menge   |
| 2 EL  | Olivenöl            |        |          |                               |         |
| 1 TL  | Meersalz            |        |          | grob                          |         |

## Zubereitung

1. Öl in einer Pfanne stark erhitzen.
2. Pimientos 4 bis 5 Minuten braten, bis die Haut Blasen wirft. ⏱ 5
3. Mit Meersalz bestreuen und sofort essen.

## Notizen

Ersatz: kleine milde Spitzpaprika oder Shishito aus dem Asia-Laden.
