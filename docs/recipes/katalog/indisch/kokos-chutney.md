# Kokos-Chutney

![Kokos-Chutney](../../pictures/kokos-chutney.jpg)

Frisches südindisches Chutney aus Kokos, Röstkichererbsen und grüner Chili, passend zu Dosa und Sambar.

## Zutaten

| Menge  | Zutat        | Gruppe | Variante | Hinweis                 | Einkauf |
| ------ | ------------ | ------ | -------- | ----------------------- | ------- |
| 100 g  | Kokosraspeln |        |          |                         |         |
| 2 EL   | Kichererbsen |        |          | geröstet, oder Erdnüsse |         |
| 1      | Chilischoten |        |          | grün                    |         |
| 1 cm   | Ingwer       |        |          |                         |         |
| 1 EL   | Zitronen     |        |          | Saft                    |         |
| 0,5 TL | Salz         |        |          |                         |         |
| 100 ml | Wasser       |        |          | warm                    | nie     |
| 1 TL   | Kokosöl      | Tadka  |          |                         |         |
| 0,5 TL | Senfkörner   | Tadka  |          |                         |         |
| 5      | Curryblätter | Tadka  |          | optional                |         |

## Zubereitung

1. Kokosraspeln, Kichererbsen, Chili, Ingwer, Zitronensaft, Salz und Wasser fein pürieren.
2. In eine Schüssel füllen.
3. Kokosöl erhitzen, Senfsamen und Curryblätter kurz knistern lassen. ⏱ 1
4. Tadka über das Chutney geben und servieren.

## Notizen

Mit TK-Kokos geht es ebenso. Im Kühlschrank 2 Tage haltbar.
