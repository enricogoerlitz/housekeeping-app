# Chapati

![Chapati](../../pictures/chapati.jpg)

Weiche Fladen aus Vollkornmehl, ohne Hefe in der Pfanne gebacken.

## Zutaten

| Menge  | Zutat        | Gruppe | Variante | Hinweis         | Einkauf |
| ------ | ------------ | ------ | -------- | --------------- | ------- |
| 250 g  | Vollkornmehl |        |          |                 |         |
| 0,5 TL | Salz         |        |          |                 |         |
| 1 EL   | Pflanzenöl   |        |          |                 |         |
| 150 ml | Wasser       |        |          | lauwarm         | nie     |
| 1 EL   | Ghee         |        |          | zum Bestreichen |         |

## Zubereitung

1. Mehl und Salz mischen, Öl und Wasser zugeben und zu einem weichen Teig kneten (5 Minuten).
2. Zugedeckt 20 Minuten ruhen lassen. ⏱ 20
3. Teig in 8 Kugeln teilen und auf bemehlter Fläche dünn ausrollen (ca. 16 cm).
4. Pfanne stark erhitzen, Fladen 40 Sekunden backen, wenden und weitere 40 Sekunden backen. ⏱ 2
5. Auf offener Flamme oder in der Pfanne mit einem Tuch andrücken, bis er sich aufbläht. Mit Ghee bestreichen und warm halten.

## Notizen

Im Küchentuch bleibt Chapati weich. Aufwärmen in der trockenen Pfanne.
