# Aloo Gobi

![Aloo Gobi](../../pictures/aloo-gobi.jpg)

Trockenes Curry aus Kartoffeln und Blumenkohl mit Kurkuma und Kreuzkümmel. Schmeckt mit Fladenbrot oder Reis.

## Zutaten

| Menge  | Zutat              | Gruppe | Variante     | Hinweis                      | Einkauf |
| ------ | ------------------ | ------ | ------------ | ---------------------------- | ------- |
| 1      | Blumenkohl         |        |              | in kleinen Röschen           |         |
| 400 g  | Kartoffeln         |        |              | festkochend, in 2 cm Würfeln |         |
| 2 EL   | Pflanzenöl         |        |              |                              |         |
| 1 TL   | Kreuzkümmel        |        |              | ganz                         |         |
| 1      | Zwiebel            |        |              | gewürfelt                    |         |
| 3      | Knoblauch          |        |              | Zehen, gehackt               |         |

| 1 TL   | Koriander gemahlen |        |              |                              |         |

## Zubereitung

1. Öl in einer großen Pfanne erhitzen, Kreuzkümmel 30 Sekunden rösten, Zwiebel 5 Minuten dünsten. ⏱ 5
2. [Mit Hähnchen] Hähnchenwürfel zugeben und 5 Minuten anbraten. ⏱ 5
3. Knoblauch, Ingwer, Kurkuma und Koriander zugeben und 1 Minute rühren.
4. Kartoffeln und 50 ml Wasser zugeben, zugedeckt 10 Minuten garen. ⏱ 10
5. Blumenkohl und Tomaten zugeben, salzen und weitere 12 Minuten zugedeckt garen, gelegentlich wenden. ⏱ 12
6. Deckel abnehmen, 3 Minuten braten, bis die Ränder Farbe nehmen. Garam Masala und Koriander unterheben. ⏱ 3
7. Mit Reis servieren.

## Notizen

Möglichst wenig Wasser nehmen, das Gemüse soll trocken und röstig werden.
