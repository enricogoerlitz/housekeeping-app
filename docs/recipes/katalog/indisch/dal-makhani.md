# Dal Makhani

![Dal Makhani](../../pictures/dal-makhani.jpg)

Schwarze Linsen und Kidneybohnen, lange geköchelt mit Butter und Sahne. Cremig und reichhaltig.

## Zutaten

| Menge  | Zutat           | Gruppe | Variante     | Hinweis               | Einkauf |
| ------ | --------------- | ------ | ------------ | --------------------- | ------- |
| 150 g  | Schwarze Linsen |        |              | Beluga oder Urdbohnen |         |
| 1 Dose | Kidneybohnen    |        |              | abgetropft            |         |
| 2 EL   | Butter          |        |              |                       |         |
| 1      | Zwiebel         |        |              | fein gewürfelt        |         |
| 3      | Knoblauch       |        |              | Zehen, gehackt        |         |
| 2 cm   | Ingwer          |        |              | gerieben              |         |
| 2 EL   | Tomatenmark     |        |              |                       |         |

| 1 TL   | Salz            |        |              |                       |         |
| 100 ml | Sahne           |        |              |                       |         |
| 300 g  | Hähnchenbrust   |        | Mit Hähnchen | in Würfeln            | Menge   |
| 250 g  | Basmatireis     |        |              |                       |         |
| 1 l    | Wasser          |        |              |                       | nie     |

## Zubereitung

1. Schwarze Linsen mit 700 ml Wasser 35 Minuten kochen, bis sie fast weich sind. ⏱ 35
2. Butter erhitzen, Zwiebel 8 Minuten braten, Knoblauch, Ingwer und Tomatenmark 2 Minuten mitrösten. ⏱ 8
3. [Mit Hähnchen] Hähnchenwürfel zugeben und 5 Minuten anbraten. ⏱ 5
4. Linsen samt Kochwasser, Kidneybohnen, Garam Masala, Paprika und Salz zugeben und 25 Minuten köcheln lassen, dabei gelegentlich rühren. ⏱ 25
5. Sahne zugeben und 5 Minuten cremig einkochen. ⏱ 5
6. Reis garen und das Dal mit Reis servieren.

## Notizen

Schwarze Linsen (Beluga) lassen sich ersatzweise mit braunen Tellerlinsen kochen, sie brauchen dann kürzer. Dal Makhani schmeckt am nächsten Tag noch besser.
