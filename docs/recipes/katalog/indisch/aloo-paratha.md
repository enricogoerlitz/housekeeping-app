# Aloo Paratha

![Aloo Paratha](../../pictures/aloo-paratha.jpg)

Gefüllte Fladen mit Gewürzkartoffeln, in Ghee knusprig gebacken. Ein beliebtes Frühstück im Punjab.

## Zutaten

| Menge  | Zutat         | Gruppe  | Variante | Hinweis            | Einkauf |
| ------ | ------------- | ------- | -------- | ------------------ | ------- |
| 250 g  | Vollkornmehl  | Teig    |          |                    |         |
| 0,5 TL | Salz          | Teig    |          |                    |         |
| 130 ml | Wasser        | Teig    |          |                    | nie     |
| 300 g  | Kartoffeln    | Füllung |          | mehligkochend      |         |
| 1 TL   | Kreuzkümmel   | Füllung |          | gemahlen           |         |
| 1 TL   | Garam Masala  | Füllung |          |                    |         |
| 1      | Chilischoten  | Füllung |          | grün, fein gehackt |         |
| 2 EL   | Koriandergrün | Füllung |          | gehackt            |         |
| 0,5 TL | Salz          | Füllung |          |                    |         |
| 3 EL   | Ghee          |         |          | zum Braten         |         |

## Zubereitung

1. Mehl, Salz und Wasser zu einem weichen Teig kneten, 20 Minuten ruhen lassen. ⏱ 20
2. Kartoffeln in Salzwasser 15 Minuten kochen, pellen und fein zerdrücken. ⏱ 15
3. Kartoffeln mit Gewürzen, Chili, Koriander und Salz vermengen und abkühlen lassen.
4. Teig in 6 Kugeln teilen, flach drücken, 1 EL Füllung mittig geben, Ränder zusammenfassen und wieder flach drücken.
5. Vorsichtig zu runden Fladen von 15 cm ausrollen.
6. Pfanne erhitzen, Paratha 2 Minuten backen, wenden, mit Ghee bestreichen und beidseitig goldbraun backen. ⏱ 4

## Notizen

Die Füllung muss vollständig abgekühlt sein, sonst reißt der Teig. Dazu Raita (gurken-raita).
