# Rajma Masala

![Rajma Masala](../../pictures/rajma-masala.jpg)

Kidneybohnen in kräftiger Tomaten-Zwiebel-Sauce, das Wohlfühlgericht des Punjab.

## Zutaten

| Menge   | Zutat              | Gruppe | Variante     | Hinweis        | Einkauf |
| ------- | ------------------ | ------ | ------------ | -------------- | ------- |
| 2 Dosen | Kidneybohnen       |        |              | abgetropft     |         |
| 2 EL    | Pflanzenöl         |        |              |                |         |
| 1       | Zwiebel            |        |              | fein gewürfelt |         |
| 3       | Knoblauch          |        |              | Zehen, gehackt |         |
| 2 cm    | Ingwer             |        |              | gerieben       |         |
| 1 TL    | Kreuzkümmel        |        |              | gemahlen       |         |
| 1 TL    | Koriander gemahlen |        |              |                |         |
| 1 TL    | Garam Masala       |        |              |                |         |
| 1 TL    | Paprikapulver      |        |              | edelsüß        |         |
| 400 g   | Passierte Tomaten  |        |              |                |         |
| 1 TL    | Salz               |        |              |                |         |
| 1 EL    | Butter             |        |              | zum Schluss    |         |
| 300 g   | Hähnchenbrust      |        | Mit Hähnchen | in Würfeln     | Menge   |
| 250 g   | Basmatireis        |        |              |                |         |
| 500 ml  | Wasser             |        |              |                | nie     |

## Zubereitung

1. Zwiebel im Öl 8 Minuten goldbraun braten. ⏱ 8
2. [Mit Hähnchen] Hähnchenwürfel zugeben und 5 Minuten anbraten. ⏱ 5
3. Knoblauch, Ingwer und alle Gewürze 1 Minute mitrösten.
4. Passierte Tomaten und Salz zugeben, 8 Minuten einkochen lassen. ⏱ 8
5. Bohnen und 150 ml Wasser zugeben, zugedeckt 20 Minuten leise köcheln lassen. ⏱ 20
6. Ein Drittel der Bohnen zerdrücken, Butter einrühren.
7. Reis garen und mit dem Rajma servieren.

## Notizen

Mit Kichererbsen statt Kidneybohnen schmeckt es ebenfalls gut.
