# Gurken-Raita

![Gurken-Raita](../../pictures/gurken-raita.jpg)

Kühler Joghurtdip mit Gurke, der scharfe Currys abmildert.

## Zutaten

| Menge   | Zutat         | Gruppe | Variante | Hinweis                    | Einkauf |
| ------- | ------------- | ------ | -------- | -------------------------- | ------- |
| 250 g   | Naturjoghurt  |        |          |                            |         |
| 0,5     | Salatgurke    |        |          | gerieben und ausgedrückt   |         |
| 1       | Knoblauch     |        |          | Zehe, gepresst             |         |
| 1 TL    | Kreuzkümmel   |        |          | gemahlen, trocken geröstet |         |
| 1 EL    | Minze         |        |          | fein gehackt               |         |
| 0,5 TL  | Salz          |        |          |                            |         |
| 1 Prise | Paprikapulver |        |          | zum Bestreuen              |         |

## Zubereitung

1. Gurke reiben und in den Händen gut ausdrücken.
2. Joghurt mit Knoblauch, Salz und Minze glatt rühren.
3. Gurke unterheben, mit Kreuzkümmel und Paprikapulver bestreuen. ⏱ 10
4. Vor dem Servieren kurz kalt stellen.

## Notizen

Hält sich im Kühlschrank 2 Tage, danach wird er wässrig.
