# Palak Paneer

![Palak Paneer](../../pictures/palak-paneer.jpg)

Cremiger Spinat mit gebratenem Paneer, ein Klassiker der vegetarischen Küche Nordindiens.

## Zutaten

| Menge  | Zutat         | Gruppe | Variante     | Hinweis                       | Einkauf |
| ------ | ------------- | ------ | ------------ | ----------------------------- | ------- |
| 450 g  | Blattspinat   |        |              | TK, aufgetaut und ausgedrückt |         |
| 250 g  | Paneer        |        | Vegetarisch  | gewürfelt                     | Menge   |
| 300 g  | Hähnchenbrust |        | Mit Hähnchen | in Stücken                    | Menge   |
| 1 EL   | Ghee          |        |              | oder Butterschmalz            |         |
| 1      | Zwiebel       |        |              | fein gehackt                  |         |
| 3      | Knoblauch     |        |              | Zehen, gehackt                |         |
| 2 cm   | Ingwer        |        |              | gerieben                      |         |
| 1      | Chilischoten  |        |              | grün, fein gehackt            |         |
| 1 TL   | Kreuzkümmel   |        |              | ganz                          |         |
| 1 TL   | Garam Masala  |        |              |                               |         |
| 1      | Tomate        |        |              | gewürfelt                     |         |
| 80 ml  | Sahne         |        |              |                               |         |
| 1 TL   | Salz          |        |              |                               |         |

## Zubereitung

1. Ghee in einer Pfanne erhitzen, Paneer (oder Hähnchen) darin goldbraun anbraten und herausnehmen. ⏱ 6
2. Im selben Fett Kreuzkümmel 30 Sekunden rösten, Zwiebel 6 Minuten mitdünsten. ⏱ 6
3. Knoblauch, Ingwer und Chili 1 Minute mitbraten, Tomate zugeben und 4 Minuten weich kochen. ⏱ 4
4. Spinat unterrühren, 5 Minuten köcheln lassen, dann mit dem Stabmixer grob pürieren. ⏱ 5
5. Sahne, Garam Masala und Salz einrühren.
6. [Mit Hähnchen] Hähnchen 10 Minuten im Spinat gar ziehen lassen. ⏱ 10
7. [Vegetarisch] Paneer im Spinat 3 Minuten erwärmen. ⏱ 3
8. Reis in Salzwasser nach Packungsanleitung garen und zum Curry servieren.

## Notizen

Frischer Spinat geht auch: 600 g kurz blanchieren, abschrecken und ausdrücken.
