# Masala Dosa

![Masala Dosa](../../pictures/masala-dosa.jpg)

Hauchdünne knusprige Crêpes aus Reis- und Linsenteig mit Kartoffel-Masala. Hier mit einem schnellen Teig ohne tagelange Gärung.

## Zutaten

| Menge  | Zutat        | Gruppe  | Variante | Hinweis            | Einkauf |
| ------ | ------------ | ------- | -------- | ------------------ | ------- |
| 150 g  | Reismehl     | Teig    |          |                    |         |
| 50 g   | Weizenmehl   | Teig    |          |                    |         |
| 2 EL   | Naturjoghurt | Teig    |          |                    |         |
| 0,5 TL | Salz         | Teig    |          |                    |         |
| 350 ml | Wasser       | Teig    |          |                    | nie     |
| 500 g  | Kartoffeln   | Füllung |          | mehligkochend      |         |
| 1 EL   | Pflanzenöl   | Füllung |          |                    |         |
| 1 TL   | Senfkörner   | Füllung |          |                    |         |
| 1      | Zwiebel      | Füllung |          | in Streifen        |         |
| 1 TL   | Kurkuma      | Füllung |          |                    |         |
| 1      | Chilischoten | Füllung |          | grün, fein gehackt |         |
| 8      | Curryblätter | Füllung |          | optional           |         |
| 1 TL   | Salz         | Füllung |          |                    |         |
| 2 EL   | Pflanzenöl   |         |          | zum Backen         |         |

## Zubereitung

1. Reismehl, Weizenmehl, Joghurt, Salz und Wasser zu einem dünnflüssigen Teig verrühren und 20 Minuten quellen lassen. ⏱ 20
2. Kartoffeln schälen, in Salzwasser 15 Minuten weich kochen, grob zerdrücken. ⏱ 15
3. Öl erhitzen, Senfsamen und Curryblätter zugeben, dann Zwiebel, Chili und Kurkuma 5 Minuten dünsten. ⏱ 5
4. Kartoffeln und Salz untermischen, Füllung warm halten.
5. Eine beschichtete Pfanne stark erhitzen, leicht ölen, eine Kelle Teig in Spiralen dünn verstreichen.
6. Bei mittlerer Hitze 2–3 Minuten backen, bis die Unterseite goldbraun und knusprig ist. ⏱ 3
7. Füllung auf eine Hälfte geben, zusammenklappen und sofort mit Chutney servieren.

## Notizen

Original wird der Teig über Nacht fermentiert; dieser Schnellteig liefert ähnliche Knusprigkeit. Dazu passt Kokos-Chutney oder Minz-Chutney.
