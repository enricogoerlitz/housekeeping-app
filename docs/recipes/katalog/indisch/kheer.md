# Kheer

![Kheer](../../pictures/kheer.jpg)

Milchreis auf indische Art: lange geköchelt, mit Kardamom, Safran und Pistazien.

## Zutaten

| Menge   | Zutat       | Gruppe | Variante | Hinweis                    | Einkauf |
| ------- | ----------- | ------ | -------- | -------------------------- | ------- |
| 60 g    | Basmatireis |        |          |                            |         |
| 750 ml  | Vollmilch   |        |          |                            |         |
| 60 g    | Zucker      |        |          |                            |         |
| 4       | Kardamom    |        |          | Kapseln, leicht angedrückt |         |
| 1 Prise | Safran      |        |          |                            |         |
| 2 EL    | Pistazien   |        |          | gehackt                    |         |
| 2 EL    | Mandeln     |        |          | gehobelt                   |         |
| 2 EL    | Rosinen     |        |          |                            |         |

## Zubereitung

1. Reis waschen und 20 Minuten in Wasser einweichen, abtropfen lassen. ⏱ 20
2. Milch mit Kardamom aufkochen, Reis zugeben und bei kleiner Hitze 35 Minuten unter häufigem Rühren köcheln, bis er sehr weich und die Milch sämig ist. ⏱ 35
3. Zucker, Safran und Rosinen einrühren, 5 Minuten weiterköcheln. ⏱ 5
4. Warm oder kalt mit Pistazien und Mandeln servieren.

## Notizen

Kardamomkapseln vor dem Servieren herausnehmen. Beim Abkühlen wird Kheer fester, gegebenenfalls mit etwas Milch verdünnen.
