# Sambar

![Sambar](../../pictures/sambar.jpg)

Südindischer Linsen-Gemüse-Eintopf mit Tamarinde, der zu Reis, Dosa oder Idli gegessen wird.

## Zutaten

| Menge   | Zutat           | Gruppe | Variante     | Hinweis                               | Einkauf |
| ------- | --------------- | ------ | ------------ | ------------------------------------- | ------- |
| 150 g   | Rote Linsen     |        |              | oder Toor Dal, oder gelbe Spaltlinsen |         |
| 1 TL    | Kurkuma         |        |              |                                       |         |
| 1       | Karotte         |        |              | in Scheiben                           |         |
| 1       | Zucchini        |        |              | gewürfelt                             |         |
| 1       | Kartoffel       |        |              | gewürfelt                             |         |
| 1       | Tomate          |        |              | gewürfelt                             |         |
| 1 EL    | Tamarindenpaste |        |              |                                       |         |
| 2 EL    | Sambar Pulver   |        |              |                                       |         |
| 1 TL    | Salz            |        |              |                                       |         |
| 1 EL    | Kokosöl         | Tadka  |              |                                       |         |
| 1 TL    | Senfkörner      | Tadka  |              | schwarz                               |         |
| 8       | Curryblätter    | Tadka  |              |                                       |         |
| 2       | Chilischoten    | Tadka  |              | getrocknet                            |         |
| 1 Prise | Asafoetida      | Tadka  |              | optional                              |         |
| 300 g   | Hähnchenbrust   |        | Mit Hähnchen | in Würfeln                            | Menge   |
| 250 g   | Basmatireis     |        |              |                                       |         |
| 1,2 l   | Wasser          |        |              |                                       | nie     |

## Zubereitung

1. Linsen mit 600 ml Wasser und Kurkuma 25 Minuten weich kochen, dann glatt rühren. ⏱ 25
2. Karotte, Kartoffel und Zucchini in 300 ml Wasser 10 Minuten bissfest kochen. ⏱ 10
3. [Mit Hähnchen] Hähnchenwürfel in den letzten 8 Minuten im Gemüse mitgaren. ⏱ 8
4. Linsen, Tomate, Tamarinde, Sambar Pulver und Salz zum Gemüse geben und 10 Minuten köcheln. ⏱ 10
5. Reis nach Packungsanleitung garen.
6. Für den Tadka Kokosöl erhitzen, Senfsamen, Curryblätter, Chilis und Asafoetida kurz knistern lassen und über den Sambar gießen.

## Notizen

Sambar Pulver und Toor Dal gibt es im Asia- oder Indienladen. Mit roten Linsen geht es auch, sie zerfallen schneller.
