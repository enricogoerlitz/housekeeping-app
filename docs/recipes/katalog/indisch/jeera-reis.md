# Jeera-Reis

![Jeera-Reis](../../pictures/jeera-reis.jpg)

Duftender Basmatireis mit Kreuzkümmel, passend zu Dal und Currys.

## Zutaten

| Menge  | Zutat        | Gruppe | Variante | Hinweis | Einkauf |
| ------ | ------------ | ------ | -------- | ------- | ------- |
| 250 g  | Basmatireis  |        |          |         |         |
| 1 EL   | Ghee         |        |          | oder Öl |         |
| 1 TL   | Kreuzkümmel  |        |          | ganz    |         |
| 2      | Lorbeerblatt |        |          |         |         |
| 0,5 TL | Salz         |        |          |         |         |
| 450 ml | Wasser       |        |          |         | nie     |

## Zubereitung

1. Reis in einem Sieb unter kaltem Wasser spülen, bis das Wasser klar ist, 15 Minuten einweichen und abtropfen lassen. ⏱ 15
2. Ghee im Topf erhitzen, Kreuzkümmel und Lorbeer 30 Sekunden rösten.
3. Reis 1 Minute mitrösten, Wasser und Salz zugeben und aufkochen.
4. Zugedeckt bei kleinster Hitze 10 Minuten garen, dann 5 Minuten ohne Hitze ruhen lassen. ⏱ 10
5. Mit einer Gabel auflockern.

## Notizen

Nicht während des Garens den Deckel heben.
