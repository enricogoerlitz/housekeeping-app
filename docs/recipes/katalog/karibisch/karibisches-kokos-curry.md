# Karibisches Kokos-Kichererbsen-Curry

![Karibisches Kokos-Kichererbsen-Curry](../../pictures/karibisches-kokos-curry.jpg)

Cremiges Curry mit Kichererbsen und Süßkartoffel in Kokosmilch, angelehnt an die jamaikanische Küche.

## Zutaten

| Menge   | Zutat        | Gruppe | Variante     | Hinweis                  | Einkauf |
| ------- | ------------ | ------ | ------------ | ------------------------ | ------- |
| 1       | Süßkartoffel |        |              | in 2 cm Würfeln          |         |
| 400 g   | Kichererbsen |        |              | aus der Dose, abgetropft |         |
| 150 g   | Blattspinat  |        |              | frisch                   |         |
| 1       | Zwiebel      |        |              | gewürfelt                |         |
| 3       | Knoblauch    |        |              | Zehen                    |         |
| 1 Stück | Ingwer       |        |              | haselnussgroß, gerieben  |         |
| 2 EL    | Currypulver  |        |              | mild                     |         |
| 1 TL    | Piment       |        |              | gemahlen                 |         |
| 1 TL    | Thymian      |        |              | getrocknet               |         |
| 400 ml  | Kokosmilch   |        |              |                          |         |
| 200 ml  | Gemüsebrühe  |        |              |                          |         |
| 200 g   | Garnelen     |        | Mit Garnelen | geschält, aufgetaut      | Menge   |
| 2 EL    | Pflanzenöl   |        |              |                          |         |
| 1       | Limette      |        |              | Saft                     |         |
| 150 g   | Basmatireis  |        |              | als Beilage              |         |
| 300 ml  | Wasser       |        |              | für den Reis             | nie     |

## Zubereitung

1. Reis mit Wasser und Salz aufkochen und zugedeckt 12 Minuten garen. ⏱ 12
2. Zwiebel in Öl 4 Minuten dünsten, Knoblauch und Ingwer 1 Minute mitbraten. ⏱ 5
3. Curry, Piment und Thymian 30 Sekunden rösten.
4. Süßkartoffel, Kokosmilch und Brühe zugeben, 12 Minuten köcheln. ⏱ 12
5. Kichererbsen zugeben und 5 Minuten kochen, Spinat unterheben, bis er zusammenfällt. ⏱ 5
6. [Mit Garnelen] Garnelen zugeben und 3 Minuten gar ziehen lassen. ⏱ 3
7. Mit Limettensaft und Salz abschmecken, mit Reis servieren.

## Notizen

Jamaikanisches Curry wird oft mit Ziegenfleisch gekocht; Piment gibt die typische Note.
