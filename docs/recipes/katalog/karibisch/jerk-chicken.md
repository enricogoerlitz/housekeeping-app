# Jerk Chicken

![Jerk Chicken](../../pictures/jerk-chicken.jpg)

Jamaikanisches Hähnchen in scharf-würziger Jerk-Marinade mit Piment, Thymian und Chili, im Ofen knusprig gebacken.

## Zutaten

| Menge | Zutat            | Gruppe   | Variante     | Hinweis                                              | Einkauf |
| ----- | ---------------- | -------- | ------------ | ---------------------------------------------------- | ------- |
| 600 g | Hähnchenschenkel |          | Mit Hähnchen | mit Haut                                             | Menge   |
| 1     | Blumenkohl       |          | Vegetarisch  | in dicken Scheiben oder Röschen (ca. 600 g)          | Menge   |
| 4     | Lauchzwiebel     | Marinade |              | grob gehackt                                         |         |
| 3     | Knoblauch        | Marinade |              | Zehen                                                |         |
| 1     | Chilischoten     | Marinade |              | Habanero, oder Scotch Bonnet, entkernt (sehr scharf) |         |
| 1 EL  | Piment           | Marinade |              | gemahlen                                             |         |
| 1 EL  | Thymian          | Marinade |              | frisch oder getrocknet                               |         |
| 3 EL  | Sojasauce        | Marinade |              |                                                      |         |
| 2 EL  | Brauner Zucker   | Marinade |              |                                                      |         |
| 3 EL  | Limetten         | Marinade |              | Saft                                                 |         |
| 2 EL  | Pflanzenöl       | Marinade |              |                                                      |         |
| 1     | Limette          |          |              | in Spalten, zum Servieren                            |         |

## Zubereitung

1. Alle Zutaten der Marinade im Mixer zu einer groben Paste pürieren.
2. Hähnchen bzw. Blumenkohl mit der Marinade einreiben und abgedeckt mindestens 4 Stunden, am besten über Nacht, kühl stellen.
3. Backofen auf 220 °C Ober-/Unterhitze vorheizen.
4. [Mit Hähnchen] Hähnchen auf ein Blech mit Rost legen und 40 bis 45 Minuten backen, nach der Hälfte wenden. ⏱ 45
5. [Vegetarisch] Blumenkohl auf einem Blech 30 Minuten rösten, nach der Hälfte wenden. ⏱ 30
6. Die letzten 5 Minuten auf Grillfunktion für dunkle Stellen stellen. ⏱ 5
7. Mit Limettenspalten servieren.

## Notizen

Habanero sehr scharf, bei Bedarf nur die Hälfte nehmen und mit Handschuhen entkernen. Dazu Rice and Peas. Piment (Nelkenpfeffer) im Gewürzregal.
