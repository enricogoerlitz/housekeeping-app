# Rice and Peas

![Rice and Peas](../../pictures/rice-and-peas.jpg)

Jamaikanischer Kokosreis mit roten Bohnen, die klassische Begleitung zu Jerk Chicken.

## Zutaten

| Menge  | Zutat        | Gruppe | Variante | Hinweis                     | Einkauf |
| ------ | ------------ | ------ | -------- | --------------------------- | ------- |
| 150 g  | Langkornreis |        |          |                             |         |
| 1 Dose | Kidneybohnen |        |          | mit Flüssigkeit (ca. 240 g) |         |
| 200 ml | Kokosmilch   |        |          |                             |         |
| 150 ml | Wasser       |        |          |                             | nie     |
| 2      | Lauchzwiebel |        |          | in Ringen                   |         |
| 2      | Knoblauch    |        |          | Zehen                       |         |
| 1 TL   | Thymian      |        |          | frisch oder getrocknet      |         |
| 1 TL   | Piment       |        |          | ganze Körner oder gemahlen  |         |
| 1 TL   | Salz         |        |          |                             |         |

## Zubereitung

1. Reis kalt abspülen und abtropfen lassen.
2. Bohnen samt Flüssigkeit, Kokosmilch, Wasser, Lauchzwiebeln, Knoblauch, Thymian, Piment und Salz in einem Topf aufkochen.
3. Reis zugeben, einmal umrühren und aufkochen.
4. Zugedeckt bei kleinster Hitze 18 Minuten garen, ohne zu rühren. ⏱ 18
5. 5 Minuten quellen lassen, mit einer Gabel auflockern. ⏱ 5

## Notizen

Mit ganzen Pimentkörnern: vor dem Servieren herausnehmen.
