# Ropa vieja

![Ropa vieja](../../pictures/ropa-vieja.jpg)

Kubanisches Schmorfleisch, in Fasern gezupft, in Tomaten-Paprika-Sauce mit Reis und Bohnen.

## Zutaten

| Menge  | Zutat            | Gruppe | Variante        | Hinweis                        | Einkauf |
| ------ | ---------------- | ------ | --------------- | ------------------------------ | ------- |
| 500 g  | Rinderschulter   |        | Mit Rindfleisch | am Stück                       | Menge   |
| 500 g  | Jackfruit        |        | Vegetarisch     | junge, abgetropft und zerzupft | Menge   |
| 1      | Zwiebel          |        |                 | in Streifen                    |         |
| 1      | Paprika          |        |                 | rot, in Streifen               |         |
| 1      | Paprika          |        |                 | grün, in Streifen              |         |
| 3      | Knoblauch        |        |                 | Zehen                          |         |
| 400 g  | Stückige Tomaten |        |                 |                                |         |
| 2 EL   | Tomatenmark      |        |                 |                                |         |
| 1 TL   | Kreuzkümmel      |        |                 | gemahlen                       |         |
| 1 TL   | Oregano          |        |                 | getrocknet                     |         |
| 2      | Lorbeerblatt     |        |                 |                                |         |
| 200 ml | Gemüsebrühe      |        |                 |                                |         |
| 2 EL   | Olivenöl         |        |                 |                                |         |
| 40 g   | Grüne Oliven     |        |                 | in Scheiben                    |         |
| 150 g  | Reis             |        |                 | als Beilage                    |         |

## Zubereitung

1. [Mit Rindfleisch] Fleisch in 1 EL Öl rundum 8 Minuten anbraten, herausnehmen. ⏱ 8
2. Zwiebel und Paprika im restlichen Öl 5 Minuten anbraten, Knoblauch, Tomatenmark und Gewürze 2 Minuten mitrösten. ⏱ 7
3. Tomaten, Brühe und Lorbeer zugeben, aufkochen.
4. [Mit Rindfleisch] Fleisch zurücklegen und zugedeckt 2 Stunden bei kleiner Hitze schmoren. ⏱ 120
5. [Mit Rindfleisch] Fleisch herausnehmen, mit zwei Gabeln zerzupfen und zurück in die Sauce geben, 10 Minuten einkochen. ⏱ 10
6. [Vegetarisch] Jackfruit zugeben und 30 Minuten bei kleiner Hitze schmoren, bis die Sauce dick ist. ⏱ 30
7. Reis kochen, Bohnen erwärmen. Mit Oliven garnieren und alles anrichten.

## Notizen

Jackfruit gibt es in Dosen (junge Frucht in Salzlake). Für den Schmorbraten eignet sich auch Wade.
