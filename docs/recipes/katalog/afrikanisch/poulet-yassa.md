# Poulet Yassa

![Poulet Yassa](../../pictures/poulet-yassa.jpg)

Senegalesischer Klassiker: Hähnchen in einer Marinade aus viel Zwiebeln, Zitrone und Senf, langsam geschmort, mit Reis.

## Zutaten

| Menge  | Zutat         | Gruppe | Variante     | Hinweis          | Einkauf |
| ------ | ------------- | ------ | ------------ | ---------------- | ------- |
| 4      | Hähnchenkeule |        | Mit Hähnchen |                  | Menge   |
| 300 g  | Tofu          |        | Vegetarisch  | fest, in Würfeln | Menge   |
| 200 g  | Champignons   |        | Vegetarisch  | geviertelt       |         |
| 5      | Zwiebel       |        |              | in Ringen        |         |
| 3      | Zitrone       |        |              | Saft             |         |

## Zubereitung

1. Zwiebeln mit Zitronensaft, Senf, Knoblauch, Salz und Pfeffer vermengen.
2. [Mit Hähnchen] Keulen in der Marinade mindestens 2 Stunden ziehen lassen. ⏱ 120
3. [Vegetarisch] Tofuwürfel in der Marinade 30 Minuten ziehen lassen. ⏱ 30
4. [Mit Hähnchen] Keulen aus der Marinade nehmen, abtupfen und in Öl rundum 8 Minuten anbraten. ⏱ 8
5. [Vegetarisch] Tofu abtupfen und in Öl goldbraun braten, danach Pilze 5 Minuten mitbraten. ⏱ 8
6. Zwiebelmarinade mit Wasser und Chili zugeben, aufkochen und 30 Minuten zugedeckt schmoren. ⏱ 30
7. Reis kochen, Oliven in die Sauce geben und alles zusammen servieren.

## Notizen

Je mehr Zwiebeln, desto besser: die Sauce lebt davon. Chili im Ganzen mitkochen, nur anstechen, wenn es schärfer sein soll.
