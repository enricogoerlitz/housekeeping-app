# Jollof-Reis

![Jollof-Reis](../../pictures/jollof-reis.jpg)

Westafrikas Festreis: Langkornreis in einer würzigen Sauce aus Tomaten, Paprika und Zwiebeln, rauchig und scharf, mit Kochbanane oder Hähnchen.

## Zutaten

| Menge  | Zutat         | Gruppe | Variante     | Hinweis                                                    | Einkauf |
| ------ | ------------- | ------ | ------------ | ---------------------------------------------------------- | ------- |
| 250 g  | Langkornreis  |        |              | parboiled                                                  |         |
| 2      | Paprika       |        |              | rot                                                        |         |
| 3      | Tomate        |        |              |                                                            |         |
| 2      | Zwiebel       |        |              |                                                            |         |
| 1      | Chilischoten  |        |              | Scotch Bonnet oder Habanero, oder 1 Habanero, nach Schärfe |         |
| 2 EL   | Tomatenmark   |        |              |                                                            |         |
| 4 EL   | Pflanzenöl    |        |              |                                                            |         |
| 1 TL   | Curry         |        |              |                                                            |         |
| 1 TL   | Thymian       |        |              | getrocknet                                                 |         |
| 2      | Lorbeerblatt  |        |              |                                                            |         |
| 400 ml | Gemüsebrühe   |        | Vegetarisch  |                                                            |         |
| 400 ml | Hühnerbrühe   |        | Mit Hähnchen |                                                            |         |
| 4      | Hähnchenkeule |        | Mit Hähnchen |                                                            | Menge   |
| 1 TL   | Salz          |        |              |                                                            |         |

## Zubereitung

1. Paprika, Tomaten, Chili und eine Zwiebel im Mixer zu einem glatten Püree verarbeiten.
2. [Mit Hähnchen] Keulen salzen, mit Curry und Thymian einreiben und in 2 EL Öl rundum 8 Minuten anbraten, herausnehmen. ⏱ 8
3. Restliche Zwiebel würfeln und im Öl glasig dünsten, Tomatenmark 2 Minuten mitrösten. ⏱ 5
4. Püree zugeben und 15 Minuten kräftig einkochen, bis das Öl sich absetzt. ⏱ 15
5. Brühe, Lorbeer, Salz und Thymian zugeben, Reis einrühren.
6. [Mit Hähnchen] Die Keulen obenauf legen.
7. Zugedeckt bei kleinster Hitze 25 Minuten garen, nicht umrühren. ⏱ 25
8. Kochbananenscheiben in Öl goldbraun braten und zum Reis servieren.

## Notizen

Scotch Bonnet ist sehr scharf, ersatzweise 1 milde Chili. Der leicht angebrannte Boden gilt als besonders gut (Party Jollof).
