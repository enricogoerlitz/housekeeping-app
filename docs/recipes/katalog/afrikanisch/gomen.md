# Gomen

![Gomen](../../pictures/gomen.jpg)

Äthiopischer Grünkohl, sanft in Knoblauch, Ingwer und Zwiebel geschmort. Die Beilage zu jedem Linsen- oder Fleischgericht.

## Zutaten

| Menge  | Zutat      | Gruppe | Variante | Hinweis                       | Einkauf |
| ------ | ---------- | ------ | -------- | ----------------------------- | ------- |
| 500 g  | Grünkohl   |        |          | entstielt, in feinen Streifen |         |
| 1      | Zwiebel    |        |          | fein gewürfelt                |         |
| 3      | Knoblauch  |        |          | Zehen, gehackt                |         |
| 1 EL   | Ingwer     |        |          | frisch gerieben               |         |
| 3 EL   | Pflanzenöl |        |          |                               |         |
| 1/2 TL | Kurkuma    |        |          |                               |         |
| 1/2 TL | Kardamom   |        |          | gemahlen                      |         |
| 100 ml | Wasser     |        |          |                               | nie     |
| 1 TL   | Salz       |        |          |                               |         |

## Zubereitung

1. Zwiebel im Öl 5 Minuten glasig dünsten, Knoblauch, Ingwer und Gewürze 1 Minute mitrösten. ⏱ 5
2. Grünkohl und Wasser zugeben, abgedeckt 20 Minuten weich schmoren. ⏱ 20
3. Offen noch 5 Minuten einkochen lassen und salzen. ⏱ 5

## Notizen

Mit Mangold oder Spinat gelingt es genauso, dann nur 8 Minuten garen.
