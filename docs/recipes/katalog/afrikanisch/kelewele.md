# Kelewele

![Kelewele](../../pictures/kelewele.jpg)

Ghanaische Würzbananen: Kochbanane in Ingwer, Chili und Piment, knusprig gebraten.

## Zutaten

| Menge  | Zutat        | Gruppe | Variante | Hinweis                            | Einkauf |
| ------ | ------------ | ------ | -------- | ---------------------------------- | ------- |
| 2      | Kochbanane   |        |          | gelbschwarz, reif, in 2 cm Würfeln |         |
| 1 EL   | Ingwer       |        |          | frisch gerieben                    |         |
| 1      | Knoblauch    |        |          | Zehe, gepresst                     |         |
| 1/2 TL | Chiliflocken |        |          |                                    |         |
| 1/2 TL | Piment       |        |          | gemahlen                           |         |
| 1/2 TL | Salz         |        |          |                                    |         |
| 1      | Limette      |        |          | Saft                               |         |
| 250 ml | Pflanzenöl   |        |          | zum Braten                         |         |
| 2 EL   | Erdnüsse     |        |          | geröstet                           |         |

## Zubereitung

1. Bananenwürfel mit Ingwer, Knoblauch, Chili, Piment, Salz und Limettensaft vermengen und 10 Minuten ziehen lassen. ⏱ 10
2. Öl in einer Pfanne auf mittlere Hitze erhitzen.
3. Bananen portionsweise 3 bis 4 Minuten goldbraun und knusprig braten. ⏱ 4
4. Auf Küchenpapier abtropfen und mit Erdnüssen servieren.

## Notizen

Kochbananen (Plantains) gibt es im Asia- und Afroshop und in großen Supermärkten, ersatzweise sehr feste Bananen.
