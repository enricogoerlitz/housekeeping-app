# Misir Wat

![Misir Wat](../../pictures/misir-wat.jpg)

Äthiopischer Linseneintopf mit Berbere, langsam gekochten Zwiebeln und Knoblauch. Mit Injera oder Fladenbrot und Reis.

## Zutaten

| Menge  | Zutat       | Gruppe | Variante | Hinweis           | Einkauf |
| ------ | ----------- | ------ | -------- | ----------------- | ------- |
| 200 g  | Rote Linsen |        |          |                   |         |
| 3      | Zwiebel     |        |          | sehr fein gehackt |         |
| 4 EL   | Pflanzenöl  |        |          |                   |         |
| 4      | Knoblauch   |        |          | Zehen, gehackt    |         |
| 1 EL   | Ingwer      |        |          | frisch gerieben   |         |
| 2 EL   | Berbere     |        |          | Gewürzmischung    |         |
| 2 EL   | Tomatenmark |        |          |                   |         |
| 600 ml | Wasser      |        |          |                   | nie     |
| 1 TL   | Salz        |        |          |                   |         |
| 1      | Fladenbrot  |        |          | oder Injera       |         |

## Zubereitung

1. Zwiebeln ohne Fett 8 Minuten bei mittlerer Hitze trocken dünsten, bis sie weich sind. ⏱ 8
2. Öl, Knoblauch, Ingwer, Berbere und Tomatenmark zugeben und 5 Minuten rösten. ⏱ 5
3. Linsen und Wasser zufügen, aufkochen und 25 Minuten köcheln, bis ein dickes Mus entsteht. ⏱ 25
4. Mit Salz abschmecken, bei Bedarf Wasser nachgießen.
5. Mit Brot und Gomen servieren.

## Notizen

Berbere (Äthiopische Gewürzmischung) im Afro- oder Orientladen; ersatzweise 1 EL Paprikapulver, 1 TL Chili, 1 TL Kreuzkümmel, 1/2 TL Zimt, 1/2 TL Ingwer, 1/2 TL Kardamom.
