# Lauchzwiebel-Pfannkuchen

![Lauchzwiebel-Pfannkuchen](../../pictures/lauchzwiebel-pfannkuchen.jpg)

Knusprig-blättrige Fladen mit Frühlingszwiebeln (Congyoubing), einfach aus Mehl und Wasser.

## Zutaten

| Menge  | Zutat          | Gruppe  | Variante | Hinweis           | Einkauf |
| ------ | -------------- | ------- | -------- | ----------------- | ------- |
| 250 g  | Weizenmehl     | Teig    |          | Type 550          | Menge   |
| 160 ml | Wasser         | Teig    |          | heiß, ca. 80 Grad | nie     |
| 1 TL   | Salz           | Teig    |          |                   |         |
| 4      | Lauchzwiebel   | Füllung |          | in feinen Ringen  |         |
| 2 EL   | Sesamöl        | Füllung |          |                   |         |
| 4 EL   | Sonnenblumenöl |         |          | zum Braten        |         |
| 3 EL   | Sojasauce      | Dip     |          |                   |         |
| 1 EL   | Reisessig      | Dip     |          |                   |         |

## Zubereitung

1. Mehl und Salz mischen, heißes Wasser einrühren, 5 Minuten kneten und zugedeckt 30 Minuten ruhen lassen. ⏱ 35
2. Teig in 2 Stücke teilen, jedes dünn zu einem Oval ausrollen, mit Sesamöl bestreichen und mit Lauchzwiebeln bestreuen.
3. Von der langen Seite aufrollen, zur Schnecke einrollen und flach zu einer Scheibe von 1 cm ausrollen.
4. 2 EL Öl in einer Pfanne erhitzen, einen Pfannkuchen pro Seite 3 Minuten bei mittlerer Hitze goldbraun braten. ⏱ 6
5. Zweiten Pfannkuchen ebenso braten, in Stücke schneiden und mit Dip servieren. ⏱ 6

## Notizen

Das Aufrollen erzeugt die Blätterschichten; je dünner der Teig, desto mehr Schichten.
