# Yangzhou-Reis

![Yangzhou-Reis](../../pictures/yangzhou-gebratener-reis.jpg)

Der klassische kantonesische Eierreis mit Erbsen und Möhren. Am besten mit Reis vom Vortag.

## Zutaten

| Menge   | Zutat          | Gruppe | Variante                  | Hinweis             | Einkauf |
| ------- | -------------- | ------ | ------------------------- | ------------------- | ------- |
| 300 g   | Jasminreis     |        |                           | vom Vortag, gekühlt | Menge   |
| 3       | Ei             |        |                           |                     | Menge   |
| 120 g   | Garnelen       |        | Mit Garnelen und Schinken | geschält, aufgetaut | Menge   |
| 80 g    | Kochschinken   |        | Mit Garnelen und Schinken | gewürfelt           | Menge   |
| 80 g    | Erbsen         |        |                           | TK                  |         |

| 1 TL    | Sesamöl        |        |                           |                     |         |
| 3 EL    | Sonnenblumenöl |        |                           |                     |         |
| 1 Prise | Salz           |        |                           |                     |         |
| 1 Prise | Pfeffer        |        |                           | weiß                |         |

## Zubereitung

1. Reis mit den Händen auflockern, damit keine Klumpen bleiben. Eier mit Salz verquirlen.
2. 1 EL Öl im Wok sehr heiß erhitzen, Eier 30 Sekunden rühren, bis sie gerade gestockt sind, herausnehmen. ⏱ 1
3. [Mit Garnelen und Schinken] Garnelen und Schinken 2 Minuten im Wok braten, herausnehmen. ⏱ 2
4. Restliches Öl erhitzen, Karotte und Erbsen 2 Minuten braten. Reis zugeben und 4 Minuten unter ständigem Wenden anbraten. ⏱ 6
5. Sojasauce am Rand des Woks zugeben, Eier (und Garnelen mit Schinken) unterheben.
6. Mit Lauchzwiebeln, Sesamöl und Pfeffer abschmecken und sofort servieren.

## Notizen

Frisch gekochter Reis wird matschig: lieber am Vortag kochen oder 30 Minuten auf einem Blech auskühlen lassen.
