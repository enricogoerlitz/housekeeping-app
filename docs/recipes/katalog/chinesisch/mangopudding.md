# Mangopudding

![Mangopudding](../../pictures/mangopudding.jpg)

Cremiges Dessert nach Hongkonger Art, gut vorzubereiten und kalt serviert.

## Zutaten

| Menge   | Zutat        | Gruppe | Variante | Hinweis                  | Einkauf |
| ------- | ------------ | ------ | -------- | ------------------------ | ------- |
| 2       | Mango        |        |          | reif, geschält           | Menge   |
| 4 Blatt | Gelatine     |        |          |                          |         |
| 150 ml  | Milch        |        |          |                          |         |
| 2 EL    | Zucker       |        |          |                          |         |
| 100 ml  | Sahne        |        |          |                          |         |
| 3 EL    | Kondensmilch |        |          | ungesüßt, zum Beträufeln |         |

## Zubereitung

1. Gelatine 5 Minuten in kaltem Wasser einweichen. ⏱ 5
2. Eine Mango fein pürieren (ca. 200 g Püree); die zweite Mango würfeln und beiseitestellen.
3. Milch mit Zucker erwärmen (nicht kochen), ausgedrückte Gelatine darin auflösen.
4. Mangopüree und Sahne einrühren, in zwei Gläser füllen und mindestens 3 Stunden kalt stellen. ⏱ 180
5. Mit Mangowürfeln und Kondensmilch servieren.

## Notizen

Mindestens 3 Stunden im Kühlschrank. Vegetarische Alternative zu Gelatine: Agar-Agar nach Packungsangabe.
