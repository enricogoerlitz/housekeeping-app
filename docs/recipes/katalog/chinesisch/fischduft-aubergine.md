# Fischduft-Aubergine

![Fischduft-Aubergine](../../pictures/fischduft-aubergine.jpg)

Yu Xiang Qiezi: weiche Aubergine in süß-saurer, scharfer Knoblauch-Ingwer-Sauce. Den „Fischduft“ liefern die Gewürze, nicht der Fisch.

## Zutaten

| Menge   | Zutat          | Gruppe | Variante        | Hinweis             | Einkauf |
| ------- | -------------- | ------ | --------------- | ------------------- | ------- |
| 2       | Aubergine      |        |                 | in Stifte, ca. 6 cm | Menge   |
| 150 g   | Schweinehack   |        | Mit Hackfleisch |                     | Menge   |
| 1 EL    | Doubanjiang    |        |                 |                     | 1×      |
| 4       | Knoblauch      |        |                 | gehackt             |         |
| 1 Stück | Ingwer         |        |                 | gehackt             |         |
| 2 EL    | Sojasauce      |        |                 |                     |         |
| 1 EL    | Zucker         |        |                 |                     |         |
| 2 EL    | Reisessig      |        |                 |                     |         |
| 1 TL    | Speisestärke   |        |                 |                     |         |
| 150 ml  | Wasser         |        |                 |                     | nie     |
| 3       | Lauchzwiebel   |        |                 | in Ringen           |         |
| 4 EL    | Sonnenblumenöl |        |                 |                     |         |
| 1 TL    | Salz           |        |                 |                     |         |
| 250 g   | Jasminreis     |        |                 | zum Servieren       | Menge   |

## Zubereitung

1. Auberginenstifte mit Salz mischen und 15 Minuten stehen lassen, dann ausdrücken und trocken tupfen. ⏱ 15
2. Sojasauce, Zucker, Essig, Stärke und Wasser zur Sauce verrühren.
3. 3 EL Öl im Wok erhitzen, Auberginen in zwei Portionen je 6 Minuten braten, bis sie weich und goldbraun sind, herausnehmen. ⏱ 12
4. [Mit Hackfleisch] Hack im restlichen Öl 4 Minuten braten, dann beiseiteschieben. ⏱ 4
5. Doubanjiang, Knoblauch und Ingwer 1 Minute braten, bis es duftet. ⏱ 1
6. Auberginen und Sauce zugeben, 3 Minuten köcheln, bis die Sauce glänzt. Mit Lauchzwiebeln bestreuen und mit Reis servieren. ⏱ 3

## Notizen

Statt Doubanjiang geht Sambal Oelek mit etwas Misopaste. Die Auberginen saugen viel Öl; das Salzen vorab reduziert das.
