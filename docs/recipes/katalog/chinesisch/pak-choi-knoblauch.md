# Pak Choi mit Knoblauch

![Pak Choi mit Knoblauch](../../pictures/pak-choi-knoblauch.jpg)

Das schnelle kantonesische Gemüse zu jedem Reisgericht.

## Zutaten

| Menge | Zutat          | Gruppe | Variante | Hinweis                        | Einkauf |
| ----- | -------------- | ------ | -------- | ------------------------------ | ------- |
| 4     | Pak Choi       |        |          | längs halbiert                 | Menge   |
| 4     | Knoblauch      |        |          | in feinen Scheiben             |         |
| 1 EL  | Sonnenblumenöl |        |          |                                |         |
| 1 EL  | Austernsauce   |        |          | oder vegetarische Austernsauce | 1×      |
| 1 TL  | Sesamöl        |        |          |                                |         |
| 3 EL  | Wasser         |        |          |                                | nie     |

## Zubereitung

1. Pak Choi waschen und gut abtropfen lassen.
2. Öl im Wok erhitzen, Knoblauch 30 Sekunden anbraten, bis er duftet, aber nicht braun wird. ⏱ 1
3. Pak Choi mit der Schnittfläche nach unten 2 Minuten anbraten. ⏱ 2
4. Wasser und Austernsauce zugeben, zugedeckt 2 Minuten dämpfen. ⏱ 2
5. Mit Sesamöl beträufeln und sofort servieren.

## Notizen

Für vegan statt Austernsauce Sojasauce nehmen.
