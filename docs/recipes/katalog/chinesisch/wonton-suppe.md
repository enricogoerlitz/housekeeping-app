# Wonton-Suppe

![Wonton-Suppe](../../pictures/wonton-suppe.jpg)

Zarte Teigtaschen in klarer, würziger Brühe, kantonesisches Comfort Food.

## Zutaten

| Menge   | Zutat              | Gruppe  | Variante         | Hinweis           | Einkauf |
| ------- | ------------------ | ------- | ---------------- | ----------------- | ------- |
| 24      | Wonton-Teigblätter |         |                  | TK oder gekühlt   | Menge   |
| 200 g   | Schweinehack       | Füllung | Mit Schweinehack |                   | Menge   |
| 200 g   | Tofu               | Füllung | Vegetarisch      | zerbröselt        | Menge   |
| 100 g   | Champignons        | Füllung | Vegetarisch      | sehr fein gehackt | Menge   |
| 1 EL    | Sojasauce          | Füllung |                  |                   |         |

| 700 ml  | Gemüsebrühe        | Brühe   |                  |                   |         |
| 1 EL    | Sojasauce          | Brühe   |                  |                   |         |
| 2       | Pak Choi           | Brühe   |                  | geviertelt        |         |
| 1 TL    | Sesamöl            | Brühe   |                  |                   |         |
| 1 Prise | Pfeffer            | Brühe   |                  | weiß              |         |

## Zubereitung

1. Alle Zutaten der Füllung gründlich zu einer glatten Masse verrühren (Hack 2 Minuten kräftig rühren).
2. 1 TL Füllung in die Mitte jedes Teigblatts setzen, Ränder mit Wasser bestreichen, zu einem Dreieck falten und die Ecken zusammendrücken. ⏱ 15
3. Brühe mit Sojasauce und Pfeffer erhitzen und leise köcheln lassen. ⏱ 5
4. Wontons in reichlich kochendem Wasser garen, bis sie oben schwimmen: Fleisch 5 Minuten, vegetarisch 4 Minuten. ⏱ 5
5. Pak Choi 2 Minuten in der Brühe garen. ⏱ 2
6. Wontons mit der Schaumkelle in Schalen geben, Brühe darübergießen, mit Sesamöl beträufeln.

## Notizen

Fertige Wontons lassen sich roh einfrieren (auf Blech vorfrieren) und direkt gefroren 1 Minute länger kochen.
