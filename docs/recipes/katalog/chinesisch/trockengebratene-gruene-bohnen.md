# Trockengebratene grüne Bohnen

![Trockengebratene grüne Bohnen](../../pictures/trockengebratene-gruene-bohnen.jpg)

Sichuan-Art: Bohnen werden bei hoher Hitze gebraten, bis sie runzlig und aromatisch sind.

## Zutaten

| Menge   | Zutat          | Gruppe | Variante | Hinweis              | Einkauf |
| ------- | -------------- | ------ | -------- | -------------------- | ------- |
| 300 g   | Grüne Bohnen   |        |          | geputzt              | Menge   |
| 3       | Knoblauch      |        |          | gehackt              |         |
| 2       | Chilischoten   |        |          | getrocknet, halbiert |         |
| 1 EL    | Sojasauce      |        |          |                      |         |
| 0,5 TL  | Zucker         |        |          |                      |         |
| 3 EL    | Sonnenblumenöl |        |          |                      |         |
| 1 Prise | Salz           |        |          |                      |         |

## Zubereitung

1. Bohnen waschen und sehr gut trocknen.
2. Öl im Wok stark erhitzen, Bohnen 6 bis 8 Minuten unter Wenden braten, bis die Haut runzlig und stellenweise gebräunt ist. ⏱ 7
3. Bohnen an den Rand schieben, Knoblauch und Chilis 30 Sekunden im Öl rösten. ⏱ 1
4. Sojasauce, Zucker und Salz zugeben, 1 Minute durchschwenken und servieren. ⏱ 1

## Notizen

Klassisch kommen noch eingelegtes Gemüse (Ya Cai) und Hack dazu; hier bewusst vegan gehalten.
