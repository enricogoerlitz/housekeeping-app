# Dan Dan Nudeln

![Dan Dan Nudeln](../../pictures/dan-dan-nudeln.jpg)

Sichuaner Straßenküche: Nudeln in einer Sauce aus Sesampaste, Chiliöl und Sojasauce, obenauf würziges Hack.

## Zutaten

| Menge  | Zutat          | Gruppe | Variante         | Hinweis                        | Einkauf |
| ------ | -------------- | ------ | ---------------- | ------------------------------ | ------- |
| 250 g  | Mie-Nudeln     |        |                  | frische oder getrocknete, dünn | Menge   |
| 150 g  | Schweinehack   |        | Mit Schweinehack |                                | Menge   |
| 150 g  | Shiitake       |        | Vegetarisch      | fein gewürfelt                 | Menge   |
| 2 EL   | Tahini         |        |                  | oder chinesische Sesampaste    |         |
| 2 EL   | Sojasauce      |        |                  |                                |         |
| 1 EL   | Chiliöl        |        |                  | mit Flocken                    |         |
| 1 TL   | Zucker         |        |                  |                                |         |
| 1 EL   | Reisessig      |        |                  |                                |         |
| 2      | Knoblauch      |        |                  | Zehen, gepresst                |         |
| 0,5 TL | Sichuanpfeffer |        |                  | gemahlen                       |         |
| 2 EL   | Erdnüsse       |        |                  | gehackt                        |         |
| 2      | Lauchzwiebel   |        |                  | in Ringen                      |         |
| 1 EL   | Sonnenblumenöl |        |                  |                                |         |
| 100 ml | Wasser         |        |                  |                                | nie     |

## Zubereitung

1. Für die Sauce Tahini, Sojasauce, Chiliöl, Zucker, Essig, Knoblauch, Sichuanpfeffer und das Nudelwasser (erst später) in zwei Schüsseln verteilen.
2. [Mit Schweinehack] Öl erhitzen, Hack bei hoher Hitze 5 Minuten krümelig und knusprig braten, mit 1 EL Sojasauce ablöschen. ⏱ 5
3. [Vegetarisch] Shiitake in Öl 6 Minuten kräftig braten, mit 1 EL Sojasauce ablöschen. ⏱ 6
4. Nudeln nach Packungsangabe in reichlich Wasser garen (frische ca. 3 Minuten). ⏱ 4
5. Je 3 EL Nudelwasser in die Saucenschüsseln rühren, Nudeln abtropfen und daraufgeben.
6. Hack beziehungsweise Pilze, Erdnüsse und Lauchzwiebeln obenauf geben, vor dem Essen alles gut vermengen.

## Notizen

Nudeln und Sauce erst am Tisch vermengen, dann bleibt alles heiß. Die Sauce ist ohnehin vegan.
