# Tomaten-Ei-Pfanne

![Tomaten-Ei-Pfanne](../../pictures/tomaten-ei-pfanne.jpg)

Xihongshi chao jidan, das chinesische Alltagsgericht Nummer eins: weiche Rühreier in saftiger, leicht süßer Tomatensauce.

## Zutaten

| Menge   | Zutat             | Gruppe | Variante     | Hinweis             | Einkauf |
| ------- | ----------------- | ------ | ------------ | ------------------- | ------- |
| 4       | Ei                |        |              |                     | Menge   |
| 4       | Tomate            |        |              | in Spalten          | Menge   |
| 150 g   | Garnelen          |        | Mit Garnelen | geschält, aufgetaut | Menge   |
| 1 TL    | Zucker            |        |              |                     |         |
| 1 EL    | Sojasauce         |        |              |                     |         |
| 1 TL    | Shaoxing-Reiswein |        |              |                     |         |
| 2       | Lauchzwiebel      |        |              | in Ringen           |         |
| 3 EL    | Sonnenblumenöl    |        |              |                     |         |
| 1 TL    | Sesamöl           |        |              |                     |         |
| 1 Prise | Salz              |        |              |                     |         |
| 250 g   | Jasminreis        |        |              | zum Servieren       | Menge   |

## Zubereitung

1. Eier mit Salz und Reiswein verquirlen. Reis nach Packungsangabe kochen. ⏱ 15
2. [Mit Garnelen] Garnelen in 1 EL Öl 2 Minuten braten, herausnehmen. ⏱ 2
3. 1 EL Öl im Wok stark erhitzen, Eier einlaufen lassen und 30 Sekunden stocken lassen, grob zerteilen und herausnehmen. ⏱ 1
4. Restliches Öl erhitzen, Tomaten 4 Minuten schmoren, bis sie zerfallen. Zucker und Sojasauce zugeben. ⏱ 4
5. Eier (und Garnelen) zurück in die Pfanne geben, 1 Minute vorsichtig durchschwenken. ⏱ 1
6. Mit Sesamöl und Lauchzwiebeln abschmecken, auf Reis servieren.

## Notizen

Reife Tomaten verwenden; mit Strauchtomaten klappt es gut. Wer es säuerlicher mag, lässt den Zucker weg.
