# Zhajiangmian – Pekinger Nudeln mit Bohnensauce

![Zhajiangmian – Pekinger Nudeln mit Bohnensauce](../../pictures/zhajiangmian.jpg)

Nordchinesisches Nudelgericht: dicke Nudeln mit dunkler, gehaltvoller Bohnensauce und knackigem Gemüse obenauf.

## Zutaten

| Menge   | Zutat             | Gruppe | Variante         | Hinweis          | Einkauf |
| ------- | ----------------- | ------ | ---------------- | ---------------- | ------- |
| 250 g   | Mie-Nudeln        |        |                  | breit oder Udon  | Menge   |
| 200 g   | Schweinehack      |        | Mit Schweinehack |                  | Menge   |
| 200 g   | Shiitake          |        | Vegetarisch      | fein gewürfelt   | Menge   |
| 3 EL    | Süße Bohnenpaste  |        |                  | oder Hoisinsauce | 1×      |
| 1 EL    | Sojasauce         |        |                  |                  |         |
| 1 EL    | Shaoxing-Reiswein |        |                  |                  |         |
| 1 TL    | Zucker            |        |                  |                  |         |
| 3       | Knoblauch         |        |                  | gehackt          |         |
| 1 Stück | Ingwer            |        |                  | gehackt          |         |
| 150 ml  | Wasser            |        |                  |                  | nie     |
| 0,5     | Salatgurke        |        |                  | in Stifte        |         |
| 1       | Karotte           |        |                  | in Stifte        |         |
| 2 EL    | Sonnenblumenöl    |        |                  |                  |         |

## Zubereitung

1. Öl im Topf erhitzen,
2. [Mit Schweinehack] Hack 5 Minuten braten, bis es Farbe hat. ⏱ 5
3. [Vegetarisch] Shiitake 6 Minuten braten, bis sie Röstaromen haben. ⏱ 6
4. Knoblauch und Ingwer 1 Minute mitbraten, Bohnenpaste zugeben und 2 Minuten rühren. ⏱ 3
5. Sojasauce, Reiswein, Zucker und Wasser zugeben und 10 Minuten leise einkochen, bis die Sauce dick ist. ⏱ 10
6. Nudeln nach Packungsangabe garen und abtropfen. ⏱ 8
7. Nudeln in Schalen geben, Sauce daraufgeben, mit Gurke und Karotte umlegen und vor dem Essen vermengen.

## Notizen

Süße Bohnenpaste (Tianmianjiang) im Asia-Laden; Hoisinsauce mit 1 TL Misopaste ist ein guter Ersatz. Salzgehalt der Paste variiert, vor dem Salzen probieren.
