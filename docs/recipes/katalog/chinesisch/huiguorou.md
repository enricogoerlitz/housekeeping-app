# Huiguorou – zweimal gegartes Schweinefleisch

![Huiguorou – zweimal gegartes Schweinefleisch](../../pictures/huiguorou.jpg)

Sichuan-Hausmannskost: Schweinebauch wird erst gegart, dann dünn geschnitten und mit Lauch, Paprika und Bohnenpaste scharf angebraten.

## Zutaten

| Menge      | Zutat             | Gruppe | Variante          | Hinweis                   | Einkauf |
| ---------- | ----------------- | ------ | ----------------- | ------------------------- | ------- |
| 300 g      | Schweinebauch     |        | Mit Schweinebauch | am Stück                  | Menge   |
| 300 g      | Räuchertofu       |        | Vegetarisch       | in dünne Scheiben         | Menge   |
| 1          | Lauch             |        |                   | schräg in Stücken         |         |
| 1          | Paprika           |        |                   | Spitzpaprika, in Streifen |         |
| 2 EL       | Doubanjiang       |        |                   |                           | 1×      |
| 1 EL       | Süße Bohnenpaste  |        |                   | oder Hoisinsauce          | 1×      |
| 3          | Knoblauch         |        |                   | in Scheiben               |         |
| 1 EL       | Sojasauce         |        |                   |                           |         |
| 1 EL       | Shaoxing-Reiswein |        |                   |                           |         |
| 2 Scheiben | Ingwer            |        |                   |                           |         |
| 2 EL       | Sonnenblumenöl    |        |                   |                           |         |
| 250 g      | Jasminreis        |        |                   | zum Servieren             | Menge   |

## Zubereitung

1. [Mit Schweinebauch] Fleisch mit Ingwer in Wasser 30 Minuten sanft köcheln, abkühlen lassen und in 3 mm dünne Scheiben schneiden. ⏱ 30
2. [Vegetarisch] Tofuscheiben in 1 EL Öl pro Seite 3 Minuten goldbraun braten, herausnehmen. ⏱ 6
3. [Mit Schweinebauch] Fleischscheiben im trockenen Wok bei mittlerer Hitze 5 Minuten braten, bis sich die Ränder einrollen und Fett austritt. ⏱ 5
4. Doubanjiang, süße Bohnenpaste und Knoblauch zugeben und 1 Minute rühren, bis es rot und duftend ist. ⏱ 1
5. Lauch und Paprika 3 Minuten mitbraten, Sojasauce und Reiswein zugeben. Tofu beziehungsweise Fleisch gut durchschwenken und mit Reis servieren. ⏱ 3

## Notizen

Der Schweinebauch lässt sich gut am Vortag vorkochen. Süße Bohnenpaste ersetzt Hoisinsauce.
