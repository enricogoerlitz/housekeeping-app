# Coleslaw

![Coleslaw](../../pictures/coleslaw.jpg)

Cremiger Krautsalat, die klassische Beilage zu BBQ und Burgern.

## Zutaten

| Menge | Zutat      | Gruppe | Variante | Hinweis       | Einkauf |
| ----- | ---------- | ------ | -------- | ------------- | ------- |
| 300 g | Weißkohl   |        |          | fein gehobelt | Menge   |
| 1     | Karotte    |        |          | geraspelt     |         |
| 3 EL  | Mayonnaise |        |          |               |         |
| 2 EL  | Joghurt    |        |          | natur         |         |
| 1 EL  | Apfelessig |        |          |               |         |
| 1 TL  | Zucker     |        |          |               |         |
| ½ TL  | Salz       |        |          |               |         |

## Zubereitung

1. Kohl in eine Schüssel geben, mit Salz und Zucker vermengen und 10 Minuten stehen lassen. ⏱ 10
2. Mayonnaise, Joghurt und Essig verrühren.
3. Karotte und Dressing zum Kohl geben, gut vermischen.
4. Mindestens 20 Minuten durchziehen lassen. ⏱ 20

## Notizen

Hält sich im Kühlschrank 2 Tage.
