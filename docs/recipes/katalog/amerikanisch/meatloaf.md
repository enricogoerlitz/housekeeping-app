# Meatloaf

![Meatloaf](../../pictures/meatloaf.jpg)

Saftiger Hackbraten im Kastenform-Format mit glänzender Ketchup-Glasur.

## Zutaten

| Menge | Zutat             | Gruppe | Variante     | Hinweis                           | Einkauf |
| ----- | ----------------- | ------ | ------------ | --------------------------------- | ------- |
| 400 g | Rinderhackfleisch |        | Mit Rindhack |                                   | Menge   |
| 100 g | Rote Linsen       |        | Vegetarisch  | 10 Minuten gekocht und abgetropft | Menge   |
| 1     | Zwiebel           |        |              | fein gewürfelt                    |         |
| 1     | Ei                |        |              |                                   |         |
| 4 EL  | Semmelbrösel      |        |              |                                   |         |
| 4 EL  | Milch             |        |              |                                   |         |
| 1 EL  | Worcestersauce    |        |              |                                   |         |
| 1 TL  | Salz              |        |              |                                   |         |
| 3 EL  | Ketchup           | Glasur |              |                                   |         |
| 1 EL  | Brauner Zucker    | Glasur |              |                                   |         |
| 1 TL  | Senf              | Glasur |              |                                   |         |

## Zubereitung

1. Backofen auf 180 °C Ober-/Unterhitze vorheizen, Kastenform fetten.
2. Semmelbrösel in Milch 5 Minuten quellen lassen. ⏱ 5
3. [Mit Rindhack] Hack mit Zwiebel, Ei, Bröseln, Worcestersauce und Salz kräftig verkneten.
4. [Vegetarisch] Linsen mit Zwiebel, Ei, Bröseln, Worcestersauce und Salz zerdrücken und gut vermengen.
5. Masse in die Form drücken und glattstreichen.
6. Glasurzutaten verrühren und die Hälfte auf dem Laib verstreichen.
7. [Mit Rindhack] 55 Minuten backen, nach 30 Minuten mit Rest-Glasur bestreichen. ⏱ 55
8. [Vegetarisch] 40 Minuten backen, nach 20 Minuten mit Rest-Glasur bestreichen. ⏱ 40
9. 10 Minuten ruhen lassen, in Scheiben schneiden. ⏱ 10

## Notizen

Dazu Kartoffelpüree und Bohnen. Vegetarisch: Rote Linsen vorab 10 Minuten kochen und abtropfen lassen. Worcestersauce enthält Fisch.
