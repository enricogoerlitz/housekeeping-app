# Mac and Cheese

![Mac and Cheese](../../pictures/mac-and-cheese.jpg)

Cremige Makkaroni in Cheddarsauce, im Ofen mit knuspriger Semmelbrösel-Kruste überbacken.

## Zutaten

| Menge  | Zutat           | Gruppe | Variante  | Hinweis               | Einkauf |
| ------ | --------------- | ------ | --------- | --------------------- | ------- |
| 250 g  | Makkaroni       |        |           |                       | Menge   |
| 30 g   | Butter          | Sauce  |           |                       |         |
| 30 g   | Mehl            | Sauce  |           | Type 405              |         |
| 500 ml | Milch           | Sauce  |           | Vollmilch             |         |
| 200 g  | Cheddar         | Sauce  |           | gerieben              | Menge   |
| ½ TL   | Senfpulver      | Sauce  |           |                       |         |

| 1 TL   | Salz            | Sauce  |           |                       |         |

| 2 l    | Wasser          |        |           | zum Kochen der Nudeln | nie     |

## Zubereitung

1. Backofen auf 200 °C Ober-/Unterhitze vorheizen.
2. [Mit Speck] Speck in einer Pfanne 5 Minuten knusprig braten, auf Küchenpapier abtropfen. ⏱ 5
3. Makkaroni in Salzwasser 2 Minuten kürzer als auf der Packung angegeben kochen, abgießen. ⏱ 6
4. Butter schmelzen, Mehl 1 Minute anschwitzen, Milch unter Rühren zugeben und 5 Minuten bei mittlerer Hitze eindicken. ⏱ 5
5. Topf vom Herd nehmen, Käse (etwas für oben zurücklassen), Senfpulver, Muskat und Salz einrühren.
6. Nudeln unterheben und in eine Auflaufform füllen.
7. [Mit Speck] Speck über die Nudeln streuen.
8. Mit Rest-Käse und den in Butter gewendeten Semmelbröseln bestreuen.
9. 15 Minuten backen, bis die Kruste goldbraun ist. ⏱ 15

## Notizen

Cheddar gibt die klassische Farbe; mit Gouda oder Emmentaler gemischt wird es milder.
