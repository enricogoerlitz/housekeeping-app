# Shrimp and Grits

![Shrimp and Grits](../../pictures/shrimp-and-grits.jpg)

Cremiger Maisgrieß mit würzig gebratenen Garnelen, ein Frühstücks- und Abendessen-Klassiker aus den Südstaaten.

## Zutaten

| Menge  | Zutat         | Gruppe | Variante     | Hinweis             | Einkauf |
| ------ | ------------- | ------ | ------------ | ------------------- | ------- |
| 120 g  | Polenta       |        |              | Instant-Maisgrieß   | Menge   |
| 500 ml | Milch         |        |              |                     |         |
| 300 ml | Wasser        |        |              |                     | nie     |
| 60 g   | Cheddar       |        |              | gerieben            |         |
| 20 g   | Butter        |        |              |                     |         |
| 200 g  | Garnelen      |        | Mit Garnelen | geschält, aufgetaut | Menge   |
| 250 g  | Champignons   |        | Vegetarisch  | geviertelt          | Menge   |
| 2      | Knoblauch     |        |              | Zehen               |         |
| ½ TL   | Paprikapulver |        |              | geräuchert          |         |
| 1 EL   | Olivenöl      |        |              |                     |         |
| 1      | Zitrone       |        |              | Saft                |         |
| 1 Bund | Schnittlauch  |        |              | in Röllchen         |         |
| 1 TL   | Salz          |        |              |                     |         |

## Zubereitung

1. Milch, Wasser und Salz aufkochen, Polenta einrieseln lassen und unter Rühren 5 Minuten bei kleiner Hitze quellen. ⏱ 5
2. Butter und Käse unterrühren, abdecken.
3. [Mit Garnelen] Garnelen in Öl 2 Minuten je Seite mit Knoblauch und Paprikapulver braten. ⏱ 4
4. [Vegetarisch] Champignons in Öl 7 Minuten kräftig braten, Knoblauch und Paprikapulver 1 Minute mitbraten. ⏱ 7
5. Mit Zitronensaft ablöschen und salzen.
6. Polenta in Schalen geben, Garnelen bzw. Pilze daraufsetzen, mit Schnittlauch bestreuen.

## Notizen

Echte Grits sind grober Maisgrieß und brauchen 45 Minuten Garzeit; Polenta ist ein guter Ersatz.
