# Brownies

![Brownies](../../pictures/brownies.jpg)

Dichte, schokoladige Brownies mit rissiger Oberfläche, innen weich.

## Zutaten

| Menge   | Zutat                | Gruppe | Variante | Hinweis      | Einkauf |
| ------- | -------------------- | ------ | -------- | ------------ | ------- |
| 150 g   | Zartbitterschokolade |        |          | gehackt      | Menge   |
| 120 g   | Butter               |        |          |              |         |
| 150 g   | Zucker               |        |          |              |         |
| 2       | Eier                 |        |          |              |         |
| 70 g    | Mehl                 |        |          | Type 405     |         |
| 1 EL    | Kakaopulver          |        |          |              |         |
| 1 Prise | Salz                 |        |          |              |         |
| 50 g    | Walnüsse             |        |          | grob gehackt |         |

## Zubereitung

1. Backofen auf 175 °C Ober-/Unterhitze vorheizen, eine kleine Form (20 × 20 cm) mit Backpapier auslegen.
2. Schokolade und Butter im Wasserbad schmelzen, 5 Minuten abkühlen lassen. ⏱ 5
3. Zucker und Eier 2 Minuten verrühren, die Schokomasse einrühren.
4. Mehl, Kakao und Salz mischen, kurz unterheben, Nüsse zugeben.
5. In die Form füllen und 22 Minuten backen; ein Zahnstocher soll noch feucht bleiben. ⏱ 22
6. Vollständig auskühlen lassen, dann schneiden.

## Notizen

Für glutenfreie Brownies Mehl durch Mandelmehl ersetzen.
