# Smash Burger

![Smash Burger](../../pictures/smash-burger.jpg)

Dünne, knusprig gebratene Patties mit viel Käse im getoasteten Brötchen.

## Zutaten

| Menge      | Zutat             | Gruppe | Variante        | Hinweis                       | Einkauf |
| ---------- | ----------------- | ------ | --------------- | ----------------------------- | ------- |
| 300 g      | Rinderhackfleisch |        | Mit Rindfleisch | 20 % Fett                     | Menge   |
| 2          | Gemüsepatty       |        | Vegetarisch     | Fertigpatty, z. B. aus Bohnen | Menge   |
| 2          | Burgerbrötchen    |        |                 | Brioche                       |         |
| 4 Scheiben | Cheddar           |        |                 |                               | Menge   |
| 1          | Rote Zwiebel      |        |                 | in dünnen Ringen              |         |
| 1          | Tomate            |        |                 | in Scheiben                   |         |
| 4          | Gewürzgurke       |        |                 | in Scheiben                   |         |
| 2 EL       | Mayonnaise        | Sauce  |                 |                               |         |
| 1 EL       | Ketchup           | Sauce  |                 |                               |         |
| 1 TL       | Senf              | Sauce  |                 |                               |         |
| 1 EL       | Butter            |        |                 |                               |         |
| 1 TL       | Salz              |        |                 |                               |         |

## Zubereitung

1. Mayonnaise, Ketchup und Senf zu einer Sauce verrühren.
2. [Mit Rindfleisch] Hack zu 4 lockeren Kugeln à 75 g formen, nicht fest drücken.
3. Brötchenhälften in Butter 1 Minute anrösten, beiseitelegen. ⏱ 1
4. [Mit Rindfleisch] Gusseiserne Pfanne sehr heiß werden lassen, Kugeln darauflegen und mit einem Pfannenwender 20 Sekunden fest flach drücken, salzen. 1,5 Minuten braten, wenden, Käse auflegen, 30 Sekunden schmelzen. ⏱ 2
5. [Vegetarisch] Patties laut Packung 8 Minuten braten, zuletzt den Käse auflegen und schmelzen. ⏱ 8
6. Brötchen mit Sauce, Salat-Zutaten, Patties und Gurken belegen, sofort essen.

## Notizen

Der Käse der Smash-Variante ist der Klebstoff: auf jedes Patty eine Scheibe. Vegetarische Patties nicht flachdrücken.
