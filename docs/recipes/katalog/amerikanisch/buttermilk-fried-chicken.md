# Buttermilk Fried Chicken

![Buttermilk Fried Chicken](../../pictures/buttermilk-fried-chicken.jpg)

Knusprig frittiertes Hähnchen aus dem Süden, saftig durch die Buttermilch-Marinade.

## Zutaten

| Menge  | Zutat            | Gruppe   | Variante     | Hinweis                      | Einkauf |
| ------ | ---------------- | -------- | ------------ | ---------------------------- | ------- |
| 500 g  | Hähnchenschenkel |          | Mit Hähnchen | mit Knochen                  | Menge   |
| 1      | Blumenkohl       |          | Vegetarisch  | in große Röschen (ca. 500 g) | Menge   |
| 300 ml | Buttermilch      |          |              |                              | Menge   |
| 1 TL   | Salz             | Marinade |              |                              |         |
| 1 TL   | Paprikapulver    | Panade   |              | edelsüß                      |         |
| 1 TL   | Knoblauchpulver  | Panade   |              |                              |         |
| ½ TL   | Cayennepfeffer   | Panade   |              |                              |         |
| 150 g  | Mehl             | Panade   |              | Type 405                     |         |
| 500 ml | Sonnenblumenöl   |          |              |                              |         |
| 2 EL   | Honig            |          |              | zum Servieren                |         |

## Zubereitung

1. Hähnchen bzw. Blumenkohl mit Buttermilch und Salz mindestens 4 Stunden, am besten über Nacht, einlegen. ⏱ 240
2. Mehl mit Gewürzen mischen. Stücke leicht abtropfen lassen und gründlich in der Mehlmischung wenden, fest andrücken.
3. Öl in einem breiten Topf auf 170 °C erhitzen.
4. [Mit Hähnchen] Stücke portionsweise 14 bis 16 Minuten goldbraun frittieren, Kerntemperatur 75 °C. ⏱ 15
5. [Vegetarisch] Röschen portionsweise 6 bis 8 Minuten goldbraun frittieren. ⏱ 7
6. Auf einem Gitter abtropfen lassen und mit Honig beträufeln.

## Notizen

Buttermilch gibt es im Kühlregal; Ersatz: Milch mit 1 EL Zitronensaft. Vorsicht beim Frittieren, Spritzgefahr.
