# Cornbread

![Cornbread](../../pictures/cornbread.jpg)

Saftiges Maisbrot mit knuspriger Kruste, ideal zu Chili und Pulled Pork.

## Zutaten

| Menge  | Zutat       | Gruppe | Variante | Hinweis     | Einkauf |
| ------ | ----------- | ------ | -------- | ----------- | ------- |
| 150 g  | Maismehl    |        |          | fein        |         |
| 100 g  | Mehl        |        |          | Type 405    |         |
| 1 EL   | Backpulver  |        |          |             |         |
| 1 EL   | Zucker      |        |          |             |         |
| ½ TL   | Salz        |        |          |             |         |
| 250 ml | Buttermilch |        |          |             |         |
| 1      | Ei          |        |          |             |         |
| 50 g   | Butter      |        |          | geschmolzen |         |

## Zubereitung

1. Backofen auf 200 °C Ober-/Unterhitze vorheizen, eine kleine Pfanne oder Form (20 cm) fetten.
2. Trockene Zutaten in einer Schüssel mischen.
3. Buttermilch, Ei und geschmolzene Butter verquirlen und kurz unterrühren, nicht zu lange.
4. Teig in die Form geben und 20 Minuten backen. ⏱ 20
5. 5 Minuten ruhen lassen, in Stücke schneiden. ⏱ 5

## Notizen

Maismehl (nicht Maisstärke) gibt es im Supermarkt; Polenta fein gemahlen tut es auch.
