# Baked Beans

![Baked Beans](../../pictures/baked-beans.jpg)

Weiße Bohnen in süßlich-rauchiger Tomatensauce, im Ofen geschmort.

## Zutaten

| Menge   | Zutat             | Gruppe | Variante | Hinweis               | Einkauf |
| ------- | ----------------- | ------ | -------- | --------------------- | ------- |
| 2 Dosen | Weiße Bohnen      |        |          | abgetropft (je 240 g) | Menge   |
| 1       | Zwiebel           |        |          | gewürfelt             |         |
| 2       | Knoblauch         |        |          | Zehen                 |         |
| 200 g   | Passierte Tomaten |        |          |                       |         |
| 2 EL    | Tomatenmark       |        |          |                       |         |
| 2 EL    | Ahornsirup        |        |          |                       |         |
| 1 EL    | Apfelessig        |        |          |                       |         |
| 1 TL    | Paprikapulver     |        |          | geräuchert            |         |
| 1 EL    | Pflanzenöl        |        |          |                       |         |
| ½ TL    | Salz              |        |          |                       |         |

## Zubereitung

1. Backofen auf 180 °C Ober-/Unterhitze vorheizen.
2. Zwiebel in Öl 4 Minuten dünsten, Knoblauch 1 Minute mitbraten. ⏱ 5
3. Passierte Tomaten, Tomatenmark, Sirup, Essig, Paprikapulver und Salz zugeben und 5 Minuten köcheln. ⏱ 5
4. Bohnen unterheben, in eine Auflaufform geben.
5. 25 Minuten ohne Deckel backen, bis die Sauce dick eingekocht ist. ⏱ 25

## Notizen

Ahornsirup ersetzt Melasse; Honig oder Zucker gehen auch.
