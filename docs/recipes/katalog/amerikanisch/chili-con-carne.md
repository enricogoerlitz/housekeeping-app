# Chili con Carne

![Chili con Carne](../../pictures/chili-con-carne.jpg)

Kräftig würziger Bohnen-Eintopf, der auch am zweiten Tag noch besser schmeckt.

## Zutaten

| ------ | ----------------- | ------ | ------------ | ----------------------- | ------- |

| 200 g  | Champignons       |        | Vegetarisch  | fein gewürfelt          | Menge   |
| 1      | Zwiebel           |        |              | gewürfelt               |         |
| 2      | Knoblauch         |        |              | Zehen                   |         |
| 1      | Paprika           |        |              | rot, gewürfelt          |         |

## Zubereitung

1. Zwiebel in Öl 4 Minuten anbraten. ⏱ 4
2. [Mit Rindhack] Hack zugeben und 7 Minuten krümelig und kräftig anbraten. ⏱ 7
3. [Vegetarisch] Champignons zugeben und 8 Minuten braten, bis sie Farbe nehmen. ⏱ 8
4. Knoblauch, Paprika, Tomatenmark und Gewürze 2 Minuten mitrösten. ⏱ 2
5. Tomaten, Brühe, Bohnen und Mais zugeben, aufkochen und 35 Minuten zugedeckt bei kleiner Hitze köcheln. ⏱ 35
6. Mit Salz und Chili abschmecken, mit saurer Sahne und Käse servieren.

## Notizen

Dazu passen Reis oder Cornbread. Für mehr Tiefe 1 Stück Zartbitterschokolade mitkochen.
