# Pierogi Ruskie

![Pierogi Ruskie](../../pictures/pierogi-ruskie.jpg)

Polnische Teigtaschen mit Kartoffel-Quark-Füllung und Röstzwiebeln. Mit Speck wird es deftiger.

## Zutaten

| Menge   | Zutat           | Gruppe  | Variante  | Hinweis                | Einkauf |
| ------- | --------------- | ------- | --------- | ---------------------- | ------- |
| 250 g   | Mehl            | Teig    |           |                        |         |
| 120 ml  | Wasser          | Teig    |           | heiß                   | nie     |
| 1 EL    | Sonnenblumenöl  | Teig    |           |                        |         |
| 1 Prise | Salz            | Teig    |           |                        |         |
| 250 g   | Kartoffel       | Füllung |           | mehligkochend, gekocht |         |
| 100 g   | Quark           | Füllung |           |                        |         |
| 1       | Zwiebel         | Füllung |           | gebraten               |         |
| 50 g    | Frühstücksspeck |         | Mit Speck | gewürfelt              | Menge   |
| 2 EL    | Butter          |         |           |                        |         |
| 4 EL    | Saure Sahne     |         |           |                        |         |
|         | Salz            |         |           |                        |         |
|         | Pfeffer         |         |           |                        |         |

## Zubereitung

1. Für den Teig Mehl, Wasser, Öl und Salz zu einem glatten Teig kneten, abgedeckt 30 Minuten ruhen lassen. ⏱ 30
2. Kartoffeln stampfen, mit Quark, Salz, Pfeffer und Hälfte der Zwiebeln (in Butter gebraten) mischen.
3. Teig dünn ausrollen, Kreise (8 cm) ausstechen, je 1 TL Füllung darauf setzen und zusammendrücken.
4. In siedendem Salzwasser 4 Minuten garen, bis sie schwimmen. ⏱ 4
5. Restliche Zwiebel in Butter goldbraun braten.
6. [Mit Speck] Speck mitbraten.
7. Pierogi in der Zwiebelbutter schwenken und mit Saurer Sahne servieren.

## Notizen

Reste schmecken angebraten.
