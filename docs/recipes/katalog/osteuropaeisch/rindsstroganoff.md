# Boeuf Stroganoff

![Boeuf Stroganoff](../../pictures/rindsstroganoff.jpg)

Rinderstreifen in Pilz-Sahne-Sauce mit Gewürzgurken. Vegetarisch mit Champignons und Räuchertofu.

## Zutaten

| Menge  | Zutat          | Gruppe | Variante    | Hinweis                                   | Einkauf |
| ------ | -------------- | ------ | ----------- | ----------------------------------------- | ------- |
| 300 g  | Rinderfilet    |        | Mit Rind    | in dünnen Streifen, ersatzweise Rumpsteak | Menge   |
| 250 g  | Räuchertofu    |        | Vegetarisch | in Streifen                               | Menge   |
| 250 g  | Champignons    |        |             | in Scheiben                               |         |
| 1      | Zwiebel        |        |             | in feinen Streifen                        |         |
| 2      | Gewürzgurke    |        |             | in Streifen                               |         |
| 1 EL   | Tomatenmark    |        |             |                                           |         |
| 1 EL   | Senf           |        |             | mittelscharf                              |         |
| 150 ml | Brühe          |        |             |                                           |         |
| 150 g  | Saure Sahne    |        |             |                                           |         |
| 1 EL   | Butter         |        |             |                                           |         |
| 1 EL   | Sonnenblumenöl |        |             |                                           |         |
| 500 g  | Kartoffelpüree |        |             | oder Kartoffeln zum Stampfen              | Menge   |
|        | Salz           |        |             |                                           |         |
|        | Pfeffer        |        |             |                                           |         |

## Zubereitung

1. [Mit Rind] Rindfleisch in Öl sehr heiß 2 Minuten anbraten, herausnehmen. ⏱ 2
2. [Vegetarisch] Räuchertofu in Öl 4 Minuten knusprig braten, herausnehmen. ⏱ 4
3. Zwiebel in Butter 4 Minuten braten, Champignons 5 Minuten mitbraten. ⏱ 5
4. Tomatenmark und Senf einrühren, mit Brühe ablöschen und 3 Minuten einkochen.
5. Saure Sahne und Gurken zugeben, Fleisch bzw. Tofu zurückgeben und 2 Minuten erwärmen (nicht mehr kochen). ⏱ 2
6. Mit Kartoffelpüree servieren.

## Notizen

Ersatz Saure Sahne: Crème fraîche.
