# Badrijani Nigvzit

![Badrijani Nigvzit](../../pictures/badrijani-nigvzit.jpg)

Gebratene Auberginenröllchen mit Walnuss-Knoblauch-Paste und Granatapfel.

## Zutaten

| Menge | Zutat          | Gruppe | Variante | Hinweis            | Einkauf |
| ----- | -------------- | ------ | -------- | ------------------ | ------- |
| 2     | Aubergine      |        |          | in dünnen Scheiben |         |
| 100 g | Walnüsse       |        |          |                    |         |
| 2     | Knoblauch      |        |          | Zehen              |         |
| 1 TL  | Koriander      |        |          | gemahlen           |         |
| 1 EL  | Essig          |        |          |                    |         |
| 4 EL  | Sonnenblumenöl |        |          |                    |         |
| 3 EL  | Granatapfel    |        |          | Kerne              |         |
| 50 ml | Wasser         |        |          |                    | nie     |
|       | Salz           |        |          |                    |         |

## Zubereitung

1. Auberginenscheiben salzen, 10 Minuten ziehen lassen, abtupfen. ⏱ 10
2. In Öl portionsweise 3 Minuten je Seite goldbraun braten. ⏱ 6
3. Walnüsse, Knoblauch, Koriander, Essig, Salz und Wasser pürieren.
4. Paste auf die Scheiben streichen, aufrollen, mit Granatapfel bestreuen.

## Notizen

Kalt servieren.
