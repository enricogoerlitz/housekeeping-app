# Draniki

![Draniki](../../pictures/draniki.jpg)

Knusprige Kartoffelpuffer mit Saurer Sahne und Dill.

## Zutaten

| Menge | Zutat          | Gruppe | Variante | Hinweis       | Einkauf |
| ----- | -------------- | ------ | -------- | ------------- | ------- |
| 500 g | Kartoffel      |        |          | mehligkochend | Menge   |
| 1     | Zwiebel        |        |          | fein gerieben |         |
| 1     | Ei             |        |          |               |         |
| 2 EL  | Mehl           |        |          |               |         |
| 4 EL  | Sonnenblumenöl |        |          |               |         |
| 4 EL  | Saure Sahne    |        |          |               |         |
| 1 EL  | Dill           |        |          |               |         |
|       | Salz           |        |          |               |         |

## Zubereitung

1. Kartoffeln fein reiben, kräftig ausdrücken.
2. Mit Zwiebel, Ei, Mehl und Salz mischen.
3. Öl erhitzen, Löffelweise Masse flach drücken, 4 Minuten je Seite braten. ⏱ 8
4. Auf Küchenpapier abtropfen, mit Saurer Sahne und Dill servieren.

## Notizen

Sofort servieren.
