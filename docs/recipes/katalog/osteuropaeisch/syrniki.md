# Syrniki

![Syrniki](../../pictures/syrniki.jpg)

Russische Quarkpfannkuchen mit Marmelade und Sahne.

## Zutaten

| Menge | Zutat         | Gruppe | Variante | Hinweis | Einkauf |
| ----- | ------------- | ------ | -------- | ------- | ------- |
| 250 g | Quark         |        |          | trocken |         |
| 1     | Ei            |        |          |         |         |
| 3 EL  | Mehl          |        |          |         |         |
| 2 EL  | Zucker        |        |          |         |         |
| 1 Pck | Vanillezucker |        |          |         |         |
| 2 EL  | Butter        |        |          |         |         |
| 2 EL  | Marmelade     |        |          |         |         |
| 2 EL  | Saure Sahne   |        |          |         |         |

## Zubereitung

1. Quark, Ei, Zucker, Vanille und 3 EL Mehl zu einem festen Teig verrühren.
2. Mit bemehlten Händen 6 flache Küchlein formen.
3. In Butter 3 Minuten je Seite goldbraun braten. ⏱ 6
4. Mit Marmelade und Saurer Sahne servieren.

## Notizen

Quark gut abtropfen lassen.
