# Adscharuli Chatschapuri

![Adscharuli Chatschapuri](../../pictures/chatschapuri.jpg)

Georgisches Käsebrot in Bootsform mit Ei und Butter.

## Zutaten

| Menge  | Zutat          | Gruppe  | Variante | Hinweis         | Einkauf |
| ------ | -------------- | ------- | -------- | --------------- | ------- |
| 300 g  | Mehl           | Teig    |          |                 |         |
| 150 ml | Milch          | Teig    |          | lauwarm         |         |
| 0.5    | Hefe           | Teig    |          | Würfel (21 g)   |         |
| 1 TL   | Zucker         | Teig    |          |                 |         |
| 1 TL   | Salz           | Teig    |          |                 |         |
| 2 EL   | Sonnenblumenöl | Teig    |          |                 |         |
| 150 g  | Mozzarella     | Füllung |          | gerieben        |         |
| 150 g  | Feta           | Füllung |          | zerbröselt      |         |
| 2      | Ei             |         |          | zum Aufschlagen |         |
| 2 EL   | Butter         |         |          |                 |         |

## Zubereitung

1. Hefe in Milch mit Zucker auflösen, mit Mehl, Salz und Öl 8 Minuten kneten. ⏱ 8
2. Abgedeckt 1 Stunde gehen lassen. ⏱ 60
3. Teig teilen, jeweils oval ausrollen, Ränder zu Rollen einschlagen (Bootsform).
4. Käse mischen und einfüllen.
5. Bei 230 °C 15 Minuten backen. ⏱ 15
6. In die Mitte ein Ei geben, 4 Minuten weiterbacken, Butter zugeben. ⏱ 4

## Notizen

Zum Eintauchen: Brotkruste in Eigelb und Käse.
