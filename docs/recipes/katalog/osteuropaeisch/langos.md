# Lángos

![Lángos](../../pictures/langos.jpg)

Ungarisches Frittierbrot mit Saurer Sahne, Käse und Knoblauch.

## Zutaten

| Menge  | Zutat          | Gruppe | Variante | Hinweis            | Einkauf |
| ------ | -------------- | ------ | -------- | ------------------ | ------- |
| 250 g  | Mehl           |        |          |                    |         |
| 0.5    | Hefe           |        |          | Würfel (21 g)      |         |
| 100 g  | Kartoffel      |        |          | gekocht, gestampft |         |
| 100 ml | Wasser         |        |          | lauwarm            | nie     |
| 1 TL   | Salz           |        |          |                    |         |
| 500 ml | Sonnenblumenöl |        |          |                    |         |
| 4 EL   | Saure Sahne    |        |          |                    |         |
| 50 g   | Gouda          |        |          | gerieben           |         |
| 1      | Knoblauch      |        |          | Zehe               |         |

## Zubereitung

1. Hefe in Wasser lösen, mit Mehl, Kartoffel und Salz zu einem Teig kneten (8 Minuten). ⏱ 8
2. 1 Stunde gehen lassen. ⏱ 60
3. Teig in 2 Stücke teilen, flach ziehen.
4. In 175 °C heißem Öl 2 Minuten je Seite frittieren. ⏱ 4
5. Mit Knoblauch einreiben, mit Sahne und Käse belegen.

## Notizen

Süß mit Zucker und Quark möglich.
