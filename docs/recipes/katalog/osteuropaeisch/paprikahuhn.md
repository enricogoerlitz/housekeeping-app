# Paprikahuhn

![Paprikahuhn](../../pictures/paprikahuhn.jpg)

Ungarisches Paprikahuhn (Csirke paprikás) in cremiger Paprika-Sahne-Sauce, mit Nockerln. Vegetarisch mit Champignons und Kichererbsen.

## Zutaten

| Menge  | Zutat            | Gruppe | Variante     | Hinweis                          | Einkauf |
| ------ | ---------------- | ------ | ------------ | -------------------------------- | ------- |
| 500 g  | Hähnchenschenkel |        | Mit Hähnchen |                                  | Menge   |
| 300 g  | Champignons      |        | Vegetarisch  | halbiert                         | Menge   |
| 1 Dose | Kichererbsen     |        | Vegetarisch  | 400 g, abgetropft                |         |
| 2      | Zwiebel          |        |              | in Würfeln                       |         |
| 2 EL   | Schweineschmalz  |        |              | oder Öl                          |         |
| 2 EL   | Paprikapulver    |        |              | edelsüß                          |         |
| 1      | Paprika          |        |              | gelb, in Streifen                |         |
| 1      | Tomate           |        |              | gewürfelt                        |         |
| 200 ml | Brühe            |        |              | Gemüse- oder Hühnerbrühe         |         |
| 150 g  | Saure Sahne      |        |              |                                  |         |
| 1 EL   | Mehl             |        |              |                                  |         |
| 250 g  | Spätzle          |        |              | als Beilage, ersatzweise Nockerl | Menge   |
|        | Salz             |        |              |                                  |         |

## Zubereitung

1. Zwiebeln in Schmalz 8 Minuten sanft goldgelb dünsten. ⏱ 8
2. Vom Herd nehmen, Paprikapulver unterrühren (verbrennt sonst bitter).
3. [Mit Hähnchen] Schenkel salzen, zugeben, 5 Minuten anbraten, Paprika, Tomate, Brühe zugeben und zugedeckt 35 Minuten schmoren. ⏱ 35
4. [Vegetarisch] Pilze, Kichererbsen, Paprika, Tomate, Brühe zugeben und 20 Minuten schmoren. ⏱ 20
5. Saure Sahne mit Mehl glatt rühren, 5 Minuten einrühren und aufkochen. ⏱ 5
6. Mit Spätzle servieren.

## Notizen

Spätzle aus dem Kühlregal.
