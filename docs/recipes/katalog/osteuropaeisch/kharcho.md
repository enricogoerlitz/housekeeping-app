# Charscho-Suppe

![Charscho-Suppe](../../pictures/kharcho.jpg)

Georgische Rindfleischsuppe mit Reis, Walnüssen und Koriander. Vegetarisch mit Kidneybohnen.

## Zutaten

| Menge  | Zutat           | Gruppe | Variante        | Hinweis       | Einkauf |
| ------ | --------------- | ------ | --------------- | ------------- | ------- |
| 300 g  | Rindfleisch     |        | Mit Rindfleisch | Suppenfleisch | Menge   |
| 1 Dose | Kidneybohnen    |        | Vegetarisch     | 400 g         |         |
| 1      | Zwiebel         |        |                 | gewürfelt     |         |
| 3      | Knoblauch       |        |                 | Zehen         |         |
| 60 g   | Walnüsse        |        |                 | gemahlen      |         |
| 50 g   | Reis            |        |                 |               |         |
| 3 EL   | Tomatenmark     |        |                 |               |         |
| 1 TL   | Korianderpulver |        |                 |               |         |
| 1 TL   | Bockshornklee   |        |                 | gemahlen      |         |
| 2 EL   | Koriander       |        |                 | frisch        |         |
| 2 EL   | Sonnenblumenöl  |        |                 |               |         |
| 1.2 l  | Wasser          |        |                 |               | nie     |
|        | Salz            |        |                 |               |         |

## Zubereitung

1. [Mit Rindfleisch] Fleisch in 1,2 l Wasser aufkochen, abschäumen, 60 Minuten köcheln. ⏱ 60
2. [Vegetarisch] 1,2 l Wasser aufkochen, Salz zugeben.
3. Zwiebel in Öl 5 Minuten anbraten, Tomatenmark, Gewürze 1 Minute mitrösten.
4. In die Brühe geben, Reis zugeben, 15 Minuten kochen. ⏱ 15
5. Walnüsse und Knoblauch zugeben.
6. [Vegetarisch] Bohnen zugeben.
7. 5 Minuten köcheln, mit Koriander servieren. ⏱ 5

## Notizen

Bockshornklee im Gewürzhandel; sonst weglassen.
