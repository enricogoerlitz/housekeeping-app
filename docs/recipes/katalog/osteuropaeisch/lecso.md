# Lecsó mit Wurst

![Lecsó mit Wurst](../../pictures/lecso.jpg)

Ungarisches Paprika-Tomaten-Gemüse, mit Wurst oder Ei.

## Zutaten

| Menge | Zutat           | Gruppe | Variante    | Hinweis                                 | Einkauf |
| ----- | --------------- | ------ | ----------- | --------------------------------------- | ------- |
| 4     | Paprika         |        |             | gemischt, in Streifen                   |         |
| 4     | Tomate          |        |             | gewürfelt                               |         |
| 2     | Zwiebel         |        |             | in Streifen                             |         |
| 150 g | Räucherwurst    |        | Mit Wurst   | Kielbasa, oder Debrecziner, in Scheiben | Menge   |
| 3     | Ei              |        | Vegetarisch |                                         | Menge   |
| 2 EL  | Schweineschmalz |        |             | oder Öl                                 |         |
| 1 EL  | Paprikapulver   |        |             | edelsüß                                 |         |
| 1 TL  | Zucker          |        |             |                                         |         |
|       | Salz            |        |             |                                         |         |
|       | Pfeffer         |        |             |                                         |         |

## Zubereitung

1. Zwiebeln in Schmalz 5 Minuten dünsten, Paprikapulver unterrühren. ⏱ 5
2. [Mit Wurst] Wurstscheiben 3 Minuten mitbraten. ⏱ 3
3. Paprika zugeben, 5 Minuten braten. ⏱ 5
4. Tomaten, Zucker, Salz, Pfeffer zugeben, zugedeckt 15 Minuten garen. ⏱ 15
5. [Vegetarisch] Eier in die Sauce aufschlagen und 4 Minuten stocken lassen. ⏱ 4

## Notizen

Mit Brot.
