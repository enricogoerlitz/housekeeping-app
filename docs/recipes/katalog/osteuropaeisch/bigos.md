# Bigos

![Bigos](../../pictures/bigos.jpg)

Polnischer Jägertopf aus Sauer- und Weißkraut mit Wurst und Pilzen.

## Zutaten

| Menge  | Zutat                   | Gruppe | Variante    | Hinweis               | Einkauf |
| ------ | ----------------------- | ------ | ----------- | --------------------- | ------- |
| 400 g  | Sauerkraut              |        |             |                       |         |
| 0.25   | Weißkohl                |        |             | in Streifen           |         |
| 200 g  | Räucherwurst            |        | Mit Fleisch | Kielbasa, in Scheiben | Menge   |
| 200 g  | Schweinenacken          |        | Mit Fleisch | in Würfeln            | Menge   |
| 30 g   | Steinpilze (getrocknet) |        | Vegetarisch |                       |         |
| 150 g  | Champignons             |        | Vegetarisch | geviertelt            |         |
| 1      | Zwiebel                 |        |             | gewürfelt             |         |
| 2 EL   | Tomatenmark             |        |             |                       |         |
| 3      | Backpflaumen            |        |             |                       |         |
| 2      | Lorbeerblatt            |        |             |                       |         |
| 3      | Wacholderbeeren         |        |             |                       |         |
| 2 EL   | Sonnenblumenöl          |        |             |                       |         |
| 300 ml | Wasser                  |        |             |                       | nie     |
|        | Salz                    |        |             |                       |         |
|        | Pfeffer                 |        |             |                       |         |

## Zubereitung

1. [Vegetarisch] Steinpilze in 200 ml heißem Wasser 20 Minuten einweichen, Pilzwasser aufheben. ⏱ 20
2. [Mit Fleisch] Schweinenacken in Öl 8 Minuten anbraten, Zwiebel zugeben. ⏱ 8
3. [Vegetarisch] Zwiebel und Champignons in Öl 8 Minuten anbraten. ⏱ 8
4. Sauerkraut, Weißkohl, Tomatenmark, Lorbeer, Wacholder, Pflaumen und 300 ml Wasser (vegetarisch Pilzwasser) zugeben.
5. Zugedeckt 75 Minuten bei kleiner Hitze schmoren. ⏱ 75
6. [Mit Fleisch] Wurst zugeben, 15 Minuten mitkochen. ⏱ 15
7. [Vegetarisch] Eingeweichte Pilze zugeben.
8. Mit Salz, Pfeffer abschmecken, kann noch durchziehen.

## Notizen

Wird nach einem Tag besser; mehrfach aufwärmen.
