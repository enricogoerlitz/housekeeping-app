# Steak Frites mit Café-de-Paris-Butter

![Steak Frites mit Café-de-Paris-Butter](../../pictures/steak-frites.jpg)

Bistro-Klassiker mit Kräuterbutter. Vegetarisch mit gebratenen Portobello-Pilzen.

## Zutaten

| Menge | Zutat      | Gruppe        | Variante    | Hinweis                      | Einkauf |
| ----- | ---------- | ------------- | ----------- | ---------------------------- | ------- |
| 2     | Rumpsteak  |               | Mit Steak   | je ca. 200 g                 | Menge   |
| 4     | Portobello |               | Vegetarisch |                              | Menge   |
| 600 g | Kartoffel  | Frites        |             | festkochend, in dünne Stifte | Menge   |
| 3 EL  | Rapsöl     | Frites        |             |                              |         |
| 60 g  | Butter     | Kräuterbutter |             | weich                        |         |
| 1     | Schalotte  | Kräuterbutter |             | fein gehackt                 |         |
| 1     | Petersilie | Kräuterbutter |             | Bund, fein gehackt           |         |
| 1 TL  | Senf       | Kräuterbutter |             | Dijon                        |         |
| 1 TL  | Zitronen   | Kräuterbutter |             | Saft                         |         |
| 1 TL  | Salz       |               |             |                              |         |
| 1 TL  | Pfeffer    |               |             |                              |         |

## Zubereitung

1. Backofen auf 220 °C Umluft vorheizen. Kartoffelstifte abspülen, trocken tupfen, mit Rapsöl und Salz mischen.
2. Auf einem Blech 25 bis 30 Minuten backen, einmal wenden. ⏱ 28
3. Für die Butter alle Zutaten verrühren, zur Rolle formen und kalt stellen. ⏱ 10
4. [Mit Steak] Steaks 1 Stunde vor dem Braten aus dem Kühlschrank nehmen, salzen und in sehr heißer Pfanne 2 bis 3 Minuten pro Seite braten, 5 Minuten ruhen lassen. ⏱ 3
5. [Vegetarisch] Portobello in heißer Pfanne mit Öl 4 Minuten pro Seite braten, salzen. ⏱ 4
6. Mit Frites und Scheiben der Kräuterbutter servieren.

## Notizen

Dicke Steaks erst scharf anbraten, dann bei 120 °C im Ofen auf Kerntemperatur 54 °C bringen.
