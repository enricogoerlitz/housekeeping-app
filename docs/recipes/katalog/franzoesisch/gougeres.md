# Gougères

![Gougères](../../pictures/gougeres.jpg)

Luftige Brandteig-Käsebällchen aus Burgund, ideal zu einem Glas Wein.

## Zutaten

| Menge   | Zutat      | Gruppe | Variante | Hinweis  | Einkauf |
| ------- | ---------- | ------ | -------- | -------- | ------- |
| 100 ml  | Wasser     |        |          |          | nie     |
| 40 g    | Butter     |        |          |          |         |
| 60 g    | Weizenmehl |        |          |          |         |
| 2       | Ei         |        |          |          |         |
| 80 g    | Gruyère    |        |          | gerieben | Menge   |
| 1 Prise | Muskat     |        |          |          |         |
| 1 Prise | Salz       |        |          |          |         |

## Zubereitung

1. Ofen auf 200 °C Ober-/Unterhitze vorheizen. Wasser, Butter und Salz aufkochen.
2. Mehl auf einmal einrühren und 1 Minute unter Rühren abbrennen, bis sich ein Kloß vom Topfboden löst. ⏱ 1
3. Teig 3 Minuten abkühlen lassen, Eier einzeln kräftig einarbeiten.
4. Käse und Muskat unterheben. Mit zwei Löffeln walnussgroße Häufchen auf ein Blech setzen.
5. 20 bis 25 Minuten backen, Ofen währenddessen nicht öffnen. ⏱ 22

## Notizen

Frisch am besten, lassen sich aber kurz im Ofen auffrischen.
