# Blanquette de Veau

![Blanquette de Veau](../../pictures/blanquette-de-veau.jpg)

Helles Ragout in samtiger Sahnesauce mit Zitrone. Vegetarisch mit Champignons und Kohlrabi.

## Zutaten

| Menge  | Zutat        | Gruppe | Variante    | Hinweis               | Einkauf |
| ------ | ------------ | ------ | ----------- | --------------------- | ------- |
| 500 g  | Kalbsgulasch |        | Mit Kalb    |                       | Menge   |
| 300 g  | Kohlrabi     |        | Vegetarisch | gewürfelt             | Menge   |
| 300 g  | Champignon   |        |             |                       | Menge   |
| 1      | Karotte      |        |             | in Scheiben           |         |
| 1      | Zwiebel      |        |             | mit 2 Nelken gespickt |         |
| 600 ml | Gemüsebrühe  |        |             |                       |         |
| 1      | Lorbeerblatt |        |             |                       |         |
| 30 g   | Butter       |        |             |                       |         |
| 30 g   | Mehl         |        |             |                       |         |
| 100 ml | Sahne        |        |             |                       |         |
| 1      | Eier         |        |             |                       |         |
| 1      | Zitrone      |        |             | Saft                  |         |
| 200 g  | Basmatireis  |        |             | zum Servieren         | Menge   |
| 1 TL   | Salz         |        |             |                       |         |

## Zubereitung

1. [Mit Kalb] Fleisch mit Brühe, Zwiebel, Lorbeer, Karotte und Salz aufkochen, Schaum abschöpfen, 75 Minuten sanft köcheln. ⏱ 75
2. [Vegetarisch] Kohlrabi, Karotte, Zwiebel, Lorbeer, Brühe und Salz 20 Minuten köcheln. ⏱ 20
3. Champignons in einer Pfanne mit etwas Butter 5 Minuten anbraten und zugeben, 10 Minuten mitgaren. ⏱ 10
4. Fleisch bzw. Gemüse herausnehmen, Brühe durchsieben und 500 ml abmessen.
5. Restliche Butter schmelzen, Mehl 1 Minute anschwitzen, mit der Brühe aufgießen und 8 Minuten köcheln. ⏱ 8
6. Sahne mit Eigelb verquirlen, mit etwas heißer Sauce temperieren, unterrühren (nicht mehr kochen) und mit Zitronensaft abschmecken.
7. Fleisch bzw. Gemüse in die Sauce geben, kurz erwärmen und mit Reis servieren. Reis nach Packungsangabe garen. ⏱ 12

## Notizen

Statt Kalb funktioniert Schweineschulter, die Garzeit bleibt gleich.
