# Poulet à la Normande

![Poulet à la Normande](../../pictures/poulet-a-la-normande.jpg)

Hähnchen in Apfel-Sahnesauce wie in der Normandie. Vegetarisch mit Blumenkohl-Steaks.

## Zutaten

| Menge  | Zutat         | Gruppe | Variante     | Hinweis                    | Einkauf |
| ------ | ------------- | ------ | ------------ | -------------------------- | ------- |
| 4      | Hähnchenkeule |        | Mit Hähnchen |                            | Menge   |
| 1      | Blumenkohl    |        | Vegetarisch  | in dicke Scheiben          | Menge   |
| 2      | Apfel         |        |              | säuerlich, in Spalten      |         |
| 2      | Schalotte     |        |              | fein gewürfelt             |         |
| 2 EL   | Butter        |        |              |                            |         |
| 100 ml | Apfelsaft     |        |              | naturtrüb (statt Calvados) |         |
| 100 ml | Weißwein      |        |              | trocken                    |         |
| 150 ml | Sahne         |        |              |                            |         |
| 1 TL   | Thymian       |        |              | getrocknet                 |         |
| 1 TL   | Salz          |        |              |                            |         |
| 1 TL   | Pfeffer       |        |              |                            |         |

## Zubereitung

1. [Mit Hähnchen] Keulen salzen und pfeffern, in 1 EL Butter 6 Minuten pro Seite goldbraun braten, herausnehmen. ⏱ 12
2. [Vegetarisch] Blumenkohlscheiben in 1 EL Butter je 4 Minuten pro Seite braun braten, herausnehmen. ⏱ 8
3. Apfelspalten in restlicher Butter 3 Minuten karamellisieren, herausnehmen. ⏱ 3
4. Schalotten 2 Minuten anbraten, mit Wein und Apfelsaft ablöschen, auf die Hälfte einkochen. ⏱ 5
5. Sahne und Thymian zugeben, Hähnchen bzw. Blumenkohl einlegen und zugedeckt 20 Minuten (Blumenkohl 10 Minuten) garen. ⏱ 20
6. Äpfel zugeben, kurz erwärmen und abschmecken.

## Notizen

Mit einem Schuss Calvados klassischer. Dazu Kartoffeln oder Baguette.
