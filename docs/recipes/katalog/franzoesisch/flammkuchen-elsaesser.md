# Elsässer Flammkuchen

![Elsässer Flammkuchen](../../pictures/flammkuchen-elsaesser.jpg)

Hauchdünner, knuspriger Boden mit Crème fraîche, Zwiebeln und Speck. Vegetarisch mit Lauch und Pilzen.

## Zutaten

| Menge   | Zutat         | Gruppe | Variante    | Hinweis          | Einkauf |
| ------- | ------------- | ------ | ----------- | ---------------- | ------- |
| 200 g   | Weizenmehl    | Teig   |             |                  | Menge   |
| 100 ml  | Wasser        | Teig   |             | lauwarm          | nie     |
| 2 EL    | Olivenöl      | Teig   |             |                  |         |
| 1 TL    | Salz          | Teig   |             |                  |         |
| 200 g   | Crème fraîche | Belag  |             |                  |         |
| 1       | Zwiebel       | Belag  |             | in dünnen Ringen |         |
| 100 g   | Speckwürfel   | Belag  | Mit Speck   |                  | Menge   |
| 1       | Lauch         | Belag  | Vegetarisch | dünne Ringe      |         |
| 100 g   | Champignon    | Belag  | Vegetarisch | in Scheiben      |         |
| 1 Prise | Muskat        | Belag  |             |                  |         |
| 1 TL    | Pfeffer       | Belag  |             |                  |         |

## Zubereitung

1. Mehl, Wasser, Öl und Salz zu einem glatten Teig kneten, 15 Minuten ruhen lassen. ⏱ 15
2. Ofen mit Blech auf 250 °C (oder höchste Stufe) vorheizen.
3. Teig sehr dünn (2 mm) ausrollen, auf Backpapier legen. Crème fraîche mit Muskat, Pfeffer und etwas Salz verrühren und aufstreichen.
4. [Mit Speck] Mit Zwiebelringen und Speck belegen.
5. [Vegetarisch] Mit Zwiebel, Lauch und Pilzen belegen.
6. Mit dem Papier auf das heiße Blech ziehen und 8 bis 10 Minuten backen, bis die Ränder dunkeln. ⏱ 9

## Notizen

Der Teig reicht für 2 kleine Flammkuchen, ggf. nacheinander backen.
