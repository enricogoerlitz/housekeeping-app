# Haricots verts mit Schalotten

![Haricots verts mit Schalotten](../../pictures/haricots-verts-aux-echalotes.jpg)

Grüne Bohnen, bissfest gegart und in Schalotten-Butter geschwenkt.

## Zutaten

| Menge   | Zutat        | Gruppe | Variante | Hinweis          | Einkauf |
| ------- | ------------ | ------ | -------- | ---------------- | ------- |
| 400 g   | Grüne Bohnen |        |          | geputzt          | Menge   |
| 2       | Schalotte    |        |          | in feinen Ringen |         |
| 20 g    | Butter       |        |          |                  |         |
| 1 TL    | Zitronen     |        |          | Saft             |         |
| 1 Prise | Salz         |        |          |                  |         |
| 1 Prise | Pfeffer      |        |          |                  |         |

## Zubereitung

1. Bohnen in reichlich Salzwasser 6 bis 8 Minuten garen, in Eiswasser abschrecken. ⏱ 7
2. Schalotten in Butter 4 Minuten glasig braten. ⏱ 4
3. Bohnen zugeben, 2 Minuten schwenken, mit Zitronensaft, Salz und Pfeffer abschmecken. ⏱ 2

## Notizen

Mit gerösteten Mandelblättchen noch besser.
