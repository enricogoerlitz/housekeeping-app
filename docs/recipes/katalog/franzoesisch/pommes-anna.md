# Pommes Anna

![Pommes Anna](../../pictures/pommes-anna.jpg)

Hauchdünne Kartoffelscheiben, mit Butter geschichtet und zu einem knusprigen Kuchen gebacken.

## Zutaten

| Menge | Zutat     | Gruppe | Variante | Hinweis                         | Einkauf |
| ----- | --------- | ------ | -------- | ------------------------------- | ------- |
| 600 g | Kartoffel |        |          | festkochend, hauchdünn gehobelt | Menge   |
| 60 g  | Butter    |        |          | geschmolzen                     |         |
| 1 TL  | Thymian   |        |          | getrocknet                      |         |
| 1 TL  | Salz      |        |          |                                 |         |

## Zubereitung

1. Ofen auf 200 °C Ober-/Unterhitze vorheizen. Eine ofenfeste Pfanne (22 cm) mit Butter auspinseln.
2. Kartoffelscheiben nicht waschen, in Kreisen dachziegelartig einschichten, dabei jede Lage mit Butter, Salz und Thymian würzen.
3. Obenauf mit Butter bestreichen, mit Backpapier abdecken und beschweren (zweite Pfanne).
4. 30 Minuten backen, Gewicht entfernen und weitere 20 Minuten bis zur goldenen Kruste backen. ⏱ 50
5. Kurz ruhen lassen, auf einen Teller stürzen.

## Notizen

Ohne Hobel sehr dünn mit dem Messer schneiden, sonst wird der Kuchen nicht kompakt.
