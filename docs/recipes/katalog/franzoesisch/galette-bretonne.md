# Galette Bretonne

![Galette Bretonne](../../pictures/galette-bretonne.jpg)

Herzhafte Buchweizenkrepps aus der Bretagne, gefaltet um Käse und Ei. Ohne Schinken vegetarisch.

## Zutaten

| Menge   | Zutat          | Gruppe | Variante     | Hinweis               | Einkauf |
| ------- | -------------- | ------ | ------------ | --------------------- | ------- |
| 100 g   | Buchweizenmehl |        |              |                       | Menge   |
| 250 ml  | Wasser         |        |              | kalt                  | nie     |
| 1       | Ei             |        |              | für den Teig          |         |
| 1 Prise | Salz           |        |              |                       |         |
| 2       | Ei             | Belag  |              | Spiegeleier           |         |
| 100 g   | Gruyère        | Belag  |              | gerieben              |         |
| 4       | Kochschinken   | Belag  | Mit Schinken | Scheiben              | Menge   |
| 100 g   | Champignon     | Belag  | Vegetarisch  | in Scheiben, gebraten | Menge   |
| 2 EL    | Butter         |        |              |                       |         |

## Zubereitung

1. Buchweizenmehl, Salz, Ei und Wasser glatt verrühren und 30 Minuten quellen lassen. ⏱ 30
2. Etwas Butter in einer großen Pfanne erhitzen, eine halbe Kelle Teig dünn ausbacken, 2 Minuten bräunen. ⏱ 2
3. Wenden, mit Käse bestreuen,
4. [Mit Schinken] Schinken darauflegen,
5. [Vegetarisch] gebratene Pilze darauflegen, ein Ei in die Mitte schlagen.
6. Ränder zu einem Quadrat nach innen falten, abdecken und 3 Minuten garen, bis das Eiweiß stockt. ⏱ 3
7. Mit dem zweiten Teigfladen ebenso verfahren, sofort servieren.

## Notizen

Aus der Teigmenge entstehen 2 bis 3 Fladen. Buchweizenmehl gibt es im Reformhaus und gut sortierten Supermarkt.
