# Pissaladière

![Pissaladière](../../pictures/pissaladiere.jpg)

Die Zwiebel-Pizza aus Nizza: sehr lange gegarte Zwiebeln auf dünnem Hefeboden, mit Oliven und Sardellen.

## Zutaten

| Menge  | Zutat           | Gruppe | Variante      | Hinweis              | Einkauf |
| ------ | --------------- | ------ | ------------- | -------------------- | ------- |
| 250 g  | Weizenmehl      | Teig   |               |                      | Menge   |
| 1      | Trockenhefe     | Teig   |               | Päckchen             |         |
| 130 ml | Wasser          | Teig   |               | lauwarm              | nie     |
| 2 EL   | Olivenöl        | Teig   |               |                      |         |
| 1 TL   | Salz            | Teig   |               |                      |         |
| 800 g  | Zwiebel         | Belag  |               | in dünnen Halbringen | Menge   |
| 3 EL   | Olivenöl        | Belag  |               |                      |         |
| 2      | Thymian         | Belag  |               | Zweige               |         |
| 8      | Sardellen       | Belag  | Mit Sardellen | in Öl                |         |
| 60 g   | Schwarze Oliven | Belag  |               | entsteint            |         |

## Zubereitung

1. Mehl, Hefe, Wasser, Öl und Salz zu einem geschmeidigen Teig kneten, abgedeckt 45 Minuten gehen lassen. ⏱ 45
2. Zwiebeln in Öl mit Thymian und etwas Salz bei niedriger Hitze 35 Minuten sehr weich und goldbraun schmoren. ⏱ 35
3. Ofen auf 220 °C Ober-/Unterhitze vorheizen. Teig rechteckig auf einem Blech auf 5 mm Dicke ausrollen.
4. Zwiebeln gleichmäßig verteilen.
5. [Mit Sardellen] Sardellen im Gittermuster darauflegen. Oliven verteilen.
6. 20 Minuten backen, bis der Rand goldbraun ist. ⏱ 20

## Notizen

Der Teig ergibt eine Backblech-Hälfte. Vegetarisch einfach ohne Sardellen, dafür mehr Oliven.
