# Französische Zwiebelsuppe

![Französische Zwiebelsuppe](../../pictures/soupe-a-l-oignon.jpg)

Zwiebeln, geduldig karamellisiert, mit Weißwein und Brühe, gekrönt von einem Käsetoast. Die Standardvariante nutzt Gemüsebrühe.

## Zutaten

| Menge  | Zutat       | Gruppe | Variante        | Hinweis              | Einkauf |
| ------ | ----------- | ------ | --------------- | -------------------- | ------- |
| 700 g  | Zwiebel     |        |                 | in feinen Halbringen | Menge   |
| 40 g   | Butter      |        |                 |                      |         |
| 1 TL   | Zucker      |        |                 |                      |         |
| 1 EL   | Mehl        |        |                 |                      |         |
| 150 ml | Weißwein    |        |                 | trocken              |         |
| 700 ml | Gemüsebrühe |        | Vegetarisch     |                      |         |
| 700 ml | Rinderbrühe |        | Mit Rinderbrühe |                      |         |
| 2      | Thymian     |        |                 | Zweige               |         |
| 4      | Baguette    |        |                 | Scheiben, getoastet  |         |
| 100 g  | Gruyère     |        |                 | gerieben             |         |
| 1 TL   | Salz        |        |                 |                      |         |
| 1 TL   | Pfeffer     |        |                 |                      |         |

## Zubereitung

1. Butter im Topf schmelzen, Zwiebeln mit Zucker und Salz bei mittlerer Hitze 30 bis 35 Minuten unter Rühren dunkelbraun karamellisieren. ⏱ 35
2. Mehl einrühren, 1 Minute rösten, mit Weißwein ablöschen und einkochen lassen. ⏱ 3
3. [Vegetarisch] Gemüsebrühe und Thymian zugeben, 15 Minuten köcheln. ⏱ 15
4. [Mit Rinderbrühe] Rinderbrühe und Thymian zugeben, 15 Minuten köcheln. ⏱ 15
5. Mit Salz und Pfeffer abschmecken. Suppe in ofenfeste Schalen füllen, je 2 Baguettescheiben darauflegen, mit Gruyère bedecken.
6. Unter dem Backofengrill (240 °C) 4 bis 5 Minuten überbacken, bis der Käse Blasen wirft. ⏱ 5

## Notizen

Ersatz für Gruyère: Emmentaler oder Bergkäse. Die Zwiebeln nicht zu heiß braten, sonst werden sie bitter.
