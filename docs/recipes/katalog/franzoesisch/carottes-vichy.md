# Carottes Vichy

![Carottes Vichy](../../pictures/carottes-vichy.jpg)

Karotten, in Butter und etwas Zucker glasiert, bis sie weich und glänzend sind.

## Zutaten

| Menge   | Zutat      | Gruppe | Variante | Hinweis       | Einkauf |
| ------- | ---------- | ------ | -------- | ------------- | ------- |
| 400 g   | Karotte    |        |          | in Scheiben   | Menge   |
| 20 g    | Butter     |        |          |               |         |
| 1 TL    | Zucker     |        |          |               |         |
| 150 ml  | Wasser     |        |          |               | nie     |
| 1       | Petersilie |        |          | Bund, gehackt |         |
| 1 Prise | Salz       |        |          |               |         |

## Zubereitung

1. Karotten mit Wasser, Butter, Zucker und Salz in einen weiten Topf geben.
2. Aufkochen und offen 12 bis 15 Minuten köcheln, bis das Wasser verdampft ist. ⏱ 14
3. Weiter unter Schwenken 2 Minuten glasieren, mit Petersilie bestreuen. ⏱ 2

## Notizen

Mit einem Spritzer Zitronensaft frischer.
