# Gratin Dauphinois

![Gratin Dauphinois](../../pictures/gratin-dauphinois.jpg)

Dünne Kartoffelscheiben in Sahne und Milch, mit Knoblauch gebacken, ohne Käse wie im Original aus dem Dauphiné.

## Zutaten

| Menge   | Zutat     | Gruppe | Variante | Hinweis                       | Einkauf |
| ------- | --------- | ------ | -------- | ----------------------------- | ------- |
| 600 g   | Kartoffel |        |          | festkochend, in 2 mm Scheiben | Menge   |
| 200 ml  | Sahne     |        |          |                               |         |
| 200 ml  | Milch     |        |          |                               |         |
| 1       | Knoblauch |        |          | Zehe, halbiert                |         |
| 1 EL    | Butter    |        |          |                               |         |
| 1 Prise | Muskat    |        |          |                               |         |
| 1 TL    | Salz      |        |          |                               |         |

## Zubereitung

1. Ofen auf 160 °C Ober-/Unterhitze vorheizen. Form mit Knoblauch ausreiben und mit Butter fetten.
2. Kartoffelscheiben nicht waschen, mit Sahne, Milch, Salz und Muskat in einem Topf 5 Minuten aufkochen. ⏱ 5
3. Alles in die Form füllen und glatt streichen.
4. 60 bis 70 Minuten backen, bis die Oberfläche goldbraun ist und die Kartoffeln weich sind. ⏱ 65

## Notizen

Passt zu Lamm, Steak und Ente. Mit Gruyère obenauf wird es ein Gratin savoyard.
