# Croque Monsieur

![Croque Monsieur](../../pictures/croque-monsieur.jpg)

Das überbackene Käse-Schinken-Sandwich mit Béchamel. Vegetarisch mit Spinat statt Schinken.

## Zutaten

| Menge   | Zutat        | Gruppe | Variante     | Hinweis          | Einkauf |
| ------- | ------------ | ------ | ------------ | ---------------- | ------- |
| 4       | Toastbrot    |        |              | Scheiben         |         |
| 4       | Kochschinken |        | Mit Schinken | Scheiben         | Menge   |
| 100 g   | Babyspinat   |        | Vegetarisch  | kurz angedünstet | Menge   |
| 120 g   | Gruyère      |        |              | gerieben         |         |
| 1 TL    | Senf         |        |              | Dijon            |         |
| 20 g    | Butter       |        |              | Béchamel         |         |
| 20 g    | Mehl         |        |              |                  |         |
| 250 ml  | Milch        |        |              |                  |         |
| 1 Prise | Muskat       |        |              |                  |         |
| 1 Prise | Salz         |        |              |                  |         |

## Zubereitung

1. Butter schmelzen, Mehl 1 Minute anschwitzen, Milch nach und nach einrühren und 5 Minuten zur dicken Sauce köcheln. Mit Muskat und Salz würzen. ⏱ 5
2. Ofen auf 220 °C Oberhitze/Grill vorheizen. Toastscheiben auf einer Seite mit Senf bestreichen.
3. [Mit Schinken] Zwei Scheiben mit Schinken und der Hälfte des Käses belegen, mit den anderen Scheiben schließen.
4. [Vegetarisch] Zwei Scheiben mit gut ausgedrücktem Spinat und der Hälfte des Käses belegen, mit den anderen Scheiben schließen.
5. Sandwiches mit Béchamel bestreichen und mit restlichem Käse bestreuen.
6. 8 bis 10 Minuten überbacken, bis die Oberfläche goldbraun ist. ⏱ 9

## Notizen

Mit einem Spiegelei obendrauf wird daraus ein Croque Madame.
