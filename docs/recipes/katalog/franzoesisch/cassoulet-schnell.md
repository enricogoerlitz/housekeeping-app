# Cassoulet für den Alltag

![Cassoulet für den Alltag](../../pictures/cassoulet-schnell.jpg)

Vereinfachtes Bohnengericht aus Südwestfrankreich mit Knusperkruste. Vegetarisch mit Räuchertofu.

## Zutaten

| Menge  | Zutat             | Gruppe | Variante    | Hinweis          | Einkauf |
| ------ | ----------------- | ------ | ----------- | ---------------- | ------- |
| 800 g  | Weiße Bohnen      |        |             | Dose, abgetropft | Menge   |
| 200 g  | Bratwurst         |        | Mit Wurst   | in Stücken       | Menge   |
| 200 g  | Räuchertofu       |        | Vegetarisch | gewürfelt        | Menge   |
| 1      | Zwiebel           |        |             | gewürfelt        |         |

## Zubereitung

1. Ofen auf 180 °C Ober-/Unterhitze vorheizen.
2. [Mit Wurst] Wurststücke in Öl rundum braun braten, herausnehmen.
3. [Vegetarisch] Räuchertofu in Öl knusprig braten, herausnehmen.
4. Zwiebel und Knoblauch im Bratfett 4 Minuten anbraten, Tomatenmark 1 Minute mitrösten, mit Wein ablöschen. ⏱ 5
5. Passierte Tomaten, Thymian, Lorbeer, Bohnen und Salz zugeben, Wurst bzw. Tofu untermischen und in eine Form füllen.
6. Mit Semmelbröseln bestreuen, mit etwas Öl beträufeln und 40 Minuten backen, bis die Kruste goldbraun ist. ⏱ 40

## Notizen

Im klassischen Cassoulet stecken Entenconfit und Schweinebauch; diese Variante ist bewusst alltagstauglich.
