# Tartiflette

![Tartiflette](../../pictures/tartiflette.jpg)

Der savoyische Bergklassiker: Kartoffeln, Zwiebeln, Weißwein und viel geschmolzener Käse. Vegetarisch ohne Speck mit Räuchertofu.

## Zutaten

| Menge  | Zutat       | Gruppe | Variante    | Hinweis                           | Einkauf |
| ------ | ----------- | ------ | ----------- | --------------------------------- | ------- |
| 700 g  | Kartoffel   |        |             | festkochend                       | Menge   |
| 150 g  | Speckwürfel |        | Mit Speck   |                                   | Menge   |
| 150 g  | Räuchertofu |        | Vegetarisch | gewürfelt                         | Menge   |
| 1      | Zwiebel     |        |             | in Halbringen                     |         |
| 1 EL   | Butter      |        |             |                                   |         |
| 100 ml | Weißwein    |        |             | trocken                           |         |
| 100 ml | Sahne       |        |             |                                   |         |
| 1      | Reblochon   |        |             | Rinde bleibt, halbiert, ca. 250 g | 1×      |
| 1 TL   | Pfeffer     |        |             |                                   |         |
| 1 TL   | Salz        |        |             |                                   |         |

## Zubereitung

1. Kartoffeln in der Schale 20 Minuten kochen, pellen und in Scheiben schneiden. ⏱ 20
2. Ofen auf 200 °C Ober-/Unterhitze vorheizen.
3. Zwiebel in Butter anbraten,
4. [Mit Speck] Speck zugeben und 4 Minuten braten. ⏱ 4
5. [Vegetarisch] Räuchertofu mit der Zwiebel 5 Minuten knusprig braten. ⏱ 5
6. Mit Wein ablöschen, Sahne zugeben, 2 Minuten einköcheln. Mit Pfeffer und Salz würzen. ⏱ 2
7. Kartoffeln mit der Sauce in eine Form geben, die Käsehälften mit der Rinde nach oben darauflegen.
8. 20 Minuten backen, bis der Käse zerlaufen und goldbraun ist. ⏱ 20

## Notizen

Ersatz für Reblochon: Brie oder Camembert (mild, nicht zu reif). Dazu ein grüner Salat.
