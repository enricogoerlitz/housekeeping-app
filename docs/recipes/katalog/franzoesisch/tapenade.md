# Tapenade

![Tapenade](../../pictures/tapenade.jpg)

Provenzalischer Olivenaufstrich mit Kapern und Knoblauch zu Baguette oder Gemüse.

## Zutaten

| Menge | Zutat           | Gruppe | Variante | Hinweis       | Einkauf |
| ----- | --------------- | ------ | -------- | ------------- | ------- |
| 150 g | Schwarze Oliven |        |          | entsteint     | Menge   |
| 1 EL  | Kapern          |        |          | abgetropft    |         |
| 1     | Knoblauch       |        |          | Zehe          |         |
| 3 EL  | Olivenöl        |        |          |               |         |
| 1 TL  | Zitronen        |        |          | Saft          |         |
| 1     | Baguette        |        |          | zum Servieren |         |

## Zubereitung

1. Oliven, Kapern, Knoblauch und Zitronensaft im Mixer grob pürieren.
2. Olivenöl nach und nach einarbeiten, bis eine streichfähige Paste entsteht.
3. Mit Baguette servieren, hält sich im Kühlschrank eine Woche.

## Notizen

Klassisch kommen Sardellenfilets dazu. Mit grünen Oliven wird die Tapenade milder.
