# Ratatouille

![Ratatouille](../../pictures/ratatouille.jpg)

Provenzalisches Sommergemüse, langsam im Ofen gegart. Mit Baguette oder als Beilage ein vollwertiges Hauptgericht.

## Zutaten

| Menge | Zutat             | Gruppe | Variante | Hinweis             | Einkauf |
| ----- | ----------------- | ------ | -------- | ------------------- | ------- |
| 1     | Aubergine         |        |          |                     | Menge   |
| 2     | Zucchini          |        |          |                     | Menge   |
| 3     | Tomate            |        |          |                     |         |
| 1     | Paprika           |        |          | rot                 |         |
| 1     | Zwiebel           |        |          | fein gewürfelt      |         |
| 3     | Knoblauch         |        |          | Zehen, gehackt      |         |
| 400 g | Passierte Tomaten |        |          |                     |         |
| 3 EL  | Olivenöl          |        |          |                     |         |
| 4     | Thymian           |        |          | Zweige              |         |
| 1     | Basilikum         |        |          | Topf, zum Servieren |         |
| 1 TL  | Salz              |        |          |                     |         |
| 1 TL  | Pfeffer           |        |          |                     |         |

## Zubereitung

1. Ofen auf 180 °C Ober-/Unterhitze vorheizen.
2. Zwiebel, Knoblauch und gewürfelte Paprika in 1 EL Olivenöl 5 Minuten anschwitzen, Passierte Tomaten, Salz und Pfeffer zugeben und 5 Minuten einkochen. In eine runde Auflaufform geben. ⏱ 10
3. Aubergine, Zucchini und Tomaten in gleich dicke (3 mm) Scheiben schneiden und fächerartig dicht auf der Sauce schichten.
4. Mit restlichem Öl beträufeln, Thymian darauflegen, würzen und mit Backpapier abdecken.
5. 40 Minuten backen, Papier abnehmen und weitere 10 Minuten garen. ⏱ 50
6. Mit Basilikum bestreuen und lauwarm servieren.

## Notizen

Ohne Backpapier-Abdeckung trocknet die Oberseite aus. Als Beilage zu Lamm oder Hähnchen sehr gut.
