# Soupe au Pistou

![Soupe au Pistou](../../pictures/soupe-au-pistou.jpg)

Provenzalische Gemüsesuppe mit weißen Bohnen und Nudeln, mit einem Klecks Basilikum-Pistou serviert.

## Zutaten

| Menge | Zutat        | Gruppe | Variante | Hinweis          | Einkauf |
| ----- | ------------ | ------ | -------- | ---------------- | ------- |
| 1     | Karotte      | Suppe  |          | gewürfelt        |         |
| 1     | Zucchini     | Suppe  |          | gewürfelt        |         |
| 150 g | Grüne Bohnen | Suppe  |          | in Stücken       |         |
| 1     | Kartoffel    | Suppe  |          | gewürfelt        |         |
| 1     | Zwiebel      | Suppe  |          | gewürfelt        |         |
| 400 g | Weiße Bohnen | Suppe  |          | Dose, abgetropft |         |
| 2     | Tomate       | Suppe  |          | gewürfelt        |         |
| 1 l   | Wasser       | Suppe  |          |                  | nie     |
| 60 g  | Suppennudeln | Suppe  |          |                  | Menge   |
| 1 EL  | Olivenöl     | Suppe  |          |                  |         |
| 1     | Basilikum    | Pistou |          | Topf             |         |
| 2     | Knoblauch    | Pistou |          | Zehen            |         |
| 4 EL  | Olivenöl     | Pistou |          |                  |         |
| 30 g  | Parmesan     | Pistou |          | gerieben         |         |
| 1 TL  | Salz         |        |          |                  |         |

## Zubereitung

1. Zwiebel in Öl 3 Minuten anschwitzen, Karotte, Kartoffel und Tomaten zugeben, 3 Minuten mitbraten. ⏱ 6
2. Wasser und Salz zugeben, aufkochen und 15 Minuten köcheln. ⏱ 15
3. Zucchini, Grüne Bohnen, Weiße Bohnen und Nudeln zugeben und 10 Minuten garen. ⏱ 10
4. Für den Pistou Basilikumblätter, Knoblauch, Olivenöl und Parmesan fein pürieren oder im Mörser zerreiben.
5. Suppe abschmecken, in Schalen füllen und einen Löffel Pistou einrühren.

## Notizen

Parmesan ist nicht vegan, Pecorino geht ebenfalls; vegan: weglassen und etwas Salz mehr im Pistou.
