# Crème brûlée

![Crème brûlée](../../pictures/creme-brulee.jpg)

Vanillecreme mit gebrannter Zuckerkruste. Muss mindestens vier Stunden kühlen.

## Zutaten

| Menge  | Zutat         | Gruppe | Variante | Hinweis             | Einkauf |
| ------ | ------------- | ------ | -------- | ------------------- | ------- |
| 250 ml | Sahne         |        |          |                     |         |
| 1      | Vanilleschote |        |          |                     |         |
| 3      | Eier          |        |          |                     |         |
| 40 g   | Zucker        |        |          |                     |         |
| 2 EL   | Zucker        |        |          | zum Karamellisieren |         |

## Zubereitung

1. Ofen auf 150 °C Ober-/Unterhitze vorheizen. Sahne mit ausgekratzter Vanilleschote 5 Minuten erhitzen und 10 Minuten ziehen lassen. ⏱ 15
2. Eigelbe mit 40 g Zucker verrühren, heiße Sahne (ohne Schote) unterrühren, nicht schaumig schlagen.
3. In zwei flache Förmchen füllen, in eine Form mit heißem Wasser (bis halbe Höhe) stellen.
4. 35 bis 40 Minuten garen, bis die Mitte noch leicht wackelt. ⏱ 38
5. Auskühlen und mindestens 4 Stunden kalt stellen.
6. Mit Zucker bestreuen und mit dem Brenner oder unter dem Grill karamellisieren.

## Notizen

Ohne Brenner den Ofengrill auf höchster Stufe nutzen, Förmchen ganz nah an den Grill stellen. Vorlauf: mind. 4 Stunden.
