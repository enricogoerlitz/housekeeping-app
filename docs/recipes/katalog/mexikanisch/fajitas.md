# Fajitas

![Fajitas](../../pictures/fajitas.jpg)

Heiß gebratene Streifen mit Paprika und Zwiebeln, kräftig gewürzt und am Tisch in warme Weizentortillas gerollt.

## Zutaten

| Menge | Zutat           | Gruppe       | Variante     | Hinweis            | Einkauf |
| ----- | --------------- | ------------ | ------------ | ------------------ | ------- |
| 300 g | Hähnchenbrust   |              | Mit Hähnchen | in Streifen        | Menge   |
| 250 g | Champignons     |              | Vegetarisch  | in dicken Scheiben | Menge   |
| 1     | Paprika         |              |              | rot, in Streifen   |         |
| 1     | Paprika         |              |              | gelb, in Streifen  |         |
| 1     | Zwiebel         |              |              | in Spalten         |         |
| 1 EL  | Paprikapulver   | Würzmischung |              | edelsüß            |         |
| 1 TL  | Kreuzkümmel     | Würzmischung |              | gemahlen           |         |
| 1 TL  | Knoblauchpulver | Würzmischung |              |                    |         |
| 1 TL  | Salz            | Würzmischung |              |                    |         |
| ½ TL  | Chilipulver     | Würzmischung |              |                    |         |
| 2 EL  | Pflanzenöl      |              |              |                    |         |

| 4     | Weizentortilla  |              |              | groß               |         |

## Zubereitung

1. Gewürze mischen und mit 1 EL Öl und Limettensaft verrühren.
2. Hähnchen bzw. Champignons in der Hälfte der Würzmarinade 10 Minuten ziehen lassen. ⏱ 10
3. Pfanne stark erhitzen, Hähnchen 5 Minuten rundum durchbraten bzw. Champignons 6 Minuten braten, herausnehmen. ⏱ 6
4. Paprika und Zwiebel im restlichen Öl 5 Minuten bei hoher Hitze anbraten, restliche Würzmarinade zugeben. ⏱ 5
5. Fleisch bzw. Pilze zurückgeben, 1 Minute mitschwenken.
6. Tortillas trocken in einer Pfanne je Seite 20 Sekunden erwärmen.
7. Mit Limettenspalten und saurer Sahne am Tisch füllen und einrollen.

## Notizen

Dazu passen Guacamole und Salsa roja.
