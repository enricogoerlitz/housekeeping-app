# Sopa de tortilla

![Sopa de tortilla](../../pictures/sopa-de-tortilla.jpg)

Aromatische Tomatensuppe mit Chili und knusprigen Tortillastreifen, am Tisch mit Avocado, Käse und saurer Sahne belegt.

## Zutaten

| Menge  | Zutat             | Gruppe   | Variante     | Hinweis            | Einkauf |
| ------ | ----------------- | -------- | ------------ | ------------------ | ------- |
| 4      | Maistortilla      |          |              | in dünnen Streifen |         |
| 2 EL   | Pflanzenöl        |          |              |                    |         |
| 1      | Zwiebel           |          |              | gewürfelt          |         |
| 2      | Knoblauch         |          |              | Zehen              |         |
| 400 g  | Stückige Tomaten  |          |              |                    | Menge   |
| 1      | Chipotle in Adobo |          |              | gehackt            |         |
| 700 ml | Gemüsebrühe       |          |              |                    |         |
| 200 g  | Hähnchenbrust     |          | Mit Hähnchen |                    | Menge   |
| 1      | Avocado           | Toppings |              | gewürfelt          |         |
| 80 g   | Feta              | Toppings |              | gewürfelt          |         |
| 3 EL   | Saure Sahne       | Toppings |              |                    |         |
| 1      | Limette           | Toppings |              | in Spalten         |         |
| 1 Bund | Koriander         | Toppings |              | gehackt            |         |

## Zubereitung

1. Tortillastreifen in 1 EL Öl bei mittlerer Hitze 3 Minuten goldbraun und knusprig braten, auf Küchenpapier abtropfen und salzen. ⏱ 3
2. Zwiebel in 1 EL Öl 4 Minuten weich dünsten, Knoblauch 30 Sekunden mitbraten. ⏱ 4
3. Tomaten und Chipotle zugeben und 5 Minuten einkochen lassen. ⏱ 5
4. Brühe angießen und 10 Minuten köcheln lassen. ⏱ 10
5. Suppe mit dem Stabmixer fein pürieren, mit Salz und Limettensaft abschmecken.
6. [Mit Hähnchen] Hähnchen in dünne Streifen schneiden, in die heiße Suppe geben und 8 Minuten gar ziehen lassen. ⏱ 8
7. In Schalen füllen und mit Tortillastreifen, Avocado, Feta, saurer Sahne und Koriander belegen.

## Notizen

Chipotle ist rauchig-scharf; für eine mildere Suppe nur das halbe Stück nehmen.
