# Gefüllte Poblano-Chilis

![Gefüllte Poblano-Chilis](../../pictures/chiles-rellenos.jpg)

Gebackene grüne Spitzpaprika mit Käse-Bohnen-Füllung auf roter Tomatensauce, angelehnt an Chiles rellenos.

## Zutaten

| Menge  | Zutat             | Gruppe  | Variante        | Hinweis                                   | Einkauf |
| ------ | ----------------- | ------- | --------------- | ----------------------------------------- | ------- |
| 4      | Paprika           |         |                 | Spitzpaprika, grün, halbiert und entkernt |         |
| 150 g  | Mais              | Füllung |                 | aus der Dose, abgetropft                  |         |
| 200 g  | Schwarze Bohnen   | Füllung |                 | abgetropft                                |         |
| 150 g  | Mozzarella        | Füllung |                 | gerieben                                  | Menge   |
| 200 g  | Rinderhackfleisch | Füllung | Mit Hackfleisch |                                           | Menge   |
| 1      | Zwiebel           | Füllung |                 | gewürfelt                                 |         |
| 1 TL   | Kreuzkümmel       | Füllung |                 | gemahlen                                  |         |
| 400 g  | Passierte Tomaten | Sauce   |                 |                                           | Menge   |
| 1      | Knoblauch         | Sauce   |                 | Zehe, gepresst                            |         |
| 1 TL   | Oregano           | Sauce   |                 | getrocknet                                |         |
| 2 EL   | Olivenöl          |         |                 |                                           |         |
| 1 TL   | Salz              |         |                 |                                           |         |
| 1 Bund | Koriander         |         |                 | gehackt                                   |         |

## Zubereitung

1. Backofen auf 200 °C Ober-/Unterhitze vorheizen.
2. Zwiebel in 1 EL Öl 3 Minuten dünsten. ⏱ 3
3. [Mit Hackfleisch] Hack zugeben und 6 Minuten krümelig braten. ⏱ 6
4. Kreuzkümmel, Bohnen, Mais und ½ TL Salz zugeben, 3 Minuten erwärmen, vom Herd nehmen, Hälfte Käse untermischen. ⏱ 3
5. Passierte Tomaten mit Knoblauch, Oregano und ½ TL Salz verrühren und in eine Auflaufform gießen.
6. Paprikahälften mit der Füllung vollstopfen und in die Sauce setzen, mit restlichem Käse bestreuen.
7. 25 Minuten backen, bis die Paprika weich und der Käse goldbraun ist. ⏱ 25
8. Mit Koriander bestreuen und servieren.

## Notizen

Echte Chiles rellenos nutzen Poblanos, geröstet und im Eiteig frittiert; Spitzpaprika ist die einfache, ofenfreundliche Version. Mit Reis servieren.
