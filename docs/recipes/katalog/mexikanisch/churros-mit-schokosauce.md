# Churros mit Schokosauce

![Churros mit Schokosauce](../../pictures/churros-mit-schokosauce.jpg)

Knusprige Brandteigstangen in Zimtzucker, zum Dippen in warmer Schokosauce.

## Zutaten

| Menge   | Zutat                | Gruppe      | Variante | Hinweis              | Einkauf |
| ------- | -------------------- | ----------- | -------- | -------------------- | ------- |

| 125 ml  | Milch                | Churros     |          |                      |         |
| 60 g    | Butter               | Churros     |          |                      |         |
| 125 g   | Mehl                 | Churros     |          | Type 405             |         |
| 1       | Ei                   | Churros     |          |                      |         |

| 100 ml  | Sahne                | Schokosauce |          |                      |         |

## Zubereitung

1. Wasser, Milch, Butter und Salz aufkochen, bis die Butter geschmolzen ist.
2. Topf vom Herd nehmen, Mehl auf einmal zugeben und kräftig zu einem glatten Kloß rühren.
3. 1 Minute bei mittlerer Hitze abbrennen, bis sich ein Belag am Topfboden bildet, dann 5 Minuten abkühlen lassen. ⏱ 5
4. Ei unterrühren, bis ein glatter, zäher Teig entsteht. In einen Spritzbeutel mit Sternenzülle füllen.
5. Sahne erhitzen, über die Schokolade gießen, 2 Minuten warten und glatt rühren. ⏱ 2
6. Öl in einem hohen Topf auf 175 °C erhitzen. Teigstränge von 10 cm direkt ins Öl spritzen und abschneiden.
7. Je 3 bis 4 Minuten goldbraun frittieren, auf Küchenpapier abtropfen. ⏱ 4
8. In Zimtzucker wälzen und sofort mit warmer Schokosauce servieren.

## Notizen

Ohne Spritzbeutel: Teig mit zwei Löffeln zu kleinen Bällchen formen. Öl nur mit Fettthermometer oder Holzstiel-Test erhitzen; Vorsicht vor Spritzern.
