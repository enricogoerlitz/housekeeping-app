# Guacamole

![Guacamole](../../pictures/guacamole.jpg)

Grobe Avocadocreme mit Limette, Zwiebel und Koriander, der perfekte Dip zu Tortillachips und Fajitas.

## Zutaten

| Menge  | Zutat        | Gruppe | Variante | Hinweis                   | Einkauf |
| ------ | ------------ | ------ | -------- | ------------------------- | ------- |
| 2      | Avocado      |        |          | sehr reif                 |         |
| ½      | Rote Zwiebel |        |          | fein gewürfelt            |         |
| 1      | Tomate       |        |          | entkernt und gewürfelt    |         |
| 1      | Jalapeño     |        |          | entkernt und fein gehackt |         |
| 1      | Limette      |        |          | Saft                      |         |
| 1 Bund | Koriander    |        |          | gehackt                   |         |
| ½ TL   | Salz         |        |          |                           |         |

## Zubereitung

1. Avocados halbieren, Fruchtfleisch mit einer Gabel grob zerdrücken.
2. Limettensaft sofort einrühren, damit das Fruchtfleisch nicht braun wird.
3. Zwiebel, Jalapeño, Tomate und Koriander untermischen, mit Salz abschmecken.
4. Direkt servieren oder mit Frischhaltefolie direkt auf der Oberfläche bis zu 2 Stunden kühl halten.

## Notizen

Den Avocadokern in die Schale legen hilft optisch nicht gegen Braunwerden; besser Folie direkt auflegen.
