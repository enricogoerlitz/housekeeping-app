# Frijoles refritos

![Frijoles refritos](../../pictures/frijoles-refritos.jpg)

Cremig gestampfte Bohnen mit Zwiebel und Kreuzkümmel, passen zu Huevos rancheros, Burritos und Tacos.

## Zutaten

| Menge   | Zutat        | Gruppe | Variante | Hinweis                                                            | Einkauf |
| ------- | ------------ | ------ | -------- | ------------------------------------------------------------------ | ------- |
| 2 Dosen | Kidneybohnen |        |          | oder Pintobohnen, abgetropft, Flüssigkeit auffangen (je ca. 240 g) | Menge   |
| 1       | Zwiebel      |        |          | fein gewürfelt                                                     |         |
| 2       | Knoblauch    |        |          | Zehen                                                              |         |
| 1 TL    | Kreuzkümmel  |        |          | gemahlen                                                           |         |
| 3 EL    | Pflanzenöl   |        |          |                                                                    |         |
| 1 TL    | Salz         |        |          |                                                                    |         |
| 50 g    | Feta         |        |          | zerbröselt, zum Servieren                                          |         |

## Zubereitung

1. Zwiebel in Öl 4 Minuten glasig dünsten, Knoblauch und Kreuzkümmel 1 Minute mitbraten. ⏱ 5
2. Bohnen mit 100 ml Bohnenflüssigkeit zugeben und 5 Minuten köcheln. ⏱ 5
3. Mit einem Stampfer zu einem groben Püree zerdrücken, bei Bedarf mehr Flüssigkeit zugeben.
4. 5 Minuten unter Rühren eindicken lassen, mit Salz abschmecken. ⏱ 5
5. Mit Feta bestreuen und servieren.

## Notizen

Pintobohnen sind im Latino-Laden erhältlich; Kidneybohnen oder weiße Bohnen funktionieren ebenso.
