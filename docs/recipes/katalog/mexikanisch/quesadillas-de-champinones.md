# Quesadillas mit Pilzen

![Quesadillas mit Pilzen](../../pictures/quesadillas-de-champinones.jpg)

Knusprig gebräunte Tortillas mit schmelzendem Käse und gebratenen Champignons, schnell gemacht und immer beliebt.

## Zutaten

| Menge  | Zutat          | Gruppe | Variante     | Hinweis            | Einkauf |
| ------ | -------------- | ------ | ------------ | ------------------ | ------- |
| 4      | Weizentortilla |        |              | mittelgroß         |         |
| 300 g  | Champignons    |        |              | in Scheiben        | Menge   |
| 1      | Zwiebel        |        |              | in dünnen Streifen |         |
| 2      | Knoblauch      |        |              | Zehen              |         |
| 200 g  | Gouda          |        |              | gerieben           | Menge   |
| 150 g  | Hähnchenbrust  |        | Mit Hähnchen | in kleinen Würfeln | Menge   |
| 1 TL   | Oregano        |        |              | getrocknet         |         |
| 2 EL   | Pflanzenöl     |        |              |                    |         |
| 1 Bund | Koriander      |        |              | gehackt            |         |
| 4 EL   | Salsa          |        |              | zum Dippen         |         |
| 3 EL   | Saure Sahne    |        |              | zum Dippen         |         |

## Zubereitung

1. [Mit Hähnchen] Hähnchenwürfel in 1 EL Öl 5 Minuten durchbraten, salzen, herausnehmen. ⏱ 5
2. Zwiebel und Champignons in 1 EL Öl bei starker Hitze 6 Minuten braten, bis das Wasser verdampft ist. ⏱ 6
3. Knoblauch, Oregano, Salz und Pfeffer zugeben, 1 Minute braten, Koriander unterheben.
4. Je Tortilla eine Hälfte mit Käse, Füllung und noch etwas Käse belegen, zuklappen.
5. In einer trockenen Pfanne bei mittlerer Hitze 2 bis 3 Minuten je Seite goldbraun und knusprig braten. ⏱ 5
6. In Spalten schneiden und mit Salsa und saurer Sahne servieren.

## Notizen

Mit Oaxaca-Käse oder Mozzarella wird der Käse besonders fadenziehend.
