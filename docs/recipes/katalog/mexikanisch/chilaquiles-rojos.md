# Chilaquiles rojos

![Chilaquiles rojos](../../pictures/chilaquiles-rojos.jpg)

Knusprige Tortillachips werden kurz in scharfer roter Tomatensauce geschwenkt und mit Spiegelei und Käse zum herzhaften Frühstück oder Abendessen.

## Zutaten

| Menge  | Zutat             | Gruppe     | Variante     | Hinweis                         | Einkauf |
| ------ | ----------------- | ---------- | ------------ | ------------------------------- | ------- |
| 150 g  | Tortilla-Chips    |            |              | ungesalzen oder leicht gesalzen | Menge   |
| 400 g  | Passierte Tomaten | Salsa roja |              |                                 | Menge   |
| 1      | Zwiebel           | Salsa roja |              | grob gehackt                    |         |
| 2      | Knoblauch         | Salsa roja |              | Zehen                           |         |
| 1      | Chipotle in Adobo | Salsa roja |              | aus der Dose, gehackt           |         |
| 150 ml | Gemüsebrühe       | Salsa roja |              |                                 |         |
| 1 TL   | Salz              | Salsa roja |              |                                 |         |

| 150 g  | Hähnchenbrust     |            | Mit Hähnchen | gegart und zerzupft             | Menge   |

| 3 EL   | Saure Sahne       |            |              |                                 |         |
| 1      | Rote Zwiebel      |            |              | in dünnen Ringen                |         |
| 1 Bund | Koriander         |            |              | gehackt                         |         |
| 2 EL   | Pflanzenöl        |            |              |                                 |         |

## Zubereitung

1. Zwiebel und Knoblauch in 1 EL Öl 3 Minuten anschwitzen. ⏱ 3
2. Passierte Tomaten, Chipotle, Brühe und Salz zugeben, 10 Minuten köcheln und anschließend fein pürieren. ⏱ 10
3. Sauce zurück in die Pfanne geben und aufkochen.
4. [Mit Hähnchen] Das zerzupfte Hähnchen in der Sauce erwärmen.
5. Chips in die heiße Sauce geben und 1 Minute schwenken, bis sie überzogen, aber noch nicht matschig sind. ⏱ 1
6. Parallel Spiegeleier in 1 EL Öl bei mittlerer Hitze 3 Minuten braten. ⏱ 3
7. Chilaquiles sofort mit Spiegelei, Feta, saurer Sahne, Zwiebelringen und Koriander servieren.

## Notizen

Chipotle in Adobo gibt es im Supermarkt bei den mexikanischen Produkten; ersatzweise 1 TL geräuchertes Paprikapulver und 1 Prise Chili. Sofort essen, sonst weichen die Chips durch.
