# Huevos rancheros

![Huevos rancheros](../../pictures/huevos-rancheros.jpg)

Spiegeleier auf knusprigen Tortillas mit Bohnenpüree und würziger Tomatensalsa, ein sättigender Klassiker vom mexikanischen Bauernhof.

## Zutaten

| Menge  | Zutat            | Gruppe | Variante    | Hinweis                | Einkauf |
| ------ | ---------------- | ------ | ----------- | ---------------------- | ------- |
| 4      | Maistortilla     |        |             | klein                  |         |
| 4      | Eier             |        |             | Größe M                |         |
| 1 Dose | Schwarze Bohnen  |        |             | abgetropft (ca. 240 g) |         |
| 1      | Zwiebel          |        |             | fein gewürfelt         |         |
| 2      | Knoblauch        |        |             | Zehen                  |         |
| 1 TL   | Kreuzkümmel      |        |             | gemahlen               |         |

| 1      | Jalapeño         | Salsa  |             | fein gehackt           |         |
| 1      | Avocado          |        |             | reif, in Scheiben      |         |
| 100 g  | Chorizo          |        | Mit Chorizo | in Scheiben            | Menge   |
| 1 Bund | Koriander        |        |             | gehackt                |         |
| 3 EL   | Pflanzenöl       |        |             |                        |         |
| 1 TL   | Salz             |        |             |                        |         |

## Zubereitung

1. Zwiebel in 1 EL Öl 3 Minuten anschwitzen, Knoblauch und Kreuzkümmel 30 Sekunden mitbraten. ⏱ 3
2. Hälfte davon in einen zweiten Topf geben: dort Stückige Tomaten, Jalapeño und ½ TL Salz 10 Minuten zur Salsa einköcheln. ⏱ 10
3. Bohnen in den ersten Topf geben und mit einem Kartoffelstampfer grob zerdrücken, 5 Minuten erhitzen und salzen. ⏱ 5
4. [Mit Chorizo] Chorizo in einer trockenen Pfanne 4 Minuten knusprig braten und unter die Salsa rühren. ⏱ 4
5. Tortillas in 1 EL Öl je Seite 1 Minute anrösten, bis sie leicht knusprig sind.
6. Eier in 1 EL Öl bei mittlerer Hitze zu Spiegeleiern braten, 3 Minuten. ⏱ 3
7. Tortillas mit Bohnen, Spiegelei und Salsa belegen, mit Avocado und Koriander servieren.

## Notizen

Schwarze Bohnen gibt es in Dosen bei den Hülsenfrüchten. Kidneybohnen gehen zur Not auch.
