# Arroz rojo

![Arroz rojo](../../pictures/arroz-rojo.jpg)

Locker gegarter Tomatenreis, die klassische Beilage zu Enchiladas, Fajitas und Bohnen.

## Zutaten

| Menge  | Zutat             | Gruppe | Variante | Hinweis            | Einkauf |
| ------ | ----------------- | ------ | -------- | ------------------ | ------- |
| 150 g  | Langkornreis      |        |          |                    |         |
| 2 EL   | Pflanzenöl        |        |          |                    |         |
| ½      | Zwiebel           |        |          | fein gewürfelt     |         |
| 2      | Knoblauch         |        |          | Zehen              |         |
| 200 g  | Passierte Tomaten |        |          |                    |         |
| 300 ml | Gemüsebrühe       |        |          |                    |         |
| 1      | Karotte           |        |          | in kleinen Würfeln |         |
| 80 g   | Erbsen            |        |          | tiefgekühlt        |         |
| ½ TL   | Salz              |        |          |                    |         |

## Zubereitung

1. Reis in einem Sieb unter kaltem Wasser abspülen, gut abtropfen lassen.
2. Reis in Öl bei mittlerer Hitze 4 Minuten unter Rühren goldgelb anrösten. ⏱ 4
3. Zwiebel und Knoblauch zugeben, 2 Minuten mitbraten. ⏱ 2
4. Passierte Tomaten, Brühe, Karotte und Salz zugeben, einmal aufkochen.
5. Zugedeckt bei kleinster Hitze 15 Minuten garen, Erbsen auflegen, weitere 5 Minuten. ⏱ 20
6. 5 Minuten ruhen lassen und mit einer Gabel auflockern. ⏱ 5

## Notizen

Nicht rühren, während der Reis gart, sonst wird er klebrig.
