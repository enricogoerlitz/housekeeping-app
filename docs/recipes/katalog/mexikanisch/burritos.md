# Burritos

![Burritos](../../pictures/burritos.jpg)

Große Weizentortillas gefüllt mit würzigem Reis, Bohnen und Käse, fest eingerollt und kurz in der Pfanne angeröstet.

## Zutaten

| Menge  | Zutat             | Gruppe | Variante     | Hinweis                    | Einkauf |
| ------ | ----------------- | ------ | ------------ | -------------------------- | ------- |
| 2      | Weizentortilla    |        |              | extra groß, ca. 30 cm      |         |
| 200 g  | Rinderhackfleisch |        | Mit Rindhack |                            | Menge   |
| 1 Dose | Schwarze Bohnen   |        |              | abgetropft                 |         |
| 120 g  | Langkornreis      |        |              |                            |         |
| 1      | Zwiebel           |        |              | gewürfelt                  |         |
| 2      | Knoblauch         |        |              | Zehen                      |         |
| 1 EL   | Paprikapulver     |        |              | edelsüß                    |         |
| 1 TL   | Kreuzkümmel       |        |              | gemahlen                   |         |
| 100 g  | Mais              |        |              | aus der Dose, abgetropft   |         |
| 100 g  | Cheddar           |        |              | gerieben                   | Menge   |
| 4 EL   | Salsa             |        |              | aus dem Glas, mittelscharf |         |
| 2 EL   | Pflanzenöl        |        |              |                            |         |
| 1 TL   | Salz              |        |              |                            |         |
| 300 ml | Wasser            |        |              |                            | nie     |

## Zubereitung

1. Reis mit Wasser und ½ TL Salz aufkochen, zugedeckt 12 Minuten bei kleinster Hitze garen, 5 Minuten quellen lassen. ⏱ 12
2. Zwiebel in 1 EL Öl 4 Minuten dünsten, Knoblauch zugeben. ⏱ 4
3. [Mit Rindhack] Hack zufügen und 6 Minuten krümelig braun braten. ⏱ 6
4. Paprikapulver, Kreuzkümmel, restliches Salz und 3 EL Salsa einrühren, 3 Minuten köcheln. ⏱ 3
5. Bohnen und Mais untermischen und 3 Minuten erwärmen. ⏱ 3
6. Tortillas kurz erwärmen, mit Reis, Füllung und Käse belegen, Seiten einschlagen und fest aufrollen.
7. In 1 EL Öl mit der Naht nach unten 2 Minuten je Seite goldbraun anbraten. ⏱ 4
8. Halbieren und mit restlicher Salsa servieren.

## Notizen

Burritos lassen sich einfrieren: einzeln in Folie wickeln, im Ofen bei 180 °C 25 Minuten aufbacken.
