# Acar Timun (Gurkenpickles)

![Acar Timun (Gurkenpickles)](../../pictures/acar-gurken.jpg)

Schnell eingelegte Gurken mit Karotte und Schalotte, ein süß-saurer Begleiter zu Sate und Reis.

## Zutaten

| Menge  | Zutat        | Gruppe | Variante | Hinweis            | Einkauf |
| ------ | ------------ | ------ | -------- | ------------------ | ------- |
| 1      | Salatgurke   |        |          | in Scheiben        |         |
| 1      | Karotte      |        |          | in dünnen Scheiben |         |
| 2      | Schalotte    |        |          | in Ringen          |         |
| 1      | Chilischoten |        |          | rot, in Ringen     |         |
| 100 ml | Reisessig    |        |          |                    |         |
| 100 ml | Wasser       |        |          |                    | nie     |
| 2 EL   | Zucker       |        |          |                    |         |
| 0,5 TL | Salz         |        |          |                    |         |

## Zubereitung

1. Essig, Wasser, Zucker und Salz erwärmen, bis sich alles gelöst hat, abkühlen lassen.
2. Gemüse in eine Schüssel geben.
3. Lake darübergießen und alles vermengen.
4. Mindestens 20 Minuten ziehen lassen. ⏱ 20

## Notizen

Im Kühlschrank 3 Tage haltbar.
