# Nasi Goreng

![Nasi Goreng](../../pictures/nasi-goreng.jpg)

Indonesischer gebratener Reis mit süßer Sojasauce (Kecap Manis), Ei und Sambal.

## Zutaten

| Menge      | Zutat            | Gruppe | Variante     | Hinweis             | Einkauf |
| ---------- | ---------------- | ------ | ------------ | ------------------- | ------- |
| 300 g      | Jasminreis       |        |              | gekocht, vom Vortag |         |
| 2 EL       | Pflanzenöl       |        |              |                     |         |
| 2          | Schalotte        |        |              | fein gehackt        |         |
| 3          | Knoblauch        |        |              | Zehen, gehackt      |         |
| 1          | Chilischoten     |        |              | rot, fein gehackt   |         |
| 200 g      | Hähnchenbrust    |        | Mit Hähnchen | in kleinen Würfeln  | Menge   |
| 100 g      | Erbsen           |        | Vegetarisch  | TK                  |         |
| 2 EL       | Kecap Manis      |        |              | süße Sojasauce      |         |
| 1 EL       | Sojasauce        |        |              |                     |         |
| 1 TL       | Sambal Oelek     |        |              |                     |         |
| 2          | Ei               |        |              |                     |         |
| 2          | Frühlingszwiebel |        |              | in Ringen           |         |
| 0,5        | Salatgurke       |        |              | in Scheiben         |         |
| 1 Handvoll | Krupuk           |        |              | Krabbenchips        |         |

## Zubereitung

1. Öl im Wok stark erhitzen, Schalotten, Knoblauch und Chili 1 Minute braten.
2. [Mit Hähnchen] Hähnchenwürfel 5 Minuten mitbraten, bis sie gar sind.
3. [Vegetarisch] Erbsen 2 Minuten mitbraten. ⏱ 5
4. Reis zugeben und 4 Minuten unter Rühren braten. ⏱ 4
5. Kecap Manis, Sojasauce und Sambal zugeben und gut vermischen.
6. Frühlingszwiebeln unterheben. Reis an den Rand schieben.
7. Spiegeleier braten, auf den Reis setzen, mit Gurke und Krupuk servieren.

## Notizen

Kecap Manis gibt es im Asia-Laden; Ersatz: Sojasauce mit braunem Zucker oder Sirup (2:1) aufkochen.
