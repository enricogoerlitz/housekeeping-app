# Sambal Tomat

![Sambal Tomat](../../pictures/sambal-tomat.jpg)

Scharfer, gekochter Tomaten-Sambal, passt zu Reis, Gebratenem und Spießen.

## Zutaten

| Menge  | Zutat        | Gruppe | Variante | Hinweis    | Einkauf |
| ------ | ------------ | ------ | -------- | ---------- | ------- |
| 3      | Tomate       |        |          | geviertelt |         |
| 4      | Chilischoten |        |          | rot        |         |
| 2      | Schalotte    |        |          |            |         |
| 2      | Knoblauch    |        |          | Zehen      |         |
| 1 EL   | Pflanzenöl   |        |          |            |         |
| 1 TL   | Palmzucker   |        |          |            |         |
| 0,5 TL | Salz         |        |          |            |         |
| 1 EL   | Limetten     |        |          | Saft       |         |

## Zubereitung

1. Tomaten, Chilis, Schalotten und Knoblauch im Öl 8 Minuten anbraten, bis sie weich werden. ⏱ 8
2. Im Mörser oder Mixer grob zerstoßen.
3. Zurück in die Pfanne geben, Zucker und Salz zugeben und 5 Minuten einkochen. ⏱ 5
4. Mit Limettensaft abschmecken.

## Notizen

Im Kühlschrank 5 Tage haltbar. Weniger Chilis für milder.
