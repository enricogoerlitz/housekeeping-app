# Mie Goreng

![Mie Goreng](../../pictures/mie-goreng.jpg)

Indonesische gebratene Nudeln mit Kecap Manis, Gemüse und Ei.

## Zutaten

| Menge | Zutat        | Gruppe | Variante     | Hinweis            | Einkauf |
| ----- | ------------ | ------ | ------------ | ------------------ | ------- |
| 250 g | Mie-Nudeln   |        |              |                    |         |
| 2 EL  | Pflanzenöl   |        |              |                    |         |
| 2     | Schalotte    |        |              | in Streifen        |         |
| 3     | Knoblauch    |        |              | Zehen, gehackt     |         |
| 200 g | Garnelen     |        | Mit Garnelen | geschält           | Menge   |
| 200 g | Tofu         |        | Vegetarisch  | gewürfelt          | Menge   |
| 0,25  | Weißkohl     |        |              | in Streifen        |         |
| 1     | Karotte      |        |              | in dünnen Streifen |         |
| 3 EL  | Kecap Manis  |        |              |                    |         |
| 1 EL  | Sojasauce    |        |              |                    |         |
| 1 TL  | Sambal Oelek |        |              |                    |         |
| 2     | Ei           |        |              |                    |         |
| 2 EL  | Röstzwiebeln |        |              |                    |         |
| 1     | Limette      |        |              | in Spalten         |         |
| 1 l   | Wasser       |        |              |                    | nie     |

## Zubereitung

1. Nudeln nach Packung bissfest kochen, abschrecken. ⏱ 4
2. Wok stark erhitzen, Öl zugeben.
3. [Mit Garnelen] Garnelen 2 Minuten braten.
4. [Vegetarisch] Tofu 4 Minuten braten, herausnehmen. ⏱ 3
5. Schalotten und Knoblauch 1 Minute braten, Kohl und Karotte 3 Minuten mitbraten. ⏱ 3
6. Nudeln, Kecap Manis, Sojasauce und Sambal zugeben und 3 Minuten durchschwenken. ⏱ 3
7. Tofu bzw. Garnelen zugeben. Spiegeleier braten.
8. Mit Ei, Röstzwiebeln und Limette servieren.

## Notizen

Mit Spaghetti statt Eiernudeln geht es zur Not auch.
