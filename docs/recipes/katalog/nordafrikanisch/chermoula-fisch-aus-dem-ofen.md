# Chermoula-Fisch aus dem Ofen

![Chermoula-Fisch aus dem Ofen](../../pictures/chermoula-fisch-aus-dem-ofen.jpg)

Weißfisch auf Tomaten und Kartoffeln mit Chermoula, der würzigen Kräuter-Zitrone-Paste aus Marokko.

## Zutaten

| Menge    | Zutat         | Gruppe    | Variante    | Hinweis                            | Einkauf |
| -------- | ------------- | --------- | ----------- | ---------------------------------- | ------- |
| 2        | Fischfilet    |           | Mit Fisch   | weiß, z. B. Seelachs oder Kabeljau | Menge   |
| 250 g    | Blumenkohl    |           | Vegetarisch | in Scheiben oder Röschen           |         |
| 400 g    | Kartoffeln    |           |             | festkochend, in dünnen Scheiben    |         |
| 200 g    | Kirschtomaten |           |             | halbiert                           |         |
| 1 Bund   | Koriander     | Chermoula |             |                                    |         |
| 1/2 Bund | Petersilie    | Chermoula |             |                                    |         |
| 3        | Knoblauch     | Chermoula |             | Zehen                              |         |
| 1 TL     | Kreuzkümmel   | Chermoula |             | gemahlen                           |         |
| 1 TL     | Paprikapulver | Chermoula |             | edelsüß                            |         |
| 1        | Zitrone       | Chermoula |             | Saft und Schale                    |         |
| 5 EL     | Olivenöl      | Chermoula |             |                                    |         |
| 50 g     | Oliven        |           |             | schwarz, entsteint                 |         |
| 1 TL     | Salz          |           |             |                                    |         |

## Zubereitung

1. Ofen auf 200 °C vorheizen.
2. Alle Chermoula-Zutaten im Mixer oder mit dem Stabmixer zu einer groben Paste verarbeiten, mit Salz abschmecken.
3. Kartoffelscheiben mit 2 EL Chermoula mischen und in einer Auflaufform 15 Minuten vorbacken. ⏱ 15
4. Tomaten und Oliven zugeben.
5. [Vegetarisch] Blumenkohl ebenfalls mit Chermoula mischen und dazugeben.
6. [Mit Fisch] Filets mit der restlichen Chermoula bestreichen und auf das Gemüse legen.
7. Backen: bei Fisch 15 Minuten, bei Blumenkohl 25 Minuten, bis alles gar ist. ⏱ 15
8. Mit Zitronenspalten servieren.

## Notizen

Chermoula hält sich im Kühlschrank 4 Tage und passt auch zu Hähnchen oder Lamm.
