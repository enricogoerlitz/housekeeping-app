# Ful Medames

![Ful Medames](../../pictures/ful-medames.jpg)

Ägyptisches Bohnenmus aus dicken Bohnen mit Zitrone, Kreuzkümmel und Olivenöl, mit Ei und Fladenbrot.

## Zutaten

| Menge    | Zutat        | Gruppe | Variante | Hinweis                      | Einkauf |
| -------- | ------------ | ------ | -------- | ---------------------------- | ------- |
| 2 Dose   | Dicke Bohnen |        |          | Ful, 400 g, nicht abgetropft |         |
| 3        | Knoblauch    |        |          | Zehen, gepresst              |         |
| 2 TL     | Kreuzkümmel  |        |          | gemahlen                     |         |
| 3 EL     | Zitronen     |        |          | Saft                         |         |
| 4 EL     | Olivenöl     |        |          |                              |         |
| 1        | Tomate       |        |          | gewürfelt                    |         |
| 2        | Ei           |        |          |                              |         |
| 1/2 Bund | Petersilie   |        |          | gehackt                      |         |
| 2        | Fladenbrot   |        |          | Pita                         |         |
| 1 TL     | Salz         |        |          |                              |         |
| 1/2 TL   | Chiliflocken |        |          |                              |         |

## Zubereitung

1. Eier 9 Minuten hart kochen, abschrecken und pellen. ⏱ 9
2. Bohnen mit Flüssigkeit, Knoblauch, Kreuzkümmel und Salz in einem Topf erhitzen und 8 Minuten köcheln. ⏱ 8
3. Mit einer Gabel zur Hälfte zerdrücken, Zitronensaft und die Hälfte des Öls einrühren.
4. In Schalen füllen und mit Tomate, Petersilie, Eierhälften, Chili und restlichem Öl toppen.
5. Mit warmem Pita servieren.

## Notizen

Ful-Bohnen gibt es im Orientladen, ersatzweise große weiße Bohnen oder Saubohnen aus dem Glas.
