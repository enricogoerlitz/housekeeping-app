# Zaalouk

![Zaalouk](../../pictures/zaalouk.jpg)

Marokkanischer Auberginen-Tomaten-Salat, warm geschmort, würzig mit Kreuzkümmel, Paprika und Knoblauch.

## Zutaten

| Menge    | Zutat         | Gruppe | Variante | Hinweis         | Einkauf |
| -------- | ------------- | ------ | -------- | --------------- | ------- |
| 2        | Aubergine     |        |          | in Würfeln      |         |
| 4        | Tomate        |        |          | reif, gewürfelt |         |
| 3        | Knoblauch     |        |          | Zehen, gepresst |         |
| 3 EL     | Olivenöl      |        |          |                 |         |
| 1 TL     | Kreuzkümmel   |        |          | gemahlen        |         |
| 1 TL     | Paprikapulver |        |          | edelsüß         |         |
| 1/2 TL   | Chiliflocken  |        |          |                 |         |
| 1 EL     | Zitronen      |        |          | Saft            |         |
| 1/2 Bund | Petersilie    |        |          |                 |         |
| 1 TL     | Salz          |        |          |                 |         |

## Zubereitung

1. Auberginenwürfel mit Salz bestreuen und 10 Minuten stehen lassen, dann abtupfen. ⏱ 10
2. In einer Pfanne in Öl bei mittlerer Hitze 8 Minuten braten. ⏱ 8
3. Knoblauch, Tomaten und Gewürze zugeben und zugedeckt 20 Minuten schmoren. ⏱ 20
4. Mit einer Gabel grob zerdrücken, mit Zitronensaft und Petersilie abschmecken.
5. Warm oder kalt mit Brot servieren.

## Notizen

Hält sich zugedeckt im Kühlschrank 3 Tage und schmeckt am nächsten Tag noch intensiver.
