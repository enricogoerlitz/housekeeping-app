# Khobz

![Khobz](../../pictures/khobz.jpg)

Marokkanisches Fladenbrot mit weicher Krume und dünner Kruste, passend zu Tajine, Zaalouk und allen Eintöpfen.

## Zutaten

| Menge      | Zutat       | Gruppe | Variante | Hinweis       | Einkauf |

| 300 g      | Weizenmehl  |        |          | Type 550      |         |
| 100 g      | Semola Mehl |        |          |               |         |
| 1 TL       | Salz        |        |          |               |         |
| 1 TL       | Zucker      |        |          |               |         |
| 1 Päckchen | Trockenhefe |        |          |               |         |
| 250 ml     | Wasser      |        |          | lauwarm       | nie     |
| 1 EL       | Olivenöl    |        |          |               |         |

## Zubereitung

1. Mehl, Grieß, Salz, Zucker und Hefe mischen, mit Wasser und Öl 10 Minuten zu einem weichen Teig kneten. ⏱ 10
2. Abgedeckt 60 Minuten gehen lassen, bis sich das Volumen verdoppelt hat. ⏱ 60
3. Teig halbieren, zu zwei runden, 2 cm dicken Fladen formen und auf einem bemehlten Blech 30 Minuten ruhen lassen. ⏱ 30
4. Ofen mit Blech oder Stein auf 230 °C vorheizen, Fladen mit Sesam bestreuen und mehrmals mit der Gabel einstechen.
5. Im Ofen 18 Minuten goldgelb backen. ⏱ 18
6. Auf einem Gitter abkühlen lassen.

## Notizen

Hartweizengrieß (Semola) im Supermarkt bei Mehl oder Pasta; ersatzweise mehr Weizenmehl.
