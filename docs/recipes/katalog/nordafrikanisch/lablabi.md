# Lablabi

![Lablabi](../../pictures/lablabi.jpg)

Tunesische Kichererbsensuppe mit Knoblauch, Kreuzkümmel und Harissa, über altbackenem Brot und Ei serviert.

## Zutaten

| Menge     | Zutat        | Gruppe | Variante      | Hinweis                                       | Einkauf |
| --------- | ------------ | ------ | ------------- | --------------------------------------------- | ------- |
| 400 g     | Kichererbsen |        |               | aus der Dose, abgetropft, Kochwasser aufheben |         |
| 500 ml    | Gemüsebrühe  |        |               |                                               |         |
| 4         | Knoblauch    |        |               | Zehen, gepresst                               |         |
| 2 TL      | Kreuzkümmel  |        |               | gemahlen                                      |         |
| 2 EL      | Olivenöl     |        |               |                                               |         |
| 2 TL      | Harissa      |        |               |                                               |         |
| 2         | Ei           |        |               |                                               |         |
| 2 Scheibe | Weißbrot     |        |               | altbacken                                     |         |
| 1         | Zitrone      |        |               | Saft                                          |         |
| 1 EL      | Kapern       |        |               |                                               |         |
| 1 Dose    | Thunfisch    |        | Mit Thunfisch | im eigenen Saft                               | 1×      |
| 1 TL      | Salz         |        |               |                                               |         |

## Zubereitung

1. Kichererbsen mit Brühe, 3 Knoblauchzehen, Kreuzkümmel und Salz 15 Minuten köcheln. ⏱ 15
2. Eier 6 Minuten wachsweich kochen und pellen. ⏱ 6
3. Brot in Stücke reißen und auf zwei tiefe Teller verteilen.
4. Suppe mit Zitronensaft und dem restlichen Knoblauch abschmecken und über das Brot schöpfen.
5. Mit Ei, Harissa, Olivenöl und Kapern belegen.
6. [Mit Thunfisch] Zusätzlich Thunfisch zupfen und darauf verteilen.

## Notizen

Harissa im Glas oder in der Tube (Supermarkt, Orientladen) ist je nach Marke sehr scharf, vorsichtig dosieren.
