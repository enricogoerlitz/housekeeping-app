# Koshari

![Koshari](../../pictures/koshari.jpg)

Ägyptisches Nationalgericht: Reis, Linsen, Nudeln und Kichererbsen mit scharfer Tomatensauce und Röstzwiebeln.

## Zutaten

| Menge  | Zutat             | Gruppe | Variante | Hinweis                  | Einkauf |
| ------ | ----------------- | ------ | -------- | ------------------------ | ------- |
| 100 g  | Basmatireis       |        |          |                          |         |
| 100 g  | Braune Linsen     |        |          |                          |         |
| 100 g  | Makkaroni         |        |          | kurz                     |         |
| 200 g  | Kichererbsen      |        |          | aus der Dose, abgetropft |         |
| 3      | Zwiebel           |        |          | in dünnen Ringen         |         |
| 5 EL   | Öl                |        |          |                          |         |
| 2 EL   | Mehl              |        |          |                          |         |
| 400 g  | Passierte Tomaten | Sauce  |          |                          |         |
| 3      | Knoblauch         | Sauce  |          | Zehen, gepresst          |         |
| 1 TL   | Kreuzkümmel       | Sauce  |          | gemahlen                 |         |
| 1/2 TL | Chiliflocken      | Sauce  |          |                          |         |
| 2 EL   | Essig             | Sauce  |          |                          |         |
| 1 TL   | Salz              |        |          |                          |         |

## Zubereitung

1. Zwiebeln mit Mehl bestäuben und in 4 EL Öl in 2 Portionen bei mittlerer Hitze 15 Minuten knusprig braun braten. ⏱ 15
2. Linsen in Salzwasser 20 Minuten kochen, abgießen. ⏱ 20
3. Reis nach Packungsanleitung kochen, Nudeln separat nach Anleitung garen. ⏱ 12
4. Knoblauch im restlichen Öl 1 Minute anschwitzen, Tomaten, Kreuzkümmel, Chili und Salz zugeben, 12 Minuten köcheln, Essig einrühren. ⏱ 12
5. Kichererbsen in der Sauce erwärmen.
6. Reis, Linsen und Nudeln in Schalen schichten, mit Tomatensauce und Röstzwiebeln krönen.

## Notizen

Eine Sauce mit Essig und Knoblauch (Daqqa) macht den Charme aus: 2 EL Essig, 1 Knoblauch, 1 TL Kreuzkümmel, etwas Wasser separat zum Beträufeln.
