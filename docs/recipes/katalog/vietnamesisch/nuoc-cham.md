# Nước Chấm

![Nước Chấm](../../pictures/nuoc-cham.jpg)

Die vietnamesische Universal-Dipsauce: süß, sauer, salzig und scharf. Passt zu Sommerrollen, Nudeln und Gegrilltem.

## Zutaten

| Menge  | Zutat        | Gruppe | Variante | Hinweis             | Einkauf |
| ------ | ------------ | ------ | -------- | ------------------- | ------- |
| 3 EL   | Fischsauce   |        |          |                     |         |
| 3 EL   | Zucker       |        |          |                     |         |
| 4 EL   | Limetten     |        |          | Saft                |         |
| 100 ml | Wasser       |        |          | warm                | nie     |
| 2      | Knoblauch    |        |          | Zehen, fein gehackt |         |
| 1      | Chilischoten |        |          | rot, fein gehackt   |         |
| 1      | Karotte      |        |          | in feinen Streifen  |         |

## Zubereitung

1. Warmes Wasser mit Zucker verrühren, bis er sich löst.
2. Fischsauce und Limettensaft zugeben.
3. Knoblauch, Chili und Karotte einrühren und 5 Minuten ziehen lassen. ⏱ 5
4. Abschmecken und in kleine Schälchen füllen.

## Notizen

Vegetarisch: Fischsauce durch Sojasauce und eine Prise Salz ersetzen. Im Kühlschrank 1 Woche haltbar.
