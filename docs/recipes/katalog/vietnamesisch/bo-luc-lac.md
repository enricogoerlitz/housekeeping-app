# Bò Lúc Lắc

![Bò Lúc Lắc](../../pictures/bo-luc-lac.jpg)

„Schüttelndes“ Rindfleisch: kräftig angebratene Würfel mit Knoblauch, Pfeffer und Limetten-Pfeffer-Dip. Vegetarisch mit Pilzen und Tofu.

## Zutaten

| Menge  | Zutat                     | Gruppe   | Variante    | Hinweis           | Einkauf |
| ------ | ------------------------- | -------- | ----------- | ----------------- | ------- |
| 350 g  | Rinderfilet               |          | Mit Rind    | in 2 cm Würfeln   | Menge   |
| 200 g  | Kräuterseitlinge          |          | Vegetarisch | in dicken Stücken |         |
| 200 g  | Tofu                      |          | Vegetarisch | gewürfelt         | Menge   |
| 3 EL   | Sojasauce                 | Marinade |             |                   |         |
| 1 EL   | Austernsauce              | Marinade | Mit Rind    |                   |         |
| 1 EL   | Vegetarische Austernsauce | Marinade | Vegetarisch |                   |         |
| 1 TL   | Zucker                    | Marinade |             |                   |         |
| 3      | Knoblauch                 | Marinade |             | Zehen, gehackt    |         |
| 1 TL   | Pfeffer                   | Marinade |             | frisch gemahlen   |         |
| 2 EL   | Pflanzenöl                |          |             |                   |         |

| 1 TL   | Salz                      | Dip      |             |                   |         |

| 250 g  | Jasminreis                |          |             |                   |         |
| 500 ml | Wasser                    |          |             |                   | nie     |

## Zubereitung

1. Fleisch bzw. Pilze und Tofu mit allen Marinadenzutaten 15 Minuten marinieren. ⏱ 15
2. Reis garen. Für den Dip Limettensaft, Salz und Pfeffer verrühren.
3. Pfanne sehr stark erhitzen, 1 EL Öl zugeben und die Zwiebel 2 Minuten anbraten, herausnehmen. ⏱ 2
4. Restliches Öl zugeben, Fleisch bzw. Pilze und Tofu in einer Schicht 2 Minuten ohne Rühren anbraten, dann schwenken und weitere 2 Minuten braten. ⏱ 4
5. Zwiebel zurückgeben, kurz schwenken.
6. Auf Kresse und Tomaten anrichten, mit Reis und Dip servieren.

## Notizen

Nur in kleinen Portionen braten, damit das Fleisch Farbe bekommt statt zu schmoren.
