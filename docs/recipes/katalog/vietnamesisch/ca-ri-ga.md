# Cà Ri Gà

![Cà Ri Gà](../../pictures/ca-ri-ga.jpg)

Mildes vietnamesisches Curry mit Zitronengras, Kokosmilch und Kartoffeln. Wird traditionell mit Baguette gegessen.

## Zutaten

| Menge     | Zutat            | Gruppe | Variante     | Hinweis          | Einkauf |
| --------- | ---------------- | ------ | ------------ | ---------------- | ------- |
| 500 g     | Hähnchenschenkel |        | Mit Hähnchen | in Stücken       | Menge   |
| 250 g     | Kichererbsen     |        | Vegetarisch  | Dose, abgetropft |         |
| 2 EL      | Currypulver      |        |              | mild             |         |
| 2 EL      | Pflanzenöl       |        |              |                  |         |
| 1         | Zwiebel          |        |              | in Spalten       |         |
| 3         | Knoblauch        |        |              | Zehen, gehackt   |         |
| 2 Stängel | Zitronengras     |        |              | angedrückt       |         |
| 300 g     | Kartoffeln       |        |              | in Würfeln       |         |
| 2         | Karotte          |        |              | in Stücken       |         |
| 400 ml    | Kokosmilch       |        |              |                  |         |
| 300 ml    | Gemüsebrühe      |        |              |                  |         |
| 1 EL      | Fischsauce       |        | Mit Hähnchen |                  |         |
| 1 EL      | Sojasauce        |        | Vegetarisch  |                  |         |
| 1 TL      | Zucker           |        |              |                  |         |
| 1         | Baguette         |        |              | zum Dippen       |         |

## Zubereitung

1. [Mit Hähnchen] Hähnchen mit Currypulver und 1 TL Salz marinieren, 15 Minuten ziehen lassen. ⏱ 15
2. Öl erhitzen, Zwiebel, Knoblauch und Zitronengras 3 Minuten anbraten. ⏱ 3
3. [Mit Hähnchen] Hähnchen 5 Minuten anbraten.
4. [Vegetarisch] Currypulver 30 Sekunden mitrösten. ⏱ 5
5. Kokosmilch, Brühe, Kartoffeln und Karotten zugeben, aufkochen und zugedeckt 25 Minuten köcheln. ⏱ 25
6. [Vegetarisch] Kichererbsen die letzten 10 Minuten mitkochen. ⏱ 10
7. Mit Fisch- bzw. Sojasauce und Zucker abschmecken, mit Baguette servieren.

## Notizen

Das Curry wird nicht scharf; Chili oder Sambal am Tisch dazu.
