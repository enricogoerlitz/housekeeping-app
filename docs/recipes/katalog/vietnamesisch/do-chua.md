# Đồ Chua (Eingelegtes Gemüse)

![Đồ Chua (Eingelegtes Gemüse)](../../pictures/do-chua.jpg)

Süß-saures Karotten-Rettich-Gemüse, passt in Bánh Mì und zu Reis- und Nudelgerichten.

## Zutaten

| Menge  | Zutat     | Gruppe | Variante | Hinweis                    | Einkauf |
| ------ | --------- | ------ | -------- | -------------------------- | ------- |
| 2      | Karotte   |        |          | in feinen Streifen         |         |
| 200 g  | Rettich   |        |          | Daikon, in feinen Streifen |         |
| 200 ml | Reisessig |        |          |                            |         |
| 200 ml | Wasser    |        |          |                            | nie     |
| 3 EL   | Zucker    |        |          |                            |         |
| 1 TL   | Salz      |        |          |                            |         |

## Zubereitung

1. Karotten und Rettich in ein Glas füllen.
2. Essig, Wasser, Zucker und Salz verrühren, bis sich alles löst.
3. Lake über das Gemüse gießen.
4. Mindestens 30 Minuten ziehen lassen, besser über Nacht. ⏱ 30

## Notizen

Im Kühlschrank 2 Wochen haltbar. Ohne Daikon: Kohlrabi oder Radieschen.
