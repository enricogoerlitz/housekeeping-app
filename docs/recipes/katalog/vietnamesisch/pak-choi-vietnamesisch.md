# Vietnamesischer Pak Choi mit Knoblauch

![Pak Choi mit Knoblauch](../../pictures/pak-choi-vietnamesisch.jpg)

Schnell gebratener Pak Choi mit viel Knoblauch, passt zu allem mit Reis.

## Zutaten

| Menge | Zutat      | Gruppe | Variante | Hinweis            | Einkauf |
| ----- | ---------- | ------ | -------- | ------------------ | ------- |
| 400 g | Pak Choi   |        |          | halbiert           |         |
| 3     | Knoblauch  |        |          | Zehen, in Scheiben |         |
| 1 EL  | Pflanzenöl |        |          |                    |         |
| 1 EL  | Sojasauce  |        |          |                    |         |
| 1 TL  | Sesamöl    |        |          |                    |         |
| 2 EL  | Wasser     |        |          |                    | nie     |

## Zubereitung

1. Wok stark erhitzen, Öl zugeben.
2. Knoblauch 20 Sekunden anbraten.
3. Pak Choi mit der Schnittfläche nach unten 2 Minuten braten. ⏱ 2
4. Sojasauce und Wasser zugeben, zugedeckt 2 Minuten dämpfen. ⏱ 2
5. Mit Sesamöl beträufeln.

## Notizen

Blätter nicht überkochen, sie sollen knackig bleiben.
