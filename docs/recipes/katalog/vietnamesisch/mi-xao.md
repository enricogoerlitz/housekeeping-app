# Mì Xào Rau

![Mì Xào Rau](../../pictures/mi-xao.jpg)

Schnell gebratene Eiernudeln mit viel Gemüse und leichter Austernsauce.

## Zutaten

| ----- | ------------------------- | ------ | ------------ | ------------------ | ------- |

| 250 g | Garnelen                  |        | Mit Garnelen | geschält           | Menge   |
| 200 g | Tofu                      |        | Vegetarisch  | gewürfelt          | Menge   |
| 2 EL  | Pflanzenöl                |        |              |                    |         |
| 3     | Knoblauch                 |        |              | Zehen, gehackt     |         |
| 1     | Karotte                   |        |              | in feinen Streifen |         |

## Zubereitung

1. Nudeln nach Packungsanleitung kochen, abschrecken, mit etwas Sesamöl mischen. ⏱ 4
2. Wok stark erhitzen, Öl zugeben.
3. [Mit Garnelen] Garnelen 2 Minuten braten.
4. [Vegetarisch] Tofu 4 Minuten braten, herausnehmen. ⏱ 3
5. Knoblauch, Karotte, Paprika und Zuckerschoten 3 Minuten braten. ⏱ 3
6. Pak Choi zugeben und 1 Minute mitbraten.
7. Nudeln, Sojasauce und Austernsauce zugeben und 2 Minuten durchschwenken. ⏱ 2
8. Garnelen bzw. Tofu zugeben, mit Frühlingszwiebeln bestreuen.

## Notizen

Beliebiges Gemüse nach Saison verwenden.
