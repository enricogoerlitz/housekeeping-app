# Orata al forno mit Kartoffeln

![Orata al forno mit Kartoffeln](../../pictures/orata-al-forno.jpg)

Ganze Dorade auf Kartoffeln und Kirschtomaten aus dem Ofen. Vegetarisch mit Fenchel und Feta.

## Zutaten

| Menge    | Zutat             | Gruppe | Variante    | Hinweis                         | Einkauf |
| -------- | ----------------- | ------ | ----------- | ------------------------------- | ------- |
| 2        | Dorade            |        | Mit Dorade  | küchenfertig, je ca. 350 g      | Menge   |
| 2        | Fenchel           |        | Vegetarisch | in Spalten                      |         |
| 100 g    | Feta              |        | Vegetarisch | in Würfeln                      |         |
| 500 g    | Kartoffeln        |        |             | festkochend, in dünnen Scheiben |         |
| 200 g    | Kirschtomaten     |        |             |                                 |         |
| 50 g     | Schwarze Oliven   |        |             |                                 |         |
| 1        | Zitrone           |        |             | in Scheiben                     |         |
| 4 EL     | Olivenöl          |        |             |                                 |         |
| 2        | Knoblauch         |        |             | Zehen, in Scheiben              |         |
| 2 Zweige | Thymian           |        |             |                                 |         |
| 1 TL     | Salz              |        |             |                                 |         |
| 1 TL     | Schwarzer Pfeffer |        |             |                                 |         |

## Zubereitung

1. Ofen auf 200 °C Ober-/Unterhitze vorheizen.
2. Kartoffeln (und Fenchel) mit 2 EL Öl, Salz, Pfeffer, Knoblauch und Thymian mischen, auf ein tiefes Blech geben und 20 Minuten vorgaren. ⏱ 20
3. [Mit Dorade] Fische innen und außen salzen, pfeffern, mit Zitronenscheiben und Thymian füllen.
4. Tomaten und Oliven zum Gemüse geben,
5. [Mit Dorade] die Fische daraufsetzen, mit 2 EL Öl beträufeln.
6. [Vegetarisch] Feta über das Gemüse bröckeln.
7. [Mit Dorade] 25 Minuten backen, bis das Fischfleisch an der Gräte weiß ist. ⏱ 25
8. [Vegetarisch] 15 Minuten weiter backen, bis alles Farbe hat. ⏱ 15
9. Mit Zitronensaft beträufelt servieren.

## Notizen

Kernthermometer: 60 °C im Fisch. Ersatz für Dorade: Wolfsbarsch (Branzino) oder Forelle.
