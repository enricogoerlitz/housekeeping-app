# Patate arrosto al rosmarino

![Patate arrosto al rosmarino](../../pictures/patate-arrosto.jpg)

Knusprige Ofenkartoffeln mit Rosmarin und Knoblauch: die klassische Beilage zu Fleisch und Fisch.

## Zutaten

| Menge    | Zutat             | Gruppe | Variante | Hinweis                       | Einkauf |
| -------- | ----------------- | ------ | -------- | ----------------------------- | ------- |
| 600 g    | Kartoffeln        |        |          | festkochend, in Spalten       |         |
| 4 EL     | Olivenöl          |        |          |                               |         |
| 2 Zweige | Rosmarin          |        |          |                               |         |
| 3        | Knoblauch         |        |          | Zehen, ungeschält, angedrückt |         |
| 1 TL     | Salz              |        |          |                               |         |
| 1 TL     | Schwarzer Pfeffer |        |          |                               |         |
| 1 TL     | Paprikapulver     |        |          |                               |         |

## Zubereitung

1. Ofen auf 220 °C Ober-/Unterhitze vorheizen.
2. Kartoffeln in Salzwasser 5 Minuten vorkochen, abgießen und kurz ausdampfen lassen. ⏱ 5
3. Mit Öl, Salz, Pfeffer und Paprika mischen und auf einem Blech verteilen, Rosmarin und Knoblauch dazugeben.
4. 35–40 Minuten backen, einmal wenden, bis sie goldbraun und knusprig sind. ⏱ 38

## Notizen

Das Vorkochen macht sie knuspriger.
