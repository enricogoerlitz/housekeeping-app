# Cannelloni mit Ricotta und Spinat

![Cannelloni mit Ricotta und Spinat](../../pictures/cannelloni-ricotta-spinat.jpg)

Röhrennudeln, gefüllt mit Ricotta und Spinat, mit Tomatensauce und Béchamel im Ofen gebacken.

## Zutaten

| Menge   | Zutat             | Gruppe   | Variante        | Hinweis                       | Einkauf |
| ------- | ----------------- | -------- | --------------- | ----------------------------- | ------- |
| 8       | Cannelloni        |          |                 | Röhrchen, ohne Vorkochen      |         |
| 250 g   | Blattspinat       |          |                 | TK, aufgetaut und ausgedrückt |         |
| 250 g   | Ricotta           |          |                 |                               |         |
| 150 g   | Rinderhackfleisch |          | Mit Hackfleisch |                               | Menge   |
| 1       | Zwiebel           |          |                 | gewürfelt                     |         |
| 1 EL    | Olivenöl          |          |                 |                               |         |
| 1       | Knoblauch         |          |                 | Zehe                          |         |
| 30 g    | Parmesan          |          |                 | gerieben                      | Menge   |
| 1 Prise | Muskat            |          |                 |                               |         |
| 400 g   | Passierte Tomaten | Sauce    |                 |                               |         |
| 20 g    | Butter            | Béchamel |                 |                               |         |
| 20 g    | Mehl              | Béchamel |                 |                               |         |
| 250 ml  | Milch             | Béchamel |                 |                               |         |
| 1 TL    | Salz              |          |                 |                               |         |
| 1 TL    | Schwarzer Pfeffer |          |                 |                               |         |

## Zubereitung

1. Ofen auf 190 °C Ober-/Unterhitze vorheizen.
2. [Mit Hackfleisch] Hack in Öl 6 Minuten krümelig braten, Zwiebel und Knoblauch mitbraten. ⏱ 6
3. Spinat mit Ricotta, Parmesan, Muskat, Salz und Pfeffer mischen (und Hackfleisch unterheben, falls verwendet).
4. Béchamel: Butter schmelzen, Mehl 1 Minute anschwitzen, Milch unter Rühren zugeben und 5 Minuten köcheln, würzen. ⏱ 5
5. Tomatensauce mit Salz in der Form verteilen. Füllung mit einem Löffel oder Spritzbeutel in die Röhrchen füllen und nebeneinander einlegen.
6. Béchamel darüber verteilen, mit etwas Parmesan bestreuen.
7. 35 Minuten backen, bis die Oberfläche goldbraun ist. ⏱ 35

## Notizen

Frischen Spinat (400 g) kurz in der Pfanne zusammenfallen lassen und gut ausdrücken. Ersatz für Ricotta: körniger Frischkäse.
