# Tiramisu

![Tiramisu](../../pictures/tiramisu.jpg)

Das klassische Tiramisu mit Mascarpone, Eigelb und Espresso, ohne Sahne. Muss mindestens 6 Stunden durchziehen.

## Zutaten

| Menge  | Zutat          | Gruppe | Variante | Hinweis     | Einkauf |
| ------ | -------------- | ------ | -------- | ----------- | ------- |
| 2      | Eier           |        |          | sehr frisch |         |
| 40 g   | Zucker         |        |          |             |         |
| 250 g  | Mascarpone     |        |          |             |         |
| 150 ml | Espresso       |        |          | kalt        |         |
| 2 EL   | Amaretto       |        |          | optional    |         |
| 12     | Löffelbiskuits |        |          | Savoiardi   |         |
| 2 EL   | Kakaopulver    |        |          |             |         |

## Zubereitung

1. Eigelb mit Zucker 5 Minuten hell und cremig aufschlagen. ⏱ 5
2. Mascarpone glattrühren und unter die Eigelbmasse heben.
3. Espresso mit Amaretto mischen. Löffelbiskuits kurz eintauchen (nicht einweichen) und eine kleine Form auslegen.
4. Hälfte der Creme darauf streichen, zweite Lage Biskuits, restliche Creme glatt streichen.
5. Mindestens 6 Stunden, besser über Nacht, kalt stellen. ⏱ 360
6. Vor dem Servieren mit Kakao bestäuben.

## Notizen

Rohes Eigelb: nur sehr frische Eier verwenden; für Schwangere und Kinder nicht geeignet. Ohne Alkohol: Amaretto weglassen.
