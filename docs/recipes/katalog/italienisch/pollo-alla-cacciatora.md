# Pollo alla cacciatora

![Pollo alla cacciatora](../../pictures/pollo-alla-cacciatora.jpg)

Hähnchenkeulen nach Jägerart: geschmort mit Tomaten, Wein, Oliven und Rosmarin.

## Zutaten

| Menge   | Zutat             | Gruppe | Variante     | Hinweis                          | Einkauf |
| ------- | ----------------- | ------ | ------------ | -------------------------------- | ------- |
| 4       | Hähnchenkeulen    |        | Mit Hähnchen | Ober- und Unterschenkel getrennt | Menge   |
| 250 g   | Kräuterseitlinge  |        | Vegetarisch  | in dicken Scheiben               |         |
| 2 EL    | Olivenöl          |        |              |                                  |         |
| 1       | Zwiebel           |        |              | in Streifen                      |         |
| 1       | Paprika           |        |              | rot, in Streifen                 |         |
| 2       | Knoblauch         |        |              | Zehen                            |         |
| 100 ml  | Rotwein           |        |              |                                  |         |
| 400 g   | Gehackte Tomaten  |        |              | Dose                             |         |
| 1 Zweig | Rosmarin          |        |              |                                  |         |
| 50 g    | Schwarze Oliven   |        |              | entsteint                        |         |
| 1 EL    | Kapern            |        |              |                                  |         |
| 1 TL    | Salz              |        |              |                                  |         |
| 1 TL    | Schwarzer Pfeffer |        |              |                                  |         |

## Zubereitung

1. [Mit Hähnchen] Keulen salzen, pfeffern und in 1 EL Öl rundum 8 Minuten braun anbraten, herausnehmen. ⏱ 8
2. [Vegetarisch] Pilze in 1 EL Öl 7 Minuten kräftig braun braten, herausnehmen. ⏱ 7
3. Im Bratfett Zwiebel und Paprika 5 Minuten anbraten, Knoblauch kurz mitbraten. ⏱ 5
4. Mit Rotwein ablöschen und halb einkochen lassen. Tomaten, Rosmarin, Salz zugeben.
5. [Mit Hähnchen] Keulen zurücklegen, zugedeckt 35 Minuten bei kleiner Hitze schmoren. ⏱ 35
6. [Vegetarisch] Pilze zurücklegen und 15 Minuten ohne Deckel köcheln lassen. ⏱ 15
7. Oliven und Kapern unterrühren, 5 Minuten ziehen lassen und mit Brot oder Polenta servieren.

## Notizen

Hähnchenschenkel mit Knochen bleiben saftiger als Brust. Rotwein lässt sich durch Brühe ersetzen.
