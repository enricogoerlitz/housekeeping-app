# Gamberi alla busara

![Gamberi alla busara](../../pictures/gamberi-alla-busara.jpg)

Garnelen in Tomaten-Knoblauch-Sauce mit einem Schuss Weißwein, dazu Brot zum Auftunken. Vegetarisch mit Zucchini und weißen Bohnen.

## Zutaten

| Menge      | Zutat            | Gruppe | Variante     | Hinweis                             | Einkauf |
| ---------- | ---------------- | ------ | ------------ | ----------------------------------- | ------- |
| 300 g      | Garnelen         |        | Mit Garnelen | mit Schale oder geschält, aufgetaut | Menge   |
| 1          | Zucchini         |        | Vegetarisch  | in Halbmonden                       |         |
| 1 Dose     | Weiße Bohnen     |        | Vegetarisch  | abgetropft                          |         |
| 2 EL       | Olivenöl         |        |              |                                     |         |
| 3          | Knoblauch        |        |              | Zehen, gehackt                      |         |
| 1          | Chilischote      |        |              | fein gehackt                        |         |
| 80 ml      | Weißwein         |        |              | trocken                             |         |
| 400 g      | Gehackte Tomaten |        |              | Dose                                |         |
| 2 EL       | Petersilie       |        |              | gehackt                             |         |
| 4 Scheiben | Ciabatta         |        |              |                                     |         |
| 1 TL       | Salz             |        |              |                                     |         |

## Zubereitung

1. Öl erhitzen, Knoblauch und Chili 30 Sekunden anschwitzen.
2. [Mit Garnelen] Garnelen zugeben und 1 Minute pro Seite braten, herausnehmen.
3. [Vegetarisch] Zucchini 5 Minuten braten, bis sie Farbe nimmt. ⏱ 5
4. Mit Wein ablöschen, Tomaten und Salz zugeben und 10 Minuten einköcheln. ⏱ 10
5. [Mit Garnelen] Garnelen zurück in die Sauce geben und 2 Minuten ziehen lassen. ⏱ 2
6. [Vegetarisch] Bohnen zugeben und 5 Minuten mitköcheln. ⏱ 5
7. Ciabatta toasten, Petersilie über das Gericht streuen und mit Brot servieren.

## Notizen

Garnelen mit Schale geben mehr Aroma. Ersatz für Weißwein: Gemüsebrühe.
