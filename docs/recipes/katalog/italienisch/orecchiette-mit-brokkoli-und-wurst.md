# Orecchiette mit Brokkoli und Wurst

![Orecchiette mit Brokkoli und Wurst](../../pictures/orecchiette-mit-brokkoli-und-wurst.jpg)

Apulische Hausmannskost: Der Brokkoli wird mit den Nudeln gekocht und zerfällt zur Sauce, dazu Salsiccia oder Sardellen.

## Zutaten

| Menge | Zutat       | Gruppe | Variante      | Hinweis                         | Einkauf |
| ----- | ----------- | ------ | ------------- | ------------------------------- | ------- |
| 200 g | Orecchiette |        |               |                                 |         |
| 400 g | Brokkoli    |        |               | in kleine Röschen               |         |
| 2     | Salsiccia   |        | Mit Salsiccia | Brät herausgedrückt, in Stücken | Menge   |
| 2 EL  | Kapern      |        | Vegetarisch   | abgetropft                      |         |
| 3     | Knoblauch   |        |               | Zehen, in Scheiben              |         |
| 1     | Chilischote |        |               | getrocknet, zerbröselt          |         |
| 4 EL  | Olivenöl    |        |               |                                 |         |
| 30 g  | Pecorino    |        |               | gerieben                        | Menge   |
| 1 TL  | Salz        |        |               |                                 |         |
| 2 l   | Wasser      |        |               |                                 | nie     |

## Zubereitung

1. Wasser kräftig salzen, aufkochen. Orecchiette hineingeben und 5 Minuten garen. ⏱ 5
2. Brokkoli zu den Nudeln geben und weitere 5–6 Minuten mitkochen, bis alles weich ist. ⏱ 6
3. [Mit Salsiccia] Währenddessen Salsiccia in 2 EL Öl 6 Minuten krümelig braun braten, dann Knoblauch und Chili 1 Minute mitbraten. ⏱ 6
4. [Vegetarisch] Währenddessen 4 EL Öl mit Knoblauch, Chili und Kapern bei niedriger Hitze 3 Minuten erwärmen.
5. Nudeln und Brokkoli mit einer Kelle Nudelwasser abgießen, in die Pfanne geben und 2 Minuten schwenken; den Brokkoli dabei leicht zerdrücken.
6. Mit Pecorino bestreut servieren.

## Notizen

Frische Orecchiette im Kühlregal brauchen nur 3 Minuten.
