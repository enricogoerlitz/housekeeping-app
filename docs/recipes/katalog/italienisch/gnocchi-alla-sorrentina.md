# Gnocchi alla sorrentina

![Gnocchi alla sorrentina](../../pictures/gnocchi-alla-sorrentina.jpg)

Gnocchi in Tomatensauce, mit Mozzarella überbacken, aus dem Ofen: ein neapolitanischer Soulfood-Klassiker.

## Zutaten

| Menge      | Zutat             | Gruppe | Variante      | Hinweis           | Einkauf |
| ---------- | ----------------- | ------ | ------------- | ----------------- | ------- |
| 500 g      | Gnocchi           |        |               | aus dem Kühlregal |         |
| 1          | Zwiebel           |        |               | fein gewürfelt    |         |
| 2          | Knoblauch         |        |               | Zehen, gehackt    |         |
| 2 EL       | Olivenöl          |        |               |                   |         |

## Zubereitung

1. Ofen auf 220 °C Ober-/Unterhitze vorheizen.
2. Öl erhitzen,
3. [Mit Salsiccia] zuerst Salsiccia 5 Minuten krümelig anbraten, dann Zwiebel 3 Minuten glasig dünsten, Knoblauch 30 Sekunden mitbraten. ⏱ 8
4. Passierte Tomaten, Salz und Zucker zugeben, 10 Minuten einköcheln lassen. ⏱ 10
5. Gnocchi in kochendem Salzwasser garen, bis sie aufsteigen (ca. 2 Minuten), abgießen.
6. Gnocchi mit der Sauce mischen, in eine Auflaufform geben, Mozzarella und Parmesan darüber verteilen.
7. Im Ofen 12–15 Minuten überbacken, bis der Käse Blasen wirft und goldene Stellen hat. ⏱ 14
8. Mit Basilikum bestreut servieren.

## Notizen

Mozzarella gut abtropfen lassen, sonst wird die Sauce wässrig.
