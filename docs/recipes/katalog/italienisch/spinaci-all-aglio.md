# Spinaci all'aglio

![Spinaci all'aglio](../../pictures/spinaci-all-aglio.jpg)

Blattspinat, in Olivenöl mit Knoblauch und Chili gebraten: in 15 Minuten fertig.

## Zutaten

| Menge   | Zutat        | Gruppe | Variante | Hinweis            | Einkauf |
| ------- | ------------ | ------ | -------- | ------------------ | ------- |
| 400 g   | Blattspinat  |        |          | frisch, gewaschen  |         |
| 3 EL    | Olivenöl     |        |          |                    |         |
| 2       | Knoblauch    |        |          | Zehen, in Scheiben |         |
| 1 Prise | Chiliflocken |        |          |                    |         |
| 0,5     | Zitrone      |        |          | Saft               |         |
| 1 TL    | Salz         |        |          |                    |         |

## Zubereitung

1. Öl mit Knoblauch und Chili bei mittlerer Hitze 1 Minute erwärmen.
2. Spinat portionsweise zugeben und 3–4 Minuten zusammenfallen lassen. ⏱ 4
3. Salzen und mit Zitronensaft abschmecken.

## Notizen

Tiefkühlspinat geht auch, vorher gut ausdrücken.
