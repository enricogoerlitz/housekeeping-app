# Focaccia genovese

![Focaccia genovese](../../pictures/focaccia-genovese.jpg)

Weiche, luftige Focaccia mit knuspriger Kruste, Olivenöl und Meersalz: ein Fladenbrot aus Ligurien.

## Zutaten

| Menge        | Zutat       | Gruppe | Variante | Hinweis  | Einkauf |
| ------------ | ----------- | ------ | -------- | -------- | ------- |
| 300 g        | Mehl        |        |          | Type 550 |         |
| 210 ml       | Wasser      |        |          | lauwarm  | nie     |
| 0,5 Päckchen | Trockenhefe |        |          |          |         |
| 1 TL         | Salz        |        |          |          |         |
| 1 TL         | Zucker      |        |          |          |         |
| 5 EL         | Olivenöl    |        |          |          |         |
| 1 TL         | Meersalz    |        |          | grob     |         |
| 1 Zweig      | Rosmarin    |        |          |          |         |

## Zubereitung

1. Mehl, Hefe, Salz und Zucker mischen, Wasser und 2 EL Öl zugeben, 5 Minuten kneten. 1 Stunde zugedeckt gehen lassen. ⏱ 60
2. Eine Form oder ein Blech mit 2 EL Öl einfetten, Teig dehnen und 30 Minuten ruhen lassen. ⏱ 30
3. Ofen auf 220 °C Ober-/Unterhitze vorheizen.
4. Mit den Fingern tiefe Mulden eindrücken, mit 1 EL Öl und 2 EL Salzwasser (Öl-Wasser-Mix) beträufeln, Rosmarin und Salz aufstreuen.
5. 20–25 Minuten goldbraun backen. ⏱ 22
6. Warm in Stücken servieren.

## Notizen

Als Beilage zu Suppen und Antipasti. Alternativ mit Kirschtomaten oder Oliven belegen.
