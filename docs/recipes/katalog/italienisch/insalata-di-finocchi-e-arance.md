# Insalata di finocchi e arance

![Insalata di finocchi e arance](../../pictures/insalata-di-finocchi-e-arance.jpg)

Knackiger Fenchel mit Orange, Oliven und roten Zwiebeln: ein frischer sizilianischer Salat.

## Zutaten

| Menge   | Zutat             | Gruppe | Variante | Hinweis                     | Einkauf |
| ------- | ----------------- | ------ | -------- | --------------------------- | ------- |
| 1       | Fenchel           |        |          | hauchdünn gehobelt          |         |
| 2       | Orangen           |        |          | filetiert, Saft aufgefangen |         |
| 0,5     | Rote Zwiebel      |        |          | in dünnen Ringen            |         |
| 30 g    | Schwarze Oliven   |        |          |                             |         |
| 2 EL    | Olivenöl          |        |          |                             |         |
| 1 TL    | Zitronen          |        |          | Saft                        |         |
| 1 Prise | Salz              |        |          |                             |         |
| 1 Prise | Schwarzer Pfeffer |        |          |                             |         |

## Zubereitung

1. Fenchel hobeln, Grün beiseitelegen. Orangen filetieren.
2. Zwiebelringe 5 Minuten in kaltem Wasser wässern. ⏱ 5
3. Öl, Orangensaft, Zitronensaft, Salz und Pfeffer verrühren.
4. Alles mischen, 10 Minuten ziehen lassen und mit Fenchelgrün servieren. ⏱ 10

## Notizen

Passt gut zu gebratenem Fisch.
