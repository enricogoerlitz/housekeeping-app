# Spaghetti alla Carbonara

![Spaghetti alla Carbonara](../../pictures/spaghetti-alla-carbonara.jpg)

Das römische Original ohne Sahne: Eigelb, Pecorino und Nudelwasser werden zu einer seidigen Sauce, Guanciale liefert Würze und Knusper.

## Zutaten

| Menge | Zutat             | Gruppe | Variante      | Hinweis               | Einkauf |
| ----- | ----------------- | ------ | ------------- | --------------------- | ------- |
| 200 g | Spaghetti         |        |               |                       |         |
| 120 g | Guanciale         |        | Mit Guanciale | in Streifen           | Menge   |
| 1     | Zucchini          |        | Vegetarisch   | in feinen Halbmonden  |         |
| 1 EL  | Olivenöl          |        | Vegetarisch   |                       |         |
| 3     | Eier              |        |               |                       |         |
| 1     | Ei                |        |               |                       |         |
| 60 g  | Pecorino          |        |               | fein gerieben         | Menge   |
| 1 TL  | Schwarzer Pfeffer |        |               | frisch gemahlen, grob |         |
| 1 TL  | Salz              |        |               | fürs Nudelwasser      |         |
| 2 l   | Wasser            |        |               |                       | nie     |

## Zubereitung

1. Nudelwasser in einem großen Topf aufkochen und salzen.
2. Eigelb, Ei, Pecorino und reichlich Pfeffer in einer Schüssel zu einer dicken Creme verrühren.
3. [Mit Guanciale] Guanciale in einer kalten Pfanne bei mittlerer Hitze 8 Minuten auslassen, bis er goldbraun und knusprig ist. ⏱ 8
4. [Vegetarisch] Olivenöl erhitzen, Zucchini 6 Minuten kräftig goldbraun braten, salzen und pfeffern. ⏱ 6
5. Spaghetti im Salzwasser 1 Minute kürzer als auf der Packung angegeben garen. ⏱ 9
6. Vor dem Abgießen eine Tasse Nudelwasser abschöpfen. Spaghetti direkt in die Pfanne zum Fett (Pfanne vom Herd nehmen) geben.
7. Eicreme mit 4 EL Nudelwasser glatt rühren, über die Nudeln gießen und zügig schwenken, bis eine cremige Sauce entsteht. Bei Bedarf mit etwas Nudelwasser lockern.
8. Sofort servieren, mit Pfeffer und etwas Pecorino bestreuen.

## Notizen

Pfanne unbedingt vom Herd nehmen, sonst gerinnt das Ei. Ersatz für Guanciale: Pancetta oder durchwachsener Speck. Ersatz für Pecorino: Parmesan (milder).
