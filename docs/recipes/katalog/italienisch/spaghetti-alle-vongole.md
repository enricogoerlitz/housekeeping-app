# Spaghetti alle vongole

![Spaghetti alle vongole](../../pictures/spaghetti-alle-vongole.jpg)

Spaghetti mit Venusmuscheln in Weißwein, Knoblauch und Petersilie. Vegetarisch mit Zucchini und Kapern.

## Zutaten

| Menge  | Zutat         | Gruppe | Variante          | Hinweis                 | Einkauf |
| ------ | ------------- | ------ | ----------------- | ----------------------- | ------- |
| 200 g  | Spaghetti     |        |                   |                         |         |
| 600 g  | Venusmuscheln |        | Mit Venusmuscheln | frisch oder tiefgekühlt | Menge   |
| 1      | Zucchini      |        | Vegetarisch       | in dünne Streifen       |         |
| 1 EL   | Kapern        |        | Vegetarisch       |                         |         |
| 3      | Knoblauch     |        |                   | Zehen, in Scheiben      |         |
| 1      | Chilischote   |        |                   | frisch, entkernt, fein  |         |
| 4 EL   | Olivenöl      |        |                   |                         |         |
| 100 ml | Weißwein      |        |                   | trocken                 |         |
| 3 EL   | Petersilie    |        |                   | gehackt                 |         |
| 1 TL   | Salz          |        |                   |                         |         |
| 2 l    | Wasser        |        |                   |                         | nie     |

## Zubereitung

1. [Mit Venusmuscheln] Muscheln 20 Minuten in kaltem Wasser wässern, offene aussortieren. ⏱ 20
2. Spaghetti in Salzwasser 2 Minuten kürzer als angegeben kochen. ⏱ 8
3. Öl mit Knoblauch und Chili bei mittlerer Hitze 1 Minute erwärmen.
4. [Mit Venusmuscheln] Muscheln und Wein zugeben, Deckel auflegen, 4–5 Minuten garen, bis sich die Muscheln öffnen; geschlossene wegwerfen. ⏱ 5
5. [Vegetarisch] Zucchini 4 Minuten braten, Wein und Kapern zugeben und 2 Minuten einköcheln. ⏱ 6
6. Spaghetti mit etwas Nudelwasser zugeben, 1 Minute schwenken, Petersilie untermischen und sofort servieren.

## Notizen

Auf Parmesan wird bei Meeresfrüchte-Pasta verzichtet. Tiefgekühlte Venusmuscheln im Beutel gibt es im Supermarkt.
