# Cacio e Pepe

![Cacio e Pepe](../../pictures/cacio-e-pepe.jpg)

Nur drei Zutaten: Pasta, Pecorino und Pfeffer. Die Sauce entsteht allein aus Käse und stärkehaltigem Nudelwasser.

## Zutaten

| Menge | Zutat             | Gruppe | Variante | Hinweis                             | Einkauf |
| ----- | ----------------- | ------ | -------- | ----------------------------------- | ------- |
| 200 g | Spaghetti         |        |          |                                     |         |
| 80 g  | Pecorino          |        |          | sehr fein gerieben                  | Menge   |
| 2 TL  | Schwarzer Pfeffer |        |          | ganze Körner, frisch grob gemörsert |         |
| 1 TL  | Salz              |        |          | fürs Nudelwasser                    |         |
| 1,5 l | Wasser            |        |          |                                     | nie     |

## Zubereitung

1. Pfeffer in einer breiten Pfanne ohne Fett 1 Minute rösten, bis er duftet.
2. Spaghetti in nur 1,5 l gesalzenem Wasser (weniger Wasser = stärkehaltiger) 1 Minute kürzer als angegeben garen. ⏱ 9
3. Eine Kelle Nudelwasser zum Pfeffer geben, Spaghetti mit der Zange direkt dazuheben.
4. Pecorino in einer Schüssel mit 5 EL lauwarmem Nudelwasser zu einer glatten Creme verrühren.
5. Pfanne vom Herd nehmen, Käsecreme zu den Nudeln geben und kräftig schwenken, bis die Sauce cremig bindet. Mit Nudelwasser nachjustieren.
6. Sofort auf vorgewärmten Tellern servieren.

## Notizen

Den Käse unbedingt sehr fein reiben und nie auf heißer Flamme zugeben, sonst klumpt er. Ersatz: halb Pecorino, halb Parmesan.
