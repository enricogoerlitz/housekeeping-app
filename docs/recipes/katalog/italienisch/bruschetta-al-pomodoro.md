# Bruschetta al pomodoro

![Bruschetta al pomodoro](../../pictures/bruschetta-al-pomodoro.jpg)

Geröstetes Brot mit Tomatenwürfeln, Knoblauch und Basilikum: einfach, aber nur gut mit reifen Tomaten.

## Zutaten

| Menge      | Zutat             | Gruppe | Variante | Hinweis           | Einkauf |
| ---------- | ----------------- | ------ | -------- | ----------------- | ------- |
| 4 Scheiben | Ciabatta          |        |          | oder Landbrot     |         |
| 300 g      | Tomaten           |        |          | reife, in Würfeln |         |
| 1          | Knoblauch         |        |          | Zehe, halbiert    |         |
| 2 EL       | Olivenöl          |        |          |                   |         |
| 1 Handvoll | Basilikum         |        |          |                   |         |
| 1 Prise    | Salz              |        |          |                   |         |
| 1 Prise    | Schwarzer Pfeffer |        |          |                   |         |

## Zubereitung

1. Tomaten mit 1 EL Öl, Salz, Pfeffer und gezupftem Basilikum mischen, 10 Minuten ziehen lassen. ⏱ 10
2. Brot im Toaster oder auf dem Grill rösten.
3. Heiße Scheiben mit der Knoblauchzehe einreiben, mit Öl beträufeln.
4. Tomatenmischung darauf verteilen und sofort servieren.

## Notizen

Im Winter besser Kirschtomaten verwenden.
