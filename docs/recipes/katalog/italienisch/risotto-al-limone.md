# Risotto al limone

![Risotto al limone](../../pictures/risotto-al-limone.jpg)

Frisches Zitronenrisotto, leicht und cremig, mit Garnelen ein feines Sommergericht.

## Zutaten

| Menge      | Zutat             | Gruppe | Variante     | Hinweis                 | Einkauf |
| ---------- | ----------------- | ------ | ------------ | ----------------------- | ------- |
| 160 g      | Risottoreis       |        |              |                         |         |
| 1          | Zwiebel           |        |              | fein gewürfelt          |         |
| 2 EL       | Olivenöl          |        |              |                         |         |
| 80 ml      | Weißwein          |        |              | trocken                 |         |
| 750 ml     | Gemüsebrühe       |        |              | heiß                    |         |
| 1          | Zitrone           |        |              | Schale abgerieben, Saft |         |
| 30 g       | Butter            |        |              | kalt                    |         |
| 50 g       | Parmesan          |        |              | gerieben                | Menge   |
| 200 g      | Garnelen          |        | Mit Garnelen | geschält, aufgetaut     | Menge   |
| 1 Handvoll | Basilikum         |        |              |                         |         |
| 1 TL       | Salz              |        |              |                         |         |
| 1 TL       | Schwarzer Pfeffer |        |              |                         |         |

## Zubereitung

1. 1 EL Öl erhitzen, Zwiebel 3 Minuten glasig dünsten, Reis zugeben und 1 Minute anrösten. ⏱ 3
2. Mit Wein ablöschen, einkochen lassen, dann kellenweise Brühe zugeben und unter Rühren etwa 18 Minuten garen. ⏱ 18
3. [Mit Garnelen] Garnelen in 1 EL Öl 2 Minuten pro Seite braten, salzen und pfeffern. ⏱ 4
4. Vom Herd nehmen, Zitronenschale, 2 EL Saft, Butter und Parmesan einrühren, abschmecken.
5. Mit Basilikum (und Garnelen) anrichten.

## Notizen

Zitrone erst am Ende zugeben, sonst wird sie bitter. Nur unbehandelte Zitronen für die Schale nehmen.
