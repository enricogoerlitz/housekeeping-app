# Ribollita

![Ribollita](../../pictures/ribollita.jpg)

Toskanische Brotsuppe mit weißen Bohnen und Schwarzkohl, so dick, dass der Löffel fast steht.

## Zutaten

| Menge      | Zutat             | Gruppe | Variante     | Hinweis                       | Einkauf |

| 2          | Karotte           |        |              | gewürfelt                     |         |
| 2 Stangen  | Staudensellerie   |        |              | gewürfelt                     |         |
| 2          | Knoblauch         |        |              | Zehen                         |         |

## Zubereitung

1. [Mit Pancetta] Pancetta in 1 EL Öl 4 Minuten auslassen. ⏱ 4
2. Öl, Zwiebel, Karotten, Sellerie 8 Minuten sanft anschwitzen, Knoblauch zugeben. ⏱ 8
3. Tomaten, Brühe und Thymian zugeben, 10 Minuten köcheln. ⏱ 10
4. Grünkohl und Bohnen (die Hälfte püriert) zugeben und 25 Minuten leise garen. ⏱ 25
5. Brotwürfel unterrühren, weitere 10 Minuten ziehen lassen, bis die Suppe dick ist. ⏱ 10
6. Abschmecken und mit kräftigem Olivenöl servieren.

## Notizen

Ribollita heißt „wieder aufgekocht“: am Folgetag in der Pfanne aufgewärmt ist sie am besten. Ersatz für Schwarzkohl: Wirsing.
