# Panna cotta mit Beerensauce

![Panna cotta mit Beerensauce](../../pictures/panna-cotta.jpg)

Zarte Vanille-Panna-cotta mit fruchtiger Beerensauce, am Vortag vorbereitet.

## Zutaten

| Menge   | Zutat         | Gruppe | Variante | Hinweis                      | Einkauf |
| ------- | ------------- | ------ | -------- | ---------------------------- | ------- |
| 200 ml  | Sahne         |        |          |                              |         |
| 100 ml  | Milch         |        |          |                              |         |
| 40 g    | Zucker        |        |          |                              |         |
| 1       | Vanilleschote |        |          | Mark ausgekratzt             |         |
| 2 Blatt | Gelatine      |        |          |                              |         |
| 150 g   | TK-Beeren     | Sauce  |          | frisch oder TK, TK, gemischt |         |
| 2 EL    | Zucker        | Sauce  |          |                              |         |
| 1 EL    | Zitronen      | Sauce  |          | Saft                         |         |

## Zubereitung

1. Gelatine 5 Minuten in kaltem Wasser einweichen. ⏱ 5
2. Sahne, Milch, Zucker, Vanillemark und Schote aufkochen und 5 Minuten bei kleiner Hitze ziehen lassen, Schote entfernen. ⏱ 5
3. Gelatine ausdrücken und in der warmen Sahne auflösen.
4. In zwei Förmchen füllen und mindestens 4 Stunden kalt stellen. ⏱ 240
5. Beeren mit Zucker und Zitronensaft 5 Minuten köcheln, abkühlen lassen.
6. Förmchen kurz in heißes Wasser tauchen, stürzen und mit Sauce servieren.

## Notizen

Das Ergebnis soll zittern, aber stehen bleiben. Ohne Gelatine: Agar-Agar nach Packung.
