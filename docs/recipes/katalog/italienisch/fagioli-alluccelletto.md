# Fagioli all'uccelletto

![Fagioli all'uccelletto](../../pictures/fagioli-alluccelletto.jpg)

Weiße Bohnen, in Tomaten mit Salbei und Knoblauch geschmort: eine einfache toskanische Beilage.

## Zutaten

| Menge   | Zutat             | Gruppe | Variante | Hinweis            | Einkauf |
| ------- | ----------------- | ------ | -------- | ------------------ | ------- |
| 1 Dose  | Weiße Bohnen      |        |          | abgetropft         |         |
| 2 EL    | Olivenöl          |        |          |                    |         |
| 2       | Knoblauch         |        |          | Zehen, in Scheiben |         |
| 6       | Salbei            |        |          | Blätter            |         |
| 150 g   | Passierte Tomaten |        |          |                    |         |
| 1 TL    | Salz              |        |          |                    |         |
| 1 Prise | Schwarzer Pfeffer |        |          |                    |         |

## Zubereitung

1. Öl mit Knoblauch und Salbei bei mittlerer Hitze 2 Minuten erwärmen.
2. Passierte Tomaten zugeben, 5 Minuten köcheln lassen. ⏱ 5
3. Bohnen unterrühren und 12 Minuten leise schmoren, bis die Sauce dick ist. ⏱ 12
4. Salzen, pfeffern und mit einem Schuss Olivenöl servieren.

## Notizen

Passt zu Wurst, Brot oder Polenta.
