# Panzanella

![Panzanella](../../pictures/panzanella.jpg)

Toskanischer Brotsalat mit reifen Tomaten, Gurke, Zwiebel und Basilikum: eine gute Resteverwertung für altes Brot.

## Zutaten

| Menge      | Zutat             | Gruppe | Variante | Hinweis              | Einkauf |
| ---------- | ----------------- | ------ | -------- | -------------------- | ------- |
| 200 g      | Weißbrot          |        |          | Ciabatta, in Würfeln |         |
| 400 g      | Tomaten           |        |          | reife, in Stücken    |         |
| 0,5        | Salatgurke        |        |          | in Würfeln           |         |
| 0,5        | Rote Zwiebel      |        |          | in dünnen Ringen     |         |
| 4 EL       | Olivenöl          |        |          |                      |         |
| 2 EL       | Rotweinessig      |        |          |                      |         |
| 1 Handvoll | Basilikum         |        |          |                      |         |
| 1 TL       | Salz              |        |          |                      |         |
| 1 Prise    | Schwarzer Pfeffer |        |          |                      |         |

## Zubereitung

1. Brotwürfel in 2 EL Öl in der Pfanne 6 Minuten goldbraun rösten. ⏱ 6
2. Tomaten, Gurke und Zwiebel mit Salz mischen und 10 Minuten Saft ziehen lassen. ⏱ 10
3. Essig, 2 EL Öl und Pfeffer zugeben, Brot und Basilikum unterheben.
4. 15 Minuten durchziehen lassen und servieren. ⏱ 15

## Notizen

Mit Mozzarella wird daraus eine Hauptspeise. Brot nicht zu früh untermischen.
