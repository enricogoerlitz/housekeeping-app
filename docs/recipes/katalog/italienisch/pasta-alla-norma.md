# Pasta alla Norma

![Pasta alla Norma](../../pictures/pasta-alla-norma.jpg)

Sizilianischer Klassiker aus Tomatensauce, gebratener Aubergine und salziger Ricotta salata.

## Zutaten

| Menge      | Zutat             | Gruppe | Variante      | Hinweis                   | Einkauf |
| ---------- | ----------------- | ------ | ------------- | ------------------------- | ------- |
| 200 g      | Rigatoni          |        |               |                           |         |
| 1          | Aubergine         |        |               | in 2 cm Würfel            |         |
| 4 EL       | Olivenöl          |        |               |                           |         |
| 2          | Knoblauch         |        |               | Zehen, in Scheiben        |         |
| 400 g      | Passierte Tomaten |        |               |                           |         |
| 3          | Sardellen         |        | Mit Sardellen | fein gehackt              |         |
| 1 Prise    | Chiliflocken      |        |               |                           |         |
| 1 Handvoll | Basilikum         |        |               | Blätter                   | Menge   |
| 50 g       | Ricotta salata    |        |               | gerieben oder zerbröckelt | Menge   |
| 1 TL       | Salz              |        |               |                           |         |
| 1 TL       | Schwarzer Pfeffer |        |               |                           |         |
| 2 l        | Wasser            |        |               |                           | nie     |

## Zubereitung

1. Aubergine mit 1 TL Salz mischen und 15 Minuten ziehen lassen, dann trocken tupfen. ⏱ 15
2. 3 EL Öl in einer großen Pfanne erhitzen, Auberginen bei hoher Hitze 8 Minuten goldbraun braten, herausnehmen. ⏱ 8
3. Restliches Öl in dieselbe Pfanne geben, Knoblauch und Chili 30 Sekunden anschwitzen,
4. [Mit Sardellen] Sardellen darin auflösen.
5. Passierte Tomaten zugeben, 15 Minuten leise köcheln lassen, mit Salz und Pfeffer abschmecken. ⏱ 15
6. Rigatoni in Salzwasser bissfest garen. ⏱ 11
7. Nudeln mit einer Kelle Nudelwasser in die Sauce geben, Auberginen und die Hälfte des Basilikums unterheben.
8. Mit Ricotta salata und restlichem Basilikum servieren.

## Notizen

Ersatz für Ricotta salata: Feta oder alter Pecorino. Auberginen nehmen weniger Öl auf, wenn sie vorher gesalzen wurden.
