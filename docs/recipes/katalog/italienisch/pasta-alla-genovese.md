# Pasta alla Genovese

![Pasta alla Genovese](../../pictures/pasta-alla-genovese.jpg)

Die neapolitanische Genovese: viel Zwiebel schmort stundenlang mit Rindfleisch zu einem süßlichen, goldbraunen Ragù.

## Zutaten

| Menge    | Zutat             | Gruppe | Variante        | Hinweis                                                    | Einkauf |
| -------- | ----------------- | ------ | --------------- | ---------------------------------------------------------- | ------- |
| 200 g    | Rigatoni          |        |                 |                                                            |         |
| 400 g    | Rindfleisch       |        | Mit Rindfleisch | Schmorstück, z. B. Beinscheibe oder Schulter, in 3 Stücken | Menge   |
| 800 g    | Zwiebeln          |        |                 | in feinen Streifen                                         |         |
| 1        | Karotte           |        |                 | fein gewürfelt                                             |         |

## Zubereitung

1. Zwiebeln, Karotte und Sellerie in einem schweren Topf mit Öl und Salz mischen.
2. [Mit Rindfleisch] Fleisch salzen und obenauf legen.
3. Deckel auflegen und bei kleinster Hitze 30 Minuten dünsten; die Zwiebeln geben Wasser ab. ⏱ 30
4. Deckel leicht versetzen, Hitze etwas erhöhen und weitere 90 Minuten unter gelegentlichem Rühren schmoren, bis die Zwiebeln goldbraun und marmeladig sind. ⏱ 90
5. Mit Wein ablöschen, 20 Minuten offen einkochen.
6. [Mit Rindfleisch] Fleisch herausnehmen, zerzupfen und zurückgeben. ⏱ 20
7. Rigatoni in Salzwasser garen, mit Nudelwasser in die Sauce rühren, Parmesan zugeben und servieren. ⏱ 12

## Notizen

Der Name hat nichts mit Genua zu tun. Die Zwiebeln dürfen nur sanft garen, nicht verbrennen. Vegetarisch schmeckt sie mit 1 EL Tomatenmark und einem Schuss Gemüsebrühe.
