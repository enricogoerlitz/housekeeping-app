# Bucatini all'amatriciana

![Bucatini all'amatriciana](../../pictures/bucatini-all-amatriciana.jpg)

Römische Pasta mit Guanciale, Tomaten und Pecorino. Vegetarisch mit geräuchertem Tofu.

## Zutaten

| Menge   | Zutat            | Gruppe | Variante      | Hinweis            | Einkauf |
| ------- | ---------------- | ------ | ------------- | ------------------ | ------- |
| 200 g   | Bucatini         |        |               |                    |         |
| 120 g   | Guanciale        |        | Mit Guanciale | in Streifen        | Menge   |
| 150 g   | Räuchertofu      |        | Vegetarisch   | in kleinen Würfeln |         |
| 1 EL    | Olivenöl         |        | Vegetarisch   |                    |         |
| 1       | Zwiebel          |        |               | fein gewürfelt     |         |
| 80 ml   | Weißwein         |        |               | trocken            |         |
| 400 g   | Gehackte Tomaten |        |               | Dose               |         |
| 1 Prise | Chiliflocken     |        |               |                    |         |
| 40 g    | Pecorino         |        |               | gerieben           | Menge   |
| 1 TL    | Salz             |        |               |                    |         |
| 2 l     | Wasser           |        |               |                    | nie     |

## Zubereitung

1. [Mit Guanciale] Guanciale in einer Pfanne 8 Minuten knusprig auslassen, die Hälfte herausnehmen. ⏱ 8
2. [Vegetarisch] Tofu in Öl 6 Minuten knusprig braten. ⏱ 6
3. Zwiebel zugeben und 4 Minuten weich dünsten, Chili zugeben. ⏱ 4
4. Mit Wein ablöschen, Tomaten zugeben und 15 Minuten köcheln. ⏱ 15
5. Bucatini in Salzwasser bissfest kochen, mit Nudelwasser in der Sauce schwenken.
6. Mit Pecorino und dem restlichen Guanciale oder Tofu servieren.

## Notizen

Ersatz für Bucatini: Spaghetti oder Rigatoni. Der Guanciale kann durch Pancetta ersetzt werden.
