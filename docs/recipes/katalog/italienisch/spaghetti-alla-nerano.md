# Spaghetti alla Nerano

![Spaghetti alla Nerano](../../pictures/spaghetti-alla-nerano.jpg)

Pasta aus Nerano an der Amalfiküste: gebratene Zucchini, Provolone und Basilikum ergeben eine cremige Sauce ohne Sahne.

## Zutaten

| Menge      | Zutat             | Gruppe | Variante | Hinweis           | Einkauf |
| ---------- | ----------------- | ------ | -------- | ----------------- | ------- |
| 200 g      | Spaghetti         |        |          |                   |         |
| 3          | Zucchini          |        |          | in dünne Scheiben |         |
| 4 EL       | Olivenöl          |        |          |                   |         |
| 2          | Knoblauch         |        |          | Zehen             |         |
| 60 g       | Provolone         |        |          | gerieben          | Menge   |
| 30 g       | Parmesan          |        |          | gerieben          | Menge   |
| 1 Handvoll | Basilikum         |        |          |                   |         |
| 1 TL       | Salz              |        |          |                   |         |
| 1 TL       | Schwarzer Pfeffer |        |          |                   |         |
| 2 l        | Wasser            |        |          |                   | nie     |

## Zubereitung

1. Zucchinischeiben in Öl in zwei Portionen je 6–8 Minuten goldbraun braten, salzen. ⏱ 12
2. Spaghetti in Salzwasser 2 Minuten kürzer als angegeben kochen. ⏱ 8
3. Knoblauch zu den Zucchini geben und 30 Sekunden mitbraten, Hälfte der Zucchini zerdrücken.
4. Spaghetti mit 100 ml Nudelwasser in die Pfanne geben und 1 Minute schwenken.
5. Pfanne vom Herd nehmen, Provolone und Parmesan zugeben, rühren, bis eine cremige Sauce entsteht. Mit Basilikum servieren.

## Notizen

Ersatz für Provolone: Gouda oder zusätzlicher Parmesan. Je dunkler die Zucchini gebraten sind, desto besser.
