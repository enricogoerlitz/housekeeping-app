# Selbstgemachte Gnocchi mit Salbeibutter

![Selbstgemachte Gnocchi mit Salbeibutter](../../pictures/gnocchi-mit-salbeibutter.jpg)

Luftige Kartoffelgnocchi aus mehligen Kartoffeln, in brauner Salbeibutter geschwenkt.

## Zutaten

| Menge      | Zutat       | Gruppe  | Variante           | Hinweis                          | Einkauf |
| ---------- | ----------- | ------- | ------------------ | -------------------------------- | ------- |
| 600 g      | Kartoffeln  | Gnocchi |                    | mehligkochend, ungeschält        |         |
| 1          | Ei          | Gnocchi |                    |                                  |         |
| 130 g      | Mehl        | Gnocchi |                    | Type 405, plus Mehl zum Arbeiten |         |
| 1 TL       | Salz        | Gnocchi |                    |                                  |         |
| 1 Prise    | Muskat      | Gnocchi |                    |                                  |         |
| 50 g       | Butter      | Sauce   |                    |                                  |         |
| 10         | Salbei      | Sauce   |                    | Blätter                          |         |
| 30 g       | Parmesan    | Sauce   |                    | gerieben                         | Menge   |
| 4 Scheiben | Rohschinken | Sauce   | Mit Parma-Schinken | Parma                            |         |
| 2 l        | Wasser      |         |                    |                                  | nie     |

## Zubereitung

1. Kartoffeln ungeschält in Salzwasser 30 Minuten weich kochen. ⏱ 30
2. Noch heiß pellen und durch die Presse drücken, auf einer Arbeitsfläche 10 Minuten ausdampfen lassen. ⏱ 10
3. Ei, Mehl, Salz und Muskat rasch zu einem weichen, nicht klebenden Teig verkneten (nicht zu lange kneten).
4. Teig in 4 Teile teilen, zu fingerdicken Rollen formen, in 2 cm Stücke schneiden und mit einer Gabel eindrücken.
5. [Mit Parma-Schinken] Schinken im Ofen oder in der Pfanne ohne Fett knusprig braten.
6. Gnocchi portionsweise in siedendes Salzwasser geben, 2 Minuten garen, bis sie aufsteigen; mit dem Schaumlöffel herausheben. ⏱ 2
7. Butter in einer Pfanne schmelzen, Salbei zugeben und bräunen lassen, bis sie nussig duftet. Gnocchi darin schwenken.
8. Mit Parmesan (und zerbröseltem Schinken) servieren.

## Notizen

Mehlig kochende Kartoffeln (z. B. Linda, Agria) sind entscheidend: je trockener, desto weniger Mehl. Gnocchi lassen sich roh einfrieren.
