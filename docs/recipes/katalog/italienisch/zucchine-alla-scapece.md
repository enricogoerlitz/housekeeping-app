# Zucchine alla scapece

![Zucchine alla scapece](../../pictures/zucchine-alla-scapece.jpg)

Gebratene Zucchini, mit Essig, Knoblauch und Minze mariniert: ein kalt servierter Klassiker aus Neapel.

## Zutaten

| Menge      | Zutat         | Gruppe | Variante | Hinweis            | Einkauf |
| ---------- | ------------- | ------ | -------- | ------------------ | ------- |
| 3          | Zucchini      |        |          | in 5 mm Scheiben   |         |
| 5 EL       | Olivenöl      |        |          |                    |         |
| 2          | Knoblauch     |        |          | Zehen, in Scheiben |         |
| 3 EL       | Weißweinessig |        |          |                    |         |
| 1 Handvoll | Minze         |        |          | Blätter            |         |
| 1 TL       | Salz          |        |          |                    |         |

## Zubereitung

1. Zucchinischeiben portionsweise in Öl 3–4 Minuten pro Seite goldbraun braten, auf Küchenpapier abtropfen und salzen. ⏱ 15
2. Schichtweise in eine Schüssel geben, mit Knoblauch und Minze belegen.
3. Essig leicht erwärmen und darübergießen.
4. Mindestens 1 Stunde marinieren, bei Zimmertemperatur servieren. ⏱ 60

## Notizen

Hält sich im Kühlschrank 3 Tage. Dazu Brot und Käse.
