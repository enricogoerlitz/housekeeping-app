# Peperonata

![Peperonata](../../pictures/peperonata.jpg)

Langsam geschmorte Paprika mit Tomaten und Zwiebel: eine Beilage für Fleisch und Fisch oder zum Brot.

## Zutaten

| Menge      | Zutat            | Gruppe | Variante | Hinweis                   | Einkauf |
| ---------- | ---------------- | ------ | -------- | ------------------------- | ------- |
| 3          | Paprika          |        |          | rot und gelb, in Streifen |         |
| 1          | Zwiebel          |        |          | in Streifen               |         |
| 2 EL       | Olivenöl         |        |          |                           |         |
| 2          | Knoblauch        |        |          | Zehen                     |         |
| 200 g      | Gehackte Tomaten |        |          | Dose                      |         |
| 1 EL       | Weißweinessig    |        |          |                           |         |
| 1 Handvoll | Basilikum        |        |          |                           |         |
| 1 TL       | Salz             |        |          |                           |         |

## Zubereitung

1. Zwiebel in Öl 4 Minuten andünsten, Paprika zugeben und 10 Minuten mitbraten. ⏱ 14
2. Knoblauch zugeben, Tomaten und Salz hinzufügen.
3. Zugedeckt 20 Minuten leise schmoren, bis die Paprika weich sind. ⏱ 20
4. Mit Essig abschmecken und mit Basilikum bestreuen.

## Notizen

Warm oder kalt. Ersatz für Essig: Zitronensaft.
