# Risotto ai funghi

![Risotto ai funghi](../../pictures/risotto-ai-funghi.jpg)

Cremiges Pilzrisotto mit Champignons und getrockneten Steinpilzen für ein tiefes Aroma.

## Zutaten

| Menge  | Zutat                   | Gruppe | Variante  | Hinweis                | Einkauf |
| ------ | ----------------------- | ------ | --------- | ---------------------- | ------- |
| 160 g  | Risottoreis             |        |           | Arborio oder Carnaroli |         |
| 250 g  | Champignons             |        |           | in Scheiben            |         |
| 10 g   | Steinpilze (getrocknet) |        |           |                        |         |
| 1      | Zwiebel                 |        |           | fein gewürfelt         |         |
| 1      | Knoblauch               |        |           | Zehe, fein gehackt     |         |
| 80 ml  | Weißwein                |        |           | trocken                |         |
| 750 ml | Gemüsebrühe             |        |           | heiß                   |         |
| 2 EL   | Olivenöl                |        |           |                        |         |
| 30 g   | Butter                  |        |           | kalt, in Würfeln       |         |
| 50 g   | Parmesan                |        |           | gerieben               | Menge   |
| 60 g   | Speckwürfel             |        | Mit Speck |                        |         |
| 1 EL   | Petersilie              |        |           | gehackt                |         |
| 1 TL   | Salz                    |        |           |                        |         |
| 1 TL   | Schwarzer Pfeffer       |        |           |                        |         |

## Zubereitung

1. Steinpilze in 100 ml heißem Wasser 15 Minuten einweichen, ausdrücken, grob hacken; Einweichwasser durch ein Sieb zur Brühe gießen. ⏱ 15
2. [Mit Speck] Speckwürfel in einer Pfanne knusprig braten und beiseitestellen.
3. Champignons in 1 EL Öl bei hoher Hitze 6 Minuten braun braten, salzen, herausnehmen. ⏱ 6
4. 1 EL Öl in einem Topf erhitzen, Zwiebel 3 Minuten glasig dünsten, Knoblauch, Reis und Steinpilze zugeben und 1 Minute rösten.
5. Mit Weißwein ablöschen und einkochen lassen. Dann kellenweise heiße Brühe zugeben, immer erst nach Aufnahme der Flüssigkeit, unter Rühren etwa 18 Minuten garen. ⏱ 18
6. Pilze (und Speck) unterheben, Topf vom Herd nehmen, Butter und Parmesan kräftig einrühren. 2 Minuten zugedeckt ruhen lassen.
7. Mit Petersilie und Pfeffer servieren.

## Notizen

Das Risotto soll „all'onda“ sein, also fließend. Gegebenenfalls einen Schuss Brühe nachgießen. Ersatz für Weißwein: Brühe mit 1 TL Zitronensaft.
