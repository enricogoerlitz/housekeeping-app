# Pasta e fagioli

![Pasta e fagioli](../../pictures/pasta-e-fagioli.jpg)

Sämiger Eintopf aus weißen Bohnen und kleinen Nudeln, mit Rosmarin: günstig und sättigend.

## Zutaten

| Menge    | Zutat             | Gruppe | Variante  | Hinweis        | Einkauf |
| -------- | ----------------- | ------ | --------- | -------------- | ------- |
| 1        | Zwiebel           |        |           | fein gewürfelt |         |
| 1        | Karotte           |        |           | fein gewürfelt |         |
| 1 Stange | Staudensellerie   |        |           | fein gewürfelt |         |
| 2        | Knoblauch         |        |           | Zehen          |         |
| 60 g     | Speckwürfel       |        | Mit Speck |                |         |
| 2 EL     | Olivenöl          |        |           |                |         |
| 2 EL     | Tomatenmark       |        |           |                |         |
| 2 Dosen  | Weiße Bohnen      |        |           | abgetropft     |         |
| 600 ml   | Gemüsebrühe       |        |           |                |         |
| 1 Zweig  | Rosmarin          |        |           |                |         |
| 100 g    | Ditalini          |        |           |                |         |
| 30 g     | Parmesan          |        |           | gerieben       | Menge   |
| 1 TL     | Salz              |        |           |                |         |
| 1 TL     | Schwarzer Pfeffer |        |           |                |         |

## Zubereitung

1. [Mit Speck] Speck im Öl 3 Minuten anbraten. ⏱ 3
2. Öl, Zwiebel, Karotte und Sellerie 6 Minuten anschwitzen, Knoblauch und Tomatenmark 1 Minute mitrösten. ⏱ 6
3. Bohnen, Brühe und Rosmarin zugeben, 15 Minuten köcheln. ⏱ 15
4. Eine Kelle Bohnen mit etwas Flüssigkeit pürieren und zurückgeben; das macht den Eintopf sämig.
5. Nudeln direkt in der Suppe 10 Minuten garen, bis sie weich sind. ⏱ 10
6. Rosmarin entfernen, abschmecken, mit Parmesan und Olivenöl servieren.

## Notizen

Bei längerem Stehen zieht die Suppe an; einfach mit Brühe verdünnen.
