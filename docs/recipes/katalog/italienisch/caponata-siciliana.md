# Caponata siciliana

![Caponata siciliana](../../pictures/caponata-siciliana.jpg)

Süßsaures Auberginengemüse mit Sellerie, Oliven und Kapern, lauwarm oder kalt ein Antipasto.

## Zutaten

| Menge     | Zutat            | Gruppe | Variante | Hinweis        | Einkauf |
| --------- | ---------------- | ------ | -------- | -------------- | ------- |
| 2         | Aubergine        |        |          | in 2 cm Würfel |         |
| 4 EL      | Olivenöl         |        |          |                |         |
| 1         | Zwiebel          |        |          | in Streifen    |         |
| 2 Stangen | Staudensellerie  |        |          | in Scheiben    |         |
| 200 g     | Gehackte Tomaten |        |          | Dose           |         |
| 30 g      | Grüne Oliven     |        |          | entsteint      |         |
| 1 EL      | Kapern           |        |          |                |         |
| 2 EL      | Rotweinessig     |        |          |                |         |
| 1 EL      | Zucker           |        |          |                |         |
| 1 EL      | Pinienkerne      |        |          | geröstet       |         |
| 1 TL      | Salz             |        |          |                |         |

## Zubereitung

1. Auberginen in Öl portionsweise 8 Minuten goldbraun braten, herausnehmen. ⏱ 8
2. Zwiebel und Sellerie in Öl 8 Minuten weich dünsten. ⏱ 8
3. Tomaten zugeben und 10 Minuten köcheln.
4. Essig und Zucker verrühren, mit Oliven, Kapern und Auberginen 10 Minuten leise schmoren. ⏱ 10
5. Abschmecken, abkühlen lassen, mit Pinienkernen servieren.

## Notizen

Hält sich im Kühlschrank 5 Tage und schmeckt am nächsten Tag besser. Passt zu Brot oder als Beilage zu Fisch.
