# Risotto alla milanese

![Risotto alla milanese](../../pictures/risotto-alla-milanese.jpg)

Das goldgelbe Risotto aus Mailand mit Safran, Butter und viel Parmesan; mit Salsiccia wird es zum Hauptgericht pur.

## Zutaten

| Menge     | Zutat       | Gruppe | Variante      | Hinweis             | Einkauf |
| --------- | ----------- | ------ | ------------- | ------------------- | ------- |
| 160 g     | Risottoreis |        |               |                     |         |
| 1         | Zwiebel     |        |               | sehr fein gewürfelt |         |
| 40 g      | Butter      |        |               |                     |         |
| 80 ml     | Weißwein    |        |               | trocken             |         |
| 700 ml    | Gemüsebrühe |        |               | heiß                |         |
| 1 Döschen | Safran      |        |               | ca. 0,2 g Fäden     |         |
| 50 g      | Parmesan    |        |               | gerieben            | Menge   |
| 2         | Salsiccia   |        | Mit Bratwurst | Brät in Stücken     |         |
| 1 TL      | Salz        |        |               |                     |         |

## Zubereitung

1. Safranfäden in 4 EL heißer Brühe 10 Minuten ziehen lassen. ⏱ 10
2. 20 g Butter im Topf schmelzen, Zwiebel 4 Minuten glasig dünsten. ⏱ 4
3. [Mit Bratwurst] Salsiccia-Brät zur Zwiebel geben und 5 Minuten krümelig anbraten. ⏱ 5
4. Reis zugeben und 1–2 Minuten unter Rühren rösten, mit Wein ablöschen und einkochen lassen.
5. Heiße Brühe kellenweise zugeben und unter Rühren etwa 17 Minuten garen. ⏱ 17
6. Safran samt Flüssigkeit 3 Minuten vor Ende unterrühren.
7. Vom Herd nehmen, restliche Butter und Parmesan einrühren, salzen, 2 Minuten ruhen lassen und servieren.

## Notizen

Safranpulver ist günstiger, aber Fäden schmecken besser. Klassisch wird das Risotto zu Ossobuco gereicht.
