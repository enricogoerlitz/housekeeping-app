# Scaloppine al limone

![Scaloppine al limone](../../pictures/scaloppine-al-limone.jpg)

Dünne Schnitzel in einer frischen Zitronen-Butter-Sauce: in 25 Minuten fertig.

## Zutaten

| Menge | Zutat               | Gruppe | Variante     | Hinweis                          | Einkauf |
| ----- | ------------------- | ------ | ------------ | -------------------------------- | ------- |
| 2     | Hähnchenbrustfilets |        | Mit Hähnchen | quer halbiert und dünn plattiert | Menge   |
| 2     | Aubergine           |        | Vegetarisch  | kleine, in 1 cm Scheiben         |         |
| 3 EL  | Mehl                |        |              |                                  |         |
| 2 EL  | Olivenöl            |        |              |                                  |         |
| 30 g  | Butter              |        |              |                                  |         |
| 1     | Zitrone             |        |              | Saft und Scheiben                |         |
| 80 ml | Gemüsebrühe         |        |              |                                  |         |
| 1 EL  | Petersilie          |        |              | gehackt                          |         |
| 1 TL  | Salz                |        |              |                                  |         |
| 1 TL  | Schwarzer Pfeffer   |        |              |                                  |         |

## Zubereitung

1. [Mit Hähnchen] Filets salzen, pfeffern und in Mehl wenden, überschüssiges Mehl abklopfen.
2. [Vegetarisch] Auberginenscheiben salzen, 10 Minuten ziehen lassen, trocknen, mehlieren. ⏱ 10
3. Öl erhitzen und Fleisch oder Aubergine bei mittlerer Hitze pro Seite 2–3 Minuten goldbraun braten, warm stellen. ⏱ 5
4. Pfanne vom Herd nehmen, Brühe, Zitronensaft und Zitronenscheiben zugeben und 3 Minuten einköcheln lassen. ⏱ 3
5. Butter einrühren, Sauce abschmecken, Schnitzel kurz darin wenden und mit Petersilie servieren.

## Notizen

Passt zu Rosmarinkartoffeln oder Weißbrot. Statt Hähnchen geht auch Kalb oder Pute.
