# Frittata di zucchine

![Frittata di zucchine](../../pictures/frittata-di-zucchine.jpg)

Dicke italienische Omelette mit Zucchini, Parmesan und Kräutern; warm oder kalt ein Genuss.

## Zutaten

| Menge | Zutat             | Gruppe | Variante     | Hinweis           | Einkauf |
| ----- | ----------------- | ------ | ------------ | ----------------- | ------- |
| 1     | Zucchini          |        |              | in dünne Scheiben |         |
| 5     | Ei                |        |              |                   |         |
| 40 g  | Parmesan          |        |              | gerieben          | Menge   |
| 80 g  | Kochschinken      |        | Mit Schinken | in Streifen       |         |
| 1     | Zwiebel           |        |              | in Ringen         |         |
| 2 EL  | Olivenöl          |        |              |                   |         |
| 1 EL  | Basilikum         |        |              | gehackt           |         |
| 1 TL  | Salz              |        |              |                   |         |
| 1 TL  | Schwarzer Pfeffer |        |              |                   |         |

## Zubereitung

1. Öl in einer ofenfesten Pfanne erhitzen, Zwiebel 3 Minuten andünsten, Zucchini 6 Minuten braten. ⏱ 9
2. Eier mit Parmesan, Basilikum, Salz und Pfeffer verquirlen (und Schinken unterrühren).
3. Eiermasse über das Gemüse gießen, bei kleiner Hitze 6 Minuten stocken lassen. ⏱ 6
4. Frittata im Ofen bei 200 °C Grill oder Oberhitze 4 Minuten fertig garen, bis die Oberseite goldbraun ist. ⏱ 4
5. In Stücke schneiden und servieren.

## Notizen

Nach Belieben Reste (Kartoffeln, Paprika) verwenden. Zum Wenden einen flachen Teller auf die Pfanne legen, stürzen und zurückgleiten lassen.
