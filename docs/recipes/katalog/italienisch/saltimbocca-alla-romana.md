# Saltimbocca alla romana

![Saltimbocca alla romana](../../pictures/saltimbocca-alla-romana.jpg)

Kalbsschnitzel mit Schinken und Salbei, in Butter und Weißwein gebraten: schnell, aromatisch, römisch. Vegetarisch mit Aubergine.

## Zutaten

| Menge      | Zutat             | Gruppe | Variante    | Hinweis             | Einkauf |
| ---------- | ----------------- | ------ | ----------- | ------------------- | ------- |
| 4          | Kalbsschnitzel    |        | Mit Kalb    | dünn, je ca. 70 g   | Menge   |
| 1          | Aubergine         |        | Vegetarisch | in 8 lange Scheiben |         |
| 4 Scheiben | Rohschinken       |        | Mit Kalb    | Parma               |         |
| 4 Scheiben | Mozzarella        |        | Vegetarisch |                     |         |
| 8          | Salbei            |        |             | Blätter             |         |
| 2 EL       | Mehl              |        |             |                     |         |
| 30 g       | Butter            |        |             |                     |         |
| 2 EL       | Olivenöl          |        |             |                     |         |
| 100 ml     | Weißwein          |        |             | trocken             |         |
| 1 TL       | Salz              |        |             |                     |         |
| 1 TL       | Schwarzer Pfeffer |        |             |                     |         |

## Zubereitung

1. [Mit Kalb] Schnitzel leicht plattieren, pfeffern, je 1 Salbeiblatt und 1 Scheibe Schinken darauflegen und mit Zahnstocher feststecken.
2. [Mit Kalb] Nur die Fleischseite leicht mehlieren. Öl und die Hälfte der Butter erhitzen, Schnitzel mit der Schinkenseite nach unten 2 Minuten braten, wenden, 1 Minute braten, herausnehmen. ⏱ 3
3. [Vegetarisch] Auberginenscheiben salzen, 10 Minuten ziehen lassen, trocknen und im Öl pro Seite 4 Minuten braten. Mit Salbei und Mozzarella belegen und 3 Minuten zugedeckt schmelzen lassen. ⏱ 11
4. Bratensatz mit Wein ablöschen, 2 Minuten einkochen, restliche Butter einrühren.
5. Sauce über das Gericht geben und sofort servieren.

## Notizen

Dazu passen Rosmarinkartoffeln (siehe Patate arrosto) oder Spinat. Kalb ersetzbar durch Schweineschnitzel oder Putenbrust.
