# Pizzoccheri della Valtellina

![Pizzoccheri della Valtellina](../../pictures/pizzoccheri-della-valtellina.jpg)

Buchweizennudeln mit Wirsing, Kartoffeln, Bergkäse und Salbeibutter: ein deftiges Gericht aus den Alpen.

## Zutaten

| Menge | Zutat       | Gruppe | Variante | Hinweis                      | Einkauf |
| ----- | ----------- | ------ | -------- | ---------------------------- | ------- |
| 200 g | Pizzoccheri |        |          | Buchweizennudeln, getrocknet |         |
| 200 g | Kartoffeln  |        |          | festkochend, in 1 cm Würfeln |         |
| 200 g | Wirsing     |        |          | in Streifen                  |         |
| 60 g  | Butter      |        |          |                              |         |
| 2     | Knoblauch   |        |          | Zehen                        |         |
| 6     | Salbei      |        |          | Blätter                      |         |
| 120 g | Bergkäse    |        |          | gerieben                     | Menge   |
| 30 g  | Parmesan    |        |          | gerieben                     | Menge   |
| 1 TL  | Salz        |        |          |                              |         |
| 2 l   | Wasser      |        |          |                              | nie     |

## Zubereitung

1. Wasser salzen und aufkochen. Kartoffeln 5 Minuten kochen. ⏱ 5
2. Wirsing zugeben, nach 3 Minuten die Nudeln einlegen und 10 Minuten garen. ⏱ 13
3. Währenddessen Butter mit Knoblauch und Salbei bei mittlerer Hitze bräunen.
4. Alles abgießen und in einer vorgewärmten Schale mit Bergkäse in Schichten mischen.
5. Salbeibutter darüber gießen, mit Parmesan bestreuen und servieren.

## Notizen

Pizzoccheri bekommt man im gut sortierten Supermarkt oder online; Ersatz: Vollkorn-Tagliatelle. Bergkäse ersetzbar durch Raclettekäse.
