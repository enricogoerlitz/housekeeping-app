# Prebranac

![Prebranac](../../pictures/prebranac.jpg)

Serbischer Ofenbohnen-Topf mit viel Zwiebel und Paprika.

## Zutaten

| Menge  | Zutat          | Gruppe | Variante      | Hinweis                 | Einkauf |
| ------ | -------------- | ------ | ------------- | ----------------------- | ------- |
| 250 g  | Weiße Bohnen   |        |               | getrocknet, eingeweicht | Menge   |
| 3      | Zwiebel        |        |               | in Halbringen           |         |
| 3      | Knoblauch      |        |               | Zehen                   |         |
| 4 EL   | Sonnenblumenöl |        |               |                         |         |
| 2 TL   | Paprikapulver  |        |               |                         |         |
| 1      | Lorbeerblatt   |        |               |                         |         |
| 2      | Würstchen      |        | Mit Würstchen | geräuchert, in Scheiben |         |
| 500 ml | Wasser         |        |               |                         | nie     |
|        | Salz           |        |               |                         |         |
|        | Pfeffer        |        |               |                         |         |

## Zubereitung

1. Eingeweichte Bohnen mit Lorbeer in frischem Wasser 50 Minuten weich kochen, Kochwasser aufheben. ⏱ 50
2. Zwiebeln in Öl 15 Minuten langsam goldbraun braten, Knoblauch zugeben. ⏱ 15
3. Paprikapulver zugeben, mit Bohnen und 200 ml Kochwasser mischen.
4. [Mit Würstchen] Würstchenscheiben untermischen.
5. In eine Form geben, bei 200 °C 25 Minuten backen. ⏱ 25

## Notizen

Schnell: 3 Dosen weiße Bohnen, entfällt das Vorkochen.
