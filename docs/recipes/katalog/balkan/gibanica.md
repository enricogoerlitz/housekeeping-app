# Gibanica

![Gibanica](../../pictures/gibanica.jpg)

Herzhafte Käsepastete mit Filoteig, Feta und Quark, außen knusprig, innen cremig.

## Zutaten

| Menge  | Zutat          | Gruppe | Variante     | Hinweis    | Einkauf |
| ------ | -------------- | ------ | ------------ | ---------- | ------- |
| 250 g  | Filoteig       |        |              |            |         |
| 200 g  | Feta           |        |              | zerbröselt |         |
| 250 g  | Quark          |        |              |            |         |
| 3      | Ei             |        |              |            |         |
| 100 ml | Mineralwasser  |        |              |            |         |
| 4 EL   | Sonnenblumenöl |        |              |            |         |
| 100 g  | Kochschinken   |        | Mit Schinken | gewürfelt  | Menge   |
|        | Salz           |        |              |            |         |

## Zubereitung

1. Backofen auf 200 °C vorheizen.
2. Feta, Quark, Eier und Mineralwasser verrühren.
3. [Mit Schinken] Schinkenwürfel unterrühren.
4. Eine Form einölen, 2 Teigblätter einlegen, mit Füllung und Öl beträufeln, wiederholen bis alles aufgebraucht ist (3–4 Lagen).
5. Mit einem Teigblatt abschließen und mit Öl bestreichen.
6. 35 Minuten goldbraun backen. ⏱ 35

## Notizen

Filoteig gibt es im Kühlregal oder im türkischen Laden.
