# Ražnjići

![Ražnjići](../../pictures/raznjici.jpg)

Fleischspieße mit Paprika und Zwiebeln, vom Grill oder aus der Pfanne.

## Zutaten

| Menge | Zutat          | Gruppe | Variante            | Hinweis       | Einkauf |
| ----- | -------------- | ------ | ------------------- | ------------- | ------- |
| 350 g | Schweinenacken |        | Mit Schweinefleisch | in Würfeln    | Menge   |
| 350 g | Hähnchenbrust  |        | Mit Hähnchen        | in Würfeln    | Menge   |
| 250 g | Halloumi       |        | Vegetarisch         | in Würfeln    | Menge   |
| 1     | Paprika        |        |                     | in Stücken    |         |
| 1     | Zwiebel        |        |                     | in Stücken    |         |
| 2     | Knoblauch      |        |                     | Zehen         |         |
| 2 EL  | Olivenöl       |        |                     |               |         |
| 1 TL  | Paprikapulver  |        |                     |               |         |
| 2 EL  | Ajvar          |        |                     | zum Servieren |         |
|       | Salz           |        |                     |               |         |
|       | Pfeffer        |        |                     |               |         |

## Zubereitung

1. Fleisch (bzw. Halloumi) mit Knoblauch, Öl, Paprikapulver, Salz und Pfeffer 1–2 Stunden marinieren.
2. Mit Paprika und Zwiebel abwechselnd auf Spieße stecken.
3. [Mit Schweinefleisch] 12 Minuten bei mittlerer Hitze braten, mehrfach wenden. ⏱ 12
4. [Mit Hähnchen] 12 Minuten bei mittlerer Hitze braten, bis das Hähnchen durchgegart ist. ⏱ 12
5. [Vegetarisch] 3 Minuten je Seite goldbraun braten. ⏱ 6
6. Mit Ajvar servieren.

## Notizen

Dazu Pommes oder Djuvec-Reis.
