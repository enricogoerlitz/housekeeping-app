# Đuveč

![Đuveč](../../pictures/djuvec.jpg)

Balkanischer Reis-Gemüse-Auflauf mit Paprika, Karotten und Erbsen aus dem Ofen.

## Zutaten

| Menge  | Zutat            | Gruppe | Variante     | Hinweis        | Einkauf |
| ------ | ---------------- | ------ | ------------ | -------------- | ------- |
| 4      | Hähnchenschenkel |        | Mit Hähnchen |                | Menge   |
| 150 g  | Langkornreis     |        |              |                | Menge   |
| 1      | Zwiebel          |        |              | gewürfelt      |         |
| 2      | Paprika          |        |              | rot, gewürfelt |         |
| 1      | Karotte          |        |              | gewürfelt      |         |
| 100 g  | Erbsen           |        |              | TK             |         |
| 2 EL   | Ajvar            |        |              |                |         |
| 400 g  | Stückige Tomaten |        |              |                |         |
| 2      | Knoblauch        |        |              | Zehen          |         |
| 3 EL   | Olivenöl         |        |              |                |         |
| 1 TL   | Paprikapulver    |        |              |                |         |
| 300 ml | Wasser           |        |              |                | nie     |
|        | Salz             |        |              |                |         |
|        | Pfeffer          |        |              |                |         |

## Zubereitung

1. Backofen auf 200 °C vorheizen.
2. [Mit Hähnchen] Schenkel salzen und in Öl 8 Minuten anbraten. ⏱ 8
3. Zwiebel, Paprika, Karotte in Öl 6 Minuten andünsten, Knoblauch, Paprikapulver und Ajvar zugeben. ⏱ 6
4. Reis, Tomaten, Wasser, Erbsen, Salz und Pfeffer unterrühren und in eine Form füllen.
5. [Mit Hähnchen] Schenkel in den Reis setzen.
6. Abgedeckt 40 Minuten backen, dann 10 Minuten offen bräunen. ⏱ 40

## Notizen

Dazu Gurkensalat.
