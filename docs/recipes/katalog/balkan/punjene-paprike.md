# Punjene Paprike

![Punjene Paprike](../../pictures/punjene-paprike.jpg)

Gefüllte Paprika mit Hack-Reis-Füllung in Tomatensauce. Vegetarisch mit Reis und Pilzen.

## Zutaten

| Menge  | Zutat             | Gruppe | Variante        | Hinweis                 | Einkauf |
| ------ | ----------------- | ------ | --------------- | ----------------------- | ------- |
| 4      | Paprika           |        |                 | rot, Deckel abschneiden |         |
| 250 g  | Rinderhack        |        | Mit Hackfleisch |                         | Menge   |
| 200 g  | Champignons       |        | Vegetarisch     | fein gewürfelt          | Menge   |
| 60 g   | Langkornreis      |        |                 |                         |         |
| 1      | Zwiebel           |        |                 | fein gewürfelt          |         |
| 2      | Knoblauch         |        |                 | Zehen                   |         |
| 1 TL   | Paprikapulver     |        |                 |                         |         |
| 500 ml | Passierte Tomaten |        |                 |                         |         |
| 2 EL   | Sonnenblumenöl    |        |                 |                         |         |
| 100 ml | Wasser            |        |                 |                         | nie     |
| 2 EL   | Saure Sahne       |        |                 | zum Servieren           |         |
|        | Salz              |        |                 |                         |         |
|        | Pfeffer           |        |                 |                         |         |

## Zubereitung

1. Zwiebel in Sonnenblumenöl 4 Minuten dünsten. ⏱ 4
2. [Mit Hackfleisch] Hack und Knoblauch 5 Minuten mitbraten. ⏱ 5
3. [Vegetarisch] Pilze und Knoblauch 6 Minuten in der Pfanne mitbraten, bis die Flüssigkeit verdampft. ⏱ 6
4. Mit Reis, Paprikapulver, Salz und Pfeffer mischen, abkühlen lassen.
5. Paprika füllen, Deckel aufsetzen und aufrecht in einen Topf stellen.
6. Tomaten und Wasser zugeben, zugedeckt 50 Minuten bei kleiner Hitze schmoren. ⏱ 50
7. Mit Saurer Sahne servieren.
