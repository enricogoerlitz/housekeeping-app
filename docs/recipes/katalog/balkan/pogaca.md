# Pogača

![Pogača](../../pictures/pogaca.jpg)

Weiches Balkan-Fladenbrot mit goldener Kruste.

## Zutaten

| Menge  | Zutat          | Gruppe | Variante | Hinweis         | Einkauf |
| ------ | -------------- | ------ | -------- | --------------- | ------- |
| 300 g  | Mehl           |        |          |                 |         |
| 0.5    | Hefe           |        |          | Würfel (21 g)   |         |
| 150 ml | Milch          |        |          | lauwarm         |         |
| 2 EL   | Joghurt        |        |          |                 |         |
| 1 EL   | Sonnenblumenöl |        |          |                 |         |
| 1 TL   | Zucker         |        |          |                 |         |
| 1 TL   | Salz           |        |          |                 |         |
| 1      | Eier           |        |          | zum Bestreichen |         |
| 1 EL   | Sesam          |        |          |                 |         |

## Zubereitung

1. Hefe in Milch mit Zucker auflösen. Mit Mehl, Joghurt, Öl und Salz 8 Minuten kneten. ⏱ 8
2. Abgedeckt 1 Stunde gehen lassen, bis sich das Volumen verdoppelt hat. ⏱ 60
3. Zu einer runden Scheibe formen, auf Backpapier legen, Kreuz einritzen, mit Eigelb bestreichen und mit Sesam bestreuen.
4. 20 Minuten ruhen lassen, bei 200 °C 25 Minuten goldbraun backen. ⏱ 25

## Notizen

Frisch zu Cevapcici.
