# Ajvar

![Ajvar](../../pictures/ajvar.jpg)

Der Balkan-Brotaufstrich aus gerösteten Paprika und Aubergine.

## Zutaten

| Menge | Zutat          | Gruppe | Variante | Hinweis | Einkauf |
| ----- | -------------- | ------ | -------- | ------- | ------- |
| 4     | Paprika        |        |          | rot     | Menge   |
| 1     | Aubergine      |        |          |         |         |
| 3     | Knoblauch      |        |          | Zehen   |         |
| 4 EL  | Sonnenblumenöl |        |          |         |         |
| 1 EL  | Weißweinessig  |        |          |         |         |
|       | Salz           |        |          |         |         |

## Zubereitung

1. Paprika und Aubergine bei 230 °C 40 Minuten rösten, bis die Haut verkohlt. ⏱ 40
2. Gemüse in einer Schüssel zugedeckt 10 Minuten dämpfen lassen, Haut abziehen, Kerne entfernen. ⏱ 10
3. Fruchtfleisch fein pürieren.
4. Mit Knoblauch, Öl und Essig in einem Topf 10 Minuten bei kleiner Hitze einkochen, salzen. ⏱ 10

## Notizen

Im Glas 1 Woche im Kühlschrank haltbar.
