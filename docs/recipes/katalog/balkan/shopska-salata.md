# Šopska Salata

![Šopska Salata](../../pictures/shopska-salata.jpg)

Der klassische Balkan-Tomatensalat mit Käsehaube.

## Zutaten

| Menge | Zutat          | Gruppe | Variante | Hinweis         | Einkauf |
| ----- | -------------- | ------ | -------- | --------------- | ------- |
| 3     | Tomate         |        |          | gewürfelt       |         |
| 1     | Salatgurke     |        |          | gewürfelt       |         |
| 1     | Paprika        |        |          | grün, gewürfelt |         |
| 1     | Zwiebel        |        |          | rot, in Ringen  |         |
| 100 g | Feta           |        |          | gerieben        |         |
| 2 EL  | Sonnenblumenöl |        |          |                 |         |
| 1 EL  | Weißweinessig  |        |          |                 |         |
|       | Salz           |        |          |                 |         |

## Zubereitung

1. Gemüse in eine Schüssel geben, mit Öl, Essig und Salz mischen.
2. Mit dem geriebenen Feta bedecken und sofort servieren.

## Notizen

Original: Sirene (Salzlakenkäse); Feta funktioniert.
