# Ćevapčići

![Ćevapčići](../../pictures/cevapcici.jpg)

Kleine gegrillte Hackröllchen im Fladenbrot mit Zwiebeln und Ajvar, der Balkan-Klassiker. Vegetarisch aus Kichererbsen und Pilzen.

## Zutaten

| Menge  | Zutat         | Gruppe | Variante        | Hinweis                       | Einkauf |
| ------ | ------------- | ------ | --------------- | ----------------------------- | ------- |
| 300 g  | Rinderhack    |        | Mit Hackfleisch |                               | Menge   |
| 200 g  | Lammhack      |        | Mit Hackfleisch |                               | Menge   |
| 1 Dose | Kichererbsen  |        | Vegetarisch     | 400 g, abgetropft             |         |
| 200 g  | Champignons   |        | Vegetarisch     | fein gehackt, ausgedrückt     | Menge   |

## Zubereitung

1. [Mit Hackfleisch] Hack mit Knoblauch, Paprikapulver, Natron, Salz, Pfeffer und Mineralwasser 5 Minuten kräftig verkneten, abgedeckt mindestens 4 Stunden kühlen. ⏱ 5
2. [Vegetarisch] Kichererbsen zerdrücken, mit Pilzen, Knoblauch, Paprikapulver, Semmelbröseln, Salz und Pfeffer zu einer festen Masse verkneten, 30 Minuten kühlen. ⏱ 30
3. Mit nassen Händen fingerdicke, 6 cm lange Röllchen formen.
4. In einer Grillpfanne mit Olivenöl bei mittlerer bis hoher Hitze 8–10 Minuten rundum braten. ⏱ 10
5. Fladenbrot kurz erwärmen, Ćevapčići mit Zwiebel und Ajvar servieren.

## Notizen

Hack sollte aus fettem Hackfleisch bestehen (mind. 20 % Fett). Ajvar siehe eigenes Rezept.
