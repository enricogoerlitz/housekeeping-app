# Pljeskavica

![Pljeskavica](../../pictures/pljeskavica.jpg)

Der große Balkan-Hackfleisch-Burger mit Zwiebeln und Ajvar. Vegetarisch aus Linsen und Bulgur.

## Zutaten

| Menge | Zutat         | Gruppe | Variante        | Hinweis       | Einkauf |
| ----- | ------------- | ------ | --------------- | ------------- | ------- |
| 400 g | Rinderhack    |        | Mit Hackfleisch |               | Menge   |
| 100 g | Rote Linsen   |        | Vegetarisch     | gekocht       | Menge   |
| 60 g  | Bulgur        |        | Vegetarisch     | fein          | Menge   |
| 1     | Zwiebel       |        |                 | fein gerieben |         |
| 2     | Knoblauch     |        |                 | Zehen         |         |
| 1 TL  | Paprikapulver |        |                 |               |         |
| 2 EL  | Semmelbrösel  |        |                 |               |         |
| 2     | Fladenbrot    |        |                 |               |         |
| 1     | Tomate        |        |                 | in Scheiben   |         |
| 2 EL  | Frischkäse    |        |                 | oder Kajmak   |         |
| 1 EL  | Olivenöl      |        |                 |               |         |
|       | Salz          |        |                 |               |         |
|       | Pfeffer       |        |                 |               |         |

## Zubereitung

1. [Vegetarisch] Linsen und Bulgur mit 120 ml heißem Wasser übergießen und 10 Minuten quellen lassen. ⏱ 10
2. Hack bzw. Linsenmasse mit Zwiebel, Knoblauch, Paprikapulver, Semmelbröseln, Salz und Pfeffer gründlich verkneten.
3. Zwei flache Patties (1,5 cm dick) formen, 15 Minuten kühlen. ⏱ 15
4. In Olivenöl 5 Minuten je Seite goldbraun braten. ⏱ 10
5. Im Fladenbrot mit Tomate, Zwiebel und Frischkäse servieren.

## Notizen

Kajmak aus dem Balkanladen; Ersatz Frischkäse.
