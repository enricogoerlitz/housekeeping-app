# Haydari

![Haydari](../../pictures/haydari.jpg)

Dicker Joghurtdip mit Walnuss, Dill und Knoblauch.

## Zutaten

| Menge | Zutat                | Gruppe | Variante | Hinweis         | Einkauf |
| ----- | -------------------- | ------ | -------- | --------------- | ------- |
| 250 g | Griechischer Joghurt |        |          |                 |         |
| 100 g | Feta                 |        |          | zerdrückt       |         |
| 1     | Knoblauch            |        |          | Zehe            |         |
| 2 EL  | Walnüsse             |        |          | gehackt         |         |
| 2 EL  | Dill                 |        |          | frisch, gehackt |         |
| 1 EL  | Olivenöl             |        |          |                 |         |

## Zubereitung

1. Joghurt mit Feta und Knoblauch glatt rühren.
2. Walnüsse und Dill unterheben.
3. Mit Olivenöl beträufeln und kalt servieren.

## Notizen

Hält sich 2 Tage.
