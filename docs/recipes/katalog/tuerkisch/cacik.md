# Cacık

![Cacık](../../pictures/cacik.jpg)

Dünne Joghurt-Gurken-Suppe/Dip mit Minze und Knoblauch, erfrischend zu allem Gegrillten.

## Zutaten

| Menge | Zutat        | Gruppe | Variante | Hinweis                | Einkauf |
| ----- | ------------ | ------ | -------- | ---------------------- | ------- |
| 300 g | Naturjoghurt |        |          |                        |         |
| 0.5   | Salatgurke   |        |          | gewürfelt              |         |
| 1     | Knoblauch    |        |          | Zehe, gepresst         |         |
| 1 EL  | Minze        |        |          | frisch oder getrocknet |         |
| 1 EL  | Olivenöl     |        |          |                        |         |
| 50 ml | Wasser       |        |          | kalt                   | nie     |
|       | Salz         |        |          |                        |         |

## Zubereitung

1. Joghurt mit Wasser, Knoblauch, Olivenöl und Salz glatt rühren.
2. Gurke und Minze unterheben.
3. 15 Minuten kalt stellen. ⏱ 15

## Notizen

Weniger Wasser für einen Dip, mehr für die Suppe.
