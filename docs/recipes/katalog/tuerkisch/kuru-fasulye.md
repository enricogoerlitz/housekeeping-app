# Kuru Fasulye

![Kuru Fasulye](../../pictures/kuru-fasulye.jpg)

Weiße Bohnen in roter Tomaten-Paprika-Sauce, das türkische Nationalgericht, mit Reis. Wahlweise mit Sucuk.

## Zutaten

| Menge  | Zutat             | Gruppe | Variante  | Hinweis                            | Einkauf |
| ------ | ----------------- | ------ | --------- | ---------------------------------- | ------- |
| 200 g  | Weiße Bohnen      |        |           | getrocknet, über Nacht eingeweicht | Menge   |
| 1      | Zwiebel           |        |           | gewürfelt                          |         |
| 2      | Knoblauch         |        |           | Zehen                              |         |
| 1 EL   | Tomatenmark       |        |           |                                    |         |
| 1 EL   | Paprikamark       |        |           | oder mehr Tomatenmark              |         |
| 2 EL   | Olivenöl          |        |           |                                    |         |
| 200 g  | Passierte Tomaten |        |           |                                    |         |
| 1 TL   | Paprikapulver     |        |           |                                    |         |
| 100 g  | Sucuk             |        | Mit Sucuk | in Scheiben                        | Menge   |
| 700 ml | Wasser            |        |           |                                    | nie     |
|        | Salz              |        |           |                                    |         |
|        | Pfeffer           |        |           |                                    |         |

## Zubereitung

1. Eingeweichte Bohnen abgießen, mit frischem Wasser bedeckt 45 Minuten vorgaren und abgießen. ⏱ 45
2. Zwiebel in Olivenöl 5 Minuten andünsten, Knoblauch, Tomaten- und Paprikamark 2 Minuten mitrösten. ⏱ 5
3. [Mit Sucuk] Sucuk-Scheiben 3 Minuten mitbraten. ⏱ 3
4. Bohnen, Passierte Tomaten, Paprikapulver und 700 ml Wasser zugeben, zugedeckt 30 Minuten köcheln. ⏱ 30
5. Salzen, pfeffern, offen noch 10 Minuten einkochen. ⏱ 10

## Notizen

Schnell: 3 Dosen weiße Bohnen verwenden und nur 20 Minuten köcheln. Dazu Reis und eingelegte Peperoni.
