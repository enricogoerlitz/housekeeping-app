# Taş Kebabı

![Taş Kebabı](../../pictures/tas-kebabi.jpg)

Zartes geschmortes Fleisch mit Kartoffeln und Paprika in Tomatensauce, eine türkische Eintopf-Klassik.

## Zutaten

| Menge  | Zutat         | Gruppe | Variante    | Hinweis           | Einkauf |
| ------ | ------------- | ------ | ----------- | ----------------- | ------- |
| 450 g  | Lammschulter  |        | Mit Lamm    | in Würfeln        | Menge   |
| 450 g  | Rindergulasch |        | Mit Rind    |                   | Menge   |
| 300 g  | Champignons   |        | Vegetarisch | geviertelt        | Menge   |
| 1      | Zwiebel       |        |             | gewürfelt         |         |
| 3      | Knoblauch     |        |             | Zehen             |         |
| 2      | Tomate        |        |             | gewürfelt         |         |
| 1 EL   | Tomatenmark   |        |             |                   |         |
| 2      | Paprika       |        |             | grün, in Streifen |         |
| 3      | Kartoffel     |        |             | in Würfeln        |         |
| 3 EL   | Olivenöl      |        |             |                   |         |
| 1 TL   | Paprikapulver |        |             |                   |         |
| 400 ml | Wasser        |        |             |                   | nie     |
|        | Salz          |        |             |                   |         |
|        | Pfeffer       |        |             |                   |         |

## Zubereitung

1. [Mit Lamm] Fleisch salzen und in Olivenöl portionsweise 8 Minuten kräftig anbraten. ⏱ 8
2. [Mit Rind] Fleisch salzen und in Olivenöl portionsweise 8 Minuten kräftig anbraten. ⏱ 8
3. [Vegetarisch] Pilze in Olivenöl 8 Minuten kräftig anbraten. ⏱ 8
4. Zwiebel, Knoblauch, Tomatenmark und Paprikapulver 4 Minuten mitrösten. ⏱ 4
5. Tomaten und Wasser zugeben, aufkochen.
6. [Mit Lamm] Zugedeckt 75 Minuten bei kleiner Hitze schmoren. ⏱ 75
7. [Mit Rind] Zugedeckt 90 Minuten bei kleiner Hitze schmoren. ⏱ 90
8. [Vegetarisch] Zugedeckt 10 Minuten köcheln.
9. Kartoffeln und Paprika zugeben, 25 Minuten garen, abschmecken. ⏱ 25

## Notizen

Mit Reis oder Fladenbrot servieren.
