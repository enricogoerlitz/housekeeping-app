# Patlıcan Musakka

![Patlıcan Musakka](../../pictures/patlican-musakka.jpg)

Türkische Musakka ohne Béchamel: gebratene Auberginen mit Hack-Tomaten-Sauce, aus der Pfanne.

## Zutaten

| Menge  | Zutat         | Gruppe | Variante        | Hinweis         | Einkauf |
| ------ | ------------- | ------ | --------------- | --------------- | ------- |
| 2      | Aubergine     |        |                 | in Scheiben     | Menge   |
| 250 g  | Rinderhack    |        | Mit Hackfleisch |                 | Menge   |
| 150 g  | Braune Linsen |        | Vegetarisch     | gekocht         | Menge   |
| 1      | Zwiebel       |        |                 | gewürfelt       |         |
| 2      | Knoblauch     |        |                 | Zehen           |         |
| 2      | Tomate        |        |                 | gewürfelt       |         |
| 1 EL   | Tomatenmark   |        |                 |                 |         |
| 4 EL   | Olivenöl      |        |                 |                 |         |
| 1      | Paprika       |        |                 | grün, gewürfelt |         |
| 100 ml | Wasser        |        |                 |                 | nie     |
|        | Salz          |        |                 |                 |         |
|        | Pfeffer       |        |                 |                 |         |

## Zubereitung

1. Auberginen salzen, 10 Minuten ziehen lassen, abtupfen und in 2 EL Öl portionsweise 8 Minuten braten. ⏱ 8
2. Zwiebel und Paprika in 1 EL Öl 5 Minuten dünsten, Knoblauch zugeben. ⏱ 5
3. [Mit Hackfleisch] Hack 8 Minuten krümelig braten. ⏱ 8
4. [Vegetarisch] Linsen 3 Minuten mitbraten. ⏱ 3
5. Tomatenmark, Tomaten, Wasser, Salz, Pfeffer zugeben und 8 Minuten köcheln. ⏱ 8
6. Auberginen auf die Sauce legen, zugedeckt 10 Minuten garen. ⏱ 10

## Notizen

Warm mit Reis oder lauwarm mit Joghurt.
