# Sucuklu Yumurta

![Sucuklu Yumurta](../../pictures/sucuklu-yumurta.jpg)

Spiegeleier auf gebratener Sucuk, das herzhafte Frühstück aus der Pfanne. Vegetarisch mit Halloumi.

## Zutaten

| Menge | Zutat         | Gruppe | Variante    | Hinweis     | Einkauf |
| ----- | ------------- | ------ | ----------- | ----------- | ------- |
| 120 g | Sucuk         |        | Mit Sucuk   | in Scheiben | Menge   |
| 150 g | Halloumi      |        | Vegetarisch | in Scheiben | Menge   |
| 4     | Ei            |        |             |             |         |
| 1 TL  | Butter        |        |             |             |         |
| 1 TL  | Paprikapulver |        |             |             |         |
| 1     | Fladenbrot    |        |             | zum Dippen  |         |
| 1 EL  | Petersilie    |        |             |             |         |
|       | Pfeffer       |        |             |             |         |

## Zubereitung

1. [Mit Sucuk] Sucuk in einer Pfanne 3 Minuten braten, bis das Fett austritt. ⏱ 3
2. [Vegetarisch] Halloumi in Butter 3 Minuten goldbraun braten. ⏱ 3
3. Eier darüber aufschlagen, mit Pfeffer würzen.
4. Zugedeckt 3–4 Minuten bei niedriger Hitze stocken lassen. ⏱ 4
5. Mit Paprikapulver und Petersilie bestreuen und mit Brot servieren.

## Notizen

Das Eigelb sollte weich bleiben.
