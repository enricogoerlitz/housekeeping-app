# Bulgur Pilavı

![Bulgur Pilavı](../../pictures/bulgur-pilavi.jpg)

Lockerer Bulgur mit Tomate und Zwiebel, passt zu allem.

## Zutaten

| Menge  | Zutat       | Gruppe | Variante | Hinweis        | Einkauf |
| ------ | ----------- | ------ | -------- | -------------- | ------- |
| 150 g  | Bulgur      |        |          |                | Menge   |
| 1      | Zwiebel     |        |          | fein gewürfelt |         |
| 1      | Tomate      |        |          | gewürfelt      |         |
| 1 EL   | Tomatenmark |        |          |                |         |
| 1 EL   | Butter      |        |          |                |         |
| 300 ml | Wasser      |        |          | heiß           | nie     |
|        | Salz        |        |          |                |         |

## Zubereitung

1. Zwiebel in Butter 4 Minuten andünsten, Tomatenmark und Tomate zugeben, 3 Minuten braten. ⏱ 4
2. Bulgur 1 Minute mitrösten.
3. Mit heißem Wasser aufgießen, salzen, zugedeckt 15 Minuten garen. ⏱ 15
4. 5 Minuten abgedeckt ruhen lassen, mit Gabel auflockern.

## Notizen

Verhältnis Bulgur zu Wasser 1:2.
