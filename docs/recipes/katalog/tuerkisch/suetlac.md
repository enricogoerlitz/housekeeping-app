# Sütlaç

![Sütlaç](../../pictures/suetlac.jpg)

Türkischer Milchreis, im Ofen mit goldener Kruste überbacken.

## Zutaten

| Menge   | Zutat         | Gruppe | Variante | Hinweis                         | Einkauf |
| ------- | ------------- | ------ | -------- | ------------------------------- | ------- |
| 80 g    | Rundkornreis  |        |          |                                 | Menge   |
| 500 ml  | Milch         |        |          |                                 |         |
| 200 ml  | Wasser        |        |          |                                 | nie     |
| 60 g    | Zucker        |        |          |                                 |         |
| 1 EL    | Speisestärke  |        |          | in 50 ml kalter Milch aufgelöst |         |
| 1 Pck   | Vanillezucker |        |          |                                 |         |
| 1 Prise | Zimt          |        |          |                                 |         |

## Zubereitung

1. Reis in 200 ml Wasser 10 Minuten kochen. ⏱ 10
2. Milch zugeben und 20 Minuten bei kleiner Hitze unter Rühren köcheln. ⏱ 20
3. Zucker, Vanillezucker und aufgelöste Stärke zugeben und 5 Minuten eindicken. ⏱ 5
4. In ofenfeste Schälchen füllen und unter dem heißen Grill 5 Minuten bräunen. ⏱ 5
5. Abkühlen, kalt stellen und mit Zimt servieren.

## Notizen

Mindestens 2 Stunden kühlen.
