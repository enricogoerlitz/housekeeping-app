# Ezme

![Ezme](../../pictures/ezme.jpg)

Scharfer Tomaten-Paprika-Dip mit Granatapfelsirup.

## Zutaten

| Menge | Zutat            | Gruppe | Variante | Hinweis              | Einkauf |
| ----- | ---------------- | ------ | -------- | -------------------- | ------- |
| 3     | Tomate           |        |          | sehr fein gewürfelt  |         |
| 1     | Paprika          |        |          | grün, fein gewürfelt |         |
| 1     | Zwiebel          |        |          | fein gewürfelt       |         |
| 1     | Knoblauch        |        |          | Zehe                 |         |
| 2 EL  | Petersilie       |        |          | gehackt              |         |
| 1 EL  | Granatapfelsirup |        |          |                      |         |
| 2 EL  | Olivenöl         |        |          |                      |         |
| 1 TL  | Chiliflocken     |        |          |                      |         |
|       | Salz             |        |          |                      |         |

## Zubereitung

1. Zwiebel mit Salz 5 Minuten durchkneten, damit sie milder wird. ⏱ 5
2. Tomate, Paprika, Knoblauch, Petersilie zugeben.
3. Sirup, Olivenöl und Chili unterrühren, 15 Minuten ziehen lassen. ⏱ 15

## Notizen

Granatapfelsirup: türkischer Laden; Ersatz Zitronensaft + 1 TL Zucker.
