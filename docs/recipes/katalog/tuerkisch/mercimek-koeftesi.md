# Mercimek Köftesi

![Mercimek Köftesi](../../pictures/mercimek-koeftesi.jpg)

Kalte Linsen-Bulgur-Röllchen mit Tomatenmark, in Salatblättern serviert.

## Zutaten

| Menge  | Zutat            | Gruppe | Variante | Hinweis        | Einkauf |
| ------ | ---------------- | ------ | -------- | -------------- | ------- |
| 100 g  | Rote Linsen      |        |          |                | Menge   |
| 80 g   | Bulgur           |        |          |                |         |
| 1      | Zwiebel          |        |          | fein gewürfelt |         |
| 1 EL   | Tomatenmark      |        |          |                |         |
| 2 EL   | Olivenöl         |        |          |                |         |
| 1 TL   | Kreuzkümmel      |        |          |                |         |
| 1 TL   | Paprikapulver    |        |          |                |         |
| 2      | Frühlingszwiebel |        |          | in Ringen      |         |
| 2 EL   | Petersilie       |        |          |                |         |
| 1      | Römersalat       |        |          | Herz, Blätter  |         |
| 1      | Zitrone          |        |          |                |         |
| 300 ml | Wasser           |        |          |                | nie     |
|        | Salz             |        |          |                |         |

## Zubereitung

1. Linsen in 300 ml Wasser 12 Minuten weich kochen. ⏱ 12
2. Bulgur zugeben, vom Herd nehmen und 15 Minuten abgedeckt quellen lassen. ⏱ 15
3. Zwiebel in Olivenöl 4 Minuten braten, Tomatenmark und Gewürze zugeben und unter die Linsen mengen. ⏱ 4
4. Auskühlen lassen, Frühlingszwiebeln und Petersilie unterkneten.
5. Mit feuchten Händen kleine Röllchen formen, auf Salatblätter setzen und mit Zitrone servieren.

## Notizen

Kalt oder raumtemperiert.
