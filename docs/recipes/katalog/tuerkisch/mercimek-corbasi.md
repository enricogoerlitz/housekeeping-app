# Mercimek Çorbası

![Mercimek Çorbası](../../pictures/mercimek-corbasi.jpg)

Samtige rote Linsensuppe, die türkische Standardsuppe, mit Zitrone und Chili-Butter.

## Zutaten

| Menge  | Zutat         | Gruppe | Variante     | Hinweis             | Einkauf |
| ------ | ------------- | ------ | ------------ | ------------------- | ------- |
| 150 g  | Rote Linsen   |        |              |                     | Menge   |
| 1      | Zwiebel       |        |              | gewürfelt           |         |
| 1      | Karotte       |        |              | gewürfelt           |         |
| 1      | Kartoffel     |        |              | gewürfelt           |         |
| 2 EL   | Butter        |        |              |                     |         |
| 1 EL   | Tomatenmark   |        |              |                     |         |
| 1 TL   | Kreuzkümmel   |        |              |                     |         |
| 1 TL   | Paprikapulver |        |              | für die Chilibutter |         |
| 1      | Zitrone       |        |              | in Spalten          |         |
| 200 g  | Hähnchenbrust |        | Mit Hähnchen | gekocht, zerzupft   | Menge   |
| 800 ml | Wasser        |        |              |                     | nie     |
|        | Salz          |        |              |                     |         |
|        | Pfeffer       |        |              |                     |         |

## Zubereitung

1. Zwiebel, Karotte und Kartoffel in 1 EL Butter 5 Minuten andünsten, Tomatenmark und Kreuzkümmel 1 Minute mitrösten. ⏱ 5
2. Linsen waschen, mit 800 ml Wasser zugeben und aufkochen.
3. 20 Minuten köcheln, bis alles weich ist. ⏱ 20
4. Mit dem Stabmixer fein pürieren, mit Salz und Pfeffer abschmecken.
5. [Mit Hähnchen] Zerzupftes Hähnchen in der Suppe erwärmen.
6. Restliche Butter mit Paprikapulver erhitzen und über die Suppe geben, mit Zitrone servieren.

## Notizen

Mit Fladenbrot oder Croutons.
