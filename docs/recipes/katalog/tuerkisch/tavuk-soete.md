# Tavuk Sote

![Tavuk Sote](../../pictures/tavuk-soete.jpg)

Hähnchen-Gemüse-Pfanne mit Paprika und Tomaten, schnell, mild und würzig. Vegetarisch mit Kichererbsen.

## Zutaten

| Menge  | Zutat         | Gruppe | Variante     | Hinweis               | Einkauf |
| ------ | ------------- | ------ | ------------ | --------------------- | ------- |
| 350 g  | Hähnchenbrust |        | Mit Hähnchen | in Würfeln            | Menge   |
| 1 Dose | Kichererbsen  |        | Vegetarisch  | 400 g, abgetropft     |         |
| 1      | Zwiebel       |        |              | in Streifen           |         |
| 2      | Paprika       |        |              | gemischt, in Streifen |         |
| 2      | Tomate        |        |              | gewürfelt             |         |
| 2      | Knoblauch     |        |              | Zehen                 |         |
| 1 EL   | Tomatenmark   |        |              |                       |         |
| 2 EL   | Olivenöl      |        |              |                       |         |
| 1 TL   | Paprikapulver |        |              |                       |         |
| 1 TL   | Oregano       |        |              |                       |         |
| 150 g  | Reis          |        |              |                       | Menge   |
|        | Salz          |        |              |                       |         |
|        | Pfeffer       |        |              |                       |         |

## Zubereitung

1. Reis nach Packungsanleitung kochen. ⏱ 12
2. [Mit Hähnchen] Hähnchen in Olivenöl 5 Minuten scharf anbraten, herausnehmen. ⏱ 5
3. [Vegetarisch] Kichererbsen in Olivenöl 4 Minuten anbraten, herausnehmen. ⏱ 4
4. Zwiebel und Paprika im Bratfett 5 Minuten braten. ⏱ 5
5. Knoblauch und Tomatenmark 1 Minute mitrösten, Tomaten und Gewürze zugeben, 8 Minuten köcheln. ⏱ 8
6. Hähnchen bzw. Kichererbsen zurückgeben, 3 Minuten durchziehen lassen und abschmecken. ⏱ 3

## Notizen

Dazu passt Reis oder frisches Fladenbrot.
