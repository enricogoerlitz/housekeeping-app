# Hähnchen-Döner aus der Pfanne

![Hähnchen-Döner aus der Pfanne](../../pictures/tavuk-doener-pfanne.jpg)

Hähnchen-Döner-Streifen mit Joghurtsauce und Salat auf Fladenbrot. Vegetarisch mit Räuchertofu.

## Zutaten

| Menge | Zutat         | Gruppe | Variante     | Hinweis            | Einkauf |
| ----- | ------------- | ------ | ------------ | ------------------ | ------- |
| 350 g | Hähnchenbrust |        | Mit Hähnchen | in dünnen Streifen | Menge   |
| 250 g | Räuchertofu   |        | Vegetarisch  | in dünnen Streifen | Menge   |
| 2 TL  | Dönergewürz   |        |              |                    |         |
| 2 EL  | Olivenöl      |        |              |                    |         |
| 2     | Fladenbrot    |        |              | oder Wraps         |         |
| 150 g | Naturjoghurt  |        |              |                    |         |
| 1     | Knoblauch     |        |              | Zehe, gepresst     |         |
| 0.25  | Rotkohl       |        |              | fein geschnitten   |         |
| 1     | Tomate        |        |              | in Scheiben        |         |
| 1     | Rote Zwiebel  |        |              | in Ringen          |         |
|       | Salz          |        |              |                    |         |

## Zubereitung

1. Fleisch bzw. Tofu mit Dönergewürz, Olivenöl und Salz vermengen.
2. [Mit Hähnchen] In einer heißen Pfanne 8 Minuten braten, bis es gebräunt und durchgegart ist. ⏱ 8
3. [Vegetarisch] In einer heißen Pfanne 6 Minuten knusprig braten. ⏱ 6
4. Joghurt mit Knoblauch und Salz verrühren.
5. Fladenbrot erwärmen, mit Joghurtsauce bestreichen, mit Fleisch bzw. Tofu, Rotkohl, Tomate und Zwiebel füllen.

## Notizen

Dönergewürz: Paprika, Kreuzkümmel, Oregano, Knoblauchpulver.
