# Ezogelin Çorbası

![Ezogelin Çorbası](../../pictures/ezogelin-corbasi.jpg)

Würzige Linsen-Bulgur-Suppe mit Minze, sättigend und einfach.

## Zutaten

| Menge  | Zutat         | Gruppe | Variante | Hinweis    | Einkauf |
| ------ | ------------- | ------ | -------- | ---------- | ------- |
| 120 g  | Rote Linsen   |        |          |            | Menge   |
| 40 g   | Bulgur        |        |          | grob       |         |
| 1      | Zwiebel       |        |          | gewürfelt  |         |
| 2      | Knoblauch     |        |          | Zehen      |         |
| 1 EL   | Tomatenmark   |        |          |            |         |
| 1 EL   | Paprikamark   |        |          |            |         |
| 2 EL   | Olivenöl      |        |          |            |         |
| 1 TL   | Minze         |        |          | getrocknet |         |
| 1 TL   | Paprikapulver |        |          |            |         |
| 1      | Zitrone       |        |          |            |         |
| 900 ml | Wasser        |        |          |            | nie     |
|        | Salz          |        |          |            |         |
|        | Pfeffer       |        |          |            |         |

## Zubereitung

1. Zwiebel und Knoblauch in Olivenöl 4 Minuten dünsten, Tomaten- und Paprikamark 1 Minute mitrösten. ⏱ 4
2. Linsen, Bulgur und Wasser zugeben und aufkochen.
3. 25 Minuten köcheln, bis alles zerfallen ist, gelegentlich rühren. ⏱ 25
4. Mit Salz, Pfeffer und der Hälfte der Minze abschmecken.
5. Mit Minze und Paprikapulver bestreuen und mit Zitrone servieren.

## Notizen

Wer es glatt mag, püriert einen Teil.
