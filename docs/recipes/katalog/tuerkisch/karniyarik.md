# Karnıyarık

![Karnıyarık](../../pictures/karniyarik.jpg)

Gebratene Auberginen mit würziger Hackfüllung, im Ofen gegart. Vegetarisch mit Kichererbsen.

## Zutaten

| Menge  | Zutat         | Gruppe | Variante        | Hinweis                      | Einkauf |
| ------ | ------------- | ------ | --------------- | ---------------------------- | ------- |
| 2      | Aubergine     |        |                 | längs halbiert               | Menge   |
| 250 g  | Rinderhack    |        | Mit Hackfleisch |                              | Menge   |
| 1 Dose | Kichererbsen  |        | Vegetarisch     | 400 g, abgetropft, zerdrückt |         |
| 1      | Zwiebel       |        |                 | gewürfelt                    |         |
| 2      | Knoblauch     |        |                 | Zehen                        |         |
| 2      | Tomate        |        |                 | 1 gewürfelt, 1 in Scheiben   |         |
| 1 EL   | Tomatenmark   |        |                 |                              |         |
| 1      | Paprika       |        |                 | Spitzpaprika, klein          |         |
| 4 EL   | Olivenöl      |        |                 |                              |         |
| 1 TL   | Paprikapulver |        |                 |                              |         |
| 150 ml | Wasser        |        |                 |                              | nie     |
|        | Salz          |        |                 |                              |         |
|        | Pfeffer       |        |                 |                              |         |

## Zubereitung

1. Auberginen mit einem Messer längs einkerben und in 2 EL Öl 6 Minuten rundum goldbraun braten. ⏱ 6
2. Zwiebel in 1 EL Öl 4 Minuten dünsten, Knoblauch zugeben. ⏱ 4
3. [Mit Hackfleisch] Hack 8 Minuten krümelig mitbraten. ⏱ 8
4. [Vegetarisch] Kichererbsen 5 Minuten mitbraten. ⏱ 5
5. Gewürfelte Tomate, Tomatenmark, Paprikapulver, Salz, Pfeffer 5 Minuten einkochen.
6. Auberginen in eine Form legen, Füllung einfüllen, mit Tomatenscheibe und Paprika belegen, Wasser angießen.
7. Bei 190 °C 35 Minuten backen. ⏱ 35

## Notizen

Dazu Reis oder Bulgur.
