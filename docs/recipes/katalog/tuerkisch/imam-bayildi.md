# Imam Bayildi

![Imam Bayildi](../../pictures/imam-bayildi.jpg)

Gefüllte Auberginen mit Zwiebel-Tomaten-Füllung, in Olivenöl geschmort, lauwarm serviert.

## Zutaten

| Menge  | Zutat      | Gruppe | Variante | Hinweis         | Einkauf |
| ------ | ---------- | ------ | -------- | --------------- | ------- |
| 2      | Aubergine  |        |          | längs halbiert  | Menge   |
| 200 g  | Rinderhack |        | Mit Hack |                 | Menge   |
| 2      | Zwiebel    |        |          | in Halbringen   |         |
| 3      | Knoblauch  |        |          | Zehen           |         |
| 3      | Tomate     |        |          | gewürfelt       |         |
| 1      | Paprika    |        |          | grün, gewürfelt |         |
| 4 EL   | Olivenöl   |        |          |                 |         |
| 1 TL   | Zucker     |        |          |                 |         |
| 2 EL   | Petersilie |        |          | gehackt         |         |
| 100 ml | Wasser     |        |          |                 | nie     |
|        | Salz       |        |          |                 |         |
|        | Pfeffer    |        |          |                 |         |

## Zubereitung

1. Backofen auf 200 °C vorheizen. Auberginen der Länge nach einschneiden (nicht durchschneiden), salzen und 15 Minuten ziehen lassen, abtupfen. ⏱ 15
2. Auberginen in 2 EL Olivenöl in einer Pfanne rundum 6 Minuten anbraten. ⏱ 6
3. Zwiebeln und Paprika in 2 EL Olivenöl 8 Minuten dünsten, Knoblauch zugeben. ⏱ 8
4. [Mit Hack] Hack zugeben und 7 Minuten krümelig braten. ⏱ 7
5. Tomaten, Zucker, Salz, Pfeffer zugeben und 5 Minuten köcheln lassen, Petersilie unterrühren. ⏱ 5
6. Füllung in die Auberginen drücken, in eine Form setzen, Wasser angießen und abgedeckt 40 Minuten backen. ⏱ 40

## Notizen

Klassisch wird kalt oder lauwarm gegessen.
