# Hünkar Beğendi

![Hünkar Beğendi](../../pictures/hunkar-begendi.jpg)

Cremiges Räucher-Auberginenpüree mit zartem Fleischragout, das Sultansgericht.

## Zutaten

| Menge  | Zutat         | Gruppe | Variante    | Hinweis                     | Einkauf |
| ------ | ------------- | ------ | ----------- | --------------------------- | ------- |
| 400 g  | Rindergulasch | Ragout | Mit Rind    | klein geschnitten           | Menge   |
| 300 g  | Champignons   | Ragout | Vegetarisch | geviertelt                  | Menge   |
| 1      | Zwiebel       | Ragout |             | gewürfelt                   |         |
| 1 EL   | Tomatenmark   | Ragout |             |                             |         |
| 2      | Tomate        | Ragout |             | gewürfelt                   |         |
| 2 EL   | Olivenöl      | Ragout |             |                             |         |

| 30 g   | Butter        | Püree  |             |                             |         |

## Zubereitung

1. Auberginen bei 220 °C 35 Minuten im Ofen rösten, bis sie zusammenfallen. ⏱ 35
2. [Mit Rind] Fleisch in Olivenöl 8 Minuten anbraten, Zwiebel zugeben. ⏱ 8
3. [Vegetarisch] Pilze in Olivenöl 8 Minuten anbraten, Zwiebel zugeben. ⏱ 8
4. Tomatenmark, Tomaten und Wasser zugeben.
5. [Mit Rind] 50 Minuten zugedeckt schmoren. ⏱ 50
6. [Vegetarisch] 15 Minuten köcheln. ⏱ 15
7. Auberginenfleisch auslöffeln. Butter schmelzen, Mehl einrühren, Milch zugießen, Aubergine und Käse unterrühren, 5 Minuten rühren. ⏱ 5
8. Püree anrichten und das Ragout daraufgeben.

## Notizen

Kaşar im türkischen Laden; Ersatz Gouda oder Emmentaler.
