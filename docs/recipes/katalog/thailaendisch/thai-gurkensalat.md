# Thai-Gurkensalat

![Thai-Gurkensalat](../../pictures/thai-gurkensalat.jpg)

Schneller süß-saurer Gurkensalat, ideal neben Gebratenem und Reis.

## Zutaten

| Menge      | Zutat         | Gruppe | Variante | Hinweis            | Einkauf |
| ---------- | ------------- | ------ | -------- | ------------------ | ------- |
| 1          | Salatgurke    |        |          | in dünnen Scheiben |         |
| 1          | Schalotte     |        |          | in Ringen          |         |
| 1          | Chilischoten  |        |          | rot, in Ringen     |         |
| 3 EL       | Reisessig     |        |          |                    |         |
| 2 EL       | Zucker        |        |          |                    |         |
| 0,5 TL     | Salz          |        |          |                    |         |
| 1 Handvoll | Koriandergrün |        |          |                    |         |
| 2 EL       | Erdnüsse      |        |          | geröstet, gehackt  |         |
| 2 EL       | Wasser        |        |          | warm               | nie     |

## Zubereitung

1. Zucker, Salz und Wasser mit dem Essig verrühren, bis alles aufgelöst ist.
2. Gurke, Schalotte und Chili in eine Schüssel geben.
3. Dressing darübergießen, 10 Minuten ziehen lassen. ⏱ 10
4. Mit Koriander und Erdnüssen bestreuen.

## Notizen

Am besten frisch essen, wird sonst wässrig.
