# Grünes Thai-Curry

![Grünes Thai-Curry](../../pictures/gruenes-curry.jpg)

Cremiges Curry mit grüner Currypaste, Kokosmilch und Thai-Basilikum. Schärfe nach Geschmack.

## Zutaten

| Menge      | Zutat          | Gruppe | Variante     | Hinweis          | Einkauf |
| ---------- | -------------- | ------ | ------------ | ---------------- | ------- |
| 2 EL       | Currypaste     |        |              | grün             |         |
| 1 EL       | Pflanzenöl     |        |              |                  |         |
| 400 ml     | Kokosmilch     |        |              |                  |         |
| 150 ml     | Wasser         |        |              |                  | nie     |
| 300 g      | Hähnchenbrust  |        | Mit Hähnchen | in Streifen      | Menge   |
| 200 g      | Tofu           |        | Vegetarisch  | gewürfelt        | Menge   |
| 1          | Aubergine      |        |              | in Stücken       |         |
| 1          | Zucchini       |        |              | in Scheiben      |         |
| 100 g      | Bambussprossen |        |              | Dose, abgetropft |         |
| 1 EL       | Fischsauce     |        | Mit Hähnchen |                  |         |
| 1 EL       | Sojasauce      |        | Vegetarisch  |                  |         |
| 1 EL       | Palmzucker     |        |              |                  |         |
| 1 Handvoll | Thai-Basilikum |        |              |                  |         |
| 250 g      | Jasminreis     |        |              |                  |         |
| 500 ml     | Wasser         |        |              |                  | nie     |

## Zubereitung

1. Öl in einem Topf erhitzen, Currypaste 1 Minute anrösten, bis sie duftet.
2. Die Hälfte der Kokosmilch zugeben und 3 Minuten einkochen, bis sich Öl absetzt. ⏱ 3
3. [Mit Hähnchen] Hähnchen zugeben und 4 Minuten mitgaren. ⏱ 4
4. Restliche Kokosmilch und Wasser zugeben, Aubergine, Zucchini und Bambus 8 Minuten köcheln. ⏱ 8
5. [Vegetarisch] Tofu die letzten 4 Minuten mitkochen. ⏱ 4
6. Mit Fisch- bzw. Sojasauce und Palmzucker abschmecken, Basilikum unterheben.
7. Jasminreis garen und mit dem Curry servieren.

## Notizen

Currypasten sind unterschiedlich scharf; erst die Hälfte nehmen. Vegetarische Paste ohne Garnelenpaste im Asia-Laden suchen.
