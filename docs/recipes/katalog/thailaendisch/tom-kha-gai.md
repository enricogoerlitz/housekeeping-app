# Tom Kha Gai

![Tom Kha Gai](../../pictures/tom-kha-gai.jpg)

Cremig-saure Kokossuppe mit Galgant, Zitronengras und Limette. Als Hauptgericht mit Reis.

## Zutaten

| Menge      | Zutat                 | Gruppe | Variante     | Hinweis                | Einkauf |
| ---------- | --------------------- | ------ | ------------ | ---------------------- | ------- |
| 400 ml     | Kokosmilch            |        |              |                        |         |
| 400 ml     | Gemüsebrühe           |        |              |                        |         |
| 3 Scheiben | Galgant               |        |              | oder Ingwer            |         |
| 2 Stängel  | Zitronengras          |        |              | angedrückt, in Stücken |         |
| 4          | Kaffirlimettenblätter |        |              |                        |         |
| 250 g      | Champignons           |        |              | in Scheiben            |         |
| 300 g      | Hähnchenbrust         |        | Mit Hähnchen | in Streifen            | Menge   |
| 200 g      | Tofu                  |        | Vegetarisch  | gewürfelt              | Menge   |
| 1 EL       | Fischsauce            |        | Mit Hähnchen |                        |         |

## Zubereitung

1. Kokosmilch und Brühe mit Galgant, Zitronengras und Limettenblättern aufkochen, 8 Minuten ziehen lassen. ⏱ 8
2. Champignons zugeben und 4 Minuten köcheln. ⏱ 4
3. [Mit Hähnchen] Hähnchenstreifen zugeben und 6 Minuten gar ziehen lassen, nicht kochen. ⏱ 6
4. [Vegetarisch] Tofu zugeben und 3 Minuten erwärmen. ⏱ 3
5. Mit Fisch- bzw. Sojasauce, Zucker und Limettensaft abschmecken.
6. Reis garen, Suppe mit Chili und Koriander servieren. Galgant und Zitronengras isst man nicht mit.

## Notizen

Kaffirlimettenblätter und Galgant gibt es tiefgekühlt im Asia-Laden. Ersatz: Limettenschale und Ingwer.
