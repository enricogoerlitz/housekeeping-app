# Pad See Ew

![Pad See Ew](../../pictures/pad-see-ew.jpg)

Breite Reisnudeln mit dunkler Sojasauce, Ei und Brokkoli, im Wok leicht angekohlt.

## Zutaten

| Menge | Zutat                     | Gruppe | Variante     | Hinweis                       | Einkauf |
| ----- | ------------------------- | ------ | ------------ | ----------------------------- | ------- |
| 250 g | Reisnudeln                |        |              | breit, frisch oder getrocknet |         |
| 250 g | Hähnchenbrust             |        | Mit Hähnchen | in dünnen Streifen            | Menge   |
| 200 g | Tofu                      |        | Vegetarisch  | in Streifen                   | Menge   |
| 2 EL  | Pflanzenöl                |        |              |                               |         |
| 3     | Knoblauch                 |        |              | Zehen, gehackt                |         |
| 2     | Ei                        |        |              |                               |         |
| 200 g | Brokkoli                  |        |              | kleine Röschen                |         |
| 2 EL  | Dunkle Sojasauce          |        |              |                               |         |
| 1 EL  | Sojasauce                 |        |              | hell                          |         |
| 1 EL  | Austernsauce              |        | Mit Hähnchen |                               |         |
| 1 EL  | Vegetarische Austernsauce |        | Vegetarisch  |                               |         |
| 1 TL  | Zucker                    |        |              |                               |         |
| 1 l   | Wasser                    |        |              |                               | nie     |

## Zubereitung

1. Getrocknete Nudeln nach Packung einweichen, abtropfen; frische Nudeln auflockern. ⏱ 15
2. Sojasaucen, Austernsauce und Zucker mischen.
3. Wok stark erhitzen, Öl zugeben.
4. [Mit Hähnchen] Hähnchen 4 Minuten braten.
5. [Vegetarisch] Tofu 5 Minuten braten. ⏱ 4
6. Knoblauch zugeben, Eier daneben stocken lassen und verrühren.
7. Brokkoli mit 2 EL Wasser 2 Minuten garen. ⏱ 2
8. Nudeln und Sauce zugeben und 3 Minuten ohne ständiges Rühren braten, damit sie leicht anbrennen. ⏱ 3

## Notizen

Original mit Chinesischem Brokkoli (Gai Lan); normaler Brokkoli geht. Nur 1–2 Portionen gleichzeitig braten.
