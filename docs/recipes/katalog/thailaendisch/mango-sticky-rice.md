# Mango Sticky Rice

![Mango Sticky Rice](../../pictures/mango-sticky-rice.jpg)

Klebreis in gesüßter Kokosmilch mit reifer Mango, das beliebteste Dessert Thailands.

## Zutaten

| Menge  | Zutat        | Gruppe | Variante | Hinweis           | Einkauf |
| ------ | ------------ | ------ | -------- | ----------------- | ------- |
| 150 g  | Klebreis     |        |          |                   |         |
| 200 ml | Kokosmilch   |        |          |                   |         |
| 3 EL   | Zucker       |        |          |                   |         |
| 0,5 TL | Salz         |        |          |                   |         |
| 2      | Mango        |        |          | reif, in Scheiben |         |
| 1 TL   | Speisestärke | Sauce  |          |                   |         |
| 100 ml | Kokosmilch   | Sauce  |          |                   |         |
| 1 EL   | Sesam        |        |          | geröstet          |         |
| 300 ml | Wasser       |        |          |                   | nie     |

## Zubereitung

1. Klebreis 4 Stunden oder über Nacht in Wasser einweichen, abtropfen lassen. ⏱ 20
2. Reis in ein Dämpfsieb über kochendem Wasser geben und 20 Minuten dämpfen. ⏱ 20
3. Kokosmilch mit Zucker und Salz erwärmen, heißen Reis unterrühren, 15 Minuten ziehen lassen, bis die Milch aufgesogen ist. ⏱ 15
4. Für die Sauce Kokosmilch mit Stärke und einer Prise Salz erhitzen, bis sie leicht bindet.
5. Reis mit Mango anrichten, Sauce darübergeben, mit Sesam bestreuen.

## Notizen

Reis möglichst am Vortag einweichen. Ohne Dämpfsieb: Reis in ein Tuch gewickelt auf einem Sieb im Topf dämpfen.
