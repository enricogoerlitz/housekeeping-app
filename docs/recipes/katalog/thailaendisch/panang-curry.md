# Panang-Curry

![Panang-Curry](../../pictures/panang-curry.jpg)

Dickes, leicht süßes Curry mit Erdnuss und Kaffirlimette, weniger flüssig als andere Currys.

## Zutaten

| Menge  | Zutat                 | Gruppe | Variante    | Hinweis                   | Einkauf |
| ------ | --------------------- | ------ | ----------- | ------------------------- | ------- |
| 2 EL   | Currypaste            |        |             | Panang                    |         |
| 1 EL   | Pflanzenöl            |        |             |                           |         |
| 400 ml | Kokosmilch            |        |             |                           |         |
| 2 EL   | Erdnussbutter         |        |             |                           |         |
| 300 g  | Rindfleisch           |        | Mit Rind    | Hüfte, in dünnen Streifen | Menge   |
| 250 g  | Tofu                  |        | Vegetarisch | gewürfelt                 | Menge   |
| 1      | Paprika               |        |             | rot, in Streifen          |         |
| 150 g  | Zuckerschoten         |        |             |                           |         |
| 1 EL   | Fischsauce            |        | Mit Rind    |                           |         |
| 1 EL   | Sojasauce             |        | Vegetarisch |                           |         |
| 1 EL   | Palmzucker            |        |             |                           |         |
| 3      | Kaffirlimettenblätter |        |             | in feinen Streifen        |         |
| 250 g  | Jasminreis            |        |             |                           |         |
| 500 ml | Wasser                |        |             |                           | nie     |

## Zubereitung

1. Öl erhitzen, Currypaste 1 Minute anrösten.
2. Hälfte der Kokosmilch und Erdnussbutter einrühren und 3 Minuten einkochen. ⏱ 3
3. [Mit Rind] Rindfleisch zugeben und 3 Minuten garen.
4. [Vegetarisch] Tofu zugeben und 3 Minuten erwärmen. ⏱ 3
5. Restliche Kokosmilch, Paprika und Zuckerschoten zugeben, 6 Minuten köcheln. ⏱ 6
6. Mit Fisch- bzw. Sojasauce und Palmzucker abschmecken, mit Limettenblättern bestreuen.
7. Reis garen und servieren.

## Notizen

Panang-Paste ersatzweise rote Currypaste plus 1 TL Erdnussbutter mehr.
