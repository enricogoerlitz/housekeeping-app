# Som Tam (Papayasalat)

![Som Tam (Papayasalat)](../../pictures/som-tam.jpg)

Scharf-saurer Salat aus grüner Papaya, im Mörser gestampft. Beilage zu Gegrilltem und Currys.

## Zutaten

| Menge | Zutat         | Gruppe | Variante | Hinweis                                     | Einkauf |
| ----- | ------------- | ------ | -------- | ------------------------------------------- | ------- |
| 300 g | Grüne Papaya  |        |          | geraspelt, ersatzweise Karotte und Weißkohl |         |
| 100 g | Kirschtomaten |        |          | halbiert                                    |         |
| 80 g  | Grüne Bohnen  |        |          | in 3 cm Stücken                             |         |
| 2     | Knoblauch     |        |          | Zehen                                       |         |
| 2     | Chilischoten  |        |          | Thai-Chili                                  |         |
| 2 EL  | Palmzucker    |        |          |                                             |         |
| 2 EL  | Limetten      |        |          | Saft                                        |         |
| 1 EL  | Fischsauce    |        |          |                                             |         |
| 30 g  | Erdnüsse      |        |          | geröstet                                    |         |

## Zubereitung

1. Knoblauch, Chili und Palmzucker im Mörser zu einer Paste zerstoßen.
2. Bohnen zugeben und leicht anquetschen.
3. Limettensaft und Fischsauce einrühren.
4. Papaya und Tomaten zugeben und mit dem Stößel vorsichtig stampfen und wenden.
5. Mit Erdnüssen bestreuen und sofort servieren.

## Notizen

Grüne Papaya gibt es im Asia-Laden; Ersatz: Karotten und Kohlrabi. Vegetarisch: Fischsauce durch Sojasauce plus Limettensaft ersetzen.
