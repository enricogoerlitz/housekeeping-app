# Khao Pad

![Khao Pad](../../pictures/khao-pad.jpg)

Gebratener Reis mit Ei, Knoblauch und Frühlingszwiebel. Perfekt für übrig gebliebenen Reis.

## Zutaten

| Menge | Zutat            | Gruppe | Variante     | Hinweis                       | Einkauf |
| ----- | ---------------- | ------ | ------------ | ----------------------------- | ------- |
| 300 g | Jasminreis       |        |              | gekocht, am besten vom Vortag |         |
| 2 EL  | Pflanzenöl       |        |              |                               |         |
| 3     | Knoblauch        |        |              | Zehen, gehackt                |         |
| 2     | Ei               |        |              |                               |         |
| 1     | Zwiebel          |        |              | gewürfelt                     |         |
| 1     | Tomate           |        |              | in Spalten                    |         |
| 3     | Frühlingszwiebel |        |              | in Ringen                     |         |
| 200 g | Garnelen         |        | Mit Garnelen | geschält                      | Menge   |
| 100 g | Erbsen           |        | Vegetarisch  | TK                            |         |
| 2 EL  | Sojasauce        |        |              |                               |         |
| 1 EL  | Fischsauce       |        | Mit Garnelen |                               |         |
| 1 TL  | Zucker           |        |              |                               |         |
| 0,5   | Salatgurke       |        |              | in Scheiben                   |         |
| 1     | Limette          |        |              | in Spalten                    |         |

## Zubereitung

1. Wok stark erhitzen, Öl zugeben, Zwiebel und Knoblauch 1 Minute rühren.
2. [Mit Garnelen] Garnelen 2 Minuten mitbraten, herausnehmen.
3. [Vegetarisch] Erbsen 2 Minuten mitbraten. ⏱ 2
4. Eier zugeben, kurz stocken lassen und zerteilen.
5. Reis zugeben, mit dem Spatel auflockern und 4 Minuten braten. ⏱ 4
6. Sojasauce und Zucker zugeben, Tomate und Frühlingszwiebeln 1 Minute unterheben.
7. [Mit Garnelen] Fischsauce zugeben.
8. [Mit Garnelen] Garnelen zurückgeben. Mit Gurke und Limette servieren.

## Notizen

Frisch gekochter Reis klumpt; lieber 1 Stunde im Kühlschrank auskühlen lassen.
