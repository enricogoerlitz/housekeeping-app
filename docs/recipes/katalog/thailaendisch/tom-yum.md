# Tom Yum mit Garnelen

![Tom Yum mit Garnelen](../../pictures/tom-yum.jpg)

Scharf-saure Suppe mit Zitronengras und Limette. Mit Reis ein leichtes Hauptgericht.

## Zutaten

| Menge      | Zutat                 | Gruppe | Variante     | Hinweis                | Einkauf |
| ---------- | --------------------- | ------ | ------------ | ---------------------- | ------- |
| 800 ml     | Gemüsebrühe           |        |              |                        |         |
| 2 Stängel  | Zitronengras          |        |              | angedrückt, in Stücken |         |
| 3 Scheiben | Galgant               |        |              | oder Ingwer            |         |
| 4          | Kaffirlimettenblätter |        |              |                        |         |
| 2 EL       | Tom-Yum-Paste         |        |              |                        |         |
| 200 g      | Champignons           |        |              | geviertelt             |         |
| 2          | Tomate                |        |              | geviertelt             |         |
| 250 g      | Garnelen              |        | Mit Garnelen | geschält               | Menge   |
| 200 g      | Tofu                  |        | Vegetarisch  | gewürfelt              | Menge   |
| 1 EL       | Fischsauce            |        | Mit Garnelen |                        |         |
| 1 EL       | Sojasauce             |        | Vegetarisch  |                        |         |
| 2          | Limette               |        |              | Saft                   |         |
| 1 Bund     | Koriandergrün         |        |              |                        |         |
| 200 g      | Jasminreis            |        |              |                        |         |
| 500 ml     | Wasser                |        |              |                        | nie     |

## Zubereitung

1. Brühe mit Zitronengras, Galgant, Limettenblättern und Tom-Yum-Paste aufkochen, 8 Minuten köcheln. ⏱ 8
2. Champignons und Tomaten zugeben und 4 Minuten garen. ⏱ 4
3. [Mit Garnelen] Garnelen zugeben und 3 Minuten gar ziehen lassen. ⏱ 3
4. [Vegetarisch] Tofu zugeben und 3 Minuten erwärmen. ⏱ 3
5. Vom Herd nehmen, Fisch- oder Sojasauce und Limettensaft einrühren.
6. Reis garen und die Suppe mit Koriander servieren.

## Notizen

Limettensaft erst vom Herd zugeben, sonst wird die Suppe bitter. Tom-Yum-Paste ist oft schon sehr scharf.
