# Kokosreis

![Kokosreis](../../pictures/kokosreis.jpg)

Duftender Jasminreis mit Kokosmilch, passt zu scharfen Currys und Gegrilltem.

## Zutaten

| Menge  | Zutat        | Gruppe | Variante | Hinweis  | Einkauf |
| ------ | ------------ | ------ | -------- | -------- | ------- |
| 250 g  | Jasminreis   |        |          |          |         |
| 200 ml | Kokosmilch   |        |          |          |         |
| 250 ml | Wasser       |        |          |          | nie     |
| 0,5 TL | Salz         |        |          |          |         |
| 1 TL   | Zucker       |        |          |          |         |
| 2 EL   | Kokosraspeln |        |          | geröstet |         |

## Zubereitung

1. Reis in einem Sieb unter kaltem Wasser spülen, bis das Wasser klar ist.
2. Kokosmilch, Wasser, Salz und Zucker aufkochen, Reis zugeben.
3. Zugedeckt bei kleinster Hitze 12 Minuten garen, 10 Minuten ohne Hitze quellen lassen. ⏱ 12
4. Auflockern und mit Kokosraspeln bestreuen.

## Notizen

Reste lassen sich als Basis für Khao Pad nutzen.
