# Rotes Thai-Curry mit Kürbis

![Rotes Thai-Curry mit Kürbis](../../pictures/rotes-curry.jpg)

Rotes Curry mit Kürbis und Paprika, sämig-süß mit leichter Schärfe.

## Zutaten

| Menge      | Zutat           | Gruppe | Variante    | Hinweis            | Einkauf |
| ---------- | --------------- | ------ | ----------- | ------------------ | ------- |
| 2 EL       | Rote Currypaste |        |             |                    |         |
| 1 EL       | Pflanzenöl      |        |             |                    |         |
| 400 ml     | Kokosmilch      |        |             |                    |         |
| 300 g      | Hokkaido Kürbis |        |             | in Würfeln         |         |
| 1          | Paprika         |        |             | rot, in Streifen   |         |
| 200 g      | Kichererbsen    |        | Vegetarisch | Dose, abgetropft   |         |
| 300 g      | Entenbrust      |        | Mit Ente    | in dünnen Scheiben | Menge   |
| 1 EL       | Sojasauce       |        |             |                    |         |
| 1 EL       | Palmzucker      |        |             |                    |         |
| 1          | Limette         |        |             | Saft               |         |
| 1 Handvoll | Thai-Basilikum  |        |             |                    |         |
| 250 g      | Jasminreis      |        |             |                    |         |
| 500 ml     | Wasser          |        |             |                    | nie     |

## Zubereitung

1. Öl erhitzen, Currypaste 1 Minute anrösten.
2. [Mit Ente] Entenscheiben mit der Paste 3 Minuten anbraten. ⏱ 3
3. Kokosmilch und 100 ml Wasser zugeben, aufkochen, Kürbis zugeben und 10 Minuten köcheln. ⏱ 10
4. Paprika zugeben und 5 Minuten weitergaren. ⏱ 5
5. [Vegetarisch] Kichererbsen zugeben und 3 Minuten miterwärmen.
6. Mit Sojasauce, Palmzucker und Limettensaft abschmecken, Basilikum unterheben.
7. Reis garen und servieren.

## Notizen

Hokkaido muss nicht geschält werden. Kichererbsen können durch Tofu ersetzt werden.
