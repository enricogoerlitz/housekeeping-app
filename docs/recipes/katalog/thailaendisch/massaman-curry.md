# Massaman-Curry

![Massaman-Curry](../../pictures/massaman-curry.jpg)

Mildes, würziges Curry mit Kartoffeln, Zwiebeln und Erdnüssen, beeinflusst von persischen und indischen Gewürzen.

## Zutaten

| Menge  | Zutat           | Gruppe | Variante    | Hinweis                   | Einkauf |
| ------ | --------------- | ------ | ----------- | ------------------------- | ------- |
| 400 g  | Rindfleisch     |        | Mit Rind    | Schmorfleisch, in Würfeln | Menge   |
| 300 g  | Süßkartoffel    |        | Vegetarisch | in Würfeln                |         |
| 200 g  | Kichererbsen    |        | Vegetarisch | Dose, abgetropft          |         |
| 2 EL   | Currypaste      |        |             | Massaman                  |         |
| 1 EL   | Pflanzenöl      |        |             |                           |         |
| 400 ml | Kokosmilch      |        |             |                           |         |
| 300 g  | Kartoffeln      |        |             | festkochend, in Würfeln   |         |
| 2      | Zwiebel         |        |             | geviertelt                |         |
| 2 EL   | Tamarindenpaste |        |             |                           |         |
| 1 EL   | Palmzucker      |        |             |                           |         |

| 2 EL   | Sojasauce       |        | Vegetarisch |                           |         |
| 40 g   | Erdnüsse        |        |             | geröstet                  |         |
| 250 g  | Jasminreis      |        |             |                           |         |

## Zubereitung

1. Öl erhitzen, Currypaste 1 Minute anrösten, Kokosmilch zugeben.
2. [Mit Rind] Rindfleisch und 200 ml Wasser zugeben, zugedeckt 40 Minuten schmoren. ⏱ 40
3. [Vegetarisch] 200 ml Wasser zugeben und 5 Minuten köcheln. ⏱ 5
4. Kartoffeln und Zwiebeln zugeben und 20 Minuten garen.
5. [Vegetarisch] Süßkartoffel und Kichererbsen mit den Kartoffeln zugeben. ⏱ 20
6. Mit Tamarinde, Palmzucker und Fisch- bzw. Sojasauce abschmecken.
7. Mit Erdnüssen bestreuen, Reis garen und servieren.

## Notizen

Das Curry schmeckt am nächsten Tag noch runder. Ohne Massaman-Paste: Rote Currypaste plus je 1 TL Zimt und Kreuzkümmel.
