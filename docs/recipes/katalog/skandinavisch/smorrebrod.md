# Smørrebrød

![Smørrebrød](../../pictures/smorrebrod.jpg)

Dänisches belegtes Roggenbrot: dünn mit Butter, üppig belegt mit Ei, Radieschen und Remoulade oder Roastbeef.

## Zutaten

| Menge     | Zutat        | Gruppe | Variante      | Hinweis                  | Einkauf |
| --------- | ------------ | ------ | ------------- | ------------------------ | ------- |
| 4 Scheibe | Brot         |        |               | Roggenbrot, dunkel, dünn |         |
| 40 g      | Butter       |        |               | weich                    |         |
| 4         | Ei           |        | Vegetarisch   |                          |         |
| 1         | Gurke        |        | Vegetarisch   | in dünnen Scheiben       |         |
| 4         | Radieschen   |        | Vegetarisch   | in Scheiben              |         |
| 150 g     | Roastbeef    |        | Mit Roastbeef | in dünnen Scheiben       | Menge   |
| 2 EL      | Remoulade    |        |               |                          |         |
| 2 EL      | Röstzwiebeln |        |               |                          |         |
| 1 Bund    | Schnittlauch |        |               |                          |         |
| 1/2 Bund  | Dill         |        |               |                          |         |
| 2         | Kopfsalat    |        |               |                          |         |

## Zubereitung

1. Eier 8 Minuten kochen, abschrecken, pellen und in Scheiben schneiden. ⏱ 8
2. Brotscheiben dünn mit Butter bestreichen und mit Salatblättern belegen.
3. [Vegetarisch] Brot mit Ei, Gurke, Radieschen und einem Klecks Remoulade belegen, mit Schnittlauch und Dill bestreuen.
4. [Mit Roastbeef] Brot mit Roastbeef, Remoulade, Röstzwiebeln und Gurke belegen.
5. Direkt servieren, damit das Brot nicht aufweicht.

## Notizen

Echtes dänisches Roggenbrot (Rugbrød) bekommt man in größeren Supermärkten; ersatzweise Vollkornbrot. Remoulade ist die dänische mit Gurkenstücken.
