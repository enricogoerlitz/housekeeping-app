# Rödbetssallad

![Rödbetssallad](../../pictures/roedbetssallad.jpg)

Schwedischer Rote-Bete-Salat mit Apfel, Gurke und Sauerrahm, rosa, frisch und leicht süß-säuerlich.

## Zutaten

| Menge  | Zutat        | Gruppe | Variante | Hinweis              | Einkauf |
| ------ | ------------ | ------ | -------- | -------------------- | ------- |
| 250 g  | Rote Bete    |        |          | vorgegart, gewürfelt |         |
| 1      | Apfel        |        |          | säuerlich, gewürfelt |         |
| 1/2    | Gurke        |        |          | gewürfelt            |         |
| 1/2    | Rote Zwiebel |        |          | fein gewürfelt       |         |
| 100 g  | Saure Sahne  |        |          |                      |         |
| 1 EL   | Zitronen     |        |          | Saft                 |         |
| 1 EL   | Dill         |        |          |                      |         |
| 1/2 TL | Salz         |        |          |                      |         |

## Zubereitung

1. Rote Bete, Apfel, Gurke und Zwiebel in eine Schüssel geben.
2. Saure Sahne mit Zitronensaft und Salz verrühren und untermengen.
3. 10 Minuten durchziehen lassen, mit Dill bestreuen. ⏱ 10

## Notizen

Wird sehr rosa. Mit Joghurt oder Quark statt Saurer Sahne etwas leichter.
