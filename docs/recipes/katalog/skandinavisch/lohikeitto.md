# Lohikeitto

![Lohikeitto](../../pictures/lohikeitto.jpg)

Finnische Lachssuppe mit Kartoffeln, Karotte und Lauch in Sahnebrühe, mit viel Dill und Pfeffer.

## Zutaten

| Menge  | Zutat       | Gruppe | Variante    | Hinweis               | Einkauf |
| ------ | ----------- | ------ | ----------- | --------------------- | ------- |
| 250 g  | Lachsfilet  |        | Mit Lachs   | ohne Haut, in Würfeln | Menge   |
| 200 g  | Räuchertofu |        | Vegetarisch | in Würfeln            | Menge   |
| 400 g  | Kartoffeln  |        |             | in 1 cm Würfeln       |         |
| 2      | Karotte     |        |             | in Scheiben           |         |
| 1      | Lauch       |        |             | in Ringen             |         |
| 1      | Zwiebel     |        |             | gewürfelt             |         |
| 1 EL   | Butter      |        |             |                       |         |
| 600 ml | Gemüsebrühe |        |             |                       |         |
| 150 ml | Sahne       |        |             |                       |         |
| 1/2 TL | Piment      |        |             |                       |         |
| 1 Bund | Dill        |        |             |                       |         |
| 1 TL   | Salz        |        |             |                       |         |
| 1/2 TL | Pfeffer     |        |             |                       |         |

## Zubereitung

1. Zwiebel und Lauch in Butter 4 Minuten anschwitzen. ⏱ 4
2. Kartoffeln, Karotten, Piment und Brühe zugeben und 12 Minuten köcheln. ⏱ 12
3. Sahne einrühren.
4. [Mit Lachs] Lachswürfel in die heiße Suppe geben und 4 Minuten bei geringer Hitze gar ziehen lassen, nicht kochen. ⏱ 4
5. [Vegetarisch] Räuchertofu zugeben und 5 Minuten erhitzen. ⏱ 5
6. Mit Salz, Pfeffer und Dill abschmecken.

## Notizen

Das Brot dazu: dunkles Roggenbrot mit Butter.
