# Raggmunk mit Preiselbeeren

![Raggmunk mit Preiselbeeren](../../pictures/raggmunk.jpg)

Schwedische Kartoffelpuffer mit etwas Teig, knusprig in Butter gebraten, mit Preiselbeeren und gebratenem Speck.

## Zutaten

| Menge  | Zutat         | Gruppe | Variante    | Hinweis                      | Einkauf |
| ------ | ------------- | ------ | ----------- | ---------------------------- | ------- |
| 500 g  | Kartoffeln    |        |             | mehligkochend, fein gerieben |         |
| 2      | Ei            |        |             |                              |         |
| 100 ml | Milch         |        |             |                              |         |
| 3 EL   | Mehl          |        |             |                              |         |
| 1 TL   | Salz          |        |             |                              |         |
| 60 g   | Butter        |        |             | zum Braten                   |         |
| 150 g  | Bacon         |        | Mit Speck   | in Streifen                  | Menge   |
| 4 EL   | Preiselbeeren |        |             | aus dem Glas                 |         |
| 1      | Apfel         |        | Vegetarisch | in dünnen Scheiben           |         |

## Zubereitung

1. Eier, Milch, Mehl und Salz glatt verrühren, die geriebenen Kartoffeln samt Saft unterheben.
2. [Mit Speck] Bacon in einer Pfanne 6 Minuten knusprig braten und herausnehmen. ⏱ 6
3. Butter in einer Pfanne erhitzen, Teig mit einer Kelle als kleine Puffer hineingeben und flach drücken.
4. Bei mittlerer Hitze von jeder Seite 4 bis 5 Minuten goldbraun backen. ⏱ 9
5. Mit Preiselbeeren servieren, mit Speck bzw. Apfelscheiben.

## Notizen

Kartoffeln nicht ausdrücken, die Stärke im Saft bindet den Teig.
