# Brunede Kartofler

![Brunede Kartofler](../../pictures/brunede-kartofler.jpg)

Dänische karamellisierte Kartoffeln, die Weihnachtsbeilage zu Ente und Braten: süß-salzig und glänzend.

## Zutaten

| Menge   | Zutat      | Gruppe | Variante | Hinweis                                           | Einkauf |
| ------- | ---------- | ------ | -------- | ------------------------------------------------- | ------- |
| 500 g   | Kartoffeln |        |          | Drillinge, kleine Kartoffeln, gekocht und gepellt |         |
| 3 EL    | Zucker     |        |          |                                                   |         |
| 30 g    | Butter     |        |          |                                                   |         |
| 1 Prise | Salz       |        |          |                                                   |         |

## Zubereitung

1. Kartoffeln 15 Minuten in Salzwasser kochen, pellen und gut abtrocknen. ⏱ 15
2. Zucker in einer großen Pfanne bei mittlerer Hitze ohne Rühren zu einem goldbraunen Karamell schmelzen. ⏱ 5
3. Butter einrühren, Kartoffeln zugeben und 5 Minuten schwenken, bis sie rundum glänzen. ⏱ 5
4. Sofort servieren.

## Notizen

Nicht rühren, solange der Zucker schmilzt, sonst kristallisiert er.
