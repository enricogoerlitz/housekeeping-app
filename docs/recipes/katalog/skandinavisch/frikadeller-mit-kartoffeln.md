# Dänische Frikadeller

![Dänische Frikadeller](../../pictures/frikadeller-mit-kartoffeln.jpg)

Dänische Fleischpflanzerl aus Schwein und Kalb, mit Zwiebel und Milch locker gemacht, in Butter gebraten, mit Kartoffeln und Rotkohl.

## Zutaten

| Menge  | Zutat                  | Gruppe | Variante         | Hinweis                     | Einkauf |
| ------ | ---------------------- | ------ | ---------------- | --------------------------- | ------- |
| 400 g  | Gemischtes Hackfleisch |        | Mit Schweinehack | Schwein und Kalb            | Menge   |
| 2      | Zucchini               |        | Vegetarisch      | fein geraspelt, ausgedrückt |         |
| 80 g   | Haferflocken           |        | Vegetarisch      | zart                        |         |
| 100 g  | Gouda                  |        | Vegetarisch      | gerieben                    | Menge   |
| 1      | Zwiebel                |        |                  | fein gerieben               |         |
| 1      | Ei                     |        |                  |                             |         |
| 2 EL   | Mehl                   |        |                  |                             |         |
| 100 ml | Milch                  |        |                  |                             |         |
| 1 TL   | Salz                   |        |                  |                             |         |
| 1/2 TL | Pfeffer                |        |                  |                             |         |
| 3 EL   | Butter                 |        |                  | zum Braten                  |         |
| 600 g  | Kartoffeln             |        |                  | festkochend                 |         |
| 200 g  | Rotkohl                |        |                  | aus dem Glas                |         |
| 4      | Gewürzgurke            |        |                  |                             |         |

## Zubereitung

1. Kartoffeln schälen und in Salzwasser 20 Minuten kochen. ⏱ 20
2. [Mit Schweinehack] Hack mit Zwiebel, Ei, Mehl, Salz und Pfeffer verkneten, dann die Milch löffelweise einarbeiten, bis ein weicher Teig entsteht.
3. [Vegetarisch] Zucchini, Haferflocken, Käse, Zwiebel, Ei, Mehl, Milch, Salz und Pfeffer vermengen und 15 Minuten quellen lassen. ⏱ 15
4. Aus der Masse mit nassem Löffel ovale Klöße formen und leicht flach drücken.
5. Butter in der Pfanne erhitzen, Frikadeller bei mittlerer Hitze von jeder Seite 6 Minuten goldbraun braten. ⏱ 12
6. Mit Kartoffeln, Rotkohl und Gurke anrichten.

## Notizen

Die Masse soll weich sein, nicht fest. Mit Milch kontrollieren: sie hält gerade so die Form. Dazu Bratensauce aus dem Bratensatz.
