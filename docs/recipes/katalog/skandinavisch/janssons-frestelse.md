# Janssons Frestelse

![Janssons Frestelse](../../pictures/janssons-frestelse.jpg)

Schwedischer Kartoffelauflauf mit Zwiebeln und eingelegten Anchovis in Sahne, goldbraun überbacken.

## Zutaten

| Menge    | Zutat        | Gruppe | Variante     | Hinweis                          | Einkauf |
| -------- | ------------ | ------ | ------------ | -------------------------------- | ------- |
| 600 g    | Kartoffeln   |        |              | mehligkochend, in feine Streifen |         |
| 2        | Zwiebel      |        |              | in Ringen                        |         |
| 1 Dose   | Anchovis     |        | Mit Anchosen | Anchosen (Gewürzsprotten), 125 g | 1×      |
| 200 g    | Champignons  |        | Vegetarisch  | in Scheiben                      | Menge   |
| 2 EL     | Butter       |        |              |                                  |         |
| 250 ml   | Sahne        |        |              |                                  |         |
| 50 ml    | Milch        |        |              |                                  |         |
| 3 EL     | Semmelbrösel |        |              |                                  |         |
| 1 TL     | Salz         |        |              |                                  |         |
| 1/2 TL   | Pfeffer      |        |              | weiß                             |         |
| 1/2 Bund | Dill         |        |              |                                  |         |

## Zubereitung

1. Ofen auf 200 °C vorheizen, Form mit Butter einfetten.
2. Zwiebeln in 1 EL Butter 8 Minuten weich dünsten.
3. [Vegetarisch] Pilze dazu und 5 Minuten mitbraten. ⏱ 8
4. Kartoffelstreifen, Zwiebeln und Anchosen (Vegetarisch: die Pilze) in drei Lagen in die Form schichten, jede Lage pfeffern.
5. Sahne und Milch mit Salz verrühren und darübergießen, mit Semmelbröseln und Butterflöckchen bestreuen.
6. Im Ofen 45 Minuten backen, bis die Kartoffeln weich sind und die Oberfläche goldbraun ist. ⏱ 45
7. 5 Minuten ruhen lassen, mit Dill bestreuen.

## Notizen

Anchosen nicht mit Sardellen verwechseln: Anchosen sind süß-säuerlich gewürzte Sprotten, im Fischregal. Ersatz: Sardellenfilets, dann weniger Salz.
