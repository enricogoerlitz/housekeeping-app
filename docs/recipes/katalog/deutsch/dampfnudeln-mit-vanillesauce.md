# Dampfnudeln mit Vanillesauce

![Dampfnudeln mit Vanillesauce](../../pictures/dampfnudeln-mit-vanillesauce.jpg)

Fluffige Hefeknödel aus der Pfanne mit knuspriger Unterseite, in Milch und Butter gedämpft. Dazu warme Vanillesauce.

## Zutaten

| Menge      | Zutat                | Gruppe | Variante | Hinweis  | Einkauf |
| ---------- | -------------------- | ------ | -------- | -------- | ------- |
| 250 g      | Mehl                 | Teig   |          | Type 550 |         |
| 1/2 Würfel | Frischhefe           | Teig   |          | 20 g     |         |
| 120 ml     | Milch                | Teig   |          | lauwarm  |         |
| 30 g       | Zucker               | Teig   |          |          |         |
| 1          | Ei                   | Teig   |          |          |         |
| 30 g       | Butter               | Teig   |          | weich    |         |

| 150 ml     | Milch                | Garen  |          |          |         |
| 2 EL       | Butter               | Garen  |          |          |         |
| 1 EL       | Zucker               | Garen  |          |          |         |
| 250 ml     | Milch                | Sauce  |          |          |         |
| 1 Päckchen | Vanillepuddingpulver | Sauce  |          |          |         |
| 2 EL       | Zucker               | Sauce  |          |          |         |

## Zubereitung

1. Hefe in lauwarmer Milch mit 1 TL Zucker auflösen, mit den restlichen Teigzutaten 8 Minuten kneten und zugedeckt 45 Minuten gehen lassen. ⏱ 45
2. Teig in vier Stücke teilen, zu Kugeln formen und 15 Minuten ruhen lassen. ⏱ 15
3. Milch, Butter und Zucker in einer breiten Pfanne mit Deckel erhitzen, Kugeln einsetzen.
4. Mit Deckel 20 Minuten bei kleiner Hitze dämpfen, Deckel nicht anheben, bis sich unten eine Kruste gebildet hat. ⏱ 20
5. Währenddessen Pudding aus Milch, Pulver und Zucker nach Packung kochen und als Vanillesauce mit etwas Milch verdünnen.
6. Dampfnudeln mit der Kruste nach oben anrichten und mit Sauce servieren.

## Notizen

OFFEN: Die Vanillesauce ist mit Puddingpulver vereinfacht; echte Sauce mit Eigelb ist möglich.
