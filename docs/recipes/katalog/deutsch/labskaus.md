# Labskaus mit Spiegelei und Rollmops

![Labskaus mit Spiegelei und Rollmops](../../pictures/labskaus.jpg)

Das Seemannsgericht aus Hamburg und Bremen: rosa Stampf mit Spiegelei, Gewürzgurke und Rollmops. Vegetarisch trägt gebratene Rote Bete den Geschmack.

## Zutaten

| Menge   | Zutat        | Gruppe | Variante        | Hinweis                                       | Einkauf |
| ------- | ------------ | ------ | --------------- | --------------------------------------------- | ------- |
| 500 g   | Kartoffeln   |        |                 | mehligkochend, geschält                       |         |
| 1       | Zwiebel      |        |                 | fein gewürfelt                                |         |
| 200 g   | Corned Beef  |        | Mit Corned Beef |                                               |         |
| 200 g   | Rote Bete    |        |                 | vorgegart, vakuumiert, gewürfelt              |         |
| 2 EL    | Gewürzgurken |        |                 | Gurkenwasser aus dem Glas, aus dem Gurkenglas | nie     |

| 2       | Gewürzgurke  |        |                 |                                               |         |
| 1 Prise | Muskatnuss   |        |                 | gerieben                                      |         |
|         | Salz         |        |                 |                                               |         |
|         | Pfeffer      |        |                 |                                               |         |

## Zubereitung

1. Kartoffeln in Salzwasser 20 Minuten gar kochen, abgießen und grob zerstampfen. ⏱ 20
2. Zwiebel in Butter 4 Minuten glasig dünsten. ⏱ 4
3. [Mit Corned Beef] Corned Beef in die Pfanne zerpflücken und 3 Minuten mitbraten. ⏱ 3
4. [Vegetarisch] 100 g mehr Rote Bete würfeln und 5 Minuten in der Zwiebelpfanne anbraten. ⏱ 5
5. Kartoffelstampf, restliche Rote Bete und Gurkenwasser unterheben, mit Salz, Pfeffer und Muskat würzen und 5 Minuten erhitzen. ⏱ 5
6. Spiegeleier im Öl braten.
7. Labskaus auf Teller geben, Spiegelei, Gurke und (nicht vegetarisch) Rollmops dazulegen.

## Notizen

Der Rollmops ist optional; vegetarisch reicht man dazu eingelegte Rote Bete und Gurke.
