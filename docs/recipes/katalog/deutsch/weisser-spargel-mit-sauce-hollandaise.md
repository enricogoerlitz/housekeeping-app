# Weißer Spargel mit Sauce Hollandaise

![Weißer Spargel mit Sauce Hollandaise](../../pictures/weisser-spargel-mit-sauce-hollandaise.jpg)

Spargelzeit: zarter weißer Spargel mit selbst gerührter Hollandaise und Pellkartoffeln. Wer mag, legt Kochschinken dazu.

## Zutaten

| Menge      | Zutat        | Gruppe | Variante         | Hinweis                             | Einkauf |
| ---------- | ------------ | ------ | ---------------- | ----------------------------------- | ------- |
| 750 g      | Spargel      |        |                  | weiß, geschält, Enden abgeschnitten | Menge   |
| 500 g      | Kartoffeln   |        |                  | festkochend, neue                   |         |
| 1 TL       | Zucker       |        |                  |                                     |         |
| 1 EL       | Butter       |        |                  | für das Spargelwasser               |         |
| 2          | Eier         | Sauce  |                  |                                     |         |
| 125 g      | Butter       | Sauce  |                  | geschmolzen                         |         |
| 1 EL       | Zitronen     | Sauce  |                  | Saft                                |         |
| 1 EL       | Wasser       | Sauce  |                  |                                     | nie     |
| 4 Scheiben | Kochschinken |        | Mit Kochschinken |                                     |         |
| 1 Bund     | Petersilie   |        |                  | gehackt                             |         |
|            | Salz         |        |                  |                                     |         |
|            | Pfeffer      |        |                  |                                     |         |

## Zubereitung

1. Kartoffeln in Salzwasser 20 Minuten kochen. ⏱ 20
2. Spargelschalen und -enden mit 2 l Wasser, Zucker, Butter und 2 TL Salz 10 Minuten auskochen, Schalen entfernen. ⏱ 10
3. Spargel in den Sud legen und 12 bis 15 Minuten bei kleiner Hitze garen, bis er biegsam, aber noch bissfest ist. ⏱ 14
4. Eigelb, Wasser und Zitronensaft über einem heißen Wasserbad 4 Minuten schaumig schlagen. ⏱ 4
5. Die flüssige Butter in dünnem Strahl unterschlagen, mit Salz und Pfeffer abschmecken.
6. Spargel abtropfen lassen, mit Kartoffeln, Hollandaise und Petersilie anrichten.
7. [Mit Kochschinken] Schinken dazulegen.

## Notizen

Hollandaise darf nicht kochen, sonst gerinnt sie; bei Gerinnung 1 TL kaltes Wasser einrühren. Statt Eigelb-Sauce gehen auch zerlassene Butter mit Bröseln.
