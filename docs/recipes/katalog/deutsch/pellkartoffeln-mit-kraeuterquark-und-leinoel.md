# Pellkartoffeln mit Kräuterquark und Leinöl

![Pellkartoffeln mit Kräuterquark und Leinöl](../../pictures/pellkartoffeln-mit-kraeuterquark-und-leinoel.jpg)

Sächsisch-thüringisches Alltagsgericht: dampfende Pellkartoffeln mit frischem Kräuterquark und Leinöl, das nussig und kräftig schmeckt. Mit Matjes wird daraus ein norddeutscher Klassiker.

## Zutaten

| Menge  | Zutat        | Gruppe | Variante   | Hinweis             | Einkauf |
| ------ | ------------ | ------ | ---------- | ------------------- | ------- |
| 600 g  | Kartoffeln   |        |            | festkochend, klein  |         |
| 250 g  | Speisequark  |        |            | 20 % Fett           |         |
| 100 g  | Saure Sahne  |        |            |                     |         |
| 1 EL   | Zitronen     |        |            | Saft                |         |
| 1 Bund | Schnittlauch |        |            | in Röllchen         |         |
| 1 Bund | Petersilie   |        |            | gehackt             |         |
| 1      | Zwiebel      |        |            | sehr fein gewürfelt |         |
| 3 EL   | Leinöl       |        |            |                     |         |
| 2      | Matjesfilet  |        | Mit Matjes |                     |         |
| 1      | Gewürzgurke  |        |            | in Würfeln          |         |
|        | Salz         |        |            |                     |         |
|        | Pfeffer      |        |            |                     |         |

## Zubereitung

1. Kartoffeln waschen und ungeschält in Salzwasser 25 Minuten garen. ⏱ 25
2. Quark, Saure Sahne und Zitronensaft glatt rühren, Zwiebel, Gurke und Kräuter unterheben und mit Salz und Pfeffer abschmecken.
3. [Mit Matjes] Matjesfilets abtupfen und in Stücke schneiden.
4. Kartoffeln abgießen, kurz ausdämpfen und aufschneiden.
5. Kartoffeln mit dem Quark anrichten, Leinöl darüberträufeln.

## Notizen

Das Leinöl nicht erhitzen und im Kühlschrank dunkel aufbewahren. Statt Leinöl geht auch Rapsöl, der Geschmack wird aber milder.
