# Gaisburger Marsch

![Gaisburger Marsch](../../pictures/gaisburger-marsch.jpg)

Schwäbischer Eintopf aus kräftiger Brühe, Kartoffeln und Spätzle, mit Röstzwiebeln. Vegetarisch kocht man eine kräftige Pilzbrühe.

## Zutaten

| Menge  | Zutat                   | Gruppe       | Variante                | Hinweis                | Einkauf |
| ------ | ----------------------- | ------------ | ----------------------- | ---------------------- | ------- |
| 300 g  | Rinderbrust             |              | Mit Rindfleisch         |                        | Menge   |
| 200 g  | Champignon              |              | Vegetarisch (Pilzbrühe) | in Scheiben            |         |
| 10 g   | Steinpilze (getrocknet) |              | Vegetarisch (Pilzbrühe) |                        |         |
| 1      | Zwiebel                 |              |                         | halbiert               |         |
| 1      | Karotte                 |              |                         |                        |         |
| 1      | Lauch                   |              |                         | Stück                  |         |
| 1      | Lorbeerblatt            |              |                         |                        |         |
| 1 l    | Wasser                  |              |                         |                        | nie     |
| 400 g  | Kartoffeln              |              |                         | festkochend, gewürfelt |         |
| 250 g  | Spätzle                 |              |                         | frisch                 |         |
| 1      | Zwiebel                 | Röstzwiebeln |                         | in Ringen              |         |
| 2 EL   | Butter                  | Röstzwiebeln |                         |                        |         |
| 1 Bund | Schnittlauch            |              |                         |                        |         |
|        | Salz                    |              |                         |                        |         |
|        | Pfeffer                 |              |                         |                        |         |

## Zubereitung

1. [Mit Rindfleisch] Rinderbrust mit Wasser, halbierter Zwiebel, Karotte, Lauch und Lorbeer aufkochen, abschäumen und 90 Minuten sanft garen. ⏱ 90
2. [Vegetarisch (Pilzbrühe)] Steinpilze, Champignons, Zwiebel, Karotte, Lauch und Lorbeer in Wasser 30 Minuten köcheln lassen und abseihen. ⏱ 30
3. Brühe abseihen, Fleisch in Würfel schneiden, mit Salz und Pfeffer abschmecken.
4. Kartoffelwürfel in der Brühe 12 Minuten garen. ⏱ 12
5. Zwiebelringe in Butter 10 Minuten goldbraun rösten. ⏱ 10
6. Spätzle in die Brühe geben und 3 Minuten ziehen lassen; Fleisch zufügen. ⏱ 3
7. In tiefen Tellern mit Röstzwiebeln und Schnittlauch servieren.

## Notizen

OFFEN: Rinderbrust braucht 90 Minuten, die Dauer von 70 Minuten gilt für die vegetarische Variante; mit Fleisch rund 2 Stunden einplanen.
