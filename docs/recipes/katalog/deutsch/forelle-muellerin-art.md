# Forelle Müllerin mit Petersilienkartoffeln

![Forelle Müllerin mit Petersilienkartoffeln](../../pictures/forelle-muellerin-art.jpg)

Die Forelle nach Müllerinart wird in Mehl gewendet und in Butter gebraten, dazu Zitrone und Petersilienkartoffeln. Vegetarisch gibt es Kohlrabischeiben auf dieselbe Weise.

## Zutaten

| Menge  | Zutat      | Gruppe | Variante               | Hinweis                    | Einkauf |
| ------ | ---------- | ------ | ---------------------- | -------------------------- | ------- |
| 2      | Forelle    |        | Mit Forelle            | küchenfertig, ca. 300 g    | Menge   |
| 2      | Kohlrabi   |        | Vegetarisch (Kohlrabi) | in 1 cm Scheiben, geschält | Menge   |
| 3 EL   | Mehl       |        |                        |                            |         |
| 3 EL   | Butter     |        |                        |                            |         |
| 1      | Zitrone    |        |                        |                            |         |
| 500 g  | Kartoffeln |        |                        | festkochend                |         |
| 1 Bund | Petersilie |        |                        | gehackt                    |         |
|        | Salz       |        |                        |                            |         |
|        | Pfeffer    |        |                        |                            |         |

## Zubereitung

1. Kartoffeln schälen und in Salzwasser 20 Minuten kochen. ⏱ 20
2. [Vegetarisch (Kohlrabi)] Kohlrabischeiben in Salzwasser 5 Minuten vorgaren und abtupfen. ⏱ 5
3. Forellen innen und außen salzen, pfeffern, mit Zitronensaft beträufeln und in Mehl wenden. Kohlrabi ebenfalls mehlieren.
4. [Mit Forelle] Die Hälfte der Butter in einer Pfanne schäumen lassen und die Forellen 5 bis 6 Minuten je Seite braten. ⏱ 11
5. [Vegetarisch (Kohlrabi)] Die Hälfte der Butter schäumen lassen und die Kohlrabischeiben 4 Minuten je Seite goldbraun braten. ⏱ 8
6. Kartoffeln abgießen, in der restlichen Butter mit Petersilie schwenken.
7. Fisch oder Kohlrabi mit Zitronenspalten und Kartoffeln servieren.

## Notizen

Statt der ganzen Forelle gehen auch Filets (kürzer braten, je Seite etwa 3 Minuten).
