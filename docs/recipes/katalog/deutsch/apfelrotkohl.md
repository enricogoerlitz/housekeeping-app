# Apfelrotkohl

![Apfelrotkohl](../../pictures/apfelrotkohl.jpg)

Süßsauer geschmorter Rotkohl mit Apfel, Nelke und Johannisbeergelee, ein Klassiker zu Braten und Knödeln.

## Zutaten

| Menge  | Zutat         | Gruppe | Variante | Hinweis                  | Einkauf |
| ------ | ------------- | ------ | -------- | ------------------------ | ------- |
| 1/2    | Rotkohl       |        |          | ca. 500 g, fein gehobelt |         |
| 1      | Apfel         |        |          | säuerlich, geraspelt     |         |
| 1      | Zwiebel       |        |          | gewürfelt                |         |
| 2 EL   | Butterschmalz |        |          |                          |         |
| 3 EL   | Rotweinessig  |        |          |                          |         |
| 100 ml | Apfelsaft     |        |          |                          |         |
| 100 ml | Rotwein       |        |          |                          |         |
| 1 EL   | Marmelade     |        |          | Johannisbeergelee        |         |
| 2      | Nelke         |        |          |                          |         |
| 1      | Lorbeerblatt  |        |          |                          |         |
| 1 TL   | Zucker        |        |          |                          |         |
|        | Salz          |        |          |                          |         |
|        | Pfeffer       |        |          |                          |         |

## Zubereitung

1. Zwiebel im Butterschmalz 3 Minuten anschwitzen. ⏱ 3
2. Rotkohl zugeben, 5 Minuten mitdünsten und mit Essig ablöschen.
3. Apfel, Apfelsaft, Rotwein, Gewürze, Zucker und Salz zugeben, zugedeckt 45 Minuten bei kleiner Hitze schmoren, gelegentlich umrühren. ⏱ 45
4. Gelee einrühren, Nelke und Lorbeer entfernen und abschmecken.

## Notizen

Schmeckt aufgewärmt noch besser. Ohne Wein: Saft verdoppeln und 1 EL mehr Essig.
