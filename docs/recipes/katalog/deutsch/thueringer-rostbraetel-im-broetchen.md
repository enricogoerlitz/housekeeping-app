# Thüringer Rostbrätel mit Röstzwiebeln und Senf

![Thüringer Rostbrätel mit Röstzwiebeln und Senf](../../pictures/thueringer-rostbraetel-im-broetchen.jpg)

Thüringer Rostbrätel sind in Bier und Zwiebeln marinierte Nackensteaks. Vegetarisch werden große Portobello-Pilze in derselben Marinade gebraten.

## Zutaten

| Menge  | Zutat          | Gruppe   | Variante                 | Hinweis                     | Einkauf |
| ------ | -------------- | -------- | ------------------------ | --------------------------- | ------- |
| 2      | Schweinenacken |          | Mit Schweinenacken       | à 150 g                     |         |
| 4      | Portobello     |          | Vegetarisch (Portobello) | große Pilze, Stiel entfernt | Menge   |
| 2      | Zwiebel        |          |                          | in Ringen                   |         |
| 100 ml | Bier           | Marinade |                          | hell                        |         |
| 2 EL   | Öl             | Marinade |                          |                             |         |

| 1 TL   | Paprikapulver  | Marinade |                          | edelsüß                     |         |
| 1 TL   | Majoran        | Marinade |                          | getrocknet                  |         |
| 2      | Knoblauch      | Marinade |                          | Zehen, gepresst             |         |
| 2      | Brötchen       |          |                          | knusprig                    |         |

## Zubereitung

1. Marinade aus Bier, Öl, Senf, Paprika, Majoran, Knoblauch, Salz und Pfeffer verrühren.
2. Fleisch bzw. Pilze mit der Hälfte der Zwiebelringe in die Marinade legen und mindestens 2 Stunden (gern über Nacht) im Kühlschrank ziehen lassen.
3. Die übrigen Zwiebelringe in 1 EL Öl 12 Minuten goldbraun rösten, herausnehmen. ⏱ 12
4. [Mit Schweinenacken] Steaks abtupfen und in einer heißen Pfanne mit dem restlichen Öl 5 Minuten je Seite braten. ⏱ 10
5. [Vegetarisch (Portobello)] Pilze abtupfen und in einer heißen Pfanne mit dem restlichen Öl 5 Minuten je Seite braten, bis sie Saft abgeben und Farbe haben. ⏱ 10
6. Brötchen aufschneiden, mit Senf bestreichen, Rostbrätel und Röstzwiebeln hineinlegen.

## Notizen

Auf dem Grill noch besser. Marinierte Zwiebeln können mitgebraten werden.
