# Handkäs mit Musik

![Handkäs mit Musik](../../pictures/handkaese-mit-musik.jpg)

Hessische Brotzeit: Handkäs in einer Marinade aus Essig, Öl und Zwiebeln. Die Musik kommt von den Zwiebeln.

## Zutaten

| Menge      | Zutat      | Gruppe | Variante | Hinweis          | Einkauf |
| ---------- | ---------- | ------ | -------- | ---------------- | ------- |
| 2          | Handkäse   |        |          | à 125 g          | Menge   |
| 1          | Zwiebel    |        |          | in feinen Ringen |         |
| 3 EL       | Apfelessig |        |          |                  |         |
| 3 EL       | Öl         |        |          |                  |         |
| 1 TL       | Kümmel     |        |          | ganz             |         |
| 1 TL       | Senf       |        |          |                  |         |
| 4 Scheiben | Brot       |        |          | Roggenbrot       |         |
| 2 EL       | Butter     |        |          |                  |         |
|            | Salz       |        |          |                  |         |
|            | Pfeffer    |        |          |                  |         |

## Zubereitung

1. Essig, Öl, Senf, Kümmel, Salz und Pfeffer verrühren.
2. Handkäse in einer flachen Schale mit der Marinade und den Zwiebelringen übergießen.
3. Zugedeckt im Kühlschrank mindestens 4 Stunden marinieren, zwischendurch wenden. ⏱ 240
4. Mit Roggenbrot und Butter servieren.

## Notizen

Handkäse gibt es in Hessen und gut sortierten Märkten; Alternative ist Harzer Käse oder Mainzer Käse.
