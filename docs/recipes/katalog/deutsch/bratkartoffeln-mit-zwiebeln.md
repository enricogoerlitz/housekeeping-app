# Knusprige Bratkartoffeln mit Zwiebeln

![Knusprige Bratkartoffeln mit Zwiebeln](../../pictures/bratkartoffeln-mit-zwiebeln.jpg)

Aus gekochten, abgekühlten Kartoffeln werden die knusprigsten Bratkartoffeln, Zwiebeln kommen erst später dazu.

## Zutaten

| Menge | Zutat         | Gruppe | Variante | Hinweis                        | Einkauf |
| ----- | ------------- | ------ | -------- | ------------------------------ | ------- |
| 600 g | Kartoffeln    |        |          | festkochend, am Vortag gekocht |         |
| 3 EL  | Butterschmalz |        |          |                                |         |
| 1     | Zwiebel       |        |          | in Ringen                      |         |
| 1 TL  | Majoran       |        |          | getrocknet                     |         |
|       | Salz          |        |          |                                |         |
|       | Pfeffer       |        |          |                                |         |

## Zubereitung

1. Pellkartoffeln pellen und in 5 mm dicke Scheiben schneiden.
2. Butterschmalz in einer großen Pfanne erhitzen, Kartoffeln in einer Schicht 10 Minuten ohne Rühren braten. ⏱ 10
3. Wenden und weitere 10 Minuten braten, bis sie goldbraun sind. ⏱ 10
4. Zwiebeln und Majoran zugeben, 6 Minuten mitbraten, mit Salz und Pfeffer würzen. ⏱ 6

## Notizen

Frisch gekochte Kartoffeln werden schmierig; am besten am Vortag kochen oder 30 Minuten ausdampfen lassen.
