# Grünkohl mit Räuchertofu und Salzkartoffeln

![Grünkohl mit Räuchertofu und Salzkartoffeln](../../pictures/gruenkohl-mit-raeuchertofu-und-kartoffeln.jpg)

Norddeutscher Winterklassiker: Grünkohl, langsam gegart mit Zwiebeln und Haferflocken, die die Sauce sämig machen. Statt Pinkel und Kassler gibt es Räuchertofu.

## Zutaten

| Menge  | Zutat           | Gruppe | Variante     | Hinweis                      | Einkauf |
| ------ | --------------- | ------ | ------------ | ---------------------------- | ------- |
| 500 g  | Grünkohl        |        |              | frisch oder TK, grob gehackt |         |
| 1      | Zwiebel         |        |              | gewürfelt                    |         |
| 2 EL   | Schweineschmalz |        | Mit Kasseler |                              |         |
| 2 EL   | Rapsöl          |        | Vegetarisch  |                              |         |
| 300 g  | Kasseler        |        | Mit Kasseler | am Stück                     |         |
| 250 g  | Räuchertofu     |        | Vegetarisch  | in dicken Scheiben           |         |
| 300 ml | Gemüsebrühe     |        |              |                              |         |
| 2 EL   | Haferflocken    |        |              | zart                         |         |
| 1 EL   | Senf            |        |              | mittelscharf                 |         |
| 1 TL   | Zucker          |        |              |                              |         |
| 500 g  | Kartoffeln      |        |              | festkochend, geschält        |         |
|        | Salz            |        |              |                              |         |
|        | Pfeffer         |        |              |                              |         |

## Zubereitung

1. Zwiebel im Schmalz bzw. Rapsöl 3 Minuten glasig dünsten. ⏱ 3
2. Grünkohl zugeben, 3 Minuten mitdünsten, mit Brühe aufgießen und mit Zucker, Salz und Pfeffer würzen.
3. [Mit Kasseler] Kasseler auf den Kohl legen und zugedeckt 40 Minuten bei kleiner Hitze garen. ⏱ 40
4. [Vegetarisch] Zugedeckt 30 Minuten bei kleiner Hitze garen, dabei gelegentlich umrühren. ⏱ 30
5. Kartoffeln in Salzwasser 20 Minuten kochen. ⏱ 20
6. Haferflocken und Senf unter den Kohl rühren und 5 Minuten offen weiter köcheln lassen. ⏱ 5
7. [Vegetarisch] Räuchertofu in einer Pfanne 3 Minuten je Seite braten und auf dem Kohl anrichten. ⏱ 6
8. Kasseler in Scheiben schneiden und mit Kohl und Kartoffeln servieren.

## Notizen

Tiefkühl-Grünkohl spart das Waschen. Der Geschmack wird am zweiten Tag aufgewärmt noch besser.
