# Semmelknödel

![Semmelknödel](../../pictures/semmelknoedel.jpg)

Bayerische Knödel aus altbackenen Semmeln, Milch und Ei, mit Zwiebel und Petersilie. Passen zu Braten, Pilzrahm und Gulasch.

## Zutaten

| Menge   | Zutat      | Gruppe | Variante | Hinweis                       | Einkauf |
| ------- | ---------- | ------ | -------- | ----------------------------- | ------- |
| 4       | Semmel     |        |          | altbacken, in dünnen Scheiben |         |
| 200 ml  | Milch      |        |          | lauwarm                       |         |
| 1       | Zwiebel    |        |          | fein gewürfelt                |         |
| 1 EL    | Butter     |        |          |                               |         |
| 2       | Eier       |        |          |                               |         |
| 2 EL    | Petersilie |        |          | gehackt                       |         |
| 1 Prise | Muskatnuss |        |          |                               |         |
| 1 TL    | Salz       |        |          |                               |         |
| 1 l     | Wasser     |        |          | zum Garen                     | nie     |

## Zubereitung

1. Zwiebel in Butter 3 Minuten glasig dünsten. ⏱ 3
2. Semmelscheiben mit warmer Milch übergießen, Zwiebel, Eier, Petersilie, Muskat und Salz zugeben, vermengen und 15 Minuten durchziehen lassen. ⏱ 15
3. Mit nassen Händen vier Knödel formen, bei Bedarf etwas Bröseln oder Milch nachgeben.
4. Wasser mit Salz aufkochen, Knödel einlegen und 20 Minuten knapp unter dem Siedepunkt ziehen lassen, nicht kochen. ⏱ 20
5. Mit Schaumkelle herausheben.

## Notizen

Zuerst einen Probeknödel garen; fällt er auseinander, etwas Semmelbrösel zufügen. Reste in Scheiben anbraten.
