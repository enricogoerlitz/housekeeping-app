# Hamburger Pannfisch mit Senfsauce

![Hamburger Pannfisch mit Senfsauce](../../pictures/hamburger-pannfisch.jpg)

Gebratener Fisch auf Bratkartoffeln mit milder Senfsauce, wie in Hamburger Fischlokalen. Vegetarisch kommt gebratener Blumenkohl an die Stelle des Fischs.

## Zutaten

| Menge  | Zutat         | Gruppe | Variante                 | Hinweis                   | Einkauf |
| ------ | ------------- | ------ | ------------------------ | ------------------------- | ------- |
| 400 g  | Seelachsfilet |        | Mit Fisch                | in 4 Stücken              | Menge   |
| 1      | Blumenkohl    |        | Vegetarisch (Blumenkohl) | in 1,5 cm dicken Scheiben | Menge   |
| 500 g  | Kartoffeln    |        |                          | festkochend, gekocht      |         |
| 1      | Zwiebel       |        |                          | in Ringen                 |         |
| 3 EL   | Butter        |        |                          |                           |         |
| 2 EL   | Mehl          |        |                          |                           |         |
| 200 ml | Gemüsebrühe   |        |                          |                           |         |
| 100 ml | Sahne         |        |                          |                           |         |
| 2 EL   | Senf          |        |                          | körnig                    |         |
| 1 TL   | Zitronen      |        |                          | Saft                      |         |
| 1 Bund | Dill          |        |                          |                           |         |
|        | Salz          |        |                          |                           |         |
|        | Pfeffer       |        |                          |                           |         |

## Zubereitung

1. Die gekochten Kartoffeln in Scheiben schneiden und in 1 EL Butter mit den Zwiebeln 12 Minuten knusprig braten. ⏱ 12
2. Für die Sauce 1 EL Butter schmelzen, Mehl einrühren, mit Brühe und Sahne ablöschen und 5 Minuten köcheln lassen; Senf, Zitronensaft, Salz und Pfeffer zugeben. ⏱ 5
3. [Mit Fisch] Fisch salzen, mehlieren und in der restlichen Butter 3 Minuten je Seite braten. ⏱ 6
4. [Vegetarisch (Blumenkohl)] Blumenkohlscheiben salzen und in der restlichen Butter 4 Minuten je Seite goldbraun braten. ⏱ 8
5. Bratkartoffeln auf Tellern verteilen, Fisch oder Blumenkohl darauflegen und mit Senfsauce übergießen.
6. Mit Dill bestreuen.

## Notizen

Gelingt auch mit Kabeljau oder Pangasius. Für Blumenkohl-Scheiben vom Strunk aus durchschneiden, die Mittelscheiben halten am besten.
