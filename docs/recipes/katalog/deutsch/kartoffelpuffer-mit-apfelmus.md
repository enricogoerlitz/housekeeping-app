# Kartoffelpuffer mit Apfelmus

![Kartoffelpuffer mit Apfelmus](../../pictures/kartoffelpuffer-mit-apfelmus.jpg)

Reibekuchen, außen knusprig, innen weich, mit Apfelmus. Mit Räucherlachs und Sauerrahm wird daraus ein herzhafter Teller.

## Zutaten

| Menge   | Zutat        | Gruppe | Variante         | Hinweis       | Einkauf |
| ------- | ------------ | ------ | ---------------- | ------------- | ------- |
| 600 g   | Kartoffeln   |        |                  | mehligkochend |         |
| 1       | Zwiebel      |        |                  |               |         |
| 1       | Ei           |        |                  |               |         |
| 2 EL    | Mehl         |        |                  |               |         |
| 1 Prise | Muskatnuss   |        |                  |               |         |
| 4 EL    | Öl           |        |                  | zum Braten    |         |
| 200 g   | Apfelmus     |        |                  |               |         |
| 100 g   | Räucherlachs |        | Mit Räucherlachs |               |         |
| 2 EL    | Saure Sahne  |        | Mit Räucherlachs |               |         |
| 1 Bund  | Dill         |        | Mit Räucherlachs |               |         |
|         | Salz         |        |                  |               |         |
|         | Pfeffer      |        |                  |               |         |

## Zubereitung

1. Kartoffeln und Zwiebel fein reiben, in ein Tuch geben und kräftig auspressen.
2. Mit Ei, Mehl, Muskat, 1 TL Salz und Pfeffer rasch vermengen.
3. Öl in der Pfanne erhitzen, je 2 EL Teig flach drücken und bei mittlerer Hitze 3 bis 4 Minuten je Seite goldbraun braten. ⏱ 8
4. Auf Küchenpapier abtropfen lassen und im Ofen bei 80 Grad warm halten.
5. Mit Apfelmus servieren.
6. [Mit Räucherlachs] Puffer mit Räucherlachs, Saurer Sahne und Dill belegen.

## Notizen

Teig nicht stehen lassen, er wird sonst grau. Statt Apfelmus passt auch Zucker-Zimt.
