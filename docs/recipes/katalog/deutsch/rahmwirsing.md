# Rahmwirsing

![Rahmwirsing](../../pictures/rahmwirsing.jpg)

Zarter Wirsing in leichter Sahnesauce mit Muskat, eine schnelle Gemüsebeilage zu Fleisch und Fisch.

## Zutaten

| Menge   | Zutat       | Gruppe | Variante | Hinweis                | Einkauf |
| ------- | ----------- | ------ | -------- | ---------------------- | ------- |
| 1/2     | Wirsing     |        |          | ca. 500 g, in Streifen |         |
| 1       | Zwiebel     |        |          | gewürfelt              |         |
| 1 EL    | Butter      |        |          |                        |         |
| 150 ml  | Gemüsebrühe |        |          |                        |         |
| 100 ml  | Sahne       |        |          |                        |         |
| 1 Prise | Muskatnuss  |        |          |                        |         |
|         | Salz        |        |          |                        |         |
|         | Pfeffer     |        |          |                        |         |

## Zubereitung

1. Zwiebel in Butter 3 Minuten glasig dünsten. ⏱ 3
2. Wirsing zugeben und 3 Minuten mitbraten.
3. Brühe angießen, zugedeckt 12 Minuten garen. ⏱ 12
4. Sahne zugeben, offen 3 Minuten einköcheln, mit Muskat, Salz und Pfeffer würzen. ⏱ 3

## Notizen

Mit etwas Mehlbutter lässt sich die Sauce stärker binden.
