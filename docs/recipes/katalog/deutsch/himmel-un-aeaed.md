# Himmel un Ääd mit Blutwurst

![Himmel un Ääd mit Blutwurst](../../pictures/himmel-un-aeaed.jpg)

Kölner Klassiker: Kartoffelpüree („Ääd“) und Apfelmus („Himmel“) mit gebratener Blutwurst und Röstzwiebeln. Vegetarisch gibt es gebratenen Räuchertofu.

## Zutaten

| Menge   | Zutat       | Gruppe | Variante      | Hinweis                         | Einkauf |
| ------- | ----------- | ------ | ------------- | ------------------------------- | ------- |
| 500 g   | Kartoffeln  |        |               | mehligkochend                   |         |
| 3       | Äpfel       |        |               | säuerlich, geschält, in Stücken |         |
| 2 EL    | Zucker      |        |               |                                 |         |
| 50 ml   | Milch       |        |               |                                 |         |
| 2 EL    | Butter      |        |               |                                 |         |
| 2       | Zwiebel     |        |               | in Ringen                       |         |
| 2 EL    | Mehl        |        |               |                                 |         |
| 200 g   | Blutwurst   |        | Mit Blutwurst | Scheiben, 1,5 cm                |         |
| 200 g   | Räuchertofu |        | Vegetarisch   | Scheiben                        |         |
| 1 EL    | Öl          |        |               |                                 |         |
| 1 Prise | Muskatnuss  |        |               |                                 |         |
|         | Salz        |        |               |                                 |         |

## Zubereitung

1. Kartoffeln schälen, vierteln und in Salzwasser 20 Minuten kochen. ⏱ 20
2. Äpfel mit Zucker und 3 EL Wasser 12 Minuten weich kochen und grob zerdrücken. ⏱ 12
3. Zwiebelringe in Mehl wenden und in 1 EL Butter 10 Minuten goldbraun braten, herausnehmen. ⏱ 10
4. [Mit Blutwurst] Blutwurstscheiben im Öl 3 Minuten je Seite knusprig braten. ⏱ 6
5. [Vegetarisch] Räuchertofuscheiben im Öl 3 Minuten je Seite braten. ⏱ 6
6. Kartoffeln abgießen, mit warmer Milch, Butter, Muskat und Salz zu Püree stampfen.
7. Püree mit Apfelmus und Fleisch bzw. Tofu anrichten, Röstzwiebeln darüber geben.

## Notizen

Traditionell wird das Apfelmus nicht ganz püriert. Eine Prise Zimt passt dazu.
