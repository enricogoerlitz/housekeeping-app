# Schwäbischer Kartoffelsalat mit Brühe

![Schwäbischer Kartoffelsalat mit Brühe](../../pictures/schwaebischer-kartoffelsalat.jpg)

Lauwarmer Kartoffelsalat ohne Mayo: Warme Brühe, Essig und Öl machen ihn saftig.

## Zutaten

| Menge  | Zutat          | Gruppe | Variante | Hinweis             | Einkauf |
| ------ | -------------- | ------ | -------- | ------------------- | ------- |
| 600 g  | Kartoffeln     |        |          | festkochend         |         |
| 1      | Zwiebel        |        |          | sehr fein gewürfelt |         |
| 150 ml | Gemüsebrühe    |        |          | heiß                |         |
| 3 EL   | Apfelessig     |        |          |                     |         |
| 1 TL   | Senf           |        |          | mittelscharf        |         |
| 3 EL   | Sonnenblumenöl |        |          |                     |         |
| 1 Bund | Schnittlauch   |        |          | in Röllchen         |         |
|        | Salz           |        |          |                     |         |
|        | Pfeffer        |        |          |                     |         |

## Zubereitung

1. Kartoffeln mit Schale in Salzwasser 25 Minuten garen, pellen und noch warm in feine Scheiben schneiden. ⏱ 25
2. Zwiebel mit heißer Brühe, Essig, Senf, Salz und Pfeffer verrühren.
3. Marinade über die warmen Kartoffeln geben, vorsichtig mischen und 15 Minuten ziehen lassen. ⏱ 15
4. Öl und Schnittlauch unterheben, abschmecken.

## Notizen

Gelingt nur mit festkochenden Kartoffeln. Lauwarm servieren.
