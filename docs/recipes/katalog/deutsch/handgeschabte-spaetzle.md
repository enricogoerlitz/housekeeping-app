# Handgeschabte Spätzle

![Handgeschabte Spätzle](../../pictures/handgeschabte-spaetzle.jpg)

Schwäbische Spätzle vom Brett: unregelmäßig, mit Biss und goldener Butter.

## Zutaten

| Menge   | Zutat      | Gruppe | Variante | Hinweis   | Einkauf |
| ------- | ---------- | ------ | -------- | --------- | ------- |
| 250 g   | Mehl       |        |          | Type 405  |         |
| 3       | Eier       |        |          |           |         |
| 100 ml  | Wasser     |        |          | sprudelnd | nie     |
| 1 TL    | Salz       |        |          |           |         |
| 1 Prise | Muskatnuss |        |          |           |         |
| 2 EL    | Butter     |        |          |           |         |

## Zubereitung

1. Mehl, Eier, Wasser, Salz und Muskat mit einem Holzlöffel 5 Minuten schlagen, bis der Teig Blasen wirft. ⏱ 5
2. Teig 10 Minuten ruhen lassen. ⏱ 10
3. In einem breiten Topf Salzwasser zum leichten Kochen bringen.
4. Teig portionsweise auf ein nasses Brett streichen und mit einem Messer dünn ins Wasser schaben.
5. Spätzle, sobald sie oben schwimmen, nach etwa 1 Minute abschöpfen und in kaltem Wasser kurz abschrecken oder direkt in Butter schwenken. ⏱ 1

## Notizen

Ein Spätzlehobel oder -sieb geht schneller. Reste in der Pfanne braten oder für Gaisburger Marsch nutzen.
