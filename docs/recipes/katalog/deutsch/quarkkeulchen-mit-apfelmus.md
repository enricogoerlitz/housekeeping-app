# Quarkkeulchen mit Apfelmus

![Quarkkeulchen mit Apfelmus](../../pictures/quarkkeulchen-mit-apfelmus.jpg)

Sächsische Spezialität aus Quark und gekochten Kartoffeln, knusprig gebraten und in Zimtzucker gewendet.

## Zutaten

| Menge   | Zutat         | Gruppe     | Variante | Hinweis                   | Einkauf |
| ------- | ------------- | ---------- | -------- | ------------------------- | ------- |
| 300 g   | Kartoffeln    |            |          | gekocht, mehligkochend    |         |
| 250 g   | Speisequark   |            |          | 20 % Fett, gut abgetropft |         |
| 1       | Ei            |            |          |                           |         |
| 50 g    | Mehl          |            |          |                           |         |
| 2 EL    | Zucker        |            |          |                           |         |
| 30 g    | Rosinen       |            |          |                           |         |
| 1 Prise | Salz          |            |          |                           |         |
| 3 EL    | Butterschmalz |            |          |                           |         |
| 2 EL    | Zucker        | Zimtzucker |          |                           |         |
| 1 TL    | Zimt          | Zimtzucker |          |                           |         |
| 200 g   | Apfelmus      |            |          |                           |         |

## Zubereitung

1. Kartoffeln durch die Presse drücken, mit Quark, Ei, Mehl, Zucker, Rosinen und Salz zu einem Teig vermengen.
2. Aus dem Teig kleine flache Küchlein formen.
3. Butterschmalz erhitzen, Küchlein 3 bis 4 Minuten je Seite goldbraun braten. ⏱ 8
4. Im Zimtzucker wenden und mit Apfelmus servieren.

## Notizen

Quark vorher in einem Tuch abtropfen lassen, sonst zerlaufen die Keulchen.
