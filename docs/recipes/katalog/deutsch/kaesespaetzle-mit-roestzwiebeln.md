# Käsespätzle mit Röstzwiebeln

![Käsespätzle mit Röstzwiebeln](../../pictures/kaesespaetzle-mit-roestzwiebeln.jpg)

Allgäuer Klassiker aus Spätzle und kräftigem Bergkäse, mit reichlich Röstzwiebeln. Schmeckt aus der Pfanne am besten.

## Zutaten

| Menge   | Zutat        | Gruppe      | Variante  | Hinweis          | Einkauf |
| ------- | ------------ | ----------- | --------- | ---------------- | ------- |
| 250 g   | Mehl         | Spätzleteig |           | Type 405         |         |
| 3       | Eier         | Spätzleteig |           |                  |         |
| 125 ml  | Wasser       | Spätzleteig |           | sprudelnd        | nie     |
| 1 TL    | Salz         | Spätzleteig |           |                  |         |
| 200 g   | Bergkäse     |             |           | frisch gerieben  |         |
| 100 g   | Emmentaler   |             |           | gerieben         |         |
| 2       | Zwiebel      |             |           | in dünnen Ringen |         |
| 3 EL    | Butter       |             |           |                  |         |
| 1 Prise | Muskatnuss   |             |           | gerieben         |         |
| 100 g   | Speckwürfel  |             | Mit Speck |                  |         |
| 1 Bund  | Schnittlauch |             |           | in Röllchen      |         |
|         | Pfeffer      |             |           |                  |         |

## Zubereitung

1. Mehl, Eier, Wasser und Salz kräftig schlagen, bis der Teig Blasen wirft; 10 Minuten quellen lassen. ⏱ 10
2. Zwiebelringe in 2 EL Butter bei mittlerer Hitze 15 Minuten goldbraun rösten, herausnehmen. ⏱ 15
3. [Mit Speck] Speckwürfel in der Pfanne knusprig auslassen und zu den Zwiebeln geben.
4. Reichlich Salzwasser aufkochen, den Teig durch ein Spätzlesieb oder vom Brett schaben; sobald die Spätzle oben schwimmen, abschöpfen. ⏱ 6
5. Spätzle schichtweise mit dem Käse in einer Pfanne mit der restlichen Butter mischen und bei niedriger Hitze 4 Minuten schmelzen lassen, mit Muskat und Pfeffer würzen. ⏱ 4
6. Mit Röstzwiebeln und Schnittlauch anrichten.

## Notizen

Mit Fertigspätzle (500 g) spart man 10 Minuten. Dazu passt ein grüner Salat mit Essig-Öl-Dressing.
