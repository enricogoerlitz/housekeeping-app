# Linsen mit Spätzle und Saitenwürstle

![Linsen mit Spätzle und Saitenwürstle](../../pictures/linsen-mit-spaetzle-und-saitenwuerstle.jpg)

Das schwäbische Sonntagsessen: Tellerlinsen mit Essig-Schuss, dazu Spätzle und Würstchen. Die vegetarische Version setzt auf Räuchertofu.

## Zutaten

| Menge  | Zutat            | Gruppe | Variante          | Hinweis                  | Einkauf |
| ------ | ---------------- | ------ | ----------------- | ------------------------ | ------- |
| 250 g  | Tellerlinsen     |        |                   |                          | Menge   |
| 1      | Zwiebel          |        |                   | gewürfelt                |         |
| 1      | Karotte          |        |                   | gewürfelt                |         |
| 1      | Knollensellerie  |        |                   | 100 g, gewürfelt         |         |
| 2 EL   | Butter           |        |                   |                          |         |
| 1 EL   | Mehl             |        |                   |                          |         |
| 500 ml | Gemüsebrühe      |        |                   |                          |         |
| 1      | Lorbeerblatt     |        |                   |                          |         |
| 2 EL   | Apfelessig       |        |                   |                          |         |
| 1 TL   | Senf             |        |                   |                          |         |
| 250 g  | Spätzle          |        |                   | frisch aus dem Kühlregal |         |
| 4      | Wiener Würstchen |        | Mit Saitenwürstle | Saitenwürstle            |         |
| 200 g  | Räuchertofu      |        | Vegetarisch       | in Würfeln               |         |
| 1 Bund | Petersilie       |        |                   | zum Bestreuen            |         |
|        | Salz             |        |                   |                          |         |
|        | Pfeffer          |        |                   |                          |         |

## Zubereitung

1. Linsen in einem Sieb abspülen. Zwiebel, Karotte und Sellerie würfeln.
2. Butter im Topf zerlassen, das Gemüse 5 Minuten anschwitzen, Mehl darüberstäuben und 1 Minute mitrühren. ⏱ 5
3. Linsen, Brühe und Lorbeerblatt zugeben, aufkochen und zugedeckt 30 Minuten bei kleiner Hitze garen. ⏱ 30
4. Mit Essig, Senf, Salz und Pfeffer abschmecken; Lorbeerblatt entfernen.
5. [Mit Saitenwürstle] Würstchen in den letzten 8 Minuten in den Linsen erhitzen, nicht kochen. ⏱ 8
6. [Vegetarisch] Räuchertofu in einer Pfanne mit etwas Butter 5 Minuten goldbraun braten und auf die Linsen geben. ⏱ 5
7. Spätzle in Butter in einer Pfanne 3 Minuten schwenken, mit den Linsen anrichten und Petersilie darüberstreuen. ⏱ 3

## Notizen

Essig erst am Ende zugeben, sonst werden die Linsen nicht weich. Wer keine frischen Spätzle findet, nimmt Trockenspätzle nach Packung.
