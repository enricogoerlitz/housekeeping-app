# Thüringer Kartoffelklöße

![Thüringer Kartoffelklöße](../../pictures/thueringer-kartoffelkloesse.jpg)

Thüringer Klöße aus roher und gekochter Kartoffel, innen locker und außen glatt, mit einem Semmelwürfel in der Mitte.

## Zutaten

| Menge   | Zutat        | Gruppe | Variante | Hinweis            | Einkauf |
| ------- | ------------ | ------ | -------- | ------------------ | ------- |
| 1 kg    | Kartoffeln   |        |          | mehligkochend      |         |
| 1       | Semmel       |        |          | in kleinen Würfeln |         |
| 2 EL    | Butter       |        |          |                    |         |
| 100 ml  | Milch        |        |          | heiß               |         |
| 1 EL    | Speisestärke |        |          |                    |         |
| 2 TL    | Salz         |        |          |                    |         |
| 1 Prise | Muskatnuss   |        |          |                    |         |
| 2 l     | Wasser       |        |          |                    | nie     |

## Zubereitung

1. Hälfte der Kartoffeln (500 g) schälen und in Salzwasser 20 Minuten weich kochen, abgießen, ausdampfen lassen und pressen. ⏱ 20
2. Semmelwürfel in Butter 4 Minuten knusprig rösten. ⏱ 4
3. Übrige Kartoffeln schälen, fein reiben, in einem Tuch fest auspressen, die Flüssigkeit absetzen lassen und die abgesetzte Stärke zu den rohen Kartoffeln geben.
4. Rohe Masse mit heißer Milch übergießen, die gepressten Kartoffeln, Stärke, Salz und Muskat zufügen und zu einem Teig kneten.
5. Aus dem Teig Klöße formen, in die Mitte einige Semmelwürfel drücken.
6. In leicht siedendem Salzwasser 25 Minuten ziehen lassen. ⏱ 25

## Notizen

Der Teig ist empfindlich: Probekloß garen, bei Zerfall etwas Stärke ergänzen. Zu Rouladen, Braten und Pilzragout.
