# Zwiebelkuchen mit Speck

![Zwiebelkuchen mit Speck](../../pictures/fraenkischer-zwiebelkuchen.jpg)

Herzhafter Hefeteig mit weichen, süßlichen Zwiebeln und Eierguss, im Herbst zum neuen Wein. Der Kümmel gehört unbedingt dazu.

## Zutaten

| Menge      | Zutat       | Gruppe | Variante  | Hinweis   | Einkauf |
| ---------- | ----------- | ------ | --------- | --------- | ------- |
| 250 g      | Mehl        | Teig   |           | Type 550  |         |
| 1/2 Würfel | Frischhefe  | Teig   |           | 20 g      |         |
| 125 ml     | Milch       | Teig   |           | lauwarm   |         |
| 2 EL       | Butter      | Teig   |           | weich     |         |
| 1/2 TL     | Salz        | Teig   |           |           |         |
| 800 g      | Zwiebel     | Belag  |           | in Ringen |         |
| 2 EL       | Butter      | Belag  |           |           |         |
| 100 g      | Speckwürfel | Belag  | Mit Speck |           |         |
| 200 g      | Saure Sahne | Guss   |           |           |         |
| 2          | Eier        | Guss   |           |           |         |
| 1 TL       | Kümmel      | Guss   |           | ganz      |         |
| 1 Prise    | Muskatnuss  | Guss   |           |           |         |
|            | Salz        |        |           |           |         |
|            | Pfeffer     |        |           |           |         |

## Zubereitung

1. Hefe in der Milch auflösen, mit Mehl, Butter und Salz 8 Minuten zu einem glatten Teig kneten und zugedeckt 45 Minuten gehen lassen. ⏱ 45
2. Zwiebeln in Butter bei mittlerer Hitze 15 Minuten glasig und weich dünsten, nicht bräunen. ⏱ 15
3. [Mit Speck] Speckwürfel 4 Minuten mitbraten. ⏱ 4
4. Ofen auf 200 Grad Ober-/Unterhitze vorheizen. Teig ausrollen und in eine gefettete Form (ca. 26 cm) mit Rand legen.
5. Saure Sahne, Eier, Kümmel, Muskat, Salz und Pfeffer verrühren, unter die abgekühlten Zwiebeln heben und auf dem Teig verteilen.
6. Im Ofen 30 Minuten backen, bis der Guss gestockt und gebräunt ist. ⏱ 30

## Notizen

Dazu passt ein Glas Federweißer oder Most. Zwiebelkuchen schmeckt lauwarm am besten.
