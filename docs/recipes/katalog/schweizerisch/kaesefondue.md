# Käsefondue Moitié-Moitié

![Käsefondue Moitié-Moitié](../../pictures/kaesefondue.jpg)

Klassisches Fondue aus Gruyère und Vacherin, mit Brot, Kartoffeln und Essiggemüse.

## Zutaten

| Menge  | Zutat        | Gruppe | Variante | Hinweis                         | Einkauf |
| ------ | ------------ | ------ | -------- | ------------------------------- | ------- |
| 200 g  | Gruyère      |        |          | gerieben                        |         |
| 200 g  | Vacherin     |        |          | gerieben, alternativ Emmentaler |         |
| 1      | Knoblauch    |        |          | Zehe, halbiert                  |         |
| 200 ml | Weißwein     |        |          | trocken                         |         |
| 1 EL   | Speisestärke |        |          |                                 |         |
| 1 EL   | Kirschwasser |        |          | optional                        |         |
| 1      | Baguette     |        |          | in Würfeln                      |         |
| 300 g  | Kartoffeln   |        |          | gekocht                         |         |
| 1 Glas | Essiggurke   |        |          |                                 |         |
|        | Pfeffer      |        |          |                                 |         |
|        | Muskatnuss   |        |          |                                 |         |

## Zubereitung

1. Caquelon mit Knoblauch ausreiben.
2. Wein erhitzen, Käse portionsweise unter Rühren zugeben.
3. Stärke mit Kirsch glatt rühren, einrühren und 2 Minuten kochen. ⏱ 2
4. Mit Pfeffer und Muskat würzen, auf einem Rechaud servieren.
5. Brot und Kartoffeln eintauchen.

## Notizen

Rührt man in Achtern, bleibt der Käse glatt.
