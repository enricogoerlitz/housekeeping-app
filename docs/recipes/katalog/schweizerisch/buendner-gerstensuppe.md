# Bündner Gerstensuppe

![Bündner Gerstensuppe](../../pictures/buendner-gerstensuppe.jpg)

Dicke Suppe aus Graupen und Wurzelgemüse. Mit Bündnerfleisch.

## Zutaten

| Menge      | Zutat           | Gruppe | Variante           | Hinweis   | Einkauf |
| ---------- | --------------- | ------ | ------------------ | --------- | ------- |
| 100 g      | Perlgraupen     |        |                    |           |         |
| 1          | Karotte         |        |                    | gewürfelt |         |
| 1          | Lauch           |        |                    | in Ringen |         |
| 100 g      | Knollensellerie |        |                    | gewürfelt |         |
| 1          | Kartoffel       |        |                    | gewürfelt |         |
| 1          | Zwiebel         |        |                    | gewürfelt |         |
| 1 EL       | Butter          |        |                    |           |         |
| 800 ml     | Gemüsebrühe     |        |                    |           |         |
| 100 ml     | Sahne           |        |                    |           |         |
| 4 Scheiben | Bündnerfleisch  |        | Mit Bündnerfleisch |           |         |
| 1 Bund     | Schnittlauch    |        |                    |           |         |
|            | Salz            |        |                    |           |         |
|            | Pfeffer         |        |                    |           |         |

## Zubereitung

1. Rollgerste 30 Minuten einweichen. ⏱ 30
2. Zwiebel und Gemüse in Butter 5 Minuten anschwitzen. ⏱ 5
3. Mit Brühe und Gerste aufgießen und 45 Minuten köcheln. ⏱ 45
4. Sahne einrühren, abschmecken.
5. [Mit Bündnerfleisch] Fleisch in Streifen schneiden und obenauf legen.
6. Mit Schnittlauch servieren.

## Notizen

Rollgerste ist Perlgraupen-ähnlich, Graupen gehen auch.
