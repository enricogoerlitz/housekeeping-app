# Älplermagronen mit Apfelmus

![Älplermagronen mit Apfelmus](../../pictures/aelplermagronen.jpg)

Hirtenessen aus Hörnli, Kartoffeln, Käse und Rahm, mit Röstzwiebeln und Apfelmus.

## Zutaten

| Menge  | Zutat       | Gruppe | Variante  | Hinweis                      | Einkauf |
| ------ | ----------- | ------ | --------- | ---------------------------- | ------- |
| 200 g  | Makkaroni   |        |           | Hörnli, alternativ Makkaroni |         |
| 300 g  | Kartoffeln  |        |           | festkochend, in Würfeln      |         |
| 150 g  | Bergkäse    |        |           | gerieben                     |         |
| 100 ml | Sahne       |        |           |                              |         |
| 2      | Zwiebel     |        |           | in Ringen                    |         |
| 2 EL   | Butter      |        |           |                              |         |
| 80 g   | Speckwürfel |        | Mit Speck |                              |         |
| 200 g  | Apfelmus    |        |           |                              |         |
|        | Salz        |        |           |                              |         |
|        | Pfeffer     |        |           |                              |         |
|        | Muskatnuss  |        |           |                              |         |

## Zubereitung

1. Kartoffelwürfel in Salzwasser 5 Minuten kochen, dann Hörnli zugeben und weitere 9 Minuten garen. ⏱ 14
2. Zwiebeln in Butter 12 Minuten goldbraun rösten. ⏱ 12
3. [Mit Speck] Speck knusprig braten.
4. Abgießen, mit Sahne und Käse zurück in den Topf, bei kleiner Hitze 3 Minuten schmelzen. ⏱ 3
5. Mit Muskat, Salz und Pfeffer würzen und mit Röstzwiebeln und Apfelmus servieren.

## Notizen

Statt Bergkäse Gruyère verwenden.
