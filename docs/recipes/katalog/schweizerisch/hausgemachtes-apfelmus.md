# Hausgemachtes Apfelmus

![Hausgemachtes Apfelmus](../../pictures/hausgemachtes-apfelmus.jpg)

Apfelmus mit Zimt, perfekt zu Älplermagronen und Rösti.

## Zutaten

| Menge | Zutat      | Gruppe | Variante | Hinweis               | Einkauf |
| ----- | ---------- | ------ | -------- | --------------------- | ------- |
| 600 g | Äpfel      |        |          | säuerlich, in Stücken |         |
| 50 ml | Wasser     |        |          |                       | nie     |
| 1 EL  | Zucker     |        |          |                       |         |
| 1     | Zimtstange |        |          |                       |         |
| 1 TL  | Zitronen   |        |          | Saft                  |         |

## Zubereitung

1. Äpfel mit Wasser, Zucker, Zimt und Zitronensaft aufkochen.
2. Zugedeckt 15 Minuten köcheln. ⏱ 15
3. Zimtstange entfernen, grob zerdrücken.

## Notizen

Hält im Kühlschrank 5 Tage.
