# Rösti

![Rösti](../../pictures/roesti.jpg)

Schweizer Kartoffelfladen, außen knusprig, innen weich.

## Zutaten

| Menge | Zutat         | Gruppe | Variante | Hinweis                        | Einkauf |
| ----- | ------------- | ------ | -------- | ------------------------------ | ------- |
| 600 g | Kartoffeln    |        |          | festkochend, am Vortag gekocht |         |
| 3 EL  | Butterschmalz |        |          |                                |         |
|       | Salz          |        |          |                                |         |
|       | Pfeffer       |        |          |                                |         |

## Zubereitung

1. Kartoffeln grob raspeln, mit Salz und Pfeffer mischen.
2. Butterschmalz erhitzen, Masse in die Pfanne geben und flach andrücken.
3. Bei mittlerer Hitze 12 Minuten braten. ⏱ 12
4. Mit Teller wenden, weitere 10 Minuten braten. ⏱ 10

## Notizen

Nicht rühren, damit die Kruste entsteht.
