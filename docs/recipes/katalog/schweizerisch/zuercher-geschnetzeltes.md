# Zürcher Geschnetzeltes mit Pilzen

![Zürcher Geschnetzeltes mit Pilzen](../../pictures/zuercher-geschnetzeltes.jpg)

Zürcher Klassiker in Weißwein-Rahmsauce, mit Rösti. Vegetarisch aus Kräuterseitlingen und Champignons.

## Zutaten

| Menge  | Zutat               | Gruppe | Variante            | Hinweis     | Einkauf |
| ------ | ------------------- | ------ | ------------------- | ----------- | ------- |
| 300 g  | Kalbsgeschnetzeltes |        | Mit Kalbfleisch     |             | Menge   |
| 300 g  | Champignon          |        |                     | in Scheiben |         |
| 200 g  | Kräuterseitling     |        | Vegetarisch (Pilze) | in Scheiben |         |
| 1      | Zwiebel             |        |                     | gewürfelt   |         |
| 2 EL   | Butter              |        |                     |             |         |
| 2 EL   | Mehl                |        |                     |             |         |
| 100 ml | Weißwein            |        |                     | trocken     |         |
| 200 ml | Sahne               |        |                     |             |         |
| 100 ml | Gemüsebrühe         |        |                     |             |         |
| 1 Bund | Petersilie          |        |                     |             |         |
|        | Salz                |        |                     |             |         |
|        | Pfeffer             |        |                     |             |         |

## Zubereitung

1. [Mit Kalbfleisch] Fleisch mehlieren, in Butter portionsweise 2 Minuten kräftig anbraten, herausnehmen. ⏱ 2
2. [Vegetarisch (Pilze)] Pilze portionsweise in Butter 5 Minuten braten, herausnehmen. ⏱ 5
3. Zwiebel 2 Minuten anschwitzen und Champignons 5 Minuten braten. ⏱ 7
4. Mit Wein ablöschen, einkochen, Brühe und Sahne zugeben und 5 Minuten reduzieren. ⏱ 5
5. Fleisch bzw. Pilze zurück in die Pfanne, 1 Minute ziehen lassen.
6. Mit Petersilie bestreuen, mit Rösti servieren.

## Notizen

Fleisch nicht kochen, sonst wird es zäh.
