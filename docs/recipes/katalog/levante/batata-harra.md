# Batata Harra

![Batata Harra](../../pictures/batata-harra.jpg)

Libanesische „scharfe Kartoffeln“: knusprige Würfel mit Knoblauch, Koriander, Zitrone und Chili.

## Zutaten

| Menge    | Zutat         | Gruppe | Variante | Hinweis                      | Einkauf |
| -------- | ------------- | ------ | -------- | ---------------------------- | ------- |
| 500 g    | Kartoffeln    |        |          | festkochend, in 2 cm Würfeln |         |
| 4 EL     | Olivenöl      |        |          |                              |         |
| 4        | Knoblauch     |        |          | Zehen, gehackt               |         |
| 1/2 TL   | Chiliflocken  |        |          |                              |         |
| 1 TL     | Paprikapulver |        |          | edelsüß                      |         |
| 1/2 Bund | Koriander     |        |          | gehackt                      |         |
| 1        | Zitrone       |        |          | Saft                         |         |
| 1 TL     | Salz          |        |          |                              |         |

## Zubereitung

1. Kartoffelwürfel in Salzwasser 6 Minuten vorkochen und gut abtropfen lassen. ⏱ 6
2. In einer großen Pfanne Öl erhitzen, Kartoffeln bei mittlerer Hitze 15 bis 18 Minuten knusprig braten, gelegentlich wenden. ⏱ 17
3. Knoblauch, Paprikapulver und Chili zugeben und 1 Minute mitbraten.
4. Vom Herd nehmen, mit Zitronensaft, Koriander und Salz vermengen.

## Notizen

Statt Koriander passt auch glatte Petersilie. Dazu Joghurt oder Toum.
