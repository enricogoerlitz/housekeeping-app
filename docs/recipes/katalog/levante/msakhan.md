# Msakhan

![Msakhan](../../pictures/msakhan.jpg)

Palästinensisches Festessen: Brot, getränkt in Olivenöl und Sumach-Zwiebeln, mit saftigem Hähnchen oder Kichererbsen belegt.

## Zutaten

| Menge  | Zutat         | Gruppe | Variante     | Hinweis                  | Einkauf |
| ------ | ------------- | ------ | ------------ | ------------------------ | ------- |
| 4      | Hähnchenkeule |        | Mit Hähnchen |                          | Menge   |
| 300 g  | Kichererbsen  |        | Vegetarisch  | aus der Dose, abgetropft | Menge   |
| 4      | Zwiebel       |        |              | in dünne Streifen        |         |
| 5 EL   | Olivenöl      |        |              |                          |         |
| 2 EL   | Sumach        |        |              |                          |         |
| 1 TL   | Piment        |        |              | gemahlen                 |         |
| 1/2 TL | Zimt          |        |              |                          |         |
| 2      | Fladenbrot    |        |              | rund, groß               |         |
| 3 EL   | Pinienkerne   |        |              |                          |         |
| 1      | Zitrone       |        |              | Saft                     |         |
| 1 TL   | Salz          |        |              |                          |         |
| 100 g  | Naturjoghurt  |        |              | zum Servieren            |         |

## Zubereitung

1. Ofen auf 200 °C vorheizen.
2. [Mit Hähnchen] Keulen mit 2 EL Öl, 1 EL Sumach, Piment, Zimt und Salz einreiben und 40 Minuten im Ofen backen. ⏱ 40
3. [Vegetarisch] Kichererbsen mit 1 EL Öl, Piment und Salz mischen und 20 Minuten im Ofen rösten. ⏱ 20
4. Zwiebeln in 3 EL Öl bei mittlerer Hitze 20 Minuten weich und goldbraun schmoren, restlichen Sumach und Zitronensaft zugeben. ⏱ 20
5. Fladenbrote auf ein Blech legen, großzügig mit der Zwiebelmasse belegen und 8 Minuten im Ofen anrösten. ⏱ 8
6. Pinienkerne trocken goldgelb rösten.
7. Hähnchenteile oder Kichererbsen auf dem Brot anrichten, mit Pinienkernen bestreuen und mit Joghurt servieren.

## Notizen

Sumach gibt es im Orientladen und gut sortierten Supermärkten; ersatzweise Zitronenschale plus Zitronensaft. Brot: Fladenbrot aus dem Supermarkt oder Tortilla-Wraps.
