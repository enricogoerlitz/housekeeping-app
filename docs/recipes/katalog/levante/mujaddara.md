# Mujaddara

![Mujaddara](../../pictures/mujaddara.jpg)

Libanesischer Linsen-Reis mit Kreuzkümmel, gekrönt von tiefbraunen Röstzwiebeln und kühlem Joghurt. Einfach, sättigend und fast ohne Kosten.

## Zutaten

| Menge    | Zutat            | Gruppe | Variante     | Hinweis        | Einkauf |
| -------- | ---------------- | ------ | ------------ | -------------- | ------- |
| 150 g    | Braune Linsen    |        |              |                |         |
| 120 g    | Basmatireis      |        |              |                |         |
| 3        | Zwiebel          |        |              | in dünne Ringe |         |
| 4 EL     | Olivenöl         |        |              |                |         |
| 1 TL     | Kreuzkümmel      |        |              | gemahlen       |         |
| 1/2 TL   | Zimt             |        |              | gemahlen       |         |
| 500 ml   | Wasser           |        |              |                | nie     |
| 1 TL     | Salz             |        |              |                |         |
| 1/4 TL   | Pfeffer          |        |              |                |         |
| 150 g    | Naturjoghurt     |        |              | zum Servieren  |         |
| 1/2 Bund | Petersilie       |        |              | gehackt        |         |
| 2        | Hähnchenschenkel |        | Mit Hähnchen |                | Menge   |
| 1 TL     | Paprikapulver    |        | Mit Hähnchen | edelsüß        |         |

## Zubereitung

1. Linsen mit 500 ml Wasser aufkochen und 10 Minuten bei mittlerer Hitze vorgaren. ⏱ 10
2. Zwiebeln in 3 EL heißem Öl bei mittlerer Hitze 20 Minuten unter häufigem Rühren dunkelbraun und knusprig braten, auf Küchenpapier legen. ⏱ 20
3. [Mit Hähnchen] Schenkel mit Paprika, Salz und Pfeffer würzen und im selben Öl 5 Minuten pro Seite goldbraun anbraten, danach im Ofen bei 200 °C 20 Minuten fertig garen. ⏱ 25
4. Reis waschen, mit Kreuzkümmel, Zimt, Salz und Pfeffer zu den Linsen geben, abgedeckt bei kleiner Hitze 15 Minuten garen. ⏱ 15
5. Topf vom Herd nehmen und 5 Minuten zugedeckt ruhen lassen, mit der Gabel lockern. ⏱ 5
6. Mit Röstzwiebeln, Joghurt und Petersilie anrichten, bei der Hähnchenvariante die Schenkel dazulegen.

## Notizen

Die Zwiebeln brauchen Geduld: erst zum Schluss dunkel werden lassen, sonst werden sie bitter. Statt Joghurt passt auch ein Tomaten-Gurken-Salat. Für die vegane Variante Joghurt weglassen.
