# Baba Ghanoush

![Baba Ghanoush](../../pictures/baba-ghanoush.jpg)

Rauchig-cremiger Auberginendip mit Tahini, Knoblauch und Zitrone, ein Muss auf jeder Mezzeplatte.

## Zutaten

| Menge  | Zutat      | Gruppe | Variante | Hinweis             | Einkauf |
| ------ | ---------- | ------ | -------- | ------------------- | ------- |
| 2      | Aubergine  |        |          | groß                |         |
| 2 EL   | Tahini     |        |          |                     |         |
| 2 EL   | Zitronen   |        |          | Saft                |         |
| 1      | Knoblauch  |        |          | Zehe, gepresst      |         |
| 2 EL   | Olivenöl   |        |          |                     |         |
| 1/2 TL | Salz       |        |          |                     |         |
| 1 EL   | Petersilie |        |          | gehackt             |         |
| 1      | Fladenbrot |        |          | Pita, zum Servieren |         |

## Zubereitung

1. Auberginen mit der Gabel mehrfach einstechen und auf dem Gasherd, Grill oder im Ofen bei 250 °C Grillstufe 35 Minuten rösten, bis die Haut schwarz und das Fruchtfleisch weich ist. ⏱ 35
2. Etwas abkühlen lassen, aufschneiden und das Fleisch aus der Schale löffeln, in einem Sieb 5 Minuten abtropfen lassen. ⏱ 5
3. Mit Tahini, Zitronensaft, Knoblauch und Salz grob zerdrücken oder pürieren.
4. Mit Olivenöl und Petersilie anrichten und mit warmem Pita servieren.

## Notizen

Je dunkler die Haut, desto rauchiger. Aus dem Backofen schmeckt es milder, ein Tropfen Räuchersalz hilft.
