# Fatteh mit Kichererbsen

![Fatteh mit Kichererbsen](../../pictures/fatteh-mit-kichererbsen.jpg)

Geschichtetes Gericht aus knusprigem Brot, warmen Kichererbsen und Knoblauch-Joghurt, mit gerösteten Pinienkernen und Butter-Paprika obenauf.

## Zutaten

| Menge | Zutat         | Gruppe | Variante        | Hinweis                  | Einkauf |
| ----- | ------------- | ------ | --------------- | ------------------------ | ------- |
| 2     | Fladenbrot    |        |                 | in Stücke gerissen       |         |
| 400 g | Kichererbsen  |        |                 | aus der Dose, abgetropft | Menge   |
| 300 g | Naturjoghurt  |        |                 |                          |         |
| 1     | Knoblauch     |        |                 | Zehe, gepresst           |         |
| 1 EL  | Tahini        |        |                 |                          |         |
| 1 EL  | Zitronen      |        |                 | Saft                     |         |
| 1 TL  | Kreuzkümmel   |        |                 | gemahlen                 |         |
| 3 EL  | Olivenöl      |        |                 |                          |         |
| 30 g  | Butter        |        |                 |                          |         |
| 1 TL  | Paprikapulver |        |                 | edelsüß                  |         |
| 2 EL  | Pinienkerne   |        |                 |                          |         |
| 1 TL  | Salz          |        |                 |                          |         |
| 200 g | Rinderhack    |        | Mit Hackfleisch |                          | Menge   |
| 2 EL  | Petersilie    |        |                 | gehackt                  |         |

## Zubereitung

1. Brotstücke mit 2 EL Öl mischen und bei 200 °C 8 Minuten knusprig backen. ⏱ 8
2. Joghurt mit Knoblauch, Tahini, Zitronensaft und Salz glatt rühren.
3. Kichererbsen mit Kreuzkümmel und Salz in 100 ml Wasser 8 Minuten erwärmen. ⏱ 8
4. [Mit Hackfleisch] Hack im restlichen Öl krümelig braun braten, würzen mit Salz und Kreuzkümmel. ⏱ 8
5. Pinienkerne in der Butter goldgelb rösten, Paprikapulver zugeben und sofort vom Herd nehmen.
6. Brot in tiefe Schalen schichten, Kichererbsen (und Hack) darauf, Joghurt darübergießen.
7. Mit Paprikabutter, Pinienkernen und Petersilie abschließen und sofort essen.

## Notizen

Das Brot nicht zu früh mit Joghurt beträufeln, sonst weicht es durch. Pinienkerne ersatzweise Mandelblätter.
