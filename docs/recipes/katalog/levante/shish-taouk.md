# Shish Taouk

![Shish Taouk](../../pictures/shish-taouk.jpg)

Zart marinierte Hähnchenspieße aus Joghurt, Zitrone und Paprika, dazu cremige Toum-Knoblauchsauce und Fladenbrot.

## Zutaten

| Menge | Zutat         | Gruppe         | Variante     | Hinweis         | Einkauf |
| ----- | ------------- | -------------- | ------------ | --------------- | ------- |
| 400 g | Hähnchenbrust |                | Mit Hähnchen | in 3 cm Würfeln | Menge   |
| 250 g | Halloumi      |                | Vegetarisch  | in Würfeln      | Menge   |
| 1     | Paprika       |                | Vegetarisch  | rot, in Stücken |         |
| 150 g | Naturjoghurt  | Marinade       |              |                 |         |
| 2 EL  | Zitronen      | Marinade       |              | Saft            |         |
| 2 EL  | Olivenöl      | Marinade       |              |                 |         |
| 1 EL  | Tomatenmark   | Marinade       |              |                 |         |
| 2 TL  | Paprikapulver | Marinade       |              | edelsüß         |         |
| 2     | Knoblauch     | Marinade       |              | Zehen, gepresst |         |
| 1 TL  | Salz          | Marinade       |              |                 |         |
| 100 g | Naturjoghurt  | Knoblauchsauce |              |                 |         |
| 2     | Knoblauch     | Knoblauchsauce |              | Zehen, gepresst |         |
| 1 EL  | Zitronen      | Knoblauchsauce |              | Saft            |         |
| 2     | Fladenbrot    |                |              |                 |         |

## Zubereitung

1. Marinade aus Joghurt, Zitronensaft, Öl, Tomatenmark, Paprikapulver, Knoblauch und Salz verrühren.
2. [Mit Hähnchen] Hähnchenwürfel mit der Marinade mischen und mindestens 1 Stunde, besser über Nacht, kühl marinieren. ⏱ 60
3. [Vegetarisch] Halloumi und Paprika nur 15 Minuten in der Marinade ziehen lassen.
4. Fleisch bzw. Halloumi und Paprika auf Spieße stecken.
5. Spieße in einer heißen Grillpfanne oder unter dem Backofengrill 12 bis 15 Minuten braten, mehrmals wenden. ⏱ 14
6. Für die Sauce Joghurt, Knoblauch, Zitronensaft und eine Prise Salz verrühren.
7. Fladenbrot kurz erwärmen und mit Spießen, Sauce und Zwiebelringen servieren.

## Notizen

Echte Toum wird aus Knoblauch und Öl aufgeschlagen, die Joghurtvariante ist die schnelle Küche. Holzspieße vorher 20 Minuten wässern.
