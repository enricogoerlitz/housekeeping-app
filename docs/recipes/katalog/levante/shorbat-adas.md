# Shorbat Adas

![Shorbat Adas](../../pictures/shorbat-adas.jpg)

Samtige Linsensuppe mit Kreuzkümmel und Zitrone, wie sie in Syrien und im Libanon im Winter auf den Tisch kommt.

## Zutaten

| Menge  | Zutat         | Gruppe | Variante     | Hinweis    | Einkauf |
| ------ | ------------- | ------ | ------------ | ---------- | ------- |
| 200 g  | Rote Linsen   |        |              |            |         |
| 1      | Zwiebel       |        |              | gewürfelt  |         |
| 2      | Karotte       |        |              | gewürfelt  |         |
| 2      | Knoblauch     |        |              | Zehen      |         |
| 2 EL   | Olivenöl      |        |              |            |         |
| 2 TL   | Kreuzkümmel   |        |              | gemahlen   |         |
| 1/2 TL | Kurkuma       |        |              |            |         |
| 800 ml | Gemüsebrühe   |        |              |            |         |
| 1      | Zitrone       |        |              | Saft       |         |
| 1 TL   | Salz          |        |              |            |         |
| 1/4 TL | Pfeffer       |        |              |            |         |
| 1      | Fladenbrot    |        |              | in Stücken |         |
| 250 g  | Hähnchenbrust |        | Mit Hähnchen |            | Menge   |

## Zubereitung

1. Zwiebel und Karotte im Öl 5 Minuten anbraten, Knoblauch und Gewürze 1 Minute mitrösten. ⏱ 5
2. Linsen und Brühe zugeben, aufkochen und 20 Minuten köcheln lassen. ⏱ 20
3. [Mit Hähnchen] Hähnchenbrust in den letzten 15 Minuten in der Suppe gar ziehen lassen, herausnehmen und zerzupfen. ⏱ 15
4. Suppe fein pürieren, mit Salz, Pfeffer und Zitronensaft abschmecken.
5. Brotstücke in Olivenöl knusprig rösten.
6. Suppe mit zerzupftem Hähnchen, Croutons und einem Schuss Öl servieren.

## Notizen

Lässt sich gut einfrieren. Bei zu dicker Suppe mit Wasser verdünnen.
