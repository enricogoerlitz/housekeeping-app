# Sabich

![Sabich](../../pictures/sabich.jpg)

Das israelische Frühstücks-Sandwich: gebratene Aubergine, hartgekochtes Ei, Tahini und Amba in der Pita.

## Zutaten

| Menge | Zutat        | Gruppe | Variante | Hinweis          | Einkauf |
| ----- | ------------ | ------ | -------- | ---------------- | ------- |
| 1     | Aubergine    |        |          | in 1 cm Scheiben |         |
| 3 EL  | Olivenöl     |        |          |                  |         |
| 2     | Ei           |        |          |                  |         |
| 2     | Fladenbrot   |        |          | Pita             |         |
| 1     | Tomate       |        |          | gewürfelt        |         |
| 1/2   | Gurke        |        |          | gewürfelt        |         |
| 2 EL  | Petersilie   |        |          | gehackt          |         |
| 3 EL  | Tahini       | Sauce  |          |                  |         |
| 2 EL  | Zitronen     | Sauce  |          | Saft             |         |
| 3 EL  | Wasser       | Sauce  |          |                  | nie     |
| 1     | Knoblauch    | Sauce  |          | Zehe, gepresst   |         |
| 1 TL  | Salz         |        |          |                  |         |
| 2 EL  | Mango-Pickle |        |          | Amba, optional   | 1×      |

## Zubereitung

1. Auberginenscheiben beidseitig salzen, 10 Minuten ziehen lassen und abtupfen. ⏱ 10
2. Eier 9 Minuten hart kochen, abschrecken und pellen. ⏱ 9
3. Aubergine im Öl in einer großen Pfanne beidseitig je 4 Minuten goldbraun braten. ⏱ 8
4. Tahini mit Zitronensaft, Wasser, Knoblauch und Salz zu einer sämigen Sauce verrühren.
5. Tomate, Gurke und Petersilie mischen und leicht salzen.
6. Pita im Toaster erwärmen und öffnen, mit Aubergine, Eischeiben, Salat, Tahini und Amba füllen.

## Notizen

Amba (Mango-Pickle) gibt es im Asia- oder Orientshop; ohne geht es auch, dann mit etwas Currypulver und Zitrone in der Tahini abschmecken.
