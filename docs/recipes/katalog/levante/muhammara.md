# Muhammara

![Muhammara](../../pictures/muhammara.jpg)

Syrischer Dip aus gerösteter Paprika, Walnüssen und Granatapfelsirup, süß-sauer, nussig und leicht scharf.

## Zutaten

| Menge  | Zutat            | Gruppe | Variante | Hinweis  | Einkauf |
| ------ | ---------------- | ------ | -------- | -------- | ------- |
| 3      | Paprika          |        |          | rot      |         |
| 80 g   | Walnüsse         |        |          |          |         |
| 3 EL   | Semmelbrösel     |        |          |          |         |
| 1 EL   | Granatapfelsirup |        |          |          |         |
| 1      | Knoblauch        |        |          | Zehe     |         |
| 1 TL   | Kreuzkümmel      |        |          | gemahlen |         |
| 1/2 TL | Chiliflocken     |        |          |          |         |
| 3 EL   | Olivenöl         |        |          |          |         |
| 1 EL   | Zitronen         |        |          | Saft     |         |
| 1/2 TL | Salz             |        |          |          |         |

## Zubereitung

1. Paprika halbieren, entkernen und mit der Hautseite nach oben bei Grillstufe 15 bis 20 Minuten rösten, bis die Haut schwarz ist. ⏱ 18
2. Paprika in einer Schüssel abgedeckt 10 Minuten schwitzen lassen und die Haut abziehen. ⏱ 10
3. Walnüsse trocken kurz anrösten.
4. Alle Zutaten im Mixer grob pürieren, mit Salz und Zitrone abschmecken.
5. Mit Olivenöl beträufeln und mit Walnussstücken servieren.

## Notizen

Granatapfelsirup gibt es im Orientladen; ersatzweise 1 TL Honig und 1 TL Zitronensaft. Aus dem Glas geröstete Paprika sparen Zeit.
