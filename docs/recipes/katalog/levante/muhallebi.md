# Muhallebi

![Muhallebi](../../pictures/muhallebi.jpg)

Libanesischer Milchpudding mit Rosenwasser, gekrönt mit Pistazien, kalt serviert.

## Zutaten

| Menge  | Zutat        | Gruppe | Variante | Hinweis       | Einkauf |
| ------ | ------------ | ------ | -------- | ------------- | ------- |
| 500 ml | Vollmilch    |        |          |               |         |
| 40 g   | Speisestärke |        |          |               |         |
| 50 g   | Zucker       |        |          |               |         |
| 1 EL   | Rosenwasser  |        |          |               |         |
| 1 EL   | Pistazien    |        |          | gehackt       |         |
| 1 EL   | Honig        |        |          | zum Servieren |         |

## Zubereitung

1. Stärke mit 100 ml kalter Milch glatt rühren.
2. Restliche Milch mit Zucker erhitzen, die angerührte Stärke einrühren und unter ständigem Rühren 4 bis 5 Minuten köcheln, bis sie dickt. ⏱ 5
3. Vom Herd nehmen, Rosenwasser einrühren und in zwei Gläser füllen.
4. Mindestens 2 Stunden kalt stellen. ⏱ 120
5. Mit Pistazien und Honig servieren.

## Notizen

Rosenwasser gibt es im Orientladen oder Drogeriemarkt; ersatzweise Vanille.
