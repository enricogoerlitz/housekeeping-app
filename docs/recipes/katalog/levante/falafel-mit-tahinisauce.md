# Falafel mit Tahinisauce

![Falafel mit Tahinisauce](../../pictures/falafel-mit-tahinisauce.jpg)

Knusprige Falafel aus eingeweichten Kichererbsen und viel Kräutern, grün im Inneren, mit Tahinisauce und Gemüse.

| -------- | -------------- | ------ | -------- | ---------------------------------- | ------- |
| 250 g    | Kichererbsen   |        |          | getrocknet, 12 Stunden eingeweicht |         |
| 1        | Zwiebel        |        |          | grob gewürfelt                     |         |
| 3        | Knoblauch      |        |          | Zehen                              |         |
| 1 Bund   | Petersilie     |        |          |                                    |         |

## Zubereitung

1. Eingeweichte, abgetropfte Kichererbsen (nicht gekocht!) mit Zwiebel, Knoblauch, Kräutern, Gewürzen und Salz im Mixer grob-krümelig pürieren. ⏱ 5
2. Backpulver untermischen und die Masse 20 Minuten im Kühlschrank ruhen lassen. ⏱ 20
3. Tahini, Zitronensaft, Wasser und Salz zu einer glatten Sauce verrühren.
4. Öl in einem kleinen Topf auf 175 °C erhitzen, mit nassen Händen walnussgroße Bällchen formen.
5. Falafel in Portionen 3 bis 4 Minuten goldbraun frittieren, auf Küchenpapier abtropfen lassen. ⏱ 4
6. Mit Gurke, Tomate und Sauce servieren.
7. [Im Pita] Pitabrote aufbacken, aufschneiden und mit Falafel, Gemüse und Sauce füllen.

## Notizen

Dosen-Kichererbsen funktionieren nicht, die Bällchen zerfallen. Probefalafel zuerst frittieren, bei Zerfall einen Esslöffel Mehl zugeben.
