# Tabouleh

![Tabouleh](../../pictures/tabouleh.jpg)

Libanesischer Petersiliensalat: sehr viel Petersilie, wenig Bulgur, Tomate und Minze mit Zitrone und Olivenöl.

## Zutaten

| Menge  | Zutat        | Gruppe | Variante | Hinweis                   | Einkauf |
| ------ | ------------ | ------ | -------- | ------------------------- | ------- |
| 3 Bund | Petersilie   |        |          | glatt, fein gehackt       |         |
| 1 Bund | Minze        |        |          | fein gehackt              |         |
| 3      | Tomate       |        |          | fest, fein gewürfelt      |         |
| 3      | Lauchzwiebel |        |          | in feinen Ringen          |         |
| 3 EL   | Bulgur       |        |          | fein                      |         |
| 3 EL   | Zitronen     |        |          | Saft                      |         |
| 4 EL   | Olivenöl     |        |          |                           |         |
| 1/2 TL | Piment       |        |          | gemahlen                  |         |
| 1 TL   | Salz         |        |          |                           |         |
| 1      | Romanasalat  |        |          | Herzblätter zum Servieren |         |

## Zubereitung

1. Bulgur mit Tomatenwürfeln und Zitronensaft mischen und 15 Minuten quellen lassen. ⏱ 15
2. Petersilie gründlich waschen und sehr gut trocknen, dann mit scharfem Messer fein hacken (nicht mixen).
3. Minze, Lauchzwiebeln und Petersilie unter die Tomaten-Bulgur-Mischung heben.
4. Mit Olivenöl, Piment und Salz abschmecken.
5. Mit Romanablättern zum Auflöffeln servieren.

## Notizen

Frisch am besten, nach 2 Stunden wird der Salat wässrig. Mit Quinoa statt Bulgur glutenfrei.
