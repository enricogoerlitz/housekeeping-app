# Erdäpfelgulasch mit Würstel

![Erdäpfelgulasch mit Würstel](../../pictures/erdaepfelgulasch.jpg)

Wiener Hausmannskost: Kartoffeln in Paprikasauce mit Zwiebeln, Majoran und Essig, mit Würstel.

## Zutaten

| Menge    | Zutat                 | Gruppe | Variante    | Hinweis                 | Einkauf |
| -------- | --------------------- | ------ | ----------- | ----------------------- | ------- |
| 600 g    | Kartoffeln            |        |             | festkochend, in Würfeln |         |
| 2        | Zwiebel               |        |             | gewürfelt               |         |
| 2 EL     | Öl                    |        |             |                         |         |
| 1 EL     | Tomatenmark           |        |             |                         |         |
| 2 EL     | Paprikapulver         |        |             | edelsüß                 |         |
| 1 TL     | Majoran               |        |             |                         |         |
| 1 TL     | Kümmel                |        |             |                         |         |
| 1        | Knoblauch             |        |             | Zehe                    |         |
| 1 Schuss | Essig                 |        |             |                         |         |
| 500 ml   | Gemüsebrühe           |        |             |                         |         |
| 2        | Frankfurter Würstchen |        | Mit Würstel | in Scheiben             |         |
| 1        | Paprika               |        |             | rot, in Streifen        |         |
|          | Salz                  |        |             |                         |         |

## Zubereitung

1. Zwiebeln im Öl 8 Minuten goldbraun rösten. ⏱ 8
2. Tomatenmark, Knoblauch und Paprikapulver kurz anrösten, sofort mit Essig und Brühe ablöschen.
3. Kartoffeln, Paprika, Majoran, Kümmel und Salz zugeben, 25 Minuten köcheln lassen. ⏱ 25
4. [Mit Würstel] Würstel 5 Minuten mitziehen lassen. ⏱ 5
5. Abschmecken, nach Wunsch Kartoffeln leicht andrücken für mehr Bindung.

## Notizen

Paprikapulver nie lang rösten, sonst wird es bitter.
