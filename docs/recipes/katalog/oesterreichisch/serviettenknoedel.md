# Serviettenknödel

![Serviettenknödel](../../pictures/serviettenknoedel.jpg)

Locker gegartes Knödelbrot als Rolle, in Scheiben als Beilage zu Pilzragout und Gulasch.

## Zutaten

| Menge   | Zutat      | Gruppe | Variante | Hinweis               | Einkauf |
| ------- | ---------- | ------ | -------- | --------------------- | ------- |
| 6       | Brötchen   |        |          | altbacken, in Würfeln |         |
| 200 ml  | Milch      |        |          | lauwarm               |         |
| 2       | Eier       |        |          |                       |         |
| 1       | Zwiebel    |        |          | fein gewürfelt        |         |
| 2 EL    | Butter     |        |          |                       |         |
| 2 EL    | Petersilie |        |          | gehackt               |         |
| 1 Prise | Muskatnuss |        |          |                       |         |
|         | Salz       |        |          |                       |         |

## Zubereitung

1. Zwiebel in Butter 3 Minuten dünsten. ⏱ 3
2. Brötchenwürfel mit Milch, Eiern, Petersilie, Muskat, Salz und Zwiebel vermengen, 15 Minuten ziehen lassen. ⏱ 15
3. Masse zu einer Rolle formen und auf Backpapier und Alufolie wickeln, Enden zudrehen.
4. In siedendem Wasser 35 Minuten ziehen lassen. ⏱ 35
5. Auswickeln und in Scheiben schneiden.

## Notizen

Folie nicht zu fest wickeln, der Knödel braucht Platz.
