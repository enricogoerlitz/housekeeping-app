# Spinatknödel mit Parmesanbutter

![Spinatknödel mit Parmesanbutter](../../pictures/spinatknoedel-mit-parmesanbutter.jpg)

Spinatknödel aus Tirol: grün, locker und mit brauner Butter. Gut mit Schinkenwürfeln.

## Zutaten

| Menge   | Zutat          | Gruppe | Variante     | Hinweis                    | Einkauf |
| ------- | -------------- | ------ | ------------ | -------------------------- | ------- |
| 4       | Semmel         |        |              | altbacken, in Würfeln      |         |
| 150 ml  | Milch          |        |              | lauwarm                    |         |
| 250 g   | Blattspinat    |        |              | TK, aufgetaut, ausgedrückt |         |
| 1       | Zwiebel        |        |              | fein gewürfelt             |         |
| 1 EL    | Butter         |        |              |                            |         |
| 2       | Eier           |        |              |                            |         |
| 2 EL    | Mehl           |        |              |                            |         |
| 50 g    | Schinkenwürfel |        | Mit Schinken |                            |         |
| 1 Prise | Muskatnuss     |        |              |                            |         |
| 60 g    | Butter         | Sauce  |              |                            |         |
| 40 g    | Parmesan       | Sauce  |              | gehobelt                   |         |
| 4       | Salbei         | Sauce  |              |                            |         |
|         | Salz           |        |              |                            |         |
|         | Pfeffer        |        |              |                            |         |

## Zubereitung

1. Zwiebel in Butter 3 Minuten dünsten, Spinat fein hacken und 2 Minuten mitdünsten. ⏱ 5
2. [Mit Schinken] Schinkenwürfel unterrühren.
3. Semmeln mit Milch, Eiern, Spinat, Mehl, Salz, Pfeffer und Muskat vermengen, 15 Minuten ziehen lassen. ⏱ 15
4. Mit nassen Händen vier Knödel formen.
5. In siedendem Salzwasser 15 Minuten ziehen lassen. ⏱ 15
6. Butter mit Salbei bräunen, Knödel darin schwenken und Parmesan darüber geben.

## Notizen

Fester Teig: ggf. 1 EL Semmelbrösel dazugeben.
