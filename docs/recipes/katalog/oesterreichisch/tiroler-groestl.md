# Tiroler Gröstl

![Tiroler Gröstl](../../pictures/tiroler-groestl.jpg)

Tiroler Resteessen aus Kartoffeln, Zwiebeln und Fleisch, mit Spiegelei. Vegetarisch kommen Champignons und Kräuterseitlinge hinein.

## Zutaten

| Menge  | Zutat         | Gruppe | Variante            | Hinweis                           | Einkauf |
| ------ | ------------- | ------ | ------------------- | --------------------------------- | ------- |
| 500 g  | Kartoffeln    |        |                     | festkochend, am Vortag gekocht    |         |
| 200 g  | Rindfleisch   |        | Mit Rindfleisch     | Reste oder Tafelspitz, in Würfeln |         |
| 250 g  | Champignon    |        | Vegetarisch (Pilze) | in Scheiben                       |         |
| 2      | Zwiebel       |        |                     | in Ringen                         |         |
| 3 EL   | Butterschmalz |        |                     |                                   |         |
| 1 TL   | Kümmel        |        |                     | gemahlen                          |         |
| 1 TL   | Majoran       |        |                     | getrocknet                        |         |
| 2      | Eier          |        |                     |                                   |         |
| 1 Bund | Schnittlauch  |        |                     |                                   |         |
|        | Salz          |        |                     |                                   |         |
|        | Pfeffer       |        |                     |                                   |         |

## Zubereitung

1. Kartoffeln pellen und in Scheiben schneiden.
2. Hälfte des Butterschmalzes erhitzen, Kartoffeln 12 Minuten goldbraun braten. ⏱ 12
3. [Mit Rindfleisch] Fleisch und Zwiebeln zugeben und 8 Minuten mitbraten. ⏱ 8
4. [Vegetarisch (Pilze)] Pilze in einer zweiten Pfanne mit Zwiebeln 8 Minuten braten und zu den Kartoffeln geben. ⏱ 8
5. Mit Kümmel, Majoran, Salz und Pfeffer kräftig würzen.
6. Spiegeleier im restlichen Fett braten.
7. Gröstl mit Ei und Schnittlauch anrichten.

## Notizen

Das Gröstl wird mit Krautsalat serviert.
