# Topfenknödel mit Butterbröseln und Zwetschgenröster

![Topfenknödel mit Butterbröseln und Zwetschgenröster](../../pictures/topfenknoedel-mit-zwetschgenroester.jpg)

Weiche Quarkknödel in Butterbröseln mit Zwetschgenröster.

## Zutaten

| Menge   | Zutat        | Gruppe | Variante | Hinweis               | Einkauf |
| ------- | ------------ | ------ | -------- | --------------------- | ------- |
| 250 g   | Speisequark  | Knödel |          | gut abgetropft        |         |
| 2 EL    | Butter       | Knödel |          | weich                 |         |
| 1       | Ei           | Knödel |          |                       |         |
| 60 g    | Grieß        | Knödel |          |                       |         |
| 1 EL    | Zucker       | Knödel |          |                       |         |
| 1 Prise | Salz         | Knödel |          |                       |         |
| 60 g    | Semmelbrösel | Brösel |          |                       |         |
| 40 g    | Butter       | Brösel |          |                       |         |
| 1 EL    | Zucker       | Brösel |          |                       |         |
| 400 g   | Zwetschgen   | Röster |          | entsteint, geviertelt |         |
| 3 EL    | Zucker       | Röster |          |                       |         |
| 1       | Zimtstange   | Röster |          |                       |         |

## Zubereitung

1. Quark, Butter, Ei, Grieß, Zucker und Salz verrühren und 30 Minuten kalt stellen. ⏱ 30
2. Zwetschgen mit Zucker, Zimt und 2 EL Wasser 15 Minuten köcheln lassen. ⏱ 15
3. Aus dem Teig 6 Knödel formen und in leicht siedendem Salzwasser 12 Minuten garen. ⏱ 12
4. Brösel in Butter mit Zucker goldbraun rösten.
5. Knödel in den Bröseln wälzen und mit Röster servieren.

## Notizen

Zwetschgen im Winter durch TK-Pflaumen ersetzen.
