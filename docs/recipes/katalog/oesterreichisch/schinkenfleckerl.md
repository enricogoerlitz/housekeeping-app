# Schinkenfleckerl

![Schinkenfleckerl](../../pictures/schinkenfleckerl.jpg)

Wiener Nudelauflauf aus Fleckerln, Schinken und Sauerrahm. Vegetarisch statt Schinken Spinat und Frischkäse.

## Zutaten

| Menge   | Zutat        | Gruppe | Variante             | Hinweis                         | Einkauf |
| ------- | ------------ | ------ | -------------------- | ------------------------------- | ------- |
| 200 g   | Fleckerl     |        |                      | alternativ Bandnudeln gebrochen |         |
| 150 g   | Kochschinken |        | Mit Schinken         | gewürfelt                       |         |
| 150 g   | Blattspinat  |        | Vegetarisch (Spinat) | TK, ausgedrückt                 |         |
| 2       | Eier         |        |                      | getrennt                        |         |
| 150 g   | Saure Sahne  |        |                      |                                 |         |
| 2 EL    | Butter       |        |                      |                                 |         |
| 2 EL    | Semmelbrösel |        |                      |                                 |         |
| 1 Prise | Muskatnuss   |        |                      |                                 |         |
| 1 Bund  | Petersilie   |        |                      | gehackt                         |         |
|         | Salz         |        |                      |                                 |         |
|         | Pfeffer      |        |                      |                                 |         |

## Zubereitung

1. Ofen auf 180 Grad Umluft vorheizen, Form buttern.
2. Fleckerl in Salzwasser 8 Minuten garen und abgießen. ⏱ 8
3. Eigelb, Saure Sahne, Muskat, Salz und Pfeffer verrühren, Petersilie zugeben.
4. Eiweiß steif schlagen.
5. [Mit Schinken] Schinken unter die Eiermasse heben.
6. [Vegetarisch (Spinat)] Spinat unter die Eiermasse heben.
7. Nudeln und Eischnee unterheben, in die Form füllen, Brösel und Butterflocken darauf verteilen.
8. 25 Minuten backen, bis die Oberfläche goldbraun ist. ⏱ 25

## Notizen

Dazu passt grüner Salat.
