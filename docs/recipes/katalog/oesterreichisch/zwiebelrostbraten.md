# Zwiebelrostbraten mit Röstzwiebeln

![Zwiebelrostbraten mit Röstzwiebeln](../../pictures/zwiebelrostbraten.jpg)

Gebratenes Rindersteak in kräftiger Sauce mit knusprigen Röstzwiebeln. Vegetarisch gibt es dicke Portobello-Pilze.

## Zutaten

| Menge  | Zutat       | Gruppe | Variante                 | Hinweis                 | Einkauf |
| ------ | ----------- | ------ | ------------------------ | ----------------------- | ------- |
| 2      | Rostbraten  |        | Mit Rindfleisch          | à 180 g, aus der Hüfte  | Menge   |
| 4      | Portobello  |        | Vegetarisch (Portobello) | groß                    | Menge   |
| 2      | Zwiebel     |        |                          | in dünnen Ringen        |         |
| 3 EL   | Mehl        |        |                          |                         |         |
| 4 EL   | Öl          |        |                          |                         |         |
| 1 EL   | Butter      |        |                          |                         |         |
| 1 EL   | Tomatenmark |        |                          |                         |         |
| 200 ml | Rinderbrühe |        |                          | alternativ Gemüsebrühe  |         |
| 1 TL   | Senf        |        |                          |                         |         |
| 300 g  | Kartoffeln  |        |                          | festkochend, in Spalten |         |
|        | Salz        |        |                          |                         |         |
|        | Pfeffer     |        |                          |                         |         |

## Zubereitung

1. Kartoffelspalten mit Öl und Salz bei 200 Grad 30 Minuten backen. ⏱ 30
2. Zwiebelringe in Mehl wenden und portionsweise in heißem Öl 5 Minuten knusprig frittieren. ⏱ 5
3. [Mit Rindfleisch] Fleisch einschneiden, salzen, pfeffern und je Seite 3 bis 4 Minuten braten, 5 Minuten ruhen lassen. ⏱ 8
4. [Vegetarisch (Portobello)] Portobello 5 Minuten je Seite braten, salzen. ⏱ 10
5. Im Bratfett Tomatenmark anrösten, mit Brühe ablöschen, Senf zugeben und 5 Minuten einkochen. ⏱ 5
6. Fleisch oder Pilze mit Sauce und Röstzwiebeln anrichten.

## Notizen

Statt Rostbraten funktioniert auch Rumpsteak.
