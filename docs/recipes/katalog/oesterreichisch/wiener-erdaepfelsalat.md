# Wiener Erdäpfelsalat

![Wiener Erdäpfelsalat](../../pictures/wiener-erdaepfelsalat.jpg)

Wiener Erdäpfelsalat: weich, lauwarm und mit Brühe, Essig und Öl mariniert.

## Zutaten

| Menge  | Zutat         | Gruppe | Variante | Hinweis           | Einkauf |
| ------ | ------------- | ------ | -------- | ----------------- | ------- |
| 600 g  | Kartoffeln    |        |          | festkochend       |         |
| 1      | Zwiebel       |        |          | fein gewürfelt    |         |
| 150 ml | Gemüsebrühe   |        |          | heiß              |         |
| 3 EL   | Weißweinessig |        |          |                   |         |
| 1 TL   | Senf          |        |          |                   |         |
| 3 EL   | Kürbiskernöl  |        |          | alternativ Rapsöl |         |
| 1 Bund | Schnittlauch  |        |          |                   |         |
|        | Salz          |        |          |                   |         |
|        | Pfeffer       |        |          |                   |         |

## Zubereitung

1. Kartoffeln mit Schale 25 Minuten garen, pellen und in Scheiben schneiden. ⏱ 25
2. Brühe mit Essig, Senf, Zwiebel, Salz und Pfeffer verrühren und über die warmen Kartoffeln geben.
3. 15 Minuten ziehen lassen, vorsichtig vermengen. ⏱ 15
4. Öl und Schnittlauch unterheben.

## Notizen

Kürbiskernöl gibt es im gut sortierten Supermarkt.
