# Kaspressknödelsuppe

![Kaspressknödelsuppe](../../pictures/kaspressknoedelsuppe.jpg)

Flache Knödel aus Semmeln, Bergkäse und Milch, in Butter gebraten und in kräftiger Brühe serviert.

## Zutaten

| Menge  | Zutat         | Gruppe | Variante  | Hinweis               | Einkauf |
| ------ | ------------- | ------ | --------- | --------------------- | ------- |
| 4      | Semmel        |        |           | altbacken, in Würfeln |         |
| 120 ml | Milch         |        |           | lauwarm               |         |
| 2      | Eier          |        |           |                       |         |
| 150 g  | Bergkäse      |        |           | gerieben              |         |
| 50 g   | Speckwürfel   |        | Mit Speck |                       |         |
| 1      | Zwiebel       |        |           | fein gewürfelt        |         |
| 1 EL   | Butter        |        |           |                       |         |
| 2 EL   | Mehl          |        |           |                       |         |
| 2 EL   | Butterschmalz |        |           |                       |         |
| 600 ml | Gemüsebrühe   |        |           |                       |         |
| 1 Bund | Schnittlauch  |        |           |                       |         |
|        | Salz          |        |           |                       |         |
|        | Muskatnuss    |        |           |                       |         |

## Zubereitung

1. Zwiebel in Butter 3 Minuten dünsten. ⏱ 3
2. [Mit Speck] Speckwürfel 3 Minuten mitbraten. ⏱ 3
3. Semmelwürfel mit Milch, Eiern, Zwiebel, Käse, Mehl, Salz und Muskat vermengen und 15 Minuten quellen lassen. ⏱ 15
4. Aus der Masse vier flache Knödel mit nassen Händen formen.
5. In Butterschmalz bei mittlerer Hitze 4 Minuten je Seite goldbraun braten. ⏱ 8
6. Brühe erhitzen.
7. Knödel in Suppenteller legen, mit Brühe übergießen und Schnittlauch bestreuen.

## Notizen

Alternativ auf Krautsalat servieren.
