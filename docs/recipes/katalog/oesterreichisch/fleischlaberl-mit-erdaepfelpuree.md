# Fleischlaberl mit Erdäpfelpüree

![Fleischlaberl mit Erdäpfelpüree](../../pictures/fleischlaberl-mit-erdaepfelpuree.jpg)

Wiener Fleischlaberl mit Semmel und Majoran, auf Erdäpfelpüree mit Bratensauce. Vegetarisch aus Linsen und Käse.

## Zutaten

| Menge  | Zutat                  | Gruppe | Variante             | Hinweis               | Einkauf |
| ------ | ---------------------- | ------ | -------------------- | --------------------- | ------- |
| 300 g  | Gemischtes Hackfleisch |        | Mit Hackfleisch      |                       | Menge   |
| 200 g  | Linsen                 |        | Vegetarisch (Linsen) | abgetropft, zerdrückt |         |
| 50 g   | Bergkäse               |        | Vegetarisch (Linsen) | gerieben              |         |
| 1      | Semmel                 |        |                      | eingeweicht           |         |
| 1      | Zwiebel                |        |                      | gewürfelt             |         |
| 1      | Ei                     |        |                      |                       |         |
| 1 TL   | Majoran                |        |                      |                       |         |
| 1      | Knoblauch              |        |                      | Zehe, gepresst        |         |
| 3 EL   | Semmelbrösel           |        |                      |                       |         |
| 3 EL   | Öl                     |        |                      |                       |         |
| 600 g  | Kartoffeln             |        |                      | mehligkochend         |         |
| 80 ml  | Milch                  |        |                      |                       |         |
| 2 EL   | Butter                 |        |                      |                       |         |
| 200 ml | Gemüsebrühe            |        |                      |                       |         |
| 1 TL   | Speisestärke           |        |                      |                       |         |
|        | Salz                   |        |                      |                       |         |
|        | Pfeffer                |        |                      |                       |         |

## Zubereitung

1. Kartoffeln schälen, vierteln und 20 Minuten in Salzwasser garen. ⏱ 20
2. [Mit Hackfleisch] Hack mit Semmel, Zwiebel, Ei, Majoran, Knoblauch, Salz und Pfeffer verkneten.
3. [Vegetarisch (Linsen)] Linsen mit Semmel, Zwiebel, Ei, Käse, Majoran, Knoblauch, Brösel, Salz und Pfeffer verkneten, 10 Minuten ruhen lassen. ⏱ 10
4. Vier Laberl formen und im Öl 5 Minuten je Seite braten. ⏱ 10
5. Kartoffeln mit warmer Milch und Butter zu Püree stampfen.
6. Brühe mit Stärke im Bratfett 3 Minuten kochen und abschmecken. ⏱ 3
7. Laberl auf Püree mit Sauce anrichten.

## Notizen

Linsenlaberl nur einmal wenden.
