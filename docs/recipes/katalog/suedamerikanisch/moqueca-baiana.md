# Moqueca

![Moqueca](../../pictures/moqueca-baiana.jpg)

Brasilianischer Eintopf mit Kokosmilch, Paprika und Tomaten, nach Art aus Bahia.

## Zutaten

| Menge  | Zutat         | Gruppe | Variante    | Hinweis                  | Einkauf |
| ------ | ------------- | ------ | ----------- | ------------------------ | ------- |
| 400 g  | Kabeljaufilet |        | Mit Fisch   | in großen Stücken        | Menge   |
| 400 g  | Kichererbsen  |        | Vegetarisch | aus der Dose, abgetropft | Menge   |
| 1      | Zwiebel       |        |             | in Ringen                |         |
| 1      | Paprika       |        |             | rot, in Streifen         |         |
| 1      | Paprika       |        |             | gelb, in Streifen        |         |
| 2      | Tomate        |        |             | gewürfelt                |         |

| 400 ml | Kokosmilch    |        |             |                          |         |

## Zubereitung

1. Fisch bzw. Kichererbsen mit Limettensaft und etwas Salz 10 Minuten marinieren. ⏱ 10
2. Zwiebel, Paprika und Knoblauch in Öl 6 Minuten bei mittlerer Hitze anbraten, Paprikapulver zugeben. ⏱ 6
3. Tomaten zugeben und 3 Minuten kochen lassen. ⏱ 3
4. Kokosmilch zugeben, aufkochen und 5 Minuten köcheln. ⏱ 5
5. [Mit Fisch] Fisch einlegen und 8 Minuten zugedeckt sanft garen. ⏱ 8
6. [Vegetarisch] Kichererbsen zugeben und 10 Minuten köcheln. ⏱ 10
7. Mit Koriander bestreuen und mit Reis servieren.

## Notizen

Original mit Palmöl (Dendê); hier Olivenöl, da besser verfügbar. Reis nach Packungsangabe separat kochen.
