# Ceviche

![Ceviche](../../pictures/ceviche-peruano.jpg)

Rohes Fischfilet in Limettensaft mariniert, mit roter Zwiebel, Chili und Koriander.

## Zutaten

| Menge  | Zutat         | Gruppe | Variante    | Hinweis                                 | Einkauf |
| ------ | ------------- | ------ | ----------- | --------------------------------------- | ------- |
| 300 g  | Kabeljaufilet |        | Mit Fisch   | sehr frisch, Sushi-Qualität, in Würfeln | Menge   |
| 250 g  | Champignons   |        | Vegetarisch | sehr frisch, in Scheiben                | Menge   |
| 6      | Limette       |        |             | Saft (ca. 150 ml)                       |         |
| 1      | Rote Zwiebel  |        |             | in feinen Ringen                        |         |
| 1      | Chili         |        |             | rot, entkernt und fein gehackt          |         |
| 1 Bund | Koriander     |        |             | gehackt                                 |         |
| 1      | Süßkartoffel  |        |             | gekocht, in Scheiben                    |         |
| 100 g  | Mais          |        |             | aus der Dose                            |         |
| 1 TL   | Salz          |        |             |                                         |         |

## Zubereitung

1. Zwiebelringe 5 Minuten in kaltem Wasser wässern und abtropfen. ⏱ 5
2. Süßkartoffel 12 Minuten in Salzwasser gar kochen und abkühlen lassen. ⏱ 12
3. Fisch bzw. Champignons mit Salz in einer Schüssel vermengen.
4. Limettensaft, Chili und Zwiebel zugeben und alles gut mischen.
5. [Mit Fisch] Genau 10 Minuten marinieren lassen, bis der Fisch außen weiß ist. ⏱ 10
6. [Vegetarisch] 20 Minuten marinieren lassen. ⏱ 20
7. Koriander unterheben, mit Süßkartoffel und Mais anrichten.

## Notizen

Fisch nur frisch und am Kauftag zubereiten, vom Fischhändler als Sushi-Qualität. Für Schwangere, Kinder und Immungeschwächte nicht geeignet.
