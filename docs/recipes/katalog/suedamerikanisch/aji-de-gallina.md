# Ají de gallina

![Ají de gallina](../../pictures/aji-de-gallina.jpg)

Peruanisches Hähnchen in cremiger gelber Chili-Nuss-Sauce, auf Kartoffelscheiben serviert.

## Zutaten

| Menge      | Zutat              | Gruppe | Variante     | Hinweis                                 | Einkauf |
| ---------- | ------------------ | ------ | ------------ | --------------------------------------- | ------- |
| 300 g      | Hähnchenbrust      |        | Mit Hähnchen |                                         | Menge   |
| 300 g      | Blumenkohl         |        | Vegetarisch  | in Röschen                              | Menge   |
| 3 Scheiben | Toastbrot          |        |              | in Milch eingeweicht                    |         |
| 150 ml     | Milch              |        |              |                                         |         |
| 1          | Zwiebel            |        |              | fein gewürfelt                          |         |

## Zubereitung

1. Reis nach Packungsangabe kochen. ⏱ 12
2. Kartoffeln in Salzwasser 15 Minuten garkochen, Eier 9 Minuten mitkochen. ⏱ 15
3. [Mit Hähnchen] Hähnchen in Salzwasser 15 Minuten gar ziehen lassen, zerzupfen. ⏱ 15
4. [Vegetarisch] Blumenkohl 8 Minuten in Salzwasser garen und zerkleinern. ⏱ 8
5. Zwiebel in Öl 4 Minuten dünsten, Knoblauch und Aji-Paste 2 Minuten mitbraten. ⏱ 6
6. Brot mit Milch, Walnüssen und Parmesan fein pürieren und zur Zwiebel geben, 8 Minuten einkochen. ⏱ 8
7. Hähnchen bzw. Blumenkohl unterheben, mit Salz abschmecken.
8. Kartoffelscheiben mit Sauce, Ei und Oliven anrichten, mit Reis servieren.

## Notizen

Ersatz für Aji Amarillo: 1 TL Kurkuma und etwas Chili. Parmesan enthält tierisches Lab; für strikt Vegetarische einen vegetarischen Hartkäse nehmen.
