# Chimichurri

![Chimichurri](../../pictures/chimichurri.jpg)

Argentinische Kräutersauce zu Gegrilltem, Kartoffeln und Empanadas.

## Zutaten

| Menge  | Zutat        | Gruppe | Variante | Hinweis             | Einkauf |
| ------ | ------------ | ------ | -------- | ------------------- | ------- |
| 1 Bund | Petersilie   |        |          | glatt, fein gehackt |         |
| 3      | Knoblauch    |        |          | Zehen, fein gehackt |         |
| 1 TL   | Oregano      |        |          | getrocknet          |         |
| ½ TL   | Chiliflocken |        |          |                     |         |
| 100 ml | Olivenöl     |        |          |                     |         |
| 3 EL   | Rotweinessig |        |          |                     |         |
| ½ TL   | Salz         |        |          |                     |         |

## Zubereitung

1. Petersilie und Knoblauch sehr fein hacken.
2. Mit Oregano, Chiliflocken, Essig und Salz in einer Schüssel vermischen.
3. Öl unterrühren, mindestens 30 Minuten durchziehen lassen. ⏱ 30

## Notizen

Im Kühlschrank 5 Tage haltbar. Nicht im Mixer pürieren, sonst wird sie bitter.
