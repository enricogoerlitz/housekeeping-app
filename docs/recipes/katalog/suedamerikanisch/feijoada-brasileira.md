# Feijoada Brasileira

![Feijoada](../../pictures/feijoada-brasileira.jpg)

Brasilianischer Nationaleintopf aus schwarzen Bohnen, Fleisch und Wurst, mit Reis, Orangen und Grünkohl serviert.

## Zutaten

| Menge | Zutat           | Gruppe | Variante    | Hinweis                            | Einkauf |
| ----- | --------------- | ------ | ----------- | ---------------------------------- | ------- |
| 250 g | Schwarze Bohnen |        |             | getrocknet, über Nacht eingeweicht | Menge   |
| 200 g | Räucherwurst    |        | Mit Fleisch | in Scheiben                        | Menge   |
| 200 g | Schweinebauch   |        | Mit Fleisch | in Würfeln                         | Menge   |
| 1     | Süßkartoffel    |        | Vegetarisch | in Würfeln                         |         |
| 1     | Zwiebel         |        |             | gewürfelt                          |         |
| 4     | Knoblauch       |        |             | Zehen                              |         |
| 2     | Lorbeerblatt    |        |             |                                    |         |
| 1 EL  | Paprikapulver   |        |             | geräuchert                         |         |
| 2 EL  | Pflanzenöl      |        |             |                                    |         |
| 1 TL  | Salz            |        |             |                                    |         |
| 1,5 l | Wasser          |        |             |                                    | nie     |
| 150 g | Reis            |        |             | als Beilage                        |         |
| 1     | Orange          |        |             | in Spalten, zum Servieren          |         |

## Zubereitung

1. Eingeweichte Bohnen abgießen und mit frischem Wasser und Lorbeer aufkochen. 60 Minuten weich köcheln. ⏱ 60
2. [Mit Fleisch] Bauchfleisch in 1 EL Öl 8 Minuten braun anbraten, Wurst 3 Minuten mitbraten. ⏱ 8
3. Zwiebel und Knoblauch in 1 EL Öl 4 Minuten anbraten, Paprikapulver zugeben. ⏱ 4
4. Alles in die Bohnen rühren und 45 Minuten köcheln. ⏱ 45
5. [Vegetarisch] Süßkartoffelwürfel in den letzten 25 Minuten mitkochen. ⏱ 25
6. Mit Salz abschmecken, Teil der Bohnen zerdrücken, damit der Eintopf eindickt.
7. Reis nach Packung kochen und mit Orangenspalten zum Eintopf servieren. ⏱ 15

## Notizen

Vegetarisch fehlt die Rauchnote; geräuchertes Paprikapulver ausgleichen. Dosenbohnen sparen Zeit: 2 Dosen, 30 Minuten köcheln.
