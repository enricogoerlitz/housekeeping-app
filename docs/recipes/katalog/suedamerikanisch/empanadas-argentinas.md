# Empanadas

![Empanadas](../../pictures/empanadas-argentinas.jpg)

Gefüllte Teigtaschen aus Argentinien mit würziger Hackfüllung, gebacken statt frittiert.

## Zutaten

| Menge  | Zutat             | Gruppe  | Variante        | Hinweis                   | Einkauf |
| ------ | ----------------- | ------- | --------------- | ------------------------- | ------- |
| 300 g  | Mehl              | Teig    |                 | Type 405                  |         |
| 100 g  | Butter            | Teig    |                 | kalt, in Würfeln          |         |
| 100 ml | Wasser            | Teig    |                 | kalt                      | nie     |
| 1      | Ei                | Teig    |                 |                           |         |
| 1 TL   | Salz              | Teig    |                 |                           |         |

## Zubereitung

1. Mehl, Butter und Salz zu Streuseln verkneten, Ei und Wasser zugeben, zu glattem Teig kneten, 30 Minuten kühlen. ⏱ 30
2. [Vegetarisch] Kartoffeln in Salzwasser 12 Minuten garkochen, abgießen und leicht zerdrücken. ⏱ 12
3. Zwiebel in Öl 3 Minuten glasig dünsten. ⏱ 3
4. [Mit Rindfleisch] Hack zugeben und 6 Minuten braten, würzen. ⏱ 6
5. Füllung mit Oliven und Eiern vermengen, abkühlen lassen.
6. Backofen auf 200 °C Ober-/Unterhitze vorheizen. Teig ausrollen und 10 Kreise (10 cm) ausstechen.
7. Je 1 EL Füllung auf die Kreise geben, Ränder mit Wasser bestreichen, zuklappen und mit der Gabel andrücken.
8. Mit Eigelb bestreichen und 22 Minuten backen, bis sie goldbraun sind. ⏱ 22

## Notizen

Vegetarische Füllung mit Kartoffel, Zwiebel, Ei und Oliven ist ebenfalls traditionell. Kreuzkümmel und Paprika in beiden Varianten verwenden. Bei der Variante mit Kartoffel Würzen nicht vergessen. Teigplatten aus dem Supermarkt (Empanada-Teig) gehen auch.
