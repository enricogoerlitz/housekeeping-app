# Arepas con queso

![Arepas con queso](../../pictures/arepas-con-queso.jpg)

Kolumbianische Maisfladen mit Käse, außen knusprig, innen weich.

## Zutaten

| Menge  | Zutat      | Gruppe | Variante | Hinweis                              | Einkauf |
| ------ | ---------- | ------ | -------- | ------------------------------------ | ------- |
| 150 g  | Maismehl   |        |          | vorgekocht, z. B. P.A.N. oder Harina |         |
| 250 ml | Wasser     |        |          | lauwarm                              | nie     |
| 100 g  | Mozzarella |        |          | gerieben                             | Menge   |
| 1 TL   | Salz       |        |          |                                      |         |
| 1 EL   | Butter     |        |          |                                      |         |

## Zubereitung

1. Wasser mit Salz verrühren, Maismehl einstreuen und 5 Minuten quellen lassen. ⏱ 5
2. Käse zugeben, 2 Minuten kneten, bis ein glatter Teig entsteht.
3. 4 Kugeln formen und zu Scheiben von 1,5 cm Dicke drücken.
4. Butter in einer Pfanne zerlassen, Arepas bei mittlerer Hitze je 5 Minuten goldbraun braten. ⏱ 10
5. Warm servieren, aufschneiden und mit Butter oder Avocado füllen.

## Notizen

Maismehl für Arepas (vorgekochtes Maismehl, Harina precocida) gibt es im Latino-Shop; normales Maismehl funktioniert nicht.
