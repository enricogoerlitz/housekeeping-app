# Okonomiyaki

![Okonomiyaki](../../pictures/okonomiyaki.jpg)

Herzhafter Kohlpfannkuchen aus Osaka mit süßer Sauce und Mayonnaise.

## Zutaten

| Menge      | Zutat             | Gruppe  | Variante  | Hinweis                         | Einkauf |
| ---------- | ----------------- | ------- | --------- | ------------------------------- | ------- |
| 100 g      | Weizenmehl        | Teig    |           |                                 | Menge   |
| 120 ml     | Wasser            | Teig    |           |                                 | nie     |
| 0,5 TL     | Dashi-Pulver      | Teig    |           |                                 | 1×      |
| 2          | Ei                | Teig    |           |                                 |         |
| 300 g      | Weißkohl          | Teig    |           | fein geschnitten                | Menge   |
| 2          | Lauchzwiebel      | Teig    |           | in Ringen                       |         |
| 4 Scheiben | Bacon             |         | Mit Bacon |                                 | Menge   |
| 2 EL       | Sonnenblumenöl    |         |           |                                 |         |
| 3 EL       | Okonomiyaki-Sauce | Topping |           | oder Worcestersauce mit Ketchup | 1×      |
| 2 EL       | Mayonnaise        | Topping |           | Japanische, wenn vorhanden      | 1×      |
| 1 EL       | Katsuobushi       | Topping |           | Bonitoflocken                   | 1×      |

## Zubereitung

1. Mehl, Wasser, Dashi und Eier glatt verrühren, Kohl und Lauchzwiebeln unterheben.
2. Öl in einer Pfanne (ca. 20 cm) bei mittlerer Hitze erhitzen, die Hälfte des Teigs einfüllen und zu einem 2 cm dicken Fladen formen.
3. [Mit Bacon] 2 Baconscheiben auf den Teig legen. ⏱ 1
4. Zugedeckt 5 Minuten braten, wenden und weitere 5 Minuten garen. ⏱ 10
5. Zweiten Pfannkuchen ebenso backen.
6. Mit Sauce bestreichen, Mayonnaise darüber ziehen und mit Bonitoflocken bestreuen.

## Notizen

Bonitoflocken weglassen für eine rein pflanzliche Variante (Dashi-Pulver ist dann ebenfalls zu ersetzen, z. B. durch Kombu-Dashi). Okonomiyaki-Sauce Ersatz: 2 EL Worcestersauce, 1 EL Ketchup, 1 TL Zucker.
