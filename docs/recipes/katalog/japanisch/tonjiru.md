# Tonjiru – Miso-Suppe mit Schwein und Gemüse

![Tonjiru – Miso-Suppe mit Schwein und Gemüse](../../pictures/tonjiru.jpg)

Deftige japanische Misosuppe als Eintopf mit Wurzelgemüse, ideal für kalte Tage.

## Zutaten

| Menge  | Zutat         | Gruppe | Variante            | Hinweis                                 | Einkauf |
| ------ | ------------- | ------ | ------------------- | --------------------------------------- | ------- |
| 150 g  | Schweinebauch |        | Mit Schweinefleisch | dünn geschnitten                        | Menge   |
| 200 g  | Tofu          |        | Vegetarisch         | gewürfelt                               | Menge   |
| 1      | Karotte       |        |                     | in Halbmonden                           |         |
| 200 g  | Rettich       |        |                     | weißer Rettich oder Daikon, in Scheiben | Menge   |
| 2      | Kartoffel     |        |                     | festkochend, gewürfelt                  |         |
| 100 g  | Shiitake      |        |                     | in Scheiben                             | Menge   |
| 700 ml | Wasser        |        |                     |                                         | nie     |
| 1 TL   | Dashi-Pulver  |        |                     |                                         | 1×      |
| 3 EL   | Misopaste     |        |                     |                                         | 1×      |
| 1 EL   | Sesamöl       |        |                     |                                         |         |
| 2      | Lauchzwiebel  |        |                     | in Ringen                               |         |

## Zubereitung

1. Sesamöl im Topf erhitzen,
2. [Mit Schweinefleisch] Fleisch 3 Minuten anbraten. ⏱ 3
3. [Vegetarisch] Tofu 4 Minuten anbraten, bis er Farbe nimmt. ⏱ 4
4. Gemüse und Pilze zugeben, 2 Minuten mitbraten, Wasser und Dashi zugeben und zugedeckt 15 Minuten köcheln. ⏱ 17
5. Topf vom Herd nehmen, Miso in einer Kelle mit etwas Brühe glatt rühren und einrühren. Nicht mehr kochen.
6. Mit Lauchzwiebeln bestreuen und heiß servieren.

## Notizen

Miso nie kochen, sonst verliert es Aroma. Passt mit einer Schale Reis zum vollständigen Essen.
