# Spinat in Sesamsauce

![Spinat in Sesamsauce](../../pictures/horenso-goma-ae.jpg)

Blanchierter Spinat mit nussiger Sesamsauce, die klassische japanische Gemüsebeilage.

## Zutaten

| Menge | Zutat       | Gruppe | Variante | Hinweis           | Einkauf |
| ----- | ----------- | ------ | -------- | ----------------- | ------- |
| 300 g | Blattspinat |        |          | frisch, gewaschen | Menge   |
| 3 EL  | Sesam       |        |          | geröstet          |         |
| 1 EL  | Sojasauce   |        |          |                   |         |
| 1 TL  | Zucker      |        |          |                   |         |
| 1 TL  | Mirin       |        |          |                   |         |

## Zubereitung

1. Spinat 1 Minute in kochendem Salzwasser blanchieren, abschrecken und sehr gut ausdrücken. ⏱ 1
2. Sesam im Mörser zu grober Paste zerreiben.
3. Sesam mit Sojasauce, Zucker und Mirin verrühren.
4. Spinat in Abschnitte schneiden, mit der Sauce vermengen und servieren.

## Notizen

Statt Mörser geht auch ein Löffel Tahini.
