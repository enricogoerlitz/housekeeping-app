# Nasu Dengaku – Aubergine mit Miso

![Nasu Dengaku – Aubergine mit Miso](../../pictures/nasu-dengaku.jpg)

Gebackene Aubergine mit süß-salziger Miso-Glasur, vegan und sehr aromatisch.

## Zutaten

| Menge | Zutat          | Gruppe | Variante | Hinweis                            | Einkauf |
| ----- | -------------- | ------ | -------- | ---------------------------------- | ------- |
| 2     | Aubergine      |        |          | klein, halbiert und eingeschnitten | Menge   |
| 2 EL  | Sonnenblumenöl |        |          |                                    |         |
| 3 EL  | Misopaste      | Glasur |          | rot oder hell                      | 1×      |
| 2 EL  | Mirin          | Glasur |          |                                    |         |
| 1 EL  | Zucker         | Glasur |          |                                    |         |
| 1 EL  | Sake           | Glasur |          | oder Wasser                        |         |
| 1 EL  | Sesam          |        |          | geröstet                           |         |

## Zubereitung

1. Ofen auf 220 Grad (Ober-/Unterhitze) vorheizen.
2. Auberginen mit der Schnittfläche nach oben auf ein Blech legen, mit Öl bestreichen und 20 Minuten backen, bis sie weich sind. ⏱ 20
3. Miso, Mirin, Zucker und Sake in einem Topf 3 Minuten unter Rühren einkochen. ⏱ 3
4. Glasur auf die Auberginen streichen und unter dem Grill 3 Minuten karamellisieren. ⏱ 3
5. Mit Sesam bestreuen.

## Notizen

Gut als Beilage zu Reis. Statt Sake einfach Wasser nehmen.
