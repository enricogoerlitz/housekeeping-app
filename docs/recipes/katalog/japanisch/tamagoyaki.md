# Tamagoyaki

![Tamagoyaki](../../pictures/tamagoyaki.jpg)

Gerolltes, leicht süßes Omelett in vielen Schichten, ein Klassiker der Bento-Box.

## Zutaten

| Menge | Zutat          | Gruppe | Variante | Hinweis | Einkauf |
| ----- | -------------- | ------ | -------- | ------- | ------- |
| 4     | Ei             |        |          |         | Menge   |
| 2 EL  | Wasser         |        |          |         | nie     |
| 1 EL  | Zucker         |        |          |         |         |
| 1 EL  | Sojasauce      |        |          |         |         |
| 1 EL  | Mirin          |        |          |         |         |
| 1 EL  | Sonnenblumenöl |        |          |         |         |

## Zubereitung

1. Eier mit Wasser, Zucker, Sojasauce und Mirin verquirlen und durch ein Sieb gießen.
2. Eine kleine Pfanne mit Öl auspinseln und bei mittlerer Hitze erhitzen.
3. Eine dünne Eierschicht eingießen, sobald das Ei anfängt zu stocken, von der Seite aufrollen und an den Rand schieben. ⏱ 1
4. Pfanne ölen, die nächste Schicht eingießen, unter dem Roll hindurchlaufen lassen und wieder aufrollen. So 4 bis 5 Mal wiederholen. ⏱ 5
5. Omelett kurz ruhen lassen, in Stücke schneiden und warm oder kalt servieren.

## Notizen

Eine rechteckige Tamagoyaki-Pfanne ist nicht nötig, eine kleine runde Pfanne geht auch.
