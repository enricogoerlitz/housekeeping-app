# Karaage mit Reis und Kohl

![Karaage mit Reis und Kohl](../../pictures/karaage-reisbowl.jpg)

Japanisch frittiertes Hähnchen mit knuspriger Kruste aus Kartoffelstärke, dazu Kohl und Zitrone.

## Zutaten

| Menge  | Zutat            | Gruppe   | Variante     | Hinweis                             | Einkauf |
| ------ | ---------------- | -------- | ------------ | ----------------------------------- | ------- |
| 400 g  | Hähnchenschenkel |          | Mit Hähnchen | ohne Haut, in mundgerechten Stücken | Menge   |
| 400 g  | Tofu             |          | Vegetarisch  | gepresst, in Würfeln                | Menge   |
| 3 EL   | Sojasauce        | Marinade |              |                                     |         |
| 1 EL   | Mirin            | Marinade |              |                                     |         |
| 1 EL   | Ingwer           | Marinade |              | gerieben                            |         |

| 400 ml | Sonnenblumenöl   |          |              | zum Frittieren                      |         |

| 2 EL   | Mayonnaise       |          |              |                                     | 1×      |

## Zubereitung

1. Reis waschen und nach Packungsangabe kochen. ⏱ 20
2. [Mit Hähnchen] Hähnchen mit der Marinade mischen und 20 Minuten ziehen lassen. ⏱ 20
3. [Vegetarisch] Tofu gut ausdrücken, mit der Marinade mischen und 20 Minuten ziehen lassen. ⏱ 20
4. Stücke in Kartoffelstärke wenden und fest andrücken.
5. Öl auf 170 Grad erhitzen, Hähnchen 5 Minuten, Tofu 4 Minuten frittieren, herausnehmen und 3 Minuten ruhen lassen. ⏱ 5
6. Bei 180 Grad weitere 1 bis 2 Minuten knusprig ausbacken. ⏱ 2
7. Mit Reis, Kohl, Zitrone und Mayonnaise anrichten.

## Notizen

Zweimaliges Frittieren macht die Kruste besonders knusprig. Kartoffelstärke ersatzweise Speisestärke.
