# Gyudon

![Gyudon](../../pictures/gyudon.jpg)

Japanische Rindfleisch-Reisschale: hauchdünn geschnittenes Fleisch mit Zwiebeln in süß-herzhafter Sojasauce.

## Zutaten

| Menge  | Zutat              | Gruppe | Variante    | Hinweis                         | Einkauf |
| ------ | ------------------ | ------ | ----------- | ------------------------------- | ------- |
| 250 g  | Sushireis          |        |             |                                 | Menge   |
| 250 g  | Rindfleisch        |        | Mit Rind    | Hüfte oder Rumpsteak, hauchdünn | Menge   |
| 250 g  | Shiitake           |        | Vegetarisch | in Scheiben                     | Menge   |
| 200 g  | Tofu               |        | Vegetarisch | in Scheiben                     | Menge   |
| 2      | Zwiebel            |        |             | in Streifen                     |         |
| 150 ml | Wasser             |        |             |                                 | nie     |
| 1 TL   | Dashi-Pulver       |        |             |                                 | 1×      |
| 3 EL   | Sojasauce          |        |             |                                 |         |
| 2 EL   | Mirin              |        |             |                                 |         |
| 1 EL   | Zucker             |        |             |                                 |         |
| 1 EL   | Eingelegter Ingwer |        |             | rot oder Gari                   | 1×      |
| 1 TL   | Sesam              |        |             |                                 |         |

## Zubereitung

1. Reis waschen und nach Packungsangabe kochen. ⏱ 20
2. Wasser, Dashi, Sojasauce, Mirin und Zucker in einer Pfanne aufkochen.
3. Zwiebeln zugeben und 5 Minuten weich köcheln. ⏱ 5
4. [Mit Rind] Fleischscheiben einzeln einlegen und 3 Minuten garen, bis sie nicht mehr rosa sind. ⏱ 3
5. [Vegetarisch] Shiitake und Tofu einlegen und 6 Minuten garen. ⏱ 6
6. Reis in Schalen füllen, Topping samt Sud darübergeben, mit Ingwer und Sesam servieren.

## Notizen

Das Rindfleisch lässt sich leichter schneiden, wenn es 30 Minuten im Gefrierfach angefroren ist. Fertig geschnittenes Fleisch gibt es auch im Asia-Laden.
