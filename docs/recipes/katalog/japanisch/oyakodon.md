# Oyakodon

![Oyakodon](../../pictures/oyakodon.jpg)

Japanische Reisschale mit sämig gestocktem Ei in süßlicher Dashi-Sojasauce, ein 20-Minuten-Gericht.

## Zutaten

| Menge  | Zutat            | Gruppe | Variante     | Hinweis               | Einkauf |
| ------ | ---------------- | ------ | ------------ | --------------------- | ------- |
| 250 g  | Sushireis        |        |              |                       | Menge   |
| 250 g  | Hähnchenschenkel |        | Mit Hähnchen | ohne Haut, in Stücken | Menge   |
| 200 g  | Tofu             |        | Vegetarisch  | in Würfeln            | Menge   |
| 100 g  | Shiitake         |        | Vegetarisch  | in Scheiben           | Menge   |
| 1      | Zwiebel          |        |              | in Streifen           |         |
| 4      | Ei               |        |              | leicht verquirlt      |         |
| 200 ml | Wasser           |        |              |                       | nie     |
| 1 TL   | Dashi-Pulver     |        |              |                       | 1×      |
| 3 EL   | Sojasauce        |        |              |                       |         |
| 2 EL   | Mirin            |        |              |                       |         |
| 1 EL   | Zucker           |        |              |                       |         |
| 1      | Lauchzwiebel     |        |              | in Ringen             |         |

## Zubereitung

1. Reis waschen und nach Packungsangabe kochen. ⏱ 20
2. Wasser, Dashi, Sojasauce, Mirin und Zucker in einer breiten Pfanne aufkochen.
3. Zwiebel zugeben und 3 Minuten köcheln. ⏱ 3
4. [Mit Hähnchen] Hähnchen einlegen und 6 Minuten bei mittlerer Hitze garen. ⏱ 6
5. [Vegetarisch] Tofu und Shiitake einlegen und 6 Minuten garen. ⏱ 6
6. Die Hälfte des Eis darübergießen, 1 Minute köcheln, dann den Rest zugeben und 30 Sekunden stocken lassen, bis es noch weich-cremig ist. ⏱ 2
7. Reis in Schalen füllen, Ei-Mischung samt Sud daraufgeben und mit Lauchzwiebeln bestreuen.

## Notizen

Dashi-Pulver (Hondashi) aus dem Asia-Laden; Ersatz: 200 ml Gemüsebrühe statt Wasser plus Dashi.
