# Zaru Soba mit Tsuyu-Dip

![Zaru Soba mit Tsuyu-Dip](../../pictures/zaru-soba.jpg)

Kalte Buchweizennudeln zum Eintauchen, erfrischend und in 20 Minuten fertig.

## Zutaten

| Menge   | Zutat          | Gruppe  | Variante             | Hinweis                        | Einkauf |
| ------- | -------------- | ------- | -------------------- | ------------------------------ | ------- |
| 200 g   | Soba-Nudeln    |         |                      |                                | Menge   |
| 100 ml  | Sojasauce      | Dip     |                      |                                |         |
| 100 ml  | Mirin          | Dip     |                      |                                |         |
| 200 ml  | Wasser         | Dip     |                      |                                | nie     |
| 1 TL    | Dashi-Pulver   | Dip     |                      |                                | 1×      |
| 2       | Lauchzwiebel   | Beilage |                      | in feinen Ringen               |         |
| 1 TL    | Wasabi         | Beilage |                      | Paste                          | 1×      |
| 1 Blatt | Nori           | Beilage |                      | in feinen Streifen             | 1×      |
| 6       | Garnelen       |         | Mit Garnelen-Tempura | geschält                       |         |
| 80 g    | Tempuramehl    |         | Mit Garnelen-Tempura | mit 140 ml Eiswasser angerührt | 1×      |
| 300 ml  | Sonnenblumenöl |         | Mit Garnelen-Tempura | zum Frittieren                 |         |

## Zubereitung

1. Für den Dip Sojasauce, Mirin, Wasser und Dashi 2 Minuten aufkochen, abkühlen und kalt stellen. ⏱ 2
2. Soba nach Packungsangabe (ca. 5 Minuten) kochen, in Eiswasser abschrecken und gründlich abtropfen. ⏱ 5
3. [Mit Garnelen-Tempura] Öl auf 175 Grad erhitzen, Garnelen durch den Teig ziehen und je 2 Minuten goldgelb frittieren. ⏱ 2
4. Nudeln auf Teller oder Bambusmatte legen, mit Nori bestreuen.
5. Dip in kleine Schalen geben, Lauchzwiebeln und Wasabi daneben anrichten. Nudeln in den Dip tauchen.

## Notizen

Soba nach dem Kochen unbedingt kalt abspülen, damit die Stärke abgewaschen wird. Das Fett vom Frittieren ist nur in der Tempura-Variante nötig.
