# Omurice

![Omurice](../../pictures/omurice.jpg)

Omelett über Ketchup-Reis, ein japanischer Kinderklassiker auch für Erwachsene.

## Zutaten

| Menge   | Zutat         | Gruppe | Variante     | Hinweis            | Einkauf |
| ------- | ------------- | ------ | ------------ | ------------------ | ------- |
| 300 g   | Jasminreis    |        |              | vom Vortag         | Menge   |
| 150 g   | Hähnchenbrust |        | Mit Hähnchen | in kleinen Würfeln | Menge   |
| 100 g   | Champignons   |        | Vegetarisch  | gewürfelt          | Menge   |
| 1       | Zwiebel       |        |              | fein gewürfelt     |         |
| 80 g    | Erbsen        |        |              | TK                 |         |
| 4 EL    | Ketchup       |        |              |                    |         |
| 1 EL    | Sojasauce     |        |              |                    |         |
| 4       | Ei            |        |              |                    |         |
| 2 EL    | Milch         |        |              |                    |         |
| 2 EL    | Butter        |        |              |                    |         |
| 1 Prise | Salz          |        |              |                    |         |

## Zubereitung

1. Butter (1 EL) in der Pfanne erhitzen, Zwiebel und
2. [Mit Hähnchen] Hähnchen 5 Minuten braten. ⏱ 5
3. [Vegetarisch] Zwiebel und Champignons 5 Minuten braten. ⏱ 5
4. Erbsen und Reis zugeben, 3 Minuten braten, mit Ketchup und Sojasauce würzen. ⏱ 3
5. Reis zu zwei Portionen formen und auf Teller geben.
6. Eier mit Milch und Salz verquirlen, die Hälfte in 1/2 EL Butter bei mittlerer Hitze unter Rühren 1 Minute anstocken lassen, Pfanne schwenken und zu einem weichen Omelett formen. ⏱ 2
7. Omelett über den Reis gleiten lassen, zweites Omelett ebenso. Mit Ketchup garnieren.

## Notizen

Das Omelett soll innen noch leicht cremig sein.
