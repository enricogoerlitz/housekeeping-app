# Dorayaki

![Dorayaki](../../pictures/dorayaki.jpg)

Zwei weiche Honigpfannkuchen, gefüllt mit süßer Azukibohnen-Paste.

## Zutaten

| Menge | Zutat          | Gruppe  | Variante | Hinweis                | Einkauf |
| ----- | -------------- | ------- | -------- | ---------------------- | ------- |
| 2     | Ei             | Teig    |          |                        | Menge   |
| 50 g  | Zucker         | Teig    |          |                        |         |
| 1 EL  | Honig          | Teig    |          |                        |         |
| 100 g | Weizenmehl     | Teig    |          |                        |         |
| 1 TL  | Backpulver     | Teig    |          |                        |         |
| 80 ml | Milch          | Teig    |          |                        |         |
| 1 EL  | Sonnenblumenöl |         |          |                        |         |
| 100 g | Anko           | Füllung |          | Azukibohnenpaste, Dose | Menge   |

## Zubereitung

1. Eier, Zucker und Honig 3 Minuten aufschlagen. ⏱ 3
2. Mehl mit Backpulver sieben, abwechselnd mit der Milch einrühren, bis ein glatter Teig entsteht. Teig 10 Minuten ruhen lassen. ⏱ 10
3. Pfanne dünn einölen und bei niedriger Hitze erhitzen. Je 2 EL Teig zu runden Pfannkuchen ausgießen.
4. Pro Seite 1 bis 2 Minuten backen, bis die Oberfläche Blasen wirft und goldgelb ist. ⏱ 3
5. Je zwei Pfannkuchen mit 2 EL Anko füllen und zusammensetzen.

## Notizen

Anko im Asia-Laden. Ersatz: Nutella oder Kastanienpüree.
