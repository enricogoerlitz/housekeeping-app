# Adas Polo

![Adas Polo](../../pictures/adas-polo.jpg)

Persischer Linsenreis mit Datteln, Rosinen und Röstzwiebeln, aromatisch mit Safran und Zimt.

## Zutaten

| Menge  | Zutat         | Gruppe | Variante     | Hinweis                                | Einkauf |
| ------ | ------------- | ------ | ------------ | -------------------------------------- | ------- |
| 200 g  | Basmatireis   |        |              |                                        |         |
| 100 g  | Braune Linsen |        |              |                                        |         |
| 2      | Zwiebel       |        |              | in Ringen                              |         |
| 4 EL   | Öl            |        |              |                                        |         |
| 8      | Datteln       |        |              | entsteint, in Stücken                  |         |
| 30 g   | Rosinen       |        |              |                                        |         |
| 1 TL   | Zimt          |        |              |                                        |         |
| 1/2 TL | Kurkuma       |        |              |                                        |         |
| 1 g    | Safran        |        |              | gemahlen, in 2 EL heißem Wasser gelöst |         |
| 30 g   | Butter        |        |              |                                        |         |
| 1 TL   | Salz          |        |              |                                        |         |
| 2      | Hähnchenbrust |        | Mit Hähnchen |                                        | Menge   |

## Zubereitung

1. Linsen in Salzwasser 15 Minuten vorkochen und abgießen. ⏱ 15
2. Zwiebeln in 3 EL Öl bei mittlerer Hitze 15 Minuten goldbraun braten, Hälfte beiseitestellen. ⏱ 15
3. [Mit Hähnchen] Hähnchenbrust in Streifen mit Salz und Kurkuma im Öl 8 Minuten goldbraun braten. ⏱ 8
4. Reis in reichlich Salzwasser 8 Minuten vorkochen und abgießen. ⏱ 8
5. Reis, Linsen, Zimt, Datteln und Rosinen in den Topf schichten, Butter und Safranwasser darübergeben.
6. Zugedeckt (Deckel in Küchentuch) bei kleinster Hitze 25 Minuten dämpfen. ⏱ 25
7. Mit den Röstzwiebeln und optional den Hähnchenstreifen anrichten.

## Notizen

Den knusprigen Reisboden (Tahdig) isst man als Beste vom Topf; dafür den Topfboden vorher mit Öl und einer Kartoffelscheibe auslegen.
