# Kuku Sabzi

![Kuku Sabzi](../../pictures/kuku-sabzi.jpg)

Persisches Kräuteromelett aus dem Ofen, voll mit Petersilie, Dill und Koriander, mit Berberitzen und Walnüssen. Warm und kalt ein Genuss.

## Zutaten

| Menge  | Zutat        | Gruppe | Variante | Hinweis          | Einkauf |
| ------ | ------------ | ------ | -------- | ---------------- | ------- |
| 6      | Ei           |        |          |                  |         |
| 2 Bund | Petersilie   |        |          | fein gehackt     |         |
| 1 Bund | Dill         |        |          | fein gehackt     |         |
| 1 Bund | Koriander    |        |          | fein gehackt     |         |
| 4      | Lauchzwiebel |        |          | in feinen Ringen |         |
| 1 EL   | Mehl         |        |          |                  |         |
| 1/2 TL | Backpulver   |        |          |                  |         |
| 1/2 TL | Kurkuma      |        |          |                  |         |
| 1 EL   | Berberitzen  |        |          | getrocknet       |         |
| 40 g   | Walnüsse     |        |          | gehackt          |         |
| 1 TL   | Salz         |        |          |                  |         |
| 3 EL   | Öl           |        |          |                  |         |
| 150 g  | Naturjoghurt |        |          | zum Servieren    |         |
| 2      | Fladenbrot   |        |          |                  |         |

## Zubereitung

1. Ofen auf 180 °C vorheizen. Berberitzen 10 Minuten in warmem Wasser einweichen. ⏱ 10
2. Eier mit Mehl, Backpulver, Kurkuma und Salz verquirlen.
3. Kräuter, Lauchzwiebeln, Walnüsse und abgetropfte Berberitzen unterheben.
4. In einer ofenfesten Pfanne (22 cm) das Öl erhitzen, die Masse einfüllen und 3 Minuten anbraten.
5. Im Ofen 20 Minuten backen, bis die Mitte fest ist. ⏱ 20
6. In Stücke schneiden und mit Joghurt und Brot servieren.

## Notizen

Berberitzen (Zereschk) im Orientladen, ersatzweise ungesüßte Cranberries.
