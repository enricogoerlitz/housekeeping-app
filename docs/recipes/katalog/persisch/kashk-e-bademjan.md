# Kashk-e Bademjan

![Kashk-e Bademjan](../../pictures/kashk-e-bademjan.jpg)

Persischer Auberginenaufstrich mit Knoblauch, Röstzwiebeln und Minzöl, traditionell mit Kashk (Molkepaste).

## Zutaten

| Menge  | Zutat        | Gruppe | Variante | Hinweis               | Einkauf |
| ------ | ------------ | ------ | -------- | --------------------- | ------- |
| 2      | Aubergine    |        |          |                       |         |
| 2      | Zwiebel      |        |          | in Ringen             |         |
| 3      | Knoblauch    |        |          | Zehen, gehackt        |         |
| 4 EL   | Öl           |        |          |                       |         |
| 1 EL   | Minze        |        |          | getrocknet            |         |
| 2 EL   | Naturjoghurt |        |          | ersatzweise für Kashk |         |
| 1/2 TL | Kurkuma      |        |          |                       |         |
| 1 TL   | Salz         |        |          |                       |         |
| 2 EL   | Walnüsse     |        |          | gehackt               |         |

## Zubereitung

1. Auberginen schälen, in dicke Scheiben schneiden, salzen und 10 Minuten ziehen lassen. In 2 EL Öl beidseitig goldbraun braten. ⏱ 15
2. Zwiebeln im restlichen Öl 15 Minuten goldbraun rösten, die Hälfte herausnehmen. ⏱ 15
3. Knoblauch und Kurkuma zugeben, Auberginen untermischen und mit einer Gabel zerdrücken, 5 Minuten köcheln. ⏱ 5
4. Mit Joghurt und Salz abschmecken.
5. Mit Röstzwiebeln, Walnüssen und in heißem Öl kurz angerösteter Minze toppen.

## Notizen

Kashk gibt es im Iran-Laden, Joghurt mit etwas Salz und Zitrone ist ein guter Ersatz.
