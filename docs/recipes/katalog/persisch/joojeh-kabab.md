# Joojeh Kabab

![Joojeh Kabab](../../pictures/joojeh-kabab.jpg)

Safran-Joghurt-Hähnchenspieße mit gebuttertem Safranreis, das Festtagsessen aus dem Iran.

## Zutaten

| Menge | Zutat         | Gruppe | Variante     | Hinweis                                | Einkauf |
| ----- | ------------- | ------ | ------------ | -------------------------------------- | ------- |
| 500 g | Hähnchenbrust |        | Mit Hähnchen | in 3 cm Würfeln                        | Menge   |
| 250 g | Halloumi      |        | Vegetarisch  | in Würfeln                             | Menge   |
| 1     | Zucchini      |        | Vegetarisch  | in dicken Scheiben                     |         |
| 1     | Zwiebel       |        |              | gerieben                               |         |
| 100 g | Naturjoghurt  |        |              |                                        |         |
| 1 g   | Safran        |        |              | gemahlen, in 3 EL heißem Wasser gelöst |         |
| 2 EL  | Zitronen      |        |              | Saft                                   |         |
| 2 EL  | Olivenöl      |        |              |                                        |         |
| 1 TL  | Salz          |        |              |                                        |         |
| 200 g | Basmatireis   |        |              |                                        |         |
| 30 g  | Butter        |        |              |                                        |         |
| 2     | Tomate        |        |              |                                        |         |

## Zubereitung

1. Zwiebel, Joghurt, die Hälfte des Safranwassers, Zitronensaft, Öl und Salz verrühren.
2. [Mit Hähnchen] Hähnchenwürfel darin mindestens 2 Stunden marinieren. ⏱ 120
3. [Vegetarisch] Halloumi und Zucchini 30 Minuten marinieren. ⏱ 30
4. Reis in Salzwasser 10 Minuten kochen, abgießen, mit Butter und dem restlichen Safranwasser mischen und 10 Minuten dämpfen. ⏱ 20
5. Fleisch bzw. Halloumi und Zucchini auf Spieße stecken, in heißer Grillpfanne oder unter dem Grill 12 Minuten braten und wenden. ⏱ 12
6. Tomaten halbieren und kurz mitgrillen.
7. Spieße auf Reis mit Tomaten anrichten.

## Notizen

Safran nicht sparen, aber nur ein kleines Briefchen (0,1 g) pro Portion genügt oft; Kurkuma färbt, ersetzt aber nicht den Geschmack.
