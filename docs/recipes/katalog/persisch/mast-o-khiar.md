# Mast-o-Khiar

![Mast-o-Khiar](../../pictures/mast-o-khiar.jpg)

Persische Joghurt-Gurken-Creme mit Minze und Walnüssen, kühl und frisch zu Reis und Gegrilltem.

## Zutaten

| Menge  | Zutat        | Gruppe | Variante | Hinweis        | Einkauf |
| ------ | ------------ | ------ | -------- | -------------- | ------- |
| 300 g  | Naturjoghurt |        |          |                |         |
| 1/2    | Gurke        |        |          | fein gewürfelt |         |
| 1 EL   | Minze        |        |          | getrocknet     |         |
| 1      | Knoblauch    |        |          | Zehe, gepresst |         |
| 2 EL   | Walnüsse     |        |          | gehackt        |         |
| 1 EL   | Rosinen      |        |          |                |         |
| 1/2 TL | Salz         |        |          |                |         |
| 1 EL   | Olivenöl     |        |          |                |         |

## Zubereitung

1. Joghurt mit Knoblauch und Salz glatt rühren.
2. Gurke, Minze, Walnüsse und Rosinen unterheben.
3. Mit Öl beträufeln und 20 Minuten durchziehen lassen. ⏱ 20

## Notizen

Mit etwas mehr Gurke wird daraus ein Löffelsalat, mit Wasser verdünnt ein Sommergetränk (Doogh).
