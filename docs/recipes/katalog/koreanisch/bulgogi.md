# Bulgogi

![Bulgogi](../../pictures/bulgogi.jpg)

Koreanisches Marinadenfleisch mit Birne und Sojasauce, süß, rauchig und butterzart.

## Zutaten

| Menge | Zutat          | Gruppe   | Variante    | Hinweis                      | Einkauf |
| ----- | -------------- | -------- | ----------- | ---------------------------- | ------- |
| 300 g | Rindfleisch    |          | Mit Rind    | Hüfte, hauchdünn geschnitten | Menge   |
| 300 g | Austernpilze   |          | Vegetarisch | in Streifen gezupft          | Menge   |
| 4 EL  | Sojasauce      | Marinade |             |                              |         |
| 1 EL  | Zucker         | Marinade |             | braun                        |         |
| 1 EL  | Sesamöl        | Marinade |             |                              |         |
| 0,5   | Birne          | Marinade |             | gerieben                     |         |
| 3     | Knoblauch      | Marinade |             | Zehen, gepresst              |         |
| 1     | Zwiebel        |          |             | in Streifen                  |         |
| 2     | Lauchzwiebel   |          |             | in Stücken                   |         |
| 1 EL  | Sesam          |          |             |                              |         |
| 1     | Kopfsalat      |          |             | Blätter zum Einwickeln       |         |
| 250 g | Jasminreis     |          |             | zum Servieren                | Menge   |
| 1 EL  | Sonnenblumenöl |          |             |                              |         |

## Zubereitung

1. Marinadenzutaten verrühren.
2. [Mit Rind] Fleisch darin 30 Minuten marinieren. ⏱ 30
3. [Vegetarisch] Pilze mit der Marinade mischen und 15 Minuten ziehen lassen. ⏱ 15
4. Reis nach Packungsangabe kochen. ⏱ 15
5. Öl in einer sehr heißen Pfanne erhitzen, Zwiebel 2 Minuten braten. ⏱ 2
6. [Mit Rind] Fleisch in zwei Portionen je 3 Minuten braten, bis es karamellisiert. ⏱ 6
7. [Vegetarisch] Pilze 6 Minuten braten, bis sie Farbe nehmen. ⏱ 6
8. Lauchzwiebeln kurz unterheben, mit Sesam bestreuen und mit Reis und Salatblättern servieren.

## Notizen

Birne gibt Süße und macht das Fleisch zart; ersatzweise 1 EL Apfelsaft. In Portionen braten, damit nichts schmort.
