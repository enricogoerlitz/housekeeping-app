# Sundubu-Jjigae – cremiger Tofu-Eintopf

![Sundubu-Jjigae – cremiger Tofu-Eintopf](../../pictures/sundubu-jjigae.jpg)

Scharfer Eintopf mit seidigem Tofu und einem Ei, schnell und wärmend.

## Zutaten

| Menge  | Zutat        | Gruppe | Variante     | Hinweis             | Einkauf |
| ------ | ------------ | ------ | ------------ | ------------------- | ------- |
| 400 g  | Seidentofu   |        |              |                     | Menge   |
| 100 g  | Champignons  |        |              | in Scheiben         |         |
| 150 g  | Garnelen     |        | Mit Garnelen | geschält, aufgetaut | Menge   |
| 1      | Zwiebel      |        |              | in Streifen         |         |
| 1 EL   | Gochugaru    |        |              |                     | 1×      |
| 1 EL   | Sojasauce    |        |              |                     |         |
| 2      | Knoblauch    |        |              | Zehen, gehackt      |         |
| 1 EL   | Sesamöl      |        |              |                     |         |
| 400 ml | Wasser       |        |              |                     | nie     |
| 1 TL   | Gemüsebrühe  |        |              | Pulver              | 1×      |
| 2      | Ei           |        |              |                     |         |
| 2      | Lauchzwiebel |        |              | in Ringen           |         |
| 250 g  | Jasminreis   |        |              | zum Servieren       | Menge   |

## Zubereitung

1. Sesamöl erhitzen, Zwiebel, Knoblauch und Gochugaru 2 Minuten bei niedriger Hitze braten. ⏱ 2
2. Champignons zugeben und 3 Minuten braten. ⏱ 3
3. Wasser, Brühpulver und Sojasauce zugeben, aufkochen und 8 Minuten köcheln. ⏱ 8
4. Tofu in großen Stücken einlöffeln,
5. [Mit Garnelen] Garnelen dazugeben, 4 Minuten garen. ⏱ 4
6. Je ein Ei in die Mitte jeder Portion schlagen, zugedeckt 1 Minute stocken lassen. ⏱ 1
7. Mit Lauchzwiebeln bestreuen und mit Reis servieren.

## Notizen

Das Ei gart im heißen Eintopf nach; wer es weich mag, lässt es nur kurz.
