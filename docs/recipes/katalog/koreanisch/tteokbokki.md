# Tteokbokki

![Tteokbokki](../../pictures/tteokbokki.jpg)

Koreanisches Streetfood: Reiskuchen in süß-scharfer Gochujang-Sauce.

## Zutaten

| Menge  | Zutat        | Gruppe | Variante               | Hinweis                                | Einkauf |
| ------ | ------------ | ------ | ---------------------- | -------------------------------------- | ------- |
| 300 g  | Tteok        |        |                        | Reiskuchen-Zylinder, Kühlregal oder TK | Menge   |
| 3 EL   | Gochujang    |        |                        |                                        | 1×      |
| 1 EL   | Gochugaru    |        |                        |                                        | 1×      |
| 1 EL   | Sojasauce    |        |                        |                                        |         |
| 1 EL   | Zucker       |        |                        |                                        |         |
| 300 ml | Wasser       |        |                        |                                        | nie     |
| 1      | Zwiebel      |        |                        | in Streifen                            |         |
| 150 g  | Weißkohl     |        |                        | in Stücken                             |         |
| 2      | Lauchzwiebel |        |                        | in Stücken                             |         |
| 2      | Ei           |        | Mit Ei und Fischkuchen | hartgekocht, geschält                  |         |
| 100 g  | Fischkuchen  |        | Mit Ei und Fischkuchen | in Streifen                            | Menge   |
| 1 TL   | Sesam        |        |                        |                                        |         |

## Zubereitung

1. Tteok 10 Minuten in warmem Wasser einweichen (falls gefroren oder hart). ⏱ 10
2. [Mit Ei und Fischkuchen] Eier 9 Minuten hart kochen, abschrecken und schälen. ⏱ 9
3. Wasser mit Gochujang, Gochugaru, Sojasauce und Zucker in einer breiten Pfanne aufkochen.
4. Zwiebel und Kohl zugeben, 5 Minuten köcheln. ⏱ 5
5. Tteok (und
6. [Mit Ei und Fischkuchen] Fischkuchen) zugeben und 8 bis 10 Minuten rühren, bis die Sauce dick wird und die Reiskuchen weich sind. ⏱ 9
7. Lauchzwiebeln und Eier zugeben, mit Sesam bestreuen.

## Notizen

Tteok im Asia-Laden. Zu scharf: 1 EL Honig oder Zucker mehr oder etwas Sahne einrühren.
