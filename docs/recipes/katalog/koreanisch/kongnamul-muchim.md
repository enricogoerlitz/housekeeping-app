# Kongnamul-Muchim – Sojasprossen-Beilage

![Kongnamul-Muchim – Sojasprossen-Beilage](../../pictures/kongnamul-muchim.jpg)

Knackige Sojasprossen mit Sesamöl und Knoblauch, das einfachste Banchan.

## Zutaten

| Menge   | Zutat        | Gruppe | Variante | Hinweis            | Einkauf |
| ------- | ------------ | ------ | -------- | ------------------ | ------- |
| 300 g   | Sprossen     |        |          | Sojabohnensprossen | Menge   |
| 1 EL    | Sesamöl      |        |          |                    |         |
| 1       | Knoblauch    |        |          | Zehe, gepresst     |         |
| 1       | Lauchzwiebel |        |          | in Ringen          |         |
| 1 TL    | Sojasauce    |        |          |                    |         |
| 1 TL    | Sesam        |        |          |                    |         |
| 1 TL    | Gochugaru    |        |          | optional           | 1×      |
| 1 Prise | Salz         |        |          |                    |         |

## Zubereitung

1. Sprossen waschen und 5 Minuten in Salzwasser kochen, Deckel geschlossen halten. ⏱ 5
2. Abgießen, in kaltem Wasser abschrecken und gut abtropfen lassen.
3. Mit Sesamöl, Knoblauch, Lauchzwiebel, Sojasauce, Gochugaru und Sesam vermengen. Kalt servieren.

## Notizen

Deckel während des Kochens nicht öffnen, sonst entsteht ein Beigeschmack.
