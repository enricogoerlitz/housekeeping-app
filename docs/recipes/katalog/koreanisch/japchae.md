# Japchae

![Japchae](../../pictures/japchae.jpg)

Glasnudeln aus Süßkartoffelstärke mit buntem Gemüse in süß-salziger Sesam-Sojasauce.

## Zutaten

| Menge | Zutat          | Gruppe | Variante | Hinweis            | Einkauf |
| ----- | -------------- | ------ | -------- | ------------------ | ------- |
| 150 g | Glasnudeln     |        |          | aus Süßkartoffel   | Menge   |
| 150 g | Blattspinat    |        |          |                    | Menge   |
| 1     | Karotte        |        |          | in Streifen        |         |
| 1     | Paprika        |        |          | rot, in Streifen   |         |
| 1     | Zwiebel        |        |          | in Streifen        |         |
| 100 g | Shiitake       |        |          | in Scheiben        |         |
| 150 g | Rindfleisch    |        | Mit Rind | in dünnen Streifen | Menge   |
| 4 EL  | Sojasauce      |        |          | geteilt            |         |
| 2 EL  | Zucker         |        |          |                    |         |
| 2 EL  | Sesamöl        |        |          |                    |         |
| 2     | Knoblauch      |        |          | Zehen, gepresst    |         |
| 1 EL  | Sesam          |        |          |                    |         |
| 2 EL  | Sonnenblumenöl |        |          |                    |         |

## Zubereitung

1. Glasnudeln nach Packungsangabe (ca. 6 Minuten) garen, abtropfen und mit Schere kürzen. Mit 2 EL Sojasauce, 1 EL Zucker und 1 EL Sesamöl mischen. ⏱ 6
2. Spinat 30 Sekunden blanchieren, ausdrücken und mit etwas Sesamöl würzen. ⏱ 1
3. Zwiebel, Karotte, Paprika und Shiitake nacheinander je 2 Minuten in Öl braten und leicht salzen. ⏱ 8
4. [Mit Rind] Rindfleisch mit Knoblauch, 1 EL Sojasauce und 1 TL Zucker 3 Minuten scharf braten. ⏱ 3
5. Alles mit den Nudeln vermengen, restliche Sojasauce zugeben und gut durchmischen.
6. Mit Sesam bestreuen, warm oder lauwarm servieren.

## Notizen

Die Nudeln nach dem Garen nicht abspülen, sonst nehmen sie die Würze schlechter auf.
