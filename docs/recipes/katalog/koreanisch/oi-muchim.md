# Oi-Muchim – scharfe Gurkenbeilage

![Oi-Muchim – scharfe Gurkenbeilage](../../pictures/oi-muchim.jpg)

Knackige Gurke mit Gochugaru und Essig, erfrischend und scharf.

## Zutaten

| Menge | Zutat      | Gruppe | Variante | Hinweis            | Einkauf |
| ----- | ---------- | ------ | -------- | ------------------ | ------- |
| 2     | Salatgurke |        |          | in dünnen Scheiben | Menge   |
| 1 TL  | Salz       |        |          |                    |         |
| 1 EL  | Gochugaru  |        |          |                    | 1×      |
| 1 EL  | Reisessig  |        |          |                    |         |
| 1 TL  | Zucker     |        |          |                    |         |
| 1     | Knoblauch  |        |          | Zehe, gepresst     |         |
| 1 TL  | Sesamöl    |        |          |                    |         |
| 1 TL  | Sesam      |        |          |                    |         |

## Zubereitung

1. Gurkenscheiben mit Salz mischen, 10 Minuten ziehen lassen, dann ausdrücken. ⏱ 10
2. Gochugaru, Essig, Zucker, Knoblauch und Sesamöl verrühren.
3. Gurken mit der Würzmischung vermengen, mit Sesam bestreuen und kühl servieren.

## Notizen

Hält sich im Kühlschrank 2 Tage, wird aber weicher.
