# Dakgalbi

![Dakgalbi](../../pictures/dakgalbi.jpg)

Scharfes Pfannengericht aus Chuncheon mit Gochujang, Kohl und Süßkartoffel.

## Zutaten

| Menge  | Zutat            | Gruppe   | Variante     | Hinweis               | Einkauf |

| 300 g  | Tofu             |          | Vegetarisch  | in dicken Würfeln     | Menge   |
| 3 EL   | Gochujang        | Marinade |              |                       | 1×      |
| 1 EL   | Gochugaru        | Marinade |              |                       | 1×      |
| 2 EL   | Sojasauce        | Marinade |              |                       |         |

## Zubereitung

1. Marinade verrühren,
2. [Mit Hähnchen] Hähnchen und
3. [Vegetarisch] Tofu jeweils 30 Minuten darin marinieren. ⏱ 30
4. Reis nach Packungsangabe kochen. ⏱ 15
5. Öl in einer großen Pfanne erhitzen, Süßkartoffel mit Wasser zugedeckt 5 Minuten vorgaren. ⏱ 5
6. Fleisch beziehungsweise Tofu samt Marinade zugeben und 8 Minuten braten. ⏱ 8
7. Kohl und Zwiebel zugeben und 7 Minuten garen, bis alles weich ist und die Sauce dick glänzt. ⏱ 7
8. Lauchzwiebeln unterheben und mit Reis servieren.

## Notizen

Gochujang gibt es im Asia-Laden; ersatzweise 2 EL Sambal Oelek plus 1 EL Tomatenmark. Vegetarisch Tofu nicht zu oft wenden.
