# Gimbap

![Gimbap](../../pictures/gimbap.jpg)

Koreanische Reisrollen mit Gemüse und Ei, ideal für Picknick und Lunchbox.

## Zutaten

| Menge      | Zutat               | Gruppe | Variante | Hinweis                  | Einkauf |
| ---------- | ------------------- | ------ | -------- | ------------------------ | ------- |
| 300 g      | Sushireis           |        |          |                          | Menge   |
| 1 EL       | Sesamöl             |        |          |                          |         |
| 1 TL       | Salz                |        |          |                          |         |
| 4 Blätter  | Nori                |        |          |                          | Menge   |
| 2          | Ei                  |        |          |                          |         |
| 1          | Karotte             |        |          | in Streifen              |         |
| 100 g      | Blattspinat         |        |          |                          |         |
| 1          | Salatgurke          |        |          | in Streifen, entkernt    |         |
| 4 Streifen | Eingelegter Rettich |        |          | gelber Rettich (Danmuji) | 1×      |
| 150 g      | Rinderhack          |        | Mit Rind |                          | Menge   |
| 1 EL       | Sojasauce           |        | Mit Rind |                          |         |
| 1 EL       | Sonnenblumenöl      |        |          |                          |         |

## Zubereitung

1. Reis nach Packungsangabe kochen und mit Sesamöl und Salz vermengen. ⏱ 20
2. Eier verquirlen, in einer dünnen Schicht stocken lassen und in Streifen schneiden. ⏱ 3
3. Karotte 2 Minuten anbraten, Spinat 30 Sekunden blanchieren und ausdrücken. ⏱ 3
4. [Mit Rind] Hack mit Sojasauce 6 Minuten krümelig braten. ⏱ 6
5. Ein Noriblatt mit der glatten Seite nach unten auf eine Bambusmatte legen, Reis dünn darauf verstreichen und unten 3 cm frei lassen.
6. Füllungen in einer Reihe auf das untere Drittel legen, eng aufrollen und mit Wasser verschließen.
7. Rolle mit Sesamöl bestreichen und in 2 cm dicke Scheiben schneiden. Alle Rollen ebenso zubereiten.

## Notizen

Danmuji (gelber Rettich) im Asia-Laden. Mit einem scharfen, feuchten Messer schneiden. Ergibt etwa 4 Rollen.
