# Kimchi-Bokkeumbap

![Kimchi-Bokkeumbap](../../pictures/kimchi-bokkeumbap.jpg)

Gebratener Reis mit Kimchi und Spiegelei, die Resteverwertung der koreanischen Küche.

## Zutaten

| Menge | Zutat          | Gruppe | Variante  | Hinweis               | Einkauf |
| ----- | -------------- | ------ | --------- | --------------------- | ------- |
| 300 g | Jasminreis     |        |           | vom Vortag            | Menge   |
| 200 g | Kimchi         |        |           | gereift, grob gehackt | Menge   |
| 2 EL  | Kimchi         |        |           | Saft, aus dem Glas    |         |
| 80 g  | Speck          |        | Mit Speck | gewürfelt             | Menge   |
| 1     | Zwiebel        |        |           | gewürfelt             |         |
| 1 EL  | Gochujang      |        |           |                       | 1×      |
| 1 EL  | Sojasauce      |        |           |                       |         |
| 2     | Ei             |        |           | Spiegelei             |         |
| 1 EL  | Sesamöl        |        |           |                       |         |
| 1 EL  | Sonnenblumenöl |        |           |                       |         |
| 1     | Lauchzwiebel   |        |           | in Ringen             |         |

## Zubereitung

1. [Mit Speck] Speck in der Pfanne 4 Minuten ausbraten. ⏱ 4
2. Öl zugeben, Zwiebel 3 Minuten braten, Kimchi zugeben und weitere 3 Minuten braten. ⏱ 6
3. Gochujang, Sojasauce und Kimchi-Saft einrühren, Reis zugeben und 5 Minuten unter Wenden braten. ⏱ 5
4. Mit Sesamöl abschmecken und auf Teller geben.
5. Spiegeleier braten und auf den Reis setzen. Mit Lauchzwiebeln bestreuen.

## Notizen

Kimchi bitte ohne Fischsauce kaufen, wenn vegetarisch gekocht wird.
