# Gyeran-Jjim – gedämpfter Eierstich

![Gyeran-Jjim – gedämpfter Eierstich](../../pictures/gyeran-jjim.jpg)

Luftig-gestockter Eierstich im Topf, mild und ein guter Ausgleich zu scharfen Gerichten.

## Zutaten

| Menge   | Zutat        | Gruppe | Variante | Hinweis   | Einkauf |
| ------- | ------------ | ------ | -------- | --------- | ------- |
| 4       | Ei           |        |          |           | Menge   |
| 120 ml  | Wasser       |        |          |           | nie     |
| 1 TL    | Sojasauce    |        |          |           |         |
| 1 TL    | Sesamöl      |        |          |           |         |
| 1       | Lauchzwiebel |        |          | in Ringen |         |
| 1 Prise | Salz         |        |          |           |         |

## Zubereitung

1. Eier verquirlen und mit Wasser, Sojasauce und Salz verrühren, durch ein Sieb gießen.
2. Mischung in einen kleinen Topf geben, bei niedriger Hitze unter Rühren 3 Minuten anstocken lassen. ⏱ 3
3. Deckel auflegen und 6 Minuten ganz sanft garen, bis die Masse aufgeplustert ist. ⏱ 6
4. Mit Sesamöl und Lauchzwiebel bestreuen und sofort servieren.

## Notizen

Die Hitze bleibt niedrig, sonst wird der Eierstich zäh.
