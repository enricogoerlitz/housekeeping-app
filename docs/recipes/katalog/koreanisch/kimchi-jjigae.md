# Kimchi-Jjigae

![Kimchi-Jjigae](../../pictures/kimchi-jjigae.jpg)

Der koreanische Alltagseintopf aus gereiftem Kimchi, Tofu und viel Würze.

## Zutaten

| Menge  | Zutat         | Gruppe | Variante          | Hinweis                          | Einkauf |
| ------ | ------------- | ------ | ----------------- | -------------------------------- | ------- |
| 250 g  | Kimchi        |        |                   | reif, grob geschnitten, mit Saft | Menge   |
| 150 g  | Schweinebauch |        | Mit Schweinebauch | in dünnen Scheiben               | Menge   |
| 200 g  | Tofu          |        |                   | in Scheiben                      | Menge   |
| 150 g  | Champignons   |        | Vegetarisch       | in Scheiben                      | Menge   |
| 1      | Zwiebel       |        |                   | in Streifen                      |         |
| 1 EL   | Gochugaru     |        |                   |                                  | 1×      |
| 1 EL   | Sojasauce     |        |                   |                                  |         |
| 1 TL   | Zucker        |        |                   |                                  |         |
| 2      | Knoblauch     |        |                   | Zehen, gehackt                   |         |
| 1 EL   | Sesamöl       |        |                   |                                  |         |
| 500 ml | Wasser        |        |                   |                                  | nie     |
| 2      | Lauchzwiebel  |        |                   | in Ringen                        |         |
| 250 g  | Jasminreis    |        |                   | zum Servieren                    | Menge   |

## Zubereitung

1. Sesamöl im Topf erhitzen,
2. [Mit Schweinebauch] Schweinebauch 4 Minuten anbraten. ⏱ 4
3. [Vegetarisch] Champignons 5 Minuten anbraten. ⏱ 5
4. Zwiebel, Knoblauch und Kimchi zugeben, 5 Minuten mitbraten. ⏱ 5
5. Gochugaru, Zucker, Sojasauce und Wasser zugeben, aufkochen und 15 Minuten köcheln. ⏱ 15
6. Tofu einlegen und 5 Minuten garen. ⏱ 5
7. Mit Lauchzwiebeln bestreuen und mit Reis servieren.

## Notizen

Je saurer und reifer das Kimchi, desto besser der Eintopf. Gochugaru (Chiliflocken) ersatzweise normale Chiliflocken, dann weniger nehmen. Für wirklich vegetarisch auf Kimchi ohne Fischsauce achten.
