# Bacalhau à Brás

![Bacalhau à Brás](../../pictures/bacalhau-a-bras.jpg)

Rührei mit Kabeljau und Strohkartoffeln, ein portugiesischer Alltagsklassiker. Vegetarisch mit Kichererbsen.

## Zutaten

| Menge  | Zutat           | Gruppe | Variante     | Hinweis                          | Einkauf |
| ------ | --------------- | ------ | ------------ | -------------------------------- | ------- |
| 250 g  | Kabeljaufilet   |        | Mit Kabeljau | gekocht, zerzupft                | Menge   |
| 200 g  | Kichererbsen    |        | Vegetarisch  | Dose, abgetropft                 | Menge   |
| 300 g  | Kartoffel       |        |              | in Streichholzstifte geschnitten | Menge   |
| 1      | Zwiebel         |        |              | in feinen Ringen                 |         |
| 2      | Knoblauch       |        |              | Zehen                            |         |
| 4      | Ei              |        |              |                                  |         |
| 3 EL   | Olivenöl        |        |              |                                  |         |
| 300 ml | Rapsöl          |        |              | zum Frittieren                   |         |
| 40 g   | Schwarze Oliven |        |              |                                  |         |
| 1      | Petersilie      |        |              | Bund, gehackt                    |         |

## Zubereitung

1. Kartoffelstifte in 180 °C heißem Öl 5 Minuten knusprig frittieren, abtropfen. ⏱ 5
2. Zwiebel und Knoblauch in Olivenöl 5 Minuten glasig dünsten. ⏱ 5
3. [Mit Kabeljau] Fisch zugeben und 3 Minuten erwärmen.
4. [Vegetarisch] Kichererbsen zugeben und 4 Minuten braten.
5. Eier verquirlen, mit den Kartoffeln unterheben und bei kleiner Hitze cremig stocken lassen. ⏱ 2
6. Mit Oliven und Petersilie anrichten.

## Notizen

Fertig gewässerter Stockfisch oder Kabeljauloin vom Fischhändler; frischen Kabeljau 5 Minuten in Wasser garen.
