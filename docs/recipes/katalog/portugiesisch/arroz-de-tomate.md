# Arroz de Tomate

![Arroz de Tomate](../../pictures/arroz-de-tomate.jpg)

Portugiesischer Tomatenreis, saftig und aromatisch, ideal zu Fisch und Hähnchen.

## Zutaten

| Menge  | Zutat            | Gruppe | Variante | Hinweis        | Einkauf |
| ------ | ---------------- | ------ | -------- | -------------- | ------- |
| 200 g  | Langkornreis     |        |          |                | Menge   |
| 1      | Zwiebel          |        |          | fein gewürfelt |         |
| 2      | Knoblauch        |        |          | Zehen          |         |
| 400 g  | Stückige Tomaten |        |          |                |         |
| 350 ml | Gemüsebrühe      |        |          |                |         |
| 3 EL   | Olivenöl         |        |          |                |         |
| 1      | Lorbeerblatt     |        |          |                |         |
| 1      | Petersilie       |        |          | Bund           |         |

## Zubereitung

1. Zwiebel und Knoblauch in Öl 4 Minuten glasig dünsten. ⏱ 4
2. Tomaten und Lorbeer zugeben, 5 Minuten einkochen. ⏱ 5
3. Reis einrühren, mit Brühe aufgießen, aufkochen und zugedeckt 12 Minuten bei kleinster Hitze garen. ⏱ 12
4. 5 Minuten quellen lassen, auflockern, mit Petersilie bestreuen.

## Notizen

Mit einem Spiegelei wird daraus eine schnelle Hauptmahlzeit.
