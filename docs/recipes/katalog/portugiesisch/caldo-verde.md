# Caldo Verde

![Caldo Verde](../../pictures/caldo-verde.jpg)

Portugals Nationalsuppe: Kartoffelpüree-Suppe mit hauchdünn geschnittenem Grünkohl.

## Zutaten

| Menge  | Zutat     | Gruppe | Variante     | Hinweis                       | Einkauf |
| ------ | --------- | ------ | ------------ | ----------------------------- | ------- |
| 500 g  | Kartoffel |        |              | mehligkochend, gewürfelt      | Menge   |
| 1      | Zwiebel   |        |              | gewürfelt                     |         |
| 2      | Knoblauch |        |              | Zehen                         |         |
| 200 g  | Grünkohl  |        |              | entstielt, in feinen Streifen | Menge   |
| 800 ml | Wasser    |        |              |                               | nie     |
| 3 EL   | Olivenöl  |        |              |                               |         |
| 100 g  | Chorizo   |        | Mit Chouriço | oder Chorizo, in Scheiben     | Menge   |
| 1 TL   | Salz      |        |              |                               |         |

## Zubereitung

1. Zwiebel und Knoblauch in 1 EL Olivenöl 4 Minuten anschwitzen. ⏱ 4
2. Kartoffeln, Wasser und Salz zugeben, 20 Minuten kochen. ⏱ 20
3. Fein pürieren, Grünkohl zugeben und 5 Minuten köcheln. ⏱ 5
4. [Mit Chouriço] Wurst in einer Pfanne knusprig braten und auf die Suppe legen.
5. Mit Olivenöl beträufeln.

## Notizen

Traditionell mit Couve galega; Grünkohl oder Wirsing sind gute Ersatz.
