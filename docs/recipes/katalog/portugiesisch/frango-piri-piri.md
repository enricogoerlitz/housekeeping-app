# Frango Piri-Piri

![Frango Piri-Piri](../../pictures/frango-piri-piri.jpg)

Portugiesisches Grillhähnchen mit scharfer Marinade aus Chili, Knoblauch und Zitrone. Vegetarisch mit Blumenkohl.

## Zutaten

| Menge | Zutat         | Gruppe   | Variante     | Hinweis                                     | Einkauf |
| ----- | ------------- | -------- | ------------ | ------------------------------------------- | ------- |
| 1     | Hähnchen      |          | Mit Hähnchen | ca. 1,2 kg, Rücken entfernt, flach gedrückt | Menge   |
| 1     | Blumenkohl    |          | Vegetarisch  | in dicke Scheiben                           | Menge   |
| 3     | Chilischoten  | Marinade |              | rot                                         |         |
| 4     | Knoblauch     | Marinade |              | Zehen                                       |         |
| 1     | Zitrone       | Marinade |              | Saft und Abrieb                             |         |
| 4 EL  | Olivenöl      | Marinade |              |                                             |         |
| 2 TL  | Paprikapulver | Marinade |              |                                             |         |
| 1 EL  | Rotweinessig  | Marinade |              |                                             |         |
| 1 TL  | Salz          |          |              |                                             |         |

## Zubereitung

1. Alle Marinadezutaten pürieren,
2. [Mit Hähnchen] Hähnchen damit einreiben und mindestens 2 Stunden marinieren. ⏱ 120
3. [Vegetarisch] Blumenkohlscheiben mit der Marinade bestreichen und 30 Minuten ziehen lassen. ⏱ 30
4. [Mit Hähnchen] Ofen auf 220 °C Ober-/Unterhitze, Hähnchen 50 Minuten braten, bis es goldbraun ist. ⏱ 50
5. [Vegetarisch] Blumenkohl 25 Minuten bei 220 °C backen, einmal wenden. ⏱ 25
6. Mit Zitronenspalten und Pommes servieren.

## Notizen

Chilis nach Schärfegrad reduzieren. Vorlauf: Marinieren, am besten über Nacht.
