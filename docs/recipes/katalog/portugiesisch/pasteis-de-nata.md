# Pastéis de Nata

![Pastéis de Nata](../../pictures/pasteis-de-nata.jpg)

Die berühmten Puddingtörtchen aus Lissabon im Blätterteig. Ergibt 6 Stück.

## Zutaten

| Menge  | Zutat         | Gruppe | Variante | Hinweis            | Einkauf |
| ------ | ------------- | ------ | -------- | ------------------ | ------- |
| 1      | Blätterteig   |        |          | Rolle, frisch      | 1×      |
| 250 ml | Milch         |        |          |                    |         |
| 3      | Eier          |        |          |                    |         |
| 60 g   | Zucker        |        |          |                    |         |
| 25 g   | Speisestärke  |        |          |                    |         |
| 1      | Vanilleschote |        |          | oder Vanillezucker |         |
| 1 TL   | Zimt          |        |          |                    |         |

## Zubereitung

1. Ofen auf 250 °C Ober-/Unterhitze vorheizen. Blätterteig aufrollen, zur Schnecke formen und in 6 Scheiben schneiden.
2. Scheiben in gefettete Muffinförmchen drücken und kühl stellen.
3. Milch, Zucker, Stärke und Vanille unter Rühren erhitzen, bis es dickt, Eigelbe einrühren. ⏱ 5
4. Creme in die Förmchen füllen und 15 bis 18 Minuten backen, bis die Oberfläche dunkle Flecken zeigt. ⏱ 16
5. Mit Zimt bestäuben und lauwarm essen.

## Notizen

Förmchen müssen sehr heiß gebacken werden. Mit einem Espresso servieren.
