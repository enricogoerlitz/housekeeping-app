# Feijoada à Portuguesa

![Feijoada](../../pictures/feijoada-portuguesa.jpg)

Portugiesischer Bohneneintopf mit Tomaten und Paprika. Vegetarisch mit Räuchertofu.

## Zutaten

| Menge | Zutat            | Gruppe | Variante    | Hinweis                   | Einkauf |
| ----- | ---------------- | ------ | ----------- | ------------------------- | ------- |
| 800 g | Kidneybohnen     |        |             | Dosen, abgetropft         | Menge   |
| 200 g | Chorizo          |        | Mit Wurst   | oder Chorizo, in Scheiben | Menge   |
| 200 g | Räuchertofu      |        | Vegetarisch | gewürfelt                 | Menge   |
| 1     | Zwiebel          |        |             | gewürfelt                 |         |
| 2     | Karotte          |        |             | in Scheiben               |         |
| 3     | Knoblauch        |        |             | Zehen                     |         |
| 400 g | Stückige Tomaten |        |             |                           |         |
| 1     | Lorbeerblatt     |        |             |                           |         |
| 1 TL  | Paprikapulver    |        |             |                           |         |
| 200 g | Reis             |        |             | zum Servieren             | Menge   |
| 2 EL  | Olivenöl         |        |             |                           |         |

## Zubereitung

1. [Mit Wurst] Wurst im Öl 5 Minuten anbraten, herausnehmen.
2. [Vegetarisch] Räuchertofu im Öl 6 Minuten knusprig braten, herausnehmen.
3. Zwiebel, Karotte und Knoblauch im Bratfett 6 Minuten anbraten, Paprikapulver zugeben. ⏱ 6
4. Tomaten, Bohnen, Lorbeer und 200 ml Wasser zugeben, 35 Minuten köcheln. ⏱ 35
5. Wurst bzw. Tofu zurückgeben und 10 Minuten ziehen lassen. ⏱ 10
6. Reis nach Packungsangabe kochen und zum Eintopf reichen.

## Notizen

Mit frisch gekochten Bohnen (aus 300 g trockenen) noch besser, dann 1 Stunde länger.
