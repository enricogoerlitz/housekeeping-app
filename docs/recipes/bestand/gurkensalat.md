# Gurkensalat

![Gurkensalat](../pictures/gurkensalat.jpg)

Hauchdünn gehobelte Salatgurke in einem leichten Joghurt-Dill-Dressing. Passt zu Fleisch vom Grill, Kartoffeln und Fisch.

## Zutaten

| Menge    | Zutat         | Gruppe   | Variante | Hinweis             | Einkauf |
| -------- | ------------- | -------- | -------- | ------------------- | ------- |
| 1        | Salatgurke    |          |          |                     |         |
| 150 g    | Joghurt       | Dressing |          | Natur, 3,5 %        |         |
| 1 EL     | Weißweinessig | Dressing |          |                     |         |
| 1 TL     | Zucker        | Dressing |          |                     |         |
| 1 EL     | Olivenöl      | Dressing |          |                     |         |
| 0,5 Bund | Dill          | Dressing |          | gehackt             |         |
| 1        | Knoblauch     | Dressing |          | Zehe, fein gerieben |         |
| 1 TL     | Salz          |          |          |                     |         |
|          | Pfeffer       |          |          |                     |         |

## Zubereitung

1. Gurke waschen und mit dem Gurkenhobel in dünne Scheiben hobeln.
2. Mit dem Salz mischen und 10 Minuten Wasser ziehen lassen, dann kräftig ausdrücken. ⏱ 10
3. Joghurt, Essig, Zucker, Öl, Knoblauch und Dill verrühren.
4. Gurke unterheben, mit Pfeffer abschmecken und sofort servieren.

## Notizen

Für die klassische Variante mit Essig-Öl statt Joghurt das Dressing mit je 2 EL Essig und Öl, 1 TL Zucker anrühren.
