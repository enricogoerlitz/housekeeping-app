# Hummus

![Hummus](../pictures/hummus.jpg)

Cremiger Hummus aus Kichererbsen und Tahini mit Zitrone und Knoblauch.

## Zutaten

| Menge   | Zutat         | Gruppe | Variante | Hinweis              | Einkauf |
| ------- | ------------- | ------ | -------- | -------------------- | ------- |
| 1 Dose  | Kichererbsen  |        |          | 240 g Abtropfgewicht | 1×      |
| 3 EL    | Tahini        |        |          |                      | 1×      |
| 1       | Zitrone       |        |          | Saft                 | 1×      |
| 1       | Knoblauch     |        |          | Zehe                 | 1×      |
| 3 EL    | Olivenöl      |        |          |                      |         |
| 3 EL    | Wasser        |        |          | eiskalt              | nie     |
| 1 TL    | Kreuzkümmel   |        |          |                      |         |
| 1 Prise | Paprikapulver |        |          | zum Bestäuben        |         |
|         | Salz          |        |          |                      |         |

## Zubereitung

1. Kichererbsen abgießen und abspülen. Kichererbsenwasser aufheben.
2. Tahini mit Zitronensaft, Knoblauch und Salz 1 Minute cremig mixen.
3. Kichererbsen, Kreuzkümmel und Olivenöl zugeben und 3 Minuten pürieren, bis die Masse glatt ist.
4. Nach und nach eiskaltes Wasser oder Kichererbsenwasser zugeben, bis die Konsistenz cremig ist.
5. In eine Schale streichen, mit Olivenöl und Paprika toppen.

## Notizen

Dazu Naan-Brot oder Gemüsesticks. Tahini gibt es im Supermarkt bei den Asia- oder Bioartikeln. Gang als Beilage gesetzt.
