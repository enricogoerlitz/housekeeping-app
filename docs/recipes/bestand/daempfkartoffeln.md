# Dämpfkartoffeln

![Dämpfkartoffeln](../pictures/daempfkartoffeln.jpg)

Kleine Kartoffeln garen im geschlossenen Topf in wenig Wasser und Fett, bis sie weich und außen goldbraun sind. Eine einfache Beilage zu Fleisch, Fisch und Quark.

## Zutaten

| Menge  | Zutat         | Gruppe | Variante | Hinweis                                    | Einkauf |
| ------ | ------------- | ------ | -------- | ------------------------------------------ | ------- |
| 600 g  | Kartoffeln    |        |          | festkochend, klein, gewaschen und halbiert |         |
| 2 EL   | Butterschmalz |        |          | oder Öl                                    |         |
| 100 ml | Wasser        |        |          |                                            | nie     |
| 1 TL   | Salz          |        |          |                                            |         |
| 1 TL   | Kümmel        |        |          | ganz, optional                             |         |
| 1 Bund | Schnittlauch  |        |          | in Röllchen                                |         |

## Zubereitung

1. Butterschmalz in einem Topf mit Deckel erhitzen und die Kartoffeln mit der Schnittfläche nach unten 5 Minuten anbraten, bis sie goldbraun sind. ⏱ 5
2. Salz und Kümmel zugeben, Wasser angießen und sofort den Deckel schließen.
3. Bei kleiner Hitze 20 bis 25 Minuten dämpfen, bis die Kartoffeln weich sind und das Wasser verdampft ist. ⏱ 22
4. Deckel abnehmen und 3 Minuten bei hoher Hitze Farbe nehmen lassen. ⏱ 3
5. Mit Schnittlauch bestreut servieren.

## Notizen

OFFEN: Der Titel ist ohne Zusatz überliefert, es wurde das klassische Dämpfen im Topf gewählt (nicht Dampfgarer). Mit Quark und Leinöl wird es ein vegetarisches Hauptgericht.
