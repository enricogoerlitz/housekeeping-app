# Hähnchen mit Kichererbsenreis und Salat

![Hähnchen mit Kichererbsenreis und Salat](../pictures/haehnchen-mit-kichererbsenreis-und-salat.jpg)

Gewürztes Hähnchen mit Kräuter-Kichererbsenreis, Oliven und Feta – eine ausgewogene Bowl mit Protein, Kohlenhydraten und gesunden Fetten.

## Zutaten

| Menge  | Zutat           | Gruppe   | Variante     | Hinweis               | Einkauf |
| ------ | --------------- | -------- | ------------ | --------------------- | ------- |
| 300 g  | Hähnchenbrust   | Hähnchen | Mit Hähnchen | in Streifen oder ganz | Menge   |
| 200 g  | Halloumi        | Hähnchen | Vegetarisch  | in Scheiben           | Menge   |
| 1 TL   | Paprikapulver   | Hähnchen |              |                       |         |
| 1 TL   | Knoblauchpulver | Hähnchen |              |                       |         |
| 1 EL   | Olivenöl        | Hähnchen |              |                       |         |
| 150 g  | Basmatireis     | Reis     |              |                       | Menge   |
| 1 Dose | Kichererbsen    | Reis     |              | abgetropft (240 g)    | 1×      |
| 1 Bund | Petersilie      | Reis     |              | fein gehackt          |         |
| 1      | Zitronen        | Reis     |              | Saft                  |         |
| 1 EL   | Olivenöl        | Reis     |              |                       |         |
| 100 g  | Oliven          | Beilage  |              | grün und schwarz      |         |
| 100 g  | Feta            | Beilage  |              | gewürfelt             |         |
| 1      | Rote Zwiebeln   | Beilage  |              | in feinen Ringen      |         |
| 1 TL   | Salz            |          |              |                       |         |
| 300 ml | Wasser          |          |              | für den Reis          | nie     |

## Zubereitung

1. Reis in Wasser mit Salz nach Packungsangabe garen und kurz quellen lassen. ⏱ 12
2. [Mit Hähnchen] Hähnchenbrust mit Paprikapulver, Knoblauchpulver und Salz würzen und in Olivenöl bei mittlerer Hitze 5 bis 6 Minuten je Seite goldbraun braten; 5 Minuten ruhen lassen, aufschneiden. ⏱ 12
3. [Vegetarisch] Halloumischeiben in Olivenöl je Seite 2 Minuten goldbraun braten.
4. Kichererbsen mit Petersilie, Zitronensaft und Olivenöl zum warmen Reis geben und vermengen.
5. Reis in Schalen füllen, Hähnchen beziehungsweise Halloumi, Oliven, Feta und Rote Zwiebelringe daneben anrichten.
