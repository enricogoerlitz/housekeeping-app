# Hackbällchen in Sahnesauce mit Reis

![Hackbällchen in Sahnesauce mit Reis](../pictures/hackbaellchen-in-sahnesauce-mit-reis.jpg)

Zarte Hackbällchen in einer cremigen, leicht paprikawürzigen Sahnesauce, dazu locker gekochter Reis. Die vegetarische Variante verwendet Veggie-Hack.

## Zutaten

| Menge  | Zutat                  | Gruppe       | Variante        | Hinweis           | Einkauf |
| ------ | ---------------------- | ------------ | --------------- | ----------------- | ------- |
| 400 g  | Gemischtes Hackfleisch | Hackbällchen | Mit Hackfleisch |                   | Menge   |
| 300 g  | Veggie-Hack            | Hackbällchen | Vegetarisch     |                   | Menge   |
| 1      | Ei                     | Hackbällchen |                 |                   | Menge   |
| 3 EL   | Paniermehl             | Hackbällchen |                 |                   | Menge   |
| 1      | Zwiebel                | Hackbällchen |                 | fein gewürfelt    | Menge   |
| 1 TL   | Paprikapulver          | Hackbällchen |                 | edelsüß           | 1×      |
| 1 EL   | Petersilie             | Hackbällchen |                 | gehackt           | 1×      |

## Zubereitung

1. Alle Zutaten der Hackbällchen vermengen, würzen und 12 Bällchen formen.
2. Butter in einer tiefen Pfanne erhitzen und die Bällchen rundum 6 Minuten goldbraun anbraten. Herausnehmen. ⏱ 6
3. Reis nach Packungsangabe in Salzwasser garen, etwa 12 Minuten. ⏱ 12
4. In der Pfanne Zwiebel 3 Minuten glasig dünsten, Tomatenmark und Mehl kurz mitrösten. ⏱ 3
5. Mit Brühe und Sahne ablöschen und unter Rühren 4 Minuten einkochen lassen. Mit Salz und Pfeffer abschmecken. ⏱ 4
6. Bällchen in der Sauce 8 Minuten bei niedriger Hitze ziehen lassen. ⏱ 8
7. Reis zu einem Hügel formen, Bällchen mit Sauce daneben anrichten und mit Petersilie bestreuen.

## Notizen

Der Reis lässt sich in einer kleinen Schüssel andrücken und auf den Teller stürzen. Mit Petersilie bestreuen.
