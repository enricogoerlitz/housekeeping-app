# Blumenkohl Curry

![Blumenkohl Curry](../pictures/blumenkohl-curry.jpg)

Cremiges Blumenkohl-Curry mit Erbsen und Kokosmilch, dazu Basmatireis. Ein schnelles Feierabendgericht.

## Zutaten

| Menge   | Zutat            | Gruppe | Variante     | Hinweis                  | Einkauf |
| ------- | ---------------- | ------ | ------------ | ------------------------ | ------- |
| 1       | Blumenkohl       |        |              | in kleinen Röschen       | Menge   |
| 1       | Zwiebel          |        |              | gewürfelt                | Menge   |
| 2       | Knoblauch        |        |              | Zehen, gehackt           | Menge   |
| 1 Stück | Ingwer           |        |              | daumengroß, gerieben     | Menge   |
| 2 EL    | Currypulver      |        |              | mild                     | 1×      |
| 1 TL    | Kurkuma          |        |              |                          |         |
| 1 Dose  | Kokosmilch       |        |              | 400 ml                   | 1×      |
| 150 g   | Erbsen           |        |              | TK                       | Menge   |
| 150 g   | Basmatireis      |        |              |                          |         |
| 200 ml  | Wasser           |        |              |                          | nie     |

| 1       | Frühlingszwiebel |        |              | in Ringen, zum Garnieren | 1×      |
|         | Salz             |        |              |                          |         |

## Zubereitung

1. Reis nach Packungsangabe kochen. ⏱ 12
2. [Mit Hähnchen] Hähnchenstreifen in Öl 5 Minuten anbraten und beiseitestellen. ⏱ 5
3. Zwiebel in Öl 3 Minuten glasig dünsten, Knoblauch und Ingwer kurz mitbraten. ⏱ 3
4. Currypulver und Kurkuma 30 Sekunden anrösten, Kokosmilch und Wasser angießen.
5. Blumenkohl zugeben und zugedeckt 12 Minuten weich köcheln. ⏱ 12
6. Erbsen (und das Hähnchen) zugeben, 3 Minuten ziehen lassen, mit Salz abschmecken. ⏱ 3
7. Mit Reis anrichten und mit Frühlingszwiebel bestreuen.
