# Pizzateig (Basis, 24h)

![Pizzateig (Basis, 24h)](../pictures/pizzateig-basis-24h.jpg)

Grundteig für Pizza mit wenig Hefe und langer Gare: 24 Stunden Ruhe geben dem Teig Aroma, Luftigkeit und eine knusprige Kruste. Reicht für 2 Pizzen. Dient als Teig für Pizza und Piccolinis.

## Zutaten

| Menge  | Zutat  | Gruppe | Variante | Hinweis                            | Einkauf |
| ------ | ------ | ------ | -------- | ---------------------------------- | ------- |
| 400 g  | Mehl   |        |          | Type 00 oder 550                   | 1×      |
| 280 ml | Wasser |        |          | kalt, 70 % Hydration               | nie     |
| 3 g    | Hefe   |        |          | frisch, ca. ein erbsengroßes Stück | Menge   |
| 10 g   | Salz   |        |          |                                    | 1×      |

## Zubereitung

1. Hefe in dem Wasser auflösen.
2. Mehl und Salz in einer Schüssel mischen, Hefewasser zugeben und alles 8 Minuten zu einem glatten, elastischen Teig kneten.
3. Teig abgedeckt 1 Stunde bei Raumtemperatur ruhen lassen. ⏱ 60
4. In zwei Kugeln teilen, in verschlossene, geölte Boxen legen und 24 Stunden im Kühlschrank gehen lassen.
5. 1 Stunde vor dem Backen aus dem Kühlschrank nehmen. ⏱ 60
6. Backofen mit Blech auf 250 °C vorheizen, Teig mit den Händen zu einem Kreis ziehen, belegen und 8 bis 10 Minuten backen.

## Notizen

Für den Einkauf bleibt Wasser außen vor. Wegen der Hefemenge von 3 g am besten ein Stück vom Würfel abschneiden und den Rest für den nächsten Teig einfrieren.
