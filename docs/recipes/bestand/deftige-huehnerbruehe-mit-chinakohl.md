# Deftige Hühnerbrühe mit Chinakohl

![Deftige Hühnerbrühe mit Chinakohl](../pictures/deftige-huehnerbruehe-mit-chinakohl.jpg)

Kräftige Hühnerbrühe mit zartem Hähnchenfleisch und weich geschmortem Chinakohl.

## Zutaten

| Menge   | Zutat        | Gruppe | Variante    | Hinweis                         | Einkauf |
| ------- | ------------ | ------ | ----------- | ------------------------------- | ------- |
| 1       | Suppenhuhn   |        |             | ca. 1,2 kg, oder Hähnchenkeulen | Menge   |
| 1       | Chinakohl    |        |             | in breiten Streifen             | Menge   |
| 2       | Karotte      |        |             | in Scheiben                     | Menge   |
| 1       | Zwiebel      |        |             | halbiert                        | Menge   |
| 1 Stück | Ingwer       |        |             | in Scheiben                     | Menge   |
| 1 EL    | Sojasauce    |        |             |                                 |         |
| 1,5 l   | Wasser       |        |             |                                 | nie     |
| 1       | Lorbeerblatt |        |             |                                 |         |
|         | Salz         |        |             |                                 |         |
|         | Pfeffer      |        |             |                                 |         |
| 200 g   | Räuchertofu  |        | Vegetarisch | gewürfelt                       | Menge   |
| 1 EL    | Gemüsebrühe  |        | Vegetarisch |                                 | 1×      |

## Zubereitung

1. [Mit Hähnchen] Huhn mit Zwiebel, Ingwer, Lorbeer und Wasser aufkochen, abschäumen und 90 Minuten leise köcheln lassen. ⏱ 90
2. [Vegetarisch] Zwiebel, Ingwer, Karotten, Brühepulver und Wasser 25 Minuten kochen. ⏱ 25
3. [Mit Hähnchen] Huhn herausnehmen, Fleisch von den Knochen lösen und zerpflücken.
4. Karotten in die Brühe geben und 10 Minuten garen. ⏱ 10
5. Chinakohl zugeben und weitere 10 Minuten weich kochen. ⏱ 10
6. [Mit Hähnchen] Fleisch zurück in die Suppe geben.
7. [Vegetarisch] Räuchertofu zurück in die Suppe geben.
8. Mit Sojasauce, Salz und Pfeffer abschmecken.

## Notizen

Suppenhuhn ist im Supermarkt nicht immer da; Hähnchenkeulen (4 Stück) gehen auch und garen kürzer (60 Minuten).
