# Süßkartoffel Wrap

![Süßkartoffel Wrap](../pictures/suesskartoffel-wrap.jpg)

Wrap aus geraspelter Süßkartoffel, knusprig gebacken und mit Avocadocreme, Tomate und Basilikum gefüllt.

## Zutaten

| Menge | Zutat         | Gruppe  | Variante | Hinweis        | Einkauf |
| ----- | ------------- | ------- | -------- | -------------- | ------- |
| 350 g | Süßkartoffeln | Wrap    |          | fein geraspelt | Menge   |
| 2     | Eier          | Wrap    |          |                |         |
| 2 EL  | Speisestärke  | Wrap    |          |                |         |
| 1 TL  | Paprikapulver | Wrap    |          |                |         |
| 1 TL  | Salz          | Wrap    |          |                |         |
| 2     | Avocado       | Füllung |          |                |         |
| 1 EL  | Limetten      | Füllung |          | Saft           |         |
| 4     | Kirschtomaten | Füllung |          | in Scheiben    |         |
| 1     | Basilikum     | Füllung |          | Topf, Blätter  |         |
| 60 g  | Mozzarella    | Füllung |          | in Scheiben    |         |

## Zubereitung

1. Ofen auf 200 °C Umluft vorheizen, ein Blech mit Backpapier auslegen.
2. Süßkartoffel mit Eiern, Stärke, Paprikapulver und Salz zu einer Masse verrühren.
3. Masse in zwei dünnen, ovalen Fladen auf dem Blech verstreichen.
4. Wraps 15 Minuten backen, wenden und weitere 8 Minuten knusprig backen. ⏱ 23
5. Avocado mit Limettensaft und Salz zerdrücken.
6. Wraps mit Avocadocreme, Tomaten, Mozzarella und Basilikum füllen und zusammenklappen.
