# Spargel Guanciale Pasta

![Spargel Guanciale Pasta](../pictures/spargel-guanciale-pasta.jpg)

Breite Pasta mit grünem Spargel, knusprigem Guanciale, Pecorino und Schnittlauch in einer glänzenden Sauce aus Nudelwasser und Käse.

## Zutaten

| Menge  | Zutat        | Gruppe | Variante      | Hinweis                             | Einkauf |
| ------ | ------------ | ------ | ------------- | ----------------------------------- | ------- |
| 250 g  | Calamarata   |        |               | oder Paccheri, Rigatoni             |         |
| 400 g  | Spargel      |        |               | grün, in 2 cm Stücke, Köpfe separat |         |
| 100 g  | Guanciale    |        | Mit Guanciale | in Streifen, ersatzweise Speck      | Menge   |
| 3 EL   | Olivenöl     |        | Vegetarisch   | zusätzlich zum Anbraten             |         |
| 1      | Schalotte    |        |               | fein gewürfelt                      |         |
| 40 g   | Pecorino     |        |               | frisch gerieben                     |         |
| 1      | Zitrone      |        |               | Abrieb                              |         |
| 1 Bund | Schnittlauch |        |               | in Röllchen                         |         |
|        | Salz         |        |               |                                     |         |
|        | Pfeffer      |        |               |                                     |         |

## Zubereitung

1. Nudeln in kräftig gesalzenem Wasser 2 Minuten kürzer als angegeben kochen, 150 ml Nudelwasser aufheben. ⏱ 10
2. [Mit Guanciale] Guanciale ohne Fett in der kalten Pfanne langsam erhitzen und 6 Minuten knusprig auslassen. Herausnehmen. ⏱ 6
3. Spargelstücke und Schalotte im Fett bzw. in 3 EL Olivenöl 5 Minuten anbraten, Köpfe in den letzten 2 Minuten zugeben. ⏱ 5
4. Nudeln mit 100 ml Nudelwasser zugeben und 2 Minuten schwenken, bis eine Sauce entsteht.
5. Pfanne vom Herd, Pecorino, Zitronenabrieb und Pfeffer untermengen, nach Bedarf mehr Nudelwasser zugeben.
6. Guanciale darüberstreuen und mit Schnittlauch servieren.

## Notizen

Guanciale gibt es beim Italiener oder an der Feinkosttheke, Pancetta oder Speckwürfel gehen auch.
