# Bananenbrot

![Bananenbrot](../pictures/bananenbrot.jpg)

Saftiges Bananenbrot aus sehr reifen Bananen: außen leicht knusprig, innen weich und süß. Hält sich mehrere Tage und schmeckt mit Butter bestrichen.

## Zutaten

| Menge   | Zutat          | Gruppe | Variante | Hinweis                  | Einkauf |
| ------- | -------------- | ------ | -------- | ------------------------ | ------- |
| 3       | Bananen        |        |          | sehr reif, braune Schale | 1×      |
| 2       | Eier           |        |          |                          | Menge   |
| 90 g    | Brauner Zucker |        |          |                          | Menge   |
| 80 g    | Butter         |        |          | geschmolzen              | Menge   |
| 200 g   | Mehl           |        |          |                          | Menge   |
| 1 TL    | Backpulver     |        |          |                          | 1×      |
| 1/2 TL  | Zimt           |        |          |                          | 1×      |
| 1 Prise | Salz           |        |          |                          | 1×      |
| 50 g    | Walnüsse       |        |          | grob gehackt, optional   | Menge   |

## Zubereitung

1. Backofen auf 175 °C Ober-/Unterhitze vorheizen. Kastenform (ca. 22 cm) einfetten oder mit Backpapier auslegen.
2. Bananen in einer großen Schüssel mit der Gabel fein zerdrücken.
3. Eier, Zucker und geschmolzene Butter zu den Bananen geben und glatt verrühren.
4. Mehl, Backpulver, Zimt und Salz mischen, zur Bananenmasse sieben und nur kurz unterrühren. Walnüsse unterheben.
5. Teig in die Form füllen und glattstreichen. Im Ofen ca. 50 Minuten backen; die Stäbchenprobe muss sauber bleiben. ⏱ 50
6. 10 Minuten in der Form ruhen lassen, dann auf einem Gitter auskühlen lassen.

## Notizen

Wird die Oberfläche zu dunkel, nach 30 Minuten locker mit Alufolie abdecken. Ohne Walnüsse genauso gut, mit Schokotropfen als Variante.
