# Hackfleisch mit Reis

![Hackfleisch mit Reis](../pictures/hackfleisch-mit-reis.jpg)

Reis und Hackfleisch garen zusammen im Topf in einer Sojasauce und werden dabei klebrig-saftig. Mit Frühlingszwiebeln und schwarzem Sesam bestreut, wie auf dem Foto.

## Zutaten

| Menge  | Zutat            | Gruppe | Variante        | Hinweis                   | Einkauf |
| ------ | ---------------- | ------ | --------------- | ------------------------- | ------- |
| 200 g  | Jasminreis       |        |                 | gewaschen                 |         |
| 250 g  | Hackfleisch      |        | Mit Hackfleisch | gemischt oder Rind        | Menge   |
| 250 g  | Veggie-Hack      |        | Vegetarisch     | oder gehackte Champignons | Menge   |
| 1      | Zwiebel          |        |                 | fein gewürfelt            |         |
| 2      | Knoblauch        |        |                 | Zehen, gehackt            |         |
| 2 EL   | Sojasauce        | Sauce  |                 |                           |         |
| 1 EL   | Austernsauce     | Sauce  | Mit Hackfleisch |                           |         |
| 1 EL   | Hoisinsauce      | Sauce  | Vegetarisch     |                           |         |
| 1 TL   | Sesamöl          | Sauce  |                 |                           |         |
| 1 TL   | Zucker           | Sauce  |                 |                           |         |
| 350 ml | Wasser           |        |                 |                           | nie     |
| 1 EL   | Sonnenblumenöl   |        |                 |                           |         |
| 2      | Frühlingszwiebel |        |                 | in Ringe                  |         |
| 1 EL   | Sesam            |        |                 | schwarz                   |         |

## Zubereitung

1. Reis in einem Sieb unter kaltem Wasser waschen, bis das Wasser klar ist.
2. Öl in einem Topf erhitzen, Hackfleisch bzw. Soja-Hack 5 Minuten krümelig anbraten. ⏱ 5
3. Zwiebel und Knoblauch zugeben und 2 Minuten mitbraten.
4. Sojasauce, Austern- bzw. Hoisinsauce, Sesamöl, Zucker und Wasser verrühren und mit dem Reis in den Topf geben.
5. Aufkochen, Deckel schließen und 12 Minuten bei kleinster Hitze garen. ⏱ 12
6. 5 Minuten ohne Deckel nachquellen lassen, mit einer Gabel auflockern.
7. Mit Frühlingszwiebeln und Sesam bestreuen.

## Notizen

Der Reis sollte beim Garen nicht gerührt werden. Etwas Chiliöl dazu macht das Gericht scharf.
