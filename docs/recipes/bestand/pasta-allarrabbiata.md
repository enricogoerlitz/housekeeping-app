# Pasta all’arrabbiata

![Pasta all’arrabbiata](../pictures/pasta-allarrabbiata.jpg)

Spaghetti mit scharfer Tomatensauce aus Tomaten, Knoblauch, Chili und Paprika. Das Gericht ist von sich aus vegetarisch, sogar vegan.

## Zutaten

| Menge      | Zutat            | Gruppe | Variante | Hinweis                 | Einkauf |
| ---------- | ---------------- | ------ | -------- | ----------------------- | ------- |
| 250 g      | Nudeln           |        |          | Spaghetti, nach Wahl    | 1×      |
| 1          | Paprika          | Soße   |          | rot, fein gehackt       | 1×      |
| 400 g      | Gehackte Tomaten | Soße   |          | Dose, z. B. Mutti       | 1×      |
| 2          | Chilischoten     | Soße   |          | frisch, fein gehackt    | 1×      |
| 3          | Knoblauch        |        |          | Zehen, in Scheiben      | 1×      |
| 3 EL       | Olivenöl         | Soße   |          |                         |         |
| 1 TL       | Salz             | Soße   |          |                         |         |
| 1 Prise    | Zucker           | Soße   |          |                         |         |
| 1 Handvoll | Basilikum        |        |          |                         |         |
| 30 g       | Pecorino         |        |          | zum Bestreuen, optional |         |

## Zubereitung

1. Nudeln in reichlich Salzwasser bissfest kochen, 100 ml Nudelwasser aufheben. ⏱ 10
2. Olivenöl bei mittlerer Hitze erwärmen, Knoblauch und Chili 1 Minute anbraten, ohne dass der Knoblauch bräunt.
3. Paprika zugeben und 3 Minuten mitbraten.
4. Gehackte Tomaten, Salz und Zucker zugeben und 12 Minuten einkochen lassen. ⏱ 12
5. Nudeln in der Sauce mit einem Schuss Nudelwasser schwenken.
6. Mit Basilikum und, falls gewünscht, Pecorino servieren.

## Notizen

Marke der Tomaten laut Bestand: Mutti. Die Schärfe über die Menge der Chilischoten steuern. Pecorino weglassen für vegan.
