# Griechische Hähnchen-Ofenplatte

![Griechische Hähnchen-Ofenplatte](../pictures/griechische-haehnchen-ofenplatte.jpg)

Hähnchenkeulen mit Kartoffelspalten, Zitrone, Oregano und Olivenöl aus dem Ofen.

## Zutaten

| Menge  | Zutat         | Gruppe | Variante     | Hinweis                                          | Einkauf |
| ------ | ------------- | ------ | ------------ | ------------------------------------------------ | ------- |
| 2      | Hähnchenkeule |        | Mit Hähnchen | ganz                                             | Menge   |
| 800 g  | Kartoffeln    |        |              | festkochend, in Spalten                          | Menge   |
| 2      | Zitrone       |        |              | Saft und Abrieb von einer, die andere in Spalten | Menge   |
| 4 EL   | Olivenöl      |        |              |                                                  |         |
| 1 EL   | Oregano       |        |              | getrocknet                                       |         |
| 3      | Knoblauch     |        |              | Zehen, zerdrückt                                 | Menge   |
| 150 ml | Hühnerbrühe   |        | Mit Hähnchen |                                                  | Menge   |
| 150 ml | Gemüsebrühe   |        | Vegetarisch  |                                                  | Menge   |
| 200 g  | Halloumi      |        | Vegetarisch  | in Scheiben, später zugeben                      | Menge   |
| 1 TL   | Paprikapulver |        |              |                                                  |         |
|        | Salz          |        |              |                                                  |         |
|        | Pfeffer       |        |              |                                                  |         |

## Zubereitung

1. Ofen auf 200 °C Ober-/Unterhitze vorheizen.
2. Kartoffeln, Knoblauch, Olivenöl, Zitronensaft, Oregano, Paprika, Salz und Pfeffer in einer großen Form mischen.
3. [Mit Hähnchen] Keulen würzen, auf die Kartoffeln setzen, Brühe angießen.
4. [Vegetarisch] Nur Brühe angießen.
5. [Mit Hähnchen] 70 Minuten backen, nach der Hälfte wenden und mit Saft begießen. ⏱ 70
6. [Vegetarisch] 40 Minuten backen, dann Halloumi dazulegen und weitere 15 Minuten backen. ⏱ 55
7. Mit Zitronenspalten servieren.
