# Shakshuka

![Shakshuka](../pictures/shakshuka.jpg)

Eier, die in einer würzigen Sauce aus Tomaten, Paprika und Kreuzkümmel pochiert werden. Mit Fladenbrot direkt aus der Pfanne zu essen.

## Zutaten

| Menge    | Zutat         | Gruppe | Variante    | Hinweis        | Einkauf |
| -------- | ------------- | ------ | ----------- | -------------- | ------- |
| 1        | Zwiebel       |        |             | gewürfelt      | Menge   |
| 2        | Paprika       |        |             | rot, gewürfelt | Menge   |
| 3        | Knoblauch     |        |             | Zehen, gehackt | Menge   |
| 1 EL     | Tomatenmark   |        |             |                | 1×      |

## Zubereitung

1. Olivenöl in einer tiefen Pfanne erhitzen.
2. [Mit Merguez] Merguez 4 Minuten anbraten. ⏱ 4
3. Zwiebel und Paprika 6 Minuten bei mittlerer Hitze anbraten. ⏱ 6
4. Knoblauch, Tomatenmark, Kreuzkümmel, Paprikapulver und Chili 1 Minute mitrösten.
5. Dosentomaten zugeben, salzen und 10 Minuten zu einer dicklichen Sauce einköcheln lassen. ⏱ 10
6. Vier Mulden in die Sauce drücken und die Eier hineinschlagen.
7. Zugedeckt 6 bis 8 Minuten bei niedriger Hitze garen, bis das Eiweiß gestockt ist, das Eigelb aber noch weich. ⏱ 7
8. Mit Feta und Petersilie bestreuen und mit Fladenbrot servieren.
