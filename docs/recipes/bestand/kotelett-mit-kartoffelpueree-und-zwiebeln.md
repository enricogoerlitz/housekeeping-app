# Kotelett mit Kartoffelpüree und Zwiebeln

![Kotelett mit Kartoffelpüree und Zwiebeln](../pictures/kotelett-mit-kartoffelpueree-und-zwiebeln.jpg)

Saftiges Schweinekotelett aus der Pfanne auf cremigem Kartoffelpüree, mit langsam geschmorten Röstzwiebeln. Die vegetarische Variante nutzt dicke Blumenkohlsteaks.

## Zutaten

| Menge   | Zutat            | Gruppe   | Variante     | Hinweis                                 | Einkauf |
| ------- | ---------------- | -------- | ------------ | --------------------------------------- | ------- |
| 2       | Schweinekotelett |          | Mit Kotelett | je ca. 200 g                            | Menge   |
| 1       | Blumenkohl       |          | Vegetarisch  | 2 Steaks à 2 cm aus der Mitte schneiden | Menge   |
| 600 g   | Kartoffeln       | Püree    |              | mehligkochend, geschält, gewürfelt      | Menge   |
| 40 g    | Butter           | Püree    |              |                                         | Menge   |
| 100 ml  | Milch            | Püree    |              | warm                                    | Menge   |
| 1 Prise | Muskat           | Püree    |              |                                         | 1×      |
| 3       | Zwiebeln         | Zwiebeln |              | in Ringen                               | Menge   |
| 1 TL    | Zucker           | Zwiebeln |              |                                         | 1×      |
| 1 EL    | Mehl             | Zwiebeln |              |                                         | 1×      |
| 2 EL    | Butterschmalz    |          |              | zum Braten                              | 1×      |
|         | Salz             |          |              |                                         | 1×      |
|         | Pfeffer          |          |              |                                         | 1×      |

## Zubereitung

1. Kartoffeln in Salzwasser 20 Minuten weich kochen. ⏱ 20
2. Zwiebeln in einer Pfanne in 1 EL Butterschmalz bei mittlerer Hitze 15 Minuten langsam bräunen, mit Zucker bestäuben und karamellisieren. ⏱ 15
3. [Mit Kotelett] Koteletts salzen, pfeffern und in 1 EL Butterschmalz je Seite 4 bis 5 Minuten braten, 3 Minuten ruhen lassen. ⏱ 9
4. [Vegetarisch] Blumenkohlsteaks salzen, pfeffern und je Seite 5 Minuten in Butterschmalz goldbraun braten, abgedeckt 3 Minuten garziehen. ⏱ 13
5. Kartoffeln abgießen, mit Butter, warmer Milch und Muskat fein stampfen und salzen.
6. Püree auf Tellern anrichten, Kotelett oder Steak darauflegen und mit den Zwiebeln krönen.

## Notizen

Die Zwiebeln nicht zu heiß anbraten, sonst bleiben sie bitter. Wer mag, bindet den Bratensatz mit einem Schuss Brühe als Sauce.
