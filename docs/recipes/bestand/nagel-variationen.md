# Nudel Variationen

![Nudel Variationen](../pictures/nagel-variationen.jpg)

Eine Grundnudel mit drei schnellen Saucen zur Auswahl: klassische Tomatensauce, grünes Pesto oder cremige Käse-Sahne.

## Zutaten

| Menge  | Zutat             | Gruppe | Variante     | Hinweis        | Einkauf |
| ------ | ----------------- | ------ | ------------ | -------------- | ------- |
| 250 g  | Spaghetti         |        |              |                | Menge   |
| 400 g  | Passierte Tomaten |        | Tomatensauce |                | Menge   |
| 1      | Zwiebel           |        | Tomatensauce | fein gewürfelt | Menge   |
| 2      | Knoblauch         |        | Tomatensauce | Zehen, gehackt | Menge   |
| 1 TL   | Oregano           |        | Tomatensauce | getrocknet     | 1×      |
| 4 EL   | Pesto             |        | Pesto        |                | Menge   |
| 30 g   | Pinienkerne       |        | Pesto        | geröstet       | Menge   |
| 200 ml | Sahne             |        | Käse-Sahne   |                | Menge   |
| 60 g   | Gouda             |        | Käse-Sahne   | gerieben       | Menge   |
| 40 g   | Parmesan          |        |              | zum Bestreuen  | Menge   |
| 2 EL   | Olivenöl          |        |              |                | 1×      |
|        | Salz              |        |              |                | 1×      |
|        | Pfeffer           |        |              |                | 1×      |

## Zubereitung

1. Spaghetti in reichlich Salzwasser al dente kochen, 1 Tasse Nudelwasser abnehmen und abgießen. ⏱ 10
2. [Tomatensauce] Zwiebel und Knoblauch in Olivenöl 3 Minuten anschwitzen, Tomaten und Oregano zugeben, salzen und 12 Minuten köcheln lassen. ⏱ 12
3. [Pesto] Pinienkerne in einer trockenen Pfanne 3 Minuten rösten. Pesto mit etwas Nudelwasser verrühren, die Nudeln darin schwenken. ⏱ 3
4. [Käse-Sahne] Sahne 3 Minuten einkochen, Gouda darin schmelzen, mit Pfeffer abschmecken. ⏱ 3
5. Nudeln mit der gewählten Sauce vermengen, bei Bedarf mit Nudelwasser lockern.
6. Mit Parmesan bestreuen und servieren.
