# Reis-Bowl aus dem Reiskocher

![Reis-Bowl aus dem Reiskocher](../pictures/reis-bowl-aus-dem-reiskocher.jpg)

Gyudon-Stil: Reis, Zwiebeln und Rindfleisch garen gemeinsam im Reiskocher in einer süßsalzigen Sojasauce und werden mit Frühlingszwiebeln bestreut. Die vegetarische Variante nutzt Tofu und Shiitake.

## Zutaten

| Menge  | Zutat             | Gruppe | Variante        | Hinweis                                                  | Einkauf |
| ------ | ----------------- | ------ | --------------- | -------------------------------------------------------- | ------- |
| 200 g  | Sushireis         |        |                 | oder Jasminreis, gewaschen                               | Menge   |
| 250 g  | Rindfleisch       |        | Mit Rindfleisch | hauchdünn geschnitten, z. B. Gyudon- oder Hotpot-Fleisch | Menge   |
| 200 g  | Tofu              |        | Vegetarisch     | fest, in Würfeln                                         | Menge   |
| 150 g  | Shiitake          |        | Vegetarisch     | in Scheiben                                              | Menge   |
| 1      | Zwiebel           |        |                 | in dünnen Streifen                                       | Menge   |
| 3 EL   | Sojasauce         | Sauce  |                 |                                                          | 1×      |
| 2 EL   | Mirin             | Sauce  |                 | Ersatz: 1 EL Honig und 1 EL Reisessig                    | 1×      |
| 1 TL   | Zucker            | Sauce  |                 |                                                          | 1×      |
| 1 TL   | Ingwer            | Sauce  |                 | frisch gerieben                                          | Menge   |
| 300 ml | Wasser            |        |                 |                                                          | nie     |
| 3      | Frühlingszwiebeln |        |                 | in Ringen                                                | Menge   |

## Zubereitung

1. Reis waschen, bis das Wasser klar ist, und im Reiskocher mit 300 ml Wasser mischen.
2. Sojasauce, Mirin, Zucker und Ingwer verrühren und zum Reis geben.
3. Zwiebel auf den Reis legen.
4. [Mit Rindfleisch] Rindfleisch darauf verteilen, ohne zu rühren.
5. [Vegetarisch] Tofu und Shiitake darauf verteilen, ohne zu rühren.
6. Reiskocher starten (Normalprogramm, ca. 30 Minuten). ⏱ 30
7. Nach dem Garen 10 Minuten zugedeckt ruhen lassen. ⏱ 10
8. Alles vorsichtig mit dem Reis vermengen und mit Frühlingszwiebeln bestreuen.

## Notizen

Ohne Reiskocher: Alles in einem Topf mit Deckel 15 Minuten auf kleiner Flamme garen, dann 10 Minuten quellen lassen. Das Fleisch im Asia-Laden TK kaufen oder halb gefrorenes Rindersteak hauchdünn schneiden.
