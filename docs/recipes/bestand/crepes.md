# Crêpes

![Crêpes](../pictures/crepes.jpg)

Dünne Crêpes, aufgerollt und mit Nuss-Nougat-Creme gefüllt, mit Puderzucker bestäubt.

## Zutaten

| Menge   | Zutat             | Gruppe | Variante | Hinweis       | Einkauf |
| ------- | ----------------- | ------ | -------- | ------------- | ------- |
| 125 g   | Mehl              |        |          |               |         |
| 250 ml  | Milch             |        |          |               |         |
| 2       | Eier              |        |          |               |         |
| 1 EL    | Zucker            |        |          |               |         |
| 1 Prise | Salz              |        |          |               |         |
| 1 EL    | Butter            |        |          | geschmolzen   |         |
| Etwas   | Butter            |        |          | zum Braten    |         |
| 4 EL    | Nuss-Nougat-Creme |        |          | zum Füllen    |         |
|         | Puderzucker       |        |          | zum Bestäuben |         |

## Zubereitung

1. Mehl, Milch, Eier, Zucker, Salz und geschmolzene Butter glatt verrühren und 15 Minuten quellen lassen. ⏱ 15
2. Pfanne mit Butter ausstreichen und bei mittlerer Hitze erhitzen.
3. Eine kleine Kelle Teig dünn in die Pfanne schwenken, 1 bis 2 Minuten backen, wenden und 30 Sekunden fertig backen. ⏱ 2
4. Crêpes mit Nuss-Nougat-Creme bestreichen, aufrollen und mit Puderzucker bestäuben.

## Notizen

Gang bewusst als Dessert gesetzt (stand unter Hauptgericht). Es gibt keine Varianten; Früchte oder Zimtzucker sind Alternativen.
