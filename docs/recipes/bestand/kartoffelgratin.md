# Kartoffelgratin

![Kartoffelgratin](../pictures/kartoffelgratin.jpg)

Dünn gehobelte Kartoffeln in Sahne und Gruyère, goldbraun überbacken. Im Original zu Entrecôte, passt aber auch zu Steak, Braten und Salat.

## Zutaten

| Menge   | Zutat      | Gruppe | Variante | Hinweis                                   | Einkauf |
| ------- | ---------- | ------ | -------- | ----------------------------------------- | ------- |
| 600 g   | Kartoffeln |        |          | festkochend, geschält, 2 mm dünn gehobelt |         |
| 200 ml  | Sahne      |        |          |                                           |         |
| 100 ml  | Milch      |        |          |                                           |         |
| 100 g   | Gruyère    |        |          | frisch gerieben, ersatzweise Bergkäse     |         |
| 1       | Knoblauch  |        |          | Zehe, halbiert zum Ausreiben der Form     |         |
| 20 g    | Butter     |        |          | für die Form                              |         |
| 1 Prise | Muskat     |        |          | frisch gerieben                           |         |
| 1 TL    | Salz       |        |          |                                           |         |
|         | Pfeffer    |        |          |                                           |         |

## Zubereitung

1. Backofen auf 180 °C Ober-/Unterhitze vorheizen. Form mit der Knoblauchzehe ausreiben und mit Butter einfetten.
2. Sahne und Milch mit Salz, Pfeffer, Muskat und der Hälfte des Käses erwärmen, bis der Käse schmilzt.
3. Kartoffelscheiben (nicht waschen) dachziegelartig in die Form schichten, jeweils mit etwas Sahnemischung übergießen.
4. Restlichen Käse darüberstreuen und mit Alufolie abdecken.
5. 45 Minuten backen, Folie abnehmen und weitere 20 Minuten bräunen. ⏱ 65
6. 10 Minuten ruhen lassen, dann servieren.

## Notizen

Die Stärke an den ungewaschenen Kartoffeln bindet die Sauce. Eine Gabel sollte ohne Widerstand einsinken.
