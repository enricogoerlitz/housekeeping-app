# Bandnudeln mit Lachs

![Bandnudeln mit Lachs](../pictures/bandnudeln-mit-lachs.jpg)

Grüne Spinat-Bandnudeln in einer cremigen Sauce mit saftigem Lachs und Kirschtomaten – schnell gemacht und sehr sättigend.

## Zutaten

| Menge  | Zutat         | Gruppe | Variante    | Hinweis                      | Einkauf |
| ------ | ------------- | ------ | ----------- | ---------------------------- | ------- |
| 250 g  | Tagliatelle   |        |             | grüne Spinat-Bandnudeln      | Menge   |
| 250 g  | Lachs         |        | Mit Lachs   | Filet, ohne Haut, in Würfeln | Menge   |
| 250 g  | Champignons   |        | Vegetarisch | in Scheiben                  | Menge   |
| 200 g  | Kirschtomaten |        |             | halbiert                     |         |
| 1      | Zwiebeln      |        |             | fein gewürfelt               |         |
| 2      | Knoblauch     |        |             | Zehen, gehackt               |         |
| 1 EL   | Olivenöl      |        |             |                              |         |
| 200 ml | Sahne         |        |             |                              | 1×      |
| 1 EL   | Frischkäse    |        |             |                              |         |
| 0,5    | Zitronen      |        |             | Saft und etwas Abrieb        |         |
| 1      | Dill          |        |             | Handvoll, gehackt            |         |
| 2 EL   | Parmesan      |        |             | gerieben                     |         |
| 1 TL   | Salz          |        |             |                              |         |
| 0,5 TL | Pfeffer       |        |             |                              |         |
| 2 l    | Wasser        |        |             | fürs Nudelwasser             | nie     |

## Zubereitung

1. Nudelwasser mit reichlich Salz aufkochen und die Bandnudeln nach Packungsangabe bissfest garen. 100 ml Nudelwasser abschöpfen. ⏱ 9
2. Olivenöl in einer großen Pfanne erhitzen, Zwiebel 2 Minuten glasig anbraten, Knoblauch kurz mitbraten.
3. [Mit Lachs] Lachswürfel zugeben und 2 bis 3 Minuten rundum anbraten, dann aus der Pfanne nehmen.
4. [Vegetarisch] Champignons 5 Minuten kräftig anbraten, bis sie Farbe haben.
5. Kirschtomaten zugeben und 2 Minuten mitbraten. Mit Sahne ablöschen, Frischkäse einrühren und 3 Minuten sanft einkochen.
6. Mit Salz, Pfeffer, Zitronensaft und -abrieb abschmecken.
7. Nudeln mit etwas Nudelwasser in die Sauce geben, schwenken, bis die Sauce an den Nudeln haftet.
8. [Mit Lachs] Lachs vorsichtig unterheben und nur noch 1 Minute ziehen lassen.
9. Mit Dill und Parmesan anrichten.

## Notizen

Der Lachs darf nur kurz garen, sonst wird er trocken. Tiefkühllachs vorher gut abtupfen.
Spinat-Tagliatelle gibt es frisch im Kühlregal; normale Bandnudeln gehen auch.
