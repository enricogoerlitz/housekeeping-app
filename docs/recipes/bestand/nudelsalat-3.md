# Nudelsalat

![Nudelsalat](../pictures/nudelsalat-3.jpg)

Frischer Rigatoni-Salat mit Rucola, Kirschtomaten, getrockneten Tomaten, Oliven und Mozzarella in einem Balsamico-Dressing.

## Zutaten

| Menge    | Zutat               | Gruppe   | Variante   | Hinweis                 | Einkauf |
| -------- | ------------------- | -------- | ---------- | ----------------------- | ------- |
| 250 g    | Rigatoni            |          |            |                         | Menge   |
| 50 g     | Rucola              |          |            |                         | Menge   |
| 150 g    | Kirschtomaten       |          |            | halbiert                | Menge   |
| 60 g     | Getrocknete Tomaten |          |            | in Öl, in Streifen      | Menge   |
| 60 g     | Schwarze Oliven     |          |            | entsteint, in Ringen    | Menge   |
| 125 g    | Mozzarella          |          |            | Mini-Kugeln, abgetropft | Menge   |
| 80 g     | Salami              |          | Mit Salami | in Streifen             | Menge   |
| 1/2 Bund | Basilikum           |          |            | gezupft                 | 1×      |
| 4 EL     | Olivenöl            | Dressing |            |                         | 1×      |
| 2 EL     | Balsamico           | Dressing |            |                         | 1×      |
| 1 TL     | Senf                | Dressing |            |                         | 1×      |
| 1 TL     | Honig               | Dressing |            |                         | 1×      |
|          | Salz                |          |            |                         | 1×      |
|          | Pfeffer             |          |            |                         | 1×      |

## Zubereitung

1. Rigatoni in Salzwasser al dente kochen, abgießen, kurz abschrecken und abtropfen lassen. ⏱ 11
2. Olivenöl, Balsamico, Senf, Honig, Salz und Pfeffer zum Dressing verrühren.
3. Noch lauwarme Nudeln mit dem Dressing mischen.
4. Tomaten, getrocknete Tomaten, Oliven, Mozzarella und Basilikum unterheben.
5. [Mit Salami] Salamistreifen untermischen.
6. Rucola erst kurz vor dem Servieren unterheben, 15 Minuten durchziehen lassen.

## Notizen

Die getrockneten Tomaten mit 1 EL Öl aus dem Glas ins Dressing geben. Hält gekühlt 2 Tage.
