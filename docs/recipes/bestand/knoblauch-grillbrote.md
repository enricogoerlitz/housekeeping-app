# Knoblauch Grillbrote

![Knoblauch Grillbrote](../pictures/knoblauch-grillbrote.jpg)

Weiche Fladenbrote mit Knoblauch-Kräuterbutter, schnell im Ofen oder auf dem Grill gebacken – ideal zu Gegrilltem.

## Zutaten

| Menge | Zutat                | Gruppe          | Variante | Hinweis         | Einkauf |
| ----- | -------------------- | --------------- | -------- | --------------- | ------- |
| 300 g | Mehl                 |                 |          |                 |         |
| 150 g | Joghurt              |                 |          |                 |         |
| 1 TL  | Backpulver           |                 |          |                 |         |
| 1 TL  | Salz                 |                 |          |                 |         |
| 2     | Knoblauch            | Knoblauchbutter |          | Zehen, gepresst |         |
| 40 g  | Butter               | Knoblauchbutter |          | zerlassen       |         |
| 1 EL  | Petersilie           | Knoblauchbutter |          | gehackt         |         |
| 1 TL  | Kräuter der Provence | Knoblauchbutter |          |                 |         |

## Zubereitung

1. Mehl, Backpulver und Salz mischen, Joghurt zugeben und zu einem glatten, weichen Teig kneten (5 Minuten). 20 Minuten abgedeckt ruhen lassen. ⏱ 20
2. Teig in 6 Portionen teilen und zu Fladen von etwa 15 cm ausrollen.
3. Butter zerlassen und Knoblauch, Petersilie und Kräuter einrühren.
4. Grillpfanne oder Grill stark erhitzen. Fladen 2 bis 3 Minuten je Seite backen, bis Grillstreifen und Blasen entstehen. ⏱ 6
5. Sofort mit Knoblauchbutter bepinseln und warm servieren.

## Notizen

Ohne Grill: Pfanne oder Backofen bei 250 °C. Joghurt-Teig braucht keine Hefe und gelingt auch spontan.
