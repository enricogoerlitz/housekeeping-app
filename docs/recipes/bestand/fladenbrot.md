# Fladenbrot

![Fladenbrot](../pictures/fladenbrot.jpg)

Luftiges türkisches Fladenbrot mit knuspriger, glänzender Kruste, bestreut mit Sesam und Schwarzkümmel. Innen weich und perfekt zum Dippen.

## Zutaten

| Menge  | Zutat         | Gruppe      | Variante | Hinweis    | Einkauf |
| ------ | ------------- | ----------- | -------- | ---------- | ------- |
| 400 g  | Weizenmehl    |             |          | Type 550   | 1×      |
| 7 g    | Trockenhefe   |             |          | 1 Päckchen | 1×      |
| 1 TL   | Zucker        |             |          |            | 1×      |
| 1,5 TL | Salz          |             |          |            | 1×      |
| 280 ml | Wasser        |             |          | lauwarm    | nie     |
| 2 EL   | Olivenöl      |             |          |            | 1×      |
| 1      | Eier          | Bestreichen |          |            | Menge   |
| 2 EL   | Naturjoghurt  | Bestreichen |          |            | Menge   |
| 2 EL   | Sesam         | Belag       |          |            | 1×      |
| 1 EL   | Schwarzkümmel | Belag       |          |            | 1×      |

## Zubereitung

1. Mehl, Hefe, Zucker und Salz mischen. Wasser und Öl zugeben und 8 Minuten zu einem weichen, glatten Teig kneten. ⏱ 8
2. Teig abgedeckt an einem warmen Ort 60 Minuten gehen lassen, bis er sich verdoppelt hat. ⏱ 60
3. Teig in 3 Stücke teilen, zu Kugeln formen und auf einem bemehlten Backpapier 10 Minuten ruhen lassen.
4. Backofen auf 230 °C Ober-/Unterhitze vorheizen, ein Blech mitheizen.
5. Kugeln zu ovalen Fladen von etwa 1,5 cm Dicke flachdrücken. Mit den Fingern Mulden eindrücken.
6. Eigelb mit Joghurt verrühren, die Fladen damit bestreichen und mit Sesam und Schwarzkümmel bestreuen.
7. Fladen auf das heiße Blech schieben und 12 bis 15 Minuten goldbraun backen. ⏱ 13
8. Kurz abkühlen lassen und warm genießen.

## Notizen

Frisch am besten; am nächsten Tag kurz im Ofen aufbacken. Ohne Schwarzkümmel nur mit Sesam bestreuen.
