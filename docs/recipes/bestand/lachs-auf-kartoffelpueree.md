# Lachs auf Kartoffelpüree

![Lachs auf Kartoffelpüree](../pictures/lachs-auf-kartoffelpueree.jpg)

Glasierter Lachs auf cremigem Kartoffelpüree.

## Zutaten

| Menge | Zutat      | Gruppe | Variante    | Hinweis        | Einkauf |
| ----- | ---------- | ------ | ----------- | -------------- | ------- |
| 2     | Lachsfilet |        | Mit Lachs   | je ca. 150 g   | Menge   |
| 2     | Halloumi   |        | Vegetarisch | dick           | Menge   |
| 3 EL  | Sojasauce  | Glasur |             |                | 1×      |
| 2 EL  | Honig      | Glasur |             |                | 1×      |
| 1     | Knoblauch  | Glasur |             | Zehe, gepresst | 1×      |
| 1 TL  | Sesamöl    | Glasur |             |                |         |
| 600 g | Kartoffeln | Püree  |             | mehligkochend  | Menge   |
| 80 ml | Milch      | Püree  |             | warm           | Menge   |
| 40 g  | Butter     | Püree  |             |                | 1×      |
| 1 EL  | Öl         |        |             | zum Braten     |         |
|       | Salz       |        |             |                |         |

## Zubereitung

1. Kartoffeln in Salzwasser 20 Minuten kochen, ausdampfen lassen und mit Butter und warmer Milch zu cremigem Püree stampfen. ⏱ 20
2. Sojasauce, Honig, Knoblauch und Sesamöl zur Glasur verrühren.
3. [Mit Lachs] Lachs in Öl auf der Hautseite 4 Minuten braten, wenden, Glasur zugeben und 2 Minuten einkochen lassen. ⏱ 6
4. [Vegetarisch] Halloumi 3 Minuten je Seite braten, Glasur zugeben und karamellisieren. ⏱ 6
5. Püree anrichten, Lachs darauflegen und mit restlicher Glasur beträufeln.
