# Erdbeerkuchen

![Erdbeerkuchen](../pictures/erdbeerkuchen.jpg)

Klassischer Obstboden mit Vanillecreme und frischen Erdbeeren unter klarem Tortenguss. Der Boden wird einen Tag vorher oder am selben Tag gebacken und gut gekühlt serviert.

## Zutaten

| Menge      | Zutat                | Gruppe | Variante | Hinweis           | Einkauf |
| ---------- | -------------------- | ------ | -------- | ----------------- | ------- |
| 3          | Eier                 | Boden  |          |                   |         |
| 100 g      | Zucker               | Boden  |          |                   |         |
| 1 Päckchen | Vanillezucker        | Boden  |          |                   |         |
| 100 g      | Weizenmehl           | Boden  |          |                   |         |

## Zubereitung

1. Backofen auf 180 °C Ober-/Unterhitze vorheizen, eine Obstbodenform (26 cm) einfetten.
2. Eier, Zucker, Vanillezucker und Salz 5 Minuten hellschaumig schlagen. Mehl mit Backpulver darübersieben und vorsichtig unterheben.
3. Teig in die Form füllen und 20 Minuten backen. Auf einem Gitter komplett auskühlen lassen. ⏱ 20
4. Pudding aus Pulver, Milch und Zucker nach Packungsangabe kochen, mit Frischhaltefolie auf der Oberfläche abkühlen lassen. ⏱ 5
5. Kalten Pudding glatt rühren, Sahne unterheben und auf dem Boden verstreichen.
6. Erdbeeren dicht auf der Creme anordnen.
7. Tortenguss mit Zucker und Wasser nach Packungsangabe kochen und sofort über die Erdbeeren geben.
8. Mindestens 2 Stunden kühlen, dann anschneiden. ⏱ 120

## Notizen

Der Kuchen schmeckt am besten am selben Tag, damit der Boden nicht durchweicht.
