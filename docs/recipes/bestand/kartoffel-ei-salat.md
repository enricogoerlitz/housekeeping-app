# Kartoffel-Ei-Salat

![Kartoffel-Ei-Salat](../pictures/kartoffel-ei-salat.jpg)

Cremiger Kartoffelsalat mit Ei, Gurke, Radieschen und Dill in einem senfigen Joghurt-Dressing – ohne Mayo, frisch und leicht.

## Zutaten

| Menge  | Zutat      | Gruppe   | Variante | Hinweis            | Einkauf |
| ------ | ---------- | -------- | -------- | ------------------ | ------- |
| 600 g  | Kartoffeln |          |          | festkochend        | Menge   |
| 4      | Eier       |          |          | hart gekocht       |         |
| 0,5    | Gurke      |          |          | in dünnen Scheiben |         |
| 6      | Radieschen |          |          | in dünnen Scheiben |         |
| 1 Bund | Dill       |          |          | gehackt            |         |
| 150 g  | Joghurt    | Dressing |          |                    |         |
| 2 EL   | Senf       | Dressing |          | körnig             |         |
| 2 EL   | Apfelessig | Dressing |          |                    |         |
| 2 EL   | Olivenöl   | Dressing |          |                    |         |
| 1 TL   | Salz       | Dressing |          |                    |         |
| 0,5 TL | Pfeffer    | Dressing |          |                    |         |

## Zubereitung

1. Kartoffeln in Salzwasser 20 Minuten gar kochen, pellen und in Würfel oder Scheiben schneiden. ⏱ 20
2. Eier 9 Minuten hart kochen, abschrecken, pellen und in Spalten schneiden. ⏱ 9
3. Für das Dressing Joghurt, Senf, Essig, Öl, Salz und Pfeffer verrühren.
4. Warme Kartoffeln mit dem Dressing mischen und 10 Minuten durchziehen lassen. ⏱ 10
5. Gurke, Radieschen, Eier und Dill vorsichtig unterheben und abschmecken.

## Notizen

Schmeckt am besten nach 1 Stunde im Kühlschrank. Mit Wasser aus dem Kartoffelkochen lässt sich das Dressing nachverdünnen.
