# Frische Pasta Variationen

![Frische Pasta Variationen](../pictures/frische-pasta-variationen.jpg)

Frische Nudeln aus Semola, Pizzamehl und Eiern mit Champignon-Sahnesauce, wahlweise mit gebratenem Rindersteak.

## Zutaten

| Menge  | Zutat       | Gruppe | Variante           | Hinweis        | Einkauf |
| ------ | ----------- | ------ | ------------------ | -------------- | ------- |
| 150 g  | Semola Mehl | Teig   |                    |                | 1×      |
| 150 g  | Pizzamehl   | Teig   |                    |                | 1×      |
| 3      | Eier        | Teig   |                    |                | 1×      |
| 250 g  | Champignons |        |                    | in Scheiben    | 1×      |
| 200 ml | Kochsahne   |        |                    | nur Veggi      | 1×      |
| 1      | Zwiebel     |        |                    | fein gewürfelt | 1×      |
| 1 EL   | Olivenöl    |        |                    |                |         |
| 1      | Baguette    |        |                    | zum Dippen     | 1×      |
| 300 g  | Rindersteak |        | Sahnesauce-Fleisch | in Streifen    | Menge   |
| 200 ml | Kochsahne   |        | Sahnesauce-Fleisch |                | 1×      |
|        | Salz        |        |                    |                |         |
|        | Pfeffer     |        |                    |                |         |

## Zubereitung

1. Semola, Pizzamehl und Eier zu einem festen Teig kneten (8 Minuten), in Folie 30 Minuten ruhen lassen. ⏱ 30
2. Teig dünn ausrollen, zu Tagliatelle schneiden und leicht bemehlen.
3. Zwiebel und Champignons in Olivenöl 6 Minuten kräftig anbraten. ⏱ 6
4. [Sahnesauce-Fleisch] Steakstreifen separat 2 Minuten je Seite scharf braten, salzen und pfeffern. ⏱ 4
5. Kochsahne zu den Pilzen geben, 5 Minuten einkochen, würzen. ⏱ 5
6. Nudeln in Salzwasser 2 bis 3 Minuten garen und in der Sauce schwenken. ⏱ 3
7. Mit Baguette servieren.
8. [Sahnesauce-Fleisch] Steak dazulegen.

## Notizen

Im Bestand ist Kochsahne doppelt (einmal je Variante) und alle Zutaten hatten "1×" als Einkauf, das bleibt. Eier: Bio kaufen (Hinweis aus dem Bestand). Standard "Sahnesauce-Veggi". Das Foto zeigt eine Sauce zusätzlich mit Brokkoli, das ist optional.
