# Pancakes

![Pancakes](../pictures/pancakes.jpg)

Fluffige Pancakes, gestapelt und mit warmer Pistaziencreme übergossen, bestreut mit gehackten Pistazien, knusprigem Engelshaar und Beeren.

## Zutaten

| Menge   | Zutat          | Gruppe         | Variante | Hinweis                             | Einkauf |
| ------- | -------------- | -------------- | -------- | ----------------------------------- | ------- |
| 150 g   | Weizenmehl     | Pancakes       |          |                                     | Menge   |
| 1 EL    | Zucker         | Pancakes       |          |                                     | Menge   |
| 2 TL    | Backpulver     | Pancakes       |          |                                     | 1×      |
| 1 Prise | Salz           | Pancakes       |          |                                     | 1×      |
| 1       | Ei             | Pancakes       |          |                                     | Menge   |

| 3 EL    | Sahne          | Pistaziensauce |          |                                     | Menge   |

| 30 g    | Kadayif        | Topping        |          | Engelshaar-Teig, in Butter geröstet | 1×      |
| 80 g    | TK-Beeren      | Topping        |          | frisch oder TK, gemischt            | Menge   |

## Zubereitung

1. Mehl, Zucker, Backpulver und Salz mischen. Ei, Milch und geschmolzene Butter zugeben und kurz zu einem Teig verrühren; kleine Klümpchen dürfen bleiben.
2. Teig 5 Minuten ruhen lassen. ⏱ 5
3. Pfanne bei mittlerer Hitze mit etwas Butter erhitzen, je 1 Kelle Teig einfüllen und 2 bis 3 Minuten backen, bis Bläschen entstehen, wenden und 2 Minuten fertig backen. ⏱ 5
4. Kadayif zerzupfen und in 1 EL Butter 3 Minuten goldbraun rösten. ⏱ 3
5. Pistaziencreme mit Sahne leicht erwärmen und glatt rühren.
6. Pancakes stapeln, mit der Pistaziensauce übergießen und mit Kadayif, Pistazien und Beeren garnieren.

## Notizen

Kadayif gibt es im türkischen oder orientalischen Laden; Ersatz: zerbröselte Cornflakes oder noch mehr gehackte Pistazien. Pistaziencreme gibt es als Aufstrich im Supermarkt oder türkischen Laden.
