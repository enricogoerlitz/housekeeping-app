# Tomate-Mozzarella mit Baguette

![Tomate-Mozzarella mit Baguette](../pictures/tomate-mozzarella-mit-baguette.jpg)

Dicke Tomatenscheiben in Kräuter-Knoblauch-Öl mit cremigem Mozzarella und Balsamico-Creme, dazu geröstetes Baguette.

## Zutaten

| Menge  | Zutat           | Gruppe   | Variante | Hinweis                       | Einkauf |
| ------ | --------------- | -------- | -------- | ----------------------------- | ------- |
| 4      | Tomaten         |          |          | groß, in dicken Scheiben      | Menge   |
| 250 g  | Mozzarella      |          |          | Burrata oder Büffelmozzarella | 1×      |
| 1      | Baguette        |          |          | in Scheiben                   | Menge   |
| 0,5    | Rote Zwiebeln   | Dressing |          | fein gehackt                  |         |
| 2      | Knoblauch       | Dressing |          | Zehen, fein gehackt           |         |
| 1 Bund | Basilikum       | Dressing |          |                               |         |
| 6 EL   | Olivenöl        | Dressing |          |                               |         |
| 1 EL   | Balsamico       | Dressing |          |                               |         |
| 1 TL   | Salz            | Dressing |          |                               |         |
| 2 EL   | Balsamico-Creme |          |          | zum Beträufeln                |         |

## Zubereitung

1. Baguettescheiben mit etwas Olivenöl bestreichen und bei 200 °C 8 Minuten goldbraun rösten. ⏱ 8
2. Zwiebel, Knoblauch und die Hälfte des Basilikums fein hacken und mit Olivenöl, Balsamico und Salz zum Dressing verrühren.
3. Tomatenscheiben auf einer Platte auslegen.
4. Mozzarella in die Mitte setzen, Dressing darüber verteilen.
5. Mit Balsamico-Creme und restlichem Basilikum garnieren und mit dem Baguette servieren.

## Notizen

Am besten mindestens 10 Minuten durchziehen lassen. Nur reife Tomaten verwenden.
