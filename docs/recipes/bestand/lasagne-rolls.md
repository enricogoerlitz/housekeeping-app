# Lasagne Rolls

![Lasagne Rolls](../pictures/lasagne-rolls.jpg)

Aufgerollte Lasagneplatten mit Ricotta-Spinat-Füllung in Tomatensauce, mit Mozzarella überbacken – hübsch und viel handlicher als klassische Lasagne.

## Zutaten

| Menge   | Zutat             | Gruppe  | Variante | Hinweis                                     | Einkauf |
| ------- | ----------------- | ------- | -------- | ------------------------------------------- | ------- |
| 8       | Lasagneplatten    |         |          |                                             | Menge   |
| 250 g   | Ricotta           | Füllung |          |                                             | Menge   |
| 200 g   | Spinat            | Füllung |          | frisch oder aufgetaut (TK), gut ausgedrückt |         |

## Zubereitung

1. Ofen auf 200 °C Ober-/Unterhitze vorheizen.
2. Lasagneplatten in Salzwasser 7 Minuten vorkochen, abtropfen und nebeneinander auf Backpapier legen. ⏱ 7
3. Ricotta mit Spinat, Ei, Parmesan, Knoblauch, Muskat, Salz und Pfeffer verrühren.
4. Zwiebel und Knoblauch in Olivenöl anschwitzen, Passierte Tomaten zugeben und 8 Minuten köcheln. In eine Auflaufform oder ofenfeste Pfanne gießen. ⏱ 8
5. Platten mit Füllung bestreichen, aufrollen und aufrecht in die Sauce stellen.
6. Mit Mozzarella belegen und 20 Minuten backen, bis die Sauce blubbert. ⏱ 20
7. Mit frischem Basilikum servieren.
