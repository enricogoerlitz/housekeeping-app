# Spitzkohlrouladen

![Spitzkohlrouladen](../pictures/spitzkohlrouladen.jpg)

Im Ofen gebackene Spitzkohlrouladen mit Bulgur-Hack-Füllung, spiralförmig geschichtet und in würziger Tomatensauce gegart.

## Zutaten

| Menge  | Zutat         | Gruppe  | Variante        | Hinweis          | Einkauf |
| ------ | ------------- | ------- | --------------- | ---------------- | ------- |
| 1      | Spitzkohl     |         |                 | groß, 12 Blätter | Menge   |
| 300 g  | Hackfleisch   | Füllung | Mit Hackfleisch |                  | Menge   |
| 200 g  | Veggie-Hack   | Füllung | Vegetarisch     |                  | Menge   |
| 100 g  | Bulgur        | Füllung |                 |                  | Menge   |
| 1      | Zwiebeln      | Füllung |                 | fein gewürfelt   |         |
| 1      | Paprika       | Füllung |                 | fein gewürfelt   |         |
| 1 Bund | Petersilie    | Füllung |                 |                  |         |
| 1 EL   | Tomatenmark   | Füllung |                 |                  |         |
| 1 TL   | Salz          | Füllung |                 |                  |         |
| 2 EL   | Tomatenmark   | Sauce   |                 |                  |         |
| 400 ml | Gemüsebrühe   | Sauce   |                 | heiß             |         |
| 2 EL   | Olivenöl      | Sauce   |                 |                  |         |
| 1 TL   | Chiliflocken  | Sauce   |                 |                  |         |
| 1 TL   | Paprikapulver | Sauce   |                 |                  |         |

## Zubereitung

1. Kohlblätter vom Strunk lösen und in Salzwasser 3 Minuten blanchieren, abschrecken und dicke Blattrippen flach schneiden. ⏱ 3
2. Füllung: Hack, Bulgur, Zwiebel, Paprika, Petersilie, Tomatenmark und Salz gut verkneten.
3. Je 2 EL Füllung am Blattende platzieren, Seiten einschlagen und fest aufrollen.
4. Rouladen dicht nebeneinander (oder spiralförmig) in eine ofenfeste Pfanne legen.
5. Sauce aus Tomatenmark, Brühe, Olivenöl, Chili und Paprikapulver verrühren und darübergießen.
6. Mit Alufolie abdecken und bei 180 °C 45 Minuten garen, dann 15 Minuten ohne Folie bräunen. ⏱ 60
7. Mit Petersilie bestreuen.

## Notizen

Bulgur quillt in der Sauce, deshalb nicht vorkochen. Foto zeigt die Rouladen spiralförmig angeordnet in einer großen Pfanne.
