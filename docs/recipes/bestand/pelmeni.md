# Pelmeni

![Pelmeni](../pictures/pelmeni.jpg)

Russische Teigtaschen mit Hackfleisch- oder Pilzfüllung, mit Schmand und Dill.

## Zutaten

| Menge  | Zutat       | Gruppe  | Variante    | Hinweis                   | Einkauf |
| ------ | ----------- | ------- | ----------- | ------------------------- | ------- |
| 300 g  | Mehl        | Teig    |             |                           | 1×      |
| 1      | Ei          | Teig    |             |                           | 1×      |
| 120 ml | Wasser      | Teig    |             | lauwarm                   | nie     |
| 1 TL   | Salz        | Teig    |             |                           |         |
| 250 g  | Hackfleisch | Füllung | Mit Fleisch | Rind und Schwein gemischt | Menge   |
| 250 g  | Champignons | Füllung | Vegetarisch | fein gehackt              | Menge   |
| 1      | Zwiebel     | Füllung |             | sehr fein gewürfelt       | Menge   |
| 1      | Knoblauch   | Füllung |             | Zehe                      | 1×      |
| 150 g  | Schmand     |         |             | zum Servieren             | 1×      |
| 1 EL   | Dill        |         |             | gehackt                   | 1×      |
| 1 EL   | Butter      |         |             |                           |         |
|        | Salz        |         |             |                           |         |
|        | Pfeffer     |         |             |                           |         |

## Zubereitung

1. Mehl, Ei, Wasser und Salz zu einem glatten Teig kneten und 30 Minuten zugedeckt ruhen lassen. ⏱ 30
2. [Mit Fleisch] Füllung: Hackfleisch mit Zwiebel, Knoblauch, Salz, Pfeffer und 2 EL kaltem Wasser verkneten.
3. [Vegetarisch] Füllung: Pilze mit Zwiebel in Butter braten, bis die Flüssigkeit verdampft ist, abkühlen lassen.
4. Teig dünn ausrollen, Kreise (5 cm) ausstechen, je 1 TL Füllung daraufgeben, zu Halbmonden falten und die Enden zusammendrücken.
5. Pelmeni portionsweise in reichlich Salzwasser kochen, bis sie oben schwimmen, dann 5 Minuten weiterkochen. ⏱ 8
6. Mit Butter schwenken und mit Schmand und Dill servieren.

## Notizen

Im Bestand nur der Titel. Pelmeni lassen sich gut einfrieren (roh auf dem Blech vorfrieren).
