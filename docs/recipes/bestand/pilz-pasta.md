# Pilz-Pasta

![Pilz-Pasta](../pictures/pilz-pasta.jpg)

Rigatoni in cremiger Knoblauch-Sahnesauce mit kräftig gebratenen Champignons und Petersilie. Dazu passt Parmesan.

## Zutaten

| Menge  | Zutat       | Gruppe | Variante  | Hinweis                  | Einkauf |
| ------ | ----------- | ------ | --------- | ------------------------ | ------- |
| 250 g  | Rigatoni    |        |           |                          |         |
| 400 g  | Champignons |        |           | braun, in dicke Scheiben | Menge   |
| 100 g  | Speck       |        | Mit Speck | gewürfelt                | Menge   |
| 3      | Knoblauch   |        |           | Zehen, gehackt           |         |
| 1      | Schalotte   |        |           | fein gewürfelt           |         |
| 200 ml | Sahne       |        |           |                          |         |
| 50 ml  | Weißwein    |        |           | oder Gemüsebrühe         |         |
| 40 g   | Parmesan    |        |           | frisch gerieben          |         |
| 1 TL   | Thymian     |        |           | getrocknet               |         |
| 1 Bund | Petersilie  |        |           | gehackt                  |         |
| 2 EL   | Olivenöl    |        |           |                          |         |
|        | Salz        |        |           |                          |         |
|        | Pfeffer     |        |           |                          |         |

## Zubereitung

1. Rigatoni in Salzwasser bissfest kochen, 100 ml Nudelwasser aufheben. ⏱ 11
2. [Mit Speck] Speck im Öl 4 Minuten knusprig braten und herausnehmen. ⏱ 4
3. Champignons in zwei Portionen im heißen Öl 5 Minuten kräftig braun anbraten, erst gegen Ende salzen. ⏱ 5
4. Schalotte, Knoblauch und Thymian 1 Minute mitbraten, mit Wein ablöschen und einkochen.
5. Sahne zugeben und 3 Minuten köcheln, Parmesan einrühren.
6. Nudeln mit Nudelwasser untermengen, mit Salz und Pfeffer abschmecken.
7. [Mit Speck] Speck unterheben.
8. Mit Petersilie servieren.
