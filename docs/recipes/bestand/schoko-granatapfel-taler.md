# Schoko-Granatapfel Taler

![Schoko-Granatapfel Taler](../pictures/schoko-granatapfel-taler.jpg)

Kleine Taler aus dunkler Schokolade, dicht gespickt mit saftigen Granatapfelkernen. Schnell gemacht, nur Kühlschrank, kein Backen.

## Zutaten

| Menge   | Zutat                | Gruppe | Variante | Hinweis             | Einkauf |
| ------- | -------------------- | ------ | -------- | ------------------- | ------- |
| 150 g   | Zartbitterschokolade |        |          | 70 % Kakao, gehackt | Menge   |
| 1       | Granatapfel          |        |          | Kerne, ca. 80 g     | Menge   |
| 1 Prise | Meersalz             |        |          | zum Bestreuen       | 1×      |

## Zubereitung

1. Granatapfel entkernen und die Kerne auf Küchenpapier gut trocken tupfen.
2. Schokolade über dem Wasserbad oder in der Mikrowelle in 30-Sekunden-Schritten schmelzen und glatt rühren.
3. Ein Blech mit Backpapier auslegen. Mit einem Löffel 8 Kleckse Schokolade zu je ca. 7 cm Durchmesser daraufsetzen.
4. Granatapfelkerne dicht darauf verteilen und leicht andrücken. Mit Meersalz bestreuen.
5. Im Kühlschrank 30 Minuten fest werden lassen. ⏱ 30

## Notizen

Die Kerne müssen sehr trocken sein, sonst klumpt die Schokolade. Im Kühlschrank 5 Tage haltbar.
