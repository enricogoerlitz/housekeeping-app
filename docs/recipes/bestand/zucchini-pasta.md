# Zucchini Pasta

![Zucchini Pasta](../pictures/zucchini-pasta.jpg)

Rigatoni in cremiger Zucchini-Parmesan-Sauce – leicht, schnell und ohne Fleisch.

## Zutaten

| Menge  | Zutat     | Gruppe | Variante | Hinweis             | Einkauf |
| ------ | --------- | ------ | -------- | ------------------- | ------- |
| 250 g  | Penne     |        |          | Rigatoni oder Penne | Menge   |
| 2      | Zucchini  |        |          | in Halbmonden       | Menge   |
| 2      | Knoblauch |        |          | Zehen               |         |
| 2 EL   | Olivenöl  |        |          |                     |         |
| 100 ml | Sahne     |        |          |                     |         |
| 60 g   | Parmesan  |        |          | gerieben            | Menge   |
| 1      | Zitronen  |        |          | Abrieb und Saft     |         |
| 1      | Basilikum |        |          | Handvoll            |         |
| 1 TL   | Salz      |        |          |                     |         |
| 0,5 TL | Pfeffer   |        |          |                     |         |
| 2 l    | Wasser    |        |          |                     | nie     |

## Zubereitung

1. Pasta in Salzwasser bissfest kochen, 150 ml Nudelwasser aufheben, abgießen. ⏱ 10
2. Zucchini in Olivenöl bei hoher Hitze 6 Minuten braten, bis sie leicht Farbe hat, Knoblauch zugeben. ⏱ 6
3. Sahne und die Hälfte des Parmesans zugeben, 2 Minuten köcheln.
4. Pasta mit Nudelwasser in die Pfanne geben und schwenken, bis eine glänzende Sauce entsteht.
5. Mit Zitronenabrieb, Salz und Pfeffer abschmecken.
6. Mit Basilikum und restlichem Parmesan anrichten.

## Notizen

Rigatoni aus dem Foto; Penne gehen genauso gut. Ein Löffel Frischkäse macht die Sauce noch cremiger.
