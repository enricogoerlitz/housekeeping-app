# Rindergeschnetzeltes mit Pilzen und Spätzle

![Rindergeschnetzeltes mit Pilzen und Spätzle](../pictures/rindergeschnetzeltes-mit-pilzen-und-spaetzle.jpg)

Zartes Rindergeschnetzeltes mit Champignons in Sahnesauce, serviert mit hausgemachten oder frischen Spätzle.

## Zutaten

| Menge  | Zutat         | Gruppe | Variante        | Hinweis                  | Einkauf |
| ------ | ------------- | ------ | --------------- | ------------------------ | ------- |
| 300 g  | Rindersteak   |        | Mit Rindfleisch | in dünnen Streifen       | Menge   |
| 200 g  | Räuchertofu   |        | Vegetarisch     | in dünnen Streifen       | Menge   |
| 250 g  | Champignons   |        |                 | in Scheiben              | Menge   |
| 1      | Zwiebeln      |        |                 | in Streifen              |         |
| 1 EL   | Butterschmalz |        |                 |                          |         |
| 150 ml | Sahne         |        |                 |                          | 1×      |
| 150 ml | Rinderbrühe   |        | Mit Rindfleisch |                          |         |
| 150 ml | Gemüsebrühe   |        | Vegetarisch     |                          |         |
| 1 EL   | Senf          |        |                 |                          |         |
| 1 TL   | Paprikapulver |        |                 |                          |         |
| 1 EL   | Mehl          |        |                 |                          |         |
| 300 g  | Spätzle       |        |                 | frisch aus dem Kühlregal | Menge   |
| 1 Bund | Petersilie    |        |                 |                          |         |
| 1 TL   | Salz          |        |                 |                          |         |
| 0,5 TL | Pfeffer       |        |                 |                          |         |

## Zubereitung

1. Fleisch (oder Räuchertofu) mit Mehl bestäuben. Butterschmalz in einer sehr heißen Pfanne erhitzen und Fleisch portionsweise 1 bis 2 Minuten scharf anbraten, herausnehmen.
2. Champignons 5 Minuten kräftig anbraten, Zwiebel zugeben und 3 Minuten mitbraten.
3. Paprikapulver einrühren, mit Brühe und Sahne ablöschen, Senf zugeben und 5 Minuten einköcheln. ⏱ 5
4. Spätzle nach Packungsangabe in Wasser oder in Butter in der Pfanne erwärmen. ⏱ 4
5. Fleisch kurz in die Sauce geben, mit Salz und Pfeffer abschmecken (nicht mehr kochen).
6. Mit Petersilie über den Spätzle anrichten.
