# Wrap Variationen

![Wrap Variationen](../pictures/wrap-variationen.jpg)

Gefüllte Wraps mit Gewürz-Kichererbsen, Salat und Joghurtsauce.

## Zutaten

| Menge  | Zutat          | Gruppe | Variante     | Hinweis              | Einkauf |
| ------ | -------------- | ------ | ------------ | -------------------- | ------- |
| 2      | Weizentortilla |        |              | groß                 | 1×      |
| 1 Dose | Kichererbsen   |        |              | 240 g Abtropfgewicht | 1×      |
| 1 TL   | Paprikapulver  |        |              | geräuchert           |         |
| 1 TL   | Kreuzkümmel    |        |              |                      |         |
| 2 EL   | Olivenöl       |        |              |                      |         |
| 200 g  | Hähnchenbrust  |        | Mit Hähnchen | in Streifen          | Menge   |
| 1      | Romanasalat    |        |              | Herz                 | Menge   |
| 1      | Tomate         |        |              | in Scheiben          | Menge   |
| 1      | Rote Zwiebel   |        |              | in Ringen            | Menge   |
| 150 g  | Joghurt        |        |              |                      | 1×      |
| 1      | Knoblauch      |        |              | Zehe                 | 1×      |
| 1 EL   | Zitronen       |        |              | Saft                 |         |
|        | Salz           |        |              |                      |         |
|        | Pfeffer        |        |              |                      |         |

## Zubereitung

1. Kichererbsen abtropfen, mit Paprika, Kreuzkümmel, Salz und 1 EL Öl vermengen und 15 Minuten bei 200 °C rösten (oder 8 Minuten in der Pfanne braten). ⏱ 15
2. [Mit Hähnchen] Hähnchen würzen und in Öl 6 Minuten braten. ⏱ 6
3. Joghurt mit Knoblauch, Zitronensaft, Salz und Pfeffer zur Sauce verrühren.
4. Tortillas kurz in der Pfanne erwärmen.
5. Mit Sauce, Salat, Tomate, Zwiebel und Kichererbsen (oder Hähnchen) füllen, einrollen.

## Notizen

Variante "Veggi-Kichererbsen" war im Bestand Standard mit TikTok-Link. "Mit Hähnchen" ist neu ergänzt. Der Link-Label stammt aus dem Bestand.
