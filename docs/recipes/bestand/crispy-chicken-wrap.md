# Crispy Chicken Wrap

![Crispy Chicken Wrap](../pictures/crispy-chicken-wrap.jpg)

Großer Weizenwrap mit knusprigem Hähnchen, Gurke, Salat und kühler Kräutersauce. Die vegetarische Variante nutzt paniertes Halloumi.

## Zutaten

| Menge     | Zutat              | Gruppe       | Variante     | Hinweis                     | Einkauf |
| --------- | ------------------ | ------------ | ------------ | --------------------------- | ------- |
| 2         | Weizentortillas    |              |              | groß                        | 1×      |
| 300 g     | Hähnchenbrustfilet |              | Mit Hähnchen | in Streifen                 | Menge   |
| 200 g     | Halloumi           |              | Vegetarisch  | in Stäbchen                 | Menge   |
| 3 EL      | Mehl               | Panade       |              |                             | Menge   |
| 2         | Eier               | Panade       |              | verquirlt                   | Menge   |

## Zubereitung

1. Joghurt mit Dill, Knoblauch, Zitronensaft, Salz und Pfeffer zur Kräutersauce verrühren und kühl stellen.
2. [Mit Hähnchen] Hähnchenstreifen mit Salz, Pfeffer und Paprikapulver würzen.
3. [Vegetarisch] Halloumi trocken tupfen.
4. Zuerst im Mehl wenden, dann durch das Ei ziehen und im Paniermehl gut andrücken.
5. Öl in einer Pfanne erhitzen und die Stücke je Seite 3 bis 4 Minuten goldbraun und knusprig braten, Hähnchen ist gar, wenn der austretende Saft klar ist. ⏱ 8
6. Tortillas kurz in einer trockenen Pfanne erwärmen.
7. Tortillas mit Sauce bestreichen, Salat, Gurke und die knusprigen Stücke darauflegen, seitlich einschlagen und fest aufrollen.
8. Diagonal halbieren und mit der restlichen Sauce zum Dippen servieren.

## Notizen

Statt Paniermehl sorgen Cornflakes für extra Knusper. Der Wrap lässt sich in Backpapier gewickelt gut mitnehmen.
