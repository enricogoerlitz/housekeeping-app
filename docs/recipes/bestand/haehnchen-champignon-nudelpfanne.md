# Hähnchen-/ Champignon-/ Nudelpfanne

![Hähnchen-/ Champignon-/ Nudelpfanne](../pictures/haehnchen-champignon-nudelpfanne.jpg)

Cremige Nudelpfanne mit Hähnchen und Champignons in einer Sahnesauce.

## Zutaten

| Menge  | Zutat         | Gruppe | Variante     | Hinweis                      | Einkauf |
| ------ | ------------- | ------ | ------------ | ---------------------------- | ------- |
| 250 g  | Nudeln        |        |              | Gabelspaghetti oder Hörnchen |         |
| 300 g  | Hähnchenbrust |        | Mit Hähnchen | in Würfeln                   | Menge   |
| 250 g  | Champignons   |        |              | in Scheiben                  | Menge   |
| 1      | Zwiebel       |        |              | gewürfelt                    | Menge   |
| 2      | Knoblauch     |        |              | Zehen                        | Menge   |
| 200 ml | Kochsahne     |        |              |                              |         |
| 300 ml | Gemüsebrühe   |        |              |                              |         |
| 2 EL   | Schnittlauch  |        |              | Röllchen                     | 1×      |
| 1 TL   | Paprikapulver |        |              |                              |         |
| 2 EL   | Öl            |        |              |                              |         |
|        | Salz          |        |              |                              |         |
|        | Pfeffer       |        |              |                              |         |

## Zubereitung

1. [Mit Hähnchen] Hähnchenwürfel in Öl 5 Minuten braun anbraten, herausnehmen. ⏱ 5
2. Champignons 5 Minuten kräftig braten, Zwiebel und Knoblauch zugeben und 2 Minuten mitbraten. ⏱ 7
3. Brühe und Sahne angießen, Paprikapulver, Salz und Pfeffer zugeben.
4. Nudeln einrühren und 10 bis 12 Minuten garen, dabei öfter umrühren. ⏱ 12
5. [Mit Hähnchen] Fleisch wieder zugeben und 2 Minuten erwärmen.
6. Mit Schnittlauch bestreuen.
