# Griechischer Salat

![Griechischer Salat](../pictures/griechischer-salat.jpg)

Echter griechischer Salat ohne Blattsalat: grobe Tomaten, Gurke, rote Zwiebel und Paprika, obenauf ein ganzer Block Feta mit Oregano und gutem Olivenöl.

## Zutaten

| Menge | Zutat        | Gruppe | Variante | Hinweis                          | Einkauf |
| ----- | ------------ | ------ | -------- | -------------------------------- | ------- |
| 4     | Tomaten      |        |          | reif, in große Stücke            | Menge   |
| 1     | Salatgurke   |        |          | in dicke Stücke                  | Menge   |
| 1     | Rote Zwiebel |        |          | in Ringen                        | Menge   |
| 1     | Paprika      |        |          | grün, in Ringen                  | Menge   |
| 200 g | Feta         |        |          | am Stück                         | Menge   |
| 100 g | Oliven       |        |          | Kalamata                         | Menge   |
| 4 EL  | Olivenöl     |        |          | kaltgepresst                     | 1×      |
| 1 EL  | Rotweinessig |        |          |                                  | 1×      |
| 1 TL  | Oregano      |        |          | getrocknet, am besten griechisch | 1×      |
|       | Salz         |        |          |                                  | 1×      |

## Zubereitung

1. Tomaten, Gurke, Paprika und Zwiebel in eine große Schüssel geben, salzen und 5 Minuten durchziehen lassen. ⏱ 5
2. Essig und die Hälfte des Olivenöls zugeben und locker vermengen.
3. Oliven obenauf verteilen und den Fetablock in die Mitte setzen.
4. Feta mit Oregano bestreuen und mit dem restlichen Olivenöl beträufeln.
5. Sofort mit frischem Brot servieren; den Feta am Tisch zerteilen.

## Notizen

Ganz ohne Salat und ohne Zitrone; die Qualität von Feta und Olivenöl macht den Unterschied.
