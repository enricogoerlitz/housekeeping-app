# Palatschinken

![Palatschinken](../pictures/palatschinken.jpg)

Dünne österreichische Pfannkuchen, aufgerollt und mit Früchten oder Nuss-Nougat-Creme gefüllt.

## Zutaten

| Menge      | Zutat               | Gruppe  | Variante | Hinweis       | Einkauf |
| ---------- | ------------------- | ------- | -------- | ------------- | ------- |
| 80 g       | Mehl                |         |          |               | 1×      |
| 250 ml     | Milch               |         |          |               | Menge   |
| 2          | Eier                |         |          |               | 1×      |
| 1 EL       | Zucker              |         |          |               | 1×      |
| 1 Prise    | Salz                |         |          |               | 1×      |
| Etwas      | Butter              |         |          | zum Backen    |         |
| 1 Handvoll | Früchte (Allgemein) | Topping |          |               | 1×      |
| 2 EL       | Nuss-Nougat-Creme   | Topping |          |               | 1×      |
|            | Puderzucker         | Topping |          | zum Bestäuben |         |

## Zubereitung

1. Mehl, Milch, Eier, Zucker und Salz glatt verrühren und 15 Minuten ruhen lassen. ⏱ 15
2. Pfanne mit etwas Butter erhitzen und eine kleine Kelle Teig dünn verteilen.
3. Je Seite 1 bis 2 Minuten goldgelb backen. ⏱ 3
4. Mit Früchten und/oder Nuss-Nougat-Creme füllen, aufrollen und mit Puderzucker bestäuben.

## Notizen

Mengen "80 g Mehl, 250 ml Milch, 2 Eier, 1 EL Zucker, 1 Prise Salz" und Topping-Gruppe stammen aus dem Bestand. Der Einkauf (Mehl, Eier, Zucker, Salz: 1×; Milch: Menge) blieb wie vorher.
