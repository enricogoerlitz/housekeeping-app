# Oliven Parmesan Dip

![Oliven Parmesan Dip](../pictures/oliven-parmesan-dip.jpg)

Grober Dip aus grünen Oliven, getrockneten Tomaten, Kräutern und Parmesan in Olivenöl, zu Brot oder Pasta.

## Zutaten

| Menge      | Zutat               | Gruppe | Variante | Hinweis                    | Einkauf |
| ---------- | ------------------- | ------ | -------- | -------------------------- | ------- |
| 200 g      | Grüne Oliven        |        |          | entsteint, grob gehackt    | 1×      |
| 80 g       | Getrocknete Tomaten |        |          | in Öl, abgetropft, gehackt | 1×      |
| 50 g       | Parmesan            |        |          | fein gerieben              | 1×      |
| 1 Bund     | Petersilie          |        |          | gehackt                    | 1×      |
| 1 Handvoll | Basilikum           |        |          | gehackt                    | 1×      |
| 2          | Knoblauch           |        |          | Zehen, fein gehackt        | 1×      |
| 5 EL       | Olivenöl            |        |          |                            |         |
| 1 TL       | Chiliflocken        |        |          |                            |         |
| 1 EL       | Rotweinessig        |        |          |                            |         |
|            | Pfeffer             |        |          |                            |         |

## Zubereitung

1. Oliven, getrocknete Tomaten, Petersilie und Basilikum fein hacken und in eine Schüssel geben.
2. Parmesan, Knoblauch, Chiliflocken, Essig und Olivenöl unterrühren und mit Pfeffer abschmecken.
3. Mindestens 30 Minuten durchziehen lassen. ⏱ 30
4. Mit Brot, Crackern oder warmer Pasta servieren.

## Notizen

Gang als Snack gesetzt (stand unter Hauptgericht). Parmesan ist nicht vegetarisch; vegetarisch geht Grana Padano ohne tierisches Lab.
