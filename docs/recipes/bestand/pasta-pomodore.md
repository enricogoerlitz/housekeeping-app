# Pasta Pomodore

![Pasta Pomodore](../pictures/pasta-pomodore.jpg)

Spaghetti in einfacher, fruchtiger Tomatensauce (Pomodoro) mit Knoblauch und frischem Basilikum.

## Zutaten

| Menge  | Zutat            | Gruppe | Variante | Hinweis        | Einkauf |
| ------ | ---------------- | ------ | -------- | -------------- | ------- |
| 250 g  | Spaghetti        |        |          |                | Menge   |
| 1 Dose | Gehackte Tomaten |        |          | 400 g          | 1×      |
| 1      | Zwiebeln         |        |          | fein gewürfelt |         |
| 2      | Knoblauch        |        |          | Zehen          |         |
| 3 EL   | Olivenöl         |        |          |                |         |
| 1 TL   | Zucker           |        |          |                |         |
| 1      | Basilikum        |        |          | Topf           |         |
| 30 g   | Parmesan         |        |          |                |         |
| 1 TL   | Salz             |        |          |                |         |
| 0,5 TL | Pfeffer          |        |          |                |         |
| 2 l    | Wasser           |        |          |                | nie     |

## Zubereitung

1. Zwiebel in Olivenöl 3 Minuten glasig dünsten, Knoblauch 1 Minute mitbraten.
2. Tomaten, Zucker und Salz zugeben und 15 Minuten leise köcheln lassen. ⏱ 15
3. Spaghetti in Salzwasser bissfest kochen, 100 ml Nudelwasser aufheben, abgießen. ⏱ 9
4. Nudeln mit Sauce und Nudelwasser verrühren.
5. Mit Basilikum und Parmesan bestreuen.
