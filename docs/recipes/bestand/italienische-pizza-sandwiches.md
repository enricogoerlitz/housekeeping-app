# Italienische Pizza Sandwiches

![Italienische Pizza Sandwiches](../pictures/italienische-pizza-sandwiches.jpg)

Frisch gebackene Pizzafladen, zusammengeklappt und gefüllt mit Mortadella, Burrata und Pistazienpesto.

## Zutaten

| Menge  | Zutat      | Gruppe  | Variante       | Hinweis            | Einkauf |
| ------ | ---------- | ------- | -------------- | ------------------ | ------- |
| 2      | Pizzateig  |         |                | Kugeln à 125 g     | Menge   |
| 150 g  | Mortadella | Füllung | Mit Mortadella | in dünnen Scheiben | Menge   |
| 150 g  | Mozzarella | Füllung | Vegetarisch    | in Scheiben        |         |
| 1      | Mozzarella | Füllung |                | Burrata            | 1×      |
| 50 g   | Pistazien  | Pesto   |                | geschält           |         |
| 1 Bund | Basilikum  | Pesto   |                |                    |         |
| 1      | Knoblauch  | Pesto   |                | Zehe               |         |
| 60 ml  | Olivenöl   | Pesto   |                |                    |         |
| 20 g   | Parmesan   | Pesto   |                |                    |         |
| 1 TL   | Salz       |         |                |                    |         |

## Zubereitung

1. Ofen mit Backblech oder Pizzastein auf 250 °C (Umluft) vorheizen, mindestens 30 Minuten. ⏱ 30
2. Pesto: Pistazien (einige zum Garnieren hacken), Basilikum, Knoblauch, Parmesan, Olivenöl und Salz zu einem groben Pesto mixen.
3. Teigkugeln auf bemehlter Fläche zu Fladen von etwa 22 cm ausziehen.
4. Fladen auf Backpapier 4 bis 5 Minuten backen, bis sie Blasen und Röstflecken haben, nicht zu dunkel. ⏱ 5
5. Sofort die Hälfte jedes Fladens mit Mortadella (oder Mozzarellascheiben) belegen, Burrata zerzupfen, mit Pesto beträufeln und zuklappen.
6. Mit gehackten Pistazien und etwas Olivenöl abschließen und schräg durchschneiden.

## Notizen

Zwei Tage vorher einen Pizzateig (24 h Gehzeit) ansetzen, siehe „Pizzateig (Basis, 24h)“. Fertigen Teig aus dem Kühlregal als Abkürzung.
