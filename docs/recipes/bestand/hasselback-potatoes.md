# Hasselback Potatoes

![Hasselback Potatoes](../pictures/hasselback-potatoes.jpg)

Eingeschnittene Ofenkartoffeln mit knusprigen Rändern und Knoblauch-Kräuterbutter.

## Zutaten

| Menge | Zutat         | Gruppe | Variante | Hinweis                         | Einkauf |
| ----- | ------------- | ------ | -------- | ------------------------------- | ------- |
| 600 g | Kartoffeln    |        |          | festkochend, klein, gleichmäßig |         |
| 50 g  | Butter        |        |          | geschmolzen                     | 1×      |
| 2     | Knoblauch     |        |          | Zehen, gepresst                 | Menge   |
| 2 EL  | Petersilie    |        |          | gehackt                         | 1×      |
| 1 EL  | Olivenöl      |        |          |                                 |         |
| 1 TL  | Paprikapulver |        |          |                                 |         |
|       | Salz          |        |          |                                 |         |
|       | Pfeffer       |        |          |                                 |         |

## Zubereitung

1. Ofen auf 200 °C Ober-/Unterhitze vorheizen.
2. Kartoffeln waschen, zwischen zwei Holzlöffelstiele legen und im Abstand von 3 mm fast bis zum Boden einschneiden.
3. Butter, Öl, Knoblauch, Paprika, Salz und Pfeffer verrühren und die Kartoffeln damit einpinseln, auch zwischen die Schnitte.
4. Auf einem Blech 45 bis 55 Minuten backen, dabei zweimal erneut mit Butter bestreichen. ⏱ 50
5. Mit Petersilie bestreuen.
