# Klöße mit Pilzrahmsauce und Rotkohl

![Klöße mit Pilzrahmsauce und Rotkohl](../pictures/kloesse-mit-pilzrahmsauce-und-rotkohl.jpg)

Thüringer Kartoffelklöße mit einer sämigen Champignon-Rahmsauce mit Speck und Petersilie, dazu süßsaurer Rotkohl.

## Zutaten

| Menge    | Zutat           | Gruppe        | Variante  | Hinweis                              | Einkauf |
| -------- | --------------- | ------------- | --------- | ------------------------------------ | ------- |
| 1 Pck.   | Kartoffelknödel |               |           | Thüringer Klöße, Kochbeutel, 6 Stück | 1×      |
| 300 g    | Champignons     | Pilzrahmsauce |           | in Scheiben                          | Menge   |
| 80 g     | Speckwürfel     | Pilzrahmsauce | Mit Speck |                                      | Menge   |
| 1        | Zwiebel         | Pilzrahmsauce |           | fein gewürfelt                       | Menge   |
| 1 EL     | Butter          | Pilzrahmsauce |           |                                      | 1×      |
| 1 EL     | Mehl            | Pilzrahmsauce |           |                                      | 1×      |
| 200 ml   | Sahne           | Pilzrahmsauce |           |                                      | Menge   |
| 100 ml   | Gemüsebrühe     | Pilzrahmsauce |           |                                      | Menge   |
| 1/2 Bund | Petersilie      | Pilzrahmsauce |           | gehackt                              | 1×      |
| 1 Glas   | Rotkohl         |               |           | ca. 350 g                            | 1×      |
| 1        | Apfel           |               |           | in Würfeln                           | Menge   |
| 1        | Lorbeerblatt    |               |           |                                      | 1×      |
|          | Salz            |               |           |                                      | 1×      |
|          | Pfeffer         |               |           |                                      | 1×      |

## Zubereitung

1. Klöße im Kochbeutel nach Packungsangabe in siedendem Salzwasser 20 Minuten ziehen lassen. ⏱ 20
2. [Mit Speck] Speck in einer Pfanne ohne Fett 4 Minuten knusprig auslassen. ⏱ 4
3. Butter zugeben, Zwiebel 3 Minuten glasig dünsten, Champignons 6 Minuten kräftig braten. ⏱ 9
4. Mehl überstäuben, kurz anschwitzen, mit Brühe und Sahne ablöschen und 5 Minuten sämig einkochen. Mit Salz und Pfeffer abschmecken, Petersilie unterrühren. ⏱ 5
5. Rotkohl mit Apfelwürfeln und Lorbeerblatt in einem Topf 10 Minuten erhitzen. ⏱ 10
6. Klöße auf Teller setzen, mit Pilzrahmsauce übergießen und mit Rotkohl servieren.

## Notizen

Klöße nach dem Garen mit zwei Gabeln einreißen, damit sie Sauce aufnehmen. Die Foto-Variante enthält Speck.
