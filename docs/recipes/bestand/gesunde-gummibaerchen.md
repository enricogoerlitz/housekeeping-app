# Gesunde Gummibärchen

![Gesunde Gummibärchen](../pictures/gesunde-gummibaerchen.jpg)

Fruchtgummis aus nur zwei Zutaten, Obst und Gelatine, ganz ohne Industriezucker. Rot, dunkelviolett und gelb je nach Frucht.

## Zutaten

| Menge | Zutat     | Gruppe | Variante | Hinweis                                                                | Einkauf |
| ----- | --------- | ------ | -------- | ---------------------------------------------------------------------- | ------- |
| 250 g | TK-Beeren |        |          | Himbeeren, Erdbeeren oder Heidelbeeren, frisch oder TK; für Gelb Mango | Menge   |
| 27 g  | Gelatine  |        |          | 3 Päckchen Pulver                                                      | 1×      |
| 1 EL  | Honig     |        |          | optional, bei sauren Früchten                                          | 1×      |

## Zubereitung

1. Früchte fein pürieren und durch ein Sieb streichen; es sollten etwa 200 ml Püree entstehen.
2. Püree mit Honig in einem kleinen Topf bei niedriger Hitze erwärmen, nicht kochen.
3. Gelatine einrühren und unter Rühren 2 bis 3 Minuten auflösen, bis keine Körnchen mehr sichtbar sind. ⏱ 3
4. Masse mit einer Pipette oder einem Löffel in Silikonformen füllen.
5. Im Kühlschrank mindestens 1 Stunde fest werden lassen. ⏱ 60
6. Gummibärchen aus der Form lösen und in einer verschlossenen Dose im Kühlschrank aufbewahren.

## Notizen

Für drei Farben dreimal ansetzen, z. B. Himbeere (rot), Heidelbeere (dunkel), Mango (gelb). Im Kühlschrank 5 bis 7 Tage haltbar. Vegetarisch geht mit Agar-Agar statt Gelatine, dann kurz aufkochen.
