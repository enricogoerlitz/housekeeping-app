# Paella

![Paella](../pictures/paella.jpg)

Spanischer Reis mit Safran, Tomate und Paprika, belegt mit ganzen Garnelen und gerösteten Paprikastreifen, wie auf dem Foto. Die vegetarische Variante nimmt Artischocken und grüne Bohnen.

## Zutaten

| Menge  | Zutat              | Gruppe | Variante     | Hinweis                   | Einkauf |
| ------ | ------------------ | ------ | ------------ | ------------------------- | ------- |
| 200 g  | Paella-Reis        |        |              | Bomba oder Rundkornreis   |         |
| 8      | Garnelen           |        | Mit Garnelen | mit Schale, roh           | Menge   |
| 150 g  | Artischockenherzen |        | Vegetarisch  | aus dem Glas, geviertelt  |         |
| 150 g  | Grüne Bohnen       |        | Vegetarisch  | in 3 cm Stücke            |         |
| 1      | Zwiebel            |        |              | fein gewürfelt            |         |
| 3      | Knoblauch          |        |              | Zehen, gehackt            |         |

| 2      | Geröstete Paprika  |        |              | aus dem Glas, in Streifen |         |
| 1 TL   | Paprikapulver      |        |              | geräuchert                |         |

## Zubereitung

1. Safran in 3 EL heißer Brühe 10 Minuten ziehen lassen. ⏱ 10
2. [Mit Garnelen] Garnelen in Öl 1 Minute pro Seite anbraten und herausnehmen.
3. Zwiebel im Öl 4 Minuten anschwitzen, Knoblauch, geriebene Tomate und Paprikapulver zugeben und 5 Minuten einkochen. ⏱ 5
4. [Vegetarisch] Bohnen und Artischocken 3 Minuten mitbraten.
5. Reis 1 Minute mitrösten, mit heißem Fond und Safran begießen und salzen. Einmal umrühren, dann nicht mehr rühren.
6. 10 Minuten bei mittlerer Hitze, dann 8 Minuten bei kleiner Hitze köcheln, bis die Flüssigkeit aufgesogen ist. ⏱ 18
7. [Mit Garnelen] Garnelen und Paprikastreifen auf den Reis legen.
8. [Vegetarisch] Paprikastreifen auf den Reis legen.
9. 5 Minuten mit Deckel ruhen lassen. ⏱ 5
10. Mit Zitronenspalten servieren.

## Notizen

Für die Kruste (Socarrat) zum Schluss 1 Minute die Hitze erhöhen. Statt Paella-Pfanne geht eine weite Pfanne.
