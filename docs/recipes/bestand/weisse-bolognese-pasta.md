# Weiße Bolognese Pasta

![Weiße Bolognese Pasta](../pictures/weisse-bolognese-pasta.jpg)

Weiße Bolognese: Hackfleisch-Ragù ohne Tomate, mit Weißwein, Gemüse und etwas Sahne, auf Tagliatelle.

## Zutaten

| Menge  | Zutat           | Gruppe | Variante        | Hinweis                | Einkauf |
| ------ | --------------- | ------ | --------------- | ---------------------- | ------- |
| 250 g  | Tagliatelle     |        |                 |                        | Menge   |
| 300 g  | Hackfleisch     |        | Mit Hackfleisch | gemischt               | Menge   |
| 250 g  | Veggie-Hack     |        | Vegetarisch     |                        | Menge   |
| 1      | Zwiebeln        |        |                 | fein gewürfelt         |         |
| 1      | Möhren          |        |                 | fein gewürfelt         |         |
| 1      | Staudensellerie |        |                 | Stange, fein gewürfelt |         |
| 2      | Knoblauch       |        |                 | Zehen                  |         |
| 150 ml | Weißwein        |        |                 |                        |         |
| 150 ml | Milch           |        |                 |                        |         |
| 100 ml | Sahne           |        |                 |                        |         |
| 2 EL   | Olivenöl        |        |                 |                        |         |
| 1      | Thymian         |        |                 | Zweig                  |         |
| 40 g   | Parmesan        |        |                 |                        |         |
| 1 TL   | Salz            |        |                 |                        |         |
| 2 l    | Wasser          |        |                 |                        | nie     |

## Zubereitung

1. Zwiebel, Möhre und Sellerie in Olivenöl 6 Minuten bei mittlerer Hitze weich dünsten, Knoblauch kurz zugeben.
2. Hack zugeben und 6 Minuten krümelig anbraten, ohne zu stark zu bräunen.
3. Mit Weißwein ablöschen und fast vollständig einkochen lassen. ⏱ 5
4. Milch und Thymian zugeben und 20 Minuten leise köcheln, Sahne einrühren und abschmecken. ⏱ 20
5. Tagliatelle in Salzwasser bissfest kochen, abgießen, 3 EL Nudelwasser aufheben. ⏱ 8
6. Nudeln mit der Sauce und dem Nudelwasser mischen, mit Parmesan servieren.
