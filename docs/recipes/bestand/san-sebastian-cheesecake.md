# San Sebastian Cheesecake

![San Sebastian Cheesecake](../pictures/san-sebastian-cheesecake.jpg)

Baskischer Käsekuchen ohne Boden: außen tief karamellisiert, innen cremig und fast flüssig.

## Zutaten

| Menge  | Zutat         | Gruppe | Variante | Hinweis          | Einkauf |
| ------ | ------------- | ------ | -------- | ---------------- | ------- |
| 400 g  | Frischkäse    |        |          | Zimmertemperatur | Menge   |
| 200 ml | Sahne         |        |          |                  | 1×      |
| 100 g  | Zucker        |        |          |                  |         |
| 2      | Eier          |        |          |                  |         |
| 1 EL   | Mehl          |        |          |                  |         |
| 1      | Vanillezucker |        |          | Päckchen         |         |
| 1      | Butter        |        |          | zum Fetten       |         |

## Zubereitung

1. Ofen auf 220 °C Ober-/Unterhitze vorheizen. Eine Springform (18 cm) fetten und mit Backpapier auslegen, das etwa 3 cm übersteht und knittrig bleibt.
2. Frischkäse mit Zucker cremig rühren, Eier einzeln einrühren.
3. Sahne, Vanillezucker und Mehl zugeben und glatt verrühren (nicht zu lange rühren).
4. Masse in die Form gießen und im Ofen 25 bis 30 Minuten backen, bis die Oberfläche dunkel karamellisiert ist; die Mitte darf noch wackeln. ⏱ 28
5. In der Form vollständig abkühlen lassen, dann mindestens 4 Stunden kühlen. ⏱ 240
