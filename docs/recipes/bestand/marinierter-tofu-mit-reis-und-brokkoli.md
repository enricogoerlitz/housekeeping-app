# Marinierter Tofu mit Reis und Brokkoli

![Marinierter Tofu mit Reis und Brokkoli](../pictures/marinierter-tofu-mit-reis-und-brokkoli.jpg)

Knuspriger Tofu in klebriger Soja-Ahornsirup-Glasur, dazu Reis und gedämpfter Brokkoli – vegan und sehr sättigend.

## Zutaten

| Menge | Zutat           | Gruppe | Variante | Hinweis          | Einkauf |
| ----- | --------------- | ------ | -------- | ---------------- | ------- |
| 400 g | Tofu            |        |          | fest, in Würfeln | Menge   |
| 2 EL  | Speisestärke    |        |          |                  |         |
| 2 EL  | Sonnenblumenöl  |        |          |                  |         |
| 3 EL  | Sojasauce       | Sauce  |          |                  |         |
| 2 EL  | Ahornsirup      | Sauce  |          |                  |         |
| 1 EL  | Reisessig       | Sauce  |          |                  |         |
| 1     | Knoblauch       | Sauce  |          | Zehen, gepresst  |         |
| 1 TL  | Ingwer          | Sauce  |          | frisch gerieben  |         |
| 1 TL  | Süße Chilisauce | Sauce  |          |                  |         |
| 1 TL  | Sesamöl         | Sauce  |          |                  |         |
| 1 TL  | Sesam           |        |          |                  |         |
| 150 g | Reis            |        |          |                  | Menge   |
| 1     | Brokkoli        |        |          | in Röschen       | Menge   |

## Zubereitung

1. Tofu trocken pressen, in 2 cm große Würfel schneiden. Sauce aus Sojasauce, Ahornsirup, Essig, Knoblauch, Ingwer, Chilisauce und Sesamöl anrühren. Tofu 30 Minuten darin marinieren. ⏱ 30
2. Reis nach Packungsangabe garen. ⏱ 12
3. Tofu aus der Marinade nehmen (Marinade aufheben), in Speisestärke wenden.
4. Öl in einer Pfanne erhitzen, Tofu 8 bis 10 Minuten rundum knusprig braten. ⏱ 8
5. Brokkoli 4 Minuten in Salzwasser blanchieren oder dämpfen. ⏱ 4
6. Restliche Marinade in die Pfanne geben, 2 Minuten einkochen, bis sie klebrig glänzt, Tofu darin wenden.
7. Mit Reis und Brokkoli anrichten, mit Sesam bestreuen.

## Notizen

Mit Backofen: Tofu bei 220 °C 25 Minuten backen, dann mit Sauce vermengen.
