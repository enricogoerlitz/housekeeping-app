# Gemüse Pasta

![Gemüse Pasta](../pictures/gemuese-pasta.jpg)

Bandnudeln mit gebratener Zucchini, Zwiebel und aromatischem Tomatenöl.

## Zutaten

| Menge      | Zutat       | Gruppe | Variante      | Hinweis            | Einkauf |
| ---------- | ----------- | ------ | ------------- | ------------------ | ------- |
| 250 g      | Tagliatelle |        |               |                    |         |
| 2          | Zucchini    |        |               | in dicken Scheiben | Menge   |
| 1          | Zwiebel     |        |               | in Streifen        | Menge   |
| 2          | Knoblauch   |        |               | Zehen              | Menge   |
| 1 EL       | Tomatenmark |        |               |                    |         |
| 5 EL       | Olivenöl    |        |               |                    |         |
| 4          | Sardellen   |        | Mit Sardellen | in Öl              | 1×      |
| 1 Handvoll | Basilikum   |        |               |                    |         |
| 50 g       | Parmesan    |        |               | gerieben           | 1×      |
|            | Salz        |        |               |                    |         |
|            | Pfeffer     |        |               |                    |         |

## Zubereitung

1. Zucchinischeiben in 3 EL Olivenöl bei hoher Hitze von beiden Seiten 3 Minuten goldbraun braten, salzen, herausnehmen. ⏱ 6
2. Zwiebel im restlichen Öl 5 Minuten weich braten. ⏱ 5
3. [Mit Sardellen] Sardellen darin auflösen.
4. Knoblauch und Tomatenmark 1 Minute mitrösten.
5. Nudeln in Salzwasser bissfest kochen, 1 Tasse Nudelwasser abnehmen. ⏱ 10
6. Nudeln mit Zucchini und Nudelwasser in der Pfanne schwenken, bis ein glänzender Film entsteht.
7. Mit Basilikum und Parmesan servieren.
