# Zimtschnecken

![Zimtschnecken](../pictures/zimtschnecken.jpg)

Fluffige schwedische Zimtschnecken mit Kardamom, Zimt-Zucker-Füllung und Frischkäse-Guss.

## Zutaten

| Menge  | Zutat          | Gruppe  | Variante | Hinweis              | Einkauf |
| ------ | -------------- | ------- | -------- | -------------------- | ------- |
| 300 g  | Mehl           | Teig    |          |                      |         |
| 150 ml | Milch          | Teig    |          | lauwarm              |         |
| 1      | Hefe           | Teig    |          | Päckchen Trockenhefe |         |
| 40 g   | Zucker         | Teig    |          |                      |         |
| 50 g   | Butter         | Teig    |          | weich                |         |
| 1      | Eier           | Teig    |          |                      |         |

| 1 TL   | Salz           | Teig    |          |                      |         |
| 60 g   | Butter         | Füllung |          | weich                |         |
| 60 g   | Brauner Zucker | Füllung |          |                      |         |
| 2 EL   | Zimt           | Füllung |          |                      |         |

| 80 g   | Puderzucker    | Guss    |          |                      |         |
| 1 EL   | Milch          | Guss    |          |                      |         |

## Zubereitung

1. Mehl, Hefe, Zucker, Kardamom und Salz mischen, Milch, Ei und weiche Butter zugeben und 10 Minuten zu einem glatten Teig kneten.
2. Abgedeckt 1 Stunde gehen lassen, bis sich das Volumen verdoppelt. ⏱ 60
3. Teig zu einem Rechteck (30 x 40 cm) ausrollen, mit weicher Butter bestreichen, Zimt und braunen Zucker darauf verteilen.
4. Von der langen Seite aufrollen und in 8 gleich dicke Stücke schneiden.
5. Schnecken in eine gefettete Form (oder Pfanne) legen und 20 Minuten gehen lassen. ⏱ 20
6. Bei 200 °C Ober-/Unterhitze 15 bis 18 Minuten goldbraun backen. ⏱ 16
7. Frischkäse, Puderzucker und Milch glatt rühren und auf die warmen Schnecken streichen.

## Notizen

Ergibt etwa 8 Schnecken; das passt zu 2 Personen mit Resten für den nächsten Tag. Foto zeigt Schnecken mit dickem hellen Guss in runder Pfanne.
