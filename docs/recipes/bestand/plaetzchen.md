# Plätzchen

![Plätzchen](../pictures/plaetzchen.jpg)

Klassische Mürbeteig-Plätzchen zum Ausstechen.

## Zutaten

| Menge   | Zutat         | Gruppe | Variante | Hinweis          | Einkauf |
| ------- | ------------- | ------ | -------- | ---------------- | ------- |
| 300 g   | Mehl          |        |          |                  | 1×      |
| 100 g   | Zucker        |        |          |                  | 1×      |
| 200 g   | Butter        |        |          | kalt, in Stücken | 1×      |
| 1       | Ei            |        |          |                  | 1×      |
| 1 Pck.  | Vanillezucker |        |          |                  |         |
| 1 Prise | Salz          |        |          |                  |         |
|         | Puderzucker   |        |          | zum Bestäuben    |         |

## Zubereitung

1. Mehl, Zucker, Vanillezucker, Salz, Butter und Ei rasch zu einem Mürbeteig verkneten, in Folie 1 Stunde kühlen. ⏱ 60
2. Ofen auf 180 °C Ober-/Unterhitze vorheizen.
3. Teig 4 mm dick ausrollen, Plätzchen ausstechen und auf ein mit Backpapier belegtes Blech setzen.
4. 10 bis 12 Minuten goldgelb backen, auf einem Gitter abkühlen lassen und bestäuben. ⏱ 12

## Notizen

Im Bestand nur der Titel, daher Grundrezept für Ausstecherle. Gang als Dessert gesetzt. Bei Bedarf Zimt, Zitronenabrieb oder Schokoglasur ergänzen.
