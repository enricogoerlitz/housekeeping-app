# Fondant Kartoffeln

![Fondant Kartoffeln](../pictures/fondant-kartoffeln.jpg)

Dicke Kartoffelzylinder, außen goldbraun gebraten und in Butter und Brühe butterweich geschmort, mit Schnittlauch bestreut. Eine elegante Beilage zu Fisch und Fleisch.

## Zutaten

| Menge  | Zutat          | Gruppe | Variante | Hinweis                                                      | Einkauf |
| ------ | -------------- | ------ | -------- | ------------------------------------------------------------ | ------- |
| 4      | Kartoffeln     |        |          | groß, festkochend, geschält, 4 cm dick Zylinder ausgestochen |         |
| 2 EL   | Sonnenblumenöl |        |          |                                                              |         |
| 40 g   | Butter         |        |          |                                                              |         |
| 2      | Knoblauch      |        |          | Zehen, angedrückt                                            |         |
| 3      | Thymian        |        |          | Zweige                                                       |         |
| 200 ml | Gemüsebrühe    |        |          | heiß                                                         |         |
| 1 Bund | Schnittlauch   |        |          | in feine Röllchen                                            |         |
|        | Salz           |        |          |                                                              |         |

## Zubereitung

1. Kartoffeln schälen, Enden gerade abschneiden und in etwa 4 cm hohe, gleichmäßige Zylinder schneiden oder ausstechen.
2. Öl in einer ofenfesten Pfanne erhitzen und die Kartoffeln auf einer Seite 6 Minuten goldbraun braten. ⏱ 6
3. Wenden, Butter, Knoblauch und Thymian zugeben und 3 Minuten weiter braten, dabei die Butter über die Kartoffeln löffeln. ⏱ 3
4. Heiße Brühe zugießen, bis die Kartoffeln zur Hälfte bedeckt sind, salzen.
5. Bei 200 °C Ober-/Unterhitze 20 Minuten im Ofen garen, bis die Brühe fast verkocht ist und eine Gabel leicht einsticht. ⏱ 20
6. Mit dem Bratensud glasieren und mit Schnittlauch bestreuen.

## Notizen

Das Foto zeigt zwei Kartoffelzylinder. Für 2 Personen reichen 4 Stück, damit jeder 2 hat. Schalen und Abschnitte als Püree oder Ofenkartoffeln verwerten.
