# Gnocchi Panna e Prosciutto

![Gnocchi Panna e Prosciutto](../pictures/gnocchi-panna-e-prosciutto.jpg)

Gnocchi in Sahnesauce mit feinen Schinkenstreifen, in zwanzig Minuten fertig.

## Zutaten

| Menge   | Zutat        | Gruppe | Variante     | Hinweis        | Einkauf |
| ------- | ------------ | ------ | ------------ | -------------- | ------- |
| 500 g   | Gnocchi      |        |              | Kühlregal      |         |
| 200 ml  | Sahne        |        |              |                | 1×      |
| 100 g   | Kochschinken |        | Mit Schinken | in Streifen    | Menge   |
| 100 g   | Erbsen       |        | Vegetarisch  | TK             | Menge   |
| 1       | Schalotte    |        |              | fein gewürfelt | Menge   |
| 1 EL    | Butter       |        |              |                |         |
| 40 g    | Parmesan     |        |              | gerieben       | 1×      |
| 1 Prise | Muskat       |        |              |                |         |
|         | Salz         |        |              |                |         |
|         | Pfeffer      |        |              |                |         |

## Zubereitung

1. Schalotte in Butter 3 Minuten glasig dünsten. ⏱ 3
2. [Mit Schinken] Schinkenstreifen kurz mitbraten.
3. Sahne angießen, 3 Minuten einkochen, mit Muskat, Salz und Pfeffer würzen. ⏱ 3
4. Gnocchi in Salzwasser garen, bis sie oben schwimmen (2 Minuten), abtropfen lassen. ⏱ 2
5. Gnocchi in die Sauce geben.
6. [Vegetarisch] Erbsen in die Sauce geben.
7. Parmesan unterrühren und 1 Minute ziehen lassen.

## Notizen

Titel stand mit Tippfehler ("Gnocci"), korrigiert. Prosciutto cotto = Kochschinken.
