# Basilikum Pesto

![Basilikum Pesto](../pictures/basilikum-pesto.jpg)

Klassisches Pesto alla Genovese aus frischem Basilikum, Pinienkernen und Parmesan, ideal für Pasta, Brot und Salate.

## Zutaten

| Menge   | Zutat       | Gruppe | Variante | Hinweis           | Einkauf |
| ------- | ----------- | ------ | -------- | ----------------- | ------- |
| 2 Töpfe | Basilikum   |        |          | Blätter abgezupft | Menge   |
| 40 g    | Pinienkerne |        |          | kurz geröstet     | 1×      |
| 50 g    | Parmesan    |        |          | fein gerieben     | 1×      |
| 1       | Knoblauch   |        |          | Zehe              | 1×      |
| 100 ml  | Olivenöl    |        |          | mild              | 1×      |
|         | Salz        |        |          |                   |         |
|         | Pfeffer     |        |          |                   |         |

## Zubereitung

1. Pinienkerne in einer trockenen Pfanne 2 Minuten goldbraun rösten und abkühlen lassen. ⏱ 2
2. Basilikumblätter, Pinienkerne, Knoblauch und Parmesan im Mixer oder Mörser grob zerkleinern.
3. Olivenöl in dünnem Strahl untermixen, bis eine cremige Paste entsteht; mit Salz und Pfeffer abschmecken.
4. In ein sauberes Glas füllen und mit einer dünnen Ölschicht bedecken.

## Notizen

Hält im Kühlschrank etwa eine Woche. Pinienkerne lassen sich durch Cashews oder Sonnenblumenkerne ersetzen. Gang bewusst als Beilage gesetzt, bestehender Eintrag stand unter Hauptgericht.
