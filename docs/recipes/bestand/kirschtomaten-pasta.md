# Kirschtomaten-Pasta

![Kirschtomaten-Pasta](../pictures/kirschtomaten-pasta.jpg)

Spaghetti mit aufgeplatzten Kirschtomaten, Knoblauch und frischem Basilikum.

## Zutaten

| Menge      | Zutat         | Gruppe | Variante     | Hinweis             | Einkauf |
| ---------- | ------------- | ------ | ------------ | ------------------- | ------- |
| 250 g      | Spaghetti     |        |              |                     |         |
| 400 g      | Kirschtomaten |        |              | halbiert            | Menge   |
| 3          | Knoblauch     |        |              | Zehen, in Scheiben  | Menge   |
| 4 EL       | Olivenöl      |        |              |                     |         |
| 1 Handvoll | Basilikum     |        |              |                     |         |
| 40 g       | Parmesan      |        |              | gerieben            | 1×      |
| 200 g      | Garnelen      |        | Mit Garnelen | geschält, aufgetaut | Menge   |
|            | Salz          |        |              |                     |         |
|            | Pfeffer       |        |              |                     |         |

## Zubereitung

1. Olivenöl mit Knoblauch bei mittlerer Hitze erwärmen, bis der Knoblauch duftet. ⏱ 2
2. Kirschtomaten zugeben, mit Salz würzen und 10 Minuten schmoren, bis sie platzen. ⏱ 10
3. [Mit Garnelen] Garnelen 2 Minuten mitbraten. ⏱ 2
4. Spaghetti in Salzwasser bissfest kochen, Nudelwasser aufheben. ⏱ 10
5. Nudeln mit Nudelwasser in die Sauce geben, schwenken, Basilikum und Parmesan unterheben.

## Notizen

Foto zeigt rote und gelbe Kirschtomaten, eine Mischung macht das Gericht bunter.
