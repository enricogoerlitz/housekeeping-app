# Brokkoli Sahne Pasta

![Brokkoli Sahne Pasta](../pictures/brokkoli-sahne-pasta.jpg)

Schnelle Pasta mit zartem Brokkoli in cremiger Parmesan-Sahnesauce. Ein Gericht aus einem Topf und einer Pfanne in 25 Minuten.

## Zutaten

| Menge   | Zutat        | Gruppe | Variante     | Hinweis                                   | Einkauf |
| ------- | ------------ | ------ | ------------ | ----------------------------------------- | ------- |
| 250 g   | Penne        |        |              |                                           | Menge   |
| 400 g   | Brokkoli     |        |              | in kleine Röschen                         | Menge   |
| 2       | Knoblauch    |        |              | Zehen, gehackt                            | Menge   |
| 200 ml  | Sahne        |        |              |                                           | Menge   |
| 50 g    | Parmesan     |        |              | frisch gerieben, plus etwas zum Servieren | Menge   |
| 1       | Zitrone      |        |              | Abrieb und 1 EL Saft                      | Menge   |
| 100 g   | Kochschinken |        | Mit Schinken | in Streifen                               | Menge   |
| 1 EL    | Olivenöl     |        |              |                                           | 1×      |
| 1 Prise | Muskat       |        |              |                                           | 1×      |
| 1 Prise | Chiliflocken |        |              | optional                                  | 1×      |
|         | Salz         |        |              |                                           | 1×      |
|         | Pfeffer      |        |              |                                           | 1×      |

## Zubereitung

1. Reichlich Salzwasser aufkochen. Penne nach Packungsangabe kochen und die Brokkoliröschen in den letzten 4 Minuten mitgaren. 1 Tasse Nudelwasser abnehmen, dann abgießen. ⏱ 10
2. Olivenöl in einer großen Pfanne erhitzen.
3. [Mit Schinken] Schinkenstreifen darin 2 Minuten anbraten. ⏱ 2
4. Knoblauch 30 Sekunden anschwitzen, mit Sahne ablöschen und 3 Minuten leicht einkochen lassen. ⏱ 3
5. Parmesan, Zitronenabrieb, Zitronensaft, Muskat, Chili, Salz und Pfeffer einrühren.
6. Nudeln und Brokkoli in die Sauce geben, mit etwas Nudelwasser cremig schwenken.
7. Mit Parmesan und Pfeffer servieren.

## Notizen

Ein Teil des Brokkolis darf leicht zerfallen, das macht die Sauce sämiger. Statt Schinken passen auch geröstete Mandelblättchen.
