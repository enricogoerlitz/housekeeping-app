# Ofen Spitzkohl mit Bohnen und Miso

![Ofen Spitzkohl mit Bohnen und Miso](../pictures/ofen-spitzkohl-mit-bohnen-und-miso.jpg)

Im Ofen gebackener Spitzkohl mit weißen Bohnen, Champignons und einer cremigen Miso-Sauce – vegetarisch und herzhaft.

## Zutaten

| Menge  | Zutat        | Gruppe | Variante | Hinweis                | Einkauf |
| ------ | ------------ | ------ | -------- | ---------------------- | ------- |
| 1      | Spitzkohl    |        |          | in 4 Spalten           | Menge   |
| 1 Dose | Weiße Bohnen |        |          | abgetropft             | 1×      |
| 200 g  | Champignons  |        |          | halbiert               | Menge   |
| 1      | Zwiebeln     |        |          | in Spalten             |         |
| 2      | Knoblauch    |        |          | Zehen                  |         |
| 3 EL   | Olivenöl     |        |          |                        |         |
| 2 EL   | Miso-Paste   | Sauce  |          | hell                   |         |
| 200 ml | Sahne        | Sauce  |          | oder pflanzliche Sahne |         |
| 200 ml | Gemüsebrühe  | Sauce  |          |                        |         |
| 1 EL   | Zitronen     | Sauce  |          | Saft                   |         |
| 1 Bund | Schnittlauch |        |          | in Röllchen            |         |
| 1 TL   | Salz         |        |          |                        |         |

## Zubereitung

1. Ofen auf 200 °C Umluft vorheizen.
2. Spitzkohl-Spalten in einer großen ofenfesten Pfanne in Olivenöl von beiden Schnittseiten 3 Minuten je Seite kräftig anbraten, herausnehmen.
3. Champignons, Zwiebel und Knoblauch in derselben Pfanne 5 Minuten anbraten, Bohnen zugeben.
4. Miso mit Brühe, Sahne und Zitronensaft glatt rühren und in die Pfanne gießen.
5. Kohl zurücklegen und 25 Minuten im Ofen garen, bis er weich und gebräunt ist. ⏱ 25
6. Mit Schnittlauch bestreuen.

## Notizen

Miso-Paste gibt es im Asia-Laden oder Bio-Regal; nie kochen, nur erwärmen, damit sie ihren Geschmack behält. Schmeckt mit Baguette.
