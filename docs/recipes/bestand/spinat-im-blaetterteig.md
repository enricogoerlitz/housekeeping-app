# Spinat im Blätterteig

![Spinat im Blätterteig](../pictures/spinat-im-blaetterteig.jpg)

Blätterteig-Taschen mit cremiger Spinat-Feta-Füllung.

## Zutaten

| Menge   | Zutat        | Gruppe | Variante     | Hinweis                       | Einkauf |
| ------- | ------------ | ------ | ------------ | ----------------------------- | ------- |
| 1 Rolle | Blätterteig  |        |              | Kühlregal, 270 g              | 1×      |
| 300 g   | Blattspinat  |        |              | TK, aufgetaut und ausgedrückt | Menge   |
| 150 g   | Feta         |        |              | zerbröselt                    | 1×      |
| 1       | Zwiebel      |        |              | fein gewürfelt                | Menge   |
| 1       | Knoblauch    |        |              | Zehe                          | 1×      |
| 1       | Ei           |        |              | zum Bestreichen               | 1×      |
| 100 g   | Kochschinken |        | Mit Schinken | gewürfelt                     | Menge   |
| 1 Prise | Muskat       |        |              |                               |         |
|         | Salz         |        |              |                               |         |
|         | Pfeffer      |        |              |                               |         |

## Zubereitung

1. Zwiebel und Knoblauch in etwas Öl 3 Minuten dünsten, Spinat zugeben und 3 Minuten braten. ⏱ 6
2. Abkühlen lassen, mit Feta, Muskat, Salz und Pfeffer vermischen.
3. [Mit Schinken] Schinken untermischen.
4. Ofen auf 200 °C Ober-/Unterhitze vorheizen. Blätterteig ausrollen und in 4 Quadrate schneiden.
5. Füllung mittig verteilen, zu Dreiecken zusammenklappen und die Ränder mit der Gabel andrücken.
6. Mit verquirltem Ei bestreichen und 20 Minuten goldbraun backen. ⏱ 20
