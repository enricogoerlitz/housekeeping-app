# Karottenkuchen

![Karottenkuchen](../pictures/karottenkuchen.jpg)

Saftiger Karottenkuchen mit Walnüssen und Frischkäse-Frosting.

## Zutaten

| Menge  | Zutat          | Gruppe   | Variante | Hinweis       | Einkauf |
| ------ | -------------- | -------- | -------- | ------------- | ------- |
| 4      | Eier           | Teig     |          |               | 1×      |
| 200 g  | Zucker         | Teig     |          |               | 1×      |
| 200 ml | Öl             | Teig     |          |               | 1×      |
| 250 g  | Mehl           | Teig     |          |               | 1×      |
| 2 TL   | Backpulver     | Teig     |          |               |         |
| 2 TL   | Zimt           | Teig     |          |               |         |
| 300 g  | Karotte        | Teig     |          | fein gerieben | Menge   |
| 100 g  | Walnüsse       | Teig     |          | gehackt       | 1×      |
| 200 g  | Frischkäse     | Frosting |          | Doppelrahm    | 1×      |
| 100 g  | Butter         | Frosting |          | weich         | 1×      |
| 150 g  | Puderzucker    | Frosting |          |               | 1×      |
| 1 TL   | Vanilleextrakt | Frosting |          |               |         |
|        | Salz           |          |          |               |         |

## Zubereitung

1. Ofen auf 175 °C Ober-/Unterhitze vorheizen, eine Springform (22 cm) fetten.
2. Eier und Zucker 5 Minuten schaumig schlagen, Öl einrühren. ⏱ 5
3. Mehl, Backpulver, Zimt und Salz mischen und unterheben, dann Karotten und die Hälfte der Walnüsse einrühren.
4. Teig in die Form füllen und 40 bis 45 Minuten backen (Stäbchenprobe). ⏱ 45
5. Kuchen vollständig auskühlen lassen und einmal waagerecht halbieren.
6. Butter, Frischkäse, Puderzucker und Vanille zum Frosting verrühren. Kuchen füllen, außen bestreichen und mit den restlichen Walnüssen dekorieren.
