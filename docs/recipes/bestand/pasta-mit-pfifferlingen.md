# Pasta mit Pfifferlingen

![Pasta mit Pfifferlingen](../pictures/pasta-mit-pfifferlingen.jpg)

Breite Bandnudeln mit goldbraun gebratenen Pfifferlingen in cremiger Sahnesauce und frischer Petersilie.

## Zutaten

| Menge    | Zutat        | Gruppe | Variante  | Hinweis                 | Einkauf |
| -------- | ------------ | ------ | --------- | ----------------------- | ------- |
| 250 g    | Tagliatelle  |        |           |                         | Menge   |
| 300 g    | Pfifferlinge |        |           | geputzt, große halbiert | Menge   |
| 2        | Schalotten   |        |           | fein gewürfelt          | Menge   |
| 1        | Knoblauch    |        |           | Zehe, gehackt           | Menge   |
| 80 g     | Speckwürfel  |        | Mit Speck |                         | Menge   |
| 50 ml    | Weißwein     |        |           | oder Brühe              | 1×      |
| 200 ml   | Sahne        |        |           |                         | Menge   |
| 2 EL     | Butter       |        |           |                         | 1×      |
| 1/2 Bund | Petersilie   |        |           | gehackt                 | 1×      |
| 30 g     | Parmesan     |        |           | gerieben                | Menge   |
|          | Salz         |        |           |                         | 1×      |
|          | Pfeffer      |        |           |                         | 1×      |

## Zubereitung

1. Tagliatelle in Salzwasser al dente kochen, 1 Tasse Nudelwasser abnehmen, abgießen. ⏱ 9
2. [Mit Speck] Speck in einer großen Pfanne ohne Fett 4 Minuten auslassen. ⏱ 4
3. Butter in der Pfanne erhitzen, Pfifferlinge bei hoher Hitze 6 Minuten braten, bis sie goldbraun sind und das Wasser verdampft ist. ⏱ 6
4. Schalotten und Knoblauch 2 Minuten mitbraten, mit Wein ablöschen und einkochen lassen. ⏱ 2
5. Sahne zugießen, 4 Minuten sämig einkochen, salzen und pfeffern. ⏱ 4
6. Nudeln in der Sauce schwenken, mit Nudelwasser lockern, Petersilie und Parmesan unterrühren.

## Notizen

Pfifferlinge nicht waschen, nur mit Pinsel oder Tuch putzen. Außerhalb der Saison (Juni bis Oktober) auf Champignons oder TK-Pfifferlinge ausweichen.
