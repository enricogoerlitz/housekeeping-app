# Quark Kuchen

![Quark Kuchen](../pictures/quark-kuchen.jpg)

Fluffiger Quarkkuchen mit Mandarinen, außen goldbraun und mit Puderzucker bestäubt, innen cremig-luftig.

## Zutaten

| Menge  | Zutat          | Gruppe | Variante | Hinweis                   | Einkauf |
| ------ | -------------- | ------ | -------- | ------------------------- | ------- |
| 250 g  | Quark          |        |          | 40 %                      | Menge   |
| 2      | Eier           |        |          | getrennt                  |         |
| 70 g   | Zucker         |        |          |                           |         |
| 1      | Vanillezucker  |        |          | Päckchen                  |         |
| 50 ml  | Sonnenblumenöl |        |          |                           |         |
| 40 g   | Puddingpulver  |        |          | Vanille                   |         |
| 80 g   | Mehl           |        |          |                           |         |
| 1 TL   | Backpulver     |        |          |                           |         |
| 1 Dose | Mandarinen     |        |          | klein (175 g), abgetropft | 1×      |
| 1 EL   | Puderzucker    |        |          | zum Bestäuben             |         |

## Zubereitung

1. Ofen auf 180 °C Ober-/Unterhitze vorheizen, eine Form (20 x 20 cm) mit Backpapier auslegen.
2. Eigelb mit Zucker und Vanillezucker schaumig rühren, Quark und Öl einrühren.
3. Mehl, Puddingpulver und Backpulver mischen und unterrühren.
4. Eiweiß steif schlagen und vorsichtig unter die Masse heben.
5. Teig in die Form füllen und die Mandarinenstücke darauf verteilen.
6. 35 bis 40 Minuten backen, bis der Kuchen goldbraun ist. ⏱ 38
7. Abkühlen lassen und mit Puderzucker bestäuben.
