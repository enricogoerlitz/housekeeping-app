# Zitronenkuchen

![Zitronenkuchen](../pictures/zitronenkuchen.jpg)

Saftiger Rührkuchen mit viel Zitrone und weißem Zuckerguss. Hält sich abgedeckt 3 Tage.

## Zutaten

| Menge      | Zutat         | Gruppe | Variante | Hinweis                  | Einkauf |
| ---------- | ------------- | ------ | -------- | ------------------------ | ------- |
| 200 g      | Butter        | Teig   |          | weich                    |         |
| 180 g      | Zucker        | Teig   |          |                          |         |
| 1 Päckchen | Vanillezucker | Teig   |          |                          |         |
| 4          | Eier          | Teig   |          |                          |         |
| 250 g      | Weizenmehl    | Teig   |          |                          |         |
| 2 TL       | Backpulver    | Teig   |          |                          |         |
| 3          | Zitronen      | Teig   |          | Abrieb von 3, Saft von 2 |         |
| 100 ml     | Milch         | Teig   |          |                          |         |
| 1 Prise    | Salz          | Teig   |          |                          |         |
| 150 g      | Puderzucker   | Guss   |          |                          |         |
| 2 EL       | Zitronen      | Guss   |          | Saft                     |         |

## Zubereitung

1. Backofen auf 175 °C Ober-/Unterhitze vorheizen, eine Kastenform (25 cm) einfetten und bemehlen.
2. Butter, Zucker, Vanillezucker und Salz 4 Minuten cremig rühren, Eier einzeln unterrühren.
3. Mehl mit Backpulver mischen und abwechselnd mit Milch, Zitronensaft und -abrieb unterheben.
4. Teig in die Form füllen und 50 bis 55 Minuten backen, bis ein Holzstäbchen sauber bleibt. ⏱ 52
5. 10 Minuten in der Form ruhen lassen, stürzen und vollständig auskühlen lassen.
6. Puderzucker mit Zitronensaft glatt rühren und über den Kuchen gießen. Antrocknen lassen.

## Notizen

Bio-Zitronen verwenden, wenn die Schale abgerieben wird.
