# Kaiserschmarren

![Kaiserschmarren](../pictures/kaiserschmarren.jpg)

Fluffiger Pfannkuchenteig, in der Pfanne gebacken, zerrissen und mit Butter und Zucker karamellisiert. Mit Puderzucker bestäubt und Zwetschgenmus serviert. Als süßes Hauptgericht vegetarisch.

## Zutaten

| Menge      | Zutat         | Gruppe | Variante | Hinweis                      | Einkauf |
| ---------- | ------------- | ------ | -------- | ---------------------------- | ------- |
| 4          | Eier          |        |          | getrennt                     |         |
| 150 g      | Weizenmehl    |        |          |                              |         |
| 250 ml     | Milch         |        |          |                              |         |
| 2 EL       | Zucker        |        |          |                              |         |
| 1 Päckchen | Vanillezucker |        |          |                              |         |
| 1 Prise    | Salz          |        |          |                              |         |
| 50 g       | Rosinen       |        |          | in Rum oder Saft eingeweicht |         |
| 30 g       | Butter        |        |          | zum Braten                   |         |
| 2 EL       | Puderzucker   |        |          | zum Bestäuben                |         |
| 200 g      | Pflaumenmus   |        |          | oder Apfelmus                |         |

## Zubereitung

1. Eigelb, Mehl, Milch, Zucker, Vanillezucker und Salz glatt verrühren, 10 Minuten quellen lassen. ⏱ 10
2. Eiweiß mit einer Prise Salz steif schlagen und vorsichtig unter den Teig heben.
3. Butter in einer großen Pfanne (28 cm) bei mittlerer Hitze schmelzen, Teig hineingießen und Rosinen daraufstreuen.
4. 3 bis 4 Minuten backen, bis die Unterseite goldbraun ist. Vierteln, wenden und weitere 3 Minuten backen. ⏱ 7
5. Mit zwei Gabeln in mundgerechte Stücke zerreißen und 2 Minuten in Butter karamellisieren, mit 1 EL Zucker bestreuen.
6. Mit Puderzucker bestäuben und mit Zwetschgenmus servieren.

## Notizen

Die Pfanne nicht zu heiß werden lassen, sonst wird der Schmarren außen dunkel und innen roh.
