# Brokkoli Pasta

![Brokkoli Pasta](../pictures/brokkoli-pasta.jpg)

Orecchiette in einer cremigen Brokkolisauce mit knusprigen Pancetta-Würfeln und gerösteten Semmelbröseln.

## Zutaten

| Menge | Zutat        | Gruppe | Variante     | Hinweis                | Einkauf |
| ----- | ------------ | ------ | ------------ | ---------------------- | ------- |
| 250 g | Orecchiette  |        |              |                        |         |
| 500 g | Brokkoli     |        |              | in Röschen             | Menge   |
| 2     | Knoblauch    |        |              | Zehen                  | Menge   |
| 1     | Chilischote  |        |              | getrocknet oder frisch | 1×      |
| 50 g  | Parmesan     |        |              | gerieben               | 1×      |
| 3 EL  | Olivenöl     |        |              |                        |         |
| 2 EL  | Semmelbrösel |        |              |                        |         |
| 100 g | Speck        |        | Mit Pancetta | Pancetta, gewürfelt    | Menge   |
|       | Salz         |        |              |                        |         |
|       | Pfeffer      |        |              |                        |         |

## Zubereitung

1. Brokkoli in kräftig gesalzenem Wasser 8 Minuten kochen, 4 Röschen zum Garnieren beiseitelegen, den Rest mit etwas Kochwasser pürieren. ⏱ 8
2. Garnierröschen in heißem Öl rösten, bis sie leicht schwarz werden.
3. [Mit Pancetta] Pancetta ohne Fett knusprig braten und herausnehmen. ⏱ 6
4. Semmelbrösel im Pancetta-Fett oder Olivenöl goldbraun rösten. ⏱ 3
5. Orecchiette im Brokkolikochwasser bissfest garen. ⏱ 11
6. Knoblauch und Chili in Öl anschwitzen, Brokkolipüree und Nudeln zugeben, mit Parmesan und Nudelwasser cremig schwenken.
7. Mit Pancetta, Bröseln und Röschen anrichten.

## Notizen

Parmesan ist nicht vegetarisch (Lab). Für die vegetarische Variante Grana Padano oder Hartkäse ohne tierisches Lab verwenden.
