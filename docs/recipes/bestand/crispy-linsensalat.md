# Crispy Linsensalat

![Crispy Linsensalat](../pictures/crispy-linsensalat.jpg)

Herzhafter Linsensalat mit Rotkohl, Avocado und frischen Kräutern, getoppt mit knusprigen Röstzwiebeln.

## Zutaten

| Menge  | Zutat        | Gruppe   | Variante | Hinweis               | Einkauf |
| ------ | ------------ | -------- | -------- | --------------------- | ------- |
| 200 g  | Belugalinsen |          |          |                       | Menge   |
| 0,25   | Rotkohl      |          |          | sehr fein gehobelt    |         |
| 1      | Avocado      |          |          | gewürfelt             |         |
| 1      | Paprika      |          |          | rot, fein gewürfelt   |         |
| 1      | Gurke        |          |          | fein gewürfelt        |         |
| 1 Bund | Petersilie   |          |          | grob gehackt          |         |
| 1 Bund | Koriander    |          |          | grob gehackt          |         |
| 3 EL   | Röstzwiebeln |          |          | zum Toppen            |         |
| 4 EL   | Olivenöl     | Dressing |          |                       |         |
| 3 EL   | Zitronen     | Dressing |          | Saft                  |         |
| 1 EL   | Senf         | Dressing |          |                       |         |
| 1 TL   | Ahornsirup   | Dressing |          |                       |         |
| 1 TL   | Salz         | Dressing |          |                       |         |
| 0,5 TL | Pfeffer      | Dressing |          |                       |         |
| 600 ml | Wasser       |          |          | zum Kochen der Linsen | nie     |

## Zubereitung

1. Linsen abspülen und in Wasser 20 Minuten bissfest kochen, abgießen und abkühlen lassen. ⏱ 20
2. Dressing aus Olivenöl, Zitronensaft, Senf, Ahornsirup, Salz und Pfeffer anrühren.
3. Rotkohl mit einem Teil des Dressings 5 Minuten kneten, damit er weich wird. ⏱ 5
4. Linsen, Paprika, Gurke und Kräuter zufügen und alles mit dem restlichen Dressing mischen.
5. Avocado vorsichtig unterheben und mit Röstzwiebeln bestreuen.

## Notizen

OFFEN: „Crispy“ ist im Foto nicht erkennbar; als Röstzwiebel-Topping interpretiert (Alternative: geröstete Kichererbsen). Linsen aus der Dose (250 g Abtropfgewicht) sparen Zeit.
