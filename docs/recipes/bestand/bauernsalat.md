# Bauernsalat

![Bauernsalat](../pictures/bauernsalat.jpg)

Klassischer Bauernsalat mit Tomaten, Gurke, Paprika, Feta und Oliven – frisch, deftig und in 15 Minuten fertig.

## Zutaten

| Menge  | Zutat         | Gruppe | Variante | Hinweis                    | Einkauf |
| ------ | ------------- | ------ | -------- | -------------------------- | ------- |
| 4      | Tomaten       |        |          | in Stücken                 | Menge   |
| 1      | Gurke         |        |          | in dicken Stücken          |         |
| 1      | Paprika       |        |          | rot oder grün, in Streifen |         |
| 1      | Rote Zwiebeln |        |          | in Ringen                  |         |
| 150 g  | Feta          |        |          | als Block oder gewürfelt   | 1×      |
| 80 g   | Oliven        |        |          | schwarz, entsteint         |         |
| 4 EL   | Olivenöl      |        |          |                            |         |
| 2 EL   | Weißweinessig |        |          |                            |         |
| 1 TL   | Oregano       |        |          | getrocknet                 |         |
| 1 TL   | Salz          |        |          |                            |         |
| 0,5 TL | Pfeffer       |        |          |                            |         |

## Zubereitung

1. Zwiebel in dünne Ringe schneiden und 5 Minuten in kaltem Wasser ziehen lassen, dann abtropfen. ⏱ 5
2. Tomaten, Gurke und Paprika grob würfeln und in eine große Schüssel geben.
3. Zwiebelringe und Oliven zufügen.
4. Olivenöl, Essig, Salz, Pfeffer und Oregano verrühren und über das Gemüse geben, vorsichtig mischen.
5. Feta daraufsetzen, mit Oregano und etwas Olivenöl beträufeln und sofort servieren.

## Notizen

Dazu passt frisches Fladenbrot. Wer es milder mag, nimmt statt Rote Zwiebeln eine halbe weiße.
