# Zucchini mal anders

![Zucchini mal anders](../pictures/zucchini-mal-anders.jpg)

Herzhafter Zucchini-Fladen aus der Pfanne: geriebene Zucchini mit Ei und Mehl, goldbraun gebraten und mit viel geschmolzenem Käse bestreut.

## Zutaten

| Menge | Zutat          | Gruppe | Variante     | Hinweis        | Einkauf |
| ----- | -------------- | ------ | ------------ | -------------- | ------- |
| 400 g | Zucchini       |        |              | grob geraspelt | Menge   |
| 1     | Karotte        |        |              | geraspelt      | Menge   |
| 3     | Eier           |        |              |                | Menge   |
| 3 EL  | Mehl           |        |              |                | 1×      |
| 1     | Knoblauch      |        |              | Zehe, gepresst | Menge   |
| 80 g  | Schinkenwürfel |        | Mit Schinken |                | Menge   |
| 100 g | Gouda          |        |              | gerieben       | Menge   |
| 2 EL  | Öl             |        |              |                | 1×      |
| 150 g | Naturjoghurt   | Dip    |              |                | Menge   |
| 1 EL  | Zitronen       | Dip    |              | Saft           | 1×      |
|       | Salz           |        |              |                | 1×      |
|       | Pfeffer        |        |              |                | 1×      |

## Zubereitung

1. Zucchini mit 1/2 TL Salz mischen, 10 Minuten stehen lassen und gut ausdrücken. ⏱ 10
2. Zucchini, Karotte, Eier, Mehl, Knoblauch, Pfeffer und etwas Salz verrühren.
3. [Mit Schinken] Schinkenwürfel unterheben.
4. Öl in einer großen, beschichteten Pfanne erhitzen, Masse gleichmäßig verteilen und bei mittlerer Hitze 5 Minuten stocken lassen. ⏱ 5
5. Mit Hilfe eines Tellers wenden und 4 Minuten von der anderen Seite braten. ⏱ 4
6. Käse darüberstreuen, Deckel auflegen und 2 Minuten schmelzen lassen. ⏱ 2
7. Joghurt mit Zitronensaft, Salz und Pfeffer verrühren und als Dip dazu reichen.

## Notizen

Die Zucchini unbedingt ausdrücken, sonst wird der Fladen matschig. Kann zusammengeklappt wie ein Omelett serviert werden.
