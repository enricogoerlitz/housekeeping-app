# Zimtschnecke als Apfelstrudel

![Zimtschnecke als Apfelstrudel](../pictures/zimtschnecke-als-apfelstrudel.jpg)

Apfelstrudel im Zimtschnecken-Stil: aufgerollter Blätterteig mit Zimt-Zucker-Butter und Apfelscheiben, in Scheiben aufrecht in eine Form gesetzt und goldbraun gebacken.

## Zutaten

| Menge   | Zutat         | Gruppe | Variante | Hinweis                  | Einkauf |
| ------- | ------------- | ------ | -------- | ------------------------ | ------- |
| 1 Rolle | Blätterteig   |        |          | Kühlregal, ca. 275 g     | 1×      |
| 2       | Äpfel         |        |          | säuerlich, dünn gehobelt | Menge   |
| 40 g    | Butter        |        |          | weich                    | Menge   |
| 3 EL    | Zucker        |        |          |                          | Menge   |
| 2 TL    | Zimt          |        |          |                          | 1×      |
| 1 EL    | Zitronen      |        |          | Saft                     | 1×      |
| 1 Pck.  | Vanillezucker |        |          |                          | 1×      |
| 2 EL    | Puderzucker   |        |          | zum Bestäuben            | 1×      |

## Zubereitung

1. Backofen auf 190 °C Ober-/Unterhitze vorheizen. Eine Kastenform (ca. 25 cm) mit Backpapier auslegen.
2. Äpfel mit Zitronensaft und Vanillezucker mischen. Zucker und Zimt mischen.
3. Blätterteig ausrollen, dünn mit weicher Butter bestreichen und mit Zimtzucker bestreuen.
4. Apfelscheiben dicht auf dem Teig verteilen und den Teig von der langen Seite her fest aufrollen.
5. Rolle in 8 Scheiben von etwa 3 cm schneiden und aufrecht, die Schnittflächen nach oben, dicht in die Form stellen.
6. Im Ofen 30 bis 35 Minuten goldbraun backen. ⏱ 32
7. 10 Minuten abkühlen lassen und mit Puderzucker bestäuben.

## Notizen

Warm mit Vanillesauce oder Eis servieren. Statt Blätterteig geht auch Hefeteig, dann 30 Minuten gehen lassen.
