# Fischstäbchen mit Kartoffelpüree

![Fischstäbchen mit Kartoffelpüree](../pictures/fischstaebchen-mit-kartoffelpueree.jpg)

Knusprige Fischstäbchen mit cremigem Kartoffelpüree und Erbsen, ein Kindheitsklassiker.

| 8       | Gemüse-Stäbchen |        | Vegetarisch       | vegetarisch, TK                     | Menge   |
| 600 g   | Kartoffeln      |        |                   | mehligkochend, geschält, in Stücken | Menge   |

|         | Salz            |        |                   |                                     |         |

## Zubereitung

1. Kartoffeln in Salzwasser 20 Minuten weich kochen. ⏱ 20
2. Fischstäbchen (oder Gemüse-Stäbchen) nach Packung im Ofen oder in der Pfanne knusprig braten. ⏱ 12
3. Kartoffeln abgießen, ausdampfen lassen, mit Butter und warmer Milch stampfen und mit Salz und Muskat würzen.
4. Erbsen 3 Minuten in Salzwasser garen. ⏱ 3
5. Alles anrichten, mit Zitronenspalte servieren.
