# Parmesan Pasta

![Parmesan Pasta](../pictures/parmesan-pasta.jpg)

Pasta in einer glänzenden Sauce aus Parmesan, Butter und Nudelwasser, mit viel schwarzem Pfeffer. Sehr schnell und mit nur wenigen Zutaten.

## Zutaten

| Menge | Zutat       | Gruppe | Variante  | Hinweis               | Einkauf |
| ----- | ----------- | ------ | --------- | --------------------- | ------- |
| 200 g | Linguine    |        |           | oder Spaghetti        | Menge   |
| 80 g  | Parmesan    |        |           | fein gerieben         | Menge   |
| 2 EL  | Butter      |        |           |                       | 1×      |
| 1 TL  | Pfeffer     |        |           | frisch gemahlen, grob | 1×      |
| 100 g | Speckwürfel |        | Mit Speck |                       | Menge   |
|       | Salz        |        |           |                       | 1×      |

## Zubereitung

1. Nudeln in Salzwasser kochen, eine Tasse Nudelwasser abnehmen und abgießen. ⏱ 10
2. [Mit Speck] Speck in einer Pfanne ohne Fett 4 Minuten knusprig braten. ⏱ 4
3. Butter und Pfeffer in der Pfanne 1 Minute anschwitzen, 100 ml Nudelwasser zugießen.
4. Nudeln in die Pfanne geben, Hitze auf niedrig stellen und den Parmesan unter ständigem Schwenken einrühren, bis eine cremige Sauce entsteht.
5. Bei Bedarf mit Nudelwasser lockern und sofort servieren.

## Notizen

Den Parmesan nur bei niedriger Hitze einrühren, sonst klumpt er. Parmesan ist nicht strikt vegetarisch (tierisches Lab).
