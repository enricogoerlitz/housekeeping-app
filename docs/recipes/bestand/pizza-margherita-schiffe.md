# Pizza Margherita Schiffe

![Pizza Margherita Schiffe](../pictures/pizza-margherita-schiffe.jpg)

Längliche, schiffchenförmige Pizza mit dickem Rand, Tomatensauce, schmelzendem Mozzarella und Basilikum. Der 24-Stunden-Teig sorgt für eine luftige, blasige Kruste.

## Zutaten

| Menge    | Zutat             | Gruppe    | Variante   | Hinweis                | Einkauf |
| -------- | ----------------- | --------- | ---------- | ---------------------- | ------- |
| 400 g    | Mehl              | Pizzateig |            |                        | 1×      |
| 280 ml   | Wasser            | Pizzateig |            |                        | nie     |
| 3 g      | Hefe              | Pizzateig |            | frisch                 | Menge   |
| 10 g     | Salz              | Pizzateig |            |                        | 1×      |
| 200 g    | Passierte Tomaten | Belag     |            |                        | Menge   |
| 250 g    | Mozzarella        | Belag     |            | in Stücken, abgetropft | Menge   |
| 1/2 Bund | Basilikum         | Belag     |            |                        | 1×      |
| 100 g    | Salami            | Belag     | Mit Salami | in Scheiben            | Menge   |
| 2 EL     | Olivenöl          | Belag     |            |                        | 1×      |
|          | Salz              |           |            |                        | 1×      |

## Zubereitung

1. Am Vortag: Mehl und Salz mischen, Hefe im Wasser auflösen und alles 8 Minuten zu einem glatten Teig kneten. In zwei Kugeln teilen und abgedeckt 24 Stunden im Kühlschrank gehen lassen.
2. Teigkugeln 1 Stunde vor dem Backen aus dem Kühlschrank nehmen. Backofen samt Backblech auf 250 °C Ober-/Unterhitze vorheizen. ⏱ 60
3. Tomaten mit 1 EL Olivenöl und Salz verrühren.
4. Teig vorsichtig zu einem länglichen Oval ziehen und einen dicken Rand stehen lassen. Mit Tomaten bestreichen.
5. Mozzarella darauf verteilen.
6. [Mit Salami] Salami auflegen.
7. Pizzen auf das heiße Blech schieben und 8 bis 10 Minuten backen, bis der Rand dunkle Flecken hat. ⏱ 9
8. Mit Basilikum und restlichem Olivenöl abschließen.

## Notizen

Der Teig entspricht dem Rezept „Pizzateig (Basis, 24h)“. Ein Pizzastein oder umgedrehtes Backblech sorgt für mehr Hitze von unten.
