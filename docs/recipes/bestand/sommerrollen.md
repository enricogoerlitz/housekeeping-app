# Sommerrollen

![Sommerrollen](../pictures/sommerrollen.jpg)

Frische Reispapier-Rollen mit Gemüse, Mango und Erdnuss-Dip.

## Zutaten

| Menge  | Zutat         | Gruppe | Variante     | Hinweis          | Einkauf |
| ------ | ------------- | ------ | ------------ | ---------------- | ------- |
| 8      | Reispapier    |        |              | Blätter, 22 cm   |         |
| 1      | Gurke         |        |              | in Streifen      | Menge   |
| 1      | Karotte       |        |              | in Streifen      | Menge   |
| 100 g  | Rotkohl       |        |              | fein gehobelt    | Menge   |
| 1      | Mango         |        |              | in Streifen      | Menge   |
| 1      | Avocado       |        |              | in Streifen      | Menge   |
| 1 Bund | Koriander     |        |              |                  |         |
| 100 g  | Reisnudeln    |        |              | gekocht          |         |
| 200 g  | Garnelen      |        | Mit Garnelen | gegart, halbiert | Menge   |
| 3 EL   | Erdnussbutter | Dip    |              |                  | 1×      |
| 2 EL   | Sojasauce     | Dip    |              |                  |         |
| 1 EL   | Limetten      | Dip    |              | Saft             |         |
| 1 EL   | Honig         | Dip    |              |                  |         |
| 2 EL   | Wasser        | Dip    |              | warm             | nie     |

## Zubereitung

1. Reisnudeln nach Packung einweichen und abgießen, Gemüse und Mango in Streifen schneiden. ⏱ 5
2. Dip: Erdnussbutter, Sojasauce, Limettensaft, Honig und Wasser glattrühren.
3. Ein Reispapierblatt 10 Sekunden in warmes Wasser tauchen und auf ein feuchtes Brett legen.
4. Unteres Drittel mit Nudeln, Gemüse, Mango, Avocado und Koriander belegen.
5. [Mit Garnelen] Garnelen darauflegen.
6. Seiten einschlagen und fest aufrollen. Mit dem Dip servieren.

## Notizen

Foto zeigt Gurke, Rotkohl, Mango und Avocado im Reispapier. Rollen nicht abgedeckt lagern, sonst trocknen sie aus.
