# Lachs Pasta Salat

![Lachs Pasta Salat](../pictures/lachs-pasta-salat.jpg)

Kalter Pastasalat mit Penne, Ofenlachs, Rucola und Kirschtomaten in einem cremigen grünen Pesto-Joghurt-Dressing. Die vegetarische Variante nutzt geröstete Kichererbsen.

## Zutaten

| Menge  | Zutat                | Gruppe   | Variante    | Hinweis               | Einkauf |
| ------ | -------------------- | -------- | ----------- | --------------------- | ------- |
| 250 g  | Penne                |          |             |                       | Menge   |
| 250 g  | Lachsfilet           |          | Mit Lachs   | ohne Haut             | Menge   |
| 1 Dose | Kichererbsen         |          | Vegetarisch | ca. 240 g abgetropft  | Menge   |
| 200 g  | Kirschtomaten        |          |             | halbiert              | Menge   |
| 60 g   | Rucola               |          |             |                       | Menge   |
| 3 EL   | Pesto                | Dressing |             |                       | Menge   |
| 150 g  | Naturjoghurt         | Dressing |             |                       | Menge   |
| 1      | Zitrone              | Dressing |             | Saft und etwas Abrieb | Menge   |
| 1 TL   | Italienische Kräuter |          |             | getrocknet            | 1×      |
| 1 EL   | Olivenöl             |          |             |                       | 1×      |
|        | Salz                 |          |             |                       | 1×      |
|        | Pfeffer              |          |             |                       | 1×      |

## Zubereitung

1. Backofen auf 200 °C Ober-/Unterhitze vorheizen.
2. [Mit Lachs] Lachs mit Olivenöl, Salz, Pfeffer und Kräutern würzen und 15 Minuten auf einem Blech backen. Abkühlen lassen und in Stücke zupfen. ⏱ 15
3. [Vegetarisch] Kichererbsen trocknen, mit Olivenöl, Salz und Kräutern mischen und 20 Minuten auf einem Blech rösten. ⏱ 20
4. Penne in Salzwasser al dente kochen, abgießen, kalt abschrecken und abtropfen lassen. ⏱ 10
5. Pesto mit Joghurt, Zitronensaft, Abrieb, Salz und Pfeffer zum Dressing verrühren.
6. Nudeln mit Dressing, Tomaten und Rucola mischen, Lachs beziehungsweise Kichererbsen vorsichtig unterheben.
7. 30 Minuten durchziehen lassen und kühl servieren.

## Notizen

Hält sich im Kühlschrank bis zum nächsten Tag; Rucola erst kurz vor dem Servieren unterheben.
