# Pizza-Dog

![Pizza-Dog](../pictures/pizza-dog.jpg)

Pizzateig wird zum Boot geformt und mit einer ganzen Bratwurst gebacken – Hot Dog trifft Pizzaofen.

## Zutaten

| Menge | Zutat                  | Gruppe | Variante      | Hinweis        | Einkauf |
| ----- | ---------------------- | ------ | ------------- | -------------- | ------- |
| 2     | Pizzateig              |        |               | Kugeln à 140 g | Menge   |
| 2     | Bratwurst              |        | Mit Bratwurst | grob, ganz     | Menge   |
| 2     | Vegetarische Würstchen |        | Vegetarisch   |                | Menge   |
| 60 g  | Mozzarella             |        |               | gerieben       |         |
| 2 EL  | Tomatensauce           |        |               | als Belag/Dip  |         |
| 1 EL  | Olivenöl               |        |               |                |         |

## Zubereitung

1. Ofen mit Blech oder Pizzastein auf 250 °C vorheizen, mindestens 30 Minuten. ⏱ 30
2. [Mit Bratwurst] Bratwürste in der Pfanne 8 Minuten rundum bräunen, damit sie fast gar sind. ⏱ 8
3. Pizzateigkugeln länglich zu Ovalen (28 cm) ausziehen.
4. Wurst in die Mitte legen, die langen Teigränder links und rechts zur Mitte klappen und an den Enden zusammendrücken, sodass ein Boot entsteht. Teig mit Olivenöl bepinseln.
5. Mozzarella in die Lücke zwischen Wurst und Teig streuen.
6. Boote 8 bis 10 Minuten backen, bis der Teig Blasen hat und angeröstet ist. ⏱ 9
7. Mit Tomatensauce zum Dippen servieren.

## Notizen
