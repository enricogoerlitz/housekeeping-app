# Involtini di Melanzane

![Involtini di Melanzane](../pictures/involtini-di-melanzane.jpg)

Gegrillte Auberginenscheiben, gerollt mit Ricotta, Mozzarella und Basilikum, in Tomatensauce im Ofen überbacken.

## Zutaten

| Menge      | Zutat             | Gruppe  | Variante     | Hinweis                    | Einkauf |
| ---------- | ----------------- | ------- | ------------ | -------------------------- | ------- |
| 2          | Auberginen        |         |              | längs in 8 Scheiben à 6 mm | Menge   |
| 250 g      | Ricotta           | Füllung |              |                            | Menge   |
| 125 g      | Mozzarella        | Füllung |              | in Würfeln                 | Menge   |
| 40 g       | Parmesan          | Füllung |              | gerieben                   | Menge   |
| 1          | Ei                | Füllung |              |                            | Menge   |
| 1/2 Bund   | Basilikum         | Füllung |              |                            | 1×      |
| 4 Scheiben | Rohschinken       | Füllung | Mit Schinken | Parma, halbiert            | Menge   |
| 400 g      | Passierte Tomaten | Sauce   |              |                            | Menge   |
| 2          | Knoblauch         | Sauce   |              | Zehen, gehackt             | Menge   |
| 4 EL       | Olivenöl          |         |              |                            | 1×      |
|            | Salz              |         |              |                            | 1×      |
|            | Pfeffer           |         |              |                            | 1×      |

## Zubereitung

1. Backofen auf 200 °C Ober-/Unterhitze vorheizen. Auberginenscheiben beidseitig mit Olivenöl bestreichen, salzen und auf Blechen 15 Minuten backen, bis sie weich sind. ⏱ 15
2. Knoblauch in 1 EL Öl 1 Minute anschwitzen, Tomaten zugeben, salzen und 10 Minuten einköcheln lassen. ⏱ 10
3. Ricotta mit Ei, Parmesan, Mozzarella, Basilikum, Salz und Pfeffer verrühren.
4. [Mit Schinken] Je eine halbe Scheibe Parmaschinken auf die Auberginenscheiben legen.
5. Füllung auf die Scheiben streichen und diese fest aufrollen.
6. Die Hälfte der Sauce in eine Auflaufform geben, die Röllchen mit der Naht nach unten einlegen, mit restlicher Sauce und etwas Parmesan bedecken.
7. 20 Minuten überbacken, bis die Sauce blubbert und der Käse Farbe hat. ⏱ 20

## Notizen

Mit Ciabatta zum Auftunken servieren. Die Auberginenscheiben können auch in der Pfanne gebraten werden.
