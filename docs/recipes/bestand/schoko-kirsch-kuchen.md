# Schoko-Kirsch Kuchen

![Schoko-Kirsch Kuchen](../pictures/schoko-kirsch-kuchen.jpg)

Saftiger Schokoladenkuchen mit Kirschen, einfach gerührt und mit Schokolade überzogen.

## Zutaten

| Menge | Zutat                | Gruppe | Variante | Hinweis                  | Einkauf |
| ----- | -------------------- | ------ | -------- | ------------------------ | ------- |
| 100 g | Butter               |        |          | weich                    |         |
| 100 g | Zucker               |        |          |                          |         |
| 2     | Eier                 |        |          |                          |         |
| 120 g | Mehl                 |        |          |                          |         |
| 30 g  | Kakao                |        |          |                          |         |
| 1 TL  | Backpulver           |        |          |                          |         |
| 50 ml | Milch                |        |          |                          |         |
| 100 g | Zartbitterschokolade |        |          | gehackt                  |         |
| 350 g | Kirschen             |        |          | aus dem Glas, abgetropft | 1×      |
| 50 g  | Kuvertüre            |        |          | zum Überziehen           |         |

## Zubereitung

1. Ofen auf 180 °C Ober-/Unterhitze vorheizen, eine kleine Kastenform fetten und mit Mehl ausstreuen.
2. Butter mit Zucker schaumig rühren, Eier einzeln unterrühren.
3. Mehl, Kakao und Backpulver mischen und abwechselnd mit der Milch einrühren.
4. Gehackte Schokolade und Kirschen vorsichtig unterheben.
5. Teig in die Form füllen und 40 bis 45 Minuten backen, bis ein Holzstäbchen sauber bleibt. ⏱ 42
6. Kuchen abkühlen lassen, Kuvertüre schmelzen und darübergießen.
