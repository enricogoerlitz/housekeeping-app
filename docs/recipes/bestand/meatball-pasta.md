# Meatball Pasta

![Meatball Pasta](../pictures/meatball-pasta.jpg)

Spaghetti mit saftigen Hackbällchen in Tomatensauce.

## Zutaten

| Menge  | Zutat             | Gruppe | Variante        | Hinweis            | Einkauf |
| ------ | ----------------- | ------ | --------------- | ------------------ | ------- |
| 250 g  | Spaghetti         |        |                 |                    |         |
| 300 g  | Hackfleisch       |        | Mit Hackfleisch | gemischt           | Menge   |
| 150 g  | Rote Linsen       |        | Vegetarisch     | gekocht, zerdrückt | Menge   |
| 40 g   | Semmelbrösel      |        |                 |                    |         |
| 1      | Ei                |        |                 |                    |         |
| 1      | Zwiebel           |        |                 | fein gewürfelt     | Menge   |

## Zubereitung

1. [Mit Hackfleisch] Hackfleisch mit Semmelbröseln, Ei, halber Zwiebel, halbem Knoblauch, Salz und Pfeffer verkneten und zu 12 Bällchen formen.
2. [Vegetarisch] Linsen mit Semmelbröseln, Ei, halber Zwiebel, halbem Knoblauch, Salz und Pfeffer verkneten und zu 12 Bällchen formen.
3. Bällchen in Olivenöl 8 Minuten rundum braun braten, herausnehmen. ⏱ 8
4. Restliche Zwiebel und Knoblauch 3 Minuten andünsten, Tomaten und Oregano zugeben und 10 Minuten köcheln. ⏱ 13
5. Bällchen in die Sauce geben und 10 Minuten ziehen lassen. ⏱ 10
6. Spaghetti kochen, mit der Sauce mischen und mit Parmesan servieren. ⏱ 10
