# Garnelen Pasta

![Garnelen Pasta](../pictures/garnelen-pasta.jpg)

Cremige Pasta mit saftigen Garnelen, Kirschtomaten und Spinat, fein mit Parmesan bestreut. Die vegetarische Variante lässt die Garnelen weg und nimmt mehr Gemüse.

## Zutaten

| Menge  | Zutat                | Gruppe | Variante     | Hinweis                           | Einkauf |
| ------ | -------------------- | ------ | ------------ | --------------------------------- | ------- |
| 250 g  | Spaghetti            |        |              |                                   | Menge   |
| 200 g  | Garnelen             |        | Mit Garnelen | küchenfertig, geschält, aufgetaut | Menge   |
| 200 g  | Kirschtomaten        |        |              | halbiert                          | Menge   |
| 100 g  | Blattspinat          |        |              | frisch                            | Menge   |
| 1      | Zucchini             |        | Vegetarisch  | in Halbmonde                      | Menge   |
| 2      | Knoblauch            |        |              | Zehen, gehackt                    | Menge   |
| 200 ml | Sahne                |        |              |                                   | Menge   |
| 40 g   | Parmesan             |        |              | frisch gerieben                   | Menge   |
| 1 EL   | Zitronen             |        |              | Saft                              | 1×      |
| 1 TL   | Italienische Kräuter |        |              | getrocknet                        | 1×      |
| 2 EL   | Olivenöl             |        |              |                                   | 1×      |
|        | Salz                 |        |              |                                   | 1×      |
|        | Pfeffer              |        |              |                                   | 1×      |

## Zubereitung

1. Spaghetti in Salzwasser al dente kochen, 1 Tasse Nudelwasser abnehmen, abgießen. ⏱ 10
2. [Mit Garnelen] Garnelen trocken tupfen, würzen und in 1 EL Olivenöl je Seite 1 bis 2 Minuten anbraten, herausnehmen. ⏱ 3
3. [Vegetarisch] Zucchini in 1 EL Olivenöl 4 Minuten goldbraun anbraten. ⏱ 4
4. Knoblauch und Tomaten in die Pfanne geben und 3 Minuten braten, bis die Tomaten aufplatzen. ⏱ 3
5. Sahne, Kräuter und Parmesan einrühren und 2 Minuten köcheln lassen. Spinat zugeben und zusammenfallen lassen.
6. Nudeln, Garnelen beziehungsweise Zucchini und Zitronensaft untermischen, mit Nudelwasser cremig schwenken.
7. Mit Parmesan bestreut servieren.

## Notizen

Tiefgekühlte Garnelen über Nacht im Kühlschrank auftauen. Bucatini passen besonders gut.
