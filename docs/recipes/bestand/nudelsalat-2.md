# Nudelsalat

![Nudelsalat](../pictures/nudelsalat-2.jpg)

Cremiger Nudelsalat mit Farfalle, Gurke, Paprika, Mais und Dill.

## Zutaten

| Menge | Zutat        | Gruppe | Variante | Hinweis              | Einkauf |
| ----- | ------------ | ------ | -------- | -------------------- | ------- |
| 250 g | Farfalle     |        |          |                      |         |
| 1     | Salatgurke   |        |          | klein gewürfelt      | Menge   |
| 1     | Paprika      |        |          | rot, klein gewürfelt | Menge   |
| 100 g | Mais         |        |          | aus der Dose         | 1×      |
| 1     | Rote Zwiebel |        |          | fein gewürfelt       | Menge   |
| 200 g | Joghurt      |        |          |                      |         |
| 2 EL  | Mayonnaise   |        |          |                      |         |
| 1 EL  | Dill         |        |          | gehackt              | 1×      |
| 1 EL  | Schnittlauch |        |          |                      |         |
| 1 EL  | Zitronen     |        |          | Saft                 |         |
|       | Salz         |        |          |                      |         |
|       | Pfeffer      |        |          |                      |         |

## Zubereitung

1. Farfalle in Salzwasser bissfest kochen, kalt abspülen und abtropfen lassen. ⏱ 10
2. Joghurt, Mayonnaise, Zitronensaft, Dill, Salz und Pfeffer zu einem Dressing verrühren.
3. Gurke, Paprika, Mais und Zwiebel mit den Nudeln vermischen.
4. Dressing unterheben und mindestens 30 Minuten durchziehen lassen. ⏱ 30
