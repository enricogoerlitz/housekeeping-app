# Spaghetti aglio e olio

![Spaghetti aglio e olio](../pictures/spaghetti-aglio-e-olio.jpg)

Der römische Klassiker: Spaghetti in Knoblauchöl mit Chili und Petersilie. Mit wenigen Zutaten in 20 Minuten fertig.

## Zutaten

| Menge    | Zutat       | Gruppe | Variante     | Hinweis                  | Einkauf |
| -------- | ----------- | ------ | ------------ | ------------------------ | ------- |
| 250 g    | Spaghetti   |        |              |                          | Menge   |
| 4        | Knoblauch   |        |              | Zehen, dünn geschnitten  | Menge   |
| 5 EL     | Olivenöl    |        |              |                          | 1×      |
| 1        | Chilischote |        |              | oder 1/2 TL Chiliflocken | Menge   |
| 1/2 Bund | Petersilie  |        |              | gehackt                  | 1×      |
| 200 g    | Garnelen    |        | Mit Garnelen | küchenfertig, aufgetaut  | Menge   |
| 30 g     | Parmesan    |        |              | optional, gerieben       | Menge   |
|          | Salz        |        |              |                          | 1×      |

## Zubereitung

1. Nudelwasser aufsetzen, kräftig salzen. Spaghetti darin al dente kochen, eine Tasse Nudelwasser abnehmen und abgießen. ⏱ 10
2. Olivenöl in einer großen Pfanne bei niedriger Hitze erwärmen, Knoblauch und Chili 3 bis 4 Minuten langsam goldgelb ziehen, nicht bräunen. ⏱ 4
3. [Mit Garnelen] Garnelen trocken tupfen und im Knoblauchöl 2 Minuten braten. ⏱ 2
4. Spaghetti in die Pfanne geben, mit einem Schuss Nudelwasser 1 Minute schwenken, bis die Sauce bindet.
5. Petersilie unterheben, bei Bedarf mit Parmesan bestreuen und sofort servieren.

## Notizen

Knoblauch darf nie braun werden, sonst schmeckt er bitter. OFFEN: Der Eintrag war nur ein Titel.
