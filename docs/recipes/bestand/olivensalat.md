# Olivensalat

![Olivensalat](../pictures/olivensalat.jpg)

Marinierter Salat aus grünen Oliven, Kirschtomaten, Fetawürfeln und roter Zwiebel, den man am besten mit frischem Baguette löffelt.

## Zutaten

| Menge | Zutat         | Gruppe   | Variante | Hinweis               | Einkauf |
| ----- | ------------- | -------- | -------- | --------------------- | ------- |
| 250 g | Kirschtomaten |          |          | halbiert              | Menge   |
| 150 g | Grüne Oliven  |          |          | entsteint, in Ringen  | Menge   |
| 200 g | Feta          |          |          | gewürfelt             | Menge   |
| 1     | Rote Zwiebel  |          |          | klein, fein gewürfelt | Menge   |
| 2 EL  | Petersilie    |          |          | fein gehackt          | 1×      |
| 1     | Knoblauch     |          |          | Zehe, gepresst        | Menge   |
| 3 EL  | Olivenöl      | Marinade |          |                       | 1×      |
| 2 EL  | Balsamico     | Marinade |          | dunkel                | 1×      |
| 1 TL  | Oregano       | Marinade |          | getrocknet            | 1×      |
| 1     | Baguette      |          |          | zum Dippen            | 1×      |
|       | Pfeffer       |          |          |                       | 1×      |

## Zubereitung

1. Olivenöl, Balsamico, Knoblauch, Oregano und Pfeffer in einer Schüssel zur Marinade verrühren.
2. Tomaten, Oliven, Zwiebel und Feta zugeben und vorsichtig vermengen.
3. Petersilie unterheben und 15 Minuten durchziehen lassen. ⏱ 15
4. Baguette in Scheiben schneiden und kurz anrösten.
5. Salat auf die Brotscheiben löffeln oder als Beilage servieren.

## Notizen

Feta ist schon salzig, daher nicht zusätzlich salzen. Am zweiten Tag noch aromatischer.
