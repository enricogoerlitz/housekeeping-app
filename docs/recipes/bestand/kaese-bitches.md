# Käse Bitches

![Käse Bitches](../pictures/kaese-bitches.jpg)

Gemütlicher Brotzeit-Abend: Käseplatte mit Schwarzbrot, Butter, Weintrauben und hochwertigem Schinken.

## Zutaten

| Menge  | Zutat        | Gruppe | Variante | Hinweis                                             | Einkauf |
| ------ | ------------ | ------ | -------- | --------------------------------------------------- | ------- |
| 1      | Käseplatte   |        |          | z. B. Camembert, Bergkäse, Gouda und Frischkäse     | 1×      |
| 750 g  | Schwarzbrot  |        |          | in Scheiben                                         | Menge   |
| 250 g  | Butter       |        |          |                                                     | 1×      |
| 300 g  | Weintrauben  |        |          | rot und grün                                        | 1×      |
| 150 g  | Schinken     |        |          | hochwertig, z. B. luftgetrockneter oder Rohschinken | 1×      |
| 1 Glas | Gewürzgurken |        |          | Cornichons                                          | 1×      |
| 1 EL   | Senf         |        |          | mittelscharf                                        | 1×      |

## Enthält

Noch keine Rezepte; die Platte lebt von den eigenen Zutaten der Sammlung.

## Notizen

So richten: Käse und Butter 30 Minuten vorher aus dem Kühlschrank nehmen, Schwarzbrot in Scheiben schneiden, Trauben in kleine Rispen teilen, Käse und Schinken auf einem großen Brett anrichten, Brot, Butter, Trauben, Gewürzgurken und Senf dazustellen.

Bleibt bewusst eine Sammlung (Entscheidung 26.11.2026: die vorhandene Bewertung soll erhalten bleiben). Einkaufszusatz „hochwertiger“ Schinken steht im Hinweis.
