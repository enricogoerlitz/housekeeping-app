# HFL Gemüse mit Grillkäse

![HFL Gemüse mit Grillkäse](../pictures/hfl-gemuese-mit-grillkaese.jpg)

Kartoffeln, Möhren und buntes Gemüse aus der Heißluftfritteuse, dazu goldbrauner Back- und Grillkäse.

## Zutaten

| Menge  | Zutat         | Gruppe | Variante | Hinweis                                   | Einkauf |
| ------ | ------------- | ------ | -------- | ----------------------------------------- | ------- |
| 500 g  | Kartoffeln    |        |          | festkochend, in Spalten                   | Menge   |
| 3      | Möhren        |        |          | in Stücken                                | Menge   |
| 250 g  | Champignons   |        |          | halbiert                                  | Menge   |
| 1      | Zucchini      |        |          | in dicken Scheiben                        |         |
| 1      | Paprika       |        |          | rot, in Stücken                           |         |
| 2      | Grillkäse     |        |          | Back- und Grillkäse Gartenkräuter (180 g) | 1×      |
| 3 EL   | Olivenöl      |        |          |                                           |         |
| 1 TL   | Paprikapulver |        |          |                                           |         |
| 1 TL   | Salz          |        |          |                                           |         |
| 0,5 TL | Pfeffer       |        |          |                                           |         |

## Zubereitung

1. Kartoffeln und Möhren mit 2 EL Olivenöl, Salz, Pfeffer und Paprikapulver mischen. In der Heißluftfritteuse bei 180 °C 15 Minuten vorgaren. ⏱ 15
2. Champignons, Zucchini und Paprika mit 1 EL Olivenöl und Salz mischen.
3. Gemüse zu den Kartoffeln geben und weitere 12 Minuten garen, zwischendurch einmal schütteln. ⏱ 12
4. Grillkäse in Scheiben schneiden beziehungsweise in der Schale lassen und auf das Gemüse legen oder separat in die Fritteuse geben.
5. 5 bis 6 Minuten bei 180 °C garen, bis der Käse goldbraun ist. ⏱ 6
6. Heiß servieren.

## Notizen

OFFEN: „HFL“ als Heißluftfritteuse gedeutet (auf dem Foto steht „Ideal auch für Air Fryer“ auf der Käsepackung). Das Foto zeigt nur die rohen Zutaten (Rougette Back- und Grillkäse, Kartoffeln, Möhren, Champignons, Paprika, Zucchini), kein fertiges Gericht; deshalb neues Bild. Ohne Heißluftfritteuse: Ofen 200 °C Umluft, Zeiten +5 Minuten.
