# Panierte Jagdwurst mit Fusilli in Tomatensauce

![Panierte Jagdwurst mit Fusilli in Tomatensauce](../pictures/panierte-jagdwurst-mit-fusilli-in-tomatensauce.jpg)

Kindheitsklassiker: knusprig panierte Jagdwurst-Scheiben auf Fusilli in einfacher Tomatensauce.

## Zutaten

| Menge  | Zutat                | Gruppe | Variante      | Hinweis                   | Einkauf |
| ------ | -------------------- | ------ | ------------- | ------------------------- | ------- |
| 250 g  | Fusilli              |        |               |                           | Menge   |
| 4      | Jagdwurst            | Panade | Mit Jagdwurst | dicke Scheiben (ca. 1 cm) | Menge   |
| 4      | Räuchertofu          | Panade | Vegetarisch   | dicke Scheiben            | Menge   |
| 2 EL   | Mehl                 | Panade |               |                           |         |
| 1      | Eier                 | Panade |               |                           |         |
| 60 g   | Paniermehl           | Panade |               |                           |         |
| 3 EL   | Sonnenblumenöl       | Panade |               |                           |         |
| 1 Dose | Gehackte Tomaten     | Sauce  |               | 400 g                     | 1×      |
| 1      | Zwiebeln             | Sauce  |               |                           |         |
| 1      | Knoblauch            | Sauce  |               | Zehe                      |         |
| 1 EL   | Tomatenmark          | Sauce  |               |                           |         |
| 1 TL   | Zucker               | Sauce  |               |                           |         |
| 1 TL   | Italienische Kräuter | Sauce  |               |                           |         |
| 1 TL   | Salz                 |        |               |                           |         |
| 2 l    | Wasser               |        |               |                           | nie     |

## Zubereitung

1. Fusilli in Salzwasser bissfest kochen und abgießen. ⏱ 10
2. Zwiebel und Knoblauch in Öl glasig dünsten, Tomatenmark kurz anrösten, Gehackte Tomaten, Zucker, Kräuter und Salz zugeben und 10 Minuten einköcheln. ⏱ 10
3. Jagdwurst- beziehungsweise Tofuscheiben nacheinander in Mehl, Ei und Paniermehl wenden.
4. In heißem Öl 2 bis 3 Minuten je Seite goldbraun braten, auf Küchenpapier abtropfen. ⏱ 5
5. Nudeln mit der Sauce mischen, die panierten Scheiben darauflegen.
