# Pasta mit Basilikum-Pesto

![Pasta mit Basilikum-Pesto](../pictures/pasta-mit-basilikum-pesto.jpg)

Spaghetti mit selbstgemachtem Basilikum-Pesto.

## Zutaten

| Menge      | Zutat           | Gruppe | Variante     | Hinweis                        | Einkauf |
| ---------- | --------------- | ------ | ------------ | ------------------------------ | ------- |
| 250 g      | Spaghetti       |        |              |                                |         |
| 6 EL       | Basilikum Pesto |        |              | siehe Rezept "Basilikum Pesto" | 1×      |
| 40 g       | Parmesan        |        |              | gehobelt                       | 1×      |
| 1 Handvoll | Kirschtomaten   |        |              | halbiert                       | 1×      |
| 300 g      | Hähnchenbrust   |        | Mit Hähnchen | in Streifen                    | Menge   |
| 1 EL       | Olivenöl        |        |              |                                |         |
|            | Salz            |        |              |                                |         |

## Zubereitung

1. [Mit Hähnchen] Hähnchenstreifen in Olivenöl 6 Minuten braten und salzen. ⏱ 6
2. Spaghetti in Salzwasser bissfest kochen, eine Tasse Nudelwasser abnehmen. ⏱ 10
3. Nudeln mit Pesto und Nudelwasser vermischen (nicht mehr erhitzen).
4. Mit Tomaten, Hähnchen und Parmesan anrichten.

## Notizen

Pesto aus dem Rezept "Basilikum Pesto" oder aus dem Glas. Parmesan ist nicht vegetarisch.
