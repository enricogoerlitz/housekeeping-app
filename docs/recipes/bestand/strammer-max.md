# Strammer Max

![Strammer Max](../pictures/strammer-max.jpg)

Dunkles Brot mit gekochtem Schinken, geschmolzenem Käse und Spiegeleiern, bestreut mit Schnittlauch und grobem Pfeffer. Die vegetarische Variante nimmt Tomatenscheiben statt Schinken.

## Zutaten

| Menge      | Zutat        | Gruppe | Variante     | Hinweis                    | Einkauf |
| ---------- | ------------ | ------ | ------------ | -------------------------- | ------- |
| 2 Scheiben | Schwarzbrot  |        |              |                            | 1×      |
| 1 EL       | Butter       |        |              | zum Bestreichen und Braten | 1×      |
| 4 Scheiben | Kochschinken |        | Mit Schinken |                            | Menge   |
| 1          | Tomate       |        | Vegetarisch  | in Scheiben                | Menge   |
| 2 Scheiben | Gouda        |        |              | oder Emmentaler            | Menge   |
| 4          | Eier         |        |              |                            | Menge   |
| 2 EL       | Schnittlauch |        |              | in Röllchen                | 1×      |
|            | Salz         |        |              |                            | 1×      |
|            | Pfeffer      |        |              | grob gemahlen              | 1×      |

## Zubereitung

1. Backofen auf 200 °C Oberhitze/Grill vorheizen.
2. Brot mit Butter bestreichen.
3. [Mit Schinken] Mit je 2 Scheiben Schinken belegen.
4. [Vegetarisch] Mit Tomatenscheiben belegen.
5. Käse darauf legen und im Ofen 4 Minuten überbacken, bis er schmilzt. ⏱ 4
6. Währenddessen Eier in Butter als Spiegeleier braten, 3 Minuten, das Eigelb soll weich bleiben. ⏱ 3
7. Je 2 Spiegeleier auf die Brote setzen, mit Salz, Pfeffer und Schnittlauch bestreuen.

## Notizen

Dazu passen Gewürzgurken. Die Schinkenmenge gilt für zwei Brote.
