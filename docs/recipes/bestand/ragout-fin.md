# Ragout Fin

![Ragout Fin](../pictures/ragout-fin.jpg)

Klassisches Ragout fin in heller Sauce, mit Käse überbacken, dazu Toast.

## Zutaten

| Menge  | Zutat          | Gruppe | Variante     | Hinweis            | Einkauf |
| ------ | -------------- | ------ | ------------ | ------------------ | ------- |
| 300 g  | Hähnchenbrust  |        | Mit Hähnchen | gegart, in Würfeln | Menge   |
| 250 g  | Champignons    |        |              | in Scheiben        | Menge   |
| 2 EL   | Butter         |        |              |                    |         |
| 2 EL   | Mehl           |        |              |                    |         |
| 250 ml | Hühnerbrühe    |        | Mit Hähnchen |                    | Menge   |
| 250 ml | Gemüsebrühe    |        | Vegetarisch  |                    | Menge   |
| 100 ml | Sahne          |        |              |                    |         |
| 1 EL   | Zitronen       |        |              | Saft               |         |
| 1 EL   | Worcestersauce |        | Mit Hähnchen |                    | 1×      |
| 80 g   | Reibekäse      |        |              | zum Überbacken     | 1×      |
| 4      | Toastbrot      |        |              | zum Servieren      | 1×      |
|        | Salz           |        |              |                    |         |
|        | Pfeffer        |        |              |                    |         |

## Zubereitung

1. Champignons in 1 EL Butter 5 Minuten kräftig anbraten, herausnehmen. ⏱ 5
2. Restliche Butter schmelzen, Mehl 1 Minute anschwitzen, mit Brühe und Sahne ablöschen und 5 Minuten bei geringer Hitze köcheln. ⏱ 5
3. [Mit Hähnchen] Gegarte Hähnchenwürfel zugeben.
4. [Vegetarisch] Mehr Champignons verwenden.
5. Mit Zitronensaft, Worcestersauce, Salz und Pfeffer abschmecken und in Portionsformen füllen.
6. Mit Käse bestreuen und bei 220 °C Oberhitze 10 Minuten gratinieren. ⏱ 10
7. Mit Toast servieren.

## Notizen

Foto zeigt überbackene Schale mit Toast, daran angelehnt. Klassisch auch mit Spargel oder Erbsen.
