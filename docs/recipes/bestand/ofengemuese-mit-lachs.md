# Ofengemüse mit Lachs

![Ofengemüse mit Lachs](../pictures/ofengemuese-mit-lachs.jpg)

Kleine Kartoffeln, grüner Spargel und Oliven auf dem Blech, darauf ein Lachsfilet mit Zitrone. Alles gart gleichzeitig im Ofen.

## Zutaten

| Menge | Zutat        | Gruppe | Variante    | Hinweis                                | Einkauf |
| ----- | ------------ | ------ | ----------- | -------------------------------------- | ------- |
| 2     | Lachsfilet   |        | Mit Lachs   | je ca. 150 g                           | Menge   |
| 250 g | Halloumi     |        | Vegetarisch | in dicke Scheiben                      | Menge   |
| 600 g | Kartoffeln   |        |             | Drillinge, kleine Kartoffeln, halbiert |         |
| 500 g | Spargel      |        |             | grün, untere Enden abgeschnitten       |         |
| 80 g  | Grüne Oliven |        |             | mit Stein                              |         |
| 3 EL  | Olivenöl     |        |             |                                        |         |
| 1     | Zitrone      |        |             | Saft und Abrieb                        |         |
| 2     | Knoblauch    |        |             | Zehen, angedrückt                      |         |
| 1 TL  | Chiliflocken |        |             |                                        |         |
| 1 TL  | Oregano      |        |             | getrocknet                             |         |
|       | Salz         |        |             |                                        |         |
|       | Pfeffer      |        |             |                                        |         |

## Zubereitung

1. Backofen auf 210 °C Ober-/Unterhitze vorheizen.
2. Kartoffeln mit 2 EL Öl, Knoblauch, Oregano, Chili, Salz und Pfeffer vermengen und auf einem Blech 20 Minuten vorbacken. ⏱ 20
3. Spargel und Oliven mit restlichem Öl mischen, auf das Blech geben und 10 Minuten backen. ⏱ 10
4. [Mit Lachs] Lachs mit Zitronenabrieb, Salz und Pfeffer würzen, auf das Gemüse legen und 12 Minuten garen. ⏱ 12
5. [Vegetarisch] Halloumi auf das Gemüse legen und 10 Minuten goldbraun backen. ⏱ 10
6. Mit Zitronensaft beträufeln und servieren.

## Notizen

Im Foto ist es Wildlachs, im Original Wildbachsfilet. Statt grünem Spargel geht auch Brokkoli.
