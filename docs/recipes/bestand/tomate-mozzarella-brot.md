# Tomate-Mozzarella Brot

![Tomate-Mozzarella Brot](../pictures/tomate-mozzarella-brot.jpg)

Geröstetes Brot mit langsam im Ofen geschmorten Kirschtomaten, Knoblauch und Oregano, gekrönt von einer ganzen cremigen Burrata.

## Zutaten

| Menge      | Zutat         | Gruppe | Variante | Hinweis                      | Einkauf |
| ---------- | ------------- | ------ | -------- | ---------------------------- | ------- |
| 300 g      | Kirschtomaten |        |          | ganz                         | Menge   |
| 3          | Knoblauch     |        |          | Zehen, in Scheiben           | Menge   |
| 4 EL       | Olivenöl      |        |          |                              | 1×      |
| 1 TL       | Oregano       |        |          | getrocknet                   | 1×      |
| 4 Scheiben | Ciabatta      |        |          | dick geschnitten             | 1×      |
| 2          | Burrata       |        |          | je 125 g; Ersatz: Mozzarella | Menge   |
| 4 Blätter  | Basilikum     |        |          |                              | 1×      |
|            | Salz          |        |          |                              | 1×      |
|            | Pfeffer       |        |          |                              | 1×      |

## Zubereitung

1. Backofen auf 200 °C Ober-/Unterhitze vorheizen.
2. Tomaten, Knoblauch, 3 EL Olivenöl, Oregano, Salz und Pfeffer in einer Form vermengen und 25 Minuten backen, bis die Tomaten platzen und weich sind. ⏱ 25
3. Brotscheiben mit dem restlichen Öl beträufeln und in den letzten 5 Minuten mit in den Ofen legen. ⏱ 5
4. Brot mit den Tomaten samt Saft belegen.
5. Je 1 Burrata obenauf setzen, mit Basilikum garnieren und sofort servieren.

## Notizen

Burrata erst auf den Tisch aufschneiden, damit die Sahne herausläuft. Statt Burrata geht Mozzarella oder Stracciatella.
