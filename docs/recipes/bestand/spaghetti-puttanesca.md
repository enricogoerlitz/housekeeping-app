# Spaghetti Puttanesca

![Spaghetti Puttanesca](../pictures/spaghetti-puttanesca.jpg)

Würzige Pastasauce aus Tomaten, Oliven, Kapern und Knoblauch mit Chili – in 20 Minuten fertig.

## Zutaten

| Menge  | Zutat            | Gruppe | Variante  | Hinweis                                | Einkauf |
| ------ | ---------------- | ------ | --------- | -------------------------------------- | ------- |
| 250 g  | Spaghetti        |        |           |                                        | Menge   |
| 4      | Sardellen        |        | Klassisch | Filets in Öl                           |         |
| 2      | Knoblauch        |        |           | Zehen, in Scheiben                     |         |
| 1      | Chilischoten     |        |           | klein, in Ringen                       |         |
| 1 Dose | Gehackte Tomaten |        |           | 400 g                                  | 1×      |
| 60 g   | Oliven           |        |           | grün oder schwarz, entsteint, halbiert |         |
| 2 EL   | Kapern           |        |           | abgetropft                             |         |
| 3 EL   | Olivenöl         |        |           |                                        |         |
| 1      | Petersilie       |        |           | Handvoll, gehackt                      |         |
| 1 TL   | Salz             |        |           |                                        |         |
| 2 l    | Wasser           |        |           |                                        | nie     |

## Zubereitung

1. Olivenöl in einer Pfanne bei mittlerer Hitze erwärmen.
2. [Klassisch] Sardellen zugeben und unter Rühren auflösen.
3. Knoblauch und Chili 1 Minute andünsten.
4. Tomaten zugeben und 12 Minuten einkochen lassen. ⏱ 12
5. Oliven und Kapern zufügen und 3 Minuten mitköcheln.
6. Spaghetti in Salzwasser bissfest kochen, 100 ml Nudelwasser aufheben, abgießen. ⏱ 9
7. Nudeln in der Sauce schwenken, bei Bedarf Nudelwasser zugeben und mit Petersilie servieren.

## Notizen

Ohne Sardellen (Vegetarisch) etwas Kapernlake und ein Spritzer Salz für den würzigen Geschmack.
