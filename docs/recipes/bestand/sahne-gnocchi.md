# Sahne-Gnocchi

![Sahne-Gnocchi](../pictures/sahne-gnocchi.jpg)

Goldbraun gebratene Gnocchi in cremiger Parmesan-Sahnesauce mit Zucchini, Kirschtomaten und Spinat. Die Variante mit Schinken ergänzt herzhafte Würfel.

## Zutaten

| Menge  | Zutat         | Gruppe | Variante | Hinweis         | Einkauf |
| ------ | ------------- | ------ | -------- | --------------- | ------- |
| 500 g  | Gnocchi       |        |          | Kühlregal       | Menge   |
| 1      | Zucchini      |        |          | in Halbmonden   | Menge   |
| 150 g  | Kirschtomaten |        |          | halbiert        | Menge   |
| 80 g   | Blattspinat   |        |          | frisch          | Menge   |
| 100 g  | Kochschinken  |        | Schinken | in Würfeln      | Menge   |
| 1      | Zwiebel       |        |          | fein gewürfelt  | Menge   |
| 2      | Knoblauch     |        |          | Zehen, gehackt  | Menge   |
| 200 ml | Sahne         |        |          |                 | Menge   |
| 40 g   | Parmesan      |        |          | frisch gerieben | Menge   |
| 2 EL   | Olivenöl      |        |          |                 | 1×      |
|        | Salz          |        |          |                 | 1×      |
|        | Pfeffer       |        |          |                 | 1×      |

## Zubereitung

1. Olivenöl in einer großen Pfanne erhitzen und die Gnocchi 6 bis 8 Minuten rundum goldbraun braten. Herausnehmen. ⏱ 7
2. [Schinken] Schinkenwürfel 2 Minuten in der Pfanne anbraten. ⏱ 2
3. Zwiebel, Zucchini und Knoblauch 4 Minuten anbraten, Tomaten 2 Minuten mitbraten. ⏱ 6
4. Sahne und Parmesan einrühren und 3 Minuten leicht einkochen lassen. Salzen und pfeffern. ⏱ 3
5. Spinat und Gnocchi zugeben und 1 Minute schwenken, bis der Spinat zusammenfällt. ⏱ 1
6. Mit Parmesan bestreut servieren.

## Notizen

Der alte Eintrag hatte die Varianten „Gemüse (Standard)“ und „Schinken“; Gemüse bleibt Standard. Statt frischer Gnocchi gehen auch TK-Gnocchi, dann etwas länger braten.
