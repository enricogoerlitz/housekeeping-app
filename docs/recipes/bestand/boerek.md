# Börek

![Börek](../pictures/boerek.jpg)

Börek mit hauchdünnen, knusprigen Teigschichten und einer cremigen Feta-Petersilien-Füllung – der Klassiker für Frühstück oder Abendbrot.

## Zutaten

| Menge     | Zutat          | Gruppe  | Variante | Hinweis                 | Einkauf |
| --------- | -------------- | ------- | -------- | ----------------------- | ------- |
| 1 Packung | Yufka-Teig     |         |          | 6 bis 8 Blätter (500 g) | 1×      |
| 250 g     | Feta           | Füllung |          | zerbröselt              | Menge   |
| 1 Bund    | Petersilie     | Füllung |          | fein gehackt            |         |
| 1         | Eier           | Füllung |          |                         |         |
| 100 g     | Reibekäse      | Füllung |          | Mozzarella oder Gouda   |         |
| 150 g     | Joghurt        | Guss    |          |                         |         |
| 2         | Eier           | Guss    |          |                         |         |
| 100 ml    | Milch          | Guss    |          |                         |         |
| 100 ml    | Sonnenblumenöl | Guss    |          |                         |         |
| 1         | Eier           | Guss    |          | Eigelb zum Bestreichen  |         |
| 1 EL      | Sesam          |         |          | zum Bestreuen           |         |

## Zubereitung

1. Ofen auf 180 °C Ober-/Unterhitze vorheizen. Eine Auflaufform oder ein Blech fetten.
2. Feta mit Petersilie, 1 Ei und Reibekäse zur Füllung verrühren.
3. Joghurt, 2 Eier, Milch und Öl für den Guss verquirlen.
4. Yufka-Blätter einzeln mit etwas Guss bestreichen, mit Füllung belegen und locker zusammenfalten oder rollen. Alles nebeneinander in die Form schichten. ⏱ 15
5. Restlichen Guss darübergießen, mit Eigelb bestreichen und Sesam bestreuen.
6. Im Ofen 40 bis 45 Minuten goldbraun backen. ⏱ 40
7. 5 Minuten ruhen lassen, dann in Stücke schneiden.

## Notizen

Yufka gibt es im Kühlregal beim Türkischen Supermarkt; Ersatz sind Filo- oder Strudelteig. Statt Feta passt auch Hackfleisch-Zwiebel-Füllung (OFFEN: Füllung im Foto Käse-Petersilie).
