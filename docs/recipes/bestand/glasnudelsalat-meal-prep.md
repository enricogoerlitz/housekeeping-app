# Glasnudelsalat (Meal Prep)

![Glasnudelsalat (Meal Prep)](../pictures/glasnudelsalat-meal-prep.jpg)

Bunter Glasnudelsalat für die Vorratsboxen: Glasnudeln mit Gurke, Paprika, Edamame, Möhre und angebratenem Tofu, mit frischen Kräutern und scharf-säuerlichem Dressing. Hält sich im Kühlschrank 3 Tage.

## Zutaten

| Menge  | Zutat          | Gruppe   | Variante     | Hinweis                        | Einkauf |
| ------ | -------------- | -------- | ------------ | ------------------------------ | ------- |
| 100 g  | Glasnudeln     |          |              |                                |         |
| 200 g  | Räuchertofu    |          | Mit Tofu     | in Würfel                      | Menge   |
| 250 g  | Hähnchenbrust  |          | Mit Hähnchen | in Würfel                      | Menge   |
| 0,5    | Salatgurke     |          |              | gewürfelt                      |         |
| 1      | Paprika        |          |              | rot, in feine Streifen         |         |
| 2      | Möhren         |          |              | geraspelt oder in feine Stifte |         |
| 100 g  | Edamame        |          |              | TK, ausgelöst                  |         |
| 1 Bund | Koriander      |          |              | gehackt, alternativ Petersilie |         |
| 3 EL   | Sojasauce      | Dressing |              |                                |         |
| 2 EL   | Limetten       | Dressing |              | Saft                           |         |
| 1 EL   | Sesamöl        | Dressing |              |                                |         |
| 1 EL   | Honig          | Dressing |              |                                |         |
| 1 TL   | Chiliflocken   | Dressing |              |                                |         |
| 1      | Knoblauch      | Dressing |              | Zehe, gerieben                 |         |
| 1 EL   | Sonnenblumenöl |          |              | zum Braten                     |         |

## Zubereitung

1. Glasnudeln nach Packungsangabe mit heißem Wasser übergießen und 5 Minuten ziehen lassen, abschrecken, abtropfen und mit der Schere kürzen. ⏱ 5
2. Edamame 3 Minuten in kochendem Wasser garen und abschrecken. ⏱ 3
3. [Mit Tofu] Tofuwürfel im Öl 6 Minuten rundum goldbraun braten. ⏱ 6
4. [Mit Hähnchen] Hähnchen im Öl 7 Minuten durchbraten. ⏱ 7
5. Dressingzutaten verrühren und mit den Nudeln vermengen.
6. Nudeln auf Boxen verteilen, Gurke, Paprika, Möhre, Edamame und Tofu bzw. Hähnchen nebeneinander darauf anrichten und mit Koriander bestreuen.

## Notizen

Das Dressing erst kurz vor dem Essen untermengen, wenn der Salat vorbereitet wird. Räuchertofu gibt es im Kühlregal.
