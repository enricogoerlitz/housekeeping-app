# Gulasch Pasta

![Gulasch Pasta](../pictures/gulasch-pasta.jpg)

Zart geschmortes Gulasch aus Rind und Zwiebeln, mit Nudeln vermengt und mit Parmesan bestreut.

## Zutaten

| 500 g  | Champignons   |        | Vegetarisch     | in Stücken                 | Menge   |
| 3      | Zwiebel       |        |                 | in Streifen                | Menge   |
| 2      | Knoblauch     |        |                 | Zehen                      | Menge   |
| 2 EL   | Tomatenmark   |        |                 |                            |         |
| 2 EL   | Paprikapulver |        |                 | edelsüß                    |         |

## Zubereitung

1. [Mit Rindfleisch] Fleisch salzen und im heißen Öl portionsweise scharf anbraten, herausnehmen.
2. [Vegetarisch] Champignons trocken kräftig braun braten. ⏱ 10
3. Zwiebeln im selben Topf 10 Minuten goldbraun schmoren, Knoblauch und Tomatenmark zugeben. ⏱ 10
4. Paprikapulver und Kümmel kurz anrösten, mit Wein ablöschen und einkochen lassen.
5. Brühe und Paprika zugeben.
6. [Mit Rindfleisch] Fleisch zugeben und zugedeckt 100 Minuten leise schmoren. ⏱ 100
7. [Vegetarisch] Pilze zugeben und zugedeckt 30 Minuten leise schmoren. ⏱ 30
8. Fleisch mit der Gabel zerzupfen, Sauce abschmecken.
9. Nudeln bissfest kochen, mit dem Gulasch vermengen und mit Parmesan servieren. ⏱ 10
