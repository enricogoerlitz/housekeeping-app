# Naan Brot

![Naan Brot](../pictures/naan-brot.jpg)

Weiches Naan aus der Pfanne mit Knoblauchbutter und Kräutern.

## Zutaten

| Menge | Zutat        | Gruppe | Variante | Hinweis                 | Einkauf |
| ----- | ------------ | ------ | -------- | ----------------------- | ------- |
| 300 g | Mehl         |        |          |                         |         |
| 150 g | Naturjoghurt |        |          |                         |         |
| 1 TL  | Backpulver   |        |          |                         |         |
| 1 TL  | Zucker       |        |          |                         |         |
| 1 TL  | Salz         |        |          |                         |         |
| 2 EL  | Öl           |        |          |                         |         |
| 50 g  | Butter       |        |          | für die Knoblauchbutter | 1×      |
| 2     | Knoblauch    |        |          | Zehen, gepresst         | Menge   |
| 1 EL  | Petersilie   |        |          | gehackt                 | 1×      |

## Zubereitung

1. Mehl, Backpulver, Zucker, Salz, Joghurt und Öl zu einem weichen Teig kneten (5 Minuten); mit 2 EL Wasser nachhelfen. ⏱ 5
2. Teig 30 Minuten zugedeckt ruhen lassen. ⏱ 30
3. In 6 Portionen teilen und oval ausrollen.
4. Eine Pfanne ohne Fett heiß werden lassen, Fladen je 2 Minuten pro Seite backen, bis Blasen und braune Stellen entstehen. ⏱ 4
5. Butter mit Knoblauch zerlassen, Naan damit bestreichen und mit Petersilie bestreuen.

## Notizen

Gang als Beilage gesetzt (stand unter Hauptgericht). Passt zu Hummus oder Currys.
