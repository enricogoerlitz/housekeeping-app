# Green Goddess Salat

![Green Goddess Salat](../pictures/green-goddess-salat.jpg)

Fein geschnittener Kohl-Salat in einem knallgrünen Kräuter-Joghurt-Dressing – frisch, cremig und mit Crunch.

## Zutaten

| Menge  | Zutat                | Gruppe   | Variante | Hinweis                    | Einkauf |
| ------ | -------------------- | -------- | -------- | -------------------------- | ------- |
| 0,5    | Spitzkohl            |          |          | in sehr feinen Streifen    | Menge   |
| 1      | Römersalat           |          |          | in feinen Streifen         |         |
| 1      | Gurke                |          |          | klein gewürfelt            |         |
| 1      | Frühlingszwiebeln    |          |          |                            |         |

| 3 EL   | Olivenöl             | Dressing |          |                            |         |

| 1 TL   | Salz                 | Dressing |          |                            |         |

## Zubereitung

1. Kräuter, Knoblauch, Joghurt, Olivenöl, Zitronensaft und Salz im Mixer zu einem leuchtend grünen Dressing pürieren.
2. Spitzkohl, Römersalat, Gurke und Frühlingszwiebeln in eine große Schüssel geben.
3. Paniermehl in einer trockenen Pfanne bei mittlerer Hitze 3 Minuten goldbraun rösten. ⏱ 3
4. Dressing über den Salat geben und gründlich mit den Händen einmassieren.
5. Mit den gerösteten Bröseln bestreuen und sofort servieren.

## Notizen

OFFEN: Die genaue Salatbasis im Video war nicht lesbar (aussehend nach Kohl und Römersalat, Panko-Topping erkennbar); hier so rekonstruiert. Das Dressing hält sich 2 Tage im Kühlschrank.
