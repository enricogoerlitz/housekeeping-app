# Parmigiana di Melanzane

![Parmigiana di Melanzane](../pictures/parmigiana-di-melanzane.jpg)

Auflauf aus geschichteten Auberginenscheiben, Tomatensauce, Mozzarella und Parmesan, im Ofen goldbraun überbacken.

## Zutaten

| Menge  | Zutat             | Gruppe | Variante | Hinweis                | Einkauf |
| ------ | ----------------- | ------ | -------- | ---------------------- | ------- |
| 3      | Aubergine         |        |          | in 1 cm dicke Scheiben | Menge   |
| 5 EL   | Olivenöl          |        |          |                        |         |
| 500 ml | Passierte Tomaten | Sauce  |          |                        | 1×      |
| 1      | Zwiebeln          | Sauce  |          |                        |         |
| 2      | Knoblauch         | Sauce  |          | Zehen                  |         |
| 1 TL   | Zucker            | Sauce  |          |                        |         |
| 1      | Basilikum         | Sauce  |          | Topf                   |         |
| 250 g  | Mozzarella        |        |          | in Scheiben            | Menge   |
| 60 g   | Parmesan          |        |          | gerieben               |         |
| 1 TL   | Salz              |        |          |                        |         |

## Zubereitung

1. Auberginenscheiben beidseitig salzen, 15 Minuten ziehen lassen, trocken tupfen. ⏱ 15
2. Scheiben mit Olivenöl bestreichen und bei 200 °C Umluft auf Backpapier 20 Minuten backen, einmal wenden. ⏱ 20
3. Zwiebel und Knoblauch in Öl dünsten, Passierte Tomaten und Zucker zugeben, 10 Minuten köcheln, Basilikum einrühren. ⏱ 10
4. Auflaufform mit Sauce bedecken, abwechselnd Auberginen, Sauce, Mozzarella und Parmesan schichten, mit Käse abschließen.
5. Bei 190 °C 25 Minuten backen, bis die Oberfläche goldbraun ist. ⏱ 25
6. 10 Minuten ruhen lassen und mit Basilikum servieren.
