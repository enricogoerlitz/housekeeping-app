# Hähnchen gekocht auf Reis

![Hähnchen gekocht auf Reis](../pictures/haehnchen-gekocht-auf-reis.jpg)

Saftig pochiertes Hähnchen mit Ingwer und Frühlingszwiebeln auf Reis, der in der Brühe gegart wird (Hainan-Stil). Die vegetarische Variante pochiert Tofu in Gemüsebrühe.

## Zutaten

| Menge  | Zutat             | Gruppe | Variante     | Hinweis                             | Einkauf |
| ------ | ----------------- | ------ | ------------ | ----------------------------------- | ------- |
| 2      | Hähnchenschenkel  |        | Mit Hähnchen | mit Haut und Knochen                | Menge   |
| 300 g  | Tofu              |        | Vegetarisch  | fest, in dicken Scheiben            | Menge   |
| 160 g  | Jasminreis        |        |              |                                     | Menge   |
| 20 g   | Ingwer            |        |              | in Scheiben, plus 1 TL fein gehackt | Menge   |
| 3      | Knoblauch         |        |              | Zehen, 2 ganz, 1 gehackt            | Menge   |
| 3      | Frühlingszwiebeln |        |              | in Ringen                           | Menge   |

| 600 ml | Gemüsebrühe       |        | Vegetarisch  |                                     | Menge   |

| 1 TL   | Sesamöl           | Sauce  |              |                                     | 1×      |
| 1 TL   | Chiliflocken      | Sauce  |              |                                     | 1×      |
| 1 EL   | Reisessig         | Sauce  |              |                                     | 1×      |
|        | Salz              |        |              |                                     | 1×      |

## Zubereitung

1. [Mit Hähnchen] Wasser mit Ingwerscheiben, ganzen Knoblauchzehen und 1 TL Salz aufkochen, Hähnchenschenkel einlegen, zugedeckt 25 Minuten bei niedriger Hitze gar ziehen lassen, nicht sprudelnd kochen. ⏱ 25
2. [Vegetarisch] Gemüsebrühe mit Ingwerscheiben und ganzen Knoblauchzehen aufkochen, Tofu einlegen und 10 Minuten ziehen lassen. ⏱ 10
3. Gegarte Stücke herausnehmen, warm halten. Brühe durch ein Sieb gießen.
4. Reis waschen und mit 250 ml der Brühe und dem gehackten Knoblauch im Topf zugedeckt 12 Minuten garen, 5 Minuten quellen lassen. ⏱ 12
5. Sojasauce, Sesamöl, Essig, gehackten Ingwer und Chiliflocken zur Sauce verrühren.
6. Fleisch beziehungsweise Tofu in Stücke schneiden, auf dem Reis anrichten, mit Sauce beträufeln und mit Frühlingszwiebeln bestreuen.

## Notizen

Die restliche Brühe als Suppe nebenher trinken. Das Foto zeigt Reis mit Hähnchenstücken, Frühlingszwiebel und Chili.
