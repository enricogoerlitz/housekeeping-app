# Gebratene Asianudeln

![Gebratene Asianudeln](../pictures/gebratene-asianudeln.jpg)

Gebratene Nudeln mit knackigem Gemüse in dunkler Soja-Knoblauch-Sauce, wahlweise mit Tofu oder Steakstreifen.

## Zutaten

| Menge  | Zutat            | Gruppe | Variante    | Hinweis                        | Einkauf |
| ------ | ---------------- | ------ | ----------- | ------------------------------ | ------- |
| 300 g  | Mie-Nudeln       |        |             |                                | Menge   |
| 1      | Paprika          |        |             | in Streifen                    | 1×      |
| 1      | Zwiebeln         |        |             | in Spalten                     | 1×      |
| 200 g  | Grüne Bohnen     |        |             | frisch, in Stücken             | 1×      |
| 3 EL   | Sojasauce        | Soße   |             |                                | 1×      |
| 100 ml | Rinderbrühe      | Soße   |             |                                | 1×      |
| 2      | Knoblauch        |        |             | Zehen, gehackt                 | 1×      |
| 1 EL   | Dunkle Sojasauce | Soße   |             |                                | Menge   |
| 1 EL   | Brauner Zucker   | Soße   |             | Rohrzucker                     | 1×      |
| 300 g  | Rindersteak      |        | Rindersteak | in dünnen Streifen             | Menge   |
| 200 g  | Tofu             |        | Tofu        | fest, gewürfelt                | Menge   |
| 2 EL   | Sonnenblumenöl   |        |             |                                |         |
| 1 EL   | Sesam            |        |             | hell und dunkel, zum Bestreuen |         |

## Zubereitung

1. Mie-Nudeln nach Packungsangabe kochen, abgießen und kalt abschrecken. ⏱ 4
2. Soße aus Sojasauce, dunkler Sojasauce, Rinderbrühe und Zucker verrühren.
3. [Rindersteak] Steakstreifen in 1 EL Öl in einer heißen Pfanne 1 Minute je Seite scharf anbraten, salzen und herausnehmen.
4. [Tofu] Tofuwürfel trocken tupfen und in 1 EL Öl 6 bis 8 Minuten knusprig braten, herausnehmen.
5. Zwiebel, Paprika und Bohnen 4 Minuten im heißen Wok oder in der Pfanne anbraten, Knoblauch kurz mitbraten.
6. Nudeln und Soße zugeben und unter Wenden braten, bis die Soße aufgesogen ist. ⏱ 3
7. Fleisch beziehungsweise Tofu zurückgeben, kurz durchschwenken und mit Sesam bestreuen.
