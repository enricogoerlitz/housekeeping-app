# Schwarzbrot mit Tomate-Mozzarella

![Schwarzbrot mit Tomate-Mozzarella](../pictures/schwarzbrot-mit-tomate-mozzarella.jpg)

Dunkles Brot mit Tomaten- und Mozzarellascheiben, Basilikum und Olivenöl. Das schnelle Abendbrot ohne Kochen.

## Zutaten

| Menge      | Zutat          | Gruppe | Variante | Hinweis           | Einkauf |
| ---------- | -------------- | ------ | -------- | ----------------- | ------- |
| 4 Scheiben | Schwarzbrot    |        |          |                   |         |
| 2 EL       | Butter         |        |          | oder Frischkäse   |         |
| 2          | Tomate         |        |          | reif, in Scheiben |         |
| 1 Kugel    | Mozzarella     |        |          | in Scheiben       |         |
| 1 Handvoll | Basilikum      |        |          |                   |         |
| 1 EL       | Olivenöl       |        |          |                   |         |
| 1 TL       | Balsamicoessig |        |          | optional          |         |
|            | Salz           |        |          |                   |         |
|            | Pfeffer        |        |          |                   |         |

## Zubereitung

1. Brotscheiben nach Wunsch kurz toasten und dünn mit Butter bestreichen.
2. Tomaten und Mozzarella abwechselnd auf das Brot schichten.
3. Mit Salz und Pfeffer würzen, mit Olivenöl und Balsamico beträufeln.
4. Mit Basilikum belegen und sofort essen.

## Notizen

Salzen erst direkt vor dem Essen, sonst zieht das Brot durch.
