# Couscous Salat

![Couscous Salat](../pictures/couscous-salat.jpg)

Orangeroter Couscous-Salat mit Tomatenmark, viel Petersilie und Frühlingszwiebeln – frisch, würzig und perfekt zum Vorbereiten.

## Zutaten

| Menge  | Zutat             | Gruppe | Variante | Hinweis          | Einkauf |
| ------ | ----------------- | ------ | -------- | ---------------- | ------- |
| 200 g  | Couscous          |        |          |                  | Menge   |
| 250 ml | Wasser            |        |          | kochend heiß     | nie     |
| 2 EL   | Tomatenmark       |        |          |                  |         |
| 1 TL   | Paprikapulver     |        |          |                  |         |
| 1 TL   | Chiliflocken      |        |          | nach Geschmack   |         |
| 4 EL   | Olivenöl          |        |          |                  |         |
| 2      | Zitronen          |        |          | Saft             |         |
| 3      | Tomaten           |        |          | fein gewürfelt   |         |
| 1      | Gurke             |        |          | klein gewürfelt  |         |
| 4      | Frühlingszwiebeln |        |          | in feinen Ringen |         |
| 1 Bund | Petersilie        |        |          | fein gehackt     |         |
| 1 Bund | Minze             |        |          | fein gehackt     |         |
| 1 TL   | Salz              |        |          |                  |         |

## Zubereitung

1. Couscous mit Salz in eine Schüssel geben, das kochende Wasser darübergießen, abdecken und 5 Minuten quellen lassen. ⏱ 5
2. Tomatenmark, Paprikapulver und Chiliflocken mit 2 EL Olivenöl verrühren und unter den warmen Couscous mischen, bis er gleichmäßig rot ist.
3. Couscous mit einer Gabel auflockern und abkühlen lassen.
4. Tomaten, Gurke, Frühlingszwiebeln, Petersilie und Minze untermischen.
5. Mit Zitronensaft, restlichem Olivenöl und Salz abschmecken und 15 Minuten durchziehen lassen. ⏱ 15

## Notizen

OFFEN: Das Foto zeigt eine Kısır-ähnliche Mischung, vermutlich mit feinem Bulgur; hier mit Couscous umgesetzt (Titel). Feiner Bulgur ist ein 1:1-Ersatz. Dazu Salatblätter zum Einwickeln.
