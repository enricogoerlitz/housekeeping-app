# Bauernfrühstück

![Bauernfrühstück](../pictures/bauernfruehstueck.jpg)

Herzhaftes Eieromelett mit knusprigen Bratkartoffeln, Zwiebeln, Pilzen und Speck, bestreut mit Schnittlauch. Ein Resteessen, das sich für Gekochtes vom Vortag anbietet.

## Zutaten

| Menge  | Zutat        | Gruppe | Variante  | Hinweis                                     | Einkauf |
| ------ | ------------ | ------ | --------- | ------------------------------------------- | ------- |
| 400 g  | Kartoffeln   |        |           | festkochend, am Vortag gekocht, in Scheiben | Menge   |
| 1      | Zwiebel      |        |           | in Ringen                                   | Menge   |
| 150 g  | Champignons  |        |           | in Scheiben                                 | Menge   |
| 80 g   | Speckwürfel  |        | Mit Speck |                                             | Menge   |
| 4      | Eier         |        |           |                                             | Menge   |
| 2 EL   | Milch        |        |           |                                             | Menge   |
| 2 EL   | Butter       |        |           | zum Braten                                  | 1×      |
| 1 Bund | Schnittlauch |        |           | in Röllchen                                 | 1×      |
| 1      | Tomate       |        |           | zum Anrichten                               | Menge   |
|        | Salz         |        |           |                                             | 1×      |
|        | Pfeffer      |        |           |                                             | 1×      |

## Zubereitung

1. Kartoffelscheiben in 1 EL Butter in einer großen beschichteten Pfanne bei mittlerer bis hoher Hitze 8 Minuten knusprig braten. Herausnehmen. ⏱ 8
2. [Mit Speck] Speckwürfel in derselben Pfanne 3 Minuten auslassen. ⏱ 3
3. Zwiebelringe und Champignons dazugeben und 5 Minuten kräftig anbraten, bis alles Farbe hat. ⏱ 5
4. Eier mit Milch, Salz und Pfeffer verquirlen. Kartoffeln zurück in die Pfanne geben.
5. Eiermasse über alles gießen, Hitze reduzieren und zugedeckt 4 bis 5 Minuten stocken lassen, bis die Unterseite goldbraun ist. ⏱ 5
6. Omelett zur Hälfte zusammenklappen, mit Schnittlauch bestreuen und mit Tomatenhälften servieren.

## Notizen

Kartoffeln lassen sich am besten aus gekochten Resten vom Vortag braten. Mit Gewürzgurken oder Brot servieren.
