# Zitronenkuchen vom Blech

![Zitronenkuchen vom Blech](../pictures/zitronenkuchen-vom-blech.jpg)

Saftiger Zitronenkuchen vom Blech mit Zitronenglasur und Abrieb.

## Zutaten

| Menge   | Zutat       | Gruppe | Variante | Hinweis         | Einkauf |
| ------- | ----------- | ------ | -------- | --------------- | ------- |
| 250 g   | Mehl        |        |          |                 | 1×      |
| 200 g   | Zucker      |        |          |                 | 1×      |
| 150 g   | Butter      |        |          | weich           | 1×      |
| 3       | Eier        |        |          |                 | 1×      |
| 2       | Zitrone     |        |          | Saft und Abrieb | 1×      |
| 1 TL    | Backpulver  |        |          |                 |         |
| 1 Prise | Salz        |        |          |                 |         |
| 150 g   | Puderzucker | Glasur |          |                 | 1×      |

## Zubereitung

1. Ofen auf 180 °C Ober-/Unterhitze vorheizen, eine Auflaufform oder ein kleines Blech (ca. 20 x 30 cm) auslegen.
2. Butter und Zucker 3 Minuten cremig rühren, Eier einzeln unterschlagen, Zitronenabrieb zugeben. ⏱ 3
3. Mehl, Backpulver, Salz und 3 EL Zitronensaft unterrühren.
4. Teig verstreichen und 25 Minuten backen, bis der Kuchen goldgelb ist. ⏱ 25
5. Puderzucker mit 3 EL Zitronensaft glatt rühren, auf den abgekühlten Kuchen streichen und mit Abrieb bestreuen.
