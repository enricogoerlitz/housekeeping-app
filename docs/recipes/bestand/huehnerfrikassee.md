# Hühnerfrikassee

![Hühnerfrikassee](../pictures/huehnerfrikassee.jpg)

Zartes Hähnchenfleisch, Erbsen, Möhren und Champignons in heller Sauce mit Zitrone, dazu Reis. Die vegetarische Variante nimmt Räuchertofu und zusätzliche Pilze.

## Zutaten

| Menge  | Zutat         | Gruppe | Variante     | Hinweis    | Einkauf |
| ------ | ------------- | ------ | ------------ | ---------- | ------- |
| 400 g  | Hähnchenbrust |        | Mit Hähnchen | am Stück   | Menge   |
| 200 g  | Räuchertofu   |        | Vegetarisch  | in Würfel  | Menge   |
| 1      | Möhren        |        |              | in Würfel  |         |
| 200 g  | Champignons   |        |              | geviertelt |         |
| 100 g  | Erbsen        |        |              | TK         |         |
| 1      | Zwiebel       |        |              | gewürfelt  |         |

## Zubereitung

1. [Mit Hähnchen] Hähnchenbrust in der Brühe 15 Minuten sanft gar ziehen, herausnehmen, in Stücke zupfen. Brühe aufheben. ⏱ 15
2. Reis nach Packungsangabe kochen. ⏱ 15
3. Butter schmelzen, Zwiebel, Möhren und Champignons 6 Minuten anbraten. ⏱ 6
4. Mehl darüberstäuben, 1 Minute anschwitzen und mit heißer Brühe unter Rühren ablöschen. 10 Minuten köcheln. ⏱ 10
5. Sahne, Erbsen und Fleisch bzw. Räuchertofu zugeben und 5 Minuten durchziehen lassen. ⏱ 5
6. Mit Zitronensaft, Salz, Pfeffer, Muskat und Kapern abschmecken und mit dem Reis servieren.

## Notizen

Vom Suppenhuhn schmeckt es noch kräftiger. Ein Eigelb zum Legieren macht die Sauce seidig.
