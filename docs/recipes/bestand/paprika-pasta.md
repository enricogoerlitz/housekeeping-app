# Paprika Pasta

![Paprika Pasta](../pictures/paprika-pasta.jpg)

Tagliatelle in cremiger Paprikasauce mit Burrata.

## Zutaten

| Menge      | Zutat         | Gruppe | Variante     | Hinweis         | Einkauf |
| ---------- | ------------- | ------ | ------------ | --------------- | ------- |
| 250 g      | Tagliatelle   |        |              |                 |         |
| 3          | Paprika       |        |              | rot, in Stücken | Menge   |
| 1          | Zwiebel       |        |              | gewürfelt       | Menge   |
| 2          | Knoblauch     |        |              | Zehen           | Menge   |
| 1 EL       | Tomatenmark   |        |              |                 |         |
| 100 ml     | Gemüsebrühe   |        |              |                 |         |
| 1          | Burrata       |        |              |                 |         |
| 1 Handvoll | Basilikum     |        |              |                 |         |
| 3 EL       | Olivenöl      |        |              |                 |         |
| 300 g      | Hähnchenbrust |        | Mit Hähnchen | in Streifen     | Menge   |
|            | Salz          |        |              |                 |         |
|            | Pfeffer       |        |              |                 |         |

## Zubereitung

1. [Mit Hähnchen] Hähnchen 5 Minuten in Öl braten, herausnehmen. ⏱ 5
2. Paprika, Zwiebel und Knoblauch 10 Minuten in Olivenöl braten, Tomatenmark zugeben. ⏱ 10
3. Brühe angießen, 5 Minuten köcheln lassen und ein Drittel der Paprika abnehmen, den Rest pürieren. ⏱ 5
4. Tagliatelle bissfest kochen, mit Sauce und den gebratenen Paprikastreifen mischen. ⏱ 9
5. Burrata zerreißen, auf die Pasta legen und mit Basilikum bestreuen.
