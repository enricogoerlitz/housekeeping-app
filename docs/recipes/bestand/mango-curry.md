# Mango Curry

![Mango Curry](../pictures/mango-curry.jpg)

Fruchtiges Curry mit Mango, Kokosmilch und Kichererbsen, dazu Basmatireis.

## Zutaten

| Menge   | Zutat         | Gruppe | Variante     | Hinweis              | Einkauf |
| ------- | ------------- | ------ | ------------ | -------------------- | ------- |
| 1       | Mango         |        |              | reif, gewürfelt      | Menge   |
| 1 Dose  | Kichererbsen  |        |              | 240 g Abtropfgewicht | 1×      |
| 1       | Zwiebel       |        |              | gewürfelt            | Menge   |
| 2       | Knoblauch     |        |              | Zehen                | Menge   |
| 1 Stück | Ingwer        |        |              | gerieben             | Menge   |
| 2 EL    | Currypaste    |        |              | gelb oder rot        | 1×      |
| 1 Dose  | Kokosmilch    |        |              | 400 ml               | 1×      |
| 1       | Paprika       |        |              | in Streifen          | Menge   |
| 150 g   | Basmatireis   |        |              |                      |         |
| 300 g   | Hähnchenbrust |        | Mit Hähnchen | in Würfeln           | Menge   |
| 1       | Limette       |        |              | Saft                 | 1×      |
| 2 EL    | Koriander     |        |              | frisch               | 1×      |
| 2 EL    | Öl            |        |              |                      |         |
|         | Salz          |        |              |                      |         |

## Zubereitung

1. Reis nach Packungsangabe kochen. ⏱ 12
2. [Mit Hähnchen] Hähnchenwürfel 5 Minuten anbraten, beiseitestellen. ⏱ 5
3. Zwiebel, Knoblauch und Ingwer in Öl 3 Minuten anbraten, Currypaste 1 Minute mitrösten. ⏱ 4
4. Kokosmilch, Paprika und Kichererbsen zugeben und 10 Minuten köcheln. ⏱ 10
5. Mango (und das Hähnchen) zugeben, 5 Minuten erwärmen. ⏱ 5
6. Mit Limettensaft und Salz abschmecken, mit Koriander und Reis servieren.
