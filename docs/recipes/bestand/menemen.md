# Menemen

![Menemen](../pictures/menemen.jpg)

Türkisches Rührei in einer Sauce aus gebratenen Tomaten und grünen Spitzpaprika, mit Brot direkt aus der Pfanne gegessen.

## Zutaten

| Menge | Zutat        | Gruppe | Variante  | Hinweis                       | Einkauf |
| ----- | ------------ | ------ | --------- | ----------------------------- | ------- |
| 3     | Tomaten      |        |           | reif, gewürfelt               | Menge   |
| 2     | Paprika      |        |           | Spitzpaprika, grün, in Ringen | Menge   |
| 1     | Zwiebel      |        |           | fein gewürfelt                | Menge   |
| 100 g | Sucuk        |        | Mit Sucuk | in Scheiben                   | Menge   |
| 4     | Eier         |        |           |                               | Menge   |
| 1 TL  | Paprikamark  |        |           |                               | 1×      |
| 1 TL  | Chiliflocken |        |           |                               | 1×      |
| 2 EL  | Butter       |        |           |                               | 1×      |
| 1     | Fladenbrot   |        |           | oder Baguette zum Dippen      | 1×      |
|       | Salz         |        |           |                               | 1×      |
|       | Pfeffer      |        |           |                               | 1×      |

## Zubereitung

1. [Mit Sucuk] Sucuk in einer Pfanne in 1 EL Butter 3 Minuten anbraten. ⏱ 3
2. Butter in der Pfanne erhitzen, Zwiebel 3 Minuten glasig dünsten und Paprika 3 Minuten mitbraten. ⏱ 6
3. Paprikamark einrühren, Tomaten zugeben, salzen und 8 Minuten schmoren, bis eine dickliche Sauce entsteht. ⏱ 8
4. Eier direkt in die Sauce schlagen, mit Chili und Pfeffer würzen.
5. Bei niedriger Hitze 2 Minuten locker verrühren, bis die Eier gerade gestockt sind, aber noch cremig sind. ⏱ 2
6. Direkt in der Pfanne mit Brot servieren.

## Notizen

Das Rührei soll nicht fest werden; Pfanne früher vom Herd nehmen, die Resthitze gart weiter.
